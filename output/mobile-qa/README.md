# 手机浏览器适配验证

验证日期：2026-09-23。对象为 `web/` Vue 主应用及其实际嵌入的 React 研究页面。

## 已完成的调整

- 手机侧边导航改为可展开、关闭的抽屉，支持 Escape、焦点恢复与安全区；桌面侧边栏状态独立保留。
- 移除手机布局的桌面最小宽度；页头、操作按钮、页签、表单、弹窗和抽屉按窄屏重排。
- 个人空间增加“文件位置”入口，选择目录后自动收起；文件表格在自身区域内横向滚动。
- 报告页操作按钮换行，目录导航压缩，宽表格局部滚动，避免工具栏挤占手机阅读区域。
- Query 选题在手机上点击后直接展示详情，并提供返回列表按钮，避免详情落在长列表末尾。
- 知识库详情页头、图谱搜索工具栏、模型配置列表、智能体编辑弹窗、基本设置与统计卡片适配窄屏。
- 模型和扩展卡片网格的最小列宽限制为容器宽度，防止卡片右侧被裁切。

## 实际浏览器验证

Chrome 中使用模拟视口验证，未使用 iPhone/Android 真机，也未完成 Safari 和深色模式验证。

14 个路由在 320、355、375、390、430、768、769、844 和 1440 CSS 像素宽度完成共 126 次页面宽度检查；其中 844 × 390 为横屏。整页和主内容区域未发现横向溢出。表格、页签等明确设计为局部滚动的区域单独处理。原始测量见 [viewport-audit.json](viewport-audit.json)。

路由：知识总览、研究任务、需求 Query、能力画像、研究报告、收藏、深研对话、智能对话、个人空间、模型设置、智能体管理、扩展、数据总览、企业管理。

交互检查包括：手机导航开关与 Escape 焦点恢复、文件目录选择自动收起、文件搜索及预览、报告目录与操作栏、Query 详情定位及返回列表、知识库详情页签、模型管理弹窗。智能体编辑与基本设置最终布局还使用真实组件的隔离测试页复核；所有测试页仅使用本地模拟数据，测试后已删除。

中途登录会话失效、浏览器重连后继续使用真实应用验证。重连后知识库卡片显示“只读全局”且不能进入，因此图谱最终调整使用真实组件的隔离页验证：288px 下搜索、刷新、索引和设置按钮均可见；320px 下设置面板展开无溢出。早前已检查真实知识库详情页并据溢出结果修复。

最后补充的卡片宽度与 Query 状态标签调整，已重新加载开发服务并在真实页面确认生效。该确认发生在批量尺寸检查之后。
