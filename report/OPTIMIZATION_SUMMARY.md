## 🚀 Phase 2: 下一步优化计划（1-2周）

### 核心优化项

#### 1. 进程池优化 ⭐⭐⭐⭐⭐ (最高优先级)

**现状问题**:
- 每次 Codex 调用启动新进程：300-750ms
- 18次调用（6 agent × 3 turns）= **5.4-13.5秒纯开销**
- 占总时间的 10-20%

**优化方案**:
```
Week 1: 预热进程缓存
  - 后台维护 2-4 个预热进程环境
  - 减少 40-60% 启动时间
  - 预期收益: 10-15% 总体提升

Week 2: 持久化进程池
  - 4-8 个持久化 Codex 进程
  - 基于 IPC 的任务分发
  - 消除进程启动开销
  - 预期收益: 额外 10-20% 提升
```

**总收益**: **20-35% 性能提升**，从 9-18分钟 → 6-12分钟

---

#### 2. 证据门控优化 ⭐⭐⭐

**现状问题**:
- 证据接受率 60-80%
- 大量材料化后被拒绝
- 浪费 15-25秒/agent 中的 20-40%

**优化方案**:
```python
# 材料化前智能过滤
class SmartEvidenceGate:
    - 快速过滤（URL、域名、类型、时效）
    - 质量预测（基于历史接受率）
    - 优先级排序
    - 接受率目标: 85%+
```

**收益**: **节省 5-10秒/agent**，提升证据质量

---

#### 3. 流式输出解析 ⭐⭐

**优化方案**:
- 实时解析 Codex JSONL 输出
- 提前获取最终消息，无需等进程结束
- 预期收益: **5-10% 提升**
