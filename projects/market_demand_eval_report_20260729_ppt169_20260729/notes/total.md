# 01_市场需求发散要求落实与评测汇报

本次汇报聚焦三个问题：文档中的发散要求是否真正落地，完整方法在 Benchmark 中表现如何，以及关键模块到底贡献了什么。当前结论是，三层九项、制胜机理和评测闭环已经形成可运行系统，并获得初步效果证据。下一阶段的重点不是继续增加复杂度，而是补强证据质量、扩大样本并降低运行时延。

---

# 02_核心结论

先看三点结论。第一，A 到 H 的研究路径、三层九项、S1 到 S6、L1 到 L4，以及审计恢复能力已经具备；第二，对通用 Codex Agent 的最新结果为十七胜两平一负，得分率百分之九十；第三，事实证据仍是对通用 Agent 差距最小的维度，二十二点九分钟的平均耗时也仍是规模化验证的主要约束。

---

# 03_原始需求拆解

原始文档允许研究路径、场景战法、装备技术和验证交付充分发散，但最终必须回到五项业务验收。成果必须真正符合领域属性，形成装备能力图像，论证制胜效能，同时兼顾创新性和可实现性。这个拆解决定了项目不是一般性的资料检索工具。

---

# 04_发散问题工程化落实

文档中的发散问题没有被整段复制进每个 Agent 的 Prompt，而是压缩成四层运行机制。十二类分类提问先进入唯一责任分支或专业 Agent，每个角色只获得最多三个专属镜头；六类颠覆逻辑则被整理为十二张反事实种子卡，运行时通常只确定性选择两到三张。S1 先形成竞争性对手体系和反适应假设，S2 再形成机制不同的作战路径，随后 S3 到 S6 逐步转化为突破机制、能力映射、差距成熟度和五到七项具体装备，最后通过五项质量门。整个选卡过程在本地完成，不增加模型调用，而且种子始终被标记为假设镜头而不是事实或必选目录。

---

# 05_分类提问路由

分类提问的主要价值，是先确定唯一主责，避免所有 Agent 重复回答同一批问题。十二类问题被映射到 A到G的主分支或 international_situation 专业 Agent，例如局部战争经验归 C 分支，体系对抗问题归 F 分支，空天、深海、电磁和网络问题归 G 分支。主分支负责主研究路径，前置专业 Agent 只获得最多三个职责专属镜头，其他 Agent 不再重复展开。

---

# 06_颠覆型提问种子卡

这十二张卡不是固定答案，而是把原始颠覆问题压缩为可控的反事实发散镜头。每张卡只保留传统关系、新关系、装备牵引和风险检查等短信息，运行时根据 Query、主分支和 Agent 职责选择少量相关卡。A1 到 F2 只是有界起始集合，智能体仍可在因果约束和质量门下提出 OTHER 新方向，但不能为了覆盖六个维度机械增加无关概念。

---

# 07_发散要求落实矩阵

从落实情况看，需求层、技术层和装备决策层都已经映射成明确产物。运行验收显示，A 到 H 路由、六步推理、九字段能力画像、证据、审计、恢复和并发等主要检查均已通过。当前运行完成、发布就绪和审计批准状态都已经形成工程证据。

# 14_Benchmark测试思路

Benchmark 使用同一批二十条 Query 比较四套系统，并复用真实完成的研究报告。总计形成八十份回答和一百二十个盲评配对，由两名 GPT-5.5 评审专家分别执行 A 对 B 和 B 对 A 的双顺序评审。本轮评审错误数为零，前端也保留了完整运行记录。

---

# 15_从五项要求到八维评测标准

五项业务验收进一步拆成八个可判维度，避免只凭总体印象判断。评审关注任务完成、事实证据、因果机理、军事价值、能力映射、前瞻创新、体系稳健和不确定性验证。篇幅更长、格式更复杂或者术语更多，都不会自动获得更高评价。

# 16_Benchmark总结果

总体结果显示，完整方法对三类基线均领先。对通用 Codex Agent 是十七胜两平一负，得分率百分之九十，百分之九十五区间为百分之七十八到百分之一百；对纯 LLM 和智谱 GLM 均为十九胜一平零负，得分率百分之九十七点五。右侧截图展示了前端保存的二十条 Query 真实结果和八维票型。

# 17_对通用Agent的八维票型

更新后的通用 Codex Agent 对比中，完整方法为十七胜两平一负，得分率百分之九十，百分之九十五置信区间为百分之七十八到百分之一百。八个评测维度现在全部领先，能力映射为七十三比零比七，因果机理为六十八比零比十二。证据与事实可靠性为三十八比十六比二十六，虽然已经由反向转为领先，但仍是差距最小、需要继续加强的维度。条形延续使用平方根压缩示意，准确数据以右侧票数为准。

---

# 18_对纯LLM的八维票型

对纯 LLM 的分维度结果显示，完整方法在八个评测维度全部领先。事实证据、不确定性验证和前瞻创新三个维度均为八十比零比零，说明双 Judge 在这三项上全部支持完整方法。条形采用平方根压缩，使六到七张 Baseline 胜票仍能清晰辨认，但准确大小仍由右侧票数表达。

---

# 19_对智谱GLM的八维票型

对智谱 GLM 的结果同样保持跨维度稳定优势。事实证据、不确定性验证和体系稳健三个维度均为八十比零比零；任务完成、因果机理、能力映射和军事价值均为七十八比零比二。前瞻创新为七十六比一比三，是该组中 Baseline 胜票最多的维度；条形经过平方根压缩后更容易看清这些少数票，但不改变票数结论。

---

# 20_Benchmark结果结论

三类对比共同说明，深度调研的优势不只来自换一个更强基模。纯 LLM 和智谱 GLM 生成快、成本低、通用表达能力强，但缺少多源研究、过程状态、证据审计、机制推演和稳定交付合同；通用 Codex Agent 已具备工具调用和一般任务执行能力，因此与完整方法的差距明显缩小，但仍缺少 A 到 H 领域路由、S1 到 S6、三层九项、能力画像和 L1 到 L4 质量循环。基模提供认知能力，通用 Agent 提供执行框架，专业 Agent 系统负责把复杂研究组织成可追溯、可验证、可正式交付的成果。

---

# 21_消融实验设计

消融实验设置了完整方法、去多源基线和去制胜机理三组。去多源组只把研究基线替换为单一受限通用检索 Agent，其余机理和循环保留；去制胜机理组保留多源基线，但跳过 S1 到 S6 并关闭质量循环。合并后的结果覆盖十条 Query 和双 Judge，仍定位为探索性证据。

---

# 22_合并后消融实验结果

初步消融实验形成三点结论。第一，去除 S1 到 S6 后，完整方法与控制组差值达到九十个百分点，制胜机理是当前最强的核心贡献信号；第二，完整方法对去多源基线领先二十个百分点，说明多源研究提供方向性增益；第三，控制组版本和样本仍有限，应固定代码、模型、Query 与 Judge 后扩样复测，再把当前信号解释为稳定因果证据。

---
