# 动态蜂群提示词

仅用于 `winning_swarm_dynamic_v2`。

- [S1](S1.md)：对手体系战场矛盾种子。
- [S2](S2.md)：任务组织、时序与效应窗口种子。
- [S3](S3.md)、[S4](S4.md)：同权创作池主提示词及语言修订使用的创造合同。
- [S5](S5.md)：最终独立组合评审；已移除被覆盖的旧评审定义。
- [S6](S6.md)：单卡画像的阶段级契约、整卡兼容提示、脊柱与修复提示；动态模式按装备并发，并为五栏分别开隔离会话。
- [S6_1](S6_1.md)、[S6_2](S6_2.md)、[S6_3](S6_3.md)、[S6_4](S6_4.md)、[S6_5](S6_5.md)：五个能力画像栏目的独立作者提示，分别对应概述、装备与技术实现、关键作战流程、形成能力与作战效果、制胜逻辑。运行时仍通过 `load_dynamic_winning_prompt("S6", section="S6_n")` 读取，调用方无需改变。
- [common](common.md)：动态节点包装、开放提示、输出说明与迭代/语言修订片段。

修改正文时保留 section 标记。S6 栏目文件中的标题及标记不进入模型提示，正文按原样读取；修改后重启 worker。栏目提示只负责本栏独有判断，通用输入、身份、JSON 和跨栏隔离约束仍由 `S6.md` 的 `module` / `module_instruction_suffix` 提供；`system` 主要用于整卡规划、兼容和恢复路径，`spine` 只用于非画像结构化判断，三个 `*_repair` 只用于异常修复。实际模式入口与边界见项目 `docs/architecture/winning-execution-flows.md`。
