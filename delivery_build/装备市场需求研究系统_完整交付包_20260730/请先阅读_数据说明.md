# 装备市场需求研究系统完整交付包

本压缩包已经包含程序源码、运行配置和现有研究数据。解压后无需启动程序，也可以直接查看产物。

## 直接查看数据

进入以下目录：

- `outputs/runs/`：每次正式研究任务的完整产物，每个 `run-*` 目录对应一次运行。
- `outputs/evals/`：评测结果、对比结果和判断记录。
- `outputs/knowledge/`：知识索引和来源优先级数据。
- `outputs/js-equipment-benchmark-v1/`：JS 装备市场需求 Benchmark 数据。

每个 `outputs/runs/run-*` 目录中，建议先打开：

1. `report.md`：最终研究报告。
2. `demand_cards.json`：需求卡片。
3. `capability_images.json`：能力画像。
4. `evidence_references.md`：证据引用说明（若该次运行生成）。
5. `delivery-manifest.json`：完整文件清单及 SHA-256 校验值。

`artifacts/`、`agent_sessions/`、`domain.jsonl`、`trace.jsonl`、`run.db` 和 `checkpoints/` 是报告对应的原始材料、智能体会话、审计轨迹与恢复数据，请保留目录结构，不要单独移动其中的文件。

## 启动系统查看

已将 Docker 数据目录改为包内的 `./outputs`，因此启动后会直接读取随包交付的数据：

```bash
cp .env.example .env
docker compose up -d --build
```

浏览器打开：`http://localhost:8080`

如需执行新的真实模型任务，请由接收方自行在 `.env` 中配置密钥。交付包不包含发送方的 `.env`、Codex 登录信息或 `auth.json`。

## 数据库说明

`outputs/application.db` 已通过 SQLite 一致性备份生成，不包含运行中的 `-wal`、`-shm` 临时文件，可直接随包读取。
