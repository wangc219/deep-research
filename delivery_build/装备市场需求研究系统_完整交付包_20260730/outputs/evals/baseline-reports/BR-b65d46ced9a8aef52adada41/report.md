**天基低时延信息支撑精确打击体系研究：市场需求挖掘报告**

**基本判断**  
该概念的核心不是“天基武器”，而是以低轨/中轨/高轨混合星座、星间光链路、战术数据链、星上处理和地面/边缘任务系统，压缩“发现、识别、跟踪、分发、决策、火力协同、毁伤评估”的信息时间。公开可参照对象是美国 SDA 的 PWSA：其运输层定位为 JADC2 的“低时延数据传输、传感器到射手连接、平台直连战术卫通”骨干，采用低轨星座、光学星间链路和射频链路形成网状网络；SDA 还公开称其完整运输层为 300 至 500 多颗 LEO 卫星，750-1200 km 轨道，满编后 95% 地区至少同时可见两颗星、99% 地区至少可见一颗星。来源：[SDA Transport Layer fact sheet](https://www.sda.mil/wp-content/uploads/2024/05/Transport-Layer_distro-A_FINAL.pdf)、[SDA Transport](https://www.sda.mil/transport/)。

**第一层：需求挖掘层**

① **典型作战场景**

1. **远海机动目标持续掌握与跨域火力协同**  
   典型对象是海上编队、机动发射平台、电子战支援节点等高价值、移动性强、窗口短的目标。传统依赖少量高轨或有人平台的 ISR/C2 链路，容易受重访周期、视距链路、平台生存性和跨军兵种数据壁垒限制。需求焦点是：海域广、目标机动快、前沿平台分散，必须由天基系统提供广域发现、轨迹保持、目标态势分发和火力单元协同。

2. **高威胁防空/反介入环境下的分布式作战**  
   当前战场趋势是指挥所、雷达、机场、港口和大型集结节点更容易被持续侦察和远程火力压制。分散部署后，地面骨干通信与空中中继不足以保证跨域协同，需要低轨星座把分散传感器、指挥节点和火力单元接成抗毁网络。

3. **高超声速/弹道/巡航威胁预警、跟踪与拦截支撑**  
   SDA 跟踪层公开定位为对先进导弹威胁，含高超声速系统，提供全球、持续的指示、探测、告警、跟踪和识别，并逐步引入“火控质量”红外传感器；其与运输层集成后用于向战区提供低时延数据。来源：[SDA Tracking Layer fact sheet](https://www.sda.mil/wp-content/uploads/2023/11/Tracking-Layer-Fact-Sheet_FINAL_Oct-2023-1.pdf)、[SDA T3 Tracking release](https://www.sda.mil/sda-seeks-proposals-for-tranche-3-tracking-layer-t3trk-of-the-proliferated-warfighter-space-architecture-pwsa/)。

4. **强电子战与网络攻击条件下的战术信息保障**  
   俄乌战争显示，商业卫星通信、遥感和数据网络对战场通信、态势感知和目标信息流有明显价值，同时地面段、链路段、终端和商业依赖也会成为攻击重点。RAND 指出，商业空间服务提升了乌克兰作战能力，但依赖单一供应商存在可靠性风险；CSIS 也强调 GPS/SATCOM 干扰、欺骗将成为未来常态。来源：[RAND Lessons from the War in Ukraine for Space](https://www.rand.org/pubs/research_reports/RRA2950-1.html)、[CSIS Extending the Battlespace to Space](https://www.csis.org/analysis/chapter-8-extending-battlespace-space)。

② **牵引需求的新战法/新概念技术及制胜机理**

1. **由“杀伤链”转向“杀伤网”**  
   JADC2 的公开定义是连接任意传感器与任意射手，跨域共享数据，并以 AI 支撑联合效应。其制胜机理在于把单线、逐级上报的链式流程改成多节点并行的网络流程，降低单点失效风险，扩大可用传感器和火力组合。来源：[DoD JADC2](https://www.war.gov/News/News-Stories/Article/Article/2948282/dod-officials-discuss-advancements-in-joint-all-domain-command-control/)。

2. **低轨扩散星座替代少量高价值平台**  
   低轨星座的优势是链路短、时延低、补网快、抗毁性更强；劣势是星数多、星座调度复杂、地面站可见时间短、目标信号与背景分离更难。GAO 对 PWSA 的评估明确列出这些优势与挑战，并指出该架构计划至少 300-500 颗 LEO 卫星、到 2029 财年前约 350 亿美元。来源：[GAO-26-107085](https://files.gao.gov/reports/GAO-26-107085/index.html)。

3. **星间光链路与动态路由形成“太空数据骨干”**  
   SDA 运输层采用光学星间链路和射频链路，目标是高数据率、极低时延、网状互联；NASA LCRD 公开验证了 1.2 Gbps 级光通信，称激光通信可比传统射频传输多 10-100 倍数据量。来源：[SDA Transport](https://www.sda.mil/transport/)、[NASA LCRD](https://www.nasa.gov/goddard/esc/lcrd/)。

4. **星上处理与边缘智能缩短信号到信息时间**  
   GAO 披露 PWSA 跟踪星规划星上任务数据处理，将红外原始图像处理成二维航迹并转为标准消息下传。制胜机理是减少原始大数据回传压力，让战区节点更快获得可融合的轨迹/告警信息。来源：[GAO-26-107085](https://files.gao.gov/reports/GAO-26-107085/index.html)。

**第二层：技术攻关层**

④ **能力实现途径总体判断**

| 能力特征 | 实现途径判断 |
|---|---|
| 扩散 LEO 覆盖 | 集成创新：小卫星平台、批产、任务载荷和发射补网成熟，但体系级调度复杂 |
| 星间光链路 | 集成创新为主、局部原理突破：高速光通信已有验证，难点在批产终端、捕获跟踪瞄准、跨厂商互操作 |
| 红外/多源跟踪 | 集成创新 + 关键器件突破：高动态范围红外焦平面、低虚警算法、星上处理是瓶颈 |
| 星上智能处理 | 沿用改进 + 集成创新：AI/边缘计算可用，但空间级算力、功耗、可信验证难 |
| 动态网络与任务管理 | 集成创新：需要把卫星网络、战术网、地面云和任务规划系统统一编排 |
| 抗干扰抗毁 | 集成创新：多路径、多频段、跳频、低截获、网络自愈、终端隐蔽组合实现 |
| 跨域数据链 | 沿用改进 + 集成创新：Link 16 等成熟，但“上天”、跨密级、跨域实时共享复杂。SDA 已公开完成 Link 16 星地传输演示，称其可把部队连成超视距联合力量。来源：[SDA Link 16 demo](https://www.sda.mil/space-development-agency-successfully-completes-space-to-ground-transmission-from-link-16-tactical-data-network/) |
| 体系快速迭代 | 集成创新：商业供应链、开放标准、模块化载荷、数字工程和在轨软件升级共同支撑 |

⑤ **重点攻关核心技术清单**

1. **多轨道混合星座设计**：LEO/MEO/GEO 协同覆盖、轨道面优化、热点区域容量倾斜、星座退化建模。  
2. **星间光通信终端**：轻小型 OCT、捕获-跟踪-瞄准、窄光束稳定、跨厂商互通标准、光/RF 自动切换。  
3. **空间网络协议与动态路由**：移动拓扑路由、断续连接容忍、拥塞控制、任务优先级调度、端到端 QoS。  
4. **高灵敏红外与多源传感载荷**：SWIR/MWIR/LWIR 组合、高动态范围焦平面、低温制冷、杂波抑制、云层/海杂波/地物背景建模。  
5. **星上处理与边缘 AI**：目标检测、航迹生成、跨星关联、异常识别、模型压缩、抗辐照计算、可解释置信度输出。  
6. **时空基准与同步**：星间高精度时间同步、PNT 备份、载荷定标、数据时间戳一致性。  
7. **任务规划与战斗管理软件**：传感器调度、链路调度、任务优先级冲突消解、数据产品分发、人在回路授权接口。  
8. **终端与数据链融合**：小型化多频段相控阵终端、机动平台自动捕获、Link 16/IBS/宽带 IP 网关、跨密级网关。  
9. **抗干扰与网络安全**：抗欺骗导航、频谱感知、跳频/波束赋形、零信任认证、密钥管理、供应链完整性。  
10. **快速制造与在轨运维**：模块化总线、标准载荷接口、批产测试、在轨健康管理、软件 OTA、快速补网发射。

⑥ **耦合关系与短板风险**

1. **红外传感器 + 星上处理 + 低时延链路强耦合**  
   传感器不给出稳定航迹，链路再快也只是更快传递不确定信息；星上处理不过关，原始数据会挤占带宽并拖慢时效。

2. **光链路 + 动态路由 + 姿态控制强耦合**  
   光链路依赖高精度指向，星座高速运动又要求路由实时重构。任何一环不稳，体系会退回低容量、较高时延的 RF 备份。

3. **星座规模 + 地面系统 + 任务软件强耦合**  
   GAO 指出 PWSA 风险不只在单星，而在架构级进度、需求透明度和系统集成；若没有架构级主进度和跨承包商集成，快速螺旋可能变成“单项发射成功、体系能力迟到”。来源：[GAO-26-107085](https://files.gao.gov/reports/GAO-26-107085/index.html)。

4. **战术数据链 + 跨密级安全 + 用户终端强耦合**  
   信息无法低摩擦进入一线平台，天基能力就停留在战略/战役态势层，难以支撑战术级精确协同。

5. **最大卡脖子项**  
   第一瓶颈是“火控级航迹质量的多源融合与低时延可信分发”；第二瓶颈是“批产可互操作星间光链路”；第三瓶颈是“体系级任务管理与地面/边缘软件”。其中任一失败都会把装备降级为一般通信或一般侦察星座，无法支撑精确打击体系闭环。

**第三层：能力图像与效能贡献层**

⑦ **能力图像**

```
天基低时延信息支撑精确打击体系
├─ 感知层：红外预警/跟踪、SAR/EO、射频侦察、商业遥感接入
├─ 传输层：LEO 光链路网、Ka/战术数据链、光地站、地面入口站
├─ 处理层：星上检测、航迹生成、多源融合、置信度评估
├─ 战管层：任务规划、资源调度、数据产品分发、人在回路授权
├─ 终端层：舰机车弹/地面节点接入、跨密级网关、移动平台终端
└─ 韧性层：扩散星座、多路径路由、抗干扰、网络安全、快速补网
```

**指标画像**  
覆盖：由区域周期访问向近全球/全球持续覆盖演进。  
时延：由小时级情报产品向分钟级、秒级告警/轨迹数据演进。  
精度：由提示级、雷达引导级向初始目标级、火控级演进。  
韧性：由少量高价值 GEO 平台向大量低价值 LEO/MEO 混合节点演进。  
互操作：由专用情报链路向 JADC2/战术数据链/商业服务融合演进。

**谱系位置**  
该装备处在“战略天基 ISR/预警系统”和“战术 C2/火力系统”之间，是新一代杀伤网的信息中枢。它不是单一侦察卫星、通信卫星或导航卫星，而是把“感知、传输、处理、战管、终端接入”组合成可快速迭代的体系级装备。公开 PWSA 的 T1 规划包括 126 颗运输层、28 颗跟踪层和 4 颗导弹防御演示星，体现了从单类卫星向分层体系的演进。来源：[SDA T1 launch release](https://www.sda.mil/space-development-agency-completes-successful-launch-of-first-tranche-1-satellites/)。

⑧ **效能贡献评估**

| 杀伤链环节 | 贡献方式 | 可量化方向 |
|---|---|---|
| 发现 | 增加广域持续监视与热点多星覆盖 | 发现概率、首次发现时间、重访间隔 |
| 定位/跟踪 | 多星、多源、星上处理形成连续航迹 | 航迹保持率、更新周期、误差收敛时间 |
| 分发 | 星间光链路与战术数据链直达战区/平台 | 端到端时延、消息投递成功率、跨域节点数 |
| 决策 | 战管软件给出多源一致态势和任务优先级 | 决策时间、态势一致性、误报处置时间 |
| 协同 | 将分散射手接入统一信息网 | 可接入平台数量、跨军种协同时间 |
| 评估 | 快速回传毁伤/效果评估和再任务规划 | BDA 回传时间、再分配任务时间 |

核心效能不是单纯提高火力威力，而是提高“时间优势”：在移动目标窗口关闭前完成态势更新、授权决策和火力协同；提高“体系韧性”：局部卫星、链路、地面站或终端受损后仍保持基本信息服务；提高“资源效率”：让高价值传感器和火力单元按优先级被调度，减少重复侦察和无效等待。

⑨ **发展优先级与近期抓手**

**优先级 1：低时延传输与跨域接入演示**  
近期抓手：建设 6-12 颗小卫星级试验星座，验证星间光链路、Ka 链路、战术数据链网关和地面入口站联动。目标是证明“天基网状路由 + 地面/海空机动终端 + 任务优先级分发”可稳定运行。

**优先级 2：星上处理与多源航迹融合演示**  
近期抓手：搭载红外/光电/射频载荷或接入商业遥感数据，验证星上检测、航迹消息生成、跨星关联和地面融合。重点不是追求一次到位的最高精度，而是建立从提示级到更高质量航迹的螺旋升级路线。

**优先级 3：抗干扰、抗毁与网络安全验证**  
近期抓手：在受控试验环境下开展链路降级、节点失效、地面站不可用、终端移动和网络攻击仿真，验证多路径路由、身份认证、密钥更新、日志追溯和任务连续性。

**优先级 4：任务软件和作战应用沙盒**  
近期抓手：建立“传感器-网络-战管-终端”数字孪生平台，接入真实或半实物终端，开展海上机动目标、导弹预警跟踪、分散平台协同三类场景的闭环演练。GAO 对 PWSA 的批评说明，体系级进度、需求追踪和用户协同必须早于大规模部署固化。

**优先级 5：开放标准与产业链能力**  
近期抓手：制定光通信终端、网络接口、航迹消息、终端接入和跨密级交换的开放规范；用多供应商并行验证降低单点依赖。俄乌经验表明，商业空间能力价值很高，但地面段、链路段和供应商依赖会带来脆弱性，必须从架构设计阶段纳入韧性约束。来源：[RAND](https://www.rand.org/pubs/research_reports/RRA2950-1.html)、[Aerospace CSPS Ukraine space lessons](https://csps.aerospace.org/sites/default/files/2024-10/05c_RussiasWarUkraine_Gleason_20241022.pdf)。

**结论**  
“天基低时延信息支撑精确打击体系”的市场需求已经从单星装备需求转向体系级能力需求：低轨扩散星座负责韧性与低时延，光链路和动态路由负责高速分发，红外/多源感知和星上处理负责可用航迹，战管软件和战术终端负责把信息送到正确用户。近期最值得启动的是小规模星座 + 星地链路 + 战管软件 + 终端接入的一体化演示，而不是先追求满编星座。
