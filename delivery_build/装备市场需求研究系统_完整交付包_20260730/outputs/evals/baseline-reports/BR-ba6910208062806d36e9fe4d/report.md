# 动态时敏目标快速感知-决策-打击一体化研究：市场需求挖掘报告

## 一、需求挖掘层：场景·战法/技术·装备能力特征

### ① 典型作战场景

**场景A：大纵深机动高价值目标窗口捕获。**  
动态时敏目标的本质是“价值高、暴露短、位置快速变化、处置授权链条复杂”。美空军2026版目标指挥条令将TST界定为经联合部队指挥官确认、需要立即响应的高价值短暂目标或即将威胁己方的目标；动态目标处置强调在执行期内“发现、定位、跟踪”后再处置。[AFDP 3-60, Targeting](https://www.doctrine.af.mil/Portals/61/documents/AFDP_3-60/3-60-AFDP-TARGETING.pdf) 典型对象包括机动火力节点、临机展开的远程打击平台、电子战/防空/指挥通信节点、临时集结的无人系统发射与保障节点等。需求焦点不是单件武器射程，而是目标窗口内的信息闭合能力。

**场景B：无人化、低成本、高频次目标在前沿区域快速出现。**  
俄乌冲突显示，小型无人机、巡飞弹、察打一体无人平台使前沿目标的发现、确认、处置节奏显著加快。RUSI在无人机防护研究中指出，俄军侦察-打击活动已覆盖乌克兰作战纵深，并对航空、炮兵、防空等关键资产造成持续损耗；反无人机能力需要在多个战术层级联合布设，而不能只作为未来概念。[RUSI](https://static.rusi.org/protecting-the-force-from-uncrewed-uas.pdf) 这反向说明：一体化系统既要打击时敏目标，也要防止己方关键节点被对手的快速杀伤链捕获。

**场景C：跨域联合作战中的“临机可组合杀伤网”。**  
DARPA ACK项目将传统固定杀伤链转向可临机组合的“杀伤网”，目标是在不同军种、不同域之间快速选择传感器、效应器和支援要素，执行任务与再任务分配。[DARPA ACK](https://www.darpa.mil/research/programs/adapting-cross-domain-kill-webs) 这类场景下，目标可能由天基、空基、地面、网络、电磁频谱或开源情报首先发现，处置手段也不一定来自同一军种或同一作战域。

**场景D：通信受扰、频谱对抗、数据不完整条件下的持续决策。**  
JADC2战略明确要求在退化和受争夺电磁频谱环境中运行，并通过数据标准、弹性基础设施、自动化与AI来压缩决策周期。[JADC2 Strategy](https://media.defense.gov/2022/Mar/17/2002958406/-1/-1/1/SUMMARY-OF-THE-JOINT-ALL-DOMAIN-COMMAND-AND-CONTROL-STRATEGY.pdf) 因此，装备需求不能假设稳定宽带链路，而要支持断续通信、边缘处理、权限降级、任务式指挥和本地闭环。

### ② 牵引需求的新战法/新概念技术及制胜机理

**从杀伤链到杀伤网。**  
线性“传感器-指挥所-火力单元”在时敏目标面前容易被一个节点、一个链路或一次授权延迟拖垮。杀伤网强调把传感器、指挥控制、效应器、保障节点以模块化方式实时组合。制胜机理是提高可用组合数量，降低单点失效影响，在目标窗口内选择“可用、可信、代价合适”的处置路径。

**从平台中心到数据中心。**  
CJADC2官方说明强调其不是单一系统，而是从战术边缘到战略层级的一组互联能力，用于为联合指挥员提供更清晰的态势图，并连接盟友伙伴的指挥控制系统。[CDAO CJADC2](https://www.ai.mil/Initiatives/CJADC2/) 制胜机理是让数据先于平台流动，形成跨层级共享态势和机器可读任务数据，使目标识别、火力匹配、授权建议和毁伤评估可以连续迭代。

**AI辅助目标识别与决策压缩。**  
美国陆军Project Convergence公开文章称，传统目标处理受通信低效和传感器到射手数据传输延迟限制；引入JADC2、战术云和AI工具后，目标循环可由小时级压缩到分钟级。[Project Convergence](https://www.lineofdeparture.army.mil/Journals/Field-Artillery/Field-Artillery-Archive/Field-Artillery-2025-E-Edition/Project-Convergence/) 制胜机理是用机器处理海量ISR视频、图像、轨迹、电磁和报告数据，把人从低价值筛选中释放出来，转向确认、授权和风险判断。

**边缘自治与断链持续作战。**  
军事评论对多域AI的分析指出，目标检测模型可部署在边缘设备上以处理大量视频图像，但高质量数据、模型更新、带宽、伪装欺骗、多光谱融合仍是难点。[Army University Press](https://www.armyupress.army.mil/Journals/Military-Review/Online-Exclusive/2024-OLE/Multidomain-Battlefield-AI/) 制胜机理是把部分识别、跟踪、优先级排序和毁伤回传前推到传感器或平台侧，在通信受限时仍维持态势更新。

**低成本巡飞/无人效应器扩张。**  
MarketsandMarkets预计巡飞弹市场从2025年53.6亿美元增至2030年132.6亿美元，CAGR为19.9%，增长驱动包括低成本精确打击、AI、自主控制和模块化设计。[MarketsandMarkets](https://www.marketsandmarkets.com/Market-Reports/loitering-munition-market-139489979.html) 这表明采购需求正从少量高端弹药转向可规模化、可分布部署、可与传感器网络耦合的效应体系。

### ③ 装备能力特征清单

| 能力域 | 定性特征 | 定量指标方向 |
|---|---|---|
| 多源快速感知 | 天/空/地/海/电磁/开源多源接入，支持主动与被动感知 | 目标首次发现时延、覆盖刷新率、目标漏警率/虚警率、多源接入种类 |
| 目标识别与置信评估 | AI辅助识别、人工确认、置信度可解释、对伪装和诱饵鲁棒 | 识别准确率、低能见度识别率、跨谱段一致性、误识别率 |
| 连续跟踪与轨迹预测 | 目标消失、遮挡、通信中断后可保持航迹假设 | 航迹保持时间、重捕获时间、轨迹误差增长率 |
| 弹性通信与数据织网 | 断续链路、多路径传输、数据优先级、跨域共享 | 端到端时延、可用带宽下限、断链恢复时间、数据同步一致性 |
| AI辅助决策 | 候选处置方案生成、火力/传感器/授权/风险综合排序 | 方案生成时间、推荐命中率、人工工作负荷下降比例 |
| 跨域任务分配 | 传感器、效应器、支援要素动态匹配 | 可用资产发现时间、重任务分配时间、任务成功概率估计误差 |
| 人在回路与规则约束 | 授权、交战规则、附带损害、友邻识别嵌入流程 | 人工确认时间、规则冲突告警率、误授权拦截率 |
| 末端效应接口 | 对接火力、电子、网络、无人效应器；支持非动能与动能选项 | 接口标准数量、效应单元接入时间、处置窗口捕获率 |
| 毁伤评估与反馈学习 | 自动回传BDA、模型再训练、任务复盘 | BDA生成时间、评估可信度、模型更新周期 |

## 二、技术攻关层：能力实现途径与核心技术

### ④ 能力实现途径总体判断

| 能力特征 | 实现途径判断 | 理由 |
|---|---|---|
| 多源感知接入 | 集成创新 | 单类传感器成熟，难点是异构协议、时间基准、坐标基准、置信度融合 |
| AI目标识别 | 沿用改进 + 集成创新 | 视觉/红外/雷达AI已有基础，但战场域迁移、伪装对抗、样本不足需强化 |
| 连续跟踪预测 | 集成创新 | 多目标跟踪算法成熟，难点在断续观测、诱饵、低可信数据融合 |
| 弹性通信 | 集成创新 + 局部突破 | 需要多链路、自组网、抗干扰、数据压缩、优先级调度协同 |
| AI辅助决策 | 集成创新 | 不是完全自动决策，而是面向指挥员的方案生成、风险评估和解释 |
| 跨域任务分配 | 集成创新 + 原理突破边缘 | DARPA ACK显示“能力市场/虚拟联络官”仍在探索，跨域价值函数难 |
| 人在回路控制 | 沿用改进 | 技术可实现，关键在流程、界面、审计、授权模型与训练 |
| 末端效应接口 | 沿用改进 + 集成创新 | 重点是开放接口、标准化任务数据包、火控安全边界 |
| BDA反馈学习 | 集成创新 | 毁伤评估可自动化，但标签可信、因果归因、快速更新仍难 |

### ⑤ 需重点攻关的核心技术清单

1. **多源数据标准化与时空对齐**：统一目标ID、坐标框架、时间戳、置信度、数据血缘、权限标签。  
2. **边缘多模态目标检测**：EO/IR、SAR、雷达、声学、RF、电子支援数据融合；支持小样本、域自适应、低光照和遮挡。  
3. **对抗鲁棒识别**：反伪装、反诱饵、反对抗样本；跨谱段一致性校验。  
4. **断续观测多目标跟踪**：航迹关联、重识别、轨迹预测、目标消失后的概率保持。  
5. **目标价值与处置窗口建模**：目标价值、威胁紧迫度、窗口持续时间、误伤风险、资源代价的统一评分。  
6. **跨域资产发现与匹配算法**：实时发现可用传感器、通信、效应器和保障资源，生成候选组合。  
7. **弹性数据织网**：多链路路由、低带宽摘要传输、断点续传、优先级队列、零信任/数据中心安全。  
8. **人机协同决策界面**：以少量高置信候选方案呈现，显示证据链、风险项、授权状态和备选方案。  
9. **任务式指挥与授权策略引擎**：把交战规则、禁限区、友邻态势、附带损害约束转化为机器可检查规则。  
10. **效应器开放接口**：非动能、动能、无人平台、传统火力之间的任务数据模型和安全隔离接口。  
11. **快速BDA与闭环学习**：多源毁伤评估、目标再出现判断、模型漂移检测、训练数据回流。  
12. **数字孪生/仿真验证环境**：在红蓝对抗、通信受扰、频谱拥塞、目标伪装条件下验证整体闭环。

### ⑥ 技术耦合关系与短板风险

**最核心耦合：数据织网 × 目标识别 × 授权决策。**  
识别模型再强，如果数据无法跨域共享，系统只能形成局部优势；通信再强，如果目标置信度不可解释，授权环节会阻塞；授权流程再快，如果数据血缘和规则校验不足，会放大误判风险。

**第一卡脖子：跨域数据标准与权限标签。**  
JADC2战略把数据企业、共同标准、分层安全和伙伴共享作为基础方向。[JADC2 Strategy](https://media.defense.gov/2022/Mar/17/2002958406/-1/-1/1/SUMMARY-OF-THE-JOINT-ALL-DOMAIN-COMMAND-AND-CONTROL-STRATEGY.pdf) 若数据不能被发现、访问、解释和审计，AI和任务分配都无法稳定工作。

**第二卡脖子：受扰环境下的通信与边缘自治平衡。**  
完全依赖云端会在强对抗中失效，完全依赖本地自治又会带来协同不足和授权风险。必须把“云端全局优化”和“边缘降级运行”结合起来。

**第三卡脖子：AI模型的战场域迁移。**  
公开研究指出，高质量训练数据、敌方新装备/TTP、伪装欺骗、模型更新带宽都是目标检测部署难点。[Army University Press](https://www.armyupress.army.mil/Journals/Military-Review/Online-Exclusive/2024-OLE/Multidomain-Battlefield-AI/) 若模型不能快速适配，系统会在真实环境中出现高虚警、高漏警，最终拖慢而不是压缩决策。

**第四卡脖子：跨域价值函数。**  
DARPA ACK点明，不同作战域有各自权限、任务和资源代价，难以快速比较支援其他任务的价值与成本。[DARPA ACK](https://www.darpa.mil/research/programs/adapting-cross-domain-kill-webs) 若没有统一价值函数，杀伤网会退化为人工协调。

## 三、能力图像与效能贡献层

### ⑦ 装备能力图像

**系统定位：战术-战役级动态目标闭环系统。**  
它不是单一巡飞弹、无人机或火控软件，而是“前沿感知节点 + 边缘AI + 弹性通信 + 指挥决策应用 + 效应器接口 + BDA反馈”的系统-of-systems。

**能力域构成：**

- 感知层：无人机、地面传感器、雷达、电子支援、卫星/航空侦察、开源与人工报告接入。  
- 融合层：目标ID、航迹关联、置信度融合、时空基准统一。  
- 决策层：目标价值排序、候选处置方案、授权状态、风险提示。  
- 行动层：对接传统火力、电子压制、网络效果、巡飞/无人效应器等。  
- 反馈层：毁伤评估、目标重现监测、模型更新、任务复盘。

**指标画像：**

- 时间：从小时级流程压缩到分钟级，并向关键环节亚分钟级告警、推荐、分发演进。  
- 精度：从单源坐标/人工判读转向多源置信融合。  
- 韧性：从固定链路转向多链路、断续通信、边缘降级运行。  
- 规模：从少量重点目标处置转向大量候选目标自动筛选。  
- 协同：从军种内闭环转向跨域、跨层级、盟伴共享。  
- 安全：从事后审查转向内嵌规则、审计和人工授权。

**谱系位置：**

- 高于传统炮兵侦察校射/单平台火控系统：它处理跨域多源数据和动态任务分配。  
- 低于国家级/战区级全域C2：它面向具体动态目标闭环和战术-战役执行。  
- 横向连接无人系统、巡飞弹、反无人机、电子战、战术云、战场管理系统。  
- 是CJADC2/JADC2概念在动态目标处置方向的垂直应用层，而不是替代CJADC2本身。

### ⑧ 效能贡献评估

**对杀伤链的贡献方式：**

1. **Find/Sense：** 增加多源发现概率，降低单一传感器盲区。  
2. **Fix/Track：** 用多源航迹关联提高目标连续性，减少目标短暂消失导致的窗口丢失。  
3. **Target/Decide：** AI生成候选方案，人负责确认与授权，减少低价值人工筛选。  
4. **Engage/Act：** 快速匹配可用效应器，支持动能与非动能选项。  
5. **Assess：** BDA自动回流，支持再次发现、再次评估和模型更新。

**可量化方向：**

- 目标窗口捕获率：目标暴露期间形成可授权处置方案的比例。  
- 传感器到决策时延：从首次发现到形成候选方案的时间。  
- 决策到任务分发时延：授权后到相关单元收到任务数据的时间。  
- 航迹连续率：动态目标在遮挡、静默、断链后的可保持比例。  
- 误报处置负担：每名操作员每小时需人工复核的低置信告警数量。  
- 资源经济性：单位目标处置所需传感器占用、通信资源、弹药/效应器数量。  
- 系统韧性：链路受扰、节点损失、数据延迟条件下的任务完成率下降幅度。  
- BDA闭环速度：处置后形成可信评估并反馈态势图的时间。  
- 联合互操作性：跨军种/盟伴系统可交换任务数据的比例和成功率。

### ⑨ 发展优先级与近期抓手

**优先级一：数据织网与目标数据模型。**  
先做统一目标对象模型、数据血缘、置信度、权限标签和审计机制。没有这一层，后续AI和跨域任务分配会成为烟囱式演示。

**优先级二：边缘AI目标识别与多源航迹融合。**  
聚焦“低带宽、低算力、断续通信、伪装干扰”条件下的识别与跟踪。近期目标应是稳定减少人工筛选负担，而不是追求完全自动化。

**优先级三：人机协同决策与规则引擎。**  
把人工确认、交战规则、禁限区、友邻识别、附带损害提示做成可审计流程。军事价值来自压缩认知负担，而不是绕开指挥责任。

**优先级四：跨域资产匹配与任务再分配。**  
参考ACK的能力市场思路，先在有限资产池内做“传感器-通信-效应器”匹配，再扩展到跨军种、跨域、盟伴共享。

**优先级五：开放效应器接口与BDA闭环。**  
先接入训练弹、模拟效应、电子压制和无人平台，再逐步扩展传统火力系统接口，降低验证风险。

**近期可启动演示验证项目构想：**

1. **“分钟级动态目标闭环”演示。**  
   在封闭试验场使用无人机、地面传感器和模拟目标，验证发现、识别、航迹融合、方案推荐、人工确认、模拟效应、BDA回传全流程。核心指标：端到端时延、目标窗口捕获率、虚警负担。

2. **“受扰通信下边缘降级运行”演示。**  
   设置带宽下降、链路中断、数据延迟情形，验证边缘节点本地识别、摘要上报、断链重同步和任务再分配。核心指标：断链期间航迹保持率、恢复后数据一致性、任务成功率下降幅度。

3. **“多模态反伪装识别”演示。**  
   对同一类目标采集可见光、红外、雷达/RF等数据，测试遮挡、伪装、诱饵和热特征变化下的识别稳定性。核心指标：低能见度识别率、跨谱段一致性、误识别率。

4. **“能力市场式跨域任务分配”演示。**  
   建立有限资产池，包含若干传感器、通信节点、模拟效应器和支援节点，系统自动生成多套候选组合，由指挥员选择。核心指标：方案生成时间、可解释性评分、资源利用率、重任务分配时间。

5. **“BDA-模型更新闭环”演示。**  
   将处置后图像、传感器变化和人工标签回流训练库，验证模型漂移检测、样本管理和快速更新流程。核心指标：BDA生成时间、标签可信度、模型更新周期、更新后识别增益。

**结论性判断：**  
该方向的市场需求不是单纯采购更远、更快或更大威力的效应器，而是采购一套能在受扰环境中把“发现、理解、授权、分配、反馈”压缩到目标窗口内的系统能力。近期最值得投入的不是完全自主打击，而是数据标准、边缘AI、多源融合、弹性通信、人机协同授权和BDA闭环的可验证组合。
