# 大规模离散目标低成本精确打击研究：市场需求挖掘报告

## 一、需求挖掘层

### ① 典型作战场景

**场景 A：前沿“透明战场”下的分散机动目标压制**

俄乌战场显示，小型无人机广泛用于侦察与打击，使装甲集群、补给车队、炮兵阵地和小分队活动更易暴露。IISS 将其概括为 UAV 侦察与打击的普遍化，造成“透明战场”，迫使俄军放弃装甲集中突击，转向更分散、更小规模的行动方式。[IISS](https://www.iiss.org/globalassets/media-library---content--migration/files/publications---free-files/strategic-dossier/uavs-2026/iiss_ch-3-uavs-isr-deterrence-and-war_032026.pdf)

适用目标：分散车辆、临时火力点、小型雷达/通信节点、无人平台集结点、补给与工程装备。  
需求本质：传统火炮/导弹对大量低价值、短暴露目标的成本和反应速度不匹配，需要“低成本、可消耗、可批量、近实时”的打击手段。

**场景 B：纵深后勤与防空体系的低成本饱和消耗**

CSIS 对 Shahed 无人机战役的分析指出，低成本无人机可用于饱和防空并迫使对方消耗更昂贵拦截弹；其估算 Shahed 单价约 2 万至 5 万美元，而现代防空拦截弹成本显著更高。[CSIS](https://www.csis.org/analysis/drone-saturation-russias-shahed-campaign)

适用目标：纵深军事仓储、集结地域、机场辅助设施、防空火力单元周边支撑节点。  
需求本质：不是单纯追求单发毁伤，而是通过规模、持续性和成本交换优势削弱对方防御体系。

**场景 C：岛礁、濒海和跨域拒止环境中的分布式精确火力**

美国“Replicator”倡议明确提出，要在 18 至 24 个月内部署“多域、可消耗、自主系统”达到数千规模，以应对大国竞争中的“质量/数量优势”和 A2/AD 挑战。[U.S. DoD](https://www.defense.gov/News/Speeches/Speech/Article/3517213/deputy-secretary-of-defense-kathleen-hicks-remarks-unpacking-the-replicator-ini/)  
同一倡议的后续公告还提到，入选能力包括小型 UAS、巡飞弹、低成本远程打击能力、海上无人系统，以及可协调数百至数千无人资产的软件使能能力。[U.S. DoD](https://www.defense.gov/News/Releases/Release/Article/3963289/deputy-secretary-of-defense-kathleen-hicks-announces-additional-replicator-all/)

适用目标：跨域分散传感器、舰艇辅助单元、登陆支撑节点、前沿补给点。  
需求本质：在昂贵平台难以进入或不宜暴露的区域，用可消耗无人系统形成分布式侦打能力。

### ② 牵引需求的新战法/技术概念及制胜机理

**1. “小、智、廉、多”的可消耗自主体系**

DoD 对 Replicator 的表述是“small, smart, cheap, and many”，核心不是替代高端平台，而是在高端平台之外增加数量、弹性和风险承受能力。[U.S. DoD](https://www.defense.gov/News/Speeches/Speech/Article/3517213/deputy-secretary-of-defense-kathleen-hicks-remarks-unpacking-the-replicator-ini/)

制胜机理：  
- 用低成本平台承担高风险任务，降低人员与高价值装备暴露。  
- 用数量制造防御压力，使对方探测、拦截、处置资源被稀释。  
- 用快速迭代缩短“发现问题到改进装备”的周期。

**2. 侦察-打击一体化与杀伤链压缩**

澳大利亚陆军研究指出，小型 UAS 已将部分炮兵时敏目标链路从约 30 分钟压缩至 3 至 5 分钟；CSIS 也提到乌克兰利用 AI 辅助无人机起降、目标识别和信息处理，在个别情况下将发现到打击压缩到约 30 秒量级，但仍有人类监督。[Australian Army Research Centre](https://researchcentre.army.gov.au/sites/default/files/241022-Occasional-Paper-29-Lessons-Learnt-from-Ukraine_2.pdf)、[CSIS](https://www.csis.org/analysis/chapter-9-technological-evolution-battlefield)

制胜机理：  
- 目标暴露窗口短，胜负取决于感知、判别、授权、分配、打击的总时延。  
- 无人侦察与低成本打击器在战术层下沉，使连排级也能获得过去需要上级火力链支援的能力。  
- AI 主要贡献在数据筛选、目标提示、航迹/任务辅助，而不应替代合法性判断和用武授权。

**3. 群体协同与人机编队**

DARPA OFFSET 项目曾面向城市环境，研究 250 架级小型无人空中/地面系统的集群战术生成、人-群交互和仿真验证。[DARPA](https://www.darpa.mil/research/programs/offensive-swarm-enabled-tactics)  
美陆军 HMI 实验也强调，人机融合不是机器替代人，而是把风险和负担转移给机器，并提出“No blood for first contact”。[U.S. Army](https://www.army.mil/article/282372/human_machine_integration_tactical_level_employment_and_the_exfor_ras_platoon)

制胜机理：  
- 单个平台性能不必极高，体系通过协同侦察、任务分配、诱饵、佯动和打击组合形成效果。  
- 指挥员从“遥控单机”转为“管理任务、约束和授权”。  
- 编队冗余提高抗损耗能力。

**4. 抗干扰、抗链路中断的边缘自治**

IISS 指出，俄乌双方使用空中中继、低轨卫星通信和平台无关态势系统来扩展小型 UAV 的通信范围，并减小链路中断对打击准确性的影响。[IISS](https://www.iiss.org/globalassets/media-library---content--migration/files/publications---free-files/strategic-dossier/uavs-2026/iiss_ch-3-uavs-isr-deterrence-and-war_032026.pdf)  
EUISS 也指出，无人机与反制手段之间的技术优势往往只能维持数周，必须依靠前线反馈和快速软件/组件迭代。[EUISS](https://www.iss.europa.eu/publications/briefs/minding-drone-gap-drone-warfare-and-eu)

制胜机理：  
- 在强电磁对抗环境中，单纯依赖遥控链路和 GNSS 的系统生存性不足。  
- 需要“可降级运行”：通信良好时协同，通信受限时保持安全、可控、可终止或返回/失效。  
- 胜负不只在平台，还在软件更新、频谱适应、任务数据闭环。

### ③ 装备能力特征清单

| 能力域 | 定性特征 | 定量指标方向 |
|---|---|---|
| 低成本可消耗平台 | 单机成本低、可批产、可接受战损 | 单位目标处置成本较传统精确弹药低 1 个数量级以上；批量为百/千级 |
| 分布式侦察识别 | EO/IR、多源情报、目标提示、人审确认 | 目标发现到火力分配从分钟级向亚分钟级演进 |
| 精确末端效应 | 对轻装甲、软目标、雷达/通信设备等差异化毁伤 | CEP/命中概率按任务类型分级，不追求一型通吃 |
| 抗干扰通信与导航 | 多链路、空中中继、低轨通信、惯性/视觉辅助 | 支持 BLOS 或中继扩展；链路中断时可安全降级 |
| 群体协同与任务分配 | 多平台协同搜索、去冲突、重分配 | 单操作员管理多平台；编队规模从十级向百级验证 |
| 人机协同 C2 | 人在回路/人在监督，授权边界清晰 | 支持任务级控制、可审计日志、规则约束 |
| 模块化载荷 | 侦察、诱饵、通信中继、电子支援、打击载荷可换 | 开放接口、快速换装、软硬件 OTA/批量配置 |
| 快速生产与保障 | 商业供应链、分布式装配、战场反馈闭环 | 迭代周期以周/月计；关键部件多源化 |
| 测试认证与安全 | 可靠性、误伤控制、网络安全、抗篡改 | 建立仿真-实飞-对抗测试闭环，符合武器审查和交战规则 |

## 二、技术攻关层

### ④ 能力实现途径总体判断

| 能力特征 | 实现途径判断 | 理由 |
|---|---|---|
| 低成本平台 | 沿用改进 + 集成创新 | 商用无人机、航电、电池、通信组件成熟，但军用可靠性、环境适应和批产质控需改进 |
| 分布式侦察识别 | 集成创新 | 传感器成熟，难点在多源数据融合、误报抑制和战术边缘部署 |
| 精确末端效应 | 沿用改进 | 巡飞弹、FPV、滑翔小弹药已有战场应用，重点是可靠性和任务适配 |
| 抗干扰通信导航 | 集成创新，局部需原理突破 | 中继、低轨通信、惯导、视觉导航可集成，但低成本、强对抗、高可靠同时满足仍难 |
| 群体协同 | 集成创新，复杂场景需原理突破 | 小规模协同可实现，百级以上动态协同、频谱约束和安全控制难度高 |
| 人机协同 C2 | 集成创新 | 关键在界面、授权逻辑、任务抽象和审计机制 |
| 模块化开放架构 | 沿用改进 | 可借鉴商用开放接口和军用 MOSA 思路 |
| 快速生产保障 | 集成创新 | 技术不单在产品，而在供应链、测试、版本管理和战场反馈 |
| 安全合规 | 集成创新 | DoD 3000.09 强调自主/半自主武器需适当人类判断、V&V、测试评估和法律合规。[DoD Directive 3000.09](https://www.esd.whs.mil/portals/54/documents/dd/issuances/dodd/300009p.pdf) |

### ⑤ 核心技术清单

**A. 低成本平台与载荷**
- 可消耗级飞行器/地面/水面平台通用底盘
- 模块化任务载荷接口
- 低成本 EO/IR 与微型计算单元
- 快速装配、出厂校验、批次一致性控制
- 环境适应：低温、雨雾、风、沙尘、电磁环境

**B. 感知与目标确认**
- 多源态势数据融合
- 边缘端目标检测与跟踪
- 目标类别置信度评估
- 误识别抑制与友邻/非战斗对象排除
- 人审确认界面与可解释提示

**C. 通信、导航与抗干扰**
- 多链路通信管理
- 空中/地面中继组网
- 低轨卫星通信适配
- GNSS 受限环境下的惯性、视觉、地形/场景辅助导航
- 链路丢失后的安全降级策略
- 频谱态势感知与自适应通信配置

**D. 群体协同与任务规划**
- 多平台任务分配
- 搜索区域动态划分
- 目标优先级排序
- 航路冲突消解
- 编队内健康状态感知
- 损耗后任务重规划
- 仿真环境中的战术生成与验证

**E. 指挥控制与人机交互**
- 任务级控制界面
- 多平台态势聚合
- 授权、暂停、召回、终止控制
- 可审计任务日志
- 规则约束与用武边界管理
- 操作员负荷评估

**F. 测试评估与安全**
- 数字孪生/仿真测试
- 软硬件版本配置管理
- 对抗环境红队测试
- 网络安全与抗篡改
- 可靠性增长试验
- 武器系统法律审查支撑材料

### ⑥ 技术耦合关系与短板风险

**最大短板：抗干扰通信导航。**  
如果链路与导航在强电磁对抗下失效，侦察、协同、精确末端、人在回路都会被拖垮。IISS 所述空中中继和低轨通信趋势，本质上是在补这个短板。[IISS](https://www.iiss.org/globalassets/media-library---content--migration/files/publications---free-files/strategic-dossier/uavs-2026/iiss_ch-3-uavs-isr-deterrence-and-war_032026.pdf)

**第二短板：目标识别与授权闭环。**  
低成本精确打击不能只看“打得准”，还要避免打错。AI 可加快信息处理，但目标确认、合法性判断和交战授权必须可追溯。DoD 3000.09 对自主武器的人类判断、V&V、T&E 和法律合规提出明确要求。[DoD Directive 3000.09](https://www.esd.whs.mil/portals/54/documents/dd/issuances/dodd/300009p.pdf)

**第三短板：规模化生产与快速迭代。**  
EUISS 指出，优势周期可能只有数周，制造商必须持续吸收前线反馈并更新组件、软件和战术。[EUISS](https://www.iss.europa.eu/publications/briefs/minding-drone-gap-drone-warfare-and-eu) 如果研发、测试、采购、训练仍按传统大平台节奏运行，低成本装备的战场价值会快速衰减。

**关键耦合：**
- 感知精度 × 授权机制：误报率高会增加人审压力，拖慢杀伤链。
- 通信韧性 × 群体规模：平台越多，频谱管理和去冲突越难。
- 单价 × 生存性：过度追求高性能会失去低成本优势，过度廉价又会导致任务失败率过高。
- 模块化 × 认证：快速换装提高适配性，但会放大测试认证复杂度。
- 自主性 × 法律合规：自主程度越高，越需要可解释、可审计、可终止设计。

## 三、能力图像与效能贡献层

### ⑦ 装备能力图像

**谱系位置**

该类装备位于传统精确制导弹药、巡飞弹、小型 UAS、电子战诱饵和分布式传感器之间：

- 比传统导弹便宜、数量更多、可承受损耗；
- 比普通侦察无人机多一层任务闭环和末端效应；
- 比单兵 FPV 更强调体系协同、抗干扰和批量管理；
- 比高端察打一体无人机更低端、分散、可消耗。

**能力图像**

| 能力域 | 初始型 | 成熟型 |
|---|---|---|
| 平台 | 空中为主，兼顾地面/水面 | 多域混合，任务包通用 |
| 规模 | 小队/连级十级投放 | 营旅级百级以上协同 |
| 控制 | 单机/小组遥控 | 任务级控制 + 人在监督 |
| 打击 | 单目标点杀伤 | 多目标分配、补打、诱饵协同 |
| 通信 | 视距链路为主 | 中继、低轨、抗干扰多链路 |
| 导航 | GNSS 依赖较高 | GNSS 受限下可降级运行 |
| 生产 | 小批试制 | 模块化批产、快速改型 |
| 体系融入 | 独立使用 | 接入 C2、ISR、火力与后勤系统 |

### ⑧ 效能贡献评估

**对杀伤链的贡献**

1. **发现环节：** 分布式低成本传感器扩大覆盖密度，降低单个高价值侦察平台压力。  
2. **识别环节：** AI 辅助筛选和多源融合减少人工检索负担，但仍需人类确认。  
3. **决策环节：** 任务级 C2 将单个平台控制转为批量任务管理，提高指挥效率。  
4. **打击环节：** 低成本效应器对大量低/中价值目标形成经济可承受的精确火力。  
5. **评估环节：** 同平台或伴随平台回传毁伤评估，支持补打或火力转移。

**可量化方向**

| 指标 | 评估口径 |
|---|---|
| 单目标处置成本 | 与炮弹、巡飞弹、导弹、有人平台出动成本对比 |
| 杀伤链时延 | 发现至授权、授权至打击、打击至评估 |
| 目标覆盖率 | 单位时间内可搜索/监控区域与目标数量 |
| 任务成功率 | 在干扰、天气、伪装、机动条件下分场景统计 |
| 损耗承受率 | 损失一定比例平台后任务完成度 |
| 操作员负荷 | 单人可监管平台数、误操作率、疲劳指标 |
| 迭代速度 | 从战场反馈到软件/硬件版本更新周期 |
| 防御消耗比 | 对方探测、拦截、电子压制资源消耗与己方成本比 |

### ⑨ 发展优先级与近期抓手

**优先级 1：抗干扰侦打闭环演示**

目标：验证“侦察发现、目标提示、人审授权、低成本打击、毁伤评估”的闭环，在通信受限和 GNSS 受限条件下保持可控。  
近期项目：  
- 选取轻型车辆、临时通信节点、模拟火力点等合法靶标；  
- 建立仿真场景与实装试验场景；  
- 重点验证链路降级、安全终止、任务重分配和误识别抑制。

**优先级 2：模块化低成本平台族**

目标：形成侦察型、中继型、诱饵型、打击型共用底盘和任务接口。  
近期项目：  
- 建立开放载荷接口和任务软件接口；  
- 以 3 至 5 类典型载荷做互换验证；  
- 测算批量生产成本、保障工时和批次一致性。

**优先级 3：人机协同 C2 与多平台监管**

目标：从“一个人控一架”转向“一个人监管多架、按任务授权”。  
近期项目：  
- 做十级平台任务管理演示；  
- 验证目标提示、冲突告警、授权记录、暂停/召回/终止；  
- 评估操作员认知负荷和误判率。

**优先级 4：快速迭代与测试认证体系**

目标：把“周/月级迭代”制度化，而不是一次性装备定型。  
近期项目：  
- 建立软件版本、硬件批次、任务数据、测试结果的闭环数据库；  
- 用仿真、半实物和实飞测试筛选版本；  
- 引入红队干扰、欺骗、网络安全测试。

**优先级 5：体系接入和规则约束**

目标：确保装备不是孤立“无人机工具”，而是可接入现有 ISR、火力、指控和后勤体系。  
近期项目：  
- 与现有态势系统进行数据接口试验；  
- 建立任务授权、目标确认、日志审计和法律审查模板；  
- 明确禁止目标、禁飞区、友邻识别和任务终止规则。

## 结论

“大规模离散目标低成本精确打击”的核心市场需求来自三个矛盾：目标数量多而价值分散、暴露窗口短而传统火力链慢、昂贵弹药难以承受长期消耗。最有前景的装备形态不是单一“廉价导弹”，而是低成本可消耗平台、分布式传感、抗干扰通信导航、人机协同 C2、模块化载荷和快速生产迭代组成的体系。

近期最值得启动的是“抗干扰侦打闭环 + 模块化平台族 + 十级多平台人机协同”三类演示验证。真正的卡点不在单个平台飞得多远或载荷多大，而在强对抗环境下能否可靠发现、正确识别、合规授权、批量协同，并以足够低的成本持续迭代。
