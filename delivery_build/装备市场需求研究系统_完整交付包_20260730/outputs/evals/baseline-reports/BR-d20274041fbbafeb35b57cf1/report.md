**高机动目标持续跟踪精确打击研究**

**资料依据**  
公开材料显示，美军相关能力建设正从单平台“发现-打击”转向跨域体系：CJADC2强调以更快、更准确的决策连接战术、战役、战略层级传感器和系统；Project Convergence被定位为持续性联合实验；HBTSS用于对先进导弹威胁提供火控质量数据和“birth-to-death”跟踪；IBCS体现“任意传感器、最佳射手”的一体化指挥控制思路；Space Force的SB-AMTI/GMTI方向则显示高机动空中、地面、海上目标的空间持续跟踪需求正在上升。公开依据见文内链接。

**一、需求挖掘层**

① **典型作战场景**

1. **陆上机动发射/防空目标的时敏处置场景**  
   目标包括机动导弹发射车、远程火力车、防空雷达车、机动指挥通信节点等。其特征是“短暂停留、频繁转移、伪装隐蔽、受地形遮蔽”，传统单次侦察图像容易过期。需求核心不是单次发现，而是发现后持续保持目标“看护”、完成身份确认、轨迹预测和可用火力匹配。

2. **近海/岛礁周边高速海上目标跟踪场景**  
   目标包括快速艇、无人艇、小型作战舰艇、机动登陆/补给单元等。海上目标会利用岛礁、港湾、民船背景和电磁静默降低可探测性。商业SAR公开材料显示，SAR具备全天候、昼夜成像优势，且可用于海事态势感知和异常活动识别，说明“光学受限条件下持续监视”已经形成成熟需求信号。[Capella Space](https://www.capellaspace.com/)

3. **高超声速/弹道类高速目标防御跟踪场景**  
   此类目标速度高、窗口短、机动轨迹复杂，要求从预警、跟踪、判别到拦截武器交接形成连续链路。美国防部公开称HBTSS目标是提供火控质量数据，支持从发射到拦截的持续跟踪，并向导弹防御武器交接数据。[DoD HBTSS发布](https://www.war.gov/News/Releases/Release/Article/3676902/mda-sda-announce-upcoming-launch-of-the-hypersonic-and-ballistic-tracking-space/)

4. **强对抗电磁/网络环境下的联合火力场景**  
   对手会用干扰、诱骗、断链、伪装、虚假目标和网络攻击削弱杀伤链。GAO指出DOD推进抗干扰M-code GPS多年但仍面临空间、地面、用户设备三段挑战，说明精确打击体系不能只依赖单一PNT来源。[GAO GPS Modernization](https://www.gao.gov/products/gao-24-106841)

② **牵引需求的新战法/新概念技术及制胜机理**

1. **从“杀伤链”转向“杀伤网”**  
   传统链路强调顺序流程，容易被某一节点拖慢或打断。新概念强调多传感器、多指挥节点、多火力单元并联，形成冗余、弹性和快速重构。CJADC2公开说明其目标是帮助联合指挥员以更快、更准确方式获得决策优势，并连接多层级传感器和系统。[CDAO CJADC2](https://www.ai.mil/Initiatives/CJADC2/)

2. **任意传感器到最佳效应器**  
   IBCS公开材料称其把传感器和效应器接入综合火控网络，增强识别、跟踪、交战和防御能力，并支持联合互操作。[U.S. Army IBCS](https://www.lineofdeparture.army.mil/Journals/Air-Defense-Artillery/ADA-Archive/2024-Edition/IBCS-Any-Sensor-Best-Shooter/)  
   制胜机理是：目标一旦被某个节点发现，体系可由其他节点继续接力跟踪，并由更合适的火力单元完成处置，降低“发现者必须也是打击者”的约束。

3. **空间层持续感知+边缘智能处理**  
   Space Force在SB-AMTI公开材料中称，传统地面/空中传感器进入高度对抗空域风险上升，空间AMTI旨在从太空连续跟踪空中威胁，并结合AI驱动地面处理和安全通信链路。[Space Systems Command SB-AMTI](https://www.ssc.spaceforce.mil/Newsroom/Article/4467880/securing-the-ultimate-high-ground-how-the-space-force-is-revolutionizing-airbor)

4. **持续实验牵引装备快速迭代**  
   Project Convergence被公开定义为持续实验而非一次性活动，用于形成可靠网络、数据驱动决策和联合作战概念。[Project Convergence](https://www.war.gov/Spotlights/Project-Convergence/)  
   制胜机理是用体系级演示验证缩短“概念-样机-战术-采购”的闭环。

**二、技术攻关层**

④ **能力实现途径总体判断**

| 能力特征 | 实现途径判断 |
|---|---|
| 广域发现 | 集成创新：SAR、红外、电子侦察、GMTI/AMTI多源组合 |
| 持续跟踪 | 集成创新为主，局部需算法突破：多源航迹融合、遮蔽后再捕获 |
| 目标识别 | 原理突破倾向较强：复杂背景下小样本、弱监督、抗欺骗识别 |
| 火控级数据 | 集成创新+工程突破：传感器标定、时空基准、误差传播控制 |
| 跨域组网 | 沿用改进+集成创新：数据标准、网关、边缘云、战术链路 |
| 抗干扰PNT | 集成创新：惯导、星基、地基、视觉/地形匹配、网络授时组合 |
| 决策辅助 | 集成创新+算法突破：可信AI、任务规划、资源优化 |
| 打击闭环 | 集成创新：ISR、火力、BDA数据闭环 |
| 网络安全 | 沿用改进：零信任、加密、最小权限、持续认证 |

⑤ **需重点攻关的核心技术清单**

1. **多源移动目标探测**  
   SAR/GMTI/AMTI联合探测、红外弱小目标检测、海杂波/地杂波抑制、目标运动特征提取、低可观测目标探测。

2. **持续航迹融合与目标看护**  
   多传感器时间同步、跨平台航迹关联、断续观测补全、遮蔽后再识别、群目标分裂/合并处理、目标意图预测。

3. **火控质量数据生成**  
   统一坐标时空基准、误差协方差建模、航迹质量评估、数据降级标识、传感器交接规则、末段更新接口。

4. **AI辅助识别与抗欺骗**  
   小样本目标识别、合成数据训练、对抗样本防护、诱饵/伪装识别、多模态置信度融合、模型漂移监测。

5. **抗干扰通信与数据分发**  
   低时延战术数据链、卫星/空中/地面多路由、边缘缓存、断链续传、优先级调度、跨密级数据治理。

6. **韧性PNT与授时同步**  
   抗干扰GNSS、惯性/视觉/地形辅助导航、分布式授时、时间完整性校验、导航源可信评估。

7. **人机协同决策**  
   目标价值排序、火力资源匹配、风险约束推理、规则可解释、人在回路授权、异常建议回退。

8. **体系安全**  
   零信任身份、端点可信计算、数据水印与溯源、异常行为检测、受损节点隔离。DoD零信任战略强调从传统边界信任转向基于多属性置信度的认证授权和最小权限访问。[DoD Zero Trust Strategy](https://dodcio.defense.gov/Portals/0/Documents/Library/DoD-ZTStrategy.pdf)

⑥ **关键技术耦合关系与短板风险**

1. **“传感器质量”拖累“火控质量”**  
   广域发现只能给出线索，若缺少高精度定位、速度、航向和置信度，后续火力无法可靠接收。HBTSS公开目标正是向火控质量数据演进，说明从“看见”到“可交战”是关键门槛。[MIT Lincoln Laboratory](https://www.ll.mit.edu/news/lincoln-laboratory-supports-missile-defense-agency-space-sensor-testing)

2. **“时间同步/PNT”拖累全链路融合**  
   多平台航迹融合依赖统一时间和坐标。PNT受扰会导致目标位置、平台位置、火力交接全部失准，是体系性风险。

3. **“网络互操作”拖累杀伤网**  
   JADC2研究报告指出，跨军种传感器接入单一网络涉及自动化、AI、云环境、新通信方式，也需要系统工程方法处理大型遗留体系融合问题。[AIRC JADC2 Report](https://document.acqirc.org/publication_documents/reports/1670425668.JADC2_REPORT.pdf)

4. **“目标识别置信度”拖累授权与节奏**  
   在民用背景、诱饵和伪装环境中，识别置信度不足会迫使人工复核增加，削弱时敏目标处置速度。

5. **“边缘处理能力”拖累数据时效**  
   高重访、多传感器会产生海量数据。若所有数据回传中心处理，链路拥塞和时延会抵消持续跟踪价值。

**三、能力图像与效能贡献层**

⑦ **装备能力图像**

可将该装备体系定位为“跨域持续目标看护与火控数据服务系统”，不是单一武器，而是介于ISR体系、C2系统和精确火力之间的中间层。

| 谱系位置 | 现有能力 | 本概念增量 |
|---|---|---|
| 传统ISR | 单平台侦察、周期性成像 | 多源连续看护、自动航迹融合 |
| 传统C2 | 分域指挥、人工协调 | 跨域目标数据服务、火力推荐 |
| 传统火力 | 接收预先目标点 | 接收动态目标状态和更新 |
| 防空反导 | 雷达局部覆盖 | 空间层预警/跟踪与火控交接 |
| 商业遥感 | 图像产品交付 | 高时效任务化、自动化TCPED |

**指标画像建议**

1. **覆盖画像**：重点区域多源覆盖、昼夜全天候、陆海空目标兼容。  
2. **时效画像**：发现到可用目标数据的端到端时延从“小时级/十分钟级”压缩到“分钟级”，高价值目标争取更短。  
3. **精度画像**：由“情报级定位”向“火控级定位/航迹质量”分层演进。  
4. **韧性画像**：单节点失效、链路受扰、GPS受限情况下仍能维持降级服务。  
5. **开放画像**：支持遗留传感器、商业星座、新型无人平台和未来火力单元接入。

⑧ **效能贡献评估**

1. **对杀伤链的贡献**  
   - Find：通过SAR、GMTI/AMTI、红外、电子侦察扩大发现概率。  
   - Fix/Track：通过多源融合降低目标丢失率。  
   - Target：提供带置信度和误差边界的目标状态数据。  
   - Engage：把目标数据交给最合适火力，而非固定平台。  
   - Assess：用战后/拦截后传感器快速回收毁伤评估。

2. **可量化方向**  
   - 目标发现概率提升。  
   - 航迹连续率提升。  
   - 目标数据更新周期缩短。  
   - 端到端决策时间缩短。  
   - 传感器/火力节点利用率提升。  
   - 误击、漏击、重复打击风险降低。  
   - 受干扰环境下任务完成率提升。

3. **对作战体系的贡献方式**  
   该体系的核心价值是把高机动目标从“机会目标”转化为“被持续管理的动态目标”。一旦形成稳定目标看护，火力系统不必长时间暴露等待，指挥系统也可在多个火力选项之间动态选择。

⑨ **发展优先级与近期抓手**

**优先级一：多源航迹融合与火控质量评估**  
近期抓手：建设“陆海空移动目标公共数据集+半实物仿真环境”，接入SAR、无人机、电侦、地面雷达等数据，验证断续观测下的航迹保持、置信度评估和误差传播。

**优先级二：抗干扰PNT与跨域时间同步**  
近期抓手：开展GPS受扰条件下的多源PNT演示，验证惯导、视觉/地形辅助、网络授时和星基信号的组合可用性。

**优先级三：开放式目标数据服务中台**  
近期抓手：研制“目标轨迹即服务”原型，统一输出目标ID、位置、速度、置信度、时效、误差边界和来源标记，面向不同指挥/火力系统提供标准接口。

**优先级四：边缘AI处理与低带宽分发**  
近期抓手：在无人机、地面站、舰载节点或战术云边缘部署目标检测/压缩/优先级分发模型，验证低带宽、断续链路下的任务可用性。

**优先级五：体系级演示验证**  
近期可启动三个演示项目：  
1. “复杂地形机动目标持续看护”演示：验证遮蔽、停走、伪装后的再捕获。  
2. “近海高速目标跨源识别”演示：验证SAR、光电、AIS/电侦线索融合与异常检测。  
3. “高动态目标火控数据交接”演示：验证从预警、跟踪到火控数据交接的时效和质量分级。

**结论**

该方向的真实需求不是单点“精确打击”，而是持续目标看护、火控质量数据、跨域网络、韧性PNT和可信AI共同构成的体系能力。近期最值得投入的是“多源航迹融合+火控质量数据服务+抗干扰时空基准”三件事；任何一项短板都会使高机动目标重新变成短窗口、低把握、难闭环的时敏目标。
