每个 agent 独立 Harness

TurnSnapshot：冻结模型、ContextPack、工具、权限和预算。

最小工具：search、fetch、read、materialize、write evidence、publish packet、checkpoint。

隔离：禁止读取其他 agent 原始 session；越权工具参数由执行层拒绝。

持久化：独立 append-only JSONL session。

4编排器汇总初检与制胜机理核心
新制胜机理：新机制 / 新打法 / 新体系组合 → 新概念能力
传统能力缺口：传统场景/战法 + 当前装备对比 → 升级与拓展
局部战争案例：战例新能力/新模式/不足 → 未来布局
L1 制胜逻辑分析弱点地图、制胜路径、效果链、关键能力、假设；低置信或覆盖不足触发定向再调。
L2 概念创新评估新概念、新技术、新手段、类比创新、跨域移植和可行性校验。
L3 文字能力画像去重归并、类别映射、五档差距、优先级和九字段能力画像。
RecallRequest 按 target_agent_id 或 target_capability_tag 路由；补充结果写入 SavePoint 后从指定 L1/L2/L3 节点继续，不从头重跑。
5最终判据与交付输出
一致性
场景、逻辑、能力与装备映射不矛盾
置信度
关键结论达到 70%，不足则降级
覆盖度
路线关键维度有结论或显式限制
用户确认
正式发布前保留分析师确认节点
轮次约束
总轮次 ≤5，同目标再调 ≤3
