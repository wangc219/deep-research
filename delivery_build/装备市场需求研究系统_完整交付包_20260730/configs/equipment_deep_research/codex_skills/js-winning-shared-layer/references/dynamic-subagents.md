# 动态专用子 Agent 契约

只有同时满足以下条件才生成动态 Agent：任务可独立拆分、上下文隔离有收益、存在结构化合并契约、预算可用、固定 Agent 无法充分覆盖。

每个动态角色必须包含唯一任务、触发缺口、能力标签、共享 Skill、知识包、受治理 Tool、合并目标、输出字段、质量门槛、预算和停止条件。最多同时生成 3 个，默认并行执行；结果只能合并到声明的 S1-S6 或 convergence 节点。

动态 Agent 不得招募新的 Agent，不得修改蓝图，不得扩大 Tool/知识权限，不得声称执行了本地 Harness Tool。完成任务或达到预算后立即回收，只保留结构化输出与审计记录。
