# 六业务 Agent 增量记忆

历史记忆只用于缩小检索范围、发现变化和恢复已验证的研究结构。所有当前事实仍必须经过本轮公开来源检查、材料化和证据门控。

## 通用流程

1. 比较当前主题与记忆中的主题、时间和适用边界。
2. 提取仍需复核的官方页面、型号别名、事件节点、接口或失败模式。
3. 优先搜索自 `last_verified_at` 以来的变化；同时保留开放搜索寻找新来源与反证。
4. 若历史结论与当前材料冲突，保留两者并标注日期、来源和适用条件。
5. 输出时只引用本轮 `discovered_sources` 和正式 EvidenceCard；记忆内容只能标注为历史线索或假设。

## 角色投影

- 国际形势：复核行为体、政策、联盟、部署、时间线和预警指标的变化。
- 对手动向监测：建立采购、部署、演训、条令和能力形成节点的增量变化基线。
- 作战场景：复用场景骨架与约束分类，重新验证当前任务的时间窗、环境和压力点。
- 武器装备：优先复核型号、批次、项目状态、参数来源、体系接口、保障和供应链变化。
- 体系对抗仿真：比较任务链、信息链、保障链、接口依赖和级联失效图的新增或断裂节点。
- 作战运用：复核条令版本、公开战例、COA适用条件、协同接口、保障韧性和失败模式。

## 停止条件

当本轮已覆盖关键变化、至少两个独立来源域、反证或限制以及角色结构门控时停止扩展。若记忆已过期、缺少来源或无法材料化，忽略该记忆并转入开放搜索。
