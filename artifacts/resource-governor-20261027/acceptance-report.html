资源策略与检查

当资源充足时按已配置上限接纳；其他计算竞争和交互增加时降低新重任务接纳。内存低于 4 GiB 时进一步收敛，低于 2.5 GiB 时暂缓新增研究和通用任务。预算过期采用保守档。CPU 与内存压力边界有自动化测试，未在生产人为制造 OOM。

候选镜像 14 项通过，包含 6 项真实 PostgreSQL 容量测试。Worker 检查直接验证 Redis 租约，替代反复加载完整后端；图数据库执行认证 HTTP 查询，替代 Java 命令行。单次测量：旧 Worker 检查 5.749 秒，新检查连同容器启动 0.776 秒；图检查 2.437 秒降到 0.829 秒。最终站点 ready，验收期间 API 日志 5xx 为 0。
