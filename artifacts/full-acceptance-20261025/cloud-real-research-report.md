# 地下避难场所应急照明系统电池失效抑制与状态监测需求研究

## 一、需求分析

### （一）需求概述

#### 1. 背景分析

研究主题为“民用公共避难场所的应急照明维护：减少电池失效和漏检”。本次交接形成的决定性判断为：weapon_equipment；combat_scenario。

#### 2. 需求阐述

从 Query 角度归纳相关装备需求：已识别的任务链问题为：能力分类：主：现场感知感知维度。概述：当前背景：公共避难场所应急照明依赖电池在断电时点亮疏散通道，但电池随年限老化、内阻升高直至失效，过程隐蔽且无预警；能力分类：主：民用应急照明电池状态的自主监测与维护决策支持；辅：预警维度。概述：当前背景：民用公共避难场所应急照明依赖电池供电，但常规巡检周期长，电池可能在两次检查间静默失效，导致真实断电时照明无法保障；据此说明需要何种装备能力与形态，以及现有手段缺口所在。

#### 3. 项目画像

围绕拟研装备主体，说明其研发作用、应对态势威胁与任务前景。

- **瞬域微功耗阻抗探针**：瞬域微功耗阻抗探针；未来任务或灾害场景下，民用公共避难场所（如地下人防工程、大型体育馆、医院）的应急照明系统需在电力中断时保障疏散安全。核心态势威胁是电池老化导致的照明失效，而传统人工巡检周期长、漏检率高，无法实时发现早期故障。；将探针嵌入应急照明电池端子，激活待机监测状态、电池自放电电流驱动振荡器，持续测量内阻与自放电率、健康参数变化触发光脉冲编码，实时指示状态（正常/可修/不可修）、维护人员通过光信号识别需更换电池，执行定向更换、系统记录状态变化，优化维护计划，实现预测性维护闭环；一种可嵌入每块应急照明电池端子的微功耗阻抗探针，利用电池自身极低频自放电电流驱动超低功耗振荡器，将内阻/自放电率变化转化为可光脉冲编码的在线状态指示，无需人工到场即可实时反映健康态，使电池失效在发生前被持续发现，并可区分可修与不可修，消除漏检窗口；公开证据不足的参数不得转化为确定性指标，保留区间与置信度。

- **余晖唤醒探针**：余晖唤醒探针；在民用公共避难场所（如地下商场、地铁站、大型体育馆）中，市电中断使应急照明必须独立供电，但大量灯具因电池老化或漏检而失效，导致疏散通道黑暗，人员恐慌踩踏，避难功能丧失。核心态势威胁是电池失效的隐蔽性和人工巡检的周期局限性，敌我关系体现为维护管理者与不确定的电池衰减过程之间的矛盾。；平时状态：探针以微安级电流维持实时监测市电状态，待机功耗极低、触发条件：检测到市电中断，探针由电池残余能量唤醒，进入自供电测试模式、注入激励：向回路注入短暂的特征电流脉冲，与正常照明负载区分，避免干扰照明功能、数据采集：记录灯具点亮状态、亮度曲线（通过内置光敏元件或电压/电流变化推断）、续亮时长、数据存储与通信：测试数据暂存于探针本地非易失存储器，市电恢复后通过低功耗无线或有线回传集中管理平台、维护决策：平台分析数据，识别亮度低于阈值或续亮时长不足的灯具，生成精确的维护工单；一种嵌入应急照明电池端子的自唤醒监测探针，平时处于微安级休眠，仅在市电中断的瞬间由电池残余能量触发，主动向回路注入特征电流脉冲并记录灯具实际点亮亮度与续亮时长，将“是否失效”转化为可量化的单次放电实测数据，直接消除依赖人工巡检的漏检窗口，使每次灾难断电都自动完成一次真实可用性验证；公开证据不足的参数不得转化为确定性指标，保留区间与置信度。

### （二）技术基础

**（1）瞬域微功耗阻抗探针**

我国在微功耗传感与能量自持领域已有较成熟的技术积累。超低功耗振荡器、微安级待机电路和电池内阻在线测量已在工业电池监测、电动车辆电池管理系统（BMS）中得到规模化应用，相关芯片和模组供应链完整，具备支撑探针小型化、低成本化的工程基础。应急照明电池端子嵌入式和光脉冲编码指示可直接借鉴消防应急照明集中监控系统的现有产品形态，GB 51309-2018已规定蓄电池初装容量与应急时间要求，为探针的状态判据提供了标准基线。可继承的成熟基础包括：电池内阻—健康状态映射模型、低功耗无线通信模组、光信号编码与解调技术，以及消防电子产品认证与检测流程。新增工作集中在三个方向：一是将内阻/自放电率变化转化为光脉冲编码的专用算法与门限标定，目前公开资料尚无针对应急照明电池的成熟判据模型；二是探针自身在长期休眠状态下的可靠性验证，公开资料未提供探针休眠期失效模式的实测数据；三是与既有应急照明系统的电气接口兼容性设计，不同厂家灯具的端子结构和回路参数不一致，需建立适配规范。主要可研缺口在于系统级故障检测率与误报率的实测验证：部分市售产品宣称具备自动巡检功能，但缺乏第三方检测报告和公开实测数据，需在真实避难场所开展不少于一个电池寿命周期的挂网试验，积累内阻变化与电池失效的相关性数据。供应链条件方面，微功耗芯片、光敏元件和阻容元件均为成熟货架产品，国内供货渠道稳定，不存在关键器件依赖。

**（2）余晖唤醒探针**

自唤醒监测探针的可继承基础主要来自电池管理行业的事件触发式监测技术。微安级休眠唤醒电路、市电状态检测、特征电流脉冲注入与放电曲线记录在UPS电源监控和储能系统维护中已有工程应用，其“平时休眠、事件唤醒”的工作模式与应急照明“市电中断即测试”的场景高度契合，原理验证风险低。应急照明灯具的光敏检测、电压/电流信号采集与本地非易失存储均为成熟技术，可支撑探针在断电瞬间自主完成一次真实放电测试并保存结果。国内已有企业提供符合GB 51309-2018的集中监控型应急照明疏散系统，可实现灯具状态实时监控和故障报警，表明系统级集成和通信协议在国内已有商业化基础，但公开资料显示其监控以在线电气参数为主，未覆盖市电中断瞬间的真实放电能力实测。新增工作包括：特征电流脉冲与正常照明负载的区分算法，避免测试动作干扰疏散照明功能；断电瞬间由电池残余能量唤醒并完成测试的低功耗时序设计，需在电池接近寿命末期、残余能量极少的工况下仍能完成数据采集；以及温度补偿算法，极端温差会影响亮度测量精度。可研缺口在于探针自身长期微安级休眠的可靠性及其对电池容量的额外消耗，公开资料未提供该条件下的寿命试验数据；此外，断电瞬间多只灯具同时触发测试可能造成回路线路瞬态过载，需开展多探针并发工况的回路仿真与试验验证。试验条件方面，可利用现有消防应急照明检测机构和避难场所样板间搭建半实物测试环境，模拟市电中断、电池老化、温度变化等工况；供应链上，微控制器、唤醒电路和光敏元件均为成熟器件，本地化供应充足。主要验证短板是缺少断电事件全量数据回传与集中维护平台之间的接口标准，当前国内产品通信协议兼容性不足，需在项目前期明确数据格式与回传机制。
