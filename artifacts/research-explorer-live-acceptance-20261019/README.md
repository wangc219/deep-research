# 调研探索员双入口真实模型验收

验收日期：2026-10-19（Asia/Shanghai）

项目 Query：`query-30510033-b96d-46e8-8a3a-48ffe2b07e8e` — 低空无人集群复杂电磁环境闭环反制装备研究

真实模型：`siliconflow-cn:deepseek-ai/DeepSeek-V4-Flash`

## 结论

智能对话与深研对话均通过效率和质量验收。两个入口串行总模型运行时间为 448.5 秒（7.48 分钟），单入口分别为 218.9 秒与 229.6 秒，均低于 600 秒门槛；相比优化前约 30–33 分钟的单入口耗时，已缩短到约 3.7–3.8 分钟。

两个入口均只启动 2 个正交调研探索员，并完成高质量 Open Websearch 与 AMiner 论文补证：

- 智能对话：10 次有效 Web 检索，90% 带 `required_terms`，25 个去重来源、9 个权威来源；AMiner 取得 1 篇完整摘要。
- 深研对话：10 次有效 Web 检索，100% 带 `required_terms`，13 个去重来源、2 个权威来源；AMiner 通过网页准确题名桥接取得 1 篇完整摘要。
- 两入口都返回可独立阅读的完整正文，未泄漏 DSML/XML 工具协议，形成具体装备候选、证据塑形说明、工程边界与最小验证动作。

## 本轮增强

- Open Websearch 在主题相关性过滤后增加政府/军队、标准、论文出版页与一手厂商发布页的优先排序和来源层级标注。
- 同题论文出版页与 ResearchGate 等聚合页去重，已有原始来源时不再让聚合页占用高价值结果位。
- 调研探索员缺少 `required_terms` 时不执行该次 Web 查询，也不扣除检索预算；要求以 1–2 个身份锚点精确重试。
- 资料提前收敛门槛从“8 个任意来源”提升为“8 个去重来源且至少 2 个一手/高权威来源”。
- AMiner 保持少量高价值调用：主题发现为空时，从论文出版页或 DOI 入口取得准确题名，再用 `mode=title` 校正并集中读取 1–3 篇完整摘要。
- 探索员不再调用 `write_todos`，减少无价值模型往返。
