# 安全说明

## 不得进入 ZIP 的内容

- `.env` 和任何真实 API Key。
- `cookie.txt`、微信公众号 `session.json`、二维码图片和浏览器 profile。
- 下载的 PDF、采集正文、运行日志和本机缓存。
- 本机绝对路径、个人 Conda 路径或私有代理配置。

打包器采用显式白名单复制，排除常见敏感文件名，再进行凭据模式扫描；异常只报告相对文件路径和规则名，不回显命中内容。最后为所有交付文件生成 `MANIFEST.sha256`。

## 安全运行方式

1. 从 `.env.example` 创建只存在于本机的 `.env`。
2. 把微信 session、CNKI Cookie 和二维码放到 `runtime/sessions/`。
3. Compose 只读挂载 `.env`，数据和 runtime 使用独立可写卷。
4. 分享日志或真实测试报告前，删除 token、Cookie、请求头、二维码和原始响应中的个人信息。
5. 重新打包时再次运行安全扫描和 checksum 验证。

noVNC 默认只绑定宿主机 `127.0.0.1:7900`，且容器内 VNC 不设置内置密码。不要把该端口转发到公网；如需远程协作，应在可信 VPN 或额外认证层后使用。
