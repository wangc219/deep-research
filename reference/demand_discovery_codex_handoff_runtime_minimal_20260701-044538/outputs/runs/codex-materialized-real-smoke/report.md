## 结论摘要

基于当前已接受证据，本候选可作为“公开军事媒体层面的能力难题与体系建设需求信号”进入报告审阅：低空无人机、巡航导弹等低空小目标正在对探测、锁定、跟踪、预警和拦截链路形成压力，需求方向集中在多层次、多模态、空地协同的探测预警与稳定跟踪能力，并需要与指挥控制、拦截打击、训练和条令体系衔接。该判断由 ev-81-lowtarget-detect-gap、ev-81-ground-airdefense-limit、ev-81-multimodal-warning-need 和 ev-81-training-doctrine-need 共同支撑，并经 audit-codex-1 审计为 approved。

本报告不将该候选表述为已确认的本方具体装备型号、预算、采购计划、量化性能指标或工程架构缺口。现有证据主要来自 81.cn / 解放军报 / 中国国防报体系，部分材料通过外军案例或外国战略呈现能力压力，因此结论应限于公开军事媒体正文中的能力缺口和体系补强信号。

## 场景与压力

当前场景是低空突防与反无人作战压力上升。ev-81-lowtarget-detect-gap 指出，无人机和巡航导弹等低空小目标成为低空突防的重要压力源；这类目标具有小雷达反射截面积、贴地飞行、地杂波背景、慢速和低成本等特征，使传统有人战机和机载雷达在发现、锁定与拦截窗口上出现错配。

地面防空链路也存在类似压力。ev-81-ground-airdefense-limit 描述了小型无人机雷达锁定难、地面防空系统对低空无人机探测和拦截距离有限等问题，并将侦测系统改进、预警无人机和系统集成作为补强方向。该证据支持“低空小目标不是单点拦截问题，而是探测、预警、跟踪和拦截链路协同问题”的判断。

## 能力缺口拆解

第一类缺口是早期发现与稳定跟踪不足。ev-81-lowtarget-detect-gap 和 ev-81-ground-airdefense-limit 共同支撑：低空小目标因小 RCS、低空/贴地飞行和复杂地杂波背景，容易造成发现难、锁定近、探测和拦截距离受限、拦截窗口短等问题。

第二类缺口是侦察预警体系不足。ev-81-multimodal-warning-need 明确指向反无人作战体系中的侦察预警环节，强调全领域预警平台、多层次侦察设备、多模态探测、尽早尽远发现和稳定跟踪。这使需求方向更接近体系化探测预警，而不是单一雷达或单一拦截装备升级。

第三类缺口是空地协同和系统集成不足。ev-81-ground-airdefense-limit 提到侦测系统改进、预警无人机和系统集成方向；结合 ev-81-multimodal-warning-need，可将其表述为组网探测、空地协同和多传感器融合的能力信号，但不能扩写为具体工程架构或已立项研发计划。

第四类缺口是训练、理论和政策嵌入不足。ev-81-training-doctrine-need 报道的是美国反无人机战略，能够作为外军经验观察，说明探测、跟踪能力提升以及将反无人机防御纳入理论、训练和政策体系的重要性；但该证据不能直接证明本方训练条令已提出同类需求。
