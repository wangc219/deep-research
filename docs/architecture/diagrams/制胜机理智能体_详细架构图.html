3四类知识资源：供推理引擎按需调用

理论工具库

战例库

问题链

Q1 敌方重心是什么？Q2 制胜逻辑怎样构建？Q3 需要哪些关键能力？Q4 能否创造新的制胜方式？问题链持续驱动多轮联网检索和再调。

4推理引擎：六步串联分析 + L1/L2/L3 分层门控
1. 防御解构分层解析敌体系的感知、决策、拦截与冗余；标注依赖关系和时间窗口，输出弱点地图。
2. 制胜路径比较多条路径的条件、风险、效费和可执行性；使用战例校验并形成优选路径与关键假设。
3. 效果链行动 → 直接效果 → 间接效果 → 最终效果；每个节点绑定证据、置信度和风险。
4. 能力映射效果 → 功能 → 性能三级转换；形成关键能力、参数方向及其对制胜逻辑的贡献。
5. 差距量化需求与现有能力按空白、关键差距、部分差距、满足、超出五档评估，形成差距矩阵。
6. 图像生成去重归并、类别映射、关键性×紧迫性×可行性排序，输出九字段文字能力画像。

L1 制胜逻辑分析

  • 接收校验：完整性、置信度、一致性和 capability 覆盖
  • 防御解构：四层解析、弱点与时间窗口
  • 制胜路径：多路径比较、战例验证、优选与假设
  • 效果链：行动-效果因果链与证据标注
  • 能力推导：关键能力、性能方向和逻辑闭环自检
输出：弱点地图、制胜路径、效果链、关键能力清单、假设、证据与置信度。
L1→L2 门控：能力清单置信度 ≥70%；无低置信度关键节点；场景/威胁缺口的再调请求已处理或明确降级。

L2 概念创新评估

  • 概念扫描：新概念、新技术、新手段和新作战样式
  • 类比创新：从战例与相关领域迁移有效机制
  • 跨域移植：陆、海、空、天、网等能力向目标场景适配
  • 组合筛选：形成 2-3 个创新方向并做可行性评价
  • 效果链验证：确保新概念增强而不破坏 L1 制胜逻辑
输出：概念扫描结果、创新提案、可行性分析、新能力清单（新增/改进/维持）。
L2→L3 门控：可行性 ≥3/5；与 L1 不矛盾；技术前景、装备验证或作战运用反馈已到位。

L3 能力图像生成

  • 去重归并：合并 L1 关键能力与 L2 创新方向
  • 类别映射：平台、任务、射程、速度、载荷和保障约束
  • 差距量化：五档评估与数据对比矩阵
  • 优先级：关键性、紧迫性、可行性综合排序
  • 画像生成：新作战能力方向与现有装备升级需求分列
输出：九字段能力画像、全景清单、优先级视图、证据和制胜逻辑追溯链。
L3 门控：九字段完整；能力差距有数据支撑；场景、制胜逻辑、证据与能力条目可以双向追溯。
5定向再调机制
L1：场景假设不足、战略变化、威胁证据或置信度不足 → 调形势/场景 agent
L2：新概念需技术前景、型号成熟度或运用验证 → 调装备/运用 agent
L3：差距数据、参数或场景映射不足 → 调装备或场景复核
约束：target_agent_id/tag；同目标 ≤3 次；总轮次 ≤5；从 return_node 继续
6编排器最终五判据
一致性场景、路径、能力、装备映射不矛盾
置信度关键结论 ≥70%，不足则明确降级
覆盖度路线必需维度均有分析或限制说明
用户确认分析师确认关键假设和发布状态
轮次约束研究与再调未超过配置上限
7最终交付：作战能力图像需求
新作战能力方向：由新制胜机制、新作战打法、新体系组合或战例创新牵引。
现有装备升级需求：由传统场景、传统制胜、传统战法下的能力差距与空白牵引。
九字段：能力编号、名称、装备类别、类型、来源制胜逻辑、关联场景、优先级、能力差距、文字能力画像。
回答：需要发展具备什么功能的产品，以及能力来自哪条逻辑、哪类场景、哪些证据和哪些缺口。
