# 研究报告生成约束：去模板化规范

## 目的

报告必须依据装备的真实任务、作用机理、使用场景和证据状态撰写。字段只是检查清单，不能先套句式再填内容。

## 每件装备的最低事实链

每件装备至少回答以下问题：

1. 它具体解决哪个作战或工程问题？
2. 它通过什么独有机理产生效果？
3. 它相对现有基线改变了哪一个环节？
4. 哪些条件下效果会下降或失效？
5. 用什么场景、对照组和观测量验证？

如果某一问题没有可靠信息，应写明“现有材料无法判断”，并指出需要补充的证据；禁止用抽象能力词替代事实。

## 禁止的套话模式

- 对所有装备重复使用“通过分布式感知、弹性协同和多样化任务效应提升……”；
- 对所有装备重复“任务贡献是……、作用路径是……、相对基线改变为……”的同构长句；
- 用“指标画像尚未形成”“公开证据不足”反复占位，却不说明缺什么数据、影响什么判断；
- 把“发现、压制、抵抗、反制、续接”等体系词直接当作装备效果；
- 把“提升效率、增强韧性、形成闭环、提高成功率”作为没有场景和观测量的结论；
- 为不同装备安排完全相同的指标、风险、验证流程或判退条件。

## 差异化写法

- 定向能：写波束、作用扇面、目标抗扰等级、遮蔽和电磁环境；
- 末段拦截：写识别时延、接敌几何、末段毁伤和误射风险；
- 网幕/栅幕：写展开可靠性、封控几何、覆盖连续性和友邻安全；
- 滑翔/精确弹：写定位误差、发射判据、末段修正和目标停留时间；
- 分布式弹群：写分离一致性、去重、补杀和断链后的信息保持；
- 折返巡飞：写再识别、航迹安全、续航、载荷和多次接敌收益。

以上只是示例，最终内容必须以实际装备资料为准。

## 证据和指标规则

每个结论绑定证据等级：已证实、合理推断、待验证或无法判断。指标必须同时给出场景、对照基线、测量方法和判退条件。没有校准数据时使用区间、趋势或定性判断，不虚构点值。

## 自动质检门

提交前执行以下检查：

- 统计高频句，任何完整句子在不同装备条目中重复出现即退回重写；
- 对比各装备的“贡献、机理、边界、指标”四栏，若结构和词汇高度相同，要求补充装备专属事实；
- 检查每个指标是否能被某个具体试验直接观测；
- 检查每个风险是否对应明确触发条件和后果；
- 删除只表达谨慎态度、没有新增信息的免责声明；
- 抽查一件装备，脱离装备名称后仍能判断其类别和作用，否则说明内容过于泛化。

## 输出要求

正文优先使用短段落和明确动词。先写事实，再写判断，最后写证据边界。不得为了填满表格而制造字段内容；宁可合并字段、留空并说明原因，也不重复套话。
