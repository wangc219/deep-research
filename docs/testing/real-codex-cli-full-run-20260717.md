8. 强化 S4 契约：强制区分装备/非装备 DOTMLPF、体系接口、边界和精确证据引用。
9. 强化 S5 契约：每项差距必须包含缺口本体、证据强度、升级、新研、验证和证据引用，避免成熟度不足被误判为空白。
