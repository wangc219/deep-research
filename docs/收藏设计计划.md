# 完整能力画像卡片收藏页升级方案

## Summary

把“收藏”升级为完整能力画像卡片管理功能：

- 能力图像页中的正式 S6 卡片可收藏到“全局公共收藏”。
- 收藏页按“公共收藏 / 个人收藏”分类。
- 收藏项保存完整能力画像卡片，包含五模块正文、分类、装备维度、置信度、优先级、证据和来源任务信息。
- 来源任务归档或删除后，收藏仍可独立打开快照。
- 个人收藏先完成接口和页面预留，后续接入系统登录后直接按账户隔离。

## Implementation Changes

### 后端数据与接口

在 `src/equipment_deep_research/persistence/repositories.py` 增加独立 `favorites` 表，字段包括：

- `favorite_id`
- `scope`: `global` 或 `private`
- `owner_id`: 公共收藏固定为 `workspace`，个人收藏预留账户 ID
- `run_id`
- `card_binding_id`、`capability_id`
- `snapshot_json`
- `source_topic`、`source_status`、`source_deleted`
- `created_at`、`updated_at`

收藏唯一键为：

```text
scope + owner_id + run_id + card_key
```

其中 `card_key` 优先使用 `card_binding_id`，兼容 `capability_id`，缺失时回退为规范化的“卡片名称 + 能力分类”。

新增接口：

- `POST /api/v1/favorites`
  - 默认创建公共收藏。
  - 只接受已有完整 S6 画像正文的正式卡片。
  - 拒绝参考装备、S5 临时条目、待成稿卡片和空画像。
  - 服务端读取能力画像并保存完整快照，重复请求幂等。
- `GET /api/v1/favorites`
  - 支持 `scope`、分页、名称搜索、能力类型筛选。
  - 默认按 `created_at DESC` 排序。
  - 返回完整快照，不要求收藏页逐个请求来源任务。
- `DELETE /api/v1/favorites/{favorite_id}`
  - 公共收藏允许成员新增。
  - 公共收藏删除和清理仅 admin 可执行。
  - 个人收藏按未来登录账户校验 owner。
- 能力画像接口补充 `card_binding_id`、`card_id`、`favorited`、`favorite_id`。

来源任务永久删除时不删除收藏记录，仅更新 `source_deleted=true`，保留完整卡片快照。

### 前端卡片与收藏页

修改 `apps/web/src/main.jsx`：

- 导航增加“收藏”入口，并显式分发到 `FavoritesPage`。
- `readNavigationState` / `navigate` 增加 `scope`、`cap` 参数。
- 在 `CapabilityImageView` 的每张卡片标题区域增加收藏星标。
- 只有 `deep_capability_portrait` 或完整 `capability_portrait_modules` 存在时启用星标。
- 收藏操作采用乐观更新：
  - 立即变更星标；
  - 请求失败时恢复原状态并提示；
  - 成功后同步全局收藏索引。
- App 层维护按 `run_id + card_key` 索引的收藏状态，避免能力页、报告页重复请求收藏状态。

新增 `FavoritesPage`：

- 默认打开 `scope=global` 公共收藏。
- 提供“公共收藏 / 个人收藏”分类切换。
- 个人收藏在未登录阶段显示“登录后使用”的预留页面，不读写匿名个人数据。
- 每个收藏项完整渲染：
  - 卡片名称；
  - 能力分类和装备维度；
  - 优先级、置信度及待核验状态；
  - 完整五模块画像：概述、装备与技术实现、关键作战流程、形成能力与作战效果、制胜逻辑；
  - 证据摘要和来源任务；
  - 收藏时间；
  - 来源已归档/已删除状态。
- 复用 `CapabilityPortrait`、`WeaponDimensions` 和现有卡片样式，保证收藏页与能力图像页视觉和内容一致。
- 支持名称搜索、能力类型筛选、分页、取消收藏、加载失败重试和空态。
- 点击收藏项：
  - 来源可读时跳转 `view=capabilities&run=<run_id>&cap=<card_key>`，定位并高亮原卡；
  - 来源不可读时继续在收藏页展示完整快照。

修改 `apps/web/src/live.css`：

- 增加星标默认、已收藏、禁用、聚焦状态。
- 增加收藏分类标签、完整卡片布局、来源状态、空态和错误态样式。
- 保证打印和 DOCX 导出不包含交互星标。

## Test Plan

- **卡片资格**
  - 完整 S6 卡片可收藏。
  - 空画像、参考装备、S5 临时卡、待成稿卡片不可收藏。
- **公共收藏**
  - analyst/reviewer 可新增。
  - 普通成员删除返回 403。
  - admin 可删除。
  - 重复 POST 不生成重复记录。
- **个人收藏预留**
  - 未登录时不返回或写入个人收藏。
  - owner 字段和查询条件支持未来账户隔离。
- **完整快照**
  - 收藏页展示五模块正文及所有关键元数据。
  - 来源任务归档后仍能打开。
  - 来源任务永久删除后仍显示快照和“原任务已删除”。
- **前端行为**
  - 星标即时反馈、失败回滚、刷新后状态一致。
  - 公共/个人分类切换、搜索、筛选、分页和空态正常。
  - 可从收藏项返回原能力卡并高亮。
  - 来源不可用时不导致收藏页整体失败。
  - 键盘、焦点和屏幕阅读器可操作。
- 执行后端 API 集成测试、SQLite 重启持久化测试、`npm run build` 和浏览器冒烟测试。

## Assumptions

- 本期只允许写入公共收藏；个人收藏完成页面和 API 预留，登录接入后启用。
- 公共收藏默认由星标操作创建，删除权限仅 admin。
- 收藏对象必须是已形成完整能力画像正文的正式 S6 卡片。
- 收藏保存快照，不随来源任务内容变化。
- 本期不加入标签、备注、文件夹、批量管理和导出。
