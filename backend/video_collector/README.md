# 电脑微信采集连接

已有 `video_text` 环境：保持采集器运行，登录电脑微信并进入视频号，网站自动复用连接。
网站与连接包都会检查 MCP、已信任证书、实际系统代理和微信页面连接；系统代理被关闭时会恢复。
首次证书尚未完成本机信任时，必须在采集程序中完成系统授权，不用修改网页配置。

首次使用或连接其他电脑：下载对应系统的连接包，解压后双击“连接我的微信”。
Python 和 FFmpeg 自动准备，采集器按 `server` 模式启动；看到网站已连接后返回网页使用。
无需手填地址、MCP 开关或配对 JSON。关闭连接窗口或在网站撤销设备即可停止个人连接。

采集端只向配置中的平台 HTTPS origin 主动连接，不需要公网 IP、端口转发或把 Cookie 上传到服务器。
本机只提取临时音频，交接给平台后删除；云端完成识别并保存 Word，临时音频处理后删除。
设备凭据只用于当前设备的任务，不能调用平台普通管理接口。不要向他人发送配对 JSON。
服务器或专用电脑登录集中账号时，也需要安装微信、启动下载器，或使用仓库提供的 SSH 私有桥接配置。
不会在普通网页中登录微信，也不会通过扫码网站登录冒充视频号采集授权。
