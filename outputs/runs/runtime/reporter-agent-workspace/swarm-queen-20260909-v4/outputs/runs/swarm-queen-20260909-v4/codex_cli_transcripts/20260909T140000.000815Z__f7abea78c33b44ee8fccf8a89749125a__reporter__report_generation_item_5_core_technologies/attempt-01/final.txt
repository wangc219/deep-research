**第二层：技术攻关层——能力实现途径与核心技术**

**⑤ 核心技术清单与攻关优先级**

本清单只收"缺了它、该型装备面对的任务断点仍然敞开"的技术，筛入判据有三条：该环节是否卡在探测失效与火力生效的交接处，其约束属物理性或能量性还是仅工艺优化，已有成熟基础是否只解决了矛盾的一半。优先级分两档：成立性（不解决则该型装备退化为既有手段）与效能性（不解决则战果规模或作战边界收窄）。

**磨蚀—吸波双功能颗粒与下风侧起爆时窗（“雾蚀”蜂群桨损播撒弹·尘幕建成与走廊封锁环节）｜成立性**
消光要求粒径匹配毫米波与激光波长并有高磁电损耗，擦伤桨面要求单颗粒质量大、硬度高，两者都指向高密度；云团却须悬浮数十秒并被旋翼与进气吸入，反而要求低密度大比表面积。烟幕消光、吸波粉体与抛撒装药各自成熟，但烟幕不做机械功、飘条纤维只作用于雷达单通道，须攻关硬核损壳片状颗粒与双峰粒径配级，并以弹内冷散布避免涂层烧蚀。同一装备的第二断点是播撒几何：抛散过猛，颗粒被湍流抬出突防高度层；过弱则成团下坠；起爆偏差数秒，吸入通量跌破擦伤临界值。时间引信与近地测风是成熟件，未闭合的是引信时窗、风场估计与雷达航迹的解算链，且尘幕对敌我动力共同生效，闭环还须输出友邻禁航段。

**零功耗长时悬定与无源磁—声值守触发（低空航道封锁布雷弹·封锁存续与识别起爆链）｜成立性**
电池驱动旋翼把功率全部用于克服重力，留空以十分钟计，形不成"长期封锁"；只有改由密封浮体承担重力、姿控单元仅在漂移超限时短时修正，能量矛盾才解开，随即撞上膜材微泄漏、温差浮力漂移、风载摆动与系缆缠绕。浮空气球与子弹药开舱充气有工程基础，缺的是承受发射与抛撒过载不发卡的发气锁定机构和浮配平自校正。悬定之后还需在近乎不耗电状态下只从地磁扰动与旋翼声纹提取特征，把小型无人机同诱饵、鸟群与风噪分开：主动探测与本弹不辐射的立意冲突，单一磁通门虚警过高，路线只能是多物理量联合判据加延时确认，落装于弹体下缘传感环与引信安全解算模块；对低磁壳体与静音平台的捕获率缺公开证据，门限须按区间与置信度设定。

**多径几何判别与掠檐折转的能量—舵效匹配（峡谷多径折返拦截弹·盲区接敌与末段窗口）｜成立性**
建筑立面把回波撕成大量镜面虚像，传统近程导引头靠幅度与相关性门限剔除多径，往往把真目标和遮挡一起滤掉，而弹体口径、功耗与散热不允许用加大孔径换分辨率。断点不在看得更远，而在毫秒内判定哪一路回波对应机体、下一段贴哪条立面飞：须把立面当作已知反射面，用目标与虚像的几何一致性判别，并与可飞航线在线重规划共用同一套量测，城市三维底图与多径抑制成像可作起点但尚未在弹载时限内合流。第二半是舵效——折叠舵面在亚跨音速大侧滑下有效面积与力矩受限，折转吃掉的剩余速度直接压缩破片最佳指向窗口，贴檐余量仅数米、舵量偏差即撞楼，而传统比例导引按小机动设计、不必在不可通行边界内侧连续改向，攻关方向是把航线曲率、可用过载、剩余速度与起爆指向收进同一在线预测控制。

**受限孔径声学接敌与无爆轰缠绞捕获（柔索缠桨拦截无人机·末段交会与杀伤环节）｜成立性**
城市背景中旋翼声压弱、图传时断时续，声学阵又被自身机身与旋翼遮挡并吸入自噪声；加装主动雷达被楼宇杂波抬高虚警且超出轻型机承载，依赖后方雷达遥控则发现与授权串在数据链上，末段数秒延迟即错过窗口。必须把测向时差混合定位、转速估计与交会解算压进机载任务计算机，让孔径受限的声学阵直接输出抛索触发量与提前量。抛出端受要地上空不爆轰的约束，索具须在极短时间内从收卷完全张开、靠配重带索头越过目标桨盘且不被弹开或磨断，纤维强度、索长、配重与相对速度互相制约；现有抛绳器材面向低速目标、不承受桨叶切割，需攻克展开动力学与缠绕几何匹配、抗摩擦升温的索体与端部连接，并使锁死能量取自目标自身电机功率而非拦截机。

**低功耗无源定向确认与数月值守起爆（阵前预置零延拦射雷·零延迟交战环节）｜成立性**
交战不经雷达与指挥链路，来袭方向是唯一触发条件，数百米航道上的方位误差直接变成破片束脱靶量。峡谷风啸、跌水与雨打植被掩盖旋翼信号，单阈值声控大风天误炸、雨天漏警——传统声控雷只能判别有无，给不出方位。攻关路线为麦克风阵列与日盲紫外的异构事件驱动融合，以到达时间差测向、用旋翼幅度调制设类别门限，使单枚电池覆盖数月值守。次级约束同样卡命：飞散角越窄越吃测向误差，炸高、延时与破片初速须匹配航速，数月日晒雨淋与杆体风振造成基线漂移与元件老化，需储备式供电加电容脉冲放电、隔爆链一次动作电引爆与寿命自诊断；取舍为灵敏度换虚警、束宽换命中密度、值守时长换能量裕度。

**旋转甩幕成幕与限时自净（展幕缠旋拦阻航弹·面积拒止环节）｜成立性**
数百米宽的断面要结成连续幕体，纤维线密度、抛撒动能与下落末速互相牵制：过细在抛出瞬间因缠结与静电吸附成团，展不开遮挡面积；过粗则末速高、悬浮短，弹重与装药超出火箭和无人机载荷上限。箔条只形成电磁假目标、抛撒布靠单件重物下垂，都撑不住低空剪切风中的大面积连续拦截，这正是幕体数十秒破洞的原因。还须按典型机型桨径与转速确定网目尺寸、单丝强度、端头配重与摩擦系数，使卷入后无法甩脱并导致升力面失效；幕体对己方旋翼机同样致命，须以计时断丝或光热降解实现限时自净，保住走廊可反复使用。

**弹载红外成像自主截获与无中心错峰抢占（群站共瞄分布式拦射弹·离架后自主段）｜成立性**
上游只给粗航迹，角误差大且不含速度，导引头开机后要在低空强地物杂波、雨雾与热交叉中从数十个候选热点里抓住小旋翼的微弱点源；非制冷红外面阵视场大了能量不足、小了兜不住航迹残差，构成口径、帧频、弹体尺寸、功耗与制导回路延时的死结。传统指令修正把识别负担留在地面，火控通道被诱饵压满即成无头弹，故须转小面阵高分帧频焦面加弹上轻量序列检测，以点源闪烁、旋翼调制与相对加速度做多维筛选，实现开机即捕获与末段诱饵拒绝。同量级的第二断点是抢占共识：多弹各自认领同一目标会立刻把并行容量变成内耗，链路断续、定位受限时须在亚秒级形成"谁已认领"的判定，而上层战管统一指派既串行又怕断链，正是本弹要绕开的对象。

**排序理由与不含项**
七项均标为成立性，是因为它们各自决定一类过去不可下达的任务能否下达；其内部次序按上游依赖排列——无源定向与悬定触发（布雷弹、零延雷）决定拒止面能否存在，播撒与成幕的介质配级（雾蚀弹、展幕航弹）决定面积效应能否维持，弹载自主段（峡谷弹、柔索机、共瞄弹）决定末段能否闭合。四型依赖无源判读的装备共用"无源"二字却不是同一项技术：布雷弹要在零功耗下把诱饵与鸟群分开，零延雷要给出方位并支撑起爆延时，柔索机要在自噪声中估转速与提前量，共瞄弹要在杂波里完成末段确认，功耗、算力与判据三项边界各不相同，合并立项会让四型同时误配。定向能与导航诱骗已由现役手段承接，不构成本批装备的成败断点，不进入本层攻关序列。
