## 第二层：技术攻关层——能力实现途径与核心技术

### ⑤ 核心技术清单与攻关优先级

本轮候选装备的成败并不取决于热门技术门类是否齐全，而取决于六处互不重复的技术断点。每处断点各自卡住某件装备的关键动作，攻不开则该装备的作战前提不成立。

**断点一：高密度磨蚀颗粒同时消光并做机械功（"雾蚀"蜂群桨损播撒弹）**
作用环节是在己方雷达与光电被扬尘、烟雾压制的时段接管走廊拒止，取代"先看清才能打"。物理矛盾很硬：对毫米波、激光与可见光造成穿透损失，要求粒径与波长匹配且磁电损耗高；要擦伤桨面、卡滞轴承，又要求单颗粒质量大、硬度高，两者都把配方推向高密度；而云团需悬浮数十秒并被旋翼与进气吸入，反而要求低密度大比表面积。成熟基础一侧，传统烟幕只消光不做机械功，飘条石墨纤维只作用于雷达单通道，形不成双重杀伤。瓶颈因此落在硬核损壳片状颗粒与双峰粒径配级、以弹内冷散布避免涂层烧蚀、把悬浮时间和消光截面做成可调量，并与其上游的引信时窗—风场估计—航迹解算链同时闭合。攻关优先级高（P0），它是七件装备中唯一能把天候掩护从敌方红利改写为双方共同代价的机理。

**断点二：零功耗长时悬定与高过载展开（低空航道封锁布雷弹）**
该装备的全部价值在于抛进去之后能否长期悬停待炸，从而在拦截弹耗尽与雷达静默时段继续占住航道。工程约束是能量分配：电池驱动旋翼把功率全部用于克服重力，留空以十分钟计，构不成"封锁"二字。成熟的只有抛撒与开舱环节，迫击炮和火箭的弹道投送、子弹药抛撒均可沿用。真正的瓶颈是改由密封浮体承担重力、姿控单元仅在漂移超限时短时修正这条路线下的低漏率密封膜、温差浮力自校正与风载摆动抑制，以及发射与抛撒过载下不发卡的发气锁定机构。优先级高（P1），无它则该装备退化为一次性的短延时空炸。

**断点三：无源值守判别的共性底座（布雷弹、阵前预置零延拦射雷、柔索缠桨拦截无人机共用）**
三件装备都立意在"不辐射、不值守、不占火力通道"，因而共同押在同一项技术上：只凭目标自身辐射与几何投影完成唤醒、测向、类别判定并下达起爆或抛索指令。约束来自背景本身——峡谷风啸、跌水与雨打植被掩盖旋翼特征，单阈值声控在大风天误炸、雨天漏警，而数百米航道上的方位误差直接等于破片束脱靶量。既有基础只到"有无可"判别的声控雷与工程上的无源测向，给不出可用方位。攻关内容为麦克风阵列与日盲紫外的异构事件驱动融合、以到达时间差测向、用旋翼幅度调制设类别门限、加延时确认压虚警，并配套储备式供电与电容脉冲放电、隔爆链一次动作电引爆、爆轰热冲击下的舱内隔离与寿命自诊断，以守住数月值守与到期自毁底线。优先级最高（P0），一次投入可同时解除三件装备的单点失败条件，是全部清单中杠杆最大的一项。

**断点四：高强纤维的展开动力学与缠绞捕获判据（柔索缠桨拦截无人机、展幕缠旋拦阻航弹共用）**
两者都以无爆轰的纯机械接触完成击落，锁死所需能量取自目标自身电机，拦截方只需把柔性件送入可被桨盘抓取的空间位置。约束互相牵制：附带损伤限制决定抛射能量不能加大，纤维线密度越细越易因缠结与静电吸附成团、展不开遮挡面积，过粗则下落末速高、悬浮时间短，并超出火箭与无人机载荷上限。箔条只形成电磁假目标、抛撒布靠单件重物下垂，都无法在低空剪切风中维持大面积连续拦截，这正是幕体数十秒即破洞的原因。需突破的是束长与线密度分级配组、低弯矩卷曲定型与抗静电处理，旋转盘角速度—释放时序—径向初速的匹配，按典型机型桨径与转速确定的网目尺寸、单丝强度、端头配重与摩擦系数，以及计时断丝或光热降解的限时自净，否则拦阻幕对己方旋翼同样致命。优先级中高（P1）。

**断点五：小口径红外成像自主截获与无中心错峰抢占（群站共瞄分布式拦射弹）**
该装备以"任一传感器推粗航迹、弹自认领"替换串行火控排队，其容量增益全部取决于两项技术。约束是尺寸、功耗与延时的死结：非制冷红外视场做大则能量不足，做小则兜不住粗航迹的角误差残差，而低空强地物杂波与热交叉背景中要在一串候选热点里稳定咬住小旋翼的弱点源。成像导引头与分布式光电感知各自已有工程基础，缺的是把识别负担从地面转到弹上。攻关方向为小面阵高分帧频焦面配合弹上轻量序列检测，用点源闪烁、旋翼调制与相对加速度做多维筛选，实现开机即捕获与诱饵拒绝；同时让多枚弹在链路断续、定位受限时以亚秒级形成"谁已认领"的共识，替代怕断链的上层统一指派。优先级高（P1），共识不成立则多弹重复拦射，并行容量被内耗抵消。

**断点六：多径感知—折转航线—舵效能量的联合闭环（峡谷多径折返拦截弹）**
它要解决的是城市低空杀伤链末端的几何断点，约束同样最苛刻：弹体口径、功耗与散热不允许靠加大孔径换分辨率；折叠舵面在亚跨音速大侧滑下有效面积与力矩受限，折转吃掉的剩余速度直接压缩攻击窗口，而贴檐余量只有数米，舵量偏差即撞楼。传统比例导引按小机动设计，导引头靠幅度与相关性门限剔除多径，往往把真目标连同遮挡一起滤掉。攻关须把立面当作已知反射面，用目标与虚像的几何一致性而非强度门限判别，并与可飞航线在线重规划共用同一套量测，再把航线曲率、可用过载、剩余速度与破片最佳指向收进同一在线预测控制。优先级中（P2）：其成立还依赖建筑立面与多径特征的先验数据，脱离峡谷优势即消失，宜先建数据与仿真闭环，不与上述各项争夺当期工程资源。

**排序依据与未立号方向**
上述序位按"是否决定该装备能否形成新任务"排列，而非按技术难度：断点一、三决定能否在无探测条件下拒止与拦截，属先决条件；断点二、四、五决定拒止面与并行容量能否持续兑现；断点六受先验数据约束，列为预研储备。抗干扰短网、高能微波与通用目标识别算法未单列，因为七件装备的失败模式集中在介质作用与无源判据两端，网络与算法按现有体系接口沿用改进即可满足。需说明的证据边界：本轮武器装备公开基线未获实质结论，上述成熟度判断停留在机理与工程路线层级，不含点值、射程、浓度或虚警率等参数，后续须在候选级补证后细化为可验证判据。
