**第二层：技术攻关层——能力实现途径与核心技术**

### ⑤ 核心技术清单与攻关优先级

本轮技术断点不按热门类别铺陈，只从七项装备各自的因果链上取"不突破即整条链路失效"的那一环。判据有三：该技术是否直接决定任务能否成立；是否存在明确的物理或工程矛盾而非单纯指标偏低；国内是否有可承接的成熟基础。三项同时满足才入清单，故清单长短不等，允许单项装备只列一项。

**一、跨装备共性断点：低空无源目标判读**

"雾蚀"蜂群桨损播撒弹、低空航道封锁布雷弹、阵前预置零延拦射雷、柔索缠桨拦截无人机四项，卡在同一处：不辐射、不依赖上游雷达的前提下，从地物杂波、风啸雨噪与民用噪声中稳定提取旋翼类目标的存在、方位与类别。这是本轮最集中的技术断点，但四者对它的索取并不相同——布雷弹与拦射雷要的是低功耗长期值守下的门限判定，播撒弹要的是走廊航迹与风场匹配后的起爆窗口，截击机要的是机动平台上声学阵自身的降噪与测向时差解算。共性投入应放在异构传感器事件驱动融合、到达时间差测向与旋翼幅度调制分类三项基础算法与器件上，按装备分别标定功耗、体积与虚警门限，避免以一套指标套四件装备。

**三、攻关优先级与排序理由**

P1（雾蚀播撒弹颗粒与播撒时序）排首位：它是唯一直接回应"天候被对手征用"这一决定性断点的手段，且颗粒配级与风场解算两项互相定义，任何一项单独推进都不产生战力。

P2 与 P5 同属"无源长期存在"类，但取舍不同。布雷弹的悬定技术在国内几乎没有可继承产品，属从零起研，需与膜材、发气机构同步布局；拦射雷的器件基础较好，主要工作在门限标定与寿命管理，可用较小投入先出原型，故 P5 排在布雷弹两项之后但仍属近期可动。

P3 与 P4 的瓶颈集中在弹载/机载实时解算，依赖同一批小口径导引头与机载计算能力，宜合并立项、分立验收，避免两套互不兼容的处理平台。P6 的纤维束成幕属材料—机构—气象交叉，缺一组基础试验数据支撑，建议以地面高速摄影与风洞实验先行。P7 的分布式自认领改变的是体系容量结构，收益最大，但对上游光电节点的在位率与时统一致性要求最严，须与组网接口标准同步推进，不宜单点抢跑。

**四、证据边界**

本轮武器装备公开基线与作战运用基线均因上游模型输出校验未获实质结论而不可用，故成熟度与瓶颈描述仅到原理与工程矛盾层次，不给出技术就绪等级点值、具体型号归属或试验结论。上述七项目标性能参数一律以区间与置信度表述，公开证据不足处不以确定数字替代。
