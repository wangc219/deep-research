第二层：技术攻关层——能力实现途径与核心技术

④ 能力实现途径

传统低空防空的失效点分布在三层：装填段缺少能对旋翼做功的介质，阵地火力无法在人在场外持续存在，指挥链的秒级闭环追不上末段机动。七个候选方向分别卡在这三层，因此实现途径不能一律按"新造一型装备"处理，而要看约束究竟绑在弹药、平台还是交战程序上。

"雾蚀"蜂群桨损播撒弹属原理突破，突破面只压在装填段与引信解算两处。微米级磨蚀与吸波双功能颗粒要在同一粒径谱内同时满足消光截面与桨面机械损伤，这与云团悬浮所需的低密度大比表面积直接冲突；现役烟幕只消光、飘条类耗材只作用于单一雷达通道，换配方补不出这重耦合。工程路线取硬核损壳片状颗粒与双峰粒径配级，以弹内冷散布避免涂层烧蚀，把悬浮时间和消光截面做成可调量，发射平台与时间引信按现役弹药接口层级沿用。新增量是把风场估计、起爆时窗与雷达航迹闭合成解算链，并向下风侧之外的友邻输出禁航段——风向翻转或目标改自上风进入时，尘幕对己方观测同样生效，该轮即不构成有效窗口。

展幕缠旋拦阻航弹从同一装填段切入，却是集成创新。旋转抛撒盘、开舱时序、火箭与无人机载运都有可借用的成熟件，难点集中在束体自身的包装与展开动力学：纤维过细则抛出瞬间缠结成团、展不出遮挡面积，过粗则下落末速高、悬浮撑不过一个批次，弹重与装药还要受载运平台上限约束。攻关落在束长与线密度分级配组、低弯矩卷曲定型与抗静电处理，并把盘角速度、释放时序、径向初速匹配成分层展开；幕体对己方旋翼同样致命，须以计时断丝或光热降解限时自净，否则封锁段把自己一并封死。

低空航道封锁布雷弹是抛撒通道沿用、子弹药原理突破的组合。迫击炮与火箭的弹道和发射界面不改动，价值全押在零功耗长期悬定：密封浮体承担重力、姿控单元仅在漂移超限时短时修正，才解开电池驱动旋翼"功率全用于克服重力、留空以十分钟计"的能量死结；代价是膜材微泄漏、温差浮力漂移、风载摆动与系缆缠绕成为主要故障源，落在上部浮体组件与展开锁定环。第二处突破是无源磁—声复合值守触发，几乎不耗电又不许主动辐射，须用多物理量联合判据加延时确认把小型无人机同诱饵、鸟群、风噪分开，落在弹体下缘传感环与引信安全解算模块。低磁壳体与静音平台的捕获率缺证据，不得写成确定门限。

阵前预置零延拦射雷把突破点从毁伤挪到交战程序：它删掉的是"发现—识别—分配—射击"这条人在环链条，雷体与埋杆悬置沿用工程保障手段。真正的攻关是低功耗无源定向确认——麦克风阵列与日盲紫外的异构事件驱动融合，以到达时间差测向、按旋翼幅度调制设类别门限，使单枚电池覆盖数月值守；以及储备式供电加电容脉冲放电、隔爆链一次动作电引爆、爆轰热冲击下舱内隔离与寿命自诊断。取舍是三对硬约束：灵敏度换虚警、破片束宽换命中密度、值守时长换能量裕度。它只在不辐射、不联网的边界内成立，航道不唯一或民用航路未关闭时必须转入延时禁用，且须多点位冗余抗诱爆。

群站共瞄分布式拦射弹属集成创新，也是体系条件最重的一项。非制冷红外成像、序列检测与抗干扰短网推送均可取用现有组件，增量在于把目标分配从火控排队改为弹自认领：导引头要在角误差大、不含速度的粗航迹误差带内开机即捕获，多弹须在亚秒级形成"谁已认领"的共识，否则并行容量被重复拦射抵消。落点一半在导引头窗口与焦面处理组件，一半在扇区边界、判别门限与认领规则的预装定，以及异构光电节点的敌我识别与时统一致。链路被压制时须能退化为单节点自主射击，这是集成路线的必配项而非选配项。

峡谷多径折返拦截弹只能按原理突破立项。它要求弹体把建筑立面当作已知反射面，以目标与虚像的几何一致性而非幅度门限判别，并把航线曲率、可用过载、剩余速度与破片最佳指向收进同一在线预测控制；现役按小机动设计的比例导引与直线追瞄架构，不支持在不可通行边界内侧连续改向，改装给不出这条闭环。折叠舵面与数米级贴檐余量决定其为新研弹体，破片战斗部与发射装置可沿用近程单装层级。成立前提是立面结构与多径特征有先验，脱离城市峡谷后优势消失。

柔索缠桨拦截无人机走集成创新，机体、弹射待战与回收再战流程沿用轻型无人机成熟做法，突破在于两件事的上机化：把测向时差混合定位、转速估计与交会解算压进机载任务计算机，使孔径受限的声学阵直接输出抛索触发量与提前量，不再把发现与授权串在数据链上；以及索具从收卷态在极短时间内靠配重带过桨盘、不被弹开或磨断，需展开动力学与缠绕几何匹配、抗摩擦升温的索体与端部连接，落在机背抛射舱、索筒与释放机构并受飞控速度姿态约束。对带护罩共轴目标、高速固定翼以及超出待战架次的饱和攻击不成立，仍需既有火力承接。

本轮未取得武器装备与作战运用的公开基线，上述"沿用"均以弹药层级与接口关系表述，不落到具体现役型号；消光截面、悬定时长、无源测向误差、截获概率等参数须由合同试验给出区间与置信度后，再定装填量、扇区边界与起爆门限。
