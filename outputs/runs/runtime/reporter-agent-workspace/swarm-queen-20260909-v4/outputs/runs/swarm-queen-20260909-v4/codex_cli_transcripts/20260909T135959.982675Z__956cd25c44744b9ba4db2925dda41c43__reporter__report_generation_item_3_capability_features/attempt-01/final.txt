## 第一层：需求挖掘层——场景·战法·装备能力特征

### ③ 装备能力特征清单

任务链上只有两处真断点：一是探测先于火力失效，扬尘、烟雾与低能见度把雷达和光电压在前头；二是火力容量先于毁伤失效，多向饱和让持续开机、逐通道占用、打完再装填变成一道算不过来的账。下列七类装备各只解其中一格，能力特征与判别指标不可互换；凡概率、时长、距离一类量，因武器装备公开基线本轮未通过校验，一律保留为变量与工况，不落点值。

"雾蚀"蜂群桨损播撒弹解传感器先瞎：一段人工尘幕同时承担两项功能，散射毫米波、激光与可见光使导引失锁，又被旋翼与进气吸入造成桨面擦伤与轴承卡滞。传统烟幕只消光不做机械功，飘条箔条只占雷达单通道，给不出这种双重降效。判别方向落在双峰粒径配比下浓度与悬浮时长能否兼顾、消光深度与桨面损伤阈值是否在同一云团内同时越过、单位时间被旋翼吸入的通量；工况为风向风速稳定度、突防高度层与背景气溶胶水平。战果口径不是命中率，而是整批目标丧失航线保持能力的时长与横向、高度离散度。

低空航道封锁布雷弹解再装填空窗与雷达为生存间歇静默的时段：封锁由靠能量维持的留空改为靠浮力维持的存在，不辐射、不在环、不因射击而耗尽。判别方向落在零功耗悬定期对膜材微泄漏、温差浮力漂移与风载摆动的容忍带，无源磁声复合值守把旋翼目标同诱饵、鸟群、风噪分开的能力及其功耗代价，开舱发气锁定机构在发射过载下的动作可靠性；工况为三十至一百五十米高度层与河谷、城镇边缘地物背景。结算量是航道通断表，即哪条航道在哪一时段不可通行，而非击落架数。

阵前预置零延拦射雷解闭环耗时大于突防可用时间：删去人在环，反应时间归零，交战脱离雷达与指挥链路。判别方向落在数月值守期内风啸、跌水、雨打植被噪声中的测向角误差，该误差直接等于定向破片束的脱靶量；类别门限对旋翼幅度调制的识别裕度与灵敏度、虚警的取舍；窄飞散角对测向误差的敏感性，以及炸高、延时与目标航速的匹配窗口。工况为峡谷口与桥隧端点的航道唯一性。它把极低空盲区从火力问题转成阵地工程问题，前提是必经航道可预判。

展幕缠旋拦阻航弹解逐点拦截成本随目标数线性增长：开火前提被摘掉，不依赖雷达反射面积、红外特征与敌我识别置信度，诱饵骗不过它。判别方向落在束长、线密度、抛撒动能与下落末速共同决定的幕体连续度，旋转盘角速度、释放时序与径向初速的匹配，网目尺寸同典型桨径、叶尖线速度构成的卷入概率，以及幕体自净时限；工况为数百米宽走廊断面与低空剪切风。战果写成一次投放造成的成群终止数量与走廊关闭时长。

群站共瞄分布式拦射弹解服务台数稀缺而非威力不足：火力容量随异构传感器与待发弹数横向扩展，弹自认领、末段自行确认。判别方向落在粗航迹误差带与导引头捕获视场的匹配宽度，点源闪烁、旋翼调制与相对加速度多维筛选对相似诱饵的拒绝率，链路断续时弹间认领的重复占用率与漏抢率；工况为夜暗、雨雾、热交叉下数十秒内多方向到达。指标取并发拦截通道数与来袭到达率之比，单发命中概率在本型上不具判别力。

峡谷多径折返拦截弹解几何断点：目标在建筑遮挡后既无稳定航迹也无直射通道。它把立面当已知反射面使用，按本体回波与镜像的几何一致性判目标，以掠檐折转航线替代直线追瞄。判别方向落在两类回波在时延和仰角上的稳定分离度，折转段剩余速度与折叠舵面有效面积、可用过载的匹配，贴檐余量与舵量偏差构成的撞界风险，航线曲率与破片最佳指向能否收进同一在线预测；工况为建筑间距与檐口高度的先验可得性，脱离峡谷优势即消失。

柔索缠桨拦截无人机解人员密集区上空的开火禁区：毁伤与电磁耦合解绑，无爆轰、无破片，单架可回收再战。判别方向落在抛射能量受限下索具完全张开的时间与配重、索长、相对速度的耦合解，卷入圈数达到锁死的概率随目标转速与桨盘暴露度的变化，机载声学阵在自噪声与机身遮挡下的测向定位精度能否直接输出抛索提前量，以及坠落走廊的人群风险约束；工况为数十至一百余米高度、数秒量级末段窗口。对高速固定翼与带护罩共轴目标不成立。

各特征的稳固程度并不相同：尘幕依赖风场可预测，航道封锁在被弃用后价值迅速衰减，缠桨遇护桨与转子惯量提升即失效，预置拦射遭诱爆与地面清路，分布式共瞄依赖传感器节点持续在位。把这些变量当作已定量，就会把能力特征误读成成熟指标。
