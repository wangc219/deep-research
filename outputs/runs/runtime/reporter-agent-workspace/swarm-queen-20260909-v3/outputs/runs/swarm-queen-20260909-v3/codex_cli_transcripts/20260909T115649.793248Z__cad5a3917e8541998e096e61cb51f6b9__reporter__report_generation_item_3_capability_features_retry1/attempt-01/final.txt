## 第一层：需求挖掘层——场景·战法/技术·装备能力特征

### ③ 装备能力特征清单

本清单从任务链断点反推每件入选装备的具体能力与有判别力的指标方向。各装备断点不同，指标组不共用；缺少台架与外场校准数据处保留变量和工况，不生成点值。

**磁通压缩脉冲微波拦截弹——群目标面失能硬毁伤**

断点在于：蜂群沿汇聚走廊密集进近时，逐发拦截使火力通道先于备弹饱和，守方被迫选择"放哪一架过去"。该弹以一次性火箭段将磁通压缩功率源送至走廊前段数十米处，释放单发亚微秒高功率微波，使同一视场内多架微型无人机和巡飞弹的飞控与引航电路同时永久烧毁，战果结算单位从"命中一架"改为"覆盖一片"。其专属指标方向为：脉冲到达辐射源前的峰值功率与脉宽（取决于电枢衬套接触状态、等离子体形成损耗及触发抖动，均需弹载工况实测标定）、数十米距离处视场内有效场强与加固器件击穿阈值的余量、群目标质心解算周期与可用释放窗口重叠概率。该弹不追求单点命中精度，其能力成立条件是近程雷达在汇聚段连续装订并给出可用起爆时机。

**碳长丝缠翼近程拦截弹——航路占据式批量旋翼失效**

断点在于：末端防御半径1至3千米、100米以下高度，旋翼类目标以3至20机批量进近，部分平台断链后靠惯性或视觉自主突防，干扰失效且逐目标射击使待发基数数十秒见底。该弹贴近预计航迹起爆，将高强度碳长丝抛撒为沿来向飘移的丝雾带，丝束灌入旋翼后机械缠绕卡死转子并引发电机绕组短路，整批进带目标同时失去升力。其专属指标方向为：起爆瞬间丝束存活率（爆轰冲击下长丝不切断、不烧蚀的阈值与装药波形、预成型骨架几何均耦合，未标定前只保留工况变量）、丝雾带从起爆至飘移至有效拦截截面的时间窗口与风速、风向的函数关系、带内丝密度对十千克级旋翼桨盘面积的覆盖率。该弹不依赖命中精度，能力边界是涵道化、高速固定翼和强侧风下覆盖急剧收窄。

**「灼羽」低空激光歼击炮——供电驱动的持续驻照歼击**

断点在于：敌以消耗—饱和—再突入三段式打法逼防御方在第三批齐射后出现火力空窗；炮弹打光那一刻即为防线缺口时刻。该炮以连续波光纤激光对已解算航迹实施秒级驻照，在1至2千米距离上烧穿旋翼及机翼复合材料蒙皮或致盲光电窗口，每架次交战仅消耗电能，不存在弹药耗尽退出的状态。其专属指标方向为：远场可维持功率密度与有效驻照时间之积（受热晕、湍流漂移、大气消光与目标机动角速度联合制约，各气象条件下数值需外场试验获取）、闭环跟踪在旋转桨叶上保持驻照点的均方误差对剂量累积效率的衰减曲线、电光转换效率所决定的废热功率与可持续射击节拍之间的约束关系。与微波弹不同，该炮要求视准线全程通视且光束不被遮蔽，烟幕和雨雾构成硬边界。

**千枚廉价撞杀巡飞弹——预置密度场与通道解耦**

断点在于：波次间隔数十秒到数分钟内，传统装备既来不及再装填也来不及重建通道分配，恰是突防发生的窗口。该装备以箱式齐射一次释放千枚级一次性小型弹体，弹靠微型涡喷或弹射起飞后自主寻向，以机体动能撞击敌巡飞弹与操控式无人机，在指定高度层形成持续数小时的"可撞单元流"。其专属指标方向为：出箱后单元自组织散开至稳态密度的时间与弹间碰撞损耗比例（取决于抛射时序、气动干扰和去冲突算法在有限算力下的收敛性，须缩比群射试验标定）、被动导引头在低空杂波中对微小目标的检测概率与虚警率随相对速度和杂波强度的变化、单位空域内可撞元密度与来袭目标遭遇概率的统计关系。指挥对象从单次射击变为一片空域的密度水位。

**伞骨撑网拦阻飞艇——零能耗几何禁入面**

断点在于：30米以下近地层被地物杂波淹没，火控最小航速与最小距离门限使高炮和近程导弹无法交战，目标保持贴地即"不可打"。该装备沿必飞走廊系留展开一批小型浮体，浮体下方由伞骨撑开大面积柔性缠绕网幕，旋翼或螺旋桨一旦撞入即被缠死坠落，无需探测、跟踪与射击。其专属指标方向为：网幕在阵风载荷下的张紧度保持范围与有效拦阻截面面积的比值（涉及伞骨刚度、网衣细度与浮体浮力的多目标约束，需风洞与外场系留试验交叉标定）、目标撞入后从接触至完全缠停的时间与动能吸收峰值对缆绳锚固系统的载荷传递、单具浮体被毁后形成孔洞的尺寸与预备浮体补位时间之间的关系。该装备不涉及电磁链路，抗毁性等同于浮体物理存活性，但仅对存在可预测必飞走廊的场景成立。

**「山听」无源截杀拦截弹——电磁静默下的降级保底拦截**

断点在于：敌以电子压制致盲雷达并以反辐射火力搜捕开机辐射源，指挥所在开战初段断链，防线出现"不敢开机、不能联网、打不出弹"的数十分钟至数小时真空。该弹埋设于山谷隘口，不辐射不联网，靠被动声纹测向与红外成像双判交叉确认自主截杀，被压制的防线仍保留不可远程清除的"哑火力"段。其专属指标方向为：山谷风噪、溪流与公路背景下声纹阵列对旋翼目标的检测概率与测向误差（取决于多路径结构、信噪比与事件驱动处理的阈值策略，未标定前只保留变量与工况条件）、冷发射出筒后目标角速度超出捕获带宽的概率、声纹与红外双判一致时虚警率约束下的正确开火率。该弹不追求拦截效率最大化，其价值在于降级条件下的存在性保障，对多目标并发与无特征目标不设预期。

**自组补射协同拦截弹群——接敌中动态生成通道**

断点在于：火力通道数在齐射瞬间固定，敌方只需把同时到达的目标数排到通道数之上即必然漏防；末制导被干扰时该弹失效而邻弹仍飞向已无必要的位置。弹群出筒后数秒自组为无中心猎群，弹间共享目标判断并自主划分拦截扇区，任一弹丢失目标时把截获信息交给邻弹补杀，通道数由接敌过程动态决定。其专属指标方向为：弹间链路在低空多径与高速相对运动下的拓扑稳定时间和对等融合收敛周期（需在不同阵间距、高度层与干扰样式下标定）、量测级移交在时统基准不一致时外推误差随弹间距离的放大曲线、冗余耗尽告警从触发到上层二次火力响应的时间。该弹群的能力上限由弹数与链路可靠性共同决定，链路被全频段阻塞时退化为独立末制导单发。
