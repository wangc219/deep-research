## 第一层：需求挖掘层——场景·战法·装备能力特征

### ① 典型作战场景

下列场景按任务链断裂的位置区分，而不是按同一背景更换装备名称：地域尺度、时间窗、授权主体与失效后果逐件不同，装备选择因此由断点决定。

要地与野战伴随防空正面上，对手不用单机突防，而把第一视角穿越机、微型无人机和巡飞弹排成同轴多波次，沿少数可预测的汇聚走廊压进来：先用密集队形挤占火控通道，再用数量耗光待发弹；地形匹配与图像末制导使压制卫星导航和链路通道的廉价干扰不再保证目标失效。决定胜负的窗口只有数秒到十余秒，即敌群尚未拉开间距的走廊前段，作用距离被压到数十米量级。行动主体是近程雷达、火控与一个不开波束照射的发射单元；约束是群航迹必须连续装订、毁伤锥内无敌我有人机与关键电子设施。两条不成立，磁通压缩脉冲微波拦截弹就没有可用战场，通道与基数耗尽后的突防照常发生。

末端防空在更窄的地域：要地、野战机场、指挥所与后勤枢纽外半径1至3千米、100米以下，15至50米每秒进近的旋翼类目标以3至20机一批重复进入，部分平台断链后靠预置航路静默冲刺。这里的决定性时段不是来袭瞬间，而是前一批耗掉待发弹与可用通道之后、下一批抵达之前的30至120秒。碳长丝缠翼近程拦截弹占据的是一段空间而非一架目标，所以射击许可前必须先有实测风向风速、飘移方向判定，以及对下方后方己方旋翼活动和低空航路的禁布核查。风场不可测或落区危及地面人员即不出弹；否则机场、化工区与管线上空会因近距起爆的坠落危害事实上不敢开火，所谓禁区也无从维持。

一至两公里这一层，交战能否成立先取决于通视而不是弹道：视准可达扇面、仰角与遮挡、湿度、雨雾、低云和强湍流共同限制单位时间内可注入靶面的热量。态势是敌以多旋翼、小型固定翼与巡飞弹配合烟幕遮蔽光电通道，多方向分批压近，目的不是自身生存而是把炮弹基数与近程弹库存提前打光。可用窗口有两个：敌进入末段、俯冲或悬停投放前的数十秒，以及我方弹药将尽未尽的中段间隙。主体是配属末端的单炮值守单元，指挥员只给威胁优先级与开放扇区，驻照由炮长在航迹稳定后自主决断。供电、散热或指示链路被压住时，该方向退回按基数挑着打的配额逻辑，第三批即出现火力空窗。

另一类场景要守的是数小时到数日：指挥所、野战机场、弹药与技术阵地、后勤枢纽和伴随防空要地上空必须持续保持低空拒止。敌把第一波与诱饵送进来逼我方开火，等拦截弹基数见底再从波次间隔突防，而这段间隔只有数十秒到数分钟，既来不及再装填也来不及重建通道分配。千枚廉价撞杀巡飞弹要占的正是这段间隔，先决条件全部落在受袭之前：要域分区、箱体前置静默、掩蔽部内一次齐射铺开，补给以箱为最小单位。单元在无卫星、链路不可靠时仍须自主寻向并彼此去冲突；一旦密度跌破门槛或敌转走高空绕袭、压制补弹线路，该轴向必须封闭重选，否则要地在持续压迫下失去可用性。

贴地渗透有自己独立的地理：山谷口、桥隧、城镇街巷以及雷达站、指挥所、弹药库外围30米以下那一层。地物遮挡把探测余量压到接近零，小反射面与弱红外特征使目标沉在杂波里，惯导加视觉自主航路又让干扰失去作用对象，要害周边近地层于是成了一条可自由穿行、可反复消耗的通道。伞骨撑网拦阻飞艇不追目标，只封走廊截面，窗口在敌突入前的最后数百米至一千米以及其被迫清扫、改航、再规划的数分钟到数小时；主体是前出布设与值守的班组，全程不开机、不出弹、不占火力通道。约束是必须提前依地形、建筑净空与低云底高判出必飞航段，风速、覆冰不得超出系留极限；对无固定航路的漫散渗透和高速弹药类目标，这一层不成立。

最险的一段时间属于开战初段：敌先以电子压制致盲搜索雷达，用反辐射与防区外火力搜捕任何开机辐射的阵地，再断链打掉指挥所，同时让巡飞弹、小型无人机和直升机沿山谷隘口在雨雾夜暗中贴地穿入。要地防空此时雷达不敢开、链路接不通、火力发不出，真空从几十分钟持续为数小时，防线中间空出一段无人负责的渗透航路。「山听」无源截杀拦截弹的边界由此而定：它必须战前埋进那条航路，不辐射、不联网，按预先划定的责任空域与授权自主值守，射界通视与航路已知是前提，强背景噪声和高红外背景下压住虚警是上限。失效后果不是拦截概率下降，而是降级条件下这段保底火力是否存在。

最后一个场景的难点不在距离而在方位：野战指挥所、炮兵阵地、机场与装备集结点这类半固定目标，会在数十秒内同时受到数个方位、数个高度层的廉价无人机、巡飞弹和末段机动精确弹药压迫。只要同时到达数略多于可用制导通道数就形成漏防，而通道在发射那一刻已被固定，重新识别与重新指派所花的时间正被第二波吃掉。自组补射协同拦截弹群把火力分配从发射前挪到航中：平台只装定拦截扇区、飞行禁区与协同规则即可收束辐射并转移，弹间链路必须在定向阻塞下维持时统与信息移交，自主重分配不得越出有人指挥授权。链路被压断或来袭总数超出弹群容限时，群内冗余耗尽并触发上报，需二次齐射或邻群接防才能补齐该方向。

七个场景的断点分别落在群航迹装订、风场与危害区许可、供能与热管理、预置展开时效、走廊研判与系留气象、链路降级下的自主判敌、弹间链路容限，不存在可通用的单一战场条件；把它们并写成一套统一背景，会直接掩盖各件装备的真实成立边界。
