## 第二层：技术攻关层——能力实现途径与核心技术

### ⑤ 核心技术清单与攻关优先级

筛选标准只有一条：某项技术不突破，该件装备的战果结算方式就不成立。因此下表不列通用目标识别、组网数据链、轻质材料等"改进好坏"的技术，只列"决定有无"的断点。

| 核心技术断点 | 所属装备与作用环节 | 物理或工程约束 | 成熟基础与瓶颈 | 攻关优先级 |
|---|---|---|---|---|
| 弹载磁通压缩脉冲能量链 | 磁通压缩脉冲微波拦截弹；弹道末端数十米处的单次释放 | 储能受弹径与起飞质量限制，须在亚微秒内聚束为吉瓦级脉冲；毫秒级储能与纳秒级同步互相拉扯；电枢与衬套接触状态、等离子体形成决定真正到达辐射源的脉宽与峰值；火箭过载与振动下起爆须保持对称 | 磁通压缩在电磁成形与地面强脉冲装置上有工程积累，均为台式或地面系统；弹载小型化、发次一致性、储能—脉冲形成—辐射源的阻抗连续无公开装填验证。失手即退化为不可控的单点干扰 | P0 |
| 群航迹密度解算与起爆距离门控 | 磁通压缩脉冲微波拦截弹；近程雷达装订到弹上比对 | 须在一个扫描周期内从混叠航迹中给出群体质心、接近速度与预计释放点；地物杂波压低更新率；释放点偏差直接摊薄耦合场强，错过即终止该发 | 群目标检测与多航迹关联有现役雷达基础；面向"一次罩住多机"的密度门槛判据、免波束照射条件下的弹载测距比对属新增 | P0 |
| 近距宽视场辐射与弹体自保护 | 磁通压缩脉冲微波拦截弹；天线与引控舱 | 天线口径受弹径约束只能展宽波束，展宽即摊薄功率密度，只能在波束形状、脉宽与起爆距离间取解；释放脉冲反噬弹上装订与引信电路 | 宽视场微波天线与时间隔离、屏蔽有器件级基础；与起爆几何联合取解无公开设计准则 | P1 |
| 碳长丝的低冲击约束储运与起爆展开成型 | 碳长丝缠翼近程拦截弹；战斗部起爆至带内丝密度建立 | 单根丝须跨越旋翼旋转平面：过长储运打结，过短灌入桨毂卡不死转子；爆轰会拉断并烧蚀丝体，须在毫秒级过载后保持连续、均匀散开，再维持数秒至十余秒不塌散 | 高强碳纤维与柔性装填有工业基础，但破片战斗部的抛撒逻辑不可迁移；低冲击分散装药配合丝束预成型骨架无同类公开记录。配套瓶颈是把点触发引信改为沿航迹的窗口段输出，并与实测风场飘移耦合 | P1 |
| 连续光纤远场亮度保持与电热闭环 | 「灼羽」低空激光歼击炮；一至两公里驻照累积剂量 | 远场功率密度正比于功率、反比于光斑面积；单纯堆功率激发模不稳定与热透镜，湍流与热晕使光斑扩张抖动；电光转换之外的能量全部变成废热，热负荷又加热防护窗口、进一步恶化束质 | 高功率光纤激光、光束合成与自适应光学有装备化基础；合成孔径下的模不稳定抑制门槛、炮座一体化两相冷却与储能缓冲的持续交战闭环是缺口。两项任缺其一，"只耗电不耗弹"兑现为不了歼灭 | P1 |
| 千元级单元的无源末端寻的与齐射去冲突 | 千枚廉价撞杀巡飞弹；出箱后无火控指示的发现、认领、撞击 | 数瓦功耗预算内用宽视场无冷却红外或事件相机，在低空杂波中捕获反射面积与红外特征都极小、闭合速度上百米每秒的目标；千枚友邻同域须自行散开避让、不重复认领；单价低于来袭单元是硬条件，器件成本与抗干扰余量互相挤压 | 非制冷红外机芯、事件相机、汽车级器件与弹射起飞具备供应链；去中心认领规则、免标定装配与长贮存即用、批次一致性无公开批产验证。虚警漏检直接换算成碰撞概率 | P1 |
| 伞骨张紧网幕与系留站位的抗冲复位 | 伞骨撑网拦阻飞艇；走廊截面的形成与保持 | 网幕须折叠小、数秒展开并建立周向预应力；伞骨要轻到可被小型浮体吊起又在阵风与撞击瞬间不失稳，金属骨架还会在桨叶拍击中割断网线；撞击动量沿系留索传向绞车，风漂、覆冰、湿重把网推离必飞高度带 | 系留浮空器、绞车收放与高强纤维网幕有工程基础；刚柔混合伞骨、同心松套网兜的分级破损吸能属新设计，班组数分钟补位的作业组织未经演练检验 | P2 |
| 微瓦级常驻声纹—红外双模判敌 | 「山听」无源截杀拦截弹；静默值守下的发现、判敌、起射 | 数月值守只允许微瓦级常驻功耗；山谷风噪、溪流与公路背景淹没旋翼声纹，小基线阵列测向误差随多路径剧烈抖动；红外在雨雾夜暗作用距离骤降；出筒即大离轴、高角速度，单目成像给不出稳定距离 | 声学阵列、事件驱动低功耗处理、红外成像与冷发射各自有基础；两模交叉确认后才唤醒制导链的闭环，以及埋设阵地长期无人复核下的虚警压制无试验结论，多目标杂波中的测向精度属未知项 | P2 |
| 弹间量测级移交与共时统 | 自组补射协同拦截弹群；末制导段丢标后的邻弹补杀 | 低空多径与地杂波使链路时断时续，弹间高速相对运动造成多普勒快变与拓扑撕裂，弹径限制孔径、算力与供电；移交内容须是目标运动状态与预测截获点而非原始图像，时统不一致时外推误差随距离迅速放大 | 协同数据链与分布式火力分配有仿真与缩比试验积累；异构导引头之间的捕获扇区换算、以捕获概率为代价的补位航路生成缺公开闭环验证 | P2 |

排序理由按对战果的作用性质分档，而不是按技术热度。两项 P0 同属一件装备且共享一条时间轴：能量链决定这一发有没有足以烧毁加固器件的场强，门控解算决定这发能不能把脉冲放进群体视场中心，任何一项缺席，"一发换一批"的结算单位就退回逐发命中，装备身份随之消失，故须并行推进并在同一地面试验台上联合验证。四项 P1 决定的是成本交换比能否压到敌廉价机体所在的量级：丝束展开成型与窗口段引信决定一次起爆能否覆盖整批；激光的亮度保持与热闭环决定同一阵地可连续付出的架次数；千元级寻的与去冲突决定拦阻层单价是否低于来袭单元。三项 P2 改变的是能力边界与降级条件下的可用性——网幕的张紧复位决定防线厚度能否等于浮体数量，无源双模判敌决定被压制防线是否残留火力段，弹间移交决定通道数能否在空中重排。它们不成立时其余装备仍可各自出战果，因此排在断点闭合之后。

不作为断点列出的方向同样需要说明：目标识别算法、抗干扰编码、宽带数据链、复合材料与通用光电传感器，都只改变单件装备性能幅度的大小，不改变任何一件装备"战果按架次还是按批次、按剂量还是按命中"的结算方式，且可沿用现役改进路径。全部九行的"成熟基础"仅指原理与地面、工业环节成立，七件装备均无公开的装填、靶试或部署记录，表中约束一律取量级与因果关系，不得转化为确定性点值指标。对手的反适应已在时间上给能量链与束亮度加了约束：器件级屏蔽滤波、电源隔离与看门狗硬复位，以及旋翼导流罩、涵道化与切丝环，都可在数月内以低成本铺开，因此场强与剂量储备必须按高于对手加固进度的速率设定，单元单价一致性与网衣在背景中的低可视性也须与主毁伤链同批验收，不能作为后续优化项。
