## 第三层：能力图像与效能贡献层

### ⑦ 装备能力图像

传统低空防空的战果结算单位是"一发对一个目标"：可用火力通道数在开火瞬间被固定，待发弹药基数决定能抗击第几波次。下列装备能够放进同一张能力图像，不是因为它们都"更强"，而是各自从不同的物理界面上改写这个结算单位——电子器件的击穿阈值、旋翼转子的几何咬入、复合材料蒙皮的热剂量、给定空域内的遭遇概率、桨盘与网衣的接触、以及"开火必须辐射"这一暴露前提。界面不同，增量、基线和失效方式也就不同，因此按装备分行比较，不设公共抽象节点。

| 装备 | 相对现役谱系的能力增量 | 被改写的现役基线及其上限 | 成立边界 | 证据状态 |
|---|---|---|---|---|
| 磁通压缩脉冲微波拦截弹 | 战果由逐发命中改为一次脉冲覆盖一片飞控与引航电路，且失效不可复位，交战次数只随批次数增长 | 近程防空导弹与高炮"一通道一目标"，通道数即同一时刻可拦目标数；廉价干扰只造成可复飞的失联 | 需近程雷达在汇聚段稳定装订群航迹并解算释放点，在数十米内拿到足够场强；对已疏开单目标、远距离目标与高速加固巡航类目标不经济 | 假设级。无公开对应型号与试验记录，吉瓦级瞬时功率与纳秒级同步只说明机理自洽，不可换算为覆盖架数 |
| 碳长丝缠翼近程拦截弹 | 毁伤对象从机体移到转子，靠几何咬入而非能量传递，加厚与加固不换取生存率；一次起爆在数十秒内占据一段来袭航路 | 破片与命中式近程弹每发只服务一架机；定向能需对每架机持续照射，破片弹在城市与机场上空事实上不可用 | 只对旋翼与螺旋桨类低速目标成立；依赖可测风场与足够早的批次粗航迹，强侧风、异高多路进近时覆盖收窄，近距起爆压缩预警与引信时序 | 概念级。起爆时不拉断长丝、丝密度维持时长均未验证，属工程未闭合项，不按已具备能力陈述 |
| 「灼羽」低空激光歼击炮 | 把稀缺资源从弹药基数换成电功率与热管理余量，可在两公里内按部位选择性毁伤（先致盲导引头窗口，再烧穿升力面），且毁伤过程有剂量可读 | 高炮火力上限由待发弹决定，指挥员被迫以省弹方式选射，第三、四批即出现火力空窗；每发都在削减不可再生基数 | 受通视、仰角与遮挡限制，不追求全向覆盖；高湿、雨雾、低云与强湍流显著削减可注入剂量，此时通道降级为指示告警 | 推断级。连续波光纤激光对靶面热剂量毁伤为公开可证方向，国外舰载激光有命中无人机靶标的演示先例；本单位功率、束质与散热门槛无公开数值 |
| 千枚廉价撞杀巡飞弹 | 同一空域内可同时交战的数目不再受通道与再装填限制，指挥对象由单次射击变为可撞密度这一连续量 | 发射平台的通道分配与装填节奏构成刚性瓶颈，波次间隔的数十秒到数分钟恰是漏防窗口 | 须战前完成预置展开并划分密度区；单元须在无卫星、无可靠数据链下自主寻的；不承担巡航导弹与有人机，主辐射源仍可保持静默 | 假设级。千元级无源末制导与千枚级空中去冲突均无公开装备实证；若这两项不突破，它只是密集的自杀无人机群而非拦阻层 |
| 伞骨撑网拦阻飞艇 | 把拦截从一次事件变成场地属性：不探测、不跟踪、不射击即持续生效，防线厚度按浮体数量而非弹药基数计 | 贴地杂波层是无人负责的空白段，火控的最小航速与最小距离门限使高炮与近程弹打不到贴地慢目标 | 只对有必飞走廊的旋翼与螺旋桨目标成立；网幕须恰好占住贴地高度带，受地形、净空、空域管制与超限气象约束，无固定航路的广域漫散渗透不成立 | 概念级。缠绕致桨叶损毁的力学后果确定，但伞骨张紧、受撞不失稳与快速补位作业无公开作战先例 |
| 「山听」无源截杀拦截弹 | 把"先暴露才能开火"换成"不开机也开火"，在被压制防线上保留一段不可远程清除的拦阻，链路恢复期不再出现防空真空 | 主动雷达须开机才能测向引导，一开机即被反辐射与防区外火力定位；指挥所断链后渗透航路无人负责 | 须预置在已知航路上并保持射界通视，只收不发；多目标与强风噪、高背景红外下的虚警压制决定能否放心授权自主开火 | 推断级。无源声学与红外告警有既有工程先例，声纹测向精度在山地多路径条件下为未知项，不设点值 |
| 自组补射协同拦截弹群 | 通道数由发射前一次性指派改为接敌过程中在航重排，失锁弹把截获信息交邻弹补杀，缺口可再生 | 弹与平台、弹与弹几乎不交换信息，一发末制导被干扰即成无效飞行，重新分配要付再装填与重照射的时间 | 弹间链路须在定向阻塞下保持低截获与秒级移交；剩余弹量覆盖不了新增密度时须上报冗余耗尽并转由末端近防承接 | 假设级。分布式协同制导属公开技术方向，拦截弹群在航补射无公开试验证据 |

行与行之间的联合只有三类有输入依据。近程雷达与火控是共同上游：群航迹装订喂给微波弹，粗航迹加窗口段解算喂给丝带弹，已解算航迹交接喂给激光炮，因此三者的战果上限同时受低空杂波中航迹连续性与更新率的约束，任一环节退化就同时退化。网幕与撞杀巡飞弹都不占射击通道、都不要求辐射，它们对来袭机的共同作用是把它抬进既有弹炮杀伤区，属于"边界让位"型配合而非信息共享型配合。「山听」既不消费也不提供链路，它与其余装备的唯一接口是撞网与截杀残骸回传的航线、编成与诱饵策略，只能事后修正布设与火力密度，不构成交战协同。把这三类关系写成一张统一调度的网，会同时高估感知冗余与授权速度。

对手的反适应路径同样不共享，这是横向比较的实际用处：面对微波弹，敌方要放弃密集同轴队形，代价是同时到达与任务协同；面对丝带弹，要改旋翼结构或前置扫带，代价是续航、载荷与一次性机体的提前消耗；面对激光炮，要挑气象窗口并放烟幕，代价是把攻击节奏交给天气；面对密度层与网幕，它只能转打地面箱体与系留点，代价是把最贵、最易暴露的侦察打击链路投进来；面对无源伏击，只能用目视与抵近清剿，代价是有人平台进谷。前三类削的是敌方的同时性与时机自主权，后两类把敌方的廉价优势转移到我方纵深目标的防护负担上，性质完全不同。

证据谱系也不对等，这决定比较能走多深：只有激光歼击炮既有公开演示先例、又有明确的高端拦截弹与廉价无人机成本交换失衡研究可依托，因此可以讨论指标方向；其余六件在公开材料中找不到对应型号或试验记录，其"一发一批""一爆一域"的表述只在机理成立的意义上有价值。可作事实使用的公共结论是一条：防空体系设计的主矛盾已是每单位预算能吸收多少架次来袭，而不是单发命中概率提高了多少。本图像可用于装备取舍的判据也就收敛为两点——是否真正改变战果结算单位，以及该单位的成立条件能否由现有感知、气象与保障接口提供。
