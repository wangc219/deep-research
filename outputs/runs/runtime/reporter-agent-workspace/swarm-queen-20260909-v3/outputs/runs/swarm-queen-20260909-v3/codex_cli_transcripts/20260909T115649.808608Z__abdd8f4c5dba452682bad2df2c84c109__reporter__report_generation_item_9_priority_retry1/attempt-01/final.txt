## 第三层：能力图像与效能贡献层

### ⑨ 发展优先级与近期抓手

排序只用两条轴：一是该装备是否直接切断"廉价批量挤占通道—耗光基数—后波次突入"这条主因果；二是它能否在现有火力链路上找到插入点，而不必等一整套新保障体系成型。两轴同时占优者靠前，只占一条者降为补充层。

**P0｜磁通压缩脉冲微波拦截弹。** 它是本组中唯一让敌方进攻算法本身失效的选项：饱和突防要求机群在汇聚走廊内保持密度与同时到达，而这恰好是微波面毁伤最好的几何条件；敌方为规避只能拆小批次、拉大间距，其协同突击本可获得的时间红利在到达之前就被消耗掉。列为最高优先并非因为技术成熟，而是它改写的交战关系无法用现役装备的任何改进替代。近期抓手集中在两处而非整弹：把群航迹密度、质心与起爆点解算做进近程雷达和火控的数据格式，形成能在现有站型上跑通的装订—距离门控链路；功率源侧先在车载或地基台架上验证压缩对称性、纳秒级触发抖动与数十米处的场强储备，越过加固器件阈值后才允许上弹。它的对手反适应也最便宜——器件级屏蔽、滤波与硬复位，因此场强余量和群目标解算速率是需要长期保持的条件，而不是验收一次即可的指标。

**P1｜碳长丝缠翼近程拦截弹。** 排在其后，因为它解决的是同一断点的末端一段：一到三千米、百米以下的旋翼类低慢小，在机场、城市与油气管线上空本来就不敢使用破片弹。丝带被转子咬入靠几何关系起效，加厚机体与结构加固换不到生存率，敌方第一层耗弹思路在此失去着力点；碳质同时导电，把机械卡死升级为绕组短路，这是它区别于一般抛撒绳索的实质理由。近期抓手是借用现成火力单元：以现役近程弹与高炮的引控接口换装丝束战斗部，把近炸引信的单点触发改为沿航迹输出的起爆窗口，并将风向风速、飘移预估与下方己方旋翼活动纳入射击许可判定。技术判定应收窄到两点——起爆加载下丝束是否被拉断烧断、带内丝密度能否维持数秒至十余秒；涵道化、外倾小桨与高速固定翼属明确的效率下降区，不必按全目标类别验收。

**P1｜「灼羽」低空激光歼击炮。** 它把交战的消耗物从弹丸换成电能，同一炮位不存在"打光"状态，末端火力由配额变成存量，这是对补给与再装填节奏的直接解放。放在第二档而非最高，是因为它一次只处理一条已解算航迹，不解决同时到达的数量问题，且其可用射程本质上是可驻留时间与远场可维持功率密度的乘积，雨雾、高湿与强湍流会把注入剂量压到阈值之下。近期抓手是把稀缺资源换掉：底盘侧解决供电、储能缓冲与两相冷却的持续输出，光路侧把自适应光学与预测跟踪并成一个闭环，编配规则上为其配光电与近程雷达的多视角接力，使被烟幕遮挡的目标由另一方向接管照射。

**P2｜伞骨撑网拦阻飞艇 与 千枚廉价撞杀巡飞弹。** 两者都以预置数量替代射击次数，但落地速度相反。撑网飞艇不占传感器、不耗弹药、不需要链路，只要研判出敌方贴地渗透的必飞走廊即可设障，撞网与否由几何相交决定，是本轮中最快能成建制形成拒止的一项；其近期抓手在工程而不在原理：伞骨在阵风与撞击瞬间不失稳、网衣不被桨叶割断、受冲动量沿系留缆传入地面绞车后能自动复位，以及班组在数分钟内完成孔洞补位。撞杀巡飞弹的因果同样成立——密度层使敌方诱饵只能消耗可丢弃的廉价弹体——但成立前提尚未闭合：千元级单元要在无卫星、无可靠数据链条件下完成弱小目标末端捕获，千枚级出箱后还要自行散开、互不相撞且不重复认领同一目标。近期只做数十枚级密度窗的遭遇概率与贮存即用性验证，不先铺"千枚"产能线。

**P2｜「山听」无源截杀拦截弹。** 它不参与正面消耗，价值落在最危险的那几十分钟：雷达不敢开、链路接不通、指挥所被压制时，防线上仍留有一段无法远程清除的火力。不排更高的原因很直接：它只能覆盖已知航路并要求射界通视，多目标杂波下的无源测向精度目前给不出可信数值，只能按区间看待。近期抓手是埋设授权规则与双模判敌的虚警控制——声纹阵列先给出方位、红外成像交叉确认后才允许自主起射，且"阵地不外泄电磁足迹"这一条须由实测而非设计说明背书。

**P3｜自组补射协同拦截弹群。** 它对应升级功能需求中最核心也最靠后的一项：把同时交战数从发射前固定的通道数，改为在航中按来袭密度重排。排到最后是因为它对弹间链路的要求与对手最省力的反制撞在同一处——定向阻塞弹间频段即可使弹群退回孤立单发，继续放大批量则能耗尽群内冗余。近期抓手只做两件事：丢标弹向邻弹移交的是可用于捕获的量测与预测截获点而非原始图像；把"冗余耗尽"做成一个可上报的指挥信号，使上层知道何时投入二次火力或由相邻单元接防。

收束时只保留两件事。判据上看两个可观测结果：同一时间窗内能一次处理的来袭批次数是否上升，拒止维持时间是否已与弹药消耗脱钩。取舍上看生态位：微波弹与丝束弹争夺的是同一个"一次对一批"位置，不必同等强度推进——前者赌毁伤面与不可复位，后者赌工程可及与即刻可装；激光歼击炮、密度层与无源伏击段都属于把贵值弹药从廉价机体上卸载的卸载手段，其建设节奏应跟在近程雷达群航迹装订与低空危害区管制这一条接口之后，而不是各自另起一条链路。
