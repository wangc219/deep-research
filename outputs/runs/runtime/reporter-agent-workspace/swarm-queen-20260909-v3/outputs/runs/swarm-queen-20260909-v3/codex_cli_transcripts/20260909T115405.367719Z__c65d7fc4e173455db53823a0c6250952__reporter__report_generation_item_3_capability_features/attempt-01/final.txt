**第一层：需求挖掘层——场景·战法/技术·装备能力特征**

**③ 装备能力特征清单**

- **磁通压缩脉冲微波拦截弹**：任务断点是敌微型无人机与巡飞弹沿少数汇聚走廊同轴密集进入，火力通道先于弹药耗尽，而廉价压制对惯导与图像末制导的目标只造成可复飞的失联。它需要的能力不是更高的单发命中概率，而是在群体尚未散开的走廊前段一次交付不可复位的电子毁伤，即"覆盖面"与"飞抵确定性"的乘积。有判别力的指标方向为：一次释放能同时致能的机数，该数值随群目标密度、耦合距离、波束形状与目标电路加固水平共同变化；触发时序抖动与起爆点相对装订几何的偏差是否小到不至于把脉冲打在群体边缘；火箭段过载与振动下压缩过程中的能量流失幅度。工况必须绑定走廊密度、加固等级、航迹连续性与毁伤锥内友军约束，不适用逐发拦截口径。
- **碳长丝缠翼近程拦截弹**：断点在末端几十至几百米——破片弹在机场上空、城市与管线上方因坠落飞溅危害实际不可用，而断链自主进近的旋翼目标又不吃干扰。能力要求是占据一条来袭航路而不是击中某架机。判据方向为：起爆后丝雾带在给定风速、风向、湿度与温度下维持有效拦截截面的时长与飘移散布；单根丝的长度与细度对不同桨盘直径、不同转速旋翼的缠入成功率与电机短路转化率；对涵道化、外倾旋翼和高速小桨的效率衰减曲线。它不引入制导精度指标，反而要求火控输出沿航迹的连续起爆窗口段并接入危害区与禁布区判定，作战量度是禁区可维持时间而非单发杀伤概率。
- **「灼羽」低空激光歼击炮**：断点是敌方"消耗—饱和—再突入"的三段式赌法，赌的是装填节奏与弹基数会先于毁伤能力枯竭。所需能力是把末端火力从配额变成可长期值守的存量，并能对部位选择性作用。判据方向为：抵达靶面的功率密度与实际驻照时间之积相对复合材料蒙皮热解分层阈值、光电窗口镀层损伤阈值的余量，该余量随大气透过率、热晕与湍流引起的光斑漂移、目标桨叶转速和横向机动而分档；同一阵位的连续交战架次与换靶间隔取决于供电可用度和热回路恢复到可交战状态的节拍。这套判据与载弹数、散布带无关，雨雾高湿与照射通道被压制时应作为强制工况保留。
- **千枚廉价撞杀巡飞弹**：断点是波次间隔内既来不及再装填也来不及重建通道分配，这段空窗正是突防发生的时段。能力要求是受袭前预置、出箱后不靠雷达开机与火控点名就能自行接敌的密度场。判据方向为：齐射后单元自组织散开成层的时间与互撞、重复认领同一目标的比例；在无卫星、无可靠数据链条件下，被动末制导于低空杂波中捕获微弱的红外与雷达反射特征所需的截获距离与虚警率；单元单价相对来袭单元单价的比值——比值不落入同一数量级以下，密度优势在经济上不成立。考核量是可持续承接的波次数与以箱为单位的补网节拍。
- **伞骨撑网拦阻飞艇**：断点是三五十米以下贴地走廊里，探测余量被地物杂波压平、火控的最小航速与最小距离门限又使高炮和近程导弹打不到，这段近地层事实上无人负责。能力要求是无需任何信息交换即持续占位，把走廊截面变成确定的碰撞几何。判据方向为：单具浮体在浮力与自重上限内能撑出的有效拦阻截面积与自身投影之比；网衣被桨盘入流吞入后的缠死概率与被拍击割断概率；风切变、覆冰、湿重使网幕偏离必飞高度带的漂移量及自动复位时间；出现孔洞后班组补位所需人数与节拍。核心量度是被封闭截面积与浮体数量的换算关系和允许容损度，而非拦截次数。
- **「山听」无源截杀拦截弹**：断点是开战初段雷达不敢开、链路接不通、防区外火力按辐射源点名的几十分钟到几小时真空。能力要求是在长期静默与完全降级条件下自主判敌并出杀伤。判据方向为：山谷风噪、溪流与公路背景声中对旋翼声纹的测向误差与多目标可分辨性；红外成像在雨雾夜暗中的判敌距离及其骤降规律；数月值守允许的整机功耗与阵地自身电磁足迹上界；虚警率与拦截授权门槛的耦合关系。这些判据以射界通视和预置已知渗透航路为前提，多目标杂波下的测向精度仍是未定项，不能用平均拦截概率单独衡量。
- **自组补射协同拦截弹群**：断点是通道数在开火瞬间被冻结、一发失锁即成无效飞行，缺的实质是重新分配火力的时间。能力要求是把目标分配从发射前一次性排定改为在航中可重排、失效可再生。判据方向为：齐射后建链收敛时间，以及低空多径、地杂波与弹间高速相对运动造成的链路可用度；主拦弹失锁到邻弹完成量测级交接并重新捕获的时延及其随距离放大的外推误差；冗余耗尽告警的准确性——上层据此决定是否二次齐射或邻区接防；弹间链路被定向阻塞后退化为独立单发时的战果保留率。考核口径为漏射率与扇区连续性，来袭总数超出弹群容限时仍会被穿透。

上述判据不共用指标组，且大多受制于外部条件：微波弹与协同弹群依赖近程雷达的群航迹装订与在航信息交接，缠翼弹依赖可测风场与空域管制，激光炮依赖供电散热与目标指示链路，飞艇与无源弹只依赖地形研判和预置授权。现有材料未给出任何一件的实测基线，也无公开数据可裁决"低成本硬拦截与定向能足以构成主解"与"压制类手段不可验证、硬杀伤需求不可削减"这两种相互冲突的判断，因此各装备的场强余量、丝带时长、截面积换算、截获距离与建链时延等量值一律保留为待校核变量，只固化其随工况变化的方向。
