## 二、项目画像

### （二）作战运用模式

#### 1. 作战运用流程

各装备的进入条件不再以通信畅通、雷达在环为前提，流程长短按其各自改写的交战规则取舍。

蜃楼抱弹诱撞无人机（P1）的窗口由敌开机制成。自陆基装置或蜂群母机在敌拦截火力轴外侧投放，装订只冒充长机与巡飞弹，投放即脱离指挥关系；以同源辐射节拍反复露头，逼敌传感器由广域搜索转为定向跟踪。唯一转入杀伤的门槛是判咬合——机载解算逼近率、敌照射截获特征与来袭弹药方向，确认后开保险俯冲，先撞咬尾的拦截弹或捕手机，其次下压发射阵位。敌开机丢弹药与阵地，关机丢监视与预警时间；敌若仅以无源跟随，则不追打，脱离另选火力轴。

伞骨张环拦截无人机（P2）值守即交战，不走告警—分配—交火。折叠伞骨弹射盘踞通道入口，不通链、不辐射，只开被动光电，值班授权仅放行与禁射区两级。目标进入可稳定测向距离且航线与弹射包线相交即成窗：按碰撞律冲入，末段只修几何不修语义，数米量级上张成刚性笼环，同时锁死旋翼与弹体并与之共压向指定空旷区，把坠落能量移出通道上方；其余值守机独立交战，多轴接近不争夺火力与频率。超包线或须横越禁射区即拒打复位，交末端火炮与软杀伤。

雾瞳蔽光巡飞攻击弹（P3）不抢先突防，先造一段看不见。前沿指挥所预授权下令，友邻无源探测框定拦截车与观瞄的方位走廊，按通视关系与风场选定必须遮断的视线体积，沿敌观测盲区连续抛洒超细冷水与吸波微粒成幕，本弹留在幕缘之外以免自致盲。通道能否用不看幕体是否可见，只看敌是否失去连续观测——是否开机辐射、前出暴露或被迫改阵。幕内静默前滑，敌车尚能机动时不起爆，末段确认轮廓后炸掉仍在提供观测的节点；幕体提前消散或遮蔽不足一个俯冲周期即侧向脱离。

倒悬坠袭伏击无人机（P5）流程重心在战前，廊道选定是成败主要杠杆。据城市地形与敌可能航线挑出必经或明显省时的遮蔽段，在夜间或维保掩护下把节点倒悬吸附于桥下、涵洞顶与棚架下表面，自判风载、雨水、桥面振动与温差下的保持余量，不合格即退设；此后仅以低占空比维持无源声学监听。目标进入结构正下方数秒内，从桥面交通、风雨与伸缩缝背景中按桨叶通过频率分离旋翼特征，依战前批准的类别、走廊、时段与禁射条件本地放行并脱附向上撞击，链路中断仍按同一规则执行。

无影猎群拦截无人机（P6）接敌由敌供能。进入伏击空域即关全部发射机，机间以高稳定时频基准建多基线阵，从敌上行遥控与下行图传混合信号中按频点驻留、帧结构与方位稳定度分选真实机体、剔除地面站与诱骗源，将辐射与航迹绑定并联合解算出可用于火力的位置与速度，群内目标由一片杂波转为可编号序列；按距离、收敛角与是否挂载排序后侧向插入，末段被动成像修正、不开测距雷达，在相对速度最高处起爆并立即回扫，判断敌编队收敛是否被阻断。全程无己方辐射开关节点。

崖影穿谷攻击无人机（P4）以地形换隐蔽：起飞即沉入山谷、崖壁与城市峡谷的雷达杂波带，靠预置地形影像与光学自主导航穿谷机动，不开数据链，通视瞬间俯冲敌低空雷达站、光电警戒点与前沿指挥节点，功率压制与导航欺骗不改变其接敌几何。无药坠杆低成本攻击无人机（P7）以数量换时机：运输级平台在敌近防射程外批量投放，装订近期影像基准、目标特征与禁打清单后无动力滑翔待机，未出现开盖、装筒、起桅或车辆活动则继续降高或转下一预定区，锁定后近垂直入射把钨钢杆砸入筒体与观瞄窗，撞地无爆炸残留，同批剩余机体继续悬置。

#### 2. 链路闭环分析

体系缺口位于闭环后段：断链或拒止条件下需要不复用同一条受扰数据链、也不复用同一片被拒止空域传感的效果判定与再分配能力。公开研究把指挥链首要缺口判在效果可判定性与跨单元再分配（`GAO-25-106454` 的 OF-1，与场景侧结论独立收敛），另有分析把末段导引列为首位；两序并存时，前者抬高不回链自闭合类装备的收益，后者抬高遮蔽与杂波类装备的收益。

闭合方式分三种。本机自闭合：蜃楼、倒悬、崖影与无药坠杆的判定与起爆全在机载完成，没有可供压制的通信接点，代价是敌我判据、禁打清单与目标装订必须战前有效，装订质量即安全边界。几何闭合：伞骨只对碰撞律求解、不读电磁语义，诱饵在几何上无法冒充真实碰撞点；无影猎群把感知成本转嫁给敌维持人工闭环与实时图传的需要，敌关链即放弃本次攻击收益，开链即被定位。观测断口闭合：雾瞳截出敌传感器与其火力单元之间的断视窗口，成立受风场与幕体生灭节律约束，仅在预设航段有效。

不回传时战果改以替代量计量：敌行为（拦截弹发射量、阵位开机时长与转移次数）、坠地坐标反推的来袭航路、友邻无源侦察。蜃楼撞后敌开机规律与阵位随同型机回传，下一波巡飞弹与远程火力据此穿入；伞骨省下的远程弹与近防火力转用于敌第二波与有人平台，值守点得以前推；无药坠杆首轮毁伤把敌疏散路线交给远程火力覆盖。这些交接只按已写明的信息回传与火力让渡关系成立，不推定统一数据接口。

闭环失效点集中在敌改打法而非打得更准：减少开机、转无源与光电值守、以高炮网捕拦撞替代导弹，使一次咬合换一枚拦截弹的算术作废；超量同时到达与大俯冲角把交会推出张环包线；异谱备份观测交叉跟踪并对幕后盲射；先遣廉价机体清扫顶面或改在廊道外超距投放；主力转入全自主关链、以持续辐射陪衬体吸引截击。雨雾夜暗下被动光电的发现距离、实测风场中幕体的滞留时间、无源定位能否达到火控级三项工况缺证，链路闭合的定量结论须保留区间。
