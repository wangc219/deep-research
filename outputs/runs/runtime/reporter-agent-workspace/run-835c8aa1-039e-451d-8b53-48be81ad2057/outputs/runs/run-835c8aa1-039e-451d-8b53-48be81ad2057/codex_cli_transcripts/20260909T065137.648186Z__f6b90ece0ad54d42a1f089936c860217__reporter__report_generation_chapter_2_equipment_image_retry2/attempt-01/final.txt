**二、项目画像**

**（一）装备图像概述**

| 装备 | 核心技术与形成能力 | 部署与进入方式 | 关键动作、作用对象与直接效果 |
|---|---|---|---|
| 蜃楼抱弹诱撞无人机 | 蒙皮共形散射调控层、射频模拟源与热辐射源联合布设，使雷达、红外、光电三谱在同一飞行状态下彼此吻合，并以无源层承担主反射、有源只补盲来给耗电源让出功率；配无链路终点自主判定与碰炸起爆。新增的不是更亮的假目标，而是断链后仍能闭合的杀伤路径 | 陆基装置或蜂群母机在敌拦截火力轴外侧投放，任务规划员按敌辐射源分布装订航路与触发判据，投放即脱离指挥关系，全程不接收指令、不回传 | 以己方长机和主力巡飞弹的辐射节拍沿敌主要进近轴反复露头，机载无源定向与成像解算逼近率、敌照射与截获特征，判定被敌高价值拦截资源咬住后开战斗部保险俯冲，优先撞咬尾拦截弹或捕手机，其次顺来袭方向下压其发射阵位。敌近程拦截弹、值守操作员与发射平台一并折损，拦截通道出现补不上的实体缺口，敌被迫减少开机、低空监视节奏中断，后续蜂群与巡飞弹利用空窗穿入；未咬住则继续露头、能量耗尽前就地沉默，绝不打断伪装。反制风险是敌转为选择性不打并改用高炮、网捕等廉价近程火力，使一次咬合换一枚拦截弹的算术作废 |
| 伞骨张环拦截无人机 | 机首伞骨在撞入前数十毫秒张满并锁成刚性承力框，靠高储能比张紧机构、自锁关节与变截面传力路径同时约束旋翼与带惯性的弹体；无辐射无链路条件下以成像测向反推距离，把角度、接近率与张环时刻收敛进弹射时序 | 折叠伞骨状态弹射值守在己方低空通道入口，不通链、不开辐射源，仅被动光电开机；值班授权只设放行与禁射区两级，捕获由机载自主闭合 | 敌群任一目标进入可稳定测向距离且航线与本机弹射包线相交即弹射，按碰撞律冲入敌航线，末段只修正几何不修正语义，张环锁死后与被捕获体共同压向指定空旷区，把坠落能量与残骸移出通道上方。单次拦截成本降到与敌机同量级，干扰、导航接管与诱饵全部失去受力对象，敌断链自主突防的密集批次在末段前被逐个摘出航线，我方低空资产无须停飞自卫，远程弹与近防火力转用于第二波和有人平台。速度或迎角超出捕获窗口、需横越禁射区时拒打复位。边界是现有材料只支撑视光明亮条件下的近距单目标捕获，雨雾、沙尘与强逆光压缩发现距离 |
| 雾瞳蔽光巡飞攻击弹 | 水滴与吸波微粒的配比、粒径谱和抗凝聚表面处理联合设计，配弹尾环形定流量喷口连续播撒，使幕体同时压住可见近红外、中远红外与毫米波而非单谱段压制；气雾配方对自机工作窗口选择性透过，配无源图像匹配与地形基准实现幕下末段制导 | 前沿指挥所在预授权封锁段内下令，先由友邻无源探测框定拦截发射车与观瞄阵地的方位走廊，再沿敌观测盲区进入接敌航路，本弹自身保持在幕体边缘之外避免自致盲 | 接敌前航段连续吐出可滞留数分钟的无源遮蔽幕，敌光电红外在幕前致盲、测距失准，电子战手段找不到作用对象，只能开机盲射或后撤重占阵地，预警到拦截的循环被打断；本弹幕内静默前滑，敌发射车仍具机动能力时不提前起爆，末段确认目标轮廓后炸毁拦截车与观瞄，把看不见的通道固化为打不掉的空缺，后续波次沿同一通道低代价穿越。风场使幕体提前消散或敌已转移则拒打侧向脱离。反制是敌预置异谱异体制备份观测形成交叉跟踪，或按预先存取坐标对幕后盲射，把攻击方逼入固定通道 |
| 崖影穿谷攻击无人机 | 预置地形影像与光学自主导航支撑穿谷机动，使航路始终贴在敌雷达无法与地物分辨的回波层内 | 起飞后即沉入敌预警盲区，全程不越出地面杂波层、不开数据链 | 通视目标瞬间俯冲打击敌低空雷达站、光电警戒点与前沿指挥节点，把敌自认为安全的盲区后方变成被逐个清除的一侧。对以功率压制、导航欺骗和远程航迹监视构成的封锁，其接敌几何不随断链改变。该方向的可用记录只给出构型与突防方式，未给出杂波层可用离地高度下限、地形匹配在雨雾与夜间条件下的可用气象范围、末端命中判据与敌低空补盲手段，故其技术卡点与量化指标不足以在本栏落定 |
| 倒悬坠袭伏击无人机 | 可控静电吸附与仿刚毛柔性接触层复合，把持力做在法向、释放做在剪切，并在吸附模块与机体之间设机械解锁件，使脱附不必对抗自身持力；声学阵列按桨叶通过频率与谐波结构分离旋翼特征，加微动多普勒完成测向测高与航路外推，事件触发唤醒、判型与点火串成硬线击发链 | 工程小组在夜间或施工维保掩护下，经桥面检修口倒悬吸附于桥下、涵洞顶与棚架下表面，朝向预期来袭方向设定捕获视场，自检风载、雨水、车辆振动与温差循环下的保持余量，不合格即退设；随后以能量采集或低占空比电池纯接收待机，热特征与外形同顶板一致 | 敌机穿入结构正下方、上方净空被构件限制而横向难以脱离的数秒内，腹部脱附、微推向上撞击其顶面与旋翼。拦截方向由水平转为垂直，敌方的干扰、欺骗、航路机动与辐射源测向同时失去对象，一条被证实的击杀使整段遮蔽走廊失去可信度；敌抬高航域即重回我方雷达与拦截火力杀伤区，逐段排查顶面又须慢速悬停而替第二层伏击创造目标。特征仅达疑似或与风振鸟群混叠、己方有人机可能进入同一净空时拒打待机 |
| 无影猎群拦截无人机 | 以敌群与操作员之间固有的遥控上行和图传下行为照明源，机间以高稳定时频基准建立可干涉的多基线阵，在跳频与间歇低功率信号中按频点驻留、帧结构与方位稳定度分选真实机体辐射，解算到火控级而非告警级 | 单架或数架进入敌离开发射阵位、在中继与集结空域必须开链维持人工闭环的时段对应的伏击空域，关闭全部发射机仅保持接收，可静默待机数小时，遭反制时静默转场不留固定阵地 | 把每部机体辐射与其航迹绑定，使群内目标由一片杂波转为可编号序列，按距离、航向收敛角与是否挂载战斗部排序后规划提前量，末段只用被动成像修正、不开测距雷达，在侧向相对速度最高处起爆破片战斗部，随即回扫判断缺口是否已阻断敌编队收敛。直接结果是己方雷达完全关机、地面电子战资产被压制时仍能开火，截击线前推到敌末段俯冲之前的集结空域，饱和攻击在收敛前解体为不具同时性的零散来袭，要地雷达、指挥所与电子战站可长期静默而不失明。敌转入全自主关闭上行虽可躲过照明，却付出更贵导引头、可预测攻击轴与放弃中途改目标的代价 |
| 无药坠杆低成本攻击无人机 | 高密度钨钢杆件替代炸药战斗部，按铝合金机体、钢制发射筒与观瞄镜面建立分级侵彻判据并配冲击隔离解锁机构，靠近垂直入射角与终端速度砸穿而非弹跳；投影一致性匹配支撑无源图像末制导，识别置信度直接耦合进大攻角控制律 | 运输级平台在敌近防射程外批量投放，机体展翼无动力滑翔，沿目标区边缘缓慢降高长期悬置，投放段与待机段全程不开数据链、不进入敌火力覆盖范围 | 友邻无源侦察在纵深集结与再装填节点确认目标停放且与民用要素可分离后，降至匹配高度连续成像并与基准比对，出现开盖、装筒、起桅或车辆活动即大角度俯冲增速，把钨杆砸入筒体与观瞄窗，机体撞地坠毁且无爆炸残留，同批剩余机体继续待机不重复攻击。直接结果是敌无爆源、无指令辐射与近似背景的热特征可循，无法判定来袭是否结束，也不敢用拦截弹交换接近配重价格的弹体，被迫疏散停放、转入硬壳工事并拉长整备转场，出动波次之间被不定次数插入压迫。成立边界是目标处于地面静止或低速装填状态、区域基准影像未过期、识别置信度足以在无人工在环时不误伤 |
