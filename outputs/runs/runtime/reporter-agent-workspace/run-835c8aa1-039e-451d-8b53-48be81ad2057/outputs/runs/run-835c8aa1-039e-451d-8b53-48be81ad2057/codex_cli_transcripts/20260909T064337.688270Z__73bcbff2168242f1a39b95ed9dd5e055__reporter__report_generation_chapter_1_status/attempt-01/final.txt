1. 国外情况

美国国防部2024年12月公开的反无人机战略情况说明书（https://media.defense.gov/2024/Dec/05/2003599149/-1/-1/0/FACT-SHEET-STRATEGY-FOR-COUNTERING-UNMANNED-SYSTEMS.PDF）给出两条对装备判断有分量的信息：一是明确承认各类手段各有适用边界、不存在单一解，电子干扰一类软杀伤仍是其列为核心的效应手段；二是把目标鉴定与采办试验节奏列为长期未解决的问题。美海军陆战队《部队设计》公开材料把无人系统比重上升与防空、电子战、跨域火力一体化列为转型方向，说明其投入正从单装采购转向体系编配。美国政府问责局2025年报告 GAO-25-106454 给出的缺口位置更值得注意：任务链主要断点在闭环后段，即打击效果难以判定、跨单元重新分配在链路中断时无法进行，而不在末段导引或火力通道本身。

上述均为类别级官方事实，未见可比对的点值参数。其含义对本项目有两向：诱骗消耗、近距捕获、观瞄遮蔽等单项动作在对方概念与预算中已有落位，唯独"打完后由谁重排"仍缺独立于打击链与同一受扰数据链的手段。断点位置本身存在反证——另有判断认为末段导引才是首位缺口，两种排序不能同时采纳，须由作战场景差异裁决，这直接改变国内研制先后。

2. 国内现状（中国）

公开材料中，国内巡飞与自杀类无人装备多以无线电链路加末端光电识别为常见形态，链路被压制或拒止后的任务维持形态未见公开试验结论；对应蜃楼抱弹诱撞无人机与无药坠杆低成本攻击无人机的两项前提——不开辐射源自主完成杀伤、以无源图像匹配砸向地面再装填节点——均无公开案例。拦截端已有光电与雷达引导下的硬弹、高炮及便携式干扰装备形成层次，展会上出现过网捕与碰撞式方案，但没有弹射值守、不通链不辐射、仅靠机载被动光电自主完成几何捕获的近距拦截实例，伞骨张环拦截无人机所针对的"敌断链后自主突防"一段，仍要靠开机照射与有限火力通道硬扛。以无源介质在指定航段制造可停留遮蔽幕、再由本体穿幕清除观瞄与发射车的做法，公开层面无对应型号或试验报道，雾瞳蔽光巡飞攻击弹属方向级空白；城市桥涵顶面临空伏击与倒悬长期吸附布设，同样未见公开装备基础。地形影像匹配与视觉导航已在若干平台公开，但全程不开数据链、贴着地面杂波层穿谷打击低空雷达站的证据缺失，崖影穿谷攻击无人机的自主性上限难以由公开材料标定；以敌遥控与图传信道为照明源的多基线无源定位截击亦无公开实例，无影猎群拦截无人机面临同类空白。有利条件是完整的低成本机体产业链与规模制造能力，以及既有要地防空和电子对抗体系，这为以成本交换与静默值守为特征的装备提供了量产与布设基础，属能力条件而非既成装备。

3. 对比小结

差距不在平台制造，而在两处体系位置。第一是"不辐射条件下维持拦截"：对手已把多手段分层与电磁静默问题写入战略文件，我方近程防空的探测与交战判定仍以开机雷达光电为前提，一旦被迫静默即失去低空监视节奏，这正是伞骨张环拦截、无影猎群拦截与雾瞳蔽光巡飞三类装备共同要填的洞。第二是效果判定与再分配：对方审计机构承认该环存在缺口，但其制约主要来自鉴定与指挥体制；我方短板更硬——缺少可替代的回传证据手段，成批打击后能否确认摧毁只能依赖同一受扰链路，直接造成重复出击与火力浪费。成本交换上的错位是，我方具备批量制造优势，而弹药与交战结构仍以含炸药战斗部与链路在环为主，敌一旦改用选择性不打或超量同时到达，现有库存的效力即被抵消。因此，近程拦截的静默化与杀伤闭环的去链路化，是发展低空新质装备的首要必要性。
