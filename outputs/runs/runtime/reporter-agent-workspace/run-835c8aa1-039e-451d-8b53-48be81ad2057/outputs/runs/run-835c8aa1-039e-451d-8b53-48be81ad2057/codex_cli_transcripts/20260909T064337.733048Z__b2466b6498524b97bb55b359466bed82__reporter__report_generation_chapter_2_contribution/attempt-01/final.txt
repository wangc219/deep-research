## 二、项目画像

### （三）体系贡献率分析

实际基线是一条开机感知—链路指令—逐发火力—回传评估的低空交战链：感知靠己方辐射，交火靠链路在环。最先断的不是末段命中，而是断链条件下的效果可判定性：不确定摧毁逼出重复出击，重复出击再吃掉弹药基数与开机时间。

蜃楼抱弹诱撞无人机按敌一次开机加一枚拦截弹计价。敌辨高价值目标越准，我方暴露越贵；它自带模拟辐射与热源扮成己方长机沿拦截火力轴反复露头，敌弹一咬住便开战斗部撞向咬尾机与其发射阵位，保目标的动作反成自伤通道。本机不收指令、不回链，压制与欺骗无从切断杀伤闭环，靠给敌火力分配决策加价换出敌减少开机前的空窗；敌改选择性不打、无源值守或以高炮网捕替导弹时，算术作废。

通道容量是伞骨张环拦截无人机的计价单位，命中概率反而居次。敌廉价群同时到达之所以有效，在于我方须以昂贵、依赖辐射与链路的火力逐发应对；该拦截机不装炸药、不通链、不辐射，弹射值守在通道入口，靠被动光电按碰撞律冲入航线，伞骨张成刚性笼环锁死旋翼与弹体压向地面。纯几何判据使干扰、欺骗与诱饵无处着力，断链自主突防者反更易捕获，雷达—火力链因此得以静默。夜暗雨雾、超量同时到达与大俯冲角剖面会顶穿其包线。

雾瞳蔽光巡飞攻击弹的战果用时间差计量：敌恢复观测与我方完成清除之间剩多久。敌远距光电预警加拦截发射车靠全程可见换我方消耗，电子压制只对辐射联网设备有效；该弹沿接敌前段吐出超细冷水与吸波微粒，结成滞留数分钟的无源遮蔽幕，幕前敌致盲失准，弹体趁幕俯冲端掉发射车与观瞄，把突防从数量堆叠改为对指定观测节点的确定性断链。幕体生灭受风场与温湿度限定，敌以异谱备份观测交叉跟踪或对幕后盲射时，我方反被逼入固定通道。

敌雷达与地物无法分辨的那层杂波，是崖影穿谷攻击无人机唯一的空间前提。它起飞后沉入山谷、崖壁与城市峡谷，靠预置地形影像与光学自主导航穿谷，全程不越出杂波层、不开数据链，通视瞬间俯冲打击敌低空雷达站、光电警戒点与前沿指挥节点，敌认定安全的盲区后方反成其感知节点的损失清单，压制与欺骗都不改变其接敌几何。该装备的增量目前只支撑到作用方式一层，地形裕度下的发现距离与航路保持误差尚未标定。

倒悬坠袭伏击无人机改的是时间常数与空间占用。同一块桥板涵洞顶既把敌机从我方雷达光电里摘走，也在其航线正上方留出一块敌看不见、我方可占的体积；它倒悬长期吸附，以无源声学与微动探测静默待机，目标掠过瞬间脱附向上撞击其无法伪装的顶面与旋翼，我方等数周、敌只有数秒，出击节奏归布设方。它与上层反无链不重叠而是创造条件：敌抬高航域或绕行开阔段时既有拦截恢复效力；敌改超距投放或以廉价机清扫顶面，预置覆盖率与回收窗口便成瓶颈。

谁为感知付费，是无影猎群拦截无人机真正改写的账目。我方每取一次低空态势都要付一次辐射暴露：开机即成敌反辐射火力与巡飞弹的首选目标，关机则防御窗口塌陷。它自身不辐射，以敌群与其操作员之间的图传遥控信道为照明源，机载多基线干涉在静默中解算群内各机体方位与距离，破片战斗部侧向插入航路截击。敌要人工闭环、中途改目标与毁伤回传就必须辐射，关发射机等于放弃攻击收益，要地雷达与指挥所则可长期静默而不失明。敌转全自主、以辐射陪衬体诱骗或改窄波束猝发传输，是主要衰减路径。

无药坠杆低成本攻击无人机按消耗率与授权成本进入体系。敌把巡飞弹、机动防空发射车与光电桅杆分散停在纵深节点，靠数分钟再装填维持压制，我方链路需十几分钟且受弹药基数与协调授权限制。它以钨钢杆件替代炸药，运输平台在近防射程外批量投放，无动力滑翔静默待机，凭无源图像匹配俯冲，把发射筒盖与观瞄镜面砸成物理摧毁而非破片轻损；无爆源、无指令辐射使敌拦截链失去稳定触发判据，也无法以拦截弹换配重级弹体。基准影像过期、投放线超出滑翔覆盖或敌转入加固库后，收益退化为牵制。

同一基线上七处增量互不等价：诱撞与静默截击以敌仍需开机识别、人工闭环为前提，蔽光与贴地突防受当场气象和地形裕度限制，捕获与伏击卡在通道容量与预置覆盖率，动能砸击卡在影像时效与端侧时延。
