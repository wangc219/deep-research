## 一、需求分析

### （三）建设必要性分析

#### 1. 作战使用角度

敌低空防御的运行前提是“辨高价值目标—集中拦截—压制链路”，我方使用无人装备的旧前提则是“链路畅通、火力可用”。建设必要性首先在于同时抽掉这两条前提。蜃楼抱弹诱撞无人机投放即脱离指挥关系，以与真长机同源的辐射与热特征沿敌拦截火力轴反复露头，敌咬住它就把自家弹药与发射阵位送进撞击路径，动用它的授权形态由“通信畅通”改为“预置判据、自主执行”。雾瞳蔽光巡飞攻击弹把遮蔽从伴随手段升为主战行动，先沿接敌航路造出一段可停留数分钟的无源幕体，再趁幕俯冲端掉拦截发射车与观瞄阵地，突防由数量堆叠改为对指定观测节点的确定断链。崖影穿谷攻击无人机把航路压进敌雷达无法与地物分辨的回波层，靠预置地形影像与光学自主导航穿谷，打击点落在敌自认为安全的盲区后方。倒悬坠袭伏击无人机把拦截方向由水平改为垂直，预占桥下、涵洞顶这类同时剥夺敌可观测性与我方可射击性的顶面，使“遮蔽航线免费”这一使用假设被证伪。伞骨张环拦截无人机与无影猎群拦截无人机改变的是防御方的使用形态：前者弹射值守在通道入口，让雷达—火力链可以整段保持静默；后者以敌群自身的图传与遥控信道为照明，把截击线前推到敌集结与中转空域。无药坠杆低成本攻击无人机把打击时机压入敌地面整备与再装填窗口，压制不再取决于是否打通突防走廊。

#### 2. 装备能力提升角度

能力提升的实质是新增几条独立于电磁对抗的闭合路径，而非命中率或航程的增量。蜃楼的增益来自两项耦合：与真长机在雷达、红外、光电通道上持续同源的信号一致性，以及无回链下的终点自主判定与准点起爆——缺前者敌根本不开火，缺后者一次压制即失效。伞骨把交战终止判据降为纯几何，碰撞律不读取电磁语义，干扰、欺骗、导航接管与诱饵同时失去作用对象，单次拦截成本可压至与敌机同量级。无影猎群把感知成本转嫁给进攻方的作战必要性，其门槛是被动定位精度必须达到火控级而非告警级。雾瞳新增的是多谱段同时消光并对自机导引头选择性透过的能力，配方、波段与导引头必须共同设计，任一失配幕体便只剩遮蔽而无杀伤。倒悬的决定量是无源判型可用距离与脱附至命中所需时间之比，识别距离小于闭合行程则整机在物理上不可能命中。无药坠杆以高密度钨杆的近垂直入射取代爆轰，毁伤判据转为终端速度与入射角，对发射筒盖、观瞄窗类薄壳硬目标是物理摧毁而非破片轻损。崖影受制于预置影像鲜度与谷内无源定位的累积误差，二者决定通视瞬间能否完成攻击。

#### 3. 领域占位角度

七型装备各占住一条现在无人承担的位势：诱耗与杀伤合一、非爆捕获、无源成幕、杂波带突防、顶面伏击、无源截击、动能持续压制。共同点在于全部落在敌现有反无判据之外——对手的反制预算建立在“目标会辐射、会响应干扰、会从水平方向来”三项默认之上。

#### 4. 综合效益

效益须按敌行为而非己方毁伤计量：敌为诱撞机减少开机即丢失预警时间，为躲无源截击转入全自主而放弃中途改目标与毁伤回传，为规避顶面伏击抬高航域而重回既有防空杀伤区，为对付无药坠杆转入工事化再装填而按天累积出动率损失。建设取舍上，唯一不依赖未标定变量、可直接进基线的是断链拒止条件下的效果可判定性与跨单元再分配，宜以蜃楼一类无回链自主杀伤及其旁证计量口径先行；伞骨、无影属值守与拦截层，须以夜暗低云雨雾下的发现距离和通道拦截容量过关为条件；雾瞳、倒悬受当场气象、顶面可达性与预置覆盖率约束，属定向建设；崖影与无药坠杆公开证据最薄，应先以投放线极限与基准影像时限做小批验证再定量级。若“评估回传—再分配”与“末段导引”的断点先后最终判为后者，崖影的建设次序相应前移。
