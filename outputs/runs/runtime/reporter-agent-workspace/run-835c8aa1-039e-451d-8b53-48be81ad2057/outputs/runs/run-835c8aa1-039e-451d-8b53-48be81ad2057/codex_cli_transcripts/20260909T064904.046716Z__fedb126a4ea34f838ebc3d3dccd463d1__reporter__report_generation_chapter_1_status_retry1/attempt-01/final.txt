## 一、需求分析

### （二）国内外现状

#### 1. 国外情况

美方公开材料中真正能改变本项目装备判断的事实有三条，且都落在运用与流程层面，不在型号性能层面。

其一，美国国防部2024年底《反无人系统战略》情况说明书把反无人机能力明确为多手段并存、无单一解，将干扰类软杀伤列为核心效应，同时自陈目标鉴定与采办节奏是长期未解问题。这条类别事实划出了作用面：对手低空防线最省力的手段专对通链、开辐射的目标，其效力边界恰好落在一架不通链、不辐射、按预置航路自主冲刺的机体上。蜃楼抱弹诱撞无人机不接收指令、伞骨张环拦截无人机把终止判据降为纯几何，两条路线正落在该边界之外。该文件不含拦截弹单价与部队实配基数，不能由它推定量级。

其二，美国海军陆战队《部队设计》公开把分布式编组、无人系统比重上升、火力与电子战和防空一体化列为转型方向。其代价是分散节点在断链条件下动用不能以通信畅通为前提，须预先装订航路与触发判据——这与无药坠杆低成本攻击无人机防区外批量投放后即脱离指挥关系、崖影穿谷攻击无人机全程不开数据链的形态直接对应。

其三，美国审计署报告（编号 GAO-25-106454）把指挥控制任务链的首要缺口判在闭环后段，即效果可判定性与跨单元再分配，而非末段导引或火力通道数量。这与本项目从场景侧独立收敛出的断点同向，也说明相关装备的战果不宜用图像回传计量，而应改用敌开机时长、拦截弹发射量与阵位转移次数这类可由无源侦察旁证的行为量。

推断边界：以上均为类别级、流程级事实。未见国外公开装备在机首张环式纯几何捕获、顶面倒悬长期贴伏、弹载连续播撒成多谱遮蔽幕这三条具体路线上型号化部署的证据，不能据此认定对手已具备相应现役能力。

#### 2. 国内现状（中国）

逐件看，公开基础能解释"能不能造出来"，普遍解释不了"断链之后还能不能闭合"。

诱撞方向：低成本靶机、诱饵弹与巡飞弹已成门类，外挂角反射器与单谱段模拟源是常规做法，可消耗平台的制造与投放不是瓶颈；未闭合的是散射、辐射波形与热特征在反复露头和姿态突变时同时落在敌传感器分辨率内不可分，以及无指令条件下从同型诱标中挑出咬住自己的那一架并准点起爆。

捕获拦截方向：近程防空、光电跟踪与网捕拦阻有积累，但公开路线普遍以开辐射照射或数据链引导为前提。毫秒级张成刚性承力笼环、锁住带惯性的弹体而非仅缠旋翼、无辐射无链路下靠几何量反推距离并把张环时刻收敛到机构响应精度以内，三项均未见闭合证据。

遮蔽突防方向：发烟与遮蔽弹药成熟，但其设计前提是瞬时团状抛撒，喷口与粒径谱不为连续线源成幕服务；幕下不辐射末段制导还要求介质配方对本机工作窗口选择性透过，未见配方、波段与导引头共同设计的产品化证据。

贴地穿谷方向：地形影像匹配与光学自主导航有预先基础，缺口在长时段不越出雷达杂波层、不开链的航迹保持，以及城市峡谷多径与剧烈遮挡下的通视瞬间识别与俯冲衔接。

顶面伏击方向：粗糙潮湿混凝土面的长期倒悬保持与可控释放、桥下强混响与结构传振中用桨叶通过特征和微动多普勒完成判型与提前量解算，均无装备化证据，且连续感知与长期静默在能量预算上互相挤压。

静默截击方向：无源探测与无线电监测以地面固定站体制为主，向机载多基线干涉迁移需要高稳定时频基准、火控级而非告警级的定位精度、对跳频间歇上行信号的截获概率与解算时延，公开材料未见机载实现。

动能砸击方向：钨合金动能侵彻体是现有技术分支，未闭合的是无源图像匹配与大攻角俯冲控制的实时收敛，以及对铝合金机体、钢制发射筒与观瞄镜面的分级侵彻判据；缺判据时精度稍偏只留凹坑，单发价值即归零。

#### 3. 对比小结

三条差距各对应一个任务链断点。

第一，对手把软杀伤当核心效应，我方主要无人装备的杀伤闭环仍挂在链路上，压制一开机，侦察—打击关系即在短时窗内脱节，弹药留在手上打不出去。这是任务维持形态问题而非通信指标问题，须由不接收指令、本机闭合杀伤的装备承担诱耗与清除，否则突防只能拿数量去撞对方的弹药基数。

第二，对手同样受制于火力通道容量与鉴定采办节奏，其公开文件承认无单一解。差距不在拦不拦得住，而在拦得起几批：单次拦截成本压不到敌机同量级、终止判据不移出电磁语义，敌"密集接近压垮通道"的成本基础就不会失效；继续沿用开辐射引导，等于每批来袭都用一次暴露去换。

第三，国外把缺口判在闭环后段，国内公开努力集中在前段探测与末段命中，"是否打中、下一波打哪里"缺少不依赖回传的判定手段。效果可判定性与跨单元再分配不补齐，伏击、诱耗与遮蔽打开的窗口就转不成后续波次的通行与补击，单点战果停在孤立事件上。

失效边界：上述判断以敌仍依赖辐射探测、半自动交接和露天再装填为前提。敌转向纯无源远程火力与纵深防空时，诱撞与遮蔽收益被摊薄；地面节点全面转入加固库并自动化补给时，动能砸击的收益退化为牵制。首要断点究竟在评估回传—再分配还是末段导引，公开证据不足以定序，应按要地外围与城市边缘两类场景分别排列装备优先级，不取单一先验。
