## 二、项目画像

### （一）装备图像概述

| 装备（S6入选，按优先序） | 核心技术与实现卡点 | 形成能力与进入方式 | 关键动作—作用对象—直接效果 |
|---|---|---|---|
| 蜃楼抱弹诱撞无人机 | 多谱特征一致性：蒙皮共形布置散射调控层、射频模拟源与热辐射源，使雷达、红外、光电通道同时呈现己方长机与主力巡飞弹特征，并在反复露头、姿态突变时保持各谱吻合；升力、电池与散热互相挤压，须以无源散射层承担主反射、有源源只补盲。第二卡点是无回链终点自主判定与起爆：高闭合速度下用弹载无源定向与成像，从同型诱标中挑出咬住自己的目标并准点起爆。 | 由陆基装置或蜂群母机在敌拦截火力轴外侧投放，装订"只冒充长机、全程不回链、自主决断"的任务边界后即刻脱离指挥关系，随己方佯动蜂群一同进入，换得一段不受功率压制与协议欺骗影响的接敌航路。 | 以与真长机同源的辐射节拍沿敌主要进近轴反复露头，把敌传感器从广域搜索逼进定向跟踪；敌拦截弹或捕手机咬住、照射能量集中到本机时开保险俯冲，先撞咬尾弹体与机群、次压下压发射阵位；未被咬住则继续露头拉长敌开机时间，绝不追打低价值目标。敌近程拦截弹、捕手机与操作员一并折损，拦截通道出现补不上的实体缺口，其低空监视—拦截节奏被迫中断，后续蜂群利用空窗穿入；敌若全程不辐射仅以无源跟随，本机按预定航路脱离另择火力轴。 |
| 伞骨张环拦截无人机 | 机首笼环须在撞入前数十毫秒张满并锁成刚性承力结构，同时约束旋翼与带惯性的弹体；折叠构型与张开刚度互相矛盾，捕获瞬间敌机动量全转给本机、关节一次承载即失效，需高储能比张紧机构与自锁关节。第二卡点是零辐射零链路下被动光电测向与张环时机的闭合：距离只能靠几何量反推、误差随快速逼近放大，须把成像测向、预测制导与弹射时序做进嵌入式实时解算。 | 折叠伞骨状态弹射值守在己方低空通道入口，不通链、不开辐射源、仅被动光电开机；值班授权只含放行与禁射区设定两级，捕获动作由机载自主闭合，可长时间静默值勤。 | 敌群任一目标进入可稳定测向跟踪距离且航线与弹射包线相交时弹射升空，按碰撞律冲入其航线，末段只修正几何不修正语义，张环锁死后与被捕获体共同向指定空旷区压降。对象是断链后按预置航路自主冲刺的廉价自杀机群：这类目标不听不看，干扰、欺骗、导航接管与诱饵全部失去作用对象。敌机在末段前被逐个摘出航线、航路与弹药同时作废，我方不必为百元级目标开火，辐射纪律与弹药保有量同时保住；超包线或需横越禁射区则拒打复位，目标交末端火炮与软杀伤。 |
| 雾瞳蔽光巡飞攻击弹 | 弹载连续播撒的无源遮蔽气雾：滴粒径须与敌工作波长同量级才能兼顾可见/近红外散射与中远红外吸收，超细滴又在低湿度剪切风场中快速蒸发，载液量与播撒功耗受弹重续航硬约束，需水滴与吸波微粒配比、粒径谱、抗凝聚表面联合设计加弹尾环形定流量喷口，并按实时风场修正投放点。互为前提的第二项是幕下不辐射末段制导：配方须对自机工作窗口选择性透过，配无源图像匹配与中段地形基准。 | 由前沿指挥所在预授权封锁段内下令，先由友邻无源探测框定拦截车与观瞄阵地的方位走廊，再沿敌观测盲区进入；可单枚成形，也可多枚接续成有起点、长度与朝向的通道段，本机保持在幕体边缘之外以免自致盲。 | 在接敌前航路连续吐出可滞留数分钟的无源遮蔽幕，敌光电与红外在幕前致盲、测距失准；本弹幕内静默前滑，敌发射车仍具机动能力时不提前起爆，末段俯冲确认轮廓后炸毁拦截车与观瞄阵地。对象是"远距光电预警加近程拦截车"咬合的观测节点，敌不能对一片不辐射、不联网的雾幕施加干扰或欺骗，也不敢在自身失明时开机拦截。同一轴线短时失去观测重建能力，后续波次沿通道低代价穿越，单点致盲扩展为段内通行；风场使幕体提前消散或遮蔽不足一个俯冲周期则拒打侧向脱离。 |
| 崖影穿谷攻击无人机 | 预置地形影像与光学自主导航支撑的穿谷机动，要求全程不越出地面杂波层，谷壁侧向净空、高度保持与航迹贴合精度是决定成败的核心变量。本条画像记录仅给出运用、目标与失效边界，未提供技术实现、指标与验证口径；缺少的证据是地形影像基准的过期时限、杂波层内高度保持精度、通视瞬间的目标判型依据以及城市峡谷多径条件下的可用性，这些量不宜转化为确定性指标。 | 起飞后即沉入敌预警盲区，沿山谷、崖壁与城市峡谷的雷达杂波带贴地进入，不开数据链、不越出地物回波层。 | 在通视目标的瞬间俯冲，打击敌低空雷达站、光电警戒点与前沿指挥节点。敌以功率压制、导航欺骗和远程航迹监视织成的封锁对它不成立：断链与欺骗都不改变其接敌几何，其航路本就藏在敌雷达无法与地物分辨的回波里，前沿感知节点在自认为安全的盲区后方被逐个掀掉。成立前提是该型装备实际分析尚未闭合的变量能取信：目标区影像可信、峡谷走向与敌阵位通视关系成立、打击窗口在单架次航时内可达。 |
| 倒悬坠袭伏击无人机 | 长期贴附与可控脱附的解耦：须数月倒悬在桥下混凝土面保持静默，又在目标掠过一瞬脱离上行；潮湿带雨膜面使真空吸附漏气并需持续抽气功耗，永磁只适用钢梁、化学胶粘不可重复，攻关方向是可控静电吸附与仿刚毛柔性接触层复合，持力做在法向、释放做在剪切，并设机械解锁件。第二卡点是头顶盲区无源发现与击发闭环：桥下混响强、风噪与结构传振污染信号，敌机仅以数秒掠过上方，须用准静态值守、事件触发唤醒压低能耗，把判型与提前量与脱附点火串成硬线击发链。 | 工程小组在夜间或施工维保掩护下经桥面检修口把节点倒悬固定于结构底面，朝向预期来袭方向设定捕获视场，自行判定吸附保持对风载、雨水、车辆振动与温差循环的安全余量，不合格即退设；随后以能量采集或低占空比电池维持纯接收待机，不发射、不上报。 | 从桥面交通与风雨背景中分离桨叶通过特征与微动多普勒，按战前批准的类别、走廊、时段与禁射条件本地闭合授权；目标进入结构正下方、上方净空被构件限制而横向难以脱离的瞬间，腹部脱附、微推向上撞击其顶面与旋翼。对象是借遮蔽走廊掠地穿行的敌小型无人装备，直接战果是机体与载荷被毁、视线遮挡与上方净空同时变成致命条件；一次已验证击杀即令整条走廊失去可信度。特征仅达疑似或与风振鸟群混叠、己方有人机可能进入同一净空则拒打待机。 |
| 无影猎群拦截无人机 | 以敌群与操作员之间固有的图传和遥控信道为照明源，机载多基线干涉在纯静默中解算群内各机体方位与距离。卡点依次是机间高稳定时频基准、对跳频与间歇低功率上行的截获分选（按频点驻留、帧结构与方位稳定度剔出真实机体辐射，排除地面站与诱骗源）、把无源定位误差压到火控级而非告警级，以及末段只用被动成像修正、不开任何测距雷达。 | 单架或数架关闭全部发射机、仅保持接收进入伏击空域布阵，可静默待机数小时；敌组织反制时静默转场，不留固定辐射阵地。 | 将每部机体辐射与其航迹绑定，群内目标由一片杂波转为可编号序列，按距离、航向收敛角与是否挂载战斗部排序，按提前量从侧向插入航路，在相对速度最高处起爆破片战斗部，同批立即回扫判断缺口是否已阻断编队收敛。对象是敌微型无人机与巡飞弹本体，尤其在其离开发射阵位、进入中继集结空域必须开链维持人工闭环与毁伤回传的时段。战果是在己方雷达关机、地面电子战资产被压制时仍能成批击落，敌饱和攻击在收敛前解体为不具同时性的零散来袭；所需电磁能量由敌自身供给，关发射机即放弃重规划与收益，开发射机即被定位截击。 |
| 无药坠杆低成本攻击无人机 | 无源图像匹配末制导与俯冲控制的实时闭合：俯冲段视场急变、惯导漂移使基准图失准，末端可用修正时间过短，须以投影一致性匹配与免辐射自主定位把识别置信度耦合进大攻角控制律。第二卡点是杆件与载体的毁伤一体化：无爆源使毁伤全依入射角、终端速度与长径比，稍偏只留凹坑，前置配重又与折叠翼展开、滑翔配平强耦合，需建立铝合金机体、钢制发射筒与观瞄镜面的分级侵彻判据和冲击隔离解锁机构。 | 运输级平台在敌近防射程外批量投放，机体展翼以升阻比沿目标区边缘缓慢降高，全程不辐射不开链，靠惯导与地形影像匹配保持位置并长期悬置待机，不触发敌雷达与电子压制关注。 | 降至匹配高度后对预定点位连续成像比对基准，仅在出现开盖、装筒、起桅或车辆活动时以大角度俯冲增速，以近垂直入射把钨钢杆砸入发射筒体与观瞄窗。对象是敌低空装备的地面停放机群、机动防空发射车与光电桅杆，直接战果是物理摧毁而非破片轻损；无爆源与爆后热烟使敌缺乏预警判据、无法判定来袭是否结束，也无法用拦截弹承担与配重价格弹体的消耗交换，被迫后撤、拉大间距并转入工事化再装填，出动节奏与前沿密度双降。置信不足或判为禁打目标即自主终止俯冲、重返待机。 |
