## 二、项目画像

### （一）装备图像概述

| 装备 | 核心技术与形成能力 | 部署与进入方式 | 关键动作—作用对象—直接效果 |
|---|---|---|---|
| 蜃楼抱弹诱撞无人机 | 共形散射层与射频模拟源、热辐射源按任务剖面分阶段调度能量，使机体在敌雷达、红外、光电三通道上与真长机统计不可分；无链路终点靠弹载无源定向从同型诱标中挑出咬住自己的敌机并准点起爆。形成断链条件下仍可闭合的杀伤能力 | 陆基装置或蜂群母机在敌拦截火力轴外侧投放，装订航路与触发判据后即刻脱离指挥关系，全程不接收指令 | 沿敌主要进近轴以同源辐射节拍反复露头→敌拦截弹或捕手机咬住后打开战斗部俯冲撞向咬尾弹体及其发射阵位→敌弹药基数与发射平台同时折损，低空监视开机节奏被迫中断，后续蜂群利用空窗穿入 |
| 伞骨张环拦截无人机 | 机首伞骨毫秒级张成刚性承力笼环并锁止旋翼与弹体，高储能比张紧机构与自锁关节承受共坠动量；无辐射条件下被动光电成像测向反推距离，碰撞律解算提前量。形成不占频谱、不耗弹药、不可诱骗的纯几何捕获能力 | 折叠伞骨弹射值守于己方低空通道入口，全机不通链不开辐射源，仅被动光电开机，值班授权限于放行与禁射区两级 | 目标进入测向可稳定跟踪距离且航线与弹射包线相交时弹射冲入敌航线→笼环在碰撞前张满锁死敌旋翼与弹体→带降压向指定空旷区→敌自杀机群密集接近压垮火力通道的打法失效，我方远程弹与近防火力不必为廉价目标开火 |
| 雾瞳蔽光巡飞攻击弹 | 水滴与吸波微粒配比、粒径谱和抗凝聚表面联合设计，弹尾环形定流量喷口连续播撒形成有长度有朝向的遮蔽幕，同时散射可见与近红外、吸收中远红外、损耗毫米波；气雾配方对自机导引窗口选择性透过，配无源图像匹配实现幕下不辐射末段制导。形成在指定航段制造确定观测空洞的能力 | 前沿指挥所在预授权封锁段下令，弹体沿敌观测盲区进入接敌前航路，自身保持幕体边缘之外避免自致盲 | 连续抛洒成幕遮断敌观瞄方向→趁敌光电致盲、测距失准时俯冲炸毁仍在提供观测的拦截发射车与观瞄阵地→敌远距光电预警加近程拦截的分层火网被截出断视窗口，后续波次沿同一通道低代价穿越 |
| 崖影穿谷攻击无人机 | 预置地形影像与光学自主导航将航路约束在山谷、崖壁与城市峡谷的雷达杂波层内，全程不越出地物回波分辨边界、不开数据链。形成敌功率压制与导航欺骗不改变接敌几何的突防能力 | 在敌远程航迹监视覆盖边缘起飞即沉入预警盲区，沿杂波带穿谷机动至目标通视方向 | 保持贴地构型穿越谷段直至获得目标瞬时通视→俯冲打击敌低空雷达站、光电警戒点与前沿指挥节点→敌前沿感知在自认安全的盲区后方被逐个掀掉，低空封锁带出现补不上的探测缺口 |
| 倒悬坠袭伏击无人机 | 可控静电吸附与仿刚毛柔性接触层把持力做在法向、释放做在剪切，机械解锁件使脱附不对抗自身持力；无源声学阵列从桥面交通与风振中分离桨叶通过频率与微动多普勒完成测向判型。形成以几何预置取代频谱压制的静默伏击能力 | 工程小组在夜间或维保掩护下将节点倒悬吸附于桥下、涵洞顶与棚架下表面，朝向预期来袭方向设定捕获视场，转入纯接收休眠 | 敌机穿入顶板正下方遮蔽段的数秒窗口内脱附向上点火撞击机体顶面与旋翼→摧毁机体与载荷→敌方遮蔽航线转为击杀走廊，敌被迫抬升进入既有雷达与拦截火力覆盖区或逐段排查顶面付出暴露与延时代价 |
| 无影猎群拦截无人机 | 以敌群与操作员之间固有的图传和遥控信道为照明源，机间高稳定时频基准建立可干涉多基线阵，纯接收解算群内各机体方位与距离至火控级；末段以被动成像修正侧向交会，全程不开测距雷达。形成感知成本转嫁给敌方辐射必要性的静默截击能力 | 单架或数架进入伏击空域后关闭全部发射机仅保持接收，不留固定辐射阵地，可静默待机数小时后转移 | 在敌群上行遥控与下行图传混合信号中分选真机体辐射并绑定航迹→破片战斗部在侧向相对速度最高处起爆击落→成批撕开攻击编队收敛，敌关发射机即放弃中途改目标与毁伤回传，开发射机则被定位截击 |
| 无药坠杆低成本攻击无人机 | 钨钢杆以高密度小截面将终端动能集中于一道接触面，对铝合金机体、钢制发射筒与观瞄镜面按入射角、速度和长径比建立分级侵彻判据；无源图像匹配耦合大攻角控制律，免辐射免链路完成末段识别。形成无爆源无热特征可预警、单发成本趋近配重的持续砸击能力 | 运输级平台在敌近防射程外批量投放，机体展翼无动力滑翔至目标区边缘缓慢降高待机，全程不开数据链不辐射 | 按基准影像比对确认开盖、装筒或起桅活动后近垂直俯冲→钨杆砸穿发射筒体与观瞄窗造成物理摧毁→敌地面集结与再装填节点被不定次数打断，被迫转入硬壳掩体并拉长整备周转，低空体系持续压制窗口收窄 |
