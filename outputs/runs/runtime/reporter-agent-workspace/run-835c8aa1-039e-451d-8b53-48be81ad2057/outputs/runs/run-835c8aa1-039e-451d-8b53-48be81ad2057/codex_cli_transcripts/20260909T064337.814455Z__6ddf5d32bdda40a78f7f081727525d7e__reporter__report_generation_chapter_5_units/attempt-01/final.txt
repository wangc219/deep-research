## 五、研制基础

### （一）参与单位

本栏不按整机厂加分系统所的通用分工，只从各装备要交付的实物、要打开的接口、要承担的试验和要拿出的证据反推机构类型；公开材料未给出具体单位归属，以下不指名。

蜃楼抱弹诱撞无人机（优先项）的产品责任压在蒙皮共形散射层、射频模拟源与热源的三谱同源上，能量调度又与升力、散热争体积，需目标特性测量与标定类机构提供一致性数据。它的验收不是命中精度，而是敌是否愿为它开火、开火是否亏本，因而必须有能扮演敌制导站与来袭拦截弹的对抗靶场，此类外场条件未见公开建设方。

伞骨张环拦截无人机的关键交付是碰撞前数十毫秒张满并锁成承力框的笼环，属快速展开机构、冲击承载与落点安全分析单位，与机体气动分属两个专业，接口在机首前向包络和锁止时序上；试验要标定捕获速度与大俯冲角包线、共坠落点散布，超出常规防空靶场科目。无药坠杆低成本攻击无人机把责任推到另一端：钨杆对发射筒盖与观瞄窗的分级侵彻判据归终端弹道与毁伤试验机构，运输级平台的防区外批量投放是外部装备既有接口，本项目只承接投放后的自主段。

雾瞳蔽光巡飞攻击弹要求气溶胶配方、自机透过窗口与导引头波段共同设计，需多谱消光测量与气象环境保障类机构，幕体停留时间只能在可控风场取数，该条件是否现成无据可查。无影猎群拦截无人机要交出己方辐射占空比为零的证据，须由电磁兼容计量单位独立复核而非研制方自检，无源定位与高稳定时频基准归无线电监测与无源探测类机构。倒悬坠袭伏击无人机的持力与释放解耦涉及吸附与结构界面类机构，声学判型只能在桥涵棚架真实构件上标定，缺的是城市背景噪声库。

崖影穿谷攻击无人机现有记录只到地形影像与光学自主导航的方向，未见部件实现，故只能确定影像基准制作与导航数据处理类单位，其余责任不作分配。

七件装备共同缺的证据是同一条：断链或拒止条件下效果能否判定、任务能否跨单元再分配，需体系级仿真与靶场联合试验的组织方把各单机数据放进同一任务链验收；在此环节落实前，任何具名单位清单都属推断。
