## 二、项目画像

### （四）主要战技指标

指标只从各件装备自身的制胜动作与最可能失效环节反推，先写它保住的作战效果，再给判据。

**蜃楼抱弹诱撞无人机**：要成立，敌必须"愿意为它开火、开火即亏本"。首要指标是与真长机的多谱特征不可分度——辐射功率谱、调制节拍、散射截面与热源特征在敌传感器分辨率内被误判为高价值目标的比例，配合"从被咬合到转入撞击"的判定正确率；其次为每架次净消耗敌拦截弹数与撞中弹体、发射阵位的概率，直接决定成本交换比是否被改写。它最怕敌选择性不打，因此单列"敌全程不辐射时按预定航路脱离并保全机体"的比例，防止用机体换低价值目标。取数方式为同型真长机双目标对照、由外部无源侦察旁证敌开机与发射量。

**伞骨张环拦截无人机**：效果是让"通道容量"成为敌必须先打穿的数。指标取单位时间可交战架次与复装间隙；张环完成时间、张开后承载刚度与吸能量，界定可捕获速度与航向交叉角包线；被动光电首次稳定跟踪距离及夜暗、雨雾下的降级幅度；单次拦截成本与敌机单价之比。包线外目标（大俯冲角、高速固定翼）与超量同时到达是判废条件，须以多机同步来袭和不同气象消光等级交叉试捕，形成捕获率—速度—迎角三维分布。

**雾瞳蔽光巡飞攻击弹**：效果是造出确定的一段"看不见"。指标为可见/近红外、中远红外、毫米波三谱路径衰减的一致性（单谱达标即被跨谱融合识破）、幕体成形时间、有效滞留时长、可维持通道长宽与风切下形态保持率，以及单枚可开通道段的架次效率。战果的真正度量是敌开机重建观测、以备份手段恢复跟踪的时间与我方完成清除的时间差。试验须按风场与湿度分级实测消光与生灭节奏，并配敌观瞄样机计时。

**崖影穿谷攻击无人机**：现有材料只支撑方向级判据。其效果是把航路藏进敌雷达无法与地物分辨的回波里，故指标为全程不越出地面杂波层的高度保持裕度与越层暴露时长、谷地机动下的影像匹配定位误差、断链与导航欺骗条件下仍达成接敌几何的比例、通视瞬间到命中的剩余目标反应时间，以及无人在环时低空雷达站与光电警戒点的识别正确率。具体点值需经外场杂波实测与雷达网截获统计标定，当前保留区间。

**倒悬坠袭伏击无人机**：效果是把敌的遮蔽航线变成击杀走廊。第一道生死线是无源声学判型可用距离与"脱附至命中所需时间"对应行程之比；同时测虚警率与误伤率，二者共同决定敌是否把廊道告警当噪声、我方是否被迫停用整段防护。另取雨膜混凝土与桥面车辆振动下的吸附保持合格率、待机时长、脱附点火成功率与误触发抑制。检查手段为桥下混响环境下的实机掠顶通过试验与含禁射区的场景回放。

**无影猎群拦截无人机**：效果是把感知成本转嫁给敌方的作战必要性。指标为无源定位方位角与距离误差能否达到火控级而非告警级、对跳频猝发低功率上行的截获概率与"截获到可交火"解算周期、群内单体分辨与诱饵判别正确率、单机可同时接战与再交战通道数，并以己方辐射占空比须为零作为硬约束。战果用"撕开编队后敌攻击同时性下降比例"衡量。敌转全自主关射频即失去照明源，此项须以辐射/静默混编批次单独考核。

**无药坠杆低成本攻击无人机**：效果是以趋近配重的价格反复砸再装填窗口。指标取敌暴露到命中的端侧时延、基准影像可接受过期时限、近垂直入射角与终端速度对应的发射筒盖与观瞄镜面贯穿率、无源终端识别正确率与误伤率、待机时长与滑翔覆盖距离、单发成本对敌拦截弹及单车的交换比、单位时间可有效压制的再装填点数量。毁伤判据须按铝合金机体、钢制发射筒、玻璃桅杆分级做靶场贯穿，影像老化后的失配率与假筒假桅杆分判另行考核。
