一、需求分析

（一）需求概述

1. 背景分析
低空无人装备在强对抗环境中被卡住的位置已经清楚：敌方在要地外围、桥隧与城市边缘铺出"分辨高价值目标—集中火力拦截—压制测控链路"的三段式拦截网，用辐射源与热特征甄别己方长机和主力巡飞弹，以少量值守资源换取己方大批平台暴露。与此同时，敌又以百元至千元级旋翼与自杀机型多方向密集接近，只要同时到达数超过己方火力通道，就能逼防空单元开火耗弹，或使低空通道内的运输、侦察平台停飞。攻守两侧共用同一个断点：效果可判定性与跨单元再分配。断链、拒止与欺骗条件下，链路降级不只是通信问题，而是任务能否维持的形态问题——侦察—打击链在短时窗内脱节是它的表现；"不确定摧毁—重复出击"的正反馈使拦截消耗无法收敛。任务链压力因此落在闭环后段：己方越依赖回传与统一指挥，链路被压制后的火力通道、弹药基数与前沿感知节点就越快透支。

2. 需求阐述
从研究问题出发，需要的是三类能力，且都不以增加航程、威力或命中精度为内容。第一，需要不依赖己方通信、却能迫使敌开火并把它自己的拦截弹药与发射阵位送进毁伤路径的能力：蜃楼抱弹诱撞无人机承担此需求，缺的正是诱骗与杀伤合一的手段——现有诱饵被动挨打，判明即被零成本戳穿，巡飞弹一旦受功率压制或协议欺骗则弹药在手而打不出去。第二，需要不开机、不通链也能完成近距交战的能力：伞骨张环拦截无人机以纯几何捕获应对断链自主突防目标，无影猎群拦截无人机把敌群自身的图传与遥控信道当作照明源，两者共同指向同一缺口——软杀伤打不到自主目标，硬杀伤在成本上先自溃，而资产近旁又不允许爆炸。第三，需要确定性观测空洞与再生节点压制：雾瞳蔽光巡飞攻击弹以无源幕体切断敌传感器与其火力单元的观测关系，崖影穿谷攻击无人机借雷达杂波带贴近突防、掀掉盲区后方的低空雷达站与光电警戒点，无药坠杆低成本攻击无人机在目标落地整备与再装填窗口实施砸击，它们分别补齐电子压制、硬压制与火力链路三种手段都做不到的位置。倒悬坠袭伏击无人机则回应遮蔽航线这一结构性空白：桥下与涵洞顶同时剥夺己方可观测性与可射击性，人力警戒又无法覆盖全部廊道。跨装备协同只有一处依据：诱撞与无源截击形成的敌开机规律、阵位与观测缺口信息，可交由后续巡飞与远程火力使用。

3. 项目画像
本项目研发的作用不是提高单机突防命中率，而是重写低空攻防的四项交换关系。敌我为"辨—集—压"支付的代价被提高：开机拦截即丢弹药与阵地，静默躲避即中断低空监视节奏，己方把该轴向保持为敌不敢开启的拒止走廊。拦截成本被压到与敌机体同量级，密集接近压垮火力通道的打法失去成本基础，其反制只能拆散编组、拉大间距，从而放弃赖以制胜的饱和效应。暴露成本由"我方每前出一分即增加一分"转为敌观测节点必须开机、前推或人工抵近才能重建，被遮方向反而成为被寻找、被毁伤的目标。感知费用转嫁给进攻方的作战必要性本身——敌要人工闭环与实时毁伤回传就必须辐射。作战前景是低空通道在强对抗下保持开通、敌方再装填节奏被压出可用时间之外，制胜增量为无需重建链路即可闭合判定与压迫。判断存在失效边界：诱撞收益以敌仍采用有人值守、半自动交接的拦截闭环为前提，敌转用无源远程火力或廉价近程拦截即被摊薄；纯几何捕获限定于低空亚音速近距目标，雨雾、沙尘与强逆光收窄捕获窗口；遮蔽幕只在预设航段与当场气象的滞留时段内成立；动能砸击的效力取决于目标处于地面静止或低速装填状态；无源截击以敌群保持辐射为前提，敌转入全自主攻击即收益衰减；设伏依赖顶面可抵达预置且清扫代价高于设伏代价；贴地突防的可用航线受谷地与城市峡谷地形限定。

因果链已逐件闭合，三级分工未越界：型号方案、作战流程与指标表留待后续栏目。
