## 五、研制基础

### （二）技术基础

本项目的技术风险不在新物理或新平台，而在少数跨域耦合点上。七件装备所依赖的载体现成门类已经存在：巡飞与诱饵类飞行器总体及低成本结构、弹药化播撒与气溶胶工程、快速解锁展开机构、无源测向与多站定位体制、高稳时频同步、壁面吸附移动平台、动能侵彻体与图像匹配末制导、弹射投放与嵌入式视觉计算。真正需要新建的是"不辐射、不回链"前提下的机载闭合能力——这是敌方功率压制、协议欺骗与导航接管已高度成熟后的必然结果，其代价是把识别、判定与击发全部压进单机。因此下述基础按装备分别评估，共性缺口集中在多谱一致性的外场度量条件，而非平台本身。

| 装备（优先级） | 可直接继承的成熟基础 | 必须新增的研制工作 | 具体可研缺口（缺哪个变量/工况） | 试验与供应链条件 |
|---|---|---|---|---|
| 蜃楼抱弹诱撞无人机（P1） | 诱饵用射频模拟源、雷达散射调控与吸波涂层、巡飞弹总体与折叠翼、碰炸引信及保险解除机构，均属在用弹药载荷门类 | 蒙皮共形布置散射调控层、射频源与热源，使三谱在反复露头与姿态突变中同源吻合；无链路条件下从同型诱标里挑出咬住自己的目标并准点起爆 | 缺"在敌传感器分辨率内与真长机不可分"的可信度量口径：须按敌典型雷达带宽、红外空间分辨率给区间而非单点值；辐射源耗电发热与升力、电池、散热三者权衡缺任务剖面数据 | 需雷达、红外、光电同场且可比对的多基地特征测量走廊，配可控模拟拦截照射源与可咬尾靶机；瓶颈在高功率密度射频器件、微型热源的寿命与批次一致性 |
| 伞骨张环拦截无人机（P2） | 弹射投放、折叠—展开锁止机构、碰撞律近距交会导引、被动光电成像测向，可沿用现有工程路线 | 高储能比张紧机构与自锁关节、变截面伞骨传力路径，使笼环在张开末端即成承力框；把角度、接近率与张环时刻的解算收敛进机构响应精度 | 张开完成时间与张开后承载刚度、吸能量的组合无公开依据，直接决定可捕获速度与航向交叉角包线；上游仅支撑视光明亮条件近距单目标捕获，夜暗、低云、雨雾下的跟踪距离降级幅度是空白量 | 需高速摄影与力—位移同步测量的地面台架、带真实惯量的自杀机模拟靶、共坠落点散布与残骸危险区标定；轻质杆件与关节精密件尚无低成本批产途径 |
| 雾瞳蔽光巡飞攻击弹（P3） | 发烟与气溶胶弹药工程、定流量环形喷口、红外成像导引头与巡飞动力段 | 由瞬时团状抛撒改为连续线源成幕：水滴与吸波微粒配比、粒径谱、抗凝聚表面处理的联合设计；气雾配方对自机工作窗口选择性透过，实现配方—波段—导引头共设 | 可见/近红外、中远红外、毫米波三谱路径衰减一致性缺外场标定；低湿度与剪切风场下浓度沿航路的塌陷速率、单枚可维持的通道长度与停留时间无可用数据 | 需多谱段同视场消光测量与开放风场布幕试验、跨谱观瞄靶标；吸波微粒组分一致性与载液稳定性构成新的供应环节，不能按现役发烟弹供应链沿用 |
| 崖影穿谷攻击无人机（P4） | 地形与场景匹配导航、惯导加光电测姿、低成本长航时机体 | 航路全程不越出地面杂波层的生成与谷内机动控制；通视瞬发的自主目标确认 | 上游画像未展开其技术实现，故不推定成熟度；可研缺口是把"藏身杂波层"变成判据所需的敌低空雷达地杂波抑制余量，以及弱纹理、强多径条件下匹配误差随速度与高度的增长关系 | 需可复现的峡谷与城区影像基准库及杂波背景试验场；缺少上述两项输入前，本装备的基础评价只能停留在类别级 |
| 倒悬坠袭伏击无人机（P5） | 壁面与顶面吸附移动平台、微机电声学阵列与结构振动监测、事件触发唤醒的低功耗常听电路、近炸击发链 | 持力与释放解耦的可控静电吸附加仿刚毛柔性接触层，并在吸附模块与机体间设机械解锁件；粗糙潮湿带雨膜面上的数月倒悬保持与一瞬脱附向上点火 | 首要未知量是无源判型可用距离与脱附至命中所需时间之比，比值不成立则物理上无法命中；桥面车辆振动、风雨、伸缩缝背景下的虚警谱与桨叶通过特征分离能力缺公开数据 | 需实体桥涵顶面的长期暴露与振动台试验、夜间借维保掩护的布设与回收训练条件；静电吸附模组仍处样件阶段，无承载保持的批次统计 |
| 无影猎群拦截无人机（P6） | 无源测向与多站定位体制、卫星共视与小型原子钟的时频同步、光电随动、近程破片战斗部 | 机载多基线干涉在气流扰动与机体振动下维持通道间相干性；群内混合上行遥控与下行图传的分选、单体绑定与威胁排序 | 定位能否从告警级进入火控级缺方位角与测距误差的实测容限；跳频、间歇与低功率上行的截获概率及解算时延未标定；敌转用窄波束猝发传输后可利用能量是硬边界 | 需可编排多机辐射的靶群、频谱管制空域与地面高精度参考站提供定位真值；机间时频基准的小型化与批量一致性是当前主要工业短板 |
| 无药坠杆低成本攻击无人机（P7） | 钨合金长杆与动能侵彻体加工、图像匹配末制导、运输级布撒平台与折叠翼滑翔体，全部为现成门类 | 无辐射无链路下的投影一致性匹配，并把识别置信度耦合进大攻角俯冲控制律；杆件—载体毁伤一体化，含分级侵彻判据、冲击隔离解锁与前置配重对展开配平的影响 | 近垂直入射对铝合金机体、钢制发射筒与光学镜面的贯穿速度—角度门限缺公开靶试数据；可接受的基准影像过期时限只有关联变量，无点值 | 需多材质靶板库与大角度俯冲打靶场、投放段飞行安全验证；钨材原料与精密加工属国内成熟产能，是把单发成本压至接近配重价格的主要有利条件 |

支撑研发新质装备的基础确实存在，但分布不均：P1、P7 只需在既有弹药与制导门类内增加耦合设计与靶试，可近期启动；P2、P3、P5、P6 的共同前置是自建试验条件——多谱一致性测量走廊、带惯量的捕获靶、开放风场布幕标定、实体桥涵长期暴露工位、可编排辐射靶群与管制频谱——这些不是型号能力问题，而是度量能力问题，缺一即无法把设计判据转成验收判据。供应链上唯一贯穿多项的紧张环节是高比能电池、微型射频与热源器件、吸波微粒的批次一致性，均需在研制阶段并行锁定，不能等样机定型后再寻源。
