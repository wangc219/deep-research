## 一、需求分析

### （一）需求概述

#### 1. 背景分析

低空对抗的重心已从"飞得远、炸得准"移到"辨得清、拦得密、压得狠"。敌方在要地外围与城市边缘铺出远距光电红外观瞄、近程拦截发射车与链路压制设备，形成三段式封锁：先用辐射波形与红外特征的统计一致性分辨己方蜂群长机和巡飞弹，再用少量拦截弹和捕手机守住几条主要进近轴，同时以功率压制和协议欺骗切断指挥回链，把成群廉价平台耗在门槛之外。进攻方向同样变硬：百元至千元级旋翼与自杀无人机在己方通道入口外数公里处多方向、多批次释放，断链后按预置航路自主冲刺，只要同时到达的数量压过己方火力通道，就能逼防空单元开火耗弹，或迫使低空运输与侦察平台停飞。

任务链的压力集中在三段。中段是暴露成本失衡：平台一进封锁带就被连续观测，敌以近乎免费的观测换取我方按架次计算的消耗。前段是杀伤闭环挂在链路上，一次压制即可让弹药留在手上打不出去。后段是效果不可判定：拒止条件下无法确认摧毁程度，已分配的火力不能跨单元再调整，形成"不确定摧毁—重复出击"的正反馈。关于断点先后，场景侧与运用侧独立收敛到后段的效果可判定性与再分配，且这一判断不依赖其他未标定变量；另有结论把末段导引列为首位。两者对应不同战斗——一场以末段被欺骗改线为主，一场以打完后无从重排为主——需要补的能力并不相同，故按双序列保留，不合并成单一首位缺口。

#### 2. 需求阐述

第一类需求是断链后仍能闭合的诱压与杀伤。现有诱饵只能被动挨打，判明后不开火即以零成本戳穿；巡飞弹受制于回链。缺的是把欺骗与杀伤合在一处、无需指令即可自主决断的手段，使敌"必须开机识别"成为强制动作，其拦截弹药与发射阵位被一并拉进消耗账。

第二类需求是抗电磁失效的近距拦截。软杀伤要求目标通链并辐射，对断链自主突防者没有着力点；导弹与高炮对廉价密集目标交换比失衡，且己方资产头顶受破片误伤约束不便起爆。缺的是不辐射、不通链、以纯几何关系终止威胁的长时间值守手段，把单次拦截成本压到与敌机体同量级，同时保住辐射纪律和弹药保有量。

第三类需求是可控的观测剥夺。电子压制只对会接收并响应能量的设备有效，敌变频、几何旁路或静默即可规避；隐身、夜航与诱饵只把被发现概率压低一些。缺的是能在敌射击环上截出一段确定断视窗口、并让己方兵力共用该窗口的低代价手段。

第四类需求是把感知成本转嫁给进攻方。我方要看见就必须先开机，开机即成为敌反辐射火力的首选目标，关机则防御窗口塌陷。缺的是以敌群与操作员之间固有的遥控与图传信道为照明、把低空感知层从固定贵重且必须开机的地面节点迁到机动可消耗纯接收节点的能力。

第五类需求是贴地盲区与遮蔽廊道的可利用化。敌把建筑顶板和地面杂波层当作免费的护身符，而同一块遮挡物上方也存在我方可以占据、敌方无法观察的体积。缺的是长期沉入杂波层或静默常驻于遮蔽面、不需要雷达网与指挥链在环仍能自主击发的行动方式。

第六类需求是打断敌再生节奏。敌将机群、发射车与观瞄分散停在纵深，靠数分钟再装填维持连续压制；我方从发现到落地需十几分钟并受弹药基数与授权限制。缺的是不受链路状态影响、可长期悬置且消耗率接近配重价格的地面节点压制手段。六类需求均无法由现役手段的既有组合补足，构成本项目的独立立项依据。

#### 3. 项目画像

本项目的整体作用，是撬开敌低空防御的地基——可探测性契约，而非提高某一发弹药命中率。按机理可分两组。一组改写暴露与观测的交换关系：自带模拟辐射与热信号的诱撞攻击机以与真长机持续同源一致的特征使敌无法不咬，咬住即转入自伤通道，敌识别越准亏损越大；蔽光巡飞弹把遮蔽从伴随手段升为主战行动，单次造出确定盲区并在其中清除观测节点；穿谷攻击机把航路藏进敌雷达无法与地物分辨的回波，在敌自认安全的盲区后方掀掉前沿感知节点；坠袭伏击节点占据遮蔽物顶面，把敌赖以突防的上方净空反转为致命条件。另一组改写成本与感知的付费方：张环拦截机以不辐射的几何捕获替火力通道卸载，敌要穿过就须加强机体、拉大间距，赖以制胜的饱和效应被其自身反制瓦解；猎群截击机把感知能量交由敌方供给，使"关机放弃攻击收益、开机提供定位照明"成为两难；无药坠杆以物理贯穿替代爆炸，无爆源与热特征可供预警，敌无法用拦截弹承担消耗交换，也无法判定来袭是否结束。

作战前景是形成一种不以通信畅通为动用前提的持续压迫：敌为降低单次损失而分散、后撤、静默并转入全自主，每一步都抬高单机成本、压低编组密度与出动节奏，我方以可消耗架次的按天累积换取其按面积摊算的高单价布防。制胜增量因此落在敌火力分配决策被系统性加价，以及被腾出的远程弹与近防通道可转向第二波目标。

判断同时带有失效边界：诱撞与猎群依赖敌仍需辐射和有人值守的拦截闭环，一旦转向纯无源远程火力，撞平台与截击的收益被摊薄；几何捕获与近距拦截以低空亚音速近距目标为限，雨雾、夜暗与强逆光收窄窗口；无源匹配与遮蔽通道以地面基准影像新鲜度和当场风场温湿度为条件，须按现场气象实算停留时间，公开证据不足以支撑的参数只保留区间与置信度。
