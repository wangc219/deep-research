## 三、总体方案

### （一）总体架构

入选各型的共同点是不靠指令链闭合杀伤，因此架构只上提四类真正共享、且会改变任务结果的状态：授权、基准、频谱与通道；蜃楼抱弹诱撞机的信号一致性、伞骨张环机的几何捕获、雾瞳弹的多谱消光、无药坠杆弹的动能贯穿留在单机，不做统一公共层。

**授权预置**：出击前装订目标类别、地理走廊、时段、禁射条件四元组，装备在本地判据内自主放行——诱撞机投放即脱离指挥关系，倒悬伏击节点按预批规则击发，伞骨值守机只有放行与禁射两级权限，坠杆弹凭预置授权边界滑翔待机。授权瓶颈由通信转移到装订时效，装订落后于敌情更新即整体失效。

**基准图层**：崖影穿谷用地形影像、坠杆用点位基准、伏击用遮蔽走廊清单、诱撞用敌辐射源与拦截火力轴分布、蔽光弹用观瞄—发射车通视关系与风场，五者消费同一份带时间戳的敌阵位—影像—气象基准，过期即转为拒打，需统一新鲜度判据与过期降级序列。

**频谱与无源共享**：伞骨值守、无影静默截击、伏击待机、坠杆滑翔共同要求自身零辐射，感知输入来自己方无源侦察与敌机自供的图传遥控信道。诱撞机撞后由同型机带回的开机规律与阵位坐标，直接决定截击编队和纵深砸击的下一批目标；诱撞机冒用己方长机特征等于消耗长机与巡飞弹的身份可信度，特征库须按批次统一轮换。

**通道准入与落点区**：遮蔽幕对敌我同等致盲，幕体几何与可用航段、禁射区、捕获体共坠残骸危险区、伏击净空必须合成同一张准入表，否则蔽光弹自盲、拦截机把捕获体压到友邻低空资产头顶、诱撞机误撞己方蜂群。

**衔接与失效耦合**：敌转入全自主静默突防时，无影猎群失去照明源、诱撞机失去咬合对象，压力退回几何捕获与对地面再装填节点的砸击；敌后撤观瞄与发射阵位、改用廉价假辐射源时，幕体与诱撞同时失去可撞目标。整个架构成立的前提，是敌仍依赖开机观测与露天再装填。
