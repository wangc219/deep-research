## 二、项目画像
### （四）主要战技指标

随浪伏击反蜂群弹的指标，不看单发命中，而看它能否把“贴海过顶”这一下变成整波清账：一是被动水声对过顶波包络的漏判率和虚警率，二是判明到垂直穿浪、再到起爆的时延是否跟得上波速，三是单次设伏对整波进入近炸半径的覆盖份额。验证时应在不同海况、不同波距和不同贴海高度下实测，重点看末端残余数量能否被压到后续防线可接手的水平。

掠波连扫拦截机的核心指标，是每趟能削掉多少波前截面，而不是打掉几架单机：一看单趟截面削减率是否与诱饵比例解耦，二看波前到达与刃带掠穿的对齐误差，三看单位时间趟次能否覆盖敌航渡暴露窗。验证重点是走廊密集波前、掺诱饵和加减速三种工况，确认其是否真能把敌“按时到齐”的计划打散。

驻空扫域电磁灭群巡飞弹的指标，应落在体积清算是否真的比逐架拦截更划算：看覆盖域内失能架数占进入架数的比例，看驻留时段内有效照射占空比，看敌为恢复同等突防能力所追加的加固和增程成本是否被迫上升。试验时必须同时记录对己通信、导航和中继的干扰停照时间，否则只能算出“能打”，算不出“能持续打”。

引浪吞波聚爆诱杀弹的成败，不在爆炸有多猛，而在能不能逼敌为辨真付账：指标应是真假源不可辨度、敌弹群收拢进入起爆包线的比例，以及每轮清算比，也就是敌耗弹数与我诱爆弹组成本的比值。验证时要把敌的反辐射寻源、光学确认和小群试探都放进同一套对抗脚本里，否则很容易把“骗开机”误判成“真清算”。

迎面撒网捕蜂拦截弹的指标，关键是把走廊打成可点数的清点通道：看单段净通过率、网幕成网完整度和在位时长，看补网投入与敌波次间隔是否能形成稳定的封段节奏。验证时要重点看大风、侧风和窄带/宽带两类走廊，确认它究竟是在“清收”，还是只是在风场里消耗网材。

过境层云爆轰断波弹的战技指标，应当直接围绕“时间切片清账”来定：看气溶胶层的连续性和浓度保持时间，看判窗误差能否支撑整层同步起爆，看一次体爆轰能否把走廊内的薄壳机体压到成批解体。验证必须盯住海上风场、湿度和铺层再成形能力，只要层体保持不住，它就会退化成局部爆燃，失去断波价值。

撞线自付近防弹巢的指标，必须抓住“只打真正撞线的末段威胁”这一点：一看末段撞击触发率和误触发率，二看诱饵骗发率是否足够低，三看近距迎面起爆能否在真弹撞节点前完成拦截。验证时要把圈外巡飞、过航干扰和末端俯冲三类目标分开测，重点证明它不是泛化的近防火力，而是专门收拾最后一段撞线动作。
