一、需求分析

（三）建设必要性分析

敌以廉价可消耗无人蜂群为主体，混合同形诱饵与干扰波先耗我火力、再在多波次中续送载荷，其优势建立在"我方逐架拦截成本高于敌单机成本"这一交换率上；低空海杂波又使现役补盲探测与分类在杀伤链起点即不闭合。必要性不在堆叠拦截弹，而在以装备本体把对抗动作改为波、截面、体积与时段级清算，使多波次拒止可恢复、可续接。

1. 作战使用角度

敌借海杂波与视界遮挡贴海航渡，只能密集成波过顶，而密集过顶是无法取消的水声暴露。随浪伏击反蜂群弹把交战界面前移到水下静默段：沿其惯常走廊坐底预置，不辐射、不联网，以被动水声阵判明方位与过顶时刻，垂直穿浪后在波群最密处起爆，用覆盖整个掠海层的破片杆幕一次整波清掉，并把残余数量与到达时刻预判移交外层火力。敌干扰、诱饵删不掉水下判明，爬升即现形、逐次清海即暴露批次，无痕偷渡被改写为走廊消耗。

掠波连扫拦截机改写的是接战粒度：不搜索、不识别、不跟踪单架，只按波级预警切入波前所在高度层，反复以横向展宽的破片刃带掠穿，每趟按整段编队截面结清，单趟成本随自身出动发生，与截面内真弹和诱饵数量无关，故敌加密波次、堆叠诱饵都压不动我方单价。其任务以整链按时到齐为兑现条件，面对不可预知的截面折损只能按最坏情况超量投保，拉稀减速又拉长自身走廊暴露，航渡预算被自己耗尽。

敌为躲远程雷达点名而低空过境，走廊几何已把航迹约束为可预置的窄带，这正是迎面撒网捕蜂拦截弹的布防条件。网弹由气球或运输机成串投放，迎风自展为纯机械柔性网幕，不载电子、不辐射、不爆炸，仅凭迎面气流把整簇前排兜卷缠裹坠地，起一网即一笔可点数取证事件。干扰、诱饵、隐身对网丝与机体的力学接触没有作用对象，敌要穿越只能在爬升现形、拉散毁掉同时到达、逐架加破网载荷自抬单价之间选择。

2. 装备能力提升角度

末端防护的浪费在于弹药被圈外巡飞与廉价诱饵放空。撞线自付近防弹巢在受护节点外缘、顶面及伪装体密布无辐射、无人值守的一次性弹巢，仅以"真正朝节点撞击"的末端航段为开火条件，最近弹巢在数十米内迎面起爆，先敌引爆战斗部或直接击毁机体。诱饵要骗走一枚须做出成本接近真弹的末端撞击动作，假目标放空火力的账不再成立，弹药消耗只随真实末端进入次数增长，防御寿命与敌库存和诱饵总量脱钩。

反辐射蜂群按"诱耗—压制—载荷"波次攻击高价值辐射源，硬防只能按弹逐发消耗。引浪吞波聚爆诱杀弹让诱弹仿形真节点辐射特征贴设于旁、真节点全程静默，敌辨认真假必须使整批弹药向诱源收拢，收拢瞬间诱爆弹以温压破片整簇起爆，成建制销毁该波导引头集群。每轮辨真都先送掉一批已收拢弹药，数量优势被逐次折算为目标确认代价，防空引导与通信节点得以延长静默存活时间，链路保持连续。

末端点防御按通道数并行接战，蜂群并发一旦超过通道即告饱和。过境层云爆轰断波弹判明低空过境时间窗后，在走廊现地铺开覆盖整层高度、延绵数公里的可爆气溶胶层，整层同步过境即触发体爆轰，以超压、火球与卷吸使层内薄壳机体成批解体，毁伤改由层内体积覆盖率决定，不再逐架结算命中率；布设成本固定不随架数增长，诱饵试触耗的是敌自身波次，弃窗乱其节奏、拉散自摊密度。

驻空扫域电磁灭群巡飞弹针对廉价数量压顶的窗口：接到告警即飞抵己方节点上空驻留，向来袭必经空域反复施加宽频高功率微波，凡未逐架加固的飞控、电调与数据链进入覆盖域即被击穿停摆，消耗按驻留防护时段结算、不随来袭架数累加。疏散、变速与混编绕不开必经空域，逐架屏蔽加固线性抬价增重缩程，敌要击落高悬弹体须动用昂贵防区外火力，形成以贵弹换一次性消耗品的反向交换。

3. 领域占位角度

现役反无人手段集中于末端点杀伤与单频段干扰，缺少覆盖近海走廊、低空过境段与节点近旁的廉价再生产能力。上述装备以被动声判明、机械网幕、刃带掠穿、微波体积清除、诱爆反辐射与末端自主触发构成多域占位，使对手的加固、清海、破网与辨真改造逐一变为单机成本与突防节奏的刚性支出，在廉价蜂群这一成本区间不必以昂贵弹药存量与敌拼再生产。

4. 综合效益

该装备族以低成本可再生产品兑换敌整波资源，把精确火力从逐架拦蜂中释放给反导与要地掩护，并以可点数、可判读的战果替代难以确认的软杀伤。建设取舍上，应先以靶试闭合决定装备成立与否的环节——水下被动判明的虚警率、微波对典型无人机的失能阈值、气溶胶层在海上风场下的稳定保持、网幕展开可靠性与弹巢误触发控制——再确定布设密度与接力节奏；一次性预置类装备须同步解决补投补给与民用航运、己方飞行净空界面，防止把体系能力问题误建为弹药数量问题。
