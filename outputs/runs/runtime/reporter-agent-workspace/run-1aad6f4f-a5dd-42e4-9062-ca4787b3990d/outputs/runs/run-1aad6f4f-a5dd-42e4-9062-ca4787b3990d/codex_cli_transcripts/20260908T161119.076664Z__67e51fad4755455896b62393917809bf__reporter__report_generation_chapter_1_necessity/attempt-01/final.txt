一、需求分析

（三）建设必要性分析

#### 1. 作战使用角度
第一岛链面对的不是单架渗透，而是贴海低空、混入诱饵、伴随干扰的成波突防。单纯加拦截弹，仍会被敌用数量和节奏拖入耗弹交换，因此必须把交战界面前推并分层改写。随浪伏击反蜂群弹把判明点压到水下静默段，迫使贴海蜂群为避海杂波而先暴露过顶几何；迎面撒网捕蜂拦截弹则把低空走廊改成可分段清点的物理闸门，使“无痕偷渡”变成逐段受阻；掠波连扫拦截机不再逐架追杀，而是按波前截面反复扫削，直接削掉敌整波到达的结构。三者合用，才能把敌蜂群从“到末端再算账”压回“进走廊就先付代价”。

#### 2. 装备能力提升角度
仅靠一种硬杀伤手段，难以同时解决探测盲区、单次成本和对抗节奏三个断点，因而需要软硬兼具的装备本体。驻空扫域电磁灭群巡飞弹把区域防护从逐架拦截改成驻留时段结算，专打未加固的小型机和伴随干扰机；引浪吞波聚爆诱杀弹则利用真假节点混淆，把敌“辨真”动作变成批量收拢后的一次清算，逼其为每轮确认付出弹药代价；撞线自付近防弹巢把末端防御再压缩到节点外缘，只对真正朝节点撞击的目标自触发，专门补上穿透到最后十几秒的漏口。这样，装备能力提升不是简单变强，而是分别把敌的低空、近节点和末端冲刺三种动作拆开打断。

#### 3. 领域占位角度
外军公开反小型无人机与低成本规模化对抗，已经把关键设施和部队集结点防护推到前沿，但现有体系仍偏向跨域集成、指挥融合和末端补漏，真正能在走廊中段以前重塑交换比的专用装备仍然稀缺。我国若不补齐这条链，就只能在敌波次已成形后被动迎战，领域占位会落在“昂贵拦截守门”这一旧模型上。把水下伏击、走廊扫削、驻空电磁压制、真假诱杀和近防弹巢连成体系，才能在第一岛链形成有层次的反蜂群专用能力带，既占住海上通道，也占住节点近旁的防护空域。

#### 4. 综合效益
这些装备的意义，不止是多几种武器，而是把防御成本曲线改写为敌方先付账、我方按时段或按波结算。它们分别压低末端通道压力、提高单次交换效率、延长节点存活时间，并为远程火力争取同步基准，最终让后续波次失去持续饱和的条件。取舍上，也必须承认边界：水下伏击受海区和声学条件制约，扫削拦截受走廊几何和波前情报制约，电磁巡飞受能源和占空比制约，诱杀弹受真假逼真度制约，近防弹巢受末端撞击条件制约。但正因为各自边界不同，才有必要分层建设，避免把全部压力压在单一拦截弹库上。
