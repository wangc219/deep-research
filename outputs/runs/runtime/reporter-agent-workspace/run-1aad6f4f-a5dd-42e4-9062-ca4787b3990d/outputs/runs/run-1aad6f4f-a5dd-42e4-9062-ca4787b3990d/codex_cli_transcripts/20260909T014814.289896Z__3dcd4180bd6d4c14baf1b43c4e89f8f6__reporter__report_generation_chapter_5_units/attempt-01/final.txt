五、研制基础

（一）参与单位

本项目不宜按通用“总体、分系统、保障”套分工，参与单位应由装备的产品责任和试验责任倒推。现有材料未提供可核实的具体承研单位、既有型号归属或产能证据，因此本栏只提出单位类型及其应交付的证据，不据此指认具体机构。

“随浪伏击反蜂群弹”首先需要具备海洋水声、海床工程和水下武器研制能力的单位，负责坐底结构、被动声学判明、穿浪发射和海况适配；还需海上试验与水下安全保障单位，交付不同底质、潮汐、渔船噪声条件下的漏判率、虚警率、长期值守可靠性和误伤边界证据。其关键接口是布设回收、友邻航迹管制和后端残余波次核验。

“掠波连扫拦截机”应由低空飞行平台、重复出动保障和面杀伤战斗部单位联合承研。平台单位承担按波级提示进入截面、反复掠穿和快速再出动，战斗部单位承担破片刃带成形、展宽及密度保持；飞行试验与鉴定单位须证明不同波前密度、高度和速度下的单趟清削率、趟次节拍和自身生存性。现有材料缺少平台速度、刃带寿命和单位出动成本，不能落实到具体承研主体。

“驻空扫域电磁灭群巡飞弹”需要高功率微波源、天线、电源储能、热管理和巡飞平台单位共同承担，但产品责任应集中于弹载能源与覆盖效应，而非另立软件平台单位。电磁兼容和靶场试验单位负责验证对不同无人机飞控、电调、数据链的失能概率，并交付有效照射占空比、驻留中断时间及对己方通信设备的兼容证据。公开材料未给出弹载功率、作用距离和驻留时长，相关单位只能作为候选类型。

“引浪吞波聚爆诱杀弹”需要射频特征仿真、主动诱饵、近炸引信和温压破片战斗部单位，另需高价值节点运用单位负责真源静默、备份设备管控和轮换开机试验。核心交付不是普通诱饵命中数，而是真假源不可辨度、敌弹群收拢率、单轮清算比及真节点静默存活时间。现无敌方分选算法和对抗试验依据，暂不能确认具体单位归属。

“迎面撒网捕蜂拦截弹”需网材与柔性结构单位、投放平台单位、风洞及实投试验单位配套，重点验证乱流、侧风和不同目标密度下的成网完整度、缠裹率、补网周期及误缠己方目标风险。高空气球或运输机只承担投放接口，不能替代网幕本体研制责任。其落网清点还需沿线光电取证单位交付逐段核销证据。

“过境层云爆轰断波弹”只能先由车辆工程、气溶胶扩散、爆轰安全、气象海试和靶场鉴定等类型单位开展缩比验证，暂不宜直接指定定型承研单位。必须先交付海风条件下成层保持、浓度均匀性、同步起爆、平台生存性和己方航行净空证据；“撞线自付近防弹巢”公开依据更少，只能由近防弹药、被动末端感知、阵地工程和安全鉴定单位承担概念样机论证，真实撞击判定、抗诱饵能力、误触发率、布设寿命及友机安全证据均待补齐。
