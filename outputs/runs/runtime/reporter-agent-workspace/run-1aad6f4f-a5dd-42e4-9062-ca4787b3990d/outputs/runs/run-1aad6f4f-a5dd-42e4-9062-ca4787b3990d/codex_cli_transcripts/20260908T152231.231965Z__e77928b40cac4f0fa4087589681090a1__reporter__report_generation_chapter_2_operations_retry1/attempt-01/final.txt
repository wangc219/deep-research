二、项目画像

（二）作战运用模式

敌蜂群制胜依赖三个可被分别剥夺的前提：借海杂波与视界遮挡实现无痕低空航渡、整链按时到齐形成饱和、以廉价单机拖垮逐架拦截的经济账。各装备的进入条件随其作用的物理界面而变：水下预置伏击只需“密集波次过顶”这一声学事件即可开火，掠波与网幕层要求走廊几何收口，驻空电磁与近防层则须先判明主扇区或真实撞击航段。故本栏按装备机理分别成链，不设统一接战骨架。

1. 作战运用流程

随浪伏击反蜂群弹用于敌贴海航渡段。敌为利用海杂波与视界遮挡必然低空密集成波过顶，整波掠过近海面形成电子手段取消不了的水声暴露，这是本弹唯一且充分的进入条件。平时由渔船与无人潜航器沿惯用走廊标定布设，弹体坐底静默、不建链路；战斗时被动水声阵不追单机定位，只把探测对象收窄为“波”这一声学事件，剔除渔船干扰后判明来向、规模与过顶时刻，起爆决策在弹内闭环。穿浪时机取波群最密处，垂直出水自下而上在掠海层内展开覆盖整层高度的破片杆幕，整波同时落入近炸半径，一次按波清账。走廊上多枚接力设伏，同一波每过一段折损一次，末端残余数量与到达时刻被预减判明，可越过雷达首次建链直接触发岛链远程火力补射。敌爬升脱离即现形于外层火力，先期清海则批次暴露并拖慢突袭节奏，其规避动作都在伏击段外提前兑现。

掠波连扫拦截机以走廊时空截面为作用对象，进入条件是敌在窄带走廊按节拍成波。体系预警只报波前到达时刻、方位、宽度与高度带，不建单机航迹；值班机前出至侧向预置高度，不搜索不识别，按波前法线横向展开破片刃带，掠穿一次即削去整段截面，掉头布带再穿，逐趟把波前削薄到末端可承受密度以下。单趟成本只随自身出动结算，截面内诱饵多少与架数不改变单价；漏网交末端兜底，故无点名截杀环节。敌加密加饵压不动单价，拉稀减速只延长自身暴露、换来更多掠穿趟次，到齐计划随暴露时间增长而破产。

驻空扫域电磁灭群巡飞弹按驻留时段结算。节点指挥所依补盲雷达与电子侦察判明威胁主扇区与到达时序，下达“占位照射”区域授权；弹体在暴露窗前发射爬升，于节点上空预定高度驻留，按禁入时间—高度面以宽频高功率微波反复扫照整个覆盖域，未逐架加固的飞控、电调与数据链进入即被击穿或周期性复位，成批失能掉队。值班员不逐架报伤，改判域内失能比例与覆盖连续性，据此调脉冲刷新率与扫描扇区；驻留体能储到限离场，预备弹接力补位。敌以加固机带队或防区外火力反压时，下调其边际收益，残余移交硬杀伤并迁移驻留点。

引浪吞波聚爆诱杀弹的对抗对象是敌反辐射引导链。真节点全程静默并管住备份与后勤电磁泄漏，仿形天线与辐射节律的诱爆弹成组贴设于其旁主动辐射；敌为辨认真假只能让整批弹药向诱源收拢，收拢即空间聚集、末端机动受限。诱爆弹以距离、高度与数量判据在收拢瞬间整簇起爆，温压超压压垮导引头电子舱、定向破片毁体，一批弹药一次清算。敌“先诱耗、再压制、后送载荷”的次序逐轮失稳：压制波须待辨真后才投送，辨真波已被诱爆消耗，数量优势逐次折算为目标确认代价。波次间隙按在位率补充轮换，穿越诱爆的漏网由邻近硬杀伤兜底。

迎面撒网捕蜂拦截弹的流程起点是“定带”：依远程雷达与前沿监视研判敌规避点名的走廊走向、入口宽度与队形密度，把布撒基线标定在敌进入之前。高空气球或运输机沿基线待机、不载电子设备，网弹成串挂载；判明来波后按风场投弹，网弹迎风自展为横张断面的柔性网幕，前排整簇被兜卷缠裹坠海。每起一网即一笔可复核的清点事件，与入口计数逐段比对得剔除数，据此调下一波投放密度；强风结冰时暂缓作业，爬升拉散的敌机移交远程火力点名，走廊由无痕偷渡变为逐段点收。

过境层云爆轰断波弹把末端海上走廊作为现地成层的战场，流程为判窗、铺层、同步起爆与再铺。岸基舰载雷达与无人值守探测连续跟踪敌出航编组，外推低空过境时间窗与高度带；车载平台沿走廊侧翼铺开覆盖整层高度、横向数公里的气溶胶层，浓度与层段完整性判读达标后守候，蜂群主体整体入层即多点同步起爆，以超压、火球与卷吸使薄壳机体成批解体坠海。先遣诱饵试触只换走一次层，不触发高价弹药；残余交点防御补漏或视下一窗口再铺，两次成层之间的间隙是敌连续小波可钻的弱点。

撞线自付近防弹巢只在真实撞击前数秒介入。弹巢密布于节点外缘、顶面与周边伪装体，无辐射、无人值守，被动感知以“真正朝节点撞击”的末端航段为唯一开火条件，最近弹巢于数十米内迎面起爆，先敌引爆战斗部或直接毁机。圈外巡飞、过航与干扰诱饵不触发不消耗；诱饵要骗一枚弹必须做出成本接近真弹的撞击动作，反辐射压制无源可寻，压波次节律压不垮自主触发，弹药消耗只随真实末端进入次数增长，防御寿命与敌诱饵总量脱钩。

2. 链路闭环分析

各层清账单位不同，串起来恰好砍断蜂群成立的三根支柱。水下伏击层以“波”为单位剥夺无预警过顶，把到达时刻改由我方节奏主导并为远程火力提供同步基准；掠波层以“趟—截面”为单位拆掉集中波前与同时到达；电磁层以“覆盖域×驻留时段”为单位做体积清算，并反复打断蜂群协同数据链，使侦察—导引—毁伤闭环在走廊内被切除；诱爆层以“辨真—收拢”为单位剥夺敌对我辐射节点的确认置信度；网幕层把无痕偷渡改成逐段可对账的剔除；云爆层以“过境时间切片”为单位把末端并发峰压成单次事件，稀缺精确弹只补漏不摊峰；近防弹巢以“真实末端进入”为单位收口，假目标放空火力的账不再成立。

层间移交形成连续因果：伏击段判明的波次时刻直接触发远程火力，网幕段清点出的漏网数反推下一轮设伏与补网密度，电磁层把波前削至末端阈值以下后，加固机与残存者才轮到硬杀伤和弹巢。对手反适应也被互相兜住——爬升现形、清海暴露批次、逐架加固线性抬价缩程、拆散波前自毁同时到达、光学慢速确认绕开收拢，都把自己送回另一层更不利的交换。失效边界同样需要闭合：恶劣海况压低声学置信度时伏击层转作通道拒止；波级预警被大规模诱饵波前诱骗时，掠波与电磁层会在空截面上烧耗趟次与电力；真源静默纪律被破坏或诱源被预清扫时，诱爆层退化为普通诱饵；云爆层仅在走廊收口、可判窗、成层可靠三条件同时成立时有效。这些边界收敛到同一批待闭合判据：浅海过顶声虚警率、刃带再生周期、弹载微波到达能注、诱源逼真度与收拢判定、网幕展开概率、海上成层保持与公里级同步起爆、近防对真末端与误触的区分。判据闭合前各层按限定窗口预置使用，其交换机理方向不随参数改变。
