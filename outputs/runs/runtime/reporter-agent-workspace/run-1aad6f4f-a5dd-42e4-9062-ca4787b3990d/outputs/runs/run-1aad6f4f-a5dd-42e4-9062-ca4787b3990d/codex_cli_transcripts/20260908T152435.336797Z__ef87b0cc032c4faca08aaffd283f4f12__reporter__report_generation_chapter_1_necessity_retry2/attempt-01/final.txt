一、需求分析

（三）建设必要性分析

1. 作战使用角度

敌以低成本蜂群结合防区外火力，对要地、岛礁与机动编队实施多波次饱和突防时，现役“雷达探测—拦截弹按架交换”的接战方式先被数量击穿：蜂群贴海低空借海杂波与视界遮挡航渡，末端火力在数百架次波次下按架耗尽。必要性首先在于改换这种把主动权交给波次规模的运用方式。随浪伏击反蜂群弹把接敌界面从可干扰的电磁域移到只收不发的水声域，坐底弹被动判明“贴海密集过顶”的方位与时刻后垂直穿浪、按波清账，敌保持低空隐蔽即沿走廊逐段折损，爬升规避则现形于远程火力。掠波连扫拦截机不跟踪单架，只按波级到达信息前出，以可再生破片刃带反复掠穿波前，一趟结算整段截面，真弹与诱饵等价清削，加密单波或加码总波数均不抬高我方趟次成本，“整链按时到齐”的计划前提由此破产。对已建立瞄准导引的节点，引浪吞波聚爆诱杀弹令真源静默、仿形诱源主动辐射，敌辨真必须让整批反辐射弹药向诱源收拢而遭聚爆清算；撞线自付近防弹巢仅以“真正朝节点撞击”的末端航段为开火条件，诱饵须做出接近真弹的撞击动作才能骗弹，假目标放空火力的账不再成立。

2. 装备能力提升角度

能力提升的必要性以现役基线的失效点衡量：单发拦截成本与目标数绑定，通道与弹库成为敌数量策略的直接攻击面。迎面撒网捕蜂拦截弹利用走廊对航线的几何约束，在入口预置纯机械网幕，不辐射、不制导、不爆炸，干扰、诱饵与隐身均无作用对象，整簇前排被迎面兜卷缠裹坠落，每网一笔可清点核销，以可再生网材换敌整簇突防机会。驻空扫域电磁灭群巡飞弹驻留节点上空，反复照射必经空域，未逐架加固的飞控、电调与数据链进入即失能，消耗按驻留时段结算；疏散变速逃不出覆盖域，逐架屏蔽则线性抬价、增重、缩程，廉价数量压垮防御的前提失效。过境层云爆轰断波弹判明过境窗后在末端走廊现地铺层，整层同步体爆轰把“逐个命中概率”替换为“层内体积覆盖率”，薄壳机体成批解体，破队单机不再构成饱和。以上与水下的按波清账、空中的按趟扫削和末端的辨真兑付分属水声判明、机械缠裹、电磁耦合、超压体域等不同物理界面，任何单维加量都不能同时抵消，制胜不再依赖单一弹道精度与火力通道。

3. 领域占位角度

现役反蜂群能力集中于电磁域探测与末端动能硬杀伤，海杂波掩护段、瞄准导引段与走廊截面的低成本反制尚属空白；上述装备分属水下静默伏击、走廊截面清削、体积性电磁清算、主动诱爆与被动末端自防等新质类别。先期按层占位，可在第一岛链形成以波次、空间与时间定价的分层消耗格局，并牵引对手转入清海、逐架加固、弃窗改期等高成本反制路径。

4. 综合效益

共同效益是贵重精确弹由“摊峰”转为“补漏”，单次交换成本不再随敌架次线性上升，弹库与再补给压力显著缓解；代价同样真实：一次性预置与无人值守弹药受净空管制、误伤规避、布设补充与阵地先期清除等约束，敌方改以高价值弹药打击驻空与预置单元，或以时间欺骗制造补防间隙，各层窗口均可能被压缩。建设取舍宜以浅海声学本底、微波效应阈值、成层浓度保持与近距引信可靠性等实测为先决门槛，分层验证、按走廊几何与末端兜底成体系编成，避免任何装备脱离自身成立条件单独使用。
