（二）作战运用模式

1. 作战运用流程

敌以低空蜂群借海杂波贴海航渡时，随浪伏击反蜂群弹的进入条件最苛刻也最明确：必须是浅近海走廊内的密集过顶波次。它不争夺电磁探测优势，而是把接敌界面前推到水下静默段，靠被动水声判明方位与时刻后垂直穿浪，在波群最密处自下而上起爆，形成覆盖掠海层的破片杆幕。敌若继续贴海推进，整波会在末端前被削峰清账；若转而爬升，就会在岛链远程火力前现形；若先行清海，则必须为整条走廊付出额外时间和兵力成本。

掠波连扫拦截机的用法不同，它面对的是已经形成波前截面的机群，而不是单架目标。体系预警只需给出到达时窗、走廊位置和高度带，拦截机便前出到波前侧翼，横向展开破片刃带反复掠穿波前，每趟都按整段截面结算。敌把波次加密并不会抬高我方单次成本，真正受损的是敌自己的航渡预算：要么拉稀减速，暴露时间被拉长；要么叠加诱饵，仍无法改变截面被批量清削的结果。

驻空扫域电磁灭群巡飞弹的进入条件，是节点已遭压制、而来袭群仍以低成本未加固机为主。它不临机逐架拦截，而是在节点上空占位驻留，对来袭必经空域反复发射宽频高功率微波脉冲，把飞控、电调和数据链一起拉进失能区。敌若不想被体积性压制覆盖，只能逐架加固，代价是重量、航程和载荷同步恶化；若动用昂贵防区外弹药打掉驻空弹体，则又把交换率推回对我有利的一边。

引浪吞波聚爆诱杀弹只对依赖反辐射辨真的波次成立。真节点全程静默，诱杀弹则仿形辐射、贴设在旁，诱敌先辨真再收拢。敌每完成一次辨真动作，就把整批弹药带进收拢窗口，诱杀弹随即整簇起爆，温压与破片一并清算该波导引头集群。对手若继续按“先诱耗、再压制、后送载荷”推进，实际上是在反复支付目标确认代价；若改用预编程或光学直击，这条链就会中断，装备效能随之明显下降。

迎面撒网捕蜂拦截弹则针对受地形约束的低空窄带过境。它的进入条件不是发现单机，而是确认敌机群被压缩在可预置走廊中。网弹由高空气球或运输机成串投下，迎风自展成大面积纯机械网幕，不靠辐射也不靠爆炸，纯以缠裹和失速把整簇前排兜卷坠地。敌方的干扰、诱饵和隐身在这里都失去作用，只剩三条代价更高的路：爬升现形、拉散自毁饱和，或者逐架加装破网装置。

过境层云爆轰断波弹则把末端拦截的计价单位改成时间切片。它要求我方能提前判明敌低空过境时间窗，并且走廊具备可收口的地形条件。车载平台在末端海上走廊现地铺开可爆气溶胶层，待敌波次整体进入层体积后同步起爆，利用超压、火球与卷吸把层内薄壳机体成批解体。敌要么弃窗改期，要么拉长分散航渡，原先依赖同刻压顶的数量优势就失去表达载体。

撞线自付近防弹巢则是最后一道近距封口手段，进入条件是目标已经逼近受护节点、且末端撞击趋势清晰。它不辐射、不识别，只在真正朝节点撞来的末端航段上被动触发，最近弹巢在数十米内迎面起爆，先敌引爆战斗部或直接击毁机体。圈外巡飞、过航和干扰不触发它，诱饵想骗取一次弹巢，就必须承担接近真弹的末端撞击动作，假目标放空火力的老办法在这里失效。

2. 链路闭环分析

这组装备的共同点，不是把同一种拦截手段换个名字，而是按敌蜂群的几何形态和任务节拍分层接敌：远端用水下伏击和走廊撒网削去密集波前，中段用连扫拦截和扫域电磁把交换率压低，节点外缘再用真假诱爆和近防弹巢堵住最后确认与撞线动作，末端走廊则由层云爆轰把饱和峰整体截断。它们各自处理的不是同一类对象，而是敌在不同距离上的不同作战矛盾。

制胜链条也因此发生了切换。水下伏击解决的是“看不见但必经”的过顶暴露，掠波连扫解决的是“看见波前但不追单机”的通道结算，驻空扫域解决的是“数量压顶但链路脆弱”的体积压制，引浪吞波解决的是“真源与诱源并存”的辨真代价，撒网拦截解决的是“低空窄带密集穿越”的几何封段，层云断波解决的是“同一时间窗并发过多”的时间切片清账，近防弹巢则解决“已经撞线”的最后一米。这些动作连起来，才构成从外沿削峰到节点封口的闭环。

对手的反适应也很清楚：它要么改道绕走廊，要么抬高飞行，要么拉散编组，要么加固单机，要么先清海，要么用预编程、光学直击替代辐射收敛。任何一条都不是免费的，且都会把敌从“低成本、高数量、同刻压顶”的优势位置推开。只要敌的波次仍然需要通过走廊、仍然需要在时间上成批到达，这些装备就分别在不同环节把它的成本抬高、节拍打乱、确认代价放大，直到饱和攻击失去原有的交换基础。若敌改成高度分离、多方位小群异步渗透，或者气象、地形、判窗条件不成立，上述装备就会依次降级，必须由远程火力、末端硬杀伤和其他层接管。
