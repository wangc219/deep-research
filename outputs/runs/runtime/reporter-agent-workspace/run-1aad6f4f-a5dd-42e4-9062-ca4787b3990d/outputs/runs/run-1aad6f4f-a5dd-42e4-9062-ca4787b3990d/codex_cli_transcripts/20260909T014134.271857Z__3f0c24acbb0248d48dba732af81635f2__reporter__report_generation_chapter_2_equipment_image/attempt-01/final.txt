## 二、项目画像

### （一）装备图像概述

| 装备对象 | 核心技术与形成能力 | 部署或进入方式及关键动作 | 作用对象、直接效果与成立边界 |
|---|---|---|---|
| 随浪伏击反蜂群弹 | 以坐底潜藏、被动水声判明和垂直穿浪破片杆幕为核心，不追求逐架识别，而是把交战单位改成贴海密集波次，形成对低空蜂群的水下静默按波清账能力。 | 沿敌惯用浅近海航渡走廊预置，多枚弹体长时静默待机；被动声阵判明波群来向、密度和过顶时刻，在最密段自主穿浪起爆，并由后续弹位接力削减残余波次。 | 作用对象是借海杂波贴海过顶的无人蜂群，直接效果是整波进入近炸破片幕，末端数量和到达时刻被提前压低。其边界是水深、底质、海况、声学虚警率、长期待机可靠性和敌方绕行或提前清海；一旦失效，只能由远程和末端火力接管。 |
| 掠波连扫拦截机 | 以可再生横向破片刃带、稳定占位和快速重复出动为关键，取消搜索、识别和逐机跟踪，把杀伤结算从“弹对单机”改为“趟次对波前截面”，形成不随诱饵数量线性增价的持续清削能力。 | 由波级预警提供走廊位置、波前宽度和到达时段，拦截机侧向切入预定高度，展开刃带掠穿波前，返场或再装填后继续对残余截面重复扫削。 | 作用对象是沿近岸走廊成波进入的真弹与诱饵混合编队，直接效果是削薄波前，使敌整条输送链难以按时齐到。其优势依赖可扫截面、预警对时和刃带再生率；敌改为多方位小群异步渗透，或诱骗波级预警时，能力退化为补充拦截。 |
| 驻空扫域电磁灭群巡飞弹 | 将宽频高功率微波源、天线、储能和热管理装入可驻空弹体，依靠空间能量耦合破坏无人机飞控、电调和数据链，把消耗单位由来袭架数改为覆盖域和驻留时间。 | 预警判明主要来向后，弹体飞至节点与威胁走廊之间的高位驻留点，按扇区反复照射；通过轮换接力维持防护时段，对密集波提高刷新率，对加固或高抗扰目标转交硬杀伤。 | 作用对象是未充分加固的无人机、诱饵和伴随干扰机，直接效果是成批失能、掉队或坠毁，切断蜂群协同并减少拦截弹消耗。其成立取决于到达能量、有效占空比、驻留体生存性和对己电磁兼容；对高抗扰、大型目标、地形遮蔽路线及被反辐射压制的驻留体不构成独立胜势。 |
| 引浪吞波聚爆诱杀弹 | 以高逼真仿形辐射源、真节点静默和收拢触发聚爆为核心，把敌方辨认真假辐射源的动作转化为弹群聚集窗口，形成针对反辐射攻击链的按批清算能力。 | 诱杀弹成组贴设在真节点旁，预先复现节点辐射特征；对抗期间真节点静默、诱源主动辐射，待敌反辐射弹药向诱源收拢后，以温压和破片在近界整簇起爆，波次间隙补充诱弹组。 | 作用对象是依赖辐射源收敛的反辐射无人机、巡飞弹和自杀机群，直接效果是成建制毁伤导引头集群，延长雷达、通信和防空节点的静默存活时间。若敌改用预编程、卫星、光学直击、单机试探或先清扫诱饵，收拢条件消失；诱源逼真度、真源静默完整性和起爆判定仍无实测支撑。 |
| 迎面撒网捕蜂拦截弹 | 以柔性高强网材、成串投放和迎风自展为核心，不依赖制导、辐射或爆炸，利用网丝与旋翼、气动面发生物理缠裹，将低空密集蜂群从逐架拦截改成按段清点。 | 依据岛链地形和雷达盲区确定窄带走廊，由高空气球或运输机在入口及中段成串投放；网弹下降后横张成幕，迎面兜卷前排，并按段补网和核销漏过数量。 | 作用对象是为规避远程点名而压入窄带低空飞行的密集蜂群，直接效果是整簇缠裹坠落，末端饱和峰被拆成可计数漏隙。其效果受走廊宽度、风场、网幕完整度、补网周期和己方净空限制；敌高空绕行、宽正面分散或平台被先期压制时，需要远程火力接续。 |
| 过境层云爆轰断波弹 | 以车载储喷成云、多点同步起爆和时间窗判读为基本技术，把燃料气溶胶层作为临时体积杀伤门，将拦截计价从架次改为过境时间切片，吸收末端并发峰值。 | 由预警链外推敌低空过境窗口，车载平台在走廊侧翼快速铺设覆盖高度层的可爆气溶胶带；确认层体连续且主体进入后同步起爆，残余目标交由点防御补漏。 | 作用对象是时间窗内通过末端走廊的低空薄壳蜂群，直接效果是机体成批解体、编队破散，敌只能弃窗或拉长分散航渡。其成立高度依赖海上风雨条件下的成云保持、浓度均匀度、同步起爆可靠性和走廊必经性；上述关键变量尚无公开试验数据，不宜外推为普遍性拦截手段。 |
| 撞线自付近防弹巢 | 现有底稿仅提出无辐射近距弹巢以“真实撞击航段”触发的概念，尚未给出感知方式、触发判据、战斗部形态、布设安全距离和实际验证事实，暂不能与前述装备形成同等强度的能力判断。 | 可确认的进入方式只有节点外缘、顶面及伪装体周边的无人值守预置；但弹巢如何区分过航、诱饵与真正撞击，如何完成友方净空管理，材料均未闭合。 | 预期作用对象是直扑节点的末端自杀机，预期直接效果为近距迎击并减少诱饵耗弹；但缺少真实末端航迹样本、误触发率、覆盖密度和连续波次补充条件，当前只能保留为待验证概念，不据此作确定性建设结论。 |
