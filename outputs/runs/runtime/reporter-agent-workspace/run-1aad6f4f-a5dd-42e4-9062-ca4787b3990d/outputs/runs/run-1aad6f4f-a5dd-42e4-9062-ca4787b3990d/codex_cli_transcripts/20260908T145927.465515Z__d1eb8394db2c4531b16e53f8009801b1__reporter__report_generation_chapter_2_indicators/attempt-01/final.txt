二、项目画像

（四）主要战技指标

随浪伏击反蜂群弹以“波”为毁伤单元，指标由触发链倒排：坐底值班期对贴海过顶声包络的漏判率与虚警率，前者漏判即放走整波，后者把一次性阵位耗在渔船等干扰源上，须在浅海混响与风浪本底噪声下对贴海编队实测，回答“敢不敢触发”；判明—穿浪—起爆时延对敌波速的裕度，决定单弹实际送入近炸半径的波覆盖份额，以垂直出水与高速波次同步性实弹试验验证；走廊接力后末端残余数量与到达时刻的预测误差，决定远程火力能否按预判时刻接续清账；阵地被发现率另列，衡量敌清海成本能否被逼付。

掠波连扫拦截机不设单发命中率，判据围绕“趟—截面”结算：单趟清削率与截面内架数、真假构成的解耦度，用同密度不同诱饵比的对照波次实测，单趟成本随诱饵占比上升即证伪；刃带有效断面覆盖率乘单位时间趟次对敌航渡暴露窗的覆盖，以及波前到达与扫削时刻的对齐误差，后者直接化为空扫或漏扫。验证以固定走廊实飞标定掠海定高穿越与横展带随距离的破片密度衰减，趟次节拍按走廊长度做能量出勤预算校核。

驻空扫域电磁灭群巡飞弹的指标须能证伪“体积结算”：域结算率即单波进入覆盖域后失能占比，须用到达能注超过该机种抗扰阈值的覆盖体积乘脉冲刷新率解释，而非笼统统计坠毁数；交换率即我方发射与驻留成本对敌恢复同等突防所需加固与数量成本的比值，检验廉价数量模型是否失效；扣除对己电磁兼容停照与反辐射规避间隙后的有效照射占空比，决定体积结算会否退化为稀疏点照。弹载宽频微波有效作用距离与重复频率无公开实测，须自建效应阈值试验，先得能源—占空比折衷曲线再冻结总体。

引浪吞波聚爆诱杀弹从“逼敌辨真付账”反推判据：真假源不可辨度含诱饵对真节点载频、脉内调制与扫描节律的复现一致度及真源静默完成率，备份与后勤电磁泄漏均入考核；敌弹群收拢率指进入诱爆破片带的弹药份额，单轮清算比以敌耗弹数对诱爆弹组成本衡量，要求单枚诱爆弹成本显著低于被诱毁的反辐射弹，否则账目反转；收拢判定时序偏差列试，过早过晚即从整簇清算退化为普通消耗。验证以敌分选算法变化的成组靶试核收拢率。

迎面撒网捕蜂拦截弹按“可点数的清道作业”设定指标：走廊段净通过率与清点核销率，以单段缠坠架次对投放网数比值和单位时段净放行架次度量；补网周期对敌波次间隔之比，大于一则出现持续破口；成网完整度与在位时长决定有效断面覆盖率。无源网幕不可遥测，成网与耗尽只能靠下游光电复核，落网计数滞后时敌可择隙试探而指挥员不知情，此盲区列入考核。先以入口窄带单段投放测展开概率与包裹率，再向全走廊复制。

过境层云爆轰断波弹按时间切片计价，判据落在成层与判窗：判窗误差对成层—守候可用时间的裕度，层未就位或散失即整窗空耗，以时间欺骗与佯动条件下的判窗试验证伪；层内可爆浓度覆盖率把逐发命中概率换成体积覆盖率，连续可爆边界与达下限浓度占比决定整层清账还是局部爆燃；单车铺层面积给出单窗所需车数编成参数。公里级同步起爆可信度与风漂、湿度下浓度保持时间是试验边界，试触波能否诱发提前起爆用对照试验核验。

撞线自付近防弹巢材料最薄，未给感知体制、作用距离与触发门限，只先定判据方向：以“真正朝节点撞击的末端航段”为唯一开火条件，用真实撞击剖面下的应发尽发率对诱饵圈外巡飞、过航波次误发率的对照，检验“诱饵须付接近真弹的撞击成本才能骗弹”；防御寿命与敌库存及诱饵总量脱钩，以诱饵大流量波次的弹耗增量证伪，数据补齐前不给具体点值。

上述指标均以各型装备自身失效环节为界并以对抗试验证伪，缺测变量在数据补齐前不转为确定性指标。
