## 一、需求分析

### （二）国内外现状

#### 1. 国外情况

美国防部2024年12月发布反无人系统战略事实页，将关键设施与部队集结点防护列为优先方向，依托联合反小型无人机办公室与Replicator 2推进规模化低成本对抗，并主张以集中式联合整合治理统筹各部门。类别事实层面，这说明美方已把低成本蜂群对固定节点的饱和冲击当作需要专门装备与专门编制回应的现实威胁，而不只是单兵器材或软件升级问题；但该文本没有给出可材料化的具体案例与参数证据，不能据此外推美方已解决“波次数压垮拦截通道与弹药经济”这一核心矛盾。

政府问责署GAO-25-106454审计提供另一类事实：美军跨域指挥控制仍缺综合框架，互操作与数据融合治理滞后，且扩大集成范围可能反增时延。两则材料并读，美方公开路线把胜负押在“规模化低成本对抗＋集中治理”两端，审计恰指认治理集成端滞后，威胁其在强对抗下跨域协同链的稳定性。可外推边界到此为止：两份文本均未公布掠海/地海杂波掩护下小目标波次的探测概率、拦截通道数与单次成本，国外“现状”的证据只到建设方向与治理缺口层，未到本项目断点所需的装备级事实层。蜂群自主化、抗干扰与逐架加固水平等变量在可引用材料中同样空缺，任何关于软杀伤成立边界或按波次结算可行性的判断都只能停留在推断层。

#### 2. 国内现状（中国）

中国侧在可引用的公开证据中缺位：没有可核验的型号、部署或试验结果，与美方文本不在同一证据水平。能确认的只有任务框架中的前提性判断——现役末端防御通道数、弹药经济性与低空探测覆盖不足——且该判断属假设而非已材料化事实。缺口集中在四类变量：典型蜂群规模下近海噪声与海杂波工况的探测概率和虚警率；末端拦截通道数与单次成本；以波次为单位清点结算的试验口径；以及水下预置、无源拦网、体积性电磁或爆轰清算等方向上国内有无在研项目及成熟度。这些变量缺失，使“空白—满足”的任何档位判断都落不到装备层：未见公开报道不等于不存在，反向同样不成立，两者都只能记为推断边界。

#### 3. 对比小结

两侧公开事实不对称：国外有战略与审计两类可引用文本，国内同口径证据缺位，比较只能单侧建立。就美方材料覆盖范围看，其对策仍在“识别—拦截”的逐点逐波对抗与指控集成优化之内，未出现以波次为探测与结算单位的装备层方案；审计指认的互操作滞后又从反面说明，仅靠扩大集成修补不了探测盲区与单次交换成本断点。机理空间同样不对等：美方文本覆盖的是空中识别拦截与体系集成，国内侧连可对照的装备事实都没有。对国内侧，任何差距或满足结论都必须先补齐上述变量与工况，否则现状比较只能支撑需求方向判断，不足以支撑装备选型。
