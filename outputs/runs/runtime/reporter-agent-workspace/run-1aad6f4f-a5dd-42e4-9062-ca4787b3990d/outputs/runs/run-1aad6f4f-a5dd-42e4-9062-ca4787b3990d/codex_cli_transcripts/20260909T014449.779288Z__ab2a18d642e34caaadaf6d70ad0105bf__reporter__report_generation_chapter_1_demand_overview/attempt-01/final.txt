一、需求分析

（一）需求概述

1. 背景分析

第一岛链沿岸、岛礁、前进机场和舰队节点面临的主要压力，已由少量高价值目标突防转向低成本无人机蜂群与防区外火力叠加的复合饱和攻击。敌方可用侦察无人机建立定位，用干扰机压低我方感知与通信质量，再以巡飞弹、自杀式无人机和其他防区外弹药分波次进入；其关键不只是来袭架数增加，而是把我方探测、识别、交战授权、拦截弹供应和末端补漏同时推入高负荷状态。

现有防护链条的主要矛盾集中在四处：低空小慢目标受海杂波、地形遮挡和低空盲区影响，杀伤链可能尚未建立便已错过窗口；逐架拦截使我方成本随敌数量近似线性增长，难以承受持续波次；敌方反辐射攻击一旦锁定真实节点，雷达、通信和防空火力会被迫在开机与生存之间反复取舍；即使前段削弱蜂群，少量残余仍可能在末端形成局部饱和。因而，需求重点不是简单增加拦截弹数量，而是改变交战的结算单位、暴露界面和时间节奏，使敌方数量优势不能直接转化为我方节点失效。

2. 需求阐述

相关装备首先需要补上“低空密集波次在末端前被削峰”的能力缺口。**随浪伏击反蜂群弹**所对应的需求，是在浅近海固定航渡走廊内，以低暴露方式判明贴海蜂群的波级通过，并在其最密集时实施整体毁伤；缺少的不是单机跟踪精度，而是能够脱离持续电磁照射、依靠水下被动界面提前改变到达数量和时刻的装备手段。

对于沿走廊前出的舰艇编队和要地，需求还包括把拦截对象从单架改为可扫截面。**掠波连扫拦截机**需要以重复出动和横向杀伤带处理波前，使敌加密编组、混入诱饵不能同步抬高我方单次交换成本；当前缺口在于低成本、高频次的截面清削能力，而非更复杂的单目标制导。

节点防护需要另一种按防护时段结算的区域清除手段。**驻空扫域电磁灭群巡飞弹**要解决未加固无人机、诱饵和伴随干扰机大量进入时的弹药消耗问题，以覆盖域内的持续电磁效应削弱敌飞控、电调和数据链；其需求边界是明确区分未加固集群与高抗扰目标，不能把区域软杀伤误当成对所有目标的通用拦截。

面对反辐射无人机和按辐射源收敛的弹药，**引浪吞波聚爆诱杀弹**所需解决的是“真实节点必须开机才能作战”的暴露矛盾。装备应使真假辐射源难以分辨，把敌方辨真动作转化为弹药聚集和批量损失；现有材料缺少对诱源逼真度、敌方分选方式及真节点静默条件的实证支撑，因此需求成立依赖特定攻击链，而不是一般性欺骗口号。

在敌方被迫沿狭窄低空通道密集通过时，**迎面撒网捕蜂拦截弹**需要提供不依赖电磁、引信和逐架识别的物理封段能力。它所弥补的是低空走廊的廉价面清收手段，使每个网段都能形成可核销的通过损失；但走廊宽度、风场和己方航空活动会直接限制其适用范围。

**过境层云爆轰断波弹**针对的是末端最高并发时间片，需求不是扩大点防御通道，而是在可判定的低空过境窗口内形成一次性区域拒止，吸收蜂群峰值后再由点防御处置残余。其关键缺口是把时间窗转化为可靠的整层毁伤机会，开放海空环境下的成层稳定性和同步作用能力尚不能由现有材料确认。

最后，节点近界仍需**撞线自付近防弹巢**这类只在真实末端撞击条件下触发的自主防护。它要避免巡飞、诱骗和远距干扰耗尽近防弹药，把有限火力保留给真正进入撞击航段的目标；但其判断只适用于近界末端，不能替代外层预警和区域削峰。

3. 项目画像

**随浪伏击反蜂群弹**的项目作用，是在要地外沿建立难以被电子侦察直接发现的水下预置清账层。它把敌为隐蔽而选择的贴海密集航渡，转化为必须暴露并接受波级削减的交战几何；敌若爬升，便失去海杂波掩护，若先行清海，则必须付出时间、兵力和暴露代价。其制胜增量是降低末端饱和，而非独立包办全部防空任务；敌绕开预置海区、改走高空或声学判明条件恶化时，作用明显下降。

**掠波连扫拦截机**改变的是舰队和走廊防护的成本函数。它不追求逐架确认，而以可重复的截面清削破坏敌方整链按时到齐的条件；敌增投数量和诱饵不能直接增加我方单趟成本，拉稀或减速又会延长暴露。其前景取决于敌是否仍需集中成波通过可占位走廊，面对多方向、异步小群时只能作为补充力量。

**驻空扫域电磁灭群巡飞弹**承担高价值节点上空的前置区域软杀伤，直接把“拦截弹够不够”转化为“防护时段能否连续覆盖”。它迫使敌在逐架加固、改变高度或投入高价值反制火力之间作出不利选择，适合压制廉价、未加固蜂群；对高抗扰平台、波束外绕行和驻留体被快速摧毁的情形，必须由硬杀伤接替。

**引浪吞波聚爆诱杀弹**的价值在于保护雷达、通信和防空节点的持续静默生存。它不是简单增加诱饵数量，而是让敌方确认真实节点的过程本身产生批量损失，从而压缩“先诱耗、再压制、后投送”的攻击节奏。其作战前景高度依赖敌仍采用反辐射收敛，若改用预编程、卫星或光学直击，制胜关系将迅速减弱。

**迎面撒网捕蜂拦截弹**适合作为低空走廊的物理闸门，把电子干扰、诱饵和隐身从决定性手段中排除，并将蜂群通过量转化为逐段清点结果。其不可替代之处在于低成本、无源和面覆盖，但它必须依托外层火力或地形把敌压入窄带，不能脱离走廊条件单独承担区域防空。

**过境层云爆轰断波弹**瞄准的是敌方同一时间片内的最大并发量，以一次区域作用破坏蜂群的同步到达和相互掩护，保留稀缺点防御处理残余目标。其潜在增量最大，但成立边界也最严格：时间窗、走廊几何、气溶胶层稳定和同步作用任一环节不成立，项目就会退化为低可靠的固定阻隔手段。

**撞线自付近防弹巢**则承担最后数十米的自主保命任务，以真实撞击航段作为触发条件，减少诱饵和过航目标对弹药库存的消耗。它的价值不在扩大防区，而在为节点提供通信受压、指挥中断时仍可工作的最后一道近界屏障；其效能只覆盖确实进入末端撞击路径的目标，对远距投放和非辐射直击方式无能为力。

上述判断目前缺少具体现役部署、敌方典型蜂群规模、抗干扰水平、海区声学背景以及各装备公开成本和试验数据，因而只能确认需求方向、作用边界和比较关系，不能据此直接推出确定的型号参数或交换比。
