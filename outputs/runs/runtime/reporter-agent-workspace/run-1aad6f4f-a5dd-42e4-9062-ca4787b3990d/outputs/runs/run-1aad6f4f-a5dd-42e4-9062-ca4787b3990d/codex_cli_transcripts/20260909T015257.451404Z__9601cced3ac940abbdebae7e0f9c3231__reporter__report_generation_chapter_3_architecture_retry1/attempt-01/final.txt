三、总体方案

（一）总体架构

总体架构不把各装备拼成统一“反无人机平台”，而是围绕蜂群波次、过境走廊、受护节点状态和剩余处置容量建立分层接口。共同上提的只有四类信息：敌波次的来向、时间窗、高度带和密集程度；各防护段的可用状态与安全净空；区域照射、诱爆和自主起爆的授权边界；网材、弹体、驻空单元及补充时间等有限资源。远程监视只需形成波级预警，交战管理负责分配走廊和移交关系，装备本体分别完成自主判明、面域清削或末端触发，避免把单件装备的专属机理虚构成公共能力。

随浪伏击反蜂群弹部署在近海必经段，以被动水声判明贴海密集过顶波次，先于空中防线削减数量并提供到达时刻；其失效取决于海区底质、声学背景和敌方绕行。掠波连扫拦截机面对仍保持集中波前的目标，以截面清削替代逐架交换，需由波级预警提供穿越时机；敌改为多方位小群后，必须转交点防御。驻空扫域电磁灭群巡飞弹负责节点上空的时段封控，以覆盖域内能注作用于未加固无人机，受驻留能源、热管理和反辐射打击约束，不能承担高抗扰目标处置。

引浪吞波聚爆诱杀弹围绕辐射节点工作，利用真节点静默与仿形诱源迫使反辐射弹群收拢，再实施批量清算；其成立依赖敌仍采用辐射收敛，且真节点必须严格静默。迎面撒网捕蜂拦截弹把低空窄走廊变为可分段清点的机械闸门，网幕状态、补投节奏和友方净空是关键接口；走廊展宽、风场失配或敌爬升后需由远程火力接续。过境层云爆轰断波弹承担末端过境峰值削减，依据时间窗成层并按时间切片清账；判窗、成层保持和同步起爆任一失败，均会使其退化为局部补漏手段。撞线自付近防弹巢则只在目标进入真实撞击航段时自主触发，隔离诱饵和圈外飞行对弹药的消耗，承担节点最后安全距离内的无源兜底。

各层衔接采用“外沿按波削峰、中段按域或按段压制、节点旁诱导分流、末端自主补漏”的分工。体系真正的失败耦合不在单装命中率，而在预警时间窗错误、走廊几何失去约束、节点静默纪律破坏、补充资源跟不上波次，或残余目标没有明确移交对象。建设上应优先验证波级判明、跨层授权时延、成效确认和连续补位能力；现有材料尚不足以确定各装备的数量配比、成本交换点及复杂海空环境下的实测效能。
