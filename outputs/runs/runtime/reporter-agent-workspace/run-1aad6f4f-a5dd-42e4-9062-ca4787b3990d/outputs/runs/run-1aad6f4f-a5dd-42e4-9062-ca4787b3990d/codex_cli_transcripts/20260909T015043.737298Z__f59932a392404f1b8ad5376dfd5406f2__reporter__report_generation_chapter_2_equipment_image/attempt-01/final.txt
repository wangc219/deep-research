## 二、项目画像

### （一）装备图像概述

| 装备 | 核心技术与形成能力 | 部署或进入方式 | 关键动作、作用对象与直接效果 |
|---|---|---|---|
| 随浪伏击反蜂群弹 | 以坐底潜藏、被动水声判明和垂直穿浪起爆为核心，不依赖持续联网或主动辐射。它把拦截对象从单架无人机改为贴海密集波次，使水下静默段成为空中防御之外的前置清账层。 | 按敌惯常贴海航渡走廊预先布设，多枚沿航路分段接力，长期低功耗待机。适用于水深、底质和航路稳定的浅近海；敌改道、爬升或先期清海时效能下降。 | 被动声阵判明波群方向、密度和过顶时刻，弹体垂直出水，在掠海高度带形成破片杆幕，直接削减整波数量并提前给出残余到达时刻。敌若爬升则暴露于远程火力，若清海则须先承担走廊暴露和时间成本。 |
| 掠波连扫拦截机 | 采用横向展宽、可重复使用的破片刃带，取消逐架搜索、识别和末端寻的，将杀伤单位改为波前截面。制胜不取决于单发命中率，而取决于单位时间内可完成的掠穿趟次和刃带覆盖密度。 | 依据波级预警进入敌航渡走廊，在预定高度侧向占位，完成掠穿后返转再出动或由同型机接力。只有敌仍被走廊压缩为集中波前时，按截面清削才具有经济性。 | 拦截机横向展开破片带，连续穿过波前所在平面，真弹、诱饵和编队密度均被同等处理，直接降低敌整链按时到齐的概率。敌加密或增加诱饵不能抬高我方单趟成本；改为分散小群后则需由点防御接替。 |
| 驻空扫域电磁灭群巡飞弹 | 将宽频高功率微波源、天线、供电和热管理压缩进可驻空弹体，把清除单位从单架目标改为空域和驻留时段。其能力对象是未充分加固的飞控、电调、通信和导航链路，而非机体本身。 | 在节点与来袭主扇区之间前置升空，按波次轮换驻留并持续刷新照射；需要可靠的来袭方向预判、足够的驻空能量和对己电磁兼容。高抗扰目标或被地形遮蔽的目标须由硬杀伤补充。 | 对进入覆盖域的无人机群实施区域性脉冲照射，使飞控复位、动力失控或数据链中断，直接压低多波次进入数量。敌若逐架屏蔽，会增加重量、成本并压缩航程；若以反辐射手段打击驻空弹，则以较高价值弹药换取消耗性防护单元。 |
| 引浪吞波聚爆诱杀弹 | 以高逼真主动辐射诱饵、真节点静默和收拢触发聚爆构成专属机理。它不与反辐射弹药逐发交换，而是把敌的目标确认动作转化为弹群聚集条件，重点打击依赖辐射源收敛的攻击链。 | 成组贴设在雷达、通信中继或防空节点旁，真节点按计划静默，诱弹仿真其辐射特征。必须保持诱饵在位、信号逼真和真源无泄漏；对预编程、光学或卫星直击目标作用有限。 | 诱弹主动辐射后，敌反辐射弹药为辨认真假向其收拢；进入预定距离和方向后整组起爆，以温压和破片批量毁伤导引头及弹体，直接削弱敌先诱耗、再压制、后送载荷的波次结构。 |
| 迎面撒网捕蜂拦截弹 | 依靠可折叠高强度网材、迎风自展和大面积柔性缠收，绕开搜索、识别和单发制导。其形成的是不受电子干扰影响的低空封段能力，适合把密集低空蜂群变成可分段清点的物理流量。 | 由高空气球或运输机在敌低空走廊入口和中段成串投放，按风场、带宽和波次间隔错时补网。要求敌航路受地形或雷达规避条件约束；宽正面分散、高空绕行和强风环境会削弱效果。 | 网幕迎向来流展开，缠入旋翼和气动面，使前排目标成簇失速坠落；每起网对应一次可复核的清点事件。敌若爬升即暴露给远程火力，若拉散则失去饱和密度，若加装破网装置则单机成本和载荷受到挤压。 |
| 过境层云爆轰断波弹 | 以车载储喷成云、多点同步起爆和时间窗控制为核心，试图用连续气溶胶层覆盖低空过境体积，把拦截计价由架次改为时间切片。其直接能力取决于云层完整性、浓度保持和同步爆轰可靠性。 | 由车载平台在末端海上走廊现地铺层，依据敌低空过境时间窗提前完成布设并短时守候。风、湿度、湍流、敌绕行和判窗误差是主要失效因素，当前缺少跨尺度成层试验证据。 | 当蜂群主体进入可爆层后实施同步体爆轰，以超压、火球和卷吸批量毁伤薄壳无人机，直接打散并发突防峰值。敌可弃窗、改期或拉长分散航渡，但这些动作会削弱协同和饱和效果；层外目标仍须其他防御处置。 |
| 撞线自付近防弹巢 | 由无辐射一次性弹巢、末端航段被动感知和自主近距起爆构成。它不追求识别所有空中目标，只判断目标是否真正朝受护节点撞击，从而把防御弹药消耗与真实末端威胁而非诱饵总量绑定。 | 密布于节点外缘、顶面和伪装阵地周边，平时无人值守、无主动信号，依靠空间布势形成最后数十米的自动防线。适合固定目标近防；弹巢数量、误触发率、友机净空和近距毁伤安全边界仍需实测。 | 当来袭目标进入真实撞击航段，最近弹巢迎面起爆，直接摧毁机体或提前引爆其战斗部。圈外巡飞、过航和电磁诱骗不应触发；敌若要用诱饵骗取弹药，必须把诱饵推进接近真实命中的末端航段，诱饵消耗优势因此被削弱。 |
