五、研制基础

（二）技术基础

现有公开材料能够证明的是反无人系统规模化建设和跨域指挥治理仍在推进，不能证明下列新装备已有定型型号、实战部署或完整供应链。因此，技术基础判断以可继承的通用工程能力为依据，把尚未形成证据闭环的部分列为新增研制或预研缺口，不将概念机理直接等同于装备成熟度。

| 装备 | 可继承基础 | 新增研制与可研缺口 | 试验及供应链条件 |
|---|---|---|---|
| 随浪伏击反蜂群弹 | 可承接水下被动声学、耐压密封、低功耗值守、海底布放和一次性发射机构等基础。 | 新增波级声学判明、垂直出水、掠海高度破片覆盖和长时静默自持；缺少浅海混响、海况噪声、敌机声学样本、长期待机和安全误触数据。 | 需开展不同水深、底质、潮汐和民船噪声条件下的海试；供应链涉及水声传感器、耐压壳体、电池、引信和布放回收平台。可作为优先工程验证方向，但暂不能证明适合常态化布设。 |
| 掠波连扫拦截机 | 可利用无人飞行平台、重复出动、破片载荷和快速再装填等成熟部件。 | 核心新增是按波级提示完成定高、定时掠穿，并形成可重复使用的横向破片覆盖；缺少单趟覆盖率、刃带再生周期、单位时间出动率和强干扰下波前提示可靠性。 | 应先做风场和飞行姿态试验，再进行不同密度、速度、高度蜂群实投；机体、动力、复材和装填设备具备一般工业承接条件，但效能取决于“趟次—截面”数据能否成立。 |
| 驻空扫域电磁灭群巡飞弹 | 可承接巡飞平台、脉冲功率、电源储能、天线和电子兼容等分系统技术。 | 新增工作集中在弹载宽频高功率源小型化、平均功率供给、热管理和覆盖域效应判定；缺少有效作用距离、重复频率、目标抗扰阈值、驻留时长及反辐射生存数据。 | 需以电子设备靶标台架、外场照射和载机驻留试验逐级验证；射频源、储能器件、天线、散热材料可形成供应基础，但对己电磁兼容和持续占空比是总体收敛的硬约束。 |
| 引浪吞波聚爆诱杀弹 | 可借鉴主动诱饵、可编程辐射源、近炸引信、温压与破片战斗部技术。 | 必须新增高逼真多源辐射复现、真节点静默管理、收拢状态判定和成组起爆控制；公开材料没有诱饵逼真度、敌分选算法、收拢率、成本交换比和节点静默可靠性证据。 | 应先做多类型导引头对抗和成组靶试，验证敌采用反辐射收敛时才有意义；射频器件、天线、引信和战斗部可供研制，但尚不具备直接转入定型的依据。 |
| 迎面撒网捕蜂拦截弹 | 可继承高强度柔性纤维、折叠包装、空投释放、气球滞空和运输机投放等基础。 | 新增难点是乱流中可靠展开、网幕保形、整簇缠裹和连续补投；缺少网材强度、展开概率、有效在位时间、小目标包裹率及友方航空净空条件。 | 适宜从风洞、低速空投和单段实投开始，逐步验证段间接力；纤维材料、包装、投放载体供应条件较好，但高空气球或运输机平台的战场生存性尚无证据支撑。 |
| 过境层云爆轰断波弹 | 可承接车载储运、雾化喷散、燃料空气燃烧、点火控制和越野底盘等通用基础。 | 新增工作涉及开放海上环境的成层保持、浓度均匀性、同步触发和安全隔离；风、湿度、湍流、沉降及诱饵试触后的再铺能力均缺少公开试验，科学可行性不能由原理直接推出。 | 必须先进行缩比扩散、海上成层和同步触发试验，并以严格安全边界评估；车辆、储喷和点火部件可承接，但成层可靠性未闭合前只能列为高风险预研。 |
| 撞线自付近防弹巢 | 可参考被动末端感知、近炸引信、模块化弹药和节点近界防护部件。 | 现有材料没有证明其具备独立成熟技术链；新增关键在于只对真实撞击航段触发、排除过航和诱饵误触，并保证密集布设下的安全隔离。 | 需先用惰性弹和代表性目标开展触发判据、误触发及友方安全试验；由于缺少同类公开样机、成本和可靠性资料，暂不宜作为近期工程化主线。 |

综合看，水下伏击弹和掠波连扫拦截机能够较多继承现有水下装备、无人平台和弹药工程基础，具备先做样机与外场试验的条件；驻空扫域电磁灭群巡飞弹分系统基础较强，但弹载能源、热管理和电磁兼容决定其能否从大型平台能力压缩为消耗性装备。主动诱爆、撒网拦截和云爆断波分别受信号逼真度、气动展开和开放环境成层可靠性制约，应以专项预研和对抗试验为先。撞线自付近防弹巢公开证据最少，当前只能保留为概念储备，不能以统一指标替代成熟度证明。
