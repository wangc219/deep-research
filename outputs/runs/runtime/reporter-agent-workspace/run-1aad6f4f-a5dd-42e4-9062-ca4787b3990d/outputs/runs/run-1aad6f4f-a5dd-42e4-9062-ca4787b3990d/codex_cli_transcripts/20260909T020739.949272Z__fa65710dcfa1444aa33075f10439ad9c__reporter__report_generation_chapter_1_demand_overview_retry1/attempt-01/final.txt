## 一、需求分析

### （一）需求概述

#### 1. 背景分析

第一岛链沿海要地、岛礁和舰队防护节点面临的主要压力，不是单架无人机突破，而是低成本无人蜂群与防区外火力叠加形成的多波次饱和突防。敌方可用侦察型、巡飞型和自杀式无人机混合编组，先以低小慢目标压低我方发现和分类质量，再以数量迫使防御方持续暴露、持续交战，随后由防区外空面火力攻击探测、供能和指挥节点。其目的在于制造多轮消耗，使我方在弹药、通道、能源或恢复时间上的某一环节先行失效，而非单纯追求一次性穿透。

这一态势把传统“发现目标—逐架拦截”的末端防空逻辑推向极限。沿海和岛礁的地海杂波、低空遮蔽会压缩首轮探测窗口；舰队机动和携弹量又限制连续拦截能力；敌方诱饵、干扰和中继节点还会污染目标判定，使授权、处置和战果确认出现延迟。公开审计材料已显示，美军跨域指挥控制在综合框架、互操作和数据融合治理方面仍有缺口，说明单纯扩大信息接入范围并不必然缩短决策时间，甚至可能增加交战迟滞。由此，反蜂群建设的核心矛盾是如何保持发现、判断、处置和恢复链的连续性，并使敌方多波次攻击陷入不利的成本交换。

#### 2. 需求阐述

相关装备首先需要在低空、海杂波和多目标同时出现的条件下，稳定提供可交战的目标信息，而不只是给出零散告警。需求重点应落在对低小慢目标的持续探测、分类和轨迹保持能力，使防御方能够区分真实攻击目标、侦察目标和诱饵，避免错误授权消耗高价值拦截资源。凡不能覆盖典型蜂群规模、不能说明虚警和漏检如何影响后续处置的探测装备，均不足以承担杀伤链起点。

其次，需要能够在蜂群进入末端包线前改变其协同质量的物理对抗装备。对依赖通信、中继或外部定位的无人机，应通过压制、欺骗或切断协同，使其失去编队一致性、航路稳定性或目标置信度，直接结果是部分弹药偏离要地和舰艇，或者在进入硬杀伤区前失去有效攻击价值。但这一需求不能被泛化为“有干扰即可”：对于具备较强自主能力、预装任务且不依赖持续链路的目标，软杀伤效果可能明显下降，因此必须把敌蜂群自主化和抗干扰水平作为成立边界。

再次，需要逼真、可部署的诱饵或假目标装备，专门改变敌方侦察确认和瞄准导引关系。其价值不在于替代全部防护，而在于把敌方有限的识别、导引和弹药资源引向无关目标，降低固定节点或机动编队被稳定瞄准的置信度。若敌方具备多源交叉确认能力，或攻击弹药不依赖实时目标链路，诱饵的减压效果将受到限制，不能以单一假目标能力替代硬杀伤和持续探测。

最后，必须保留面向漏网目标和自主化目标的低成本、可连续使用的末端硬杀伤能力。需求不应只看单次命中，而应看单位时间可处理目标数、连续波次中的弹药消耗和再装填恢复。昂贵弹药逐架拦截会在数百架次压力下先耗尽资源；能够以较低边际成本处理低价值目标、把高价值拦截留给真正威胁的装备，才可能把交换关系扭转为敌方攻击越持续、边际收益越低。现有材料未提供我方具体部署、通道数、弹药成本以及敌蜂群自主性和抗干扰水平，因而暂不能为单件装备确定型号、数量或性能点值。

#### 3. 项目画像

本项目应形成面向沿海要地、岛礁和舰队节点的反蜂群战斗装备组合，其研发作用是把防御重点从“增加拦截弹数量”转向“降低敌方有效突防机会并延长我方持续作战时间”。低空多目标探测装备承担的是恢复首段可见性和分类可信度；软杀伤装备承担的是破坏通信协同、航迹稳定和攻击一致性；诱饵装备承担的是降低敌方对真实目标的瞄准置信度；低成本末端装备承担的是处理突破软杀伤后的实质威胁。四类能力的直接增量并不相同，不能用统一指标或同一作战效果概括。

装备研发的制胜机理在于形成分层降耗：让一部分目标在形成有效攻击前失去协同，让另一部分目标把弹药和导引资源消耗在假目标上，再用经济性更合理的末端装备处理少量高威胁目标。这样才能使敌方后续波次的突防成本逐步上升，而我方关键节点仍保有恢复和再战能力。美国国防部公开提出以联合反小型无人机办公室和“复制者2”推进低成本规模化反无人系统建设，也反映出大规模消耗对抗已成为装备发展的现实方向；但跨域整合治理的公开短板表明，项目价值必须由战斗装备本体的探测、发射、布设和杀伤能力承担，不能以软件平台或体系口号替代立项。

项目的作战前景取决于能否在多波次压力下维持关键功能存续，而不是单波次演示中的局部成功。若敌方完全自主、抗干扰并具备多源确认能力，诱骗和通信压制的作用会收窄，需求重心将转向探测连续性、低成本硬杀伤和节点快速恢复；若我方仍依赖昂贵弹药逐架处置、无法确认软杀伤是否生效，或波次间恢复时间长于敌方再次组织时间，则项目难以改变总体交换关系。最终应以公开可复核的蜂群规模、海杂波低空条件、连续波次成本交换和恢复周期压力，检验装备是否真正带来不可替代的防护增量。
