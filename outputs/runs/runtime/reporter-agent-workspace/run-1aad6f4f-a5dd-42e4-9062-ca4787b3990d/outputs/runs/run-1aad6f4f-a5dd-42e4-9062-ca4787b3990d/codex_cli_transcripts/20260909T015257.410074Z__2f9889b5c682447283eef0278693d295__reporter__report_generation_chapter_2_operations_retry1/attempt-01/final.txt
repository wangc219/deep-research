二、项目画像

（二）作战运用模式

1. 作战运用流程

本项目不是把多种反无人装备并列堆放，而是按蜂群航渡几何和突防阶段分工。敌以低空、密集、多波次接近沿海要地、岛礁或舰队节点时，首先由“随浪伏击反蜂群弹”在浅近海预置走廊静默待机。它不依赖对空辐射和逐架跟踪，而是在蜂群贴海成波过顶时以被动水声判明波次，在最密处垂直出水形成破片杆幕，先把敌波次削薄并给出残余数量和到达时刻。敌若改为爬升，将失去海杂波掩护并暴露给远程火力；若先行清海，则必须提前暴露批次并付出时间代价。

进入低空航渡段后，“迎面撒网捕蜂拦截弹”针对被地形和雷达盲区压缩成窄带的蜂群路线，在入口和中段成串投放无源网弹，利用迎面气流展开大面积网幕，把密集前排整体缠落。它的直接战果可以按段清点，漏过目标再交后续火力处理。敌若爬升越网，将从低空隐蔽转为可被雷达和远程火力点名；若加大间隔，则自行破坏同时到达的饱和峰；若为破网逐架加装装置，则单机重量、成本和载荷均受损。

对仍保持集中波前的目标，“掠波连扫拦截机”不再执行逐架搜索和制导拦截，而是在预警给出波前位置、宽度和时间窗后，横向展开破片刃带反复掠穿波前。其战果按“趟次—截面”结算，诱饵数量和单波加密不直接抬高我方单次消耗。敌若拉稀、减速或拆散波前，虽可降低单次损失，却会延长航渡暴露并消耗自身输送时间；只有改成多方向、异步小群渗透，才能使该装备明显降效，但也会失去原有的集中突防能力。

在固定节点外缘，“过境层云爆轰断波弹”用于吸收最危险的过境峰值。岸基或舰载探测判明低空蜂群的时间窗后，车载平台在末端走廊快速铺设覆盖高度层的可爆气溶胶层，待主体整体进入后同步起爆，使薄壳无人机成批解体，迫使残余目标以零散形态进入点防御。敌可以改期、绕行、分散或改变高度，但这些动作会削弱其同步突击效果；该装备的中止条件是时间窗不可靠、风场导致成层失稳或敌不再经过预设走廊。

对于依赖辐射源收敛的反辐射无人机和巡飞弹，“引浪吞波聚爆诱杀弹”与真节点贴设使用。真节点保持静默，诱弹模拟其辐射特征，迫使敌弹群向假源聚集，在收拢瞬间以温压和破片整簇清算。它直接破坏敌“先诱耗、再压制、后投送”的波次顺序；但敌若改用预编程、卫星或光学直击，诱爆条件就不再出现。

“驻空扫域电磁灭群巡飞弹”在节点上空占位，以驻留时段和覆盖体积而非来袭架数结算。对未充分加固的廉价无人机、诱饵和干扰机，宽频高功率微波可造成飞控复位、电调失效或数据链中断，使蜂群在进入末段前成批失能。敌若逐架加强屏蔽，便会承担重量、成本和航程损失；若以高价值火力清除驻空弹，则交换关系转向我方有利。对高抗扰目标、地形遮蔽航路和持续反辐射打击，该装备只承担软杀伤，不宜独立承担节点防御。

末端仍由“撞线自付近防弹巢”封闭漏口。其一次性弹巢布置在节点外缘和顶面附近，仅以目标真正朝节点撞击的末段航迹作为触发条件，圈外巡飞、过航和普通诱饵不消耗弹药；敌若要骗取弹巢，必须作出接近真实攻击的末端动作。因此它不追求远距识别，而是把最后几十米的防护决策下沉到弹巢本体，直接阻止漏网目标撞击关键节点。

2. 链路闭环分析

上述装备共同改变的是蜂群的交战计价单位：水下伏击弹按波次削峰，网弹按走廊段清点，连扫拦截机按波前截面结算，层云爆轰弹按过境时间窗清账，电磁巡飞弹按覆盖域和驻留时段作用，诱爆弹按敌辨真收拢批次兑付，近防弹巢则只对真实末端撞击付出消耗。它们分别避开逐架识别、逐发制导和高价弹药线性消耗造成的瓶颈。

制胜链条由“先期削峰—走廊截断—波前清削—时间窗拒止—节点欺骗—区域失能—末端拒撞”组成。直接战果不是保证每架目标均被确认击落，而是使敌蜂群无法保持原有的密集、同步和低成本突防状态：到达数量下降，抵达时间被拉散，辐射引导链被诱导，软目标在覆盖域内失能，少量残余再交给点防御处理。这样，末端高价拦截弹不再承担整波压力，固定要地和舰队节点获得持续作战时间。

链路闭合的关键不在统一指控软件，而在每件装备能否在通信受压时保持本体动作：伏击弹自主判明过顶，网弹依靠物理接触，连扫机按波级提示掠穿，诱爆弹依靠收拢触发，近防弹巢依靠末端撞击触发。仍需外部信息提供走廊、时间窗和残余移交，但不应让单一通信或授权节点成为全链断点。验证应围绕各自失效条件展开：敌改高空或多路分散时，水下伏击、网幕和截面清削的贡献下降；气象和成层稳定性不满足时，层云装备退出；目标完成抗扰加固时，电磁清算转为辅助；敌不依赖辐射收敛时，聚爆诱杀失去触发基础。只有在多波次压力下证明各层能连续接力、恢复间隔不形成可利用缺口，项目才真正改变第一岛链节点的防护结果。
