二、项目画像

（二）作战运用模式

蜂群威胁的成立条件是“廉价数量”与“整链按时到齐”相耦合：只要拦截按架次计价，敌持续加量就能拖垮防御经济。本项目因此不堆拦截通道，而是沿敌贴海航渡链的水下前段、走廊段与近节点段分层设清算点，每层只对敌必须做出的某一次物理动作结算，层间仅交接残余数量与到达时刻。

1. 作战运用流程

敌为借海杂波与视界遮挡隐蔽航渡，航线只能锁定为贴海低空、密集成波的走廊过顶——密集过顶是电磁手段取消不了的物理暴露，随浪伏击反蜂群弹的运用即以此为判据。平时按水深、底质与潮汐在敌惯用走廊标定布设坐底弹，弹岸不建链路；战斗阶段不追求逐架定位，只以被动水声阵把“波”判成声学事件，估定来向、规模与过顶时刻，在波群最密处垂直穿浪、自下而上起爆破片杆幕，让整层掠海高度同时进入近炸半径。敌每越过一段设伏即折损一次，到达末端的数量与时刻被预减并判明，可直接充当远程火力射击基准；想绕开本层必须预支整条走廊的反潜清海时间，清海批次自身暴露并拖慢突袭节拍。中止边界是敌放弃贴海成波、改走高/中空分散航渡，此后本层只作通道拒止。

走廊段的掠波连扫拦截机把“何时过顶”的判明让给体系，只解决“把波前削到多薄”。值班机按波级通报的到达时刻、走廊位置与宽度高度带前出占位，以“到达提示、侧向布带、掠穿、掉头再穿”循环反复穿越波前平面；每趟成本随自身出动固定，截面内是诱饵还是真弹、有几架都不进入成本函数，敌加密单波或加码总波数压不动我方单价，而拉稀减速拖长暴露、累积被扫趟次，耗尽整链航渡预算，只能按最坏情况超量投保。本层不点名清空，只把波前削薄到末端自防御可承受的密度，漏网者移交末端兜底；若敌拆成多路小群异步渗透，可扫截面消失，趟次结算即退化，须由走廊其余手段与末端接手。

迎面撒网捕蜂拦截弹用的是同一条走廊的另一笔账：按段布网、逐网清点。流程先由地形与雷达盲区标定窄带入口，气球或运输机在带上方成串投弹，网弹迎风自展成无源柔性网幕，以迎面相对气流把整簇前排兜卷缠坠；网丝与旋翼、气动面的力学接触使干扰、诱饵、隐身都没有作用对象，敌只剩爬升现形、拉散自拆同时到达峰、逐架加破网装置抬价三条代价路径。每起一网即一笔可取证清点事件，与入口计数逐段比对即可核销。敌若派试探波找破口，则以多段错时补网与随机化段位回应，时间吞吐由补网周期对敌波次间隔之比决定。

过境层云爆轰断波弹的整层清账以判窗为进入条件：走廊几何可收口、探测能提前外推出过境时间窗与高度带，满足后车载平台才现地铺出覆盖整层高度、绵延数公里的可爆气溶胶层，待波次主体入层即多点同步起爆。体爆轰把逐架命中概率换成层内体积覆盖率，薄壳机体成批解体，计价从架次改为过境时间切片，诱饵试触只耗敌自身波次、换不走固定布设成本。敌只剩弃窗改期或拉长分散：前者重编波次、再次暴露航渡，后者压低单窗密度、使我方恢复逐批从容。层的一次性使两次成层之间的再铺间隙成为固有恢复断点，敌会以连续小波专耗这一节奏。

越过走廊进入近节点段，火力不必再识别“哪一架”，只需识别三种注定发生的动作：进入覆盖域、向辐射源收拢、进入撞击航段。驻空扫域电磁灭群巡飞弹先按威胁主轴占位建屏，再以宽频高功率微波反复照射覆盖域，未逐架加固的飞控、电调与数据链入域即停摆，结算随驻留时段发生，增派架次不抬高我方边际支出，敌疏散、变速、混编皆无效，只能逐架屏蔽加固或动用昂贵防区外火力击落高悬弹体。引浪吞波聚爆诱杀弹对付的是反辐射收敛链：真节点全程静默，仿形诱爆弹组贴设其旁并按真节点载频与节律主动辐射，敌辨真必须让整批弹药向诱源收拢，收拢瞬间温压破片整簇起爆，成建制清掉该波导引头集群，先诱耗、再压制、后送载荷的波次规划随之失去自洽。撞线自付近防弹巢只认末段航迹：节点外缘、顶面与周边伪装体密布无辐射弹巢，以“真正朝节点撞击”为唯一触发，最近弹巢数十米内迎面起爆、先敌引爆战斗部；圈外巡飞与廉价诱饵不触发不消耗，诱饵要骗走一枚先得做出成本接近真弹的撞击动作。三者的值班判断都压缩为波次是否失能、覆盖域是否连续、节点是否存活，不依赖逐架授权。

2. 链路闭环分析

上述各层的闭环能成立，是因为触发判据都取自敌必须兑现的物理动作——过顶、成波、入域、收拢、钻网、撞线都不可用诱饵与干扰提前兑换，故每条链都把“发现—分类—授权—处置”压成“动作触发—本地结算”，绕开了体系授权时延。各层的恢复环节又相互独立：伏击弹靠走廊后端被动声学与雷达哨位清点漏网并修正再布设密度；掠波靠再出动与刃带再生跟上波前节拍；网幕靠沿线光电复核逐网核销，无源网幕不可遥测，计数滞后会让敌在补网间隙试出破口；层云以层完整性判读保证同步起爆可信，再铺周期决定能否接住下一时间窗；电磁层按失能比例调节刷新率与扇区并轮换补位；诱杀弹以距离、高度、数量判据防单发早炸，波次间隙整补诱饵组、恢复真节点静默—短时开机节奏；弹巢自主闭合，恢复全凭物理补充。任一层因判据质量空放时，下游仍按预判的残余数量与时刻接续，单层失效降级为断链而非整体崩溃。

失稳点由此转移到判据质量与自伤边界：水声判明虚警会误爆耗弹、漏判放波；层完整性误判与诱爆早炸会错过清算窗口；网幕与气溶胶层对己方航空需要净空时序避让；电磁照射须约定禁扫方向；真节点静默期间的自身防护要交给弹巢层。待试验闭合的变量集中在各层判据的虚警率与恢复周期——过顶声判明的漏判/虚警率、宽频耦合失效阈值、网幕展开与包裹率、层域保持与同步起爆可信度、真假源不可辨度，实测后才能把各层“触发—结算—恢复”周期换算成对波次间隔与架数的明确门限，并据此排定布设密度、值班轮换与接力节奏。
