一、需求分析

（三）建设必要性分析

1. 作战使用角度

敌蜂群以廉价数量取胜，制胜前提是整链按时到齐：先以诱饵与干扰消耗高价拦截、诱导节点辐射，防区外火力再压制探测与能源节点，使按架识别、按发交换的防御漏过率随投入数量上升，且软杀伤不可确认、恢复不闭合。使用上须把交战对象改为敌无法取消的集体暴露，以预置判据、自主触发取代临机授权。

随浪伏击反蜂群弹把拦截界面推入水下：敌贴海密集成波借杂波航渡，此几何无法以电磁手段抹除；坐底弹不辐射不联网，仅以被动水声阵判明过顶方位与时刻，垂直穿浪起爆，破片杆幕覆盖整个掠海层，整波结算。敌爬升即现形于远程火力，先清海则须预支整条走廊时间并暴露批次。

掠波连扫拦截机、迎面撒网捕蜂拦截弹与过境层云爆轰断波弹沿走廊按各自机理拆峰：连扫机不搜不跟踪单架，以横展破片刃带反复掠穿波前，一趟清削整段截面，单趟成本与真弹诱饵数目无关，敌加量压不动单价，拉稀减速反自耗航渡预算；撒网弹在入口窄带投无源柔性网幕，迎面气流将前排整簇缠裹坠落，干扰诱饵隐身对纯机械接触失效，起一网即一笔可点数核销战果；云爆弹判窗后在末端走廊铺可爆气溶胶层，整层过境即体爆轰，以一次爆轰事件取代逐发命中概率，敌只能弃窗或分散拉长。漏网者分交末端自防御、远程火力与点防御补账。

2. 装备能力提升角度

能力提升的实质是删除单架制导依赖、重构消耗函数。驻空扫域电磁灭群巡飞弹驻留节点上空，反复施放宽频高功率微波，未加固的飞控、电调与数据链在覆盖域内击穿停摆，消耗按驻留时段结算而非来袭架数；疏散变速混编绕不开覆盖体积，逐架屏蔽则抬价增重缩程，敌以贵弹击落弹体反成以贵换廉。引浪吞波聚爆诱杀弹令真节点静默、仿形诱弹成组主动辐射，把抗反辐射从真源硬防变为辨真付账：敌弹为辨真必然收拢，收拢即遭温压破片整簇清算，先诱耗再压制后送载荷的序列每轮先折一批，数量优势被抵扣为目标确认代价。撞线自付近防弹巢只以真正朝节点撞击的末端航段触发，数十米内迎面起爆、先敌引爆战斗部，不识别不辐射；诱饵须以接近真弹的成本撞击才能骗弹，弹耗只随真实末端进入次数增长。

3. 领域占位角度

需求由此从追加拦截弹基数转为补链、强链与替代链：水下静默伏击、可再生截面清削、体积电磁毁伤、辨真聚爆等机理填补现役雷达—制导弹药体制之外的反无人目录，彼此独立又可接力，敌单一反适应难以同时瓦解全链；外军以规模化低成本对抗为战略优先并专设机构，公开审计显示短板恰在跨域集成治理，先以装备本体定义交换规则者占据领域主动权。

4. 综合效益

综合效益支点是成本反转：蜂群越廉价，越须为清海、穿网破网刀具与保整链到齐的超量投保付出反向开支；我方支出转向低边际成本的一次性预置与可再生载荷，不再随敌架数线性增长，要地关键功能持续存续，制导弹药转用于反导掩护。取舍按失效边界分层：敌高/中空绕行、全自主无链或全加固编成时，各机理退场，须保留末端硬杀伤兜底；坐底声学判明、宽频源能注、气溶胶成层与同步起爆、网幕保形均缺公开实测，应以多波次压力推演与成本交换数据证伪后再冻结型号边界。
