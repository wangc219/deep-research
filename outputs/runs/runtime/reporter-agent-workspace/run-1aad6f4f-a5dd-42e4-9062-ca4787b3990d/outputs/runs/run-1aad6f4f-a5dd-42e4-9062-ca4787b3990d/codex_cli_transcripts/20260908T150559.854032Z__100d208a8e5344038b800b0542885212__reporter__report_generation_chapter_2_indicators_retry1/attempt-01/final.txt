## 二、项目画像

### （四）主要战技指标

本节指标逐件由制胜机理与最可能失效环节反推，先对应作战效果再给可证伪判据，不设通用指标组。

随浪伏击反蜂群弹起爆决策在弹内闭环，判别量先是过顶声判明的漏判率与虚警率：漏判等于放行整波、虚警自耗一弹并暴露伏击走廊，二者决定指挥员敢不敢把拦截前推至水下无人值守段；再是判明—穿浪—起爆时延与波速耦合下的单波覆盖率，决定整波实际进入破片杆幕的份额；接力后的末端残余与到达时刻预测误差，检验后段清账是否仍饱和。验证以浅海混响与风浪本底下的贴海编队声样本标定，水声背景与敌典型队形实测缺失，相关量按区间给值。

掠波连扫拦截机的指标验证“解耦”而非命中率：单趟清削率在混入同外形诱饵的高、低密度波前上分别标定，证明加密单波、堆叠诱饵压不动我方单价；掠穿趟次与刃带再生周期对敌航渡暴露窗的覆盖率，决定波级预警受压制后是否出现扫削空档；刃带空间密度对应真弹统计漏过率，按末端自防御可承受密度定标。敌把集中波前拆成多路小群异步渗透时，上述指标退化为逐群交换，即成立边界。

驻空扫域电磁灭群巡飞弹按“覆盖体积×驻留时段”结算，首要失效是能注不足使体积结算退化为点清除，判别量取域结算率：单波进入覆盖域后被失能架数占比，须以超过该机种抗扰阈值的覆盖体积与脉冲刷新率解释，防止点清除冒充体积战果；交换率取我方发射与驻留成本对敌恢复突防追加的加固与数量成本，对应廉价数量前提是否废止；有效照射占空比扣除对己兼容停照与反辐射规避时段，决定驻留体被毁前覆盖是否连续。弹载宽频微波作用距离与重复频率无公开实测，为标定最大缺口。

引浪吞波聚爆诱杀弹以逼敌付“辨真”代价为成立条件：判别量一为真假源不可辨度，由诱饵辐射逼真度与真节点静默完成率（含备份与后勤电磁泄漏）合成，任一不足敌即远距确认真源、全链失效；二为敌弹收拢率，即进入诱爆破片带的弹药占比，对应每轮辨真兑付的敌弹量；三为单轮清算比与真节点静默可用时长，衡量数量优势被抵扣为目标确认代价的速率。验证用成组靶试对抗敌分选算法并实测收拢弹道包线，分选判据未知，决定配弹与补充节奏。

迎面撒网捕蜂拦截弹的指标落在段吞吐而非命中：单段缠坠架次对投放网数之比，使每起一网可与入口计数逐段对账；补网周期对敌波次间隔之比，决定时间吞吐是否被连续波次击穿；成网完整度与在位时长合成断面覆盖率。盲区是网幕无源不可遥测，成网与耗尽状态只能经下游光电复核，计数滞后时敌可趁补网间隙试探破口；验证先在不同风场下收敛展开概率与包裹率，再向全走廊复制。

过境层云爆轰断波弹按过境时间切片计价，第一判别量是判窗—成层—守候时序裕量对敌过境时间窗的匹配度，预测误差大于可用时间即空耗布设；第二是层完整性：风漂、湍流、湿度、沉降下浓度达爆轰下限的连续段比例与公里级同步起爆可靠度，决定体爆轰是否退化为只伤部分机体的局部爆燃；第三是层内体积覆盖率对薄壳机体超压阈值的清账份额与再铺周期对敌波次间隔之比。公里级开放大气成层与同步起爆尚无试验证据，须先于编成论证。

撞线自付近防弹巢以“真正朝节点撞击的末端航段”为唯一开火条件，判别量是触发歧义：对圈外巡飞、过航与廉价诱饵的误触发率须低到不耗弹，诱饵骗取一枚就须做出成本接近真弹的末端撞击动作，假目标放空火力的账即失效；触发距离与近距杀伤半径的匹配决定能否先敌引爆战斗部；弹巢消耗与真实末端进入次数耦合，决定防御寿命是否与敌诱饵总量脱钩。公开材料仅到机理层，被动感知判定机理、触发散布与对节点自身安全余量未公开，指标只定方向不给点值。
