## 一、需求分析

### （一）需求概述

#### 1. 背景分析

外军公开处于无人系统与防区外打击同步扩张的建设期，把低成本可消耗无人机蜂群同空面打击组合为复合饱和样式：蜂群以巡飞、自杀与侦察型混编，借地海杂波与视界遮挡贴海低空成波航渡，配合防区外火力对沿海要地、岛礁与机动编队实施多波次同时到达。威胁的实质不是某一型无人机，而是对防御算账结构的整体颠覆：低空杂波下的漏检漏分使杀伤链在起步段即断；数百架次波次摊薄末端拦截通道；拦截弹按架交换令单次成本远高于敌单机造价，弹药先于敌波次耗尽；敌“先诱耗、再压制、后送载荷”的波次规划又持续消耗我判断与拦截资源。任务链压力在于时间：蜂群由防区外交付、沿走廊成波航渡，过顶窗口被压缩到分钟级，防御若等到末端才拼通道数，已在敌设计中被判负。

#### 2. 需求阐述

从任务链断点反推，需求集中在四个能力缺项，且各缺项对应不同作用段，不能合并成一个体系口号。其一，探测分类断点：雷达在地海杂波与低空盲区对多小慢目标漏检漏分，而敌为隐蔽锁定“贴海、密集、过顶”的固定几何，其成波过顶是唯一无法用电子手段取消的时空暴露，故需要在该航段建立不依赖电磁的水下判明手段，把探测对象从“单架”降为“波次的方位与过顶时刻”。其二，交换经济断点：只要拦截按架结算，防御库存就随敌数量线性消耗，故需要走廊段与末端把计价单位换成截面、趟次或过境时间片，令敌加密、加量、混入诱饵都不进入我方成本函数，同时保留少量末端点杀伤处置漏网。其三，被瞄准置信度断点：敌反辐射链与稳定瞄准链一旦收敛，硬杀伤覆盖不了其弹药规模，需要使真源静默、假源主动辐射，把“辨真”和“真实撞击”变成必然付出一批弹药的确认动作。其四，饱和结构断点：敌计划以整链按时到齐为兑现条件，需要在走廊暴露窗内逐段折损、拆散波峰，使末端面对残余而非饱和。当前证据缺口是：典型蜂群规模在杂波与海况工况下的判明置信度与虚警水平、走廊布设的持续性与安全净空、敌蜂群自主化与抗干扰上限，均无实测或情报支撑。

#### 3. 项目画像

本项目是把反蜂群从“发现—跟踪—逐架拦截”改写为分层断链与降耗的装备体系命题，各件装备以不同作用界面改写交战关系：前沿水下静默伏击把接敌界面前推至敌无法用电子手段取消的水声段，在波群最密处垂直穿浪按波清账并判明到达时刻；走廊内可再生平台把清削成本固定在趟次与整段截面，敌拉稀减速只拉长自身暴露；节点上方驻空单元按防护时段对覆盖域作体积电磁清算，逼敌逐架屏蔽加固而线性抬价；节点近旁真假不可辨的诱爆组把敌每轮辨真折算成一批已收拢弹药；末端走廊以时间片整层体爆轰吸收过顶峰值，稀缺精确火力只补漏、不摊峰。其制胜增量不在增加拦截弹数量，而在使敌数量与诱饵优势失效、把规避代价转为爬升现形、清海暴露批次与加固缩程等暴露动作，逐项落入岛链远程火力与其他层；要地与编队在持续饱和攻击下保持关键功能存续，后续波次被隔离后恢复持续作战能力。立项收束须明确：各装备只在低空成波、走廊收口等几何前提与判窗、环境适应性成立时有效，虚警率、覆盖率与再补给节奏须以试验闭合后定编成，不能以统一指标表替代各自失效边界的验证。
