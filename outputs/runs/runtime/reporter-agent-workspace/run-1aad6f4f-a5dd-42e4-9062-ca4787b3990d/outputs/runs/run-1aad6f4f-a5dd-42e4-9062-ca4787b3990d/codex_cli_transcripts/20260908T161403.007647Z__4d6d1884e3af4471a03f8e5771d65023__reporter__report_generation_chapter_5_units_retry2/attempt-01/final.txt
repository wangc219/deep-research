## 五、研制基础

### （一）参与单位
本项目的参与单位应按装备本体拆分，而不是沿用通用的“总体单位加若干配套”的空泛写法。就“随浪伏击反蜂群弹”而言，承担主责的应是坐底式弹体与战斗部研制单位，负责静默待机、被动水声判明、垂直穿浪与掠海层面毁伤这条主链；与其配套的应是水声换能器、低功耗电源密封、抗海况结构和近炸引信单位，分别解决过顶识别、长期值守、耐压耐腐和时机触发问题。若没有能够证明其完成波次判明、起爆窗口和整波毁伤试验的机构，只能写到机构类型，不能虚构具体承研方。

对“掠波连扫拦截机”，主责单位应落在有人/无人重复出动平台和截面清削战斗部研制单位，关键接口由飞控、载荷展开机构和再装填保障单位承担，证据重点是趟次稳定性、刃带展开宽度和波前截面覆盖率；对“驻空扫域电磁灭群巡飞弹”，主责单位应是宽频高功率微波载荷与驻空平台单位，配套单位应提供电源热控、天线整形和对己电磁兼容验证，若缺少覆盖域内失能概率、驻留时段占空比和反辐射生存性的试验记录，只能保留到单位类型层面。

“引浪吞波聚爆诱杀弹”需要诱饵仿形、辐射编程和聚爆控制三类单位协同，分别对应真假源一致性、收拢判定和成组起爆；“迎面撒网捕蜂拦截弹”则更像材料与空投机构牵头的封段式拦截项目，网材、展开机构和走廊补投保障单位是核心，证据不足时不能点名具体厂所。总体看，公开材料只足以支持机构类型判断：总体研制、战斗部/载荷、平台、传感控制、试验验证和保障维护六类单位必须出现，但当前缺少能把这些类型落实到具体单位名下的公开证据。
