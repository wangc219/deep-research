## 二、项目画像

### （四）主要战技指标

**随浪伏击反蜂群弹。** 该装备的首要指标不是单发命中，而是浅近海杂波条件下对蜂群“过顶事件”的判明质量，因为只有先识别波群来向、密集程度和过顶时刻，垂直穿浪破片幕才能在波峰处形成整波毁伤。应重点考察过顶声学事件的漏判率、虚警率和判明提前量，并将判明至出水、起爆的时延与敌波速、队形宽度联动评价；直接战果用单弹覆盖波次比例和接力设伏后末端残余数量及到达时刻误差表示。验证应在不同水深、底质、风浪和船噪背景下进行连续波次实测，同时检查长期坐底后的再激活可靠性。若高速疏散波次无法留下稳定声包络，或敌绕开预置海区，以上指标即失去作战意义。

**掠波连扫拦截机。** 其作战效果取决于能否把敌波前持续压薄，而非能否锁定某一架目标，因而核心指标应转为单趟有效截面覆盖率、破片刃带在横向和高度方向的完整度，以及单位时间可完成的掠穿趟次。还需测量波前到达预测与拦截机实际穿越时刻的偏差，判断扫削节奏能否覆盖敌在走廊内的暴露窗口；直接战果以整链按时到齐概率下降和末端进入密度是否降至点防御可承受范围表示。验证应设置不同波前宽度、目标密度、速度和诱饵比例，核对单趟清削效果是否确实不随目标真假构成显著变化。若敌改用多方向、异步小群渗透，指标应转入逐群处理，不能继续套用整截面结算。

**驻空扫域电磁灭群巡飞弹。** 它要形成的是连续区域失能，因此指标首先对应覆盖域内无人机的失能比例和协同链中断程度，而不是单次脉冲峰值。应测量有效照射体积、脉冲刷新率与不同机型抗扰阈值的匹配关系，并单列驻留时间内实际有效照射占空比，扣除热管理、对己电磁兼容和反辐射规避造成的停照时间；直接效果则看多个波次进入后节点是否保持可用、末端硬杀伤是否由主战转为补漏。验证需将未加固、局部加固和高抗扰目标分组，在不同高度、扇区和遮蔽条件下测定失能概率，不能用单一目标样本外推蜂群效果。若能量储备不足、驻留体先被摧毁，或敌从主波束外绕行，该装备只能降为局部压制手段。

**引浪吞波聚爆诱杀弹。** 本装备的判别性指标应围绕“敌为辨真而付出多少代价”设置。首先要测真假辐射源的不可辨程度，包括诱源在信号特征、功率变化、扫描节律和空间位置上的仿真一致性，以及真节点静默期间的泄漏率；其次考察敌弹群实际向诱源收拢并进入爆区的比例。直接战果用单轮清算比，即敌损失弹药量相对我方诱爆弹组消耗的关系，结合真节点静默可用时长和轮换开机后的存活率判断节点是否真正获益。验证应采用成组反辐射导引目标，设置单发试探、光学辅助和预清扫等反适应动作，检验诱饵是否仍能迫使敌批量收拢。若敌改用预编程、卫星或光学直击，不能把普通诱饵命中数继续计入本装备战果。

**迎面撒网捕蜂拦截弹。** 其作用对象是走廊断面上的密集低空机群，指标应直接反映网幕能否把饱和流量转化为可清点的坠落事件。重点测量单段缠坠架次、投放网数与净通过架次之间的关系，网幕完整展开概率、有效断面覆盖率、在位时间以及补网周期相对敌波次间隔的裕度。作战效果以走廊单位时间净放行架次和逐段核销率表示，只有能及时发现破口，后续火力才可按漏网数量补射。验证应覆盖侧风、乱流、弱风、降雨和不同目标间距，检查网体展开、保持和缠裹是否连续成立。走廊过宽、敌改走高空或补网速度跟不上流量时，应判定为封段能力下降，而非继续宣称能够整体清除蜂群。

**过境层云爆轰断波弹。** 该装备的成败取决于时间窗内能否形成连续、均匀且可控的杀伤层，因此指标应先服务于层域形成，再服务于毁伤结果。应测量从判窗到完成铺层的时间裕度、云层覆盖高度与纵深、可爆浓度保持时间、层内均匀度以及多点同步触发误差；直接战果看层内薄壳无人机的成批解体率、破队后残余密度和敌弃窗或分散改航比例。验证必须在海上开放环境中开展缩比铺层、风场扰动和连续波次试验，分别确认气溶胶保持、同步起爆和诱饵试触后的再铺能力。现有材料没有这些实测数据，故不能给出具体覆盖距离或毁伤点值；若判窗误差超过成层存续时间，或敌以高度分离绕层，指标体系即退回普通点防御口径。

**撞线自付近防弹巢。** 现有材料仅支持其“无辐射预置、末端自主触发、近界先敌起爆”的功能判断，尚不足以设定确定数值。其指标应围绕真实威胁筛选和弹药节约展开：一是对朝节点撞击航段的判定准确性，以及对过航、巡飞和诱饵目标的拒触率；二是从满足撞线条件到起爆的响应时间和近界毁伤有效性；三是单位弹巢覆盖的节点周界、剩余弹巢状态和连续波次后的可用率。验证应采用不同入射角、速度、假目标和多目标混入条件，分别记录误触发、漏触发、先敌引爆和节点附带损伤。由于缺少传感方式、布设密度、战斗部效应和维护周期数据，本装备只能以区间试验结果作为后续指标依据，不能据概念直接推定其防护寿命或交换比。
