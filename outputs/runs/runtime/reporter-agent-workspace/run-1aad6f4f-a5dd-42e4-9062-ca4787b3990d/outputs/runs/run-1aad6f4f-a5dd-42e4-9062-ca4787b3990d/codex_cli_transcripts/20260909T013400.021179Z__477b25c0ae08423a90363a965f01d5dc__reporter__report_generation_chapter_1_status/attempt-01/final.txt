## 一、需求分析

### （二）国内外现状

#### 1. 国外情况

国外公开资料显示，反无人系统建设已从单一末端拦截转向“发现、主动防御、被动防御、网络压制和快速迭代”并行推进。美国国防部《反无人系统战略》明确把关键设施和部队集结地域作为重点防护对象，并依托联合反小型无人机办公室、战士高级综合组和“复制器2”计划推进规模化建设；其公开表述还特别强调降低无人系统与反制手段之间的成本失衡、扩大试验和快速采购。这一事实与本项目面对的蜂群饱和矛盾直接相关，说明国外建设重点已经从“提高单发拦截概率”转向“在更大数量、更高自主性条件下保持防护有效性”。

但现有国外公开证据主要证明战略方向和建设机制，并未证明本项目所设想的具体装备已经形成成熟战斗力。对于“驻空扫域电磁灭群巡飞弹”，国外公开战略支持区域防护和主动、被动防御方向，却没有提供弹载宽频高功率微波的有效作用距离、驻留时长或对不同无人机的失能概率；因此只能判断其问题牵引关系成立，不能把战略文件当作装备参数证据。对于“随浪伏击反蜂群弹”和“迎面撒网捕蜂拦截弹”，国外资料虽承认低空、隐蔽和数量化无人系统正在改变战场，但未给出水下被动声学按波伏击或走廊无源网幕拦截的公开部署案例，二者仍属于需由本项目自行验证的装备机理。

国外公开建设的另一面是体系整合仍存在明显短板。美国政府问责局2025年报告指出，国防部联合全域指挥控制尚未建立能够统一指导投资、衡量进度的完整框架，各军种和战区仍有相互分立的数据整合工作，数据分级、接口不互通和经验共享不足也会拖慢作战信息流转。[GAO-25-106454](https://files.gao.gov/reports/GAO-25-106454/index.html)这意味着国外并非已经解决蜂群反制的全部问题：即使具备较强的预警、指挥和试验资源，若波级预警不能稳定传递，掠波连扫拦截机的截面掠穿、过境层云爆轰断波弹的判窗成层，以及驻空电磁弹的扇区接力，都可能因信息时延而失去作用窗口。

#### 2. 国内现状（中国）

本轮可用材料没有提供中国现役或在研反蜂群装备的公开型号、实战案例、试验报告、单价和规模化部署数据，因此不能据此认定中国已经具备上述装备，也不能把概念画像写成国内成熟能力。能够作出的判断是：现有公开证据不足以支撑对中国低空探测连续性、末端通道数、软杀伤覆盖率或大规模波次承受能力的点值评价，国内现状应暂按“关键变量缺少可核验材料”处理。

从装备机理看，六类方向的证据缺口并不相同。“随浪伏击反蜂群弹”所缺的是浅海声学背景、敌蜂群过顶声包络和坐底长期值守可靠性，不能以一般水下探测能力替代；“掠波连扫拦截机”所缺的是平台重复出动率、破片刃带展宽和单位时间清削截面，不能用传统拦截弹命中率代替；“驻空扫域电磁灭群巡飞弹”所缺的是弹载能源、热管理、宽频耦合和驻留体抗反辐射能力，公开存在微波压制技术也不等于具备驻空体积清算能力。

“引浪吞波聚爆诱杀弹”依赖高逼真仿形辐射、真节点全程静默和敌弹群收拢，现有材料没有中国诱饵逼真度、敌方分选方式及成组起爆试验事实；“迎面撒网捕蜂拦截弹”依赖低空走廊确实收窄、网幕在风场中完整展开并避免误缠己方目标，不能以普通网捕或反无人机演示外推；“过境层云爆轰断波弹”则缺少开放海上气溶胶层保持、同步起爆和安全净空数据，工程不确定性明显高于前述方向。“撞线自付近防弹巢”目前仅有任务概念，连触发判据、近距毁伤包线和误触发率都没有可引用的中国公开证据，不能列为已形成的国内能力。

#### 3. 对比小结

国外优势主要体现在战略牵引、专项组织、快速采购和公开试验导向，且已明确把成本交换、规模压力和关键节点防护纳入反无人系统建设；其不足是跨军种指挥控制和数据治理仍未完全打通。中国方面，本轮材料无法证明存在对应装备的公开定型或成熟应用，差距首先表现为可核验事实不足，而不是可以直接量化的性能落后。

因此，国外公开事实可作为任务真实性、建设方向和验证方法的参照，不能直接替代六类装备的本体论证。各装备的成立条件必须分别验证：水下伏击看声学判明和按波毁伤，连扫拦截看截面覆盖和再出动节拍，电磁巡飞看能注与驻留连续性，诱杀弹看真假源不可辨和收拢率，撒网拦截看走廊几何与成网可靠性，云爆断波看成层保持与同步触发，近防弹巢则需先补齐基本参数和试验事实。
