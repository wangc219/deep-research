## 二、项目画像

### （一）装备图像概述

| 装备 | 核心技术与形成能力 | 部署或进入方式 | 关键动作、作用对象与直接效果 |
|---|---|---|---|
| 随浪伏击反蜂群弹 | 以坐底潜藏、被动水声判明和垂直穿浪起爆为核心，把交战界面从易受干扰的空中探测段前推到水下静默段。其战斗部形成覆盖掠海高度的破片杆幕，形成按波次而非按单架清除的能力。 | 沿敌惯用贴海航渡走廊由布设平台沉放，负浮力坐底并长时低功耗值守，不依赖持续通信和主动辐射。适用前提是水深、底质和航路允许预置，且敌仍采用低空密集过顶队形。 | 被动水声阵判明蜂群过顶方向和时刻，弹体在波群最密处穿浪，自下而上以破片杆幕作用于整段掠海机群，直接削减波次规模并预先判明残余到达时间。敌若爬升则暴露于远程火力，若先行清海则必须付出时间和兵力代价；敌绕开走廊或改用高空分散航线时效能下降。 |
| 掠波连扫拦截机 | 以横向展宽、可重复再生的破片刃带替代逐机搜索、识别和末端制导，形成按“波前截面—出动趟次”结算的面杀伤能力。其成本不随截面内诱饵和目标数量同步增加。 | 依据预警网提供的波前位置、宽度和到达时段，前出占据走廊侧向空域，按敌波次节拍反复出动。成立条件是敌仍受走廊几何约束，能够形成可被单一刃带横向切过的集中波前。 | 拦截机不追逐单架，而是在波前所在高度横向展开破片刃带并反复掠穿，作用对象是整段编队截面，直接削薄波次并降低敌整链按时到齐的概率。敌加密或增加诱饵不能抬高我方单趟成本；若改为多方向、小群、异步渗透，截面优势消失，需由点防御接管。 |
| 驻空扫域电磁灭群巡飞弹 | 将宽频高功率微波源、定向天线、储能和热管理压缩进可驻空弹体，形成按保护空域和驻留时间结算的非动能清除能力。作用重点是未充分加固无人机的飞控、电调、数据链和导航接收链路。 | 接到威胁主扇区和时间窗提示后，巡飞弹爬升至节点与来袭走廊之间的高位驻留点，按扇区轮换照射并由后续弹体接力。其效能受目标抗扰水平、覆盖几何、能源占空比和驻留体生存性限制。 | 向来袭必经空域反复发射高功率微波脉冲，使进入覆盖域的廉价无人机批量失控、掉链或坠落，直接把逐架拦截改为区域清算。敌若逐架屏蔽加固，将承受重量、成本和航程损失；高空绕行、地形遮蔽或反辐射打击可使本装备转为辅助层，不能替代硬杀伤。 |
| 引浪吞波聚爆诱杀弹 | 以仿形辐射源、真节点静默和收拢触发聚爆为核心，把敌“辨真”动作转化为弹群空间聚集条件。其价值不在逐发拦截，而在诱导反辐射弹药成批进入温压和破片杀伤区。 | 成组贴设于雷达、通信中继或防空节点旁，诱杀弹按真节点特征主动辐射，真节点保持静默并控制备份设备和后勤电磁泄漏。该方案只对依赖辐射收敛的攻击链有效。 | 敌反辐射弹药为确认目标而向诱源收拢，诱杀弹在收拢包线内成组起爆，作用对象是集群导引头和末段弹体，直接清算一批来袭弹药并压缩后续压制窗口。敌改用预编程、卫星或光学直击，或先清扫诱饵阵地时，收拢条件消失，装备退化为普通诱饵。 |
| 迎面撒网捕蜂拦截弹 | 以高强度柔性网材、成串投放和迎风展开为核心，形成不依赖雷达识别、无线电链路和制导精度的机械面拦截能力。网幕直接作用于旋翼、螺旋桨和气动面，适合处理低空密集目标。 | 由高空气球或运输机在低空走廊入口和中段成串投放，按风向、走廊宽度和波次间隔错时补网。成立前提是敌为规避远程探测而被迫沿窄带低空密集通过，且风场允许网幕成形并保持有效断面。 | 网弹迎风展开为大面积网幕，作用于进入断面的蜂群前排，使机体缠网、失速并坠落；每次成网都可由沿线观察点核销，直接把饱和波拆成可清点的漏隙流。敌爬升会暴露于远程火力，拉散会削弱饱和效果，安装破网装置则抬高单机成本；宽正面绕行或恶劣风场会使其失效。 |
| 过境层云爆轰断波弹 | 以车载储喷成云、多点同步起爆和层域体爆轰为核心，把拦截计价从逐架命中改为过境时间切片。其形成的不是单点弹药通道，而是覆盖特定走廊高度带的临时体积杀伤门。 | 由车载平台在末端海上走廊现地喷洒可爆气溶胶，依据预警判定的低空过境时间窗完成成层和守候。该概念的关键边界是海风、湿度、湍流对云层均匀度和存续时间的影响，尚需专门试验验证。 | 当蜂群主体进入可爆层的覆盖体积后，多点引信实施同步体爆轰，以超压、火球和卷吸作用批量毁伤层内薄壳无人机，直接打散并发突防峰值。敌若弃窗或拉长分散航渡，协同密度下降；若改道、分层越过或利用气象破坏成层，装备只能作为固定栅栏，不能独立承担防区封锁。 |
| 撞线自付近防弹巢 | 以无辐射弹巢、被动末端判定和近距自主起爆为核心，把开火条件从“识别目标”收窄为“目标确实朝受护节点撞击”。弹巢可分散布置，减少对持续指挥链和主动传感器的依赖。 | 在节点外缘、顶面和周边伪装体附近密布一次性弹巢，平时无人值守、静默待机；只有进入真实撞击航段的目标才触发最近弹巢。其成立边界取决于末端航迹判定的可靠性、误伤控制和弹巢补充能力，现有材料尚不足以给出确定参数。 | 来袭目标进入真实撞击航段时，最近弹巢迎面起爆，直接摧毁机体或提前引爆其战斗部；作用对象是已经进入节点近防区的真突防目标，圈外巡飞、过航和诱饵不触发、不消耗。敌若要以诱饵骗取弹药，必须完成接近真实撞击的高成本动作，因而难以用廉价假目标耗空防线；其对远距发射和高空投放目标无能为力。 |
