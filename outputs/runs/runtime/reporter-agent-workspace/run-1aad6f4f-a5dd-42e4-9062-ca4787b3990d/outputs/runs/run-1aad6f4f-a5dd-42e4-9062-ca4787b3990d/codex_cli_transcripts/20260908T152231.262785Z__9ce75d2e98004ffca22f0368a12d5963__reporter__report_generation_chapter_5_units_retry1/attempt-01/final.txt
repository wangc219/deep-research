五、研制基础

（一）参与单位

本批装备均在概念论证层，公开材料未给出承研单位归属，以下只按产品责任、关键接口与试验责任给出机构类型并保留缺失证据。随浪伏击反蜂群弹须由水中兵器与海洋水声两类机构联合承接：前者负责坐底筒、垂直穿浪与破片杆幕战斗部，后者对被动阵“过顶波”判明的低虚警负责，接口锁定判明—穿浪时间预算；试验责任在浅海混响与长时坐底自持考核，缺海区水声背景和敌队形样本实测。掠波连扫拦截机整体删除制导机构，参与类型收敛为掠海平台总体与线型破片刃带战斗部设计方，体系预警仅按波级交付走廊位置与到达时段；刃带展宽、掠穿包线与再生周期须飞行试验标定，单趟成本与刃带寿命无公开数值。驻空扫域电磁灭群巡飞弹的责任枢纽在弹载宽频高功率源与驻空供电热控的总体匹配，毁伤判据由电磁效应试验机构建立；它须先实测弹载条件下的有效作用距离与重复频率，该项缺失直接阻塞覆盖扇区与交替密度装订。引浪吞波聚爆诱杀弹须由电子对抗机构按真节点辐射档案制作仿形源、弹药机构承担收拢判定与温压破片起爆链，并与警戒雷达、通信中继等真节点型号总体约定静默—照射接口；成组靶试前，敌分选算法与收拢弹道包线仍是缺失证据。迎面撒网捕蜂拦截弹的承研类型为柔性纤维材料、空投展开与系留气球平台三方，清点取证依托走廊光电复核；乱流下整网展开概率与幕面在位时长无风洞及实投数据，决定其能否固化为常态闸门。过境层云爆轰断波弹需火炸药与车载储喷雾化机构联合成层、多点同步起爆网统一起爆时序，判窗接口落在岸基舰载雷达组网；海上风场下浓度保持与公里级同步点火须以缩比铺层试验和扩散数值仿真闭合，均未见公开。撞线自付近防弹巢主责在被动近炸引信与一次性弹药低成本批量制造，布设伪装归阵地工程机构；验证须证明圈外诱饵与过航目标不触发、真末端撞击在数十米内可靠迎面起爆，虚警与毁伤数据均未公开。
