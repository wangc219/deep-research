## 五、研制基础

### （一）参与单位

本项目不宜按通用“总体、分系统、配套”模板指定承研方，应从装备直接承担的产品责任和验证责任配置参与单位。现有材料未提供具体单位归属、既有型号或在研项目证据，因此本栏仅确定机构类型，不将类型外推为具体承研单位。

“随浪伏击反蜂群弹”的核心责任应由具备水下武器总体、坐底结构、被动水声探测和穿浪发射能力的单位承担，并由海洋环境测量、海上试验和水下安全保障单位配套。其关键接口不是持续数据链，而是水深底质适配、声学判明与战斗部起爆时序；验收证据应包括复杂海况下过顶声识别、长期坐底值守、穿浪姿态和按波毁伤结果。现无公开材料证明具体单位已具备该组合能力，需补充相关试验与工程履历。

“掠波连扫拦截机”需要飞行平台、横向破片刃带和快速再出动保障三类责任主体共同参与。平台单位负责低空定高、波前穿越和返场循环，战斗部单位负责刃带成形、空间覆盖与破片密度，试验单位则应按不同波前宽度和间隔交付“每趟清削率—再生周期—连续趟次”证据，而不是沿用单发命中率。现有资料未给出平台来源、刃带寿命或出动保障单位。

“驻空扫域电磁灭群巡飞弹”应由巡飞平台与宽频高功率微波源、天线、电源储能、热管理和电磁兼容单位联合承担；另需具备无人机抗扰效应试验、空域安全和对己设备防护能力的单位。其证据交付应覆盖覆盖域内能注、重复照射占空比、不同飞控和数据链的失能概率，以及驻留体受反辐射打击后的接力能力。当前没有公开依据确认具体单位或现成系统基础。

“引浪吞波聚爆诱杀弹”所需单位更偏向高逼真辐射源、节点仿真、近炸引信和温压破片战斗部。真节点静默管理必须由被保护节点所属装备保障单位参与，辐射特征逼真度和敌弹收拢率则需由电子对抗试验单位交付对抗数据；现有材料未提供诱饵在位率、敌分选算法或成组起爆试验记录，不能据此指定成熟承研方。

“迎面撒网捕蜂拦截弹”需配置网材与柔性结构单位、投放载具单位、气动展开试验单位及低空飞行安全保障单位。高空气球或运输机只承担投放接口，不能替代网幕产品责任；验收应以乱流、侧风和连续补网条件下的成网完整度、缠裹率、段净通过率和残骸清点证据为准。公开材料不足以证明具体投放平台或网材单位的承接关系。

“过境层云爆轰断波弹”需要车载总体、燃料雾化与扩散、同步起爆、气象环境测量和海上危险品试验单位共同参与。其首要责任不是传统弹体命中，而是开放海域成层保持、时间窗对准和多点同步触发；因此必须由具备海上缩比铺层、扩散测量和爆炸安全资质的机构交付证据。现有资料明确缺少相关公开试验基础，暂不能作定型承研安排。

“撞线自付近防弹巢”目前只有概念性任务描述，适合先由近界被动感知、近炸引信、战斗部和阵地安全防护类型单位开展预研；具体单位、产品成熟度、触发判据和误伤控制证据均未公开。其参与单位配置必须待末端航段判明能力、友邻目标排除和近距起爆试验形成证据后再收敛。
