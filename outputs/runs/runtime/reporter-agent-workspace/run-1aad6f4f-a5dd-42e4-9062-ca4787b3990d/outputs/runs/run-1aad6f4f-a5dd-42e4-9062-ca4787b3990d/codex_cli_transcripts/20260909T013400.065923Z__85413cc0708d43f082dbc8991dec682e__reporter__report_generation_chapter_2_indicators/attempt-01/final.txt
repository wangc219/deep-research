二、项目画像

（四）主要战技指标

随浪伏击反蜂群弹的关键战果，是在海杂波掩护段把密集过顶波次提前削峰，并把残余数量和到达时刻交给后续火力。首要指标应是被动水声对“过顶声包络”的漏判率、虚警率及有效判明提前量，验证须在不同水深、底质、风浪和渔船噪声背景下，以成组低空目标实测；其次考察判明后穿浪至破片杆幕形成的时间闭合度，确认波群实际进入毁伤层的比例。若高速分散波次使时延预算不足，或预置走廊被绕开，指标即失去作战意义。

掠波连扫拦截机不追求单机命中，而要使敌波前在连续趟次中降至末端防御可承受密度。判别性指标应采用单趟对波前截面的有效清削比例、刃带实际展宽与空间密度，以及连续掠穿间的再生和再出动间隔；验证以不同波宽、目标高度和纵向间距的实飞对抗，比较清削率是否不随诱饵数量同步恶化。若敌改成多方向、异步小群，评价重点应转为截面消失后的降效程度，不能继续套用集中波前条件。

驻空扫域电磁灭群巡飞弹的作战效果，不是击落多少架，而是能否在一个防护时段内保持足够覆盖，使未加固无人机的数量优势失效。核心指标应为覆盖域内达到失能阈值的有效体积占比、脉冲刷新后的连续作用时间和实际有效照射占空比，并单独测量驻留体被定位后仍能维持覆盖的时间。验证须用不同抗扰等级、不同高度和多扇区会聚目标开展射频效应试验；若能注不足、兼容停照或驻留体过早被毁，体积清算将退化为零散点状压制。

引浪吞波聚爆诱杀弹的直接价值，在于把敌辨认真假节点的动作转化为整批弹药损失。指标应围绕诱源不可分辨程度、来袭弹群进入聚爆包线的比例，以及每组诱弹实际换取的敌方弹药批量建立，不能只统计坠毁架数。验证需让反辐射导引弹在真实节点静默、诱源成组辐射和多源背景下自主分选，并记录其收拢轨迹与起爆时机。敌改用预编程、光学直击或单枚试探时，批量清算优势会明显收缩。

迎面撒网捕蜂拦截弹的战果取决于低空走廊是否被切成可核销的网段。指标应首先看单位投网形成有效断面的完整度、网幕在位时间与整簇缠坠率，再看补网周期相对于敌波次间隔能否保持连续封段；验证采用不同风向、风速、乱流和蜂群密度进行实投，按入口架次与段末净通过架次逐一对账。走廊变宽、敌改高空或网幕被风场推离预定断面时，单网收益下降，必须由远程火力接管。

过境层云爆轰断波弹所需的效果，是在预定时间片内吸收蜂群并破坏其同时到达条件。决定性指标不是爆炸威力，而是可爆层的连续覆盖率、有效保持时间、波次进入层体积的比例和多点同步起爆误差。验证应先进行海上缩比铺层，测量风、湿度、湍流造成的浓度衰减，再以成组薄壳无人机检验整层毁伤；在判窗误差超过层体保持时间、目标越层绕行或云层无法同步时，不得把原理性效果外推为实战能力。

撞线自付近防弹巢的效能在于只为真正指向节点的末端目标消耗弹药，并拒绝圈外诱饵造成的空耗。应重点测量末端撞击航段判定的误触发率、漏触发率和从判定到近距起爆的时间裕量，同时检验多方向同时撞击时相邻弹巢的独立触发能力。由于材料没有给出感知方式、有效距离、战斗部覆盖和工程成熟度，现阶段只能将上述项目列为待测变量；验证应采用真实末端航迹、诱饵绕飞和多波次饱和试验，不能据概念直接确定点值或交换比。
