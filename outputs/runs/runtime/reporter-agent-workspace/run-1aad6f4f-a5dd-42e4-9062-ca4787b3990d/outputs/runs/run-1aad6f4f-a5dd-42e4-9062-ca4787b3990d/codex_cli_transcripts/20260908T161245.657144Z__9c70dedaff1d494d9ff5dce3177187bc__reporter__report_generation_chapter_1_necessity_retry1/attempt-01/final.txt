**一、需求分析**

**（三）建设必要性分析**

**1. 作战使用角度**
第一岛链面对的不是单架来袭，而是贴海、低空、混编、成波的持续突防，传统做法把火力压在“发现后逐架拦截”，结果往往先输在通道数和交换成本上。随浪伏击反蜂群弹把交战界面前推到水下静默段，专打密集过顶的物理暴露；掠波连扫拦截机不盯单机，只削波前截面，迫使敌波次计划先付走廊暴露代价；迎面撒网捕蜂拦截弹把低空走廊改成按段清点的封段通道；过境层云爆轰断波弹则在末端时间窗上直接“截窗清账”，不让饱和峰完整落到节点前沿；驻空扫域电磁灭群巡飞弹把蜂群从“按架消耗”改成“按驻留时段压制”；引浪吞波聚爆诱杀弹让敌为辨真付账；撞线自付近防弹巢则把最后数十米的冲刺动作变成自担损失。几类装备分别卡住水下、走廊、空域、时间窗和节点边缘，才可能把蜂群作战从连续压顶改写为分段受阻。

**2. 装备能力提升角度**
现有短板不在“有没有弹”，而在能否把敌方数量优势拆成可承受的小块。随浪伏击反蜂群弹提升的是水下静默判明和按波毁伤能力，把电子压制的优势从交战前端剥离出去；掠波连扫拦截机提升的是单位趟次的截面清削能力，使成本不再随诱饵和架数上升；驻空扫域电磁灭群巡飞弹提升的是覆盖域内的持续压制能力，把防空从一次次拦截变成连续结算；引浪吞波聚爆诱杀弹提升的是真假源混淆和目标确认成本，让敌每次辨真都要损失一批弹药；迎面撒网捕蜂拦截弹提升的是无源面拦截与段控能力，适合低空窄带；过境层云爆轰断波弹提升的是末端窗口封堵能力，专门应对蜂群同时压顶；撞线自付近防弹巢提升的是节点最后防线的自触发近距杀伤能力。它们共同补上的，是现役体系最缺的低成本、分层次、可重复、能对付饱和波次的战斗装备本体。

**3. 领域占位角度**
这组装备不是对既有防空弹药的简单补量，而是在第一岛链反蜂群防护中分别占住水下伏击、走廊截面、节点上空、真假欺骗、末端窗口和近距自卫几个关键空白。谁能先占住这些位置，谁就能把对手的蜂群优势压缩成局部漏网问题，而不是体系性失守。若这些位置长期空缺，防御就只能回到高价拦截弹对低价无人机的消耗战，越打越被动；若这些位置被分层补齐，蜂群就很难再依靠同一种战法贯穿全程。

**4. 综合效益**
建设这组装备的综合效益，不只是多几层火力，而是把防护逻辑改成分层定价、分段清账、分窗结算，直接改善关键节点的存续时间和后续反击条件。它能减少高价拦截弹前消耗，保住末端通道，给远程火力和后续处置留出时间，也能降低单一手段失效带来的整体风险。其取舍边界同样清楚：若敌改走高空、散渗、绕行或预先清海，部分装备会降级为补充手段，不能单独包打天下；但在现有低空饱和突防威胁下，这些装备不建，体系就缺少真正能改写交换关系的本体支撑。
