## 二、项目画像

### （一）装备图像概述

| 装备本体与核心技术 | 形成能力及部署/进入方式 | 主要作用对象与改写的作战矛盾 | 关键动作及直接效果 |
|---|---|---|---|
| **随浪伏击反蜂群弹**：以坐底潜藏式发射筒、低功耗被动水声阵、垂直穿浪机构和竖向破片杆幕构成。其关键不是逐架精确定位，而是从过顶声包络中判明蜂群来向、密集程度和过顶时刻。 | 沿浅近海必经低空航渡走廊分段预置，多枚装备按距离接力，平时不辐射、不联网，依靠弹上判明和自主触发完成伏击。它把反蜂群交战界面由易受干扰的空中电磁探测段前推到水下静默段。 | 作用对象是借海杂波和视界遮挡贴海密集航渡的无人蜂群。敌若保持低空密集队形，就必然在水下形成可判明的声学暴露；原本需要雷达持续跟踪、拦截弹逐架消耗的矛盾，转为利用敌波次集中几何进行一次性清账。 | 水声阵在波群最密处触发弹体垂直出水，自下而上在掠海层展开破片杆幕，整波目标同时进入毁伤范围，直接削减末端数量并给出残余波次的到达时刻。敌若爬升则暴露于远程火力，若先反潜清海则须为整条走廊付出时间和兵力成本。其效果受海底底质、水声背景、待机寿命和敌绕行方式限制。 |
| **掠波连扫拦截机**：采用可重复出动的平台和横向展开的破片刃带，不配置逐架搜索、识别和末段寻的设备，杀伤依据是刃带与波前截面的几何交会。 | 依托波级预警获得走廊位置、波前宽度和到达时间，拦截机前出至预设高度，连续掠穿同一波前并返场再装填、再次出动。装备消耗按出动趟次和刃带使用结算，而不是按命中架次结算。 | 主要针对近岸走廊内混入诱饵、可加密单波的蜂群。它解决的是“敌增加目标和诱饵即使我方拦截成本同步增加”的交换困境，把最小打击单元由单架改为波前截面，使诱饵数量不再直接抬高我方单趟成本。 | 平台按波前法线展开破片刃带，横向掠穿并对残余梯队重复扫削，逐趟压低敌有效到达速率，使其整条输送链难以按时到齐。敌拉稀或减速虽能降低单趟损失，却会延长走廊暴露时间并增加被扫次数；若改成多方位、小群异步渗透，单一截面优势下降，须由末端点防御补漏。 |
| **驻空扫域电磁灭群巡飞弹**：将宽频高功率微波源、定向天线、弹载供电与热管理装入一次性驻空平台，依靠反复脉冲使飞控、电调、数据链和导航接收部件复位、失控或停摆。 | 由节点或邻近平台发射，在受护节点上空预定高度驻留，按主攻扇区持续照射并由预备弹轮换接力。其结算单位是覆盖空域和驻留时间，不随进入覆盖域的无人机架数线性增加。 | 作用对象是未充分加固的廉价无人机、诱饵和伴随干扰机，解决传统拦截弹逐架消耗、容易被数量拖垮的矛盾。敌疏散、变速和混编不能消除覆盖效应；逐架屏蔽加固则会增加重量、成本和电源负担，压缩其航程与投载规模。 | 巡飞弹提前占位，在蜂群进入防护空域后反复刷新微波场，使群内目标成批失能，直接切断侦察、协同和导引链，末端硬杀伤只处理漏网或高抗扰目标。其成立依赖有效能注、驻留时间、照射占空比和对己电磁兼容；高抗扰目标、地形遮蔽、反辐射打击或多扇区同时会聚会使其降效。 |
| **引浪吞波聚爆诱杀弹**：以高逼真仿形辐射源、成组贴设结构、收拢状态判定和温压加破片聚爆战斗部为核心。装备价值不在主动压制，而在制造真假节点难以区分的辐射目标集。 | 成组贴设于真实雷达、通信中继或防空火力节点附近，真节点转入静默，诱杀弹按照真实节点的信号特征主动辐射。它不承担远距离追击，而是在节点近界等待敌弹药自行收拢。 | 作用对象是依赖反辐射或按辐射源引导的无人机、巡飞弹和自杀机群，改写“真节点开机才能作战、开机即暴露”的矛盾。敌为确认真源必须向诱源集中，辨真动作本身被转化为可利用的聚集窗口。 | 敌弹群向诱源收拢并进入预定包线后，诱杀弹整簇起爆，温压和破片同时清算导引头及弹体，直接消耗一批来袭弹药并保持真节点静默。敌若改用预编程、卫星或光学直击，或先行清扫诱饵，收拢条件便不出现；真节点静默不彻底、诱源逼真度不足和起爆判定错误，是主要失效点。 |
| **迎面撒网捕蜂拦截弹**：由高空气球或运输机成串投放，网弹无制导、无辐射、无爆炸，依靠迎面气流展开大面积柔性网幕，以网丝缠入旋翼和气动面完成物理拦截。 | 按地形夹出的低空窄带划分入口和中段网段，依据波次间隔、风场和密度错时补网。网幕不依赖自身传感器，落网数量由沿线光电观察逐段核销，形成可再生的封段布设。 | 目标是为规避远程雷达而沿固定低空走廊密集过境的无人蜂群。它绕开探测、识别和逐架火控，解决电子干扰、诱饵和隐身使传统拦截链失效的问题；机械接触不受这些手段影响，且敌密度越高，整簇撞网概率越大。 | 网弹在走廊断面迎风成幕，前排目标被兜卷、缠裹并失速坠落，直接把饱和波次拆成逐段可点数的清收事件。敌爬升会重新暴露于远程火力，拉散会破坏同时到达条件，加装破网装置则抬高单机成本。其边界在于走廊宽度、风场、网幕展开完整度、补网周期以及己方航空器净空管制。 |
| **过境层云爆轰断波弹**：本体是车载储喷成云和同步起爆系统，包括燃料储存、气动雾化铺展、多点起爆网络及时间窗控制装置。其创新在于把燃料空气爆轰由点状弹药作用扩展为走廊时间切片内的层域作用。 | 车载平台在末端咽喉走廊机动进入阵位，依据外部预警判明低空过境时间窗后快速铺设覆盖目标高度带的可爆气溶胶层，确认层体完整后同步触发。 | 主要作用对象是低空、薄壳、密集过境的无人蜂群，针对点防御通道数有限、敌并发量一大便造成拦截饱和的矛盾。它把清算单位从架次改为过境时间片，使同一时间窗内的多架目标共享一个体积毁伤事件。 | 在敌波次主体进入云层后多点同步起爆，以超压、火球和卷吸使层内机体成批解体坠海，直接打断蜂群同时到达的数量峰。敌只能弃用该时间窗或拉长、分散航渡，后者会降低协同密度并回到我方逐批处置条件。该方案高度依赖判窗精度、气溶胶抗风保持、浓度均匀性和同步起爆可靠性，现有材料尚无相应实测数据。 |
| **撞线自付近防弹巢**：概念上是在受护节点外缘、顶面和伪装体周边密布无辐射、无人值守的一次性近距弹巢，以被动感知“真正朝节点撞击”的末端航段为触发条件。 | 弹巢贴近节点固定布设，不依赖持续联网或远程照射；圈外巡飞、过航和干扰目标不满足撞击条件时不触发，只有进入近界撞击航迹的目标才由最近弹巢自主迎击。 | 作用对象是已经突破外层防线、以自杀撞击方式攻击节点的无人机和巡飞弹，所改写的是“诱饵和试探目标可反复消耗近防弹药”的末端矛盾。其防御寿命主要随真实撞击次数变化，而非随敌在外围制造的假目标数量变化。 | 当目标进入近距撞线航段，弹巢在节点外缘迎面起爆，直接引爆战斗部或击毁机体，避免节点承受最后一次撞击。该构想目前缺少触发判据、布设安全距离、抗误触发能力和实际毁伤数据，不能据现有材料给出确定拦截率或成本交换结论；对远距投放、非撞击攻击和高空俯冲目标的适用性也需单独验证。 |
