四、关键技术

（一）关键技术清单与攻关途径

关键技术选取只回答一个问题：断掉“我贵敌廉”交换关系的那个环节，工程上能否成立。六型装备已分别以按波清账、按截面趟次、按驻留时段、按辨真动作、按网段点收、按过境时间切片替代逐架交战，各自删除了对单机的探测—识别—跟踪环节；凡把攻关继续投向制导精度与单发命中率的安排都应剔除，经费应向各型唯一未闭合的物理环节集中。

坐底伏击弹的成败由波级声学判明的虚警—漏判预算决定，破片杆幕威力反而最不是瓶颈。坐底弹一次布设、交战窗口内不可补投，虚警白耗一枚、漏判放走整波，均无补救机会；浅海混响、风浪本底与渔船干扰叠在过顶声包络上，检测门限无法先验给定，判明—穿浪—起爆又须落在波群过顶的秒级时间窗内。主攻应转向低功耗长值守的波事件判明与坐底自持，先取海区水声背景与成波噪声样本、标定漏判率虚警率与布设间距的关系，再定接力编成；两类实测样本现均缺失，只能定机制、不能定判据。

掠波连扫要跨过的关口在刃带成形与掠穿节拍，不在弹道。刃带空间密度不足时真弹会统计性漏过栅栏，趟次再生周期长于敌波次间隔则扫削出现空档，“整链按时到齐”即恢复兑现；而续航与往返趟次限定可清削总截面，掠穿节拍必须按走廊长度做能量—出勤预算才能跟住波前到达率。攻关应标定横展刃带随距离的密度衰减、掠穿定高与时机误差、单趟削截率与再生周期；强对抗下波级预报可用性取数之前，只能确认交换方向，不能给趟数与出动定额。

驻空电磁巡飞弹的主攻顺序由驻空平均功率预算倒排，微波毁伤原理不是问题所在。小型动力驻空发电量有限，脉冲源只能间歇工作，留空时长、可清算覆盖体积与弹径重量三者互斥；宽频覆盖与单脉冲能量在天线上互相牵制，只能向来袭必经高度带整形波束。效应击穿是统计性事件，公开资料仅给定性范围，失效概率须自建试验积累，该缺口决定体积结算是否退化为稀疏点照，也决定自身导引与数据链能否在自辐照下存活。应先以台架与载机试验建立“到达能注—失效概率”判据，再冻结单弹覆盖扇区与群弹交替密度，顺序颠倒会把总体锁死在未验证的能量边界上。

诱杀弹的成败由诱源逼真度与收拢判定共同决定，且逼真度被成本反向约束。现有单频常开、无扫描样式的信标诱饵会被导引头按到达角连续性与脉间特征直接剔除，诱源须做成可编程固态宽频源配小型天线阵成组同步辐射；但它是一次性贴设消耗品，单弹成本须显著低于被诱毁的一枚反辐射弹，逼真度上限由此被单价封死。收拢起爆判定要抗干扰排除诱骗与偶发目标、防单发早炸，布设间距夹在“过近聚爆伤真节点、过远敌可低耗辨真”之间，只能按超压衰减与破片散布实测取值。敌分选算法与收拢弹道包线未知，应先成组靶试取数再锁配弹量。

网弹能否固化为稳定战果取决于迎风展开与段际补网的可靠性，网材等级不是主矛盾。乱流下整网完整展开的可用概率、有效张开时间与网目对小目标的缠绞可靠性三者不闭合，整簇兜捕就落不到可点数战果；幕面须横张走廊截面，带宽超单幅须多幅并排或错时补投，强风把网吹离窄带、弱风无法展网保形，段际补网周期又须短于敌波次间隔。攻关应放在网幕展开动力学与成串投放时序，以风洞与实投试验标定展开概率、有效幅宽与补网节拍，之后才能决定由单段验证向全走廊复制所需数量。

断波弹把工程风险集中在开放大气中的成层保持与千米级同步起爆，风险已被０.５５的科学可行性评分量化。风漂、湍流、湿度与沉降会拆掉可爆浓度梯度，同步起爆不可信则体爆轰退化为局部爆燃；雾滴粒径、挥发速率与海风输运的匹配决定铺层—守候—起爆时窗能否闭合，判窗误差大于层存续时间则层未就位或已散失。单车铺层面积决定单个时间窗所需车数，但须以成层试验取数，诱饵与真机混编时的起爆时机亦无实测。应先以缩比海上铺层与扩散爆轰数值仿真收敛浓度边界与同步误差，再进整车集成，此前机理只在设定窗口内成立。

攻关取舍由断点类型决定启动次序：坐底声学判明、网幕展开属外场试验可闭合的确定性工程问题，宜近期启动；驻空功率—效应与开放成层—同步起爆属能量和统计边界问题，必须先以台架、缩比试验回答反向约束，否则总体不具备冻结条件。各装备关键技术清单与攻关判据汇总如下。
