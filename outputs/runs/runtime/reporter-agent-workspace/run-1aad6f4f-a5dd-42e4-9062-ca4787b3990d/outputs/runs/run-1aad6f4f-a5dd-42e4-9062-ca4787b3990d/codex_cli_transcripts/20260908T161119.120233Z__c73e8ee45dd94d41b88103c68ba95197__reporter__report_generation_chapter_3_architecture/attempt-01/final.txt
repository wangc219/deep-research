三、总体方案
（一）总体架构
总体架构不按单一拦截链堆叠，而是按敌蜂群进入第一岛链的路径分层接力：海下浅近海通道由随浪伏击反蜂群弹先削贴海密集过顶波次；低空走廊由迎面撒网捕蜂拦截弹和掠波连扫拦截机清削波前截面，把“逐架交换”改成“按段、按趟结算”；节点上空由驻空扫域电磁灭群巡飞弹压制未加固机群与伴随诱饵；对依赖辐射收敛的反辐射批次，由引浪吞波聚爆诱杀弹在真源静默前提下诱聚清算；末端残余峰值再由过境层云爆轰断波弹一次压平。各层共享的只是一组共同状态、权限、资源和接口，即波级预警、走廊坐标、空海净空、驻留/投放窗口、补位节奏、战果核销与友邻通报，不共享单件装备专属机理。体系分工是前层负责削峰与断链，后层负责补漏与兜底，任何一层失效都会把密度和时窗推向下一层，故必须保留远程火力和末端硬杀伤的接管余量，并用补网、补层、轮驻维持封控不断链。
