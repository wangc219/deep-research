## 一、需求分析

### （三）建设必要性分析

#### 1. 作战使用角度

第一岛链沿海、岛礁和舰艇编队面临的核心矛盾，不是单个无人机难以击落，而是低成本蜂群与防区外火力叠加后，使我方探测、授权、拦截和战果确认在多波次连续压力下逐段失效。因此，建设重点应放在改变交战几何和交换方式，而不能只增加逐架拦截数量。

“随浪伏击反蜂群弹”针对敌蜂群利用海杂波和视界遮挡贴海密集航渡的必经暴露，在浅近海航路预置坐底弹体，以被动水声判明波群过顶时刻，垂直穿浪并在掠海高度形成破片杆幕，按整波削减目标。它把原本依赖雷达持续跟踪的空中拦截，前移为水下静默伏击；敌若爬升便暴露于远程火力，若先行清海则必须提前暴露并牺牲突袭节奏。该装备只适用于水深、底质和航路满足预置条件，敌改道、分散或声学判明失效时需由其他防线接替。

“掠波连扫拦截机”不以单架为目标，而是在敌形成集中波前时，以横向破片刃带反复掠穿其航渡截面。其直接改变的是成本函数：一次出动按趟次和截面清削结算，不因诱饵数量或单波加密而同步增加我方消耗。敌若拉散、减速或延后波次，便会延长暴露时间并破坏按时齐到的作战计划；但面对多方位、异步小群渗透时，截面优势会明显下降，仍需末端点防御补漏。

“迎面撒网捕蜂拦截弹”利用敌为躲避远程雷达而被迫进入的低空窄走廊，在入口或中段按段布设柔性网幕，依靠迎面相对气流缠裹密集机群。它不依赖辐射、识别和精确制导，能够把蜂群由无形突防转化为可逐段清点的实体损失。敌爬升会进入远程火力区，拉大间隔会自行削弱饱和效果，逐机加装破网装置则抬高成本。其效能受走廊宽度、风场、补网周期和投送平台生存性限制。

#### 2. 装备能力提升角度

“驻空扫域电磁灭群巡飞弹”填补的是蜂群进入末端防区前的区域性软杀伤空档。巡飞弹在节点上空驻留，向来袭必经空域反复施加宽频高功率微波，使未充分加固的飞控、电调和数据链批量失能，防护消耗由来袭架数转为驻留时间和有效照射占空比。敌疏散、变速和混编难以避开覆盖域；若逐架加强屏蔽，则重量、成本和航程同步恶化。其成立前提是弹载能源、热管理、覆盖几何和目标抗扰水平达到可用范围，对高度遮蔽、全面加固或反辐射打击目标必须由硬杀伤接续。

“引浪吞波聚爆诱杀弹”面向依赖辐射源收敛的反辐射无人机和巡飞弹。它在真节点旁仿形辐射，真节点保持静默，诱使敌弹群向假源聚集后以温压和破片成组清算。该动作把敌“辨真”变成自身损耗，使先诱耗、再压制、后送载荷的波次安排难以连续兑现。其能力不适用于预编程、卫星引导或光学直击等非辐射攻击，成败取决于诱源逼真度、真节点静默纪律和诱爆包线。

“过境层云爆轰断波弹”以低空过境时间窗为作战对象，在末端走廊现地形成覆盖高度层的可爆气溶胶层，待蜂群主体进入后同步起爆，按时间切片而非架次完成成片毁伤。其价值在于吸收并发峰值，使残余目标降为点防御可处理的规模；敌改期、拉长队形或绕行，都会削弱原有饱和优势。但气象条件、成层保持、同步起爆和己方净空安全均属关键验证边界，不能在缺少试验数据时把概念效果直接等同于成熟战果。

“撞线自付近防弹巢”承担最后数十米的节点保命任务。弹巢无辐射、无人值守，仅在目标真正沿撞击航线逼近节点时自主触发，圈外巡飞、诱饵和干扰不消耗弹药，从而避免末端防御被假目标提前掏空。它不能解决远距侦察或大范围蜂群，只能作为节点外缘和顶面的最后保险；公开材料不足以确定其触发可靠性、误伤概率和持续补充能力，应以末端真实撞击工况验证。

#### 3. 领域占位角度

上述装备共同推动反蜂群建设从“逐架发现、逐发拦截”转向“按波、按截面、按空域、按时间窗和按真实撞击动作清算”。其中，水下伏击弹和撒网拦截弹前移交战界面，连扫拦截机和层云爆轰弹削减蜂群并发峰值，电磁巡飞弹压低未加固目标的批量突防能力，聚爆诱杀弹改写敌瞄准链，近防弹巢封闭节点最后缺口。其领域价值不在概念叠加，而在为现有点防御提供不可替代的降耗和断链环节。

#### 4. 综合效益

建设必要性最终取决于能否在多波次压力下保持关键节点和编队功能，而非单次拦截数字。建议优先验证水下过顶判明、低空截面清削和电磁覆盖三类直接改变交换关系的装备，再验证成层爆轰、主动诱爆和近防弹巢的工程边界；所有方案均须通过不同走廊几何、波次密度、敌自主性和反适应条件下的压力试验，确认其能否真正降低末端饱和并缩短恢复周期。
