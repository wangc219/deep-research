一、需求分析

（三）建设必要性分析

1. 作战使用角度

面对第一岛链沿海、岛礁和舰队节点遭遇低空无人蜂群与防区外火力复合饱和突袭，建设必要性首先在于改变“发现后逐架拦截”的被动用法。随浪伏击反蜂群弹前置到浅近海航渡走廊，在海杂波遮蔽电磁探测时，以坐底静默和被动水声判明密集波次，在蜂群过顶瞬间垂直出水形成破片拦截层，使敌在末端前先付出数量损失；敌若爬升避开，则转入我方远程火力可作用的空域，若先行反潜清海，又会暴露突袭企图并拖慢节奏。它解决的是蜂群“无痕接近”的问题，而不是重复末端火力。

掠波连扫拦截机针对的是另一种矛盾：敌波次数量、诱饵比例和编组密度不断变化，使逐目标拦截的成本与通道压力同步上升。该机不追求识别单架，而是在预警给出波前位置和时间后，反复以横向破片刃带切过波前截面，按出动趟次削薄整段编队。敌加密或混入诱饵不能直接增加我方单趟成本，拉稀、减速又延长其在走廊中的暴露时间，因而把“按时成链到达”转化为难以维持的作战条件。

驻空扫域电磁灭群巡飞弹则把防护动作从临机截击改为提前占位。它在高价值节点与来袭主轴之间驻留，以宽频高功率微波反复作用于未充分加固无人机的飞控、电调和数据链，按覆盖空域和驻留时间处理多个波次，先切断蜂群协同，再由硬杀伤处置漏网目标。引浪吞波聚爆诱杀弹服务于辐射节点遭反辐射蜂群围攻的场景：真节点静默，仿形诱源主动辐射，迫使敌弹群向假源收拢，再在聚集窗口整批清算，从而把敌的“辨真”动作变成自身弹药损失。

2. 装备能力提升角度

这些装备的必要提升不在统一增加弹药数量，而在于分别改变交战的计价单位和作用界面。迎面撒网捕蜂拦截弹利用敌为避开远程雷达而被迫进入的低空窄带，在入口和中段投放无源柔性网幕，以物理缠裹整簇目标，绕开探测、识别、制导和电子对抗链；敌若爬升即暴露，若拉散则自行削弱饱和效果，若加装破网装置则承担增重和载荷损失。过境层云爆轰断波弹进一步把末端拦截从按架次处理改为按过境时间窗口处理，在可判明的走廊内现地成层并同步作用于层内薄壳飞行器，使点防御只需处理绕行和残余目标。但其海上气溶胶保持、层域完整性和同步触发尚无材料化试验支撑，不能把设想效果直接当作定型能力。

撞线自付近防弹巢承担最后一道低成本保命任务。它布置在节点外缘、顶面和伪装体周边，仅对真正进入末端撞击航段的目标自主触发，圈外巡飞、干扰和普通诱饵不消耗弹巢；敌若要骗取火力，就必须完成接近真实攻击的末端动作。由此，防御寿命不再随敌诱饵总量线性缩短，而主要取决于真实突入次数。该装备的关键不在远程发现，而在末端航向判定、近距安全间隔和多方向覆盖，公开材料不足以支持具体触发距离、覆盖密度或可靠性指标。

3. 领域占位角度

上述装备共同指向反蜂群领域从“雷达发现—逐架拦截”向“预置几何、区域清算、末端限损”转变，但各自占位不可互换：随浪伏击反蜂群弹负责海上低空走廊的水下前沿削峰；掠波连扫拦截机负责可预占航路中的截面持续清削；驻空扫域电磁灭群巡飞弹负责节点上空的时间段区域压制；引浪吞波聚爆诱杀弹负责辐射节点的反辨真防护；迎面撒网捕蜂拦截弹负责低空窄带封段；过境层云爆轰断波弹负责条件成熟时的窗口遮断；撞线自付近防弹巢负责最后数十米的自主补漏。其价值在于填补不同交战断点，而不是形成同质化装备堆叠。

建设取舍应以敌方是否仍被迫形成密集波次、低空走廊或辐射收敛为前提。敌改用多方向小群、预编程直击、高空分散或先期清扫时，部分装备会明显降效，必须保留末端硬杀伤和机动火力作为边界接管手段。

4. 综合效益

建设本栏装备的直接军事收益，是把关键节点由“弹药先耗尽或通道先饱和”转为“敌在接近、成波、辨真和末端撞击的不同阶段分别付出代价”，延长要地、舰队和前沿辐射节点持续作战时间。其综合效益不应以单一击落数衡量，而应看末端残余数量、到达时刻、敌清海和加固成本、我方弹药消耗以及节点功能保持时间是否同步改善。由于现有材料缺少海况声学背景、微波效应阈值、网幕展开数据、云爆海上试验和近防弹巢实测结果，近期建设宜优先验证各装备最小成立条件，再据压力试验结果决定规模化取舍。
