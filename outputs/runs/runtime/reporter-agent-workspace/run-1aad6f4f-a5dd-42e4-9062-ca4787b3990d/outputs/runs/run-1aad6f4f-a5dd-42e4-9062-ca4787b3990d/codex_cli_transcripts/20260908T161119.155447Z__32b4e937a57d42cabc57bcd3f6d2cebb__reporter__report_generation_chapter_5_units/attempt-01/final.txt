五、研制基础

（一）参与单位

参与单位不能按通用“总体单位加分系统”来套，必须按谁直接承担产品责任、谁掌握关键接口、谁负责外场试验来分。公开材料不足以点名具体单位时，只能写机构类型，不得虚构承研归属。

水下伏击型装备的牵头，应是具备坐底式水中兵器研制能力的单位，负责负浮力筒体、长期静默待机、被动水声判明与垂直穿浪机构；与之配套的是水声试验机构，必须在浅海混响、风浪噪声和渔船干扰条件下交付漏判率、虚警率、判明到起爆时延等证据。若缺海区声学背景与敌典型贴海队形样本，声学门限就不能定死，相关责任只能保留为试验缺口。

空中掠波和驻空电磁两类装备，产品责任分别落在无人机平台单位与弹载高功率射频单位。前者要承担刃带展开、再出动节拍和走廊占位；后者要承担宽频微波源、天线、供电和热控。对应的试验责任不在一般飞行试验，而在靶场效应试验，必须给出单趟削截率、域结算率、有效作用距离和重复频率的实测数据。若没有这些数据，单位只能停留在概念性配套，不能冒充定型承制。

诱饵与近防类装备的参与方更偏向电子对抗、引信和阵地伪装单位。引浪吞波聚爆诱杀弹需要电子对抗辐射源单位复现真节点辐射特征，需要引信单位证明收拢判定与同步起爆可靠；撞线自付近防弹巢则更依赖末端触发传感和安全保险设计单位，必须先证明只对真实撞击航段响应，且数十米内起爆不伤及受护节点。拦网与断波装备则分别牵涉柔性高强材料、气象适配和成层爆轰试验单位，证据重点是展开完整度、补网周期、成层保持时间和同步起爆可信度。

因此，本项目的参与单位应是一组围绕不同物理域分工的专业机构，而不是一个包打天下的总装名目。公开证据只够支撑单位类型，不足以支撑具体名录；在关键试验数据未补齐前，所有单位责任都应以“产品责任、接口责任、试验责任、证据责任”四项闭合为准。
