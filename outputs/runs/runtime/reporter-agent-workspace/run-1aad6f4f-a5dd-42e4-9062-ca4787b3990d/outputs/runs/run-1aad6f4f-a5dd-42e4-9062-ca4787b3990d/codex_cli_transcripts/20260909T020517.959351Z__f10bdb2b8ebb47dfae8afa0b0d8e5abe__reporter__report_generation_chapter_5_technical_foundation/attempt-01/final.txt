# 五、研制基础

## （二）技术基础

现有交接材料未提供通过质量门的 `capability_portrait`，也未给出具体装备名称、型号、研制单位、已有样机、成熟度等级或试验记录。因此，本栏只能依据已明确的候选装备边界判断可承接的工程基础，不能把通用技术方向直接认定为已经具备研制条件。技术基础的核心不在于增加拦截数量，而在于支撑低空蜂群的连续发现、低成本压制、瞄准链扰乱和多波次末端拒止；其中任何一环缺少可实测的装备本体，沿海要地和舰艇编队仍可能在后续波次中失去防护能力。

| 候选装备方向 | 可继承基础与新增工作 | 可研缺口、试验及供应链条件 |
|---|---|---|
| 低空多目标探测装备 | 可承接既有低空监视、光电复核和阵地通信工程经验，但这些基础能否覆盖地海杂波中的低小慢多目标，尚无材料证明。新增工作应围绕连续发现、分类可信和轨迹保持展开，使探测结果能够在蜂群进入软硬杀伤包线前形成稳定目标指示。 | 缺少典型蜂群规模下的探测概率、虚警率、更新率及低空盲区数据。试验必须设置沿海、岛礁和舰载机动三类工况，并记录首检、持续跟踪和目标分裂情况。还需核实射频前端、光电组件、时频基准和恶劣海洋环境适应性的国产供应能力。 |
| 电磁压制与欺骗装备 | 可继承的工程基础应包括功率产生、天线辐射、频谱感知和快速指向等现有能力，但交接材料没有给出具体设备或功率等级。新增工作不是单纯提高辐射功率，而是针对蜂群通信、中继和导航依赖，形成可切换的压制或欺骗动作，并能判断敌蜂群是否失去协同。 | 缺少目标抗干扰、自主飞行和断链后行为数据，因而不能确认软杀伤对全自主蜂群的有效边界。需开展不同自主程度、不同通信依赖度下的实飞或半实物对抗试验；功率放大器、散热、电源和宽带天线的连续工作可靠性是供应链关键。 |
| 诱饵与假目标装备 | 其工程基础不等同于软件生成目标，必须落实为可部署、可辐射或可被敌传感器观测的物理对象，以改变敌蜂群的瞄准置信度。新增工作应根据要地、岛礁和舰艇编队的特征，分别验证假目标能否承接敌侦察、引导和火力分配。 | 缺少敌方识别特征、传感器组合及假目标逼真度要求，无法判断诱偏距离、持续时间和抗识别能力。试验应比较真实目标、诱饵和混合部署下的敌方指向变化，并核实快速布设、补充消耗和海上储运条件；对不依赖外部链路的自主攻击蜂群，诱骗作用可能明显下降。 |
| 末端硬杀伤与点防御装备 | 可继承基础只能由已有拦截武器、近程火力或弹药生产能力逐项证明。新增工作的制胜机理是以足够通道数和较低单次交换成本承受连续波次，而非继续依靠昂贵弹药逐架拦截。再装填速度、持续射击稳定性和目标确认后的快速转火，直接决定要地能否保持关键功能。 | 当前缺少拦截单价、备弹量、通道数、再装填时间、命中判据及大规模波次数据，无法判断其能否改变成本曲线。试验必须采用多波次、混合目标和波次间隔变化的压力条件，验证弹药消耗、局部击穿和恢复周期。弹药、制导部件、能源与火控执行机构的持续供应能力也需单独核实。 |

工程上，跨域信息融合和交战管理只能作为接口条件，不能替代上述装备本体。公开审计已显示，跨域指挥控制仍存在综合框架、互操作和数据治理缺口；若把更多功能继续集中到尚未稳定的联合链路中，可能增加授权时延，反而削弱蜂群防护所需的快速处置能力。因而研制基础的成立门槛应是：每件装备均有可追溯的样机或既有技术谱系，有与沿海、岛礁、舰艇工况对应的试验条件，并能用多波次压力试验说明其如何降低成本交换、保持探测连续性或削弱敌瞄准链。现有材料尚不足以证明这些条件已经全部具备，后续应优先补齐装备身份、成熟度、关键部件来源和实测数据。
