五、研制基础

（一）参与单位

随浪伏击反蜂群弹的承研责任按机理切分：负浮力坐底筒、无链路长效待机与电池自持归水中兵器与水下长效能源专业，决定单次潜伏上限；浅海混响中把“整波过顶”从渔船噪声低虚警剔出的被动判明属水声探测单位，决定敢不敢触发；垂直穿浪、破片杆幕与近炸引信归弹药毁伤专业。近海靶场须按典型水深、底质、海况实测漏判虚警率，渔航禁入界面由使用方与海事部门共定。

掠波连扫拦截机主责在可重复出动的平台而非弹药：航空平台总体解决掠海定高穿越与再出动节拍，横向破片刃带再生载荷解决展宽与破片密度，与体系只交走廊级到达提示的低带宽指控接口；单趟削截率、带材再生周期与自身损失率缺公开参数，须飞行对抗试验标定。

驻空扫域电磁灭群巡飞弹须巡飞弹平台与高功率微波/定向能单位协同，把宽频源与天线压进可驻空弹体并维持按防护时段工作的供电热控；毁伤阈值是统计量，须由电磁效应试验场对典型飞控、电调与数据链建库标定。

引浪吞波聚爆诱杀弹的承研界面在辐射档案：诱源须复现被护节点载频、扫描节律与功率起伏，电子对抗辐射模拟单位须与现役雷达研制方建立特征数据接口；温压破片与收拢判定引信归弹药引信专业，成本须低于单枚反辐射弹。靶试对抗反辐射导引头分选，敌分选算法与收拢弹道包线未知。

迎面撒网捕蜂拦截弹的责任在网材与展开动力学：高比强度柔性纤维、迎风成网概率与投放时序须纺织材料、空投动力学试验与浮空器/运输机保障单位协同；乱流成网率与缠绞可靠性须风洞实投验证。

过境层云爆轰断波弹把责任压在云爆装药配方、公里级气溶胶铺展与多点同步起爆，属燃料空气弹药专业并集成车载雾化装置；海上成层保持与同步起爆无公开试验是可行性短板，须海上试验场配气象保障做缩比铺层验证。

撞线自付近防弹巢仅余“末端撞击航段才触发”概念，缺引信判据、布设密度与净空事实，暂只能归近距弹药与被动引信类单位。

各型均无公开承研归属与成熟度声明，上述为按机理推导的机构类型，具体承研承试单位留待立项询价补证。
