（二）作战运用模式

1. 作战运用流程

敌蜂群要兑现饱和威胁，须同时保持“贴海低空、密集成波、按时过顶”三个剖面直到末端；各装备方向分别以取消其中某一剖面为接敌入口，进入条件、决定性动作与结束方式随装备机理各异，不共用流程骨架。

随浪伏击反蜂群弹在敌贴海密集成波、走廊水深底质可坐底时接战。渔船与无人潜航器平时沿敌惯用航渡走廊标定布设，弹间弹岸不建链路；坐底被动水声阵把探测对象收窄为“波次过顶”这一声学事件，越过阈值即判明方位、规模与过顶时刻，在波群最密处垂直穿浪，以覆盖整个掠海层的破片杆幕自下而上起爆，使整波同时进入近炸半径。其决定性动作是用“波次必然途经的空间与时刻”取代逐架截获条件，敌为隐蔽而锁定的密集贴海队形反成杆幕几何下的最不利构形。直接战果是每波过顶前被折损一次，到达末端的数量与时刻被预减并判明，供后段火力同步补射；判明置信不足或时间窗错配时宁放勿炸，漏网交接力点与末端手段补账。

迎面撒网捕蜂拦截弹在走廊几何把敌航迹压成可预置窄带时进入。高空气球或运输机沿带前缘按波次节拍成串投弹，网弹迎风自展为横张走廊断面的纯机械网幕，不载电子、不辐射、不爆炸，仅靠迎面相对气流把整簇前排兜卷缠裹坠海，探测、识别、单发火控与干扰对抗被整体绕开。每起一网与入口计数对账成一笔可点数取证的清点事件，按段核销净通过架次后决定补网密度与段位前移后撤。敌爬升越网即现形于远程火力，拉大间隔则自毁同时到达的饱和峰，逐架加装破网装置则抬单价压载荷；风场破坏网幕保形、带宽超出覆盖或补网周期跟不上波次间隔时中止作业，由火力层先把敌逼回可覆盖几何。

掠波连扫拦截机以敌保持相对集中的波前为前提，体系只须以波级粒度给出到达时刻、走廊位置与高度带。值班机不做单机识别，前出到波前所在水平层横向展开破片刃带反复掠穿，每趟按整段编队截面结算，真弹与诱饵等价清削；刃带随趟再生，多架按波次节拍接力，扫削密度取决于单位时间趟次而非弹药基数。敌加密单波压不动我方单趟成本，增投诱饵无法替真弹穿过刃带，拉稀减速只拉长自身暴露、耗尽航渡预算，直接效果是“整链按时到齐”的计划前提被压垮；波前一旦拆散为多方位、多时段异步小包，可扫截面消失，本机中止掠穿、退回逐群兜底。

过境层云爆轰断波弹按判窗、铺层、同步起爆三段运行。岸基舰载雷达与海上无人值守探测先外推敌末端过境时间窗、航速与层内高度带，预留佯动调整余量；车载平台沿走廊侧翼展开，贴海播撒燃料气溶胶，在覆盖整层高度、横向绵延数公里的横断面内维持可爆浓度；敌波次主体整体进入层体积且浓度达标时多点同步起爆，以体爆轰超压、火球与卷吸使层内薄壳机体成批解体坠海。计价由架次改为过境时间切片，先遣诱饵试触只耗敌自身波次资源；敌弃窗改期或拉长分散，都给我方留出再侦判与再铺层时间。层未就位、判窗误差超出成层—守候余量或风漂使层不可维持时不起爆，收回平台等下一时间窗。

驻空扫域电磁灭群巡飞弹以威胁判性为入口：来袭判为未加固的消耗性编成时升格为当波主用手段，判为全程加固机队则改走硬杀伤链。弹体在节点与威胁来向之间高位驻留，按禁扫方向约束对己兼容，对必经空域反复施加宽频高功率微波，交战规则从逐目标授权改为划定空域与时段内的自动区域照射，凡未逐架屏蔽的飞控、电调与数据链进入覆盖域即停摆。疏散、变速、混编都绕不开覆盖体积，敌只剩逐架屏蔽加固——单机成本、重量与航程同步恶化——或以昂贵防区外火力击落高悬弹体，形成以贵换廉的反向消耗。战果按驻留时段与压制波次数结算，能储到限即离场、预备弹接力补位；敌以加固机带队或反辐射反压驻留区时，下调本弹边际收益、收缩迁移驻留点，残余移交硬杀伤梯队。

引浪吞波聚爆诱杀弹只在敌以反辐射引导弹药或按源引导自杀机攻击高价值辐射节点时进入，流程为布、引、聚、爆、补循环。诱爆弹成组贴设于真节点旁，仿形天线与辐射规律主动辐射，真节点全程静默并管住备份设备与后勤电磁泄漏；敌为辨认真假只能让整批弹药向诱源收拢，收拢即空间聚集加末段机动受限，诱爆弹在收拢瞬间以温压破片整簇起爆，成建制销毁该波导引头集群。辨真由此从敌方决策成本变成我方开火窗口，压制波与载荷波每推进一步都要重复支付辨真代价，数量优势逐次折算为目标确认费用。敌改预编程、卫星或光学慢速确认直击时诱爆条件不出现，或改单机试探加识别后直击，逐组诱爆退化为普通诱饵消耗，真源防护移交邻近硬杀伤。

撞线自付近防弹巢是离节点最近的终段手段：弹巢沿节点外缘、顶面与周边伪装体密布，无辐射、无人值守，被动感知只认“真正朝节点撞击”的末端航段为开火条件，最近弹巢随即在数十米内迎面起爆，先敌引爆战斗部或直接击毁机体。圈外巡飞、过航与廉价诱饵不触发不消耗；诱饵要骗取一枚，必须做出成本接近真弹的末端撞击动作，假目标放空火力的账不再成立，防御消耗只随真实末端进入次数增长。触发后弹巢一次性报废，须在波次间隙补设；材料未给出触发判据、布设间距与对己方低空活动误触管理，只能确认这一终段动作方向，不能定量其防御能力。

2. 链路闭环分析

这些方向对任务链的改写不是增加拦截通道，而是各自摘掉“单机识别—逐目标授权—逐发效果确认”中最贵的一环，并把毁伤核销改成自身机理可核的实体：水下伏击按波核销、撒网按坠网清点核销、连扫按趟次核销、电磁驻空按时段与压制波次核销、层云按过境时间片核销、诱爆按收拢清算比核销、近防弹巢按真实撞击次数核销。判断一条链是否闭合只看三问：谁提供进入信息、毁伤按什么单位结算、下一波来临前能否恢复。

中段断点在分类可信与授权时延，去除方式分两类。以几何取代识别的连扫、撒网与层云把授权时延一并删除，预警只提供批级到达信息，接战由平台自身动作完成；代价是三者的结算前提都押在“敌保持集中波前或整窗进入”上，敌拆散为多路小包异步渗透时同时失效，逐级退为补充手段。驻空扫域把授权从逐目标改为时段自动照射，剩余决策只剩编成判性与禁扫管理，闭环弱点是效果确认粒度粗，域内失能率只能统计估计，对己电磁兼容与反辐射规避造成的停照时间须计入有效占空比。水下伏击与近防弹巢把闭环压进弹内、不占指控时延，代价转到预置与误触侧：前者虚警耗弹、漏判放波，后者一次性报废并承受误触发风险。

恢复闭合是各方向差别最大、也决定多波次拒止能否持续的环节：水下伏击一次性坐底、交战窗口内无法补投，须战前按走廊饱和预置并把上一波漏网修正为补设密度；撒网靠气球滞空与运输机再投，补网周期必须短于敌波次间隔，否则出现持续破口；连扫靠返场再装填与刃带再生，趟次节拍是软约束；电磁驻空靠发射接力轮驻，单发驻留短于敌波次持续即断链；层云每窗每段一次，两次成层间隙正是敌可冲击的窗口；诱爆与近防弹巢都在波次间隙整补，在位率决定下一波还剩多少清算额度。对手反适应沿链作用：清海清除针对水下伏击却须暴露清海批次，拆波前、加破网装置、逐架屏蔽与改非辐射引导分别针对扫削截面、网幕、电磁覆盖与辐射诱爆，方向各异却共享同一代价——放弃“低空密集、同刻过顶”这一最省成本剖面。闭环判据因此统一为：把敌逼出经济剖面，并在其改剖面后由下一层接管；任一装备在自身结算单位不再成立时中止并移交，以层间接力维持多波次拒止连续性。验证与建设取舍上，先闭合走廊几何约束、波级预警可用性与补设节奏三项共性前提，再谈装备数量与编成。
