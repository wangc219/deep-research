三、总体方案

（一）总体架构

总体架构按敌蜂群由航渡、成波突入到末端命中的交战几何组织，不把各装备的专属机理抽象为统一探测或统一火力层。体系共享的最小公共信息仅包括威胁来向、走廊段位、波次到达时间窗、残余规模、己方禁入区和可用资源状态，并以波级提示、时间戳、段状态和移交标志衔接，避免把逐架识别重新变成瓶颈。

“随浪伏击反蜂群弹”部署在浅近海必经航段，以无辐射被动水声判明贴海密集波次，在过顶瞬间垂直起爆，先削减敌波并提供到达时刻基准；其失效于海区不适配、声学判明失真或阵位被清除。“迎面撒网捕蜂拦截弹”利用低空窄带和迎面气流形成机械网幕，按段缠收前排目标，重点处理不宜消耗制导弹的密集低空流量；走廊变宽、风场失稳或敌改走高空时，由远程火力接管。“掠波连扫拦截机”不追逐单机，而按波前截面反复掠穿，以趟次削薄集中波次；其关键接口是波前位置、高度带和到达节拍，若敌改为多方位异步小群，转由末端手段补漏。

进入节点防护区后，“驻空扫域电磁灭群巡飞弹”按防护时段占位，对未加固蜂群实施区域性失能，承担压低来袭密度和切断协同的任务；高抗扰目标、波束外绕行和驻留体被压制时，必须及时移交硬杀伤。“引浪吞波聚爆诱杀弹”只针对依赖辐射收敛的攻击链，通过真源静默与仿形诱源把敌弹群引入聚爆区；敌改用预编程、光学直击或先清扫诱饵时，该环节降级。末端“过境层云爆轰断波弹”在可判窗、可收口走廊内吸收并发峰值，残余目标再交点防御；“撞线自付近防弹巢”因缺少可核验参数暂按近界自主兜底概念保留，不作为核心能力承诺。

体系成败取决于三类公共条件：波级预警持续可用，交战区域和己方航迹权限清晰，补投、再装填与轮换资源跟得上波次节拍。任一条件失效，装备不会互相替代，而是按“外层削峰、区域失能、节点诱杀、末端补漏”逐级降级。
