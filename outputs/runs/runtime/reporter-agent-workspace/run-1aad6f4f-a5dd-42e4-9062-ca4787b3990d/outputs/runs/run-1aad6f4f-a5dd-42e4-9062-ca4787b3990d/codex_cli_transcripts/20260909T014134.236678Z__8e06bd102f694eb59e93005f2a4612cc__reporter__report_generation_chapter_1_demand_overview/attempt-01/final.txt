一、需求分析

（一）需求概述

1. 背景分析

第一岛链沿海要地、岛礁、前进机场和舰艇编队面临的主要压力，已由少量高价值目标突防转向低成本无人机蜂群与防区外火力叠加的连续饱和攻击。敌方可利用海杂波、地形遮蔽和低空航路压缩预警时间，以侦察机、诱饵机、巡飞弹和自杀机混编成波，先扰乱探测与指挥，再以数量冲击末端防御。现有“发现、识别、跟踪、逐架拦截”的任务链在低空小目标、复杂杂波和多波次条件下容易出现探测漏失、火力通道不足、拦截弹快速耗尽等断点；即使单次拦截有效，也可能因交换成本高于敌方单机成本而在持续攻击中失去防护能力。真正需要改变的不是简单增加弹药数量，而是把交战计价单位由“单架目标”改为波次、截面、覆盖域或时间窗口，并使敌方低空密集、依赖辐射或必须集中到达的行为转化为暴露和消耗。

2. 需求阐述

装备需求首先应覆盖蜂群进入末端前的低成本削峰。沿海浅近海走廊需要一种能避开电磁暴露、利用贴海密集过顶这一固定几何完成按波毁伤的水下预置装备，以弥补雷达低空盲区和末端逐架拦截不足；其关键缺口是浅海声学判明、长期静默值守和阵地不被先期清除。对受走廊约束的集中波次，还需要把拦截对象从单架改为波前截面，依靠可重复出动的横向破片刃带持续削薄编队，解决诱饵加密会同步推高我方弹药消耗的问题；其缺口在于平台能否稳定占位、按时掠穿并维持刃带再生节拍。

对岛礁、机场和舰艇核心节点，需求重点是把蜂群数量优势转化为敌方加固和时间成本。驻空扫域电磁灭群巡飞弹应以覆盖域和驻留时段承担前置软杀伤，压低未加固无人机及伴随干扰机的协同能力；但其成立取决于弹载能源、有效能注、照射占空比和驻留体抗反辐射能力。面对反辐射攻击链，则需要以真假节点混淆迫使敌弹群收拢，再由聚爆诱杀弹按批清算，补足单纯静默、欺骗或逐发拦截无法解决的辨真断点；其缺口是诱源逼真度、真节点静默纪律和敌方改用光学、预编程直击后的适用范围。

对被地形压缩的低空窄带，可考虑无源柔性网幕按段清收，使电子干扰、诱饵和隐身失去作用对象；但该需求只在敌坚持低空密集过境、风场和网幕展开条件允许时成立。对末端收口段，过境层云爆轰断波弹试图以时间窗口替代架次拦截，吸收并发峰值、将漏网目标降至点防御可承受范围；其关键缺口是开放海上气溶胶层的保持、同步起爆和己方净空约束。撞线自付近防弹巢则针对真正末端撞击目标实施无辐射自主触发，避免被圈外诱饵耗弹，但现有材料缺少目标判定、误触发和安全隔离证据，需求应暂列为待补证方向。

3. 项目画像

本项目不是单一反无人机型号的替换，而是围绕“先期削峰、区域清算、节点欺骗、末端收口”形成若干具有不同制胜机理的装备方向。随浪伏击反蜂群弹的价值在于把交战界面前推到水下静默段，使敌若坚持贴海密集航渡就必须逐段付出损耗或反潜清海代价；掠波连扫拦截机则以“趟次—截面”替代“弹药—单机”，专门破坏敌整链按时到齐的计划条件。驻空扫域电磁灭群巡飞弹改变的是蜂群经济账，迫使敌逐架加固并承担重量、航程和成本惩罚；引浪吞波聚爆诱杀弹改变的是节点防护账，使敌每次辨认真假都可能先损失一批导引弹药。迎面撒网捕蜂拦截弹利用低空走廊的几何约束，把无痕偷渡变成可分段清点的物理闸门；过境层云爆轰断波弹则以时间片吸收末端并发峰值，但工程和安全边界最为突出。撞线自付近防弹巢具有无辐射、低值守和抗诱饵潜力，当前只能作为末端补位概念，不能据现有材料确认其成熟度。

这些装备的共同前景，是把防御胜负从“拦截弹是否先耗尽”转向“敌是否仍能保持集中、低空、按时和可辨识的突防条件”。其制胜增量并非替代全部探测和硬杀伤，而是在不同交战几何下切断敌链、降低末端并发量，并把敌方反适应迫使到更高成本、更长暴露或更差协同的路径上。各方向能否立项，最终取决于对应场景的物理条件、敌方自主化和抗干扰水平，以及关键效应能否通过可重复试验得到证实。
