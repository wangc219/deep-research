（三）体系贡献率分析

第一岛链反蜂群体系的核心矛盾，不是单纯增加拦截通道，而是防止敌以低成本、多波次和复合诱饵把我方逐架拦截链拖入高耗竭状态。七类装备分别改变暴露位置、清算单位或敌方决策代价，贡献率不能按同一指标横向套用。

随浪伏击反蜂群弹把交战界面前推至敌方贴海航渡段。敌为利用海杂波和视界遮挡，往往必须低空密集过顶；该空间和时间关系虽可规避电磁探测，却难完全取消水下声学暴露。坐底弹以被动判明波群过顶时刻，垂直穿浪在密集段形成破片覆盖，按波次而非按单机削减来袭数量，直接降低末端防御的并发压力，并迫使敌改道、爬升或先行清海。其贡献依赖海区水深、底质、声学背景和预置走廊，敌绕行、高空分散或先期清除阵位时效能明显下降。

掠波连扫拦截机解决的是集中波前带来的数量劣势。它不承担逐架搜索和识别，而以横向破片刃带反复穿越敌波前，把一次出动的价值绑定于走廊截面，不随截面内真假目标数量线性增加。敌加密或混入诱饵，不能同步抬高我方单趟成本；若拉稀、减速，则暴露时间和航渡消耗上升，整条输送链按时到齐的概率下降。该装备真正改变的是成本结算单位，但对多方位、小群异步渗透以及无法稳定占位的空域贡献有限，仍需点防御补漏。

驻空扫域电磁灭群巡飞弹针对的是廉价蜂群以架次压垮高价弹药的交换关系。巡飞弹在节点上空驻留，以宽频高功率微波反复覆盖来袭扇区，令未充分加固的飞控、电调或数据链成批失能，防护消耗由来袭架数转为驻留时段和有效照射占空比。敌若继续维持低成本编组，将在覆盖域内集中损失；若逐架屏蔽加固，则重量、成本和航程同步恶化。其效果受弹载供电、散热、波束几何和目标抗扰水平限制，对高抗扰或绕开主覆盖域的目标必须交由硬杀伤处理。

引浪吞波聚爆诱杀弹不与敌反辐射弹药逐发交换，而是把“辨认真节点”变成敌方必须支付的损耗。诱弹贴近静默真节点，仿真其辐射特征并主动引导敌弹收拢；当弹群进入聚集状态后，以温压和破片实施批量清算。这样可延长雷达、通信和火力节点的静默存活时间，破坏敌“先诱耗、再压制、后送载荷”的波次顺序。其成立前提是敌仍依赖辐射收敛，且诱源逼真、真节点静默彻底；若敌改用预编程、光学确认或远距试探，清算规模将退化。

迎面撒网捕蜂拦截弹利用低空走廊的几何约束，绕开复杂感知和电子对抗。高空气球或运输机在入口、中段成串投放网弹，网幕迎风展开，以物理缠裹清除密集前排，并由下游观测逐段核销。它把走廊从无痕通道变为可分段清点的消耗区，使干扰、诱饵和隐身难以发挥作用；敌若爬升则暴露于远程火力，若拉散则自行削弱饱和条件。装备贡献受风场、网幕幅宽、补投周期和己方净空管制约束，不能覆盖宽正面或高空突防。

过境层云爆轰断波弹承担“吸收末端过境峰值”的任务。它依据低空蜂群的时间窗，在海上走廊铺设覆盖一定高度层的可爆气溶胶区域，以整层体爆轰替代逐架跟踪，使薄壳无人机在同一时间切片内成批解体，残余目标数量降至点防御可承受范围。敌只能弃窗、拉长队形或改道，均会损失同步突击优势。该构想的关键风险是海风、湿度、湍流对成层保持和同步起爆的影响；若层域完整性或判窗可靠性不足，装备将退化为局部阻滞手段。

撞线自付近防弹巢直接补上节点最后数十米的防护缺口。弹巢无辐射、无人值守，只在目标真正进入撞击航段时自主起爆，圈外巡飞和远距诱饵不会轻易消耗弹药，敌若要诱发拦截，必须承担接近真实攻击的末端风险。它不改变外层蜂群规模，却能把漏网目标与节点接触前的最后机会转化为低决策时延的物理毁伤，尤其适合通信受压或指控链中断时维持最低防护。其贡献取决于感知误触发率、覆盖密度、弹巢补充能力和对己方人员装备的安全隔离，公开材料不足以支持确定的杀伤或成本数值。

综合看，水下伏击弹和网幕装备主要削减前段波次规模，连扫拦截机和层云断波弹分别压低截面密度与过境峰值，电磁巡飞弹改变持续驻防的边际成本，诱爆弹转嫁敌方辨真损耗，近防弹巢则保证链路受损后的末端存续。体系贡献应以多波次后关键节点是否仍能运行、敌有效到达量是否持续下降以及我方补充周期能否闭合为判据，而不能只看单件装备的命中数量。
