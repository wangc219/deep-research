## 一、需求分析

### （三）建设必要性分析

#### 1. 作战使用角度

第一岛链沿海、岛礁和舰队节点面临的主要矛盾，是低成本无人蜂群以低空、海杂波和诱饵掩护压缩防御反应时间，并与防区外火力形成多波次叠加。若继续依靠发现单机、逐架授权、逐发拦截的方式，敌方只需增加波次和诱饵，就能把我方防御拖入弹药、通道和决策时间同时不足的状态。因此，建设必要性不在简单增加拦截数量，而在把交战单位由“单架目标”改造成“波次、走廊、时间窗或真实撞击事件”。

随浪伏击反蜂群弹针对贴海航渡阶段的低空盲区。敌蜂群为躲避远程探测而贴海密集飞行，虽然降低了发现概率，却必须承受航路集中和波群过顶的物理约束。该弹通过水下预置、被动声学判别和近距离穿浪起爆，在波群最密处形成破片覆盖，使防御从等待雷达逐架建链转为提前削减整波，直接减轻后续末端火力压力。其成立前提是浅近海水深、底质、航路和声学环境适合预置；敌若改走高空、分散航线或先行清除伏击区，作用就会明显下降。

迎面撒网捕蜂拦截弹利用低空通道的几何约束，以气球或运输机投放无源网幕，依靠相对气流缠住密集航渡的前排目标。它不需要对每架无人机完成精确制导，而是把必经走廊切成若干阻滞段；敌方若爬升，将暴露于其他火力，若分散，则蜂群的同时到达优势被削弱。该装备的直接价值是用机械阻滞替代部分弹药交换，但走廊过宽、风场过强、网幕成形不稳定或补网投放跟不上波次间隔时，拒止效果难以保证。

掠波连扫拦截机面对的是敌方以同外形诱饵混编、压缩单波间隔和提高编队密度的加量战术。它按波前截面实施连续掠穿，以破片刃带成段清削，不把时间耗费在逐架辨认和逐架命中上，从而使诱饵数量不再等比例增加我方单次交换成本。该机适合敌方仍受低空走廊或海上航路约束的场景；若敌改为多方向、异步、小群渗透，波前截面难以形成，其作用必须由其他末端装备接替。

#### 2. 装备能力提升角度

过境层云爆轰断波弹提升的是末端对高并发波次的处理能力。它在判明低空过境时间窗后，于海上走廊形成覆盖一定高度带的可爆气溶胶层，待主体波次进入后同步起爆，以体积覆盖替代逐架跟踪。敌若弃窗，需要重新组织航渡并暴露更多时间；若拉长编队，单窗密度下降，蜂群的饱和优势随之减弱。该能力受风、雨、湿度、湍流、层体保持和判窗误差制约，对高空绕行目标及耐受层内爆轰的目标不能视为有效。

驻空扫域电磁灭群巡飞弹改变的是软杀伤的作用方式。它不以逐架压制为主要任务，而是在节点上空持续驻留，对必经空域实施宽频、高功率区域照射，使未充分加固的飞控、电调和通信部件在覆盖域内集中失效。防御成本由来袭架数转为驻留时段，迫使敌方在加固重量、航程和数量之间作出牺牲。对抗高度自主、抗干扰或采取地形遮蔽绕行的蜂群时，软杀伤效果会下降，且驻空平台本身需要防止被优先摧毁。

引浪吞波聚爆诱杀弹用于切断敌方“侦察定位—确认真源—组织导引—集中突击”的瞄准链。该装备以仿形诱源主动辐射，真实节点保持静默，诱使反辐射或寻源弹药向假目标收拢，再实施聚爆清除，使敌方的辨真过程转化为弹药集中和批量损失。它能延长雷达、通信和火力节点的静默生存时间，但对预编程、卫星引导或光学直击目标的诱导作用有限，诱源逼真度和真实节点的静默纪律决定其上限。

撞线自付近防弹巢面向的是所有外层防线失效后的最后数十米。弹巢无辐射、无人值守，只在目标航迹明确指向受护节点并进入末端撞击段时触发，过航侦察机、远距巡飞目标和普通干扰诱饵不消耗弹药。它把开火判据从“是否识别出真目标”改为“是否正在实施真实撞击”，可避免廉价诱饵提前耗尽近防资源。其关键风险是触发误差、漏触发和近距爆炸对己方设施的安全边界，必须通过实弹靶试确认。

#### 3. 领域占位角度

反蜂群装备建设应形成区别于传统逐架拦截的物理能力谱系：随浪伏击反蜂群弹解决贴海航渡的先期削峰，掠波连扫拦截机处理受约束走廊内的波前目标，撒网装备和层云爆轰断波弹分别承担机械阻滞与时间窗拒止，驻空扫域电磁灭群巡飞弹压制低抗扰蜂群，聚爆诱杀弹保护被瞄准节点，撞线自付近防弹巢承担最后撞击兜底。其领域价值在于改变交换单位和敌方攻击链，而不是把体系软件、指控流程或通用口号包装成装备项目。

#### 4. 综合效益

综合效益应以多波次攻击后要地和舰队关键功能是否持续存在来衡量，而不是以单次拦截率替代判断。建设取舍上，应优先验证低空海杂波条件下的波次判明、走廊截面清削、区域电磁作用和末端自主触发；对受风场、海况、布设条件强约束的网幕、爆轰层和水下预置装备，则应按海区和航路择段配置。凡仍依赖昂贵弹药逐架交换、无法在通信受限或节点受压时独立完成物理作用的方案，不足以支撑持续拒止。
