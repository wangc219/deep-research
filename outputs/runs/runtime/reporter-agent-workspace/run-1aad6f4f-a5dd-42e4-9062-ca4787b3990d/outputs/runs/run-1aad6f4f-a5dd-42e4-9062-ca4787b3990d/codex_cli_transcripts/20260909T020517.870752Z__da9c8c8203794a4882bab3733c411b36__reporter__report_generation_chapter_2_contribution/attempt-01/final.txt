二、项目画像

（三）体系贡献率分析

本栏输入未提供任何 `capability_cues` 装备记录，无法按“逐件装备”给出专属体系贡献率判断。缺少的不是文字材料，而是决定贡献率能否成立的关键事实：装备名称或类别边界、作用对象、交战距离或覆盖范围、对低小慢多目标的探测或杀伤机理、单次处置成本、通道数、再装填或持续工作能力、对自主蜂群和抗干扰链路的有效边界。因此，不能把低空探测、电子压制、诱饵欺骗、低成本硬杀伤等能力方向直接写成已确认装备贡献，也不能编造某型装备在第一岛链场景下的贡献比例。

从已给出的实际体系基线看，反蜂群贡献率不能按传统“增加几套拦截装备”计算。敌方低成本无人蜂群的主要威胁，是用数量和波次把我方发现、分类、授权、处置、确认和恢复链条逐段拖慢，使固定要地、岛礁节点和机动编队在防区外火力到达前暴露辐射特征、耗尽高价值弹药或失去连续防护。真正产生体系增量的装备，应当至少改变其中一个交换关系：要么把蜂群更早从海杂波、地物背景和低空遮蔽中稳定分离出来；要么让敌方瞄准链无法形成一致判断；要么用低成本、多通道、可快速恢复的方式压低末端拦截消耗。

若后续确认存在低空低小慢目标专用探测装备，其贡献不应写成“提升预警能力”，而应落在杀伤链起点的可信轨迹供给上。它面对的核心矛盾是蜂群目标小、慢、低、数量多，容易与海面杂波、岸线反射和民用低空活动混杂，导致后续火力不是来不及打，就是打向错误目标。该类装备只有在能持续输出可分类航迹、降低虚警牵引、为软硬杀伤提前分配目标时，才对体系有不可替代贡献；一旦强杂波、低空遮蔽或多批次交叉航迹使分类置信度下降，其贡献会迅速从“提前处置”退化为“末端告警”，并把压力重新转嫁给拦截通道。

若后续确认存在电子压制或欺骗装备，其贡献口径应放在“降低敌方瞄准置信度”，而不是简单统计压制距离。它的直接作用对象不是每一架无人机的物理毁伤，而是蜂群侦察、中继、协同和导引链中的一致性。对依赖链路更新、外部定位或群内协同的蜂群，这类装备可迫使敌方弹药丢失共同目标、互相脱节或转向低价值区域，从而把末端硬杀伤压力前移到较低成本的软杀伤阶段。其失效边界也必须写清：若敌蜂群具备较高自主识别、预装航线、抗干扰导航和无链路协同能力，电子压制只能削弱部分攻击效率，不能单独保证要地和编队存续。

若后续确认存在诱饵假目标装备，其体系贡献在于改变敌方“发现即命中”的收益模型。第一岛链场景中，固定节点和舰艇编队一旦被无人蜂群确认坐标，后续防区外火力会利用同一瞄准链实施叠加打击；诱饵若能在电磁、红外、雷达反射或活动规律上形成足够逼真目标，就可把敌方侦察与弹药消耗引向假目标，使真实节点获得机动、关机、转移或再组织防护的时间。它的贡献不是杀伤数量，而是制造错误分配和火力浪费；若敌方具备多源交叉验证、近距视觉复核或长期模式识别，诱饵贡献会随暴露时间增长而衰减。

若后续确认存在低成本硬杀伤或点防御装备，其贡献必须以末端交换比和持续作战能力衡量。它面对的是蜂群已经穿过探测和软杀伤区后的最后压力，关键不在单发命中率口号，而在单位时间可处理目标数、单次处置成本、备弹或能源恢复速度，以及能否在多波次间维持防护闭合。只有当其边际防护成本低于敌方边际突防成本，并能在拦截后快速确认毁伤和恢复通道时，才会把传统“高价弹逐架拦截”的亏损交换改写为可持续拒止。若再装填慢、目标分配慢、毁伤确认不清或对混合诱饵大量开火，则会再次被敌方低成本波次拖入消耗劣势。

因此，本栏能确认的体系贡献判断只有一项：第一岛链反无人蜂群项目的有效装备组合，必须分别在“早发现并可信分类”“扰乱敌瞄准一致性”“诱导敌火力误投”“低成本末端清除”四类不同交换关系上形成可验证增量。具体哪一件装备贡献最大，取决于后续补齐的装备本体事实；在缺少 `capability_cues` 的情况下，任何按装备名称排列的贡献率、优先级或百分比都不具备证据基础。
