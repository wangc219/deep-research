## 五、研制基础

### （二）技术基础

技术基础要回答：七型装备改按波、截面、时段或体积清账后，既有工程与试验条件能否承接。可继承基础决定研制起点，新增工作决定主攻方向，实测缺口决定立项前先补的验证。

| 装备 | 可继承成熟基础 | 新增研制工作 | 可研缺口及试验/供应链条件 |
| --- | --- | --- | --- |
| 随浪伏击反蜂群弹 | 坐底自持、水声阵、水下出水运载器成熟，可按水深底质预置。 | 判明收窄为“过顶声包络”并弹内自主起爆，穿浪时延按波速/密度装订。 | 浅海混响下判明距离与虚警漏放无实测，坐底寿命、补投与净空未验证，须海区长期靶试。 |
| 掠波连扫拦截机 | 可复用无人机低空定高与快返再装填成熟，软性展开载荷可迁移。 | 不装识别跟踪设备，按波级提示对准波前层掠穿，标定刃带展宽、密度衰减与趟次接力。 | 单趟清削率随波前密度/高度无定量数据，提示可用性未过强电磁对抗试验，须靶机波前按趟—截面考核。 |
| 驻空扫域电磁灭群巡飞弹 | 宽频高功率微波源与效应测试设施成熟，巡飞弹供电与热管理可承接。 | 源/天线/供电同弹压缩并按驻留时段维持平均功率，频率—功率—效率同表折衷。 | 弹载微波有效作用距离与重复频率无实测，毁伤阈值须自建效应试验，决定扇区覆盖与接力密度。 |
| 引浪吞波聚爆诱杀弹 | 固态宽频源与辐射节律复现已工程化，温压—破片战斗部成熟。 | 低造价复现真节点脉内/扫描/功率起伏的不可辨仿形，收拢判据引信防早炸，间距按超压与破片双约束实测。 | 敌分选算法与收拢弹道包线未知，无成本/产能数据，须指纹比对与成组靶试后锁主攻。 |
| 迎面撒网捕蜂拦截弹 | 网捕反无人机有公开演示，网材与系留气球滞空产业成熟、低成本。 | 成串软包按走廊入口投撒、迎风自展横张网幕，网目按缠绞选型，错时补网与核销。 | 缠裹率随撞击速度、强风保形无公开数据，网幕耗尽须光电复核，补网周期按敌波次间隔实测。 |
| 过境层云爆轰断波弹 | 云爆多点同步起爆有先例，车载储液雾化铺撒成熟。 | 改作海面整层高度、数公里纵深成层—守候—同步起爆，防早燃保浓度，多车同步与再铺管理。 | 海上风/湿下公里级成层与体爆轰无试验证据，判窗误差与空海避让须实弹层域试验。 |
| 撞线自付近防弹巢 | 被动近距感知、近炸引信与微型战斗部货架化，可批量制造。 | 开火只认真撞击末端航段以剔除圈外诱饵，数十米迎面起爆的杀伤锥与自防护间距。 | 证据最薄：诱饵近真末端试探的误触发率与判别时延无量化依据，须混合靶试定边界，宜先样机。 |

收束：水下过顶声判明、弹载宽频效应、海面公里级成层三处最大缺口均无实测，应优先海区与靶场试验；其余各型按自身工况边界靶试标定即可闭合。网材、电池、燃料、固态源与可复用平台均在现有产业链射程内，真正短板是大空间、长航时、按整批结算口径的试验设施，而非材料来源。
