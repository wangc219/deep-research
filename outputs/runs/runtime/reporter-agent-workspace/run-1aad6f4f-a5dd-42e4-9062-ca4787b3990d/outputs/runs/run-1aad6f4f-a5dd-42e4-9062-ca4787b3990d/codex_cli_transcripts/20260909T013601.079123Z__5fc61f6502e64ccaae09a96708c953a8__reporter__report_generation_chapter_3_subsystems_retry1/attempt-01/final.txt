三、总体方案

（二）子系统方案

随浪伏击反蜂群弹应采用坐底潜藏式发射筒，平时负浮力静默待机，仅由被动水声阵监听贴海密集波次，不依赖常开数据链。它不追求逐架定位，而是识别波群来向、密度和过顶时刻，达到判据后自主垂直穿浪，在掠海高度展开破片杆幕。其输入是水深、底质、潮汐、航路和本底噪声条件，输出是波次判明时刻、毁伤动作和末端残余预测。工程验证应优先覆盖浅海混响下的漏判、虚警、判明至起爆时延，以及长期坐底后的电池、密封、再激活和安全自毁；敌改走高空、绕开走廊或先期清海时，只能由其他防线接替。

掠波连扫拦截机的核心不是目标搜索，而是可重复进入预定截面的飞行平台与横向破片刃带。体系只需提供波前到达时间、走廊位置及宽度高度带，平台按法向切入波前，完成“掠穿—拉出—再穿”的循环，输入输出关系由单机航迹改为波前截面和每趟清削量。其关键接口是波级预警、飞行定高、载荷再装填和末端漏网移交。验证重点应是刃带有效展宽、破片密度衰减、单趟清削率、连续出动节拍及敌诱饵波前造成的空扫风险；敌改为多方向小群异步渗透时，该装备降为补充拦截手段。

驻空扫域电磁灭群巡飞弹应做成一次性驻留平台，由弹载能源、宽频高功率微波源、定向天线和热管理单元组成。它根据来袭主扇区和保护时段前置占位，反复照射覆盖域，不以单目标装订；输入是扇区、到达时序、禁扫方向和己方电磁兼容约束，输出是覆盖域内无人机失能、掉队或坠落，以及需要硬杀伤接续的目标比例。关键接口在低空监视、节点禁扫区、驻空轮换和反辐射规避。验证不能只看击落架数，还要测有效照射占空比、覆盖域内能注分布、不同抗扰机体的失能概率和驻留体中断时间；高抗扰目标、地形遮蔽和驻留体被先期摧毁时，必须立即转交动能防御。

引浪吞波聚爆诱杀弹服务于辐射节点的近界防护，产品形态应是可成组贴设的仿形主动辐射诱爆单元，配合真节点静默管理和收拢判定引信。其控制重点不在远程指挥，而在诱源谱形、功率包络、扫描节律与真节点静默时序的一致性；输入是节点伪装构型、敌弹来向和收拢状态，输出是对收拢弹群的温压破片整簇清算。接口包括节点关机与备份设备管控、诱饵组同步、近界安全间隔及残余目标硬杀伤移交。应通过成组对抗试验验证诱源逼真度、敌弹收拢率、误触发率和单轮清算比。敌改用预编程、光学确认或先清扫诱饵时，机制退化为普通诱饵，不能替代点防御。

迎面撒网捕蜂拦截弹应以无源网弹、成串投放机构和可再生布撒平台构成封段子系统。它依靠低空走廊的几何约束，在入口和中段形成迎风展开的柔性网幕，以整簇缠裹替代逐架制导。输入是走廊宽度、来流方向、波次间隔和风场，输出是按段核销的缠坠数量及漏过数量。关键接口是走廊定带、气球或运输机投放、沿线光电复核和远程火力接续。验证应集中在乱流下成网完整度、网幕在位时间、小目标缠绞率、补网周期和己方净空安全；走廊过宽、风场不利或敌改走高空时，装备不应强行使用。

过境层云爆轰断波弹不是单发制导弹，而是车载储喷成云与同步触发系统。车辆依据外部预警给出的低空过境时间窗，在末端走廊铺设覆盖目标高度带的可爆气溶胶层，待层完整性满足条件且波次主体进入后同步触发。输入是过境时间窗、航速、高度分布、风场和层浓度状态，输出是整层体积毁伤、波次破队和残余目标补漏请求。接口包括判窗传感器、车载喷洒装置、多点触发网络、空域管制和点防御。由于材料未提供海上成层与同步爆轰试验依据，首要验证应是缩比海上铺层、浓度保持、风雨影响、同步触发和诱饵试触后的再铺能力；任一环节不稳，只能保留为受限窗口方案。

撞线自付近防弹巢应采用分布在节点外缘、顶面和伪装体周边的无辐射一次性弹巢，控制逻辑只判断目标是否进入真正撞击航段，不承担远程识别。其输入是节点几何、禁入区域和近距撞线状态，输出是迎面起爆、引爆来袭战斗部或直接毁伤机体。关键接口是节点伪装与安全隔离、友邻航迹管制、弹巢状态自检和战果复核。验证应围绕末端航段判定的抗诱骗能力、近距起爆安全窗、连续多目标触发和误伤概率展开。圈外巡飞、过航诱饵不应触发；但目标从高空俯冲、远距投放或采用非撞击攻击时，弹巢只能作为最后一道局部防护。
