五、研制基础

（一）参与单位

项目七型装备机理域跨度大，分属水下声学、空中机械面、电磁、热化学与无源近距触发等不同工业门类，参与单位须由产品责任与试验责任反推落位，不能以统一总体—分系统分工覆盖。随浪伏击反蜂群弹的责任在坐底自持、被动水声阵对过顶波次的低虚警判明与穿浪—杆幕触发时序，须水下武器总体与水声传感两类单位，关键接口在船艇或无人潜航器布设及禁航安全协调，试验须置于浅海混响与风浪本底中实测判明概率、虚警率与长期坐底再激活，海区水声试验鉴定机构因此入列；相应海区声学本底与敌过顶队形声样本现缺，具体承研归属无公开依据。掠波连扫拦截机的责任在按走廊占位、破片刃带展开与按趟再生出动，对应布撒平台总体与掠穿包线试验单位；迎面撒网捕蜂拦截弹的责任在网幕迎风展开、成串投放与补网节拍，另需柔性网材与落网清点取证接口单位。

驻空扫域电磁灭群巡飞弹的关口在弹载宽频高功率源、电源热控与天线折衷，须高功率微波源与效应评估单位会同弹载能源单位，交付典型无人机飞控、电调的耦合失效阈值与电磁兼容边界。引浪吞波聚爆诱杀弹须电子对抗仿形与弹药引信单位联合，将真假源不可辨度、收拢判定抗诱骗做成外场可检验判据。过境层云爆轰断波弹对应车载成层总体与爆轰试验单位，须在海上风场验证成层保持、浓度边界与同步起爆；撞线自付近防弹巢对应无源近距触发引信单位，以误触发率与对真撞击的响应可靠性为交付证据。

各类单位共同接口是向指控体系交付触发判据、失效边界与战果核销格式，支撑走廊后段声学与光电哨位逐段对账。公开证据仅能界定上述单位类型并列出缺失证据，具体机构归属、成熟度与产能不作指定，须待立项阶段以针对性试验大纲反向确认。
