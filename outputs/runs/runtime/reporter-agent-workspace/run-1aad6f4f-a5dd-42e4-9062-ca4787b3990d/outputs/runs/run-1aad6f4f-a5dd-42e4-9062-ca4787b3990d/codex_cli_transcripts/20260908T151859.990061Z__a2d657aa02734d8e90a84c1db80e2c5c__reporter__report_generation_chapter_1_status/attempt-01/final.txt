（二）国内外现状

本栏只比较与本项目任务、装备机理和工程基础直接相关的公开事实，两侧不作对称罗列，并始终区分类别事实、具体案例、参数证据与推断边界。

1. 国外情况

可核验的外军事实集中于美国两份公开文件。类别事实层面，美国防部2024年12月发布反无人系统战略，把低成本无人系统规模饱和视为关键设施与兵力集结地防护的首要矛盾，确立联合反小型无人机办公室牵头、以Replicator 2推进规模化低成本对抗；其前提与“拦截弹—通道经济模型被波次数量颠覆、须重构交换成本”的命题同源，表明从成本交换而非堆弹量入手的反蜂群方向在公开战略层面成立。具体案例层面，美国会问责署GAO-25-106454（2025）审计指出，国防部跨域指挥控制仍缺综合框架，互操作与数据融合治理滞后，扩大集成范围可能反增时延；外军公开暴露的滞后环节恰在跨域融合，而不是各层装备本体。

参数证据缺失须单列：两份文件均未公开反制装备单价、单次拦截成本与规模化验收数据，“低成本”是方向主张而非已验证交换值；且材料化来源没有一条落到具体杀伤机理——水下静默判明过顶、刃带按趟扫削、气溶胶层体爆轰、网幕兜捕、弹载宽频微波等均无外军公开工程对应物。推断边界随之固定：无公开对应不等于无能力，外军上述机理的真实成熟度在本底稿内既不能判定先进，也不能判定空白。

2. 国内现状（中国）

中方一侧本轮输入未返回任何可材料化来源，本栏只能区分任务给定基线、机理对应事实与缺口。可作假设而非事实的基线是：现役末端防御通道数、弹药经济性与低空多小目标探测覆盖不足以支撑数百架次波次交换——该基线本身待公开数据核验。逐机理看，判定国内现状所需证据俱缺且缺项随机理不同：随浪伏击反蜂群弹以贴海密集过顶的水声暴露为毁伤判据，缺海区水声本底与敌方典型队形声样本；过境层云爆轰断波弹要求现地成层并保持数公里可爆浓度带，缺海上成层保持与公里级同步起爆试验记录；迎面撒网捕蜂拦截弹依赖网幕迎风展开与缠绞，缺展开概率和小目标缠绞可靠性实测；掠波连扫拦截机按趟次清削波前截面，缺波级预警精度与单趟削截率数据；驻空扫域电磁灭群巡飞弹按“覆盖域乘驻留时段”结算，缺弹载宽频微波有效作用距离、重复频率与器件抗扰阈值；引浪吞波聚爆诱杀弹以敌收拢辨真为起爆窗口，缺敌分选算法与收拢弹道包线的对抗试验。撞线自付近防弹巢在输入中只有一句机理，无独立实现与验证事实，材料厚度明显低于其余方向。据此，任何“国内已具备或已落后于某机理”的表述在现底稿上均无证据支撑，只能确认为待补事实。

3. 对比小结

可闭合与不可闭合须分开。可闭合的是任务前提层：外方有战略文件、我方有任务假设，两侧以不同证据等级指向同一矛盾——低成本数量使逐架高价交换失效，故以装备本体改写计价单位的方向不受外军公开事实否定。不可闭合的是机理与参数层：外方仅有战略与治理级事实、无机理参数；中方在本底稿内连战略级材料化来源也没有。因此在现证据上，“国外领先需追赶”与“机理空白可自主占位”两类结论都推不出，能确认的仅是双方机理级公开变量俱缺、且缺口随机理而异。后续取证应据此收敛：对外核验Replicator 2与联合反小型无人机办公室的验收口径、单价文件和GAO后续审计，对内按上述各机理缺项收集公开试验与工业证据；在此之前，任何把双方差距写成确定数值或确定领先/落后的判断都须降级为待验证假设。
