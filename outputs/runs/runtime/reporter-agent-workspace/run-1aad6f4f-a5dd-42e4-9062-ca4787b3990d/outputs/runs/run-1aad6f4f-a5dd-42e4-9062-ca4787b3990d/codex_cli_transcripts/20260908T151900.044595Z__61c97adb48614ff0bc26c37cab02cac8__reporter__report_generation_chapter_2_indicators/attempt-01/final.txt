## 二、项目画像

### （四）主要战技指标

随浪伏击反蜂群弹的战果先由两类声学错误划定：漏判放走整波，虚警空耗静默伏击资产。判别指标是浅海混响与风浪本底噪声下对贴海密集群过顶的漏判率与虚警率——虚警率决定弹敢不敢起爆，须以含渔船、航运与海况差异的长时段实测样本统计，单次靶试不能认定；另一项是判明—穿浪—起爆时延与波速耦合的单弹波次覆盖率，即每波落入破片杆幕近炸半径的份额，决定接力间距与移交末端的残余规模。前者管触发门槛、后者管布设密度，缺一不能按走廊配弹。

掠波连扫拦截机的判据须先证伪成本解耦：把真弹与同外形诱饵按不同比例混装成波，重复测单趟清削率，确认清削份额不随架数与诱饵比漂移，构成其与逐架弹药的分界；其后是节奏项——单位时间掠穿趟次与刃带再生周期相对波级预警到达时刻的跟随裕度，并在预警受压制、扫削错位的工况下检验漏过栅栏的统计份额。单波过稀只摊薄单趟收益，须以更高趟次频度补足，但补趟周期不得长于敌一次航渡暴露窗。

驻空扫域电磁灭群巡飞弹的体积结算从两个入口退化：到达能注低于目标抗扰阈值，或驻留体结算前被反辐射、撞击摧毁且能储先尽。判别指标是域结算率，即单波进入覆盖域架数中的失能比例，且须用“能注超过该机种抗扰阈值的覆盖体积×脉冲刷新率”解释，只报坠落数会把点清除冒充体积清算；另一项是扣除对己电磁停照与反辐射规避后的有效照射占空比，决定敌能否借停照间隙突防。验收须自建分机种、分屏蔽程度的效应试验积累击穿阈值与失效概率；若敌仅靠廉价局部屏蔽即压低域结算率，本弹应退出该时段主用、缺口交还硬杀伤。

引浪吞波聚爆诱杀弹的战果藏在敌的确认动作里，只数毁伤架数会高估效能。指标捕捉辨真成本：真假源不可辨度（诱源载频、脉内与扫描节律的复现逼真度，叠加真节点含备份与后勤的静默完成率）决定敌能否远距分真而不收拢；收拢率与单轮清算比（进入温压破片清算带的敌弹份额、敌该波耗弹对我方一组诱爆弹成本之比）说明数量优势是否被逐次抵扣。验证以成组诱源对抗敌分选算法与收拢弹道靶试取数，另测真节点长时静默存活率；敌转单发试探后清算退化为单弹兑付，指标解释须随之切换。

迎面撒网捕蜂拦截弹以清点核销代替战果估算，判据锚在段通过率：单段缠坠架次对投放网数之比、单位时段净放行架次、补网周期对敌波次间隔之比，决定走廊是逐段闸门还是一戳即破的纱帘。网幕无源不可遥测，成网与耗尽只能靠下游光电复核，复核滞后时敌恰在补网间隙试探破口，故验收须把有效断面覆盖率与复核时延绑定，并以乱流下整网展开概率与缠绞可靠性的实投取值确定段位布设。

过境层云爆轰断波弹的失效先于爆炸：层不可维持则体爆轰退化为局部爆燃，判窗误差大于成层—守候时间则层未就位或已散。指标先测层完整性，即起爆前可爆浓度达标并连续覆盖走廊横截面的保持时间与面积占比；再测判窗—铺层时间预算，即过境窗预测误差对车辆展开与守候时间的余量；单层清账率须在诱饵与真机混编下实测起爆时机，不能按原理推定。现无公开试验数据，应先以缩比海上铺层与扩散爆轰数值仿真收敛浓度保持与同步起爆边界，再核算单车铺层面积与车组编成。

六类装备的指标均属概念层、无公开点值；敌蜂群自主性、抗扰加固水平与海区气象水文未定，设定工况内的演示不能外推为立项结论。宜以失效主线先闭合者优先——水声判明置信度、趟次再生率、能注—抗扰阈值库、诱源逼真度、网幕展开概率、成层保持时间，未闭合前不冻结总体方案。
