五、研制基础

（一）参与单位

公开材料未提供具体承研单位、型号归属或既有研制链条，因此本栏仅按装备本体责任、关键接口、试验责任和证据交付反推参与单位类型，不据此指认具体机构。

随浪伏击反蜂群弹的责任主体应是具备水下兵器总体、坐底密封与垂直出水机构研制能力的武器总体单位，并由水声探测、近炸引信和海洋工程单位配套。其核心接口不是持续指挥链，而是布设平台、海区水深底质数据、友邻航迹管制和后端战果核验。试验责任应落到浅海复杂混响、长期坐底值守、波次声学判明、穿浪姿态及破片杆幕覆盖试验单位；目前缺少海区声学背景、典型蜂群声样本和长期可靠性证据。

掠波连扫拦截机应由航空平台与面杀伤战斗部总体单位联合承研，重点交付可重复出动、稳定掠穿和破片刃带再生能力。其关键接口是波级预警、走廊几何和再补给节拍，而非单机火控。飞行试验单位需验证不同波前密度、速度和高度下的截面清削率、刃带有效展宽及连续出动间隔；现有材料没有平台速度、刃带寿命、单趟覆盖率和自身损失数据。

驻空扫域电磁灭群巡飞弹需要航空平台、宽频高功率微波源、天线、电源储能和热管理等类型单位共同承担，电磁兼容和空域安全单位负责对己方通信、导航及航空器的隔离验证。其证据交付应围绕驻留时段内有效照射占空比、覆盖域能注和不同无人机抗扰阈值展开；公开材料缺少弹载功率、有效距离、驻留时间及反辐射生存性数据，不能据此确定具体承研归属。

引浪吞波聚爆诱杀弹须由电子对抗诱饵、辐射特征仿真、近界战斗部和节点电磁管控等类型单位联合承研。产品责任集中在真假源逼真度、真节点静默保持和敌弹群收拢后的成组起爆，试验单位还需构造反辐射导引、光学辨识和预清扫等对抗条件。当前缺少敌方分选特征、诱源相似度、收拢率及真节点静默完成率证据。

过境层云爆轰断波弹涉及车载储喷系统、气溶胶扩散、爆轰起爆、气象环境和靶场安全等单位，不能由一般拦截弹总体单位单独承担。其关键接口是过境时间窗、成层完整性判读、交通净空和残余目标补漏。应由海上开放环境试验单位交付风雨湿度下的成层保持、浓度均匀性和同步起爆证据；目前没有公开的海上长距离成层与整层毁伤试验依据。

撞线自付近防弹巢的参与单位类型应包括近界弹药总体、被动末端感知、近炸引信、阵地伪装和节点防护单位。其责任边界是只对真实撞击航段触发，避免被圈外巡飞、诱饵和干扰消耗；试验需证明误触发率、近界毁伤范围、友邻目标安全净空及连续波次补充能力。该方向公开证据最少，缺少感知判据、触发可靠性、成本和部署密度数据，暂只能保留机构类型判断。
