三、总体方案

（二）子系统方案

本项目不宜按“探测、干扰、拦截”统一拆分，而应按各装备改写交战关系的方式确定子系统边界。随浪伏击反蜂群弹依靠水下静默伏击，把低空蜂群的必经过顶转化为水声触发窗口；掠波连扫拦截机依靠横向刃带反复穿越波前，把杀伤单位由单架改为截面；驻空扫域电磁灭群巡飞弹依靠驻留时间覆盖空域，把逐架消耗改为区域清算；引浪吞波聚爆诱杀弹则以真假节点制造弹群收拢，再由近距聚爆完成批量毁伤。其余装备分别承担走廊截断、时间窗拒止和节点末端自卫，不能用同一套传感器、火控和验证指标替代。

| 装备 | 产品形态与控制机理 | 必要输入输出、关键接口及工程验证 |
|---|---|---|
| 随浪伏击反蜂群弹 | 采用坐底潜藏式弹体，平时不辐射、不联网，仅以被动水声阵监听密集低空蜂群形成的过顶声学事件；判明波群来向和过顶时刻后，弹内自主完成穿浪、姿态修正和掠海层破片杆幕起爆。它的作用对象是整波，不承担单机识别。 | 输入是布设海区的水深、底质、航路和水声背景，输出为波次毁伤与过顶时刻判明结果，后端可据此调整远程火力接续。接口应保持单向、低暴露，并允许通信中断时自主运行。验证重点是复杂海况下的漏判、虚警、判明至起爆时延、破片幕有效高度和长期坐底后的再激活可靠性；敌绕开走廊、先期清海或改变高度后效能降级。 |
| 掠波连扫拦截机 | 采用可重复出动的平台和横向展开式破片刃带，不配置逐架搜索、识别和末端寻的链路。平台根据波前的走廊位置、宽度、高度带和到达时间侧向切入，穿越一次完成一笔截面清削，再按剩余航渡时间组织下一趟。 | 输入只需波级到达提示和截面几何，输出是被削弱的波前密度，不要求逐架战果确认。与预警和指控的接口应压缩为时间窗、走廊段和高度层，保障接口则围绕刃带补装、平台再出动和能量周转建立。验证应比较不同密度、间距和高度剖面下的单位时间清削率、截面覆盖连续性和再出动节拍；敌改用多方位小群异步渗透时，须由点防御接管。 |
| 驻空扫域电磁灭群巡飞弹 | 以一次性驻空平台承载宽频高功率微波源、定向天线和储能系统，在节点上空占位，对来袭必经扇区按周期反复照射。其控制对象是覆盖域和驻留时段，而非单架目标；脉冲刷新、扇区切换和轮换补位决定连续防护能力。 | 输入是威胁主扇区、到达时序、己方禁扫方向和电磁兼容约束，输出是覆盖域内无人机失能、掉队或坠毁比例。接口重点是预警指示、对己方平台的禁扫管理和驻空单元接力，不应把逐架授权作为必要环节。工程验证须建立不同机体抗扰水平下的有效作用范围、重复照射占空比、驻留时间、热管理和己方设备安全边界；全面加固目标、地形遮蔽和反辐射攻击是明确失效条件。 |
| 引浪吞波聚爆诱杀弹 | 采用贴近真节点布设的仿形主动辐射诱杀弹组，真节点保持静默。诱杀弹复现高价值节点的主要辐射特征，诱使反辐射弹药向其收拢；当弹群进入预定近距包线后，弹组以温压和破片完成成批清算。 | 输入是目标节点的辐射特征、静默时序和诱饵在位状态，输出是敌弹群收拢率、单轮清算结果和真节点静默存活时间。接口不在于持续引导，而在于节点静默纪律、诱饵组轮换和末端硬杀伤补漏。验证应围绕真假源不可辨度、敌方收拢比例、引信抗诱骗能力、聚爆对真节点的隔离距离和诱饵补充周期展开。若敌改用预编程、光学直击或远距发射，诱爆条件可能不再出现。 |
| 迎面撒网捕蜂拦截弹 | 采用无源网弹、成串投放载具和按段布设的低空网幕。网弹不依靠制导和电子识别，出舱后借相对气流展开柔性网体，在走廊断面迎面缠裹密集蜂群；其核心不是追击，而是把低空窄带变成可清点的机械闸门。 | 输入是走廊入口、风场、来波方向和波次间隔，输出是各段净通过量及落网清点结果。关键接口是走廊段位标定、投放节奏、下游复核和爬升目标移交远程火力。验证重点是成网完整率、有效断面覆盖、包裹率、补网周期和强侧风条件下的保形能力；走廊过宽、敌高空绕行或波次间隔短于补网周期时，不能承担主要防御任务。 |
| 过境层云爆轰断波弹 | 采用车载储喷、成层保持和多点同步起爆组合，依据低空蜂群过境时间窗，在末端走廊现地形成短时覆盖层域的毁伤门。它把防御计价从逐架命中换成过境时间切片，目标是削平同一时间窗内的并发峰值，而非追求单机跟踪。 | 输入是过境时间窗、飞行高度带、风场和走廊几何，输出是层内成批毁伤及残余波次的时间、方向信息。关键接口集中于外部判窗、成层完整性判读、己方航路净空和残余目标补漏。工程验证首先要回答开放海况下层域保持、浓度均匀性、同步起爆和对己方平台的安全隔离问题；若敌改道、分层越过、以假波耗尽布设或气象导致成层失稳，该方案不能替代常规拦截。 |
| 撞线自付近防弹巢 | 采用围绕受护节点外缘、顶面和伪装体布设的一次性无源弹巢，依靠末端航迹、速度变化或接近方向判断目标是否真正朝节点撞击；仅在进入近距撞线条件时自主起爆，圈外巡飞、过航和普通诱饵不触发。 | 输入是节点周边安全净空、弹巢布设位置和末端接近特征，输出是对真实撞击目标的近距先敌毁伤。接口应尽量少依赖通信，重点与节点伪装、民用活动管制和残余目标复核衔接。现有材料缺少传感方式、误触发率、有效杀伤距离和安全隔离数据，工程验证应先证明“真实撞线才触发、非攻击过航不消耗”，再评估弹巢密度、维护周期和战场回收；在缺乏这些试验前，不应把它列为确定性主防层。
