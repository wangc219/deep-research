二、项目画像

（三）体系贡献率分析

随浪伏击反蜂群弹对应的是沿海、岛礁浅近海低空通道的关键差距。现有“雷达发现—火控跟踪—逐架拦截”在海杂波、低空盲区和蜂群密集过顶条件下容易把防御压力推迟到末端，导致漏检与弹药消耗同时增加。本装备把坐底被动水声判明作为接敌入口，在敌为隐蔽而必须贴海成波航渡时，于过顶瞬间垂直穿浪，以破片杆幕处理一个波次，而不是逐架寻找目标。它直接削减抵达末端的架数，并给后续火力提供较明确的波次时间基准，使末端由承受完整饱和峰转为处置残余目标。电子干扰、诱饵和隐身难以取消水声暴露，但敌改走高空、分散多路或先行反潜清海后，贡献会降为局部通道拒止；其成败取决于海底条件、声学虚警、长期待机和布设后能否保持接力。

掠波连扫拦截机填补的是低空走廊持续消耗能力，而非单架拦截能力。它不把目标识别和末段寻的作为前提，而是在波前截面上反复掠穿，利用横向破片刃带一次削去一段编队。相对逐发拦截弹，本装备的成本结算随出动趟次发生，不随截面内无人机数量、真假构成同步增长，因而敌加密波次和堆叠诱饵不能直接抬高我方边际消耗。直接战果表现为敌输送链难以按时齐到，必须增加冗余投放；若拉稀或减速，则在走廊暴露更久，航渡时窗和能源预算反而被消耗。它的贡献建立在敌仍形成可预报、可扫削的集中波前上；一旦改为多方位小群异步渗透，或波级预警被诱骗，单趟收益便会退化，末端点防御仍不可撤除。

驻空扫域电磁灭群巡飞弹针对的是节点上空防护时段内的数量压制。传统防御按来袭架数逐一消耗，最容易被低价无人机和诱饵拖垮；该弹在岛礁、前进机场或舰队核心上空占位，以宽频高功率微波反复覆盖来袭空域，使未充分加固的飞控、电调和数据链在进入覆盖域后失能、掉队或坠落。它将交换单位由“命中一架”改成“驻留时段覆盖一个空域”，直接保持节点电子可用并切断蜂群协同链。敌若逐架加固，重量、成本和航程受到反向约束；若以高价值火力清除驻留体，又形成以贵击廉的交换。可是，高抗扰目标、地形遮蔽、多扇区同时会聚和反辐射打击会压缩作用范围；弹载能源、热管理、对己电磁兼容和有效占空比尚无材料化数据，不能把区域清算能力外推为普遍硬杀伤。

引浪吞波聚爆诱杀弹改变的是高价值辐射节点的生存方式。面对反辐射无人机和巡飞弹按“先辨真、后压制、再投载荷”推进的攻击，单纯关机或依靠拦截会牺牲节点任务连续性。本装备将仿形主动辐射诱源贴设在真节点旁，使真源静默、假源承担暴露；敌若依靠反辐射引导辨别真假，就会把成批弹药导向诱源，并在收拢时被温压与破片整体清算。直接效果不是多击落几架，而是延长真节点静默存活和轮换开机时间，使警戒、通信与防空引导链不断裂。其贡献只对必须依赖辐射收敛的攻击链成立；敌改用预编程、卫星或光学直击，或先清扫诱饵阵地，机制即明显退化。诱源逼真度、真节点静默纪律和收拢触发可靠性，是决定其能否由概念变为装备的关键缺口。

迎面撒网捕蜂拦截弹提供的是低空走廊的无源封段能力。敌为避开远程雷达点名而被地形压入窄带时，网弹可由高空气球或运输机成串投放，依靠迎面气流展开柔性网幕，以缠裹旋翼和气动面使密集前排失速坠落。它绕开探测、识别、制导和电子抗干扰链路，每起一网即可形成可复核的段清点事件，直接把末端饱和峰拆成逐段漏隙流。敌干扰、诱饵和隐身对机械接触不起作用；爬升会暴露于远程火力，拉散会破坏同时到达，破网加固则抬高单机成本。不过，走廊过宽、风场不利、补网跟不上波次或投放平台先被摧毁时，网幕无法形成连续闸门；它必须依赖外层火力把敌压回可覆盖几何，不能单独承担全空域防御。

过境层云爆轰断波弹承担的是末端高并发时间窗的峰值吸收。点防御通道数有限，蜂群同时进入时，逐架拦截的漏过率会随并发量上升。本装备由车载平台在可判定的低空走廊时间窗内现地成层，待目标整体进入后同步触发体爆轰，以体积超压和卷吸批量破坏薄壳机体，把拦截计价从架次改成过境时间切片。其直接贡献是先打散最高密度的一段，让残余目标回到点防御可承受范围；敌若弃窗便失去突袭时机，若拉长分散则密度和协同质量下降。该构想的体系价值高，但工程边界最严，风、湿度、湍流、浓度保持和同步起爆任何一项失效，都会使整层清账退化为局部毁伤；对高空、绕行和耐受目标也不能替代其他手段。

撞线自付近防弹巢属于末端最后一道低暴露补强，解决的是诱饵、过航目标把近防弹药提前耗空的问题。它在节点外缘和顶部伪装体附近分散布置，无人值守、不辐射，只在目标进入真正朝节点撞击的末段航段时由最近弹巢自主起爆。相较需要持续搜索、识别和逐架授权的近防链，本装备把开火条件收窄到“确实撞线”，圈外巡飞、伴随干扰和无效诱饵不再轻易触发消耗，直接提高节点最后几十米范围内的存续概率。其交换优势在于敌若要骗取弹巢，必须让假目标完成接近真实撞击的高代价动作；但对预编程直击、超低空掠过、顶部投放和多方向同时撞击，单个弹巢覆盖有限，仍需依靠合理布设和多层补漏。现有材料未给出触发判据、覆盖间距、误击率和再装填条件，贡献应暂按末端补强而非独立体系解法计。

综合比较，七类装备并非简单替换拦截弹，而是分别把敌我交换单位改写为波次、截面、驻留时段、辨真动作、走廊段、过境时间片和真实撞线事件。按现有材料能够确认的相对基线，随浪伏击反蜂群弹对浅近海密集过顶构成关键差距补链，掠波连扫拦截机和迎面撒网捕蜂拦截弹主要承担部分差距的低成本外层削峰，驻空扫域电磁灭群巡飞弹和引浪吞波聚爆诱杀弹分别强化区域软杀伤与节点反辐射生存，过境层云爆轰断波弹具有较强峰值拒止潜力但验证风险最高，撞线自付近防弹巢则是满足末端补漏需求后的低暴露增量。由于材料没有现有部署、在研型号、成本和实测工况，不能据此给出量化贡献率；后续应优先用波次压力、走廊几何、声学与电磁环境、敌自主化程度及连续防护时长检验各装备的成立边界。
