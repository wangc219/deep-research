二、项目画像

（四）主要战技指标

本栏输入未提供经过确认的具体装备型号、现役基线参数及各方向的 `capability_portrait`，因此以下指标按任务中已经明确的三类装备本体命题提出，属于可证伪的需求判据，不把未经证实的点值写成既成能力。指标选择围绕蜂群攻击最可能造成的三处断裂：低空发现分类不可信、敌瞄准链无法被稳定改写、末端拦截在多波次中先耗尽。

低空多目标探测装备的首要战果，不是单次发现距离最大，而是在沿海、岛礁和舰艇编队常见的地海杂波、低空遮蔽条件下，持续把低小慢目标转化为可供交战的可信航迹。其判别性指标应包括典型蜂群规模下的首检成功率、连续航迹保持能力、多目标分类正确性、虚警对操作员和交战授权的污染程度，以及从目标出现到形成可用告警的时间。只有当装备能在目标尚未进入软硬杀伤包线前完成稳定分类，后续干扰、诱骗和拦截才有实际触发依据；若只能在单目标、开阔背景或目标已接近阵地时获得漂亮探测数据，不能改变杀伤链起点失效的问题。验证应采用海杂波和低空掩护环境中的混合蜂群，记录漏检、误报、航迹中断和告警延迟，而不是只验静态探测距离。当前仍缺少敌方无人机典型雷达散射特征、实际飞行高度分布和我方现役传感器布势资料，具体门限需由补充试验确定。

面向敌瞄准—导引链的电磁压制或欺骗装备，直接作战效果应体现为敌方侦察结果不再能稳定支撑编队或要地的精确指向，使蜂群出现失协同、误跟踪、偏航或对假目标实施无效攻击。它的核心指标不宜沿用探测装备的覆盖率，而应考察在敌方主动侦察、跳频通信和多节点中继条件下，对目标观测一致性的破坏程度：包括有效作用扇区和持续时间、对多架目标及中继节点的同时作用能力、压制后敌方航迹或指向的偏移稳定性，以及受干扰后重新建立协同所需时间。装备必须能够在不依赖敌方链路完全暴露的情况下形成可观察效果，否则只能证明“发射了干扰”，不能证明改变了交战关系。验证应设置侦察型、巡飞攻击型和具备自主航行能力的混合目标，比较干扰前后的定位误差、编队保持、目标选择和重新入链时间。若对手采用不依赖外部通信的全自主攻击，软杀伤效果可能显著下降，此类自主程度、抗干扰设计和载荷末制导方式是本方向成立边界。

承担末端处置的低成本硬杀伤或点防御装备，必须解决的是多波次交换关系，而非单发命中率。其直接战果是让蜂群在进入要地或舰艇关键部位前持续减员，同时保留足够的通道数、弹药量和再次接战能力，使防御节点不因第一轮拦截成功而在后续波次失去处置能力。判别指标应根据其制胜机理设置为单位时间可同时处理的目标数、连续波次中的有效处置率、从发现确认到发射的反应时间、再装填或恢复时间，以及单次处置资源消耗与目标价值之间的交换关系；其中任何一项都不能由“单目标命中率”替代。验证应在诱饵先导、蜂群密集突防和防区外火力伴随压制的组合压力下，连续实施多轮攻击，观察弹药耗尽、通道堵塞、能源恢复和关键设施受损的先后顺序。若装备仍依赖昂贵弹药逐架处置，或无法在波次间恢复交战能力，即使单轮拦截率较高，也不能支撑本项目的成本优势。现有资料尚未给出拦截弹单价、备弹规模、目标波次间隔和阵地补给条件，这些变量决定最终判退线。
