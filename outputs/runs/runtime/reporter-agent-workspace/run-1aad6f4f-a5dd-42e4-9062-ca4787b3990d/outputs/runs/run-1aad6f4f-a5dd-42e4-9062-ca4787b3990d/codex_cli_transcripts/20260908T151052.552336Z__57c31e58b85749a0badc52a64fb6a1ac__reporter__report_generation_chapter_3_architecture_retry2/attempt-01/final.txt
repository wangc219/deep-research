三、总体方案

（一）总体架构

总体架构按敌突防进程的空间界面分层设伏，不以杀伤手段归类，避免把单装机理抽象成统一公共层。水下界面由随浪伏击反蜂群弹以被动水声判明过顶波次、整波清账；走廊中段由掠波连扫拦截机对波前截面反复趟削、迎面撒网捕蜂拦截弹按段缠收；节点临近空域由驻空扫域电磁灭群巡飞弹按驻留时段行体积照射、过境层云爆轰断波弹按过境时间切片整层爆轰；节点本体由引浪吞波聚爆诱杀弹迫使反辐射弹群收拢后成簇销毁、撞线自付近防弹巢仅对真正末端撞击自主起爆。

层间真正共享并改变结果的不是毁伤机理，而是三项状态：以走廊号位加到达时刻窗替代逐架航迹的波级事件状态，使判过顶、对波前、占位成层均只依赖低带宽波级提示；布设与驻留节拍状态，伏击接力密度、网幕补投、巡飞轮驻、云爆再铺均按残余放行量调节；净空与自主触发权限，无辐射自主触发与宽域能投装备共用禁入区划定与解除保险判据。衔接只传递残余架数、到达时刻预测与失效段位，末端按真实撞击与落网核销回流修正前层密度。

失败耦合有三：波级判窗失准使伏击、连扫、云爆同步错位，末端自主触发不依赖判窗故可兜底；敌改多路小群或高空分散时，依赖集中走廊几何的伏击、撒网、云爆与截面趟削同步退为补充，改由电磁体积清除与诱杀、撞线两类节点自主手段按各自触发条件接续；前层漏放沿走廊累积至末端，撞线弹巢按真实撞击次数线性消耗，恢复周期以弹巢库存与补设节拍为界。
