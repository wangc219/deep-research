## 二、项目画像

### （二）作战运用模式

#### 1. 作战运用流程

第一岛链沿海要地、岛礁和舰队节点面对的不是单一无人机来袭，而是低空蜂群与防区外火力同时压迫：敌以低小慢目标贴海航渡，利用海杂波和视界遮挡缩短我方发现时间，再以诱饵、干扰机和自杀式无人机消耗末端拦截通道。作战运用的关键，不是把现有拦截弹数量简单做大，而是在敌进入末端前改写交战对象、交战位置和成本结算方式，使蜂群不能以完整波次按时抵达。

“随浪伏击反蜂群弹”适合部署在敌必经的浅近海低空航渡走廊，作为最外沿的静默清波层。战前按水深、底质、潮汐和敌惯用航路布放，战时不依赖持续联网，仅用被动水声阵监听贴海密集波次形成的过顶声学事件。当判明波群方位和过顶时刻后，伏击弹从水下垂直穿浪，在掠海高度层内展开破片杆幕，直接削减整波而非逐架追踪。多枚弹沿走廊接力，可使同一波次连续折损，末端防御面对的是数量已被预减、到达时间已被提前判明的残余目标。敌若爬升规避，便脱离海杂波掩护并暴露给远程火力；若先行反潜清海，则必须提前暴露突袭批次并消耗时间。其效能受海区适配、声学背景、敌方航速和预置走廊准确性限制，绕行或改用高空分散编组时转为有限的通道拒止手段。

“掠波连扫拦截机”面对的是在固定近岸走廊内成波推进、波内混入诱饵并可持续加量的蜂群。它的决定性动作不是搜索和锁定单机，而是依据波前到达时间、走廊位置及高度带，提前进入敌波前截面，横向展开破片刃带并反复掠穿。一次出动按“趟次”结算，清削对象是整段波前截面，截面内目标数量和真假构成不再直接抬高我方单次成本。这样，敌加密单波不能有效压低我方交换率，投放诱饵也不能让真弹穿过刃带；敌若拉稀或减速，虽然降低单次损失，却会延长在走廊的暴露时间，消耗自身航渡和协同预算。多机接力应以波前节拍和刃带再生率为核心，漏过栅栏的少量目标再交由末端点防御处置。该装备的成立条件是敌仍受走廊几何约束并形成可扫波前，若改用多方位、小群、异步渗透，截面清削收益会迅速下降。

“驻空扫域电磁灭群巡飞弹”用于节点上空的中段区域封控。远程预警判明来袭主扇区后，巡飞弹前出至受护节点与蜂群之间的高位驻留点，面向必经空域反复发射宽频高功率微波脉冲。进入覆盖域的廉价无人机不必逐架被识别，只要其飞控、电调、数据链或导航接收环节未充分加固，就可能因复位、误码、失控或停摆而退出编队。该装备把消耗单位由“来袭架数”换成“驻留防护时段”，因此敌增投数量不再线性增加我方边际支出。敌若逐架屏蔽加固，单机重量、成本和航程受到反向约束；若使用昂贵火力打击驻空弹，则形成高价值弹药换一次性防护单元的交换。其直接效果是削弱蜂群的协同密度并压低进入末端包线的目标量。能量储备、热管理、有效照射占空比和敌机抗扰水平是主要边界；高抗扰目标、地形遮蔽目标及突破主波束的目标仍须由硬杀伤接续。

“引浪吞波聚爆诱杀弹”部署在高价值辐射节点旁，适合对抗反辐射无人机和依赖辐射源收敛的自杀式弹药。真节点按计划静默，诱杀弹成组仿形并主动辐射，使敌无法在远距确认真假。敌若要完成辨真，就必须让一批导引弹药向诱源收拢；当目标进入预定空间包线，诱杀弹以温压和破片整簇起爆，直接清算该批导引头。此动作把敌的“目标确认”转化为我方毁伤窗口，打断其“先诱耗、再压制、后送载荷”的波次顺序。敌越依赖反辐射收敛，越可能在辨真阶段先付出成批损失。该装备不适用于预编程、卫星引导或光学确认后直击的攻击链；真节点静默不彻底、诱饵辐射特征不逼真，或敌改以小批试探，都会使整簇清算退化为有限诱饵消耗。

“迎面撒网捕蜂拦截弹”用于低空走廊入口和中段的封段拦截。敌为规避远程雷达点名而压低高度并沿地形形成的窄带航路，反而为网弹提供可预置的拦截断面。高空气球或运输机按来流方向成串投放，网弹依靠迎面气流展开大面积柔性网幕，迎头进入的无人机被旋翼和气动面缠裹后失速坠落。装备不携带搜索、制导和辐射设备，电子干扰、诱饵和低可探测外形均不能改变机械接触结果；每起一网还可通过下游观测形成可核销的清点事件。敌爬升即暴露于远程火力，拉散则失去饱和密度，逐架加装破网装置又会抬高成本并压缩载荷。其失效因素主要是走廊过宽、风场不适、补网速度跟不上波次，或敌改走高空和多路分散航线。

“过境层云爆轰断波弹”承担末端走廊吸收峰值的任务。当预警链能够较可靠地判明敌蜂群低空过境时间窗和高度带时，车载平台在海上或沿岸咽喉段快速铺设可爆气溶胶层，待敌主体进入层域后同步起爆，以超压、火球和卷吸效应成批毁伤薄壳无人机。它把拦截计价从逐架交换改成按过境时间切片清账，使原本超过点防御通道数的并发蜂群被压缩为一次区域性毁伤事件。破队后的零散目标再由少量精确火力补漏。敌可弃用该时间窗、拉长队形或改道，但这些动作会降低同时到达密度并增加航渡暴露。该概念的关键成立边界是气溶胶层在海风、湿度和湍流中的保持能力，以及成层、守候和同步起爆的可靠性；若判窗错误或层域不完整，效果会退化为局部毁伤。

“撞线自付近防弹巢”是最后一道无人值守的节点贴身防护。弹巢布设于重要节点外缘、顶面和伪装目标周边，不主动辐射，不依赖外部持续指挥，仅在目标进入真正指向节点的末端撞击航段时自主触发，近距离迎面起爆或直接毁伤机体。其关键不是提高远距命中率，而是把开火条件收窄到“确实会撞击”的最后航段，使外围巡飞、过航和低成本诱饵不触发、不消耗。敌若以诱饵骗取弹巢，诱饵必须完成接近真实撞击的动作，诱饵放空火力的经济优势随之消失；反辐射压制也找不到持续辐射源。该装备直接保护节点关键设施和人员安全，但覆盖范围有限，弹巢触发判据、误伤隔离、补充周期及对高速目标的时间裕度仍需验证。

#### 2. 链路闭环分析

上述装备形成的是按敌方交战几何分层的反蜂群链条，而不是若干同质化拦截器的简单叠加。水下伏击弹先在电磁探测难以稳定工作的贴海段削波；网弹在可预测低空走廊把密集过境变成逐段清点；连扫拦截机针对仍保持集中波前的目标实施低成本截面削减；驻空电磁巡飞弹在节点外侧按时间封控，破坏飞控和协同；层云爆轰断波弹吸收末端并发峰值；聚爆诱杀弹保护必须静默的辐射节点；近防弹巢则把漏网目标压缩在节点外缘，避免单架突破直接造成致命毁伤。

其制胜链条首先是“前推作用界面”，让敌在尚未形成末端齐射前就付出波次损失；其次是“改变结算单位”，分别按波、截面、驻留时段、诱导收拢批次、走廊段和过境时间窗口处理目标，避免我方始终以高价弹药逐架交换；最后是“迫使敌反适应自付代价”。敌若爬升，会失去低空掩护；若拉散，会失去饱和协同；若加固，会牺牲成本、重量和航程；若清海、改道或试探，则须提前暴露行动并消耗额外时间。

闭环判定不能只看单件装备的击落数，还应看蜂群能否按原计划、原密度和原时刻抵达。水下伏击弹重点核对过顶判明误差、按波覆盖率和末端残余数量；连扫拦截机核对每趟截面清削率、趟次连续性和波前对齐误差；电磁巡飞弹核对覆盖域失能率、有效照射占空比和驻留接力连续性；诱杀弹核对真假源不可辨程度、敌弹群收拢率和单轮清算比；网弹核对网幕完整度、段净通过率与补网周期；层云断波弹核对成层保持、时间窗命中和层内目标占比；近防弹巢则需核对真实撞击触发率、误触发率与节点存续率。现有材料尚不足以给出这些指标的实测点值，后续应优先通过海杂波、复杂风场、抗干扰蜂群和连续多波次压力试验，验证各装备何时能够真正把敌方饱和攻击转化为可承受的残余流量。
