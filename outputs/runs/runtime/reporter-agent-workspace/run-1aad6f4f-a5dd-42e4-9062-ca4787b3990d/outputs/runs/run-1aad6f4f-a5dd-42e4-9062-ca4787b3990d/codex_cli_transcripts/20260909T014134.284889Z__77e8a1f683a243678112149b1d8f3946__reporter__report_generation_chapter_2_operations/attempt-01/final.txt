## 二、项目画像

### （二）作战运用模式

#### 1. 作战运用流程

第一岛链沿海要地、岛礁和舰艇编队面对的共同矛盾，是敌方以低成本无人机、侦察机、巡飞弹和防区外火力组成连续波次，使我方探测、识别、拦截和弹药补充同时承压。作战运用不能再把每架无人机都当作独立目标处理，而应依据敌方进入高度、航渡路线、制导方式和编队密度，分别把交战单元改为波次、截面、覆盖域、诱导汇聚区或末端撞击线。六类装备的使用先后并不相同：有的负责在敌进入防区前削峰，有的负责迫使敌改变航路，有的专门打断反辐射攻击链，另有装备只在目标已经形成真实撞击威胁时才启动。

随浪伏击反蜂群弹适用于敌为躲避雷达而长期贴海、沿浅近海固定通道密集过顶的情形。其进入条件不是岸基实时跟踪，而是预先掌握海区水深、底质、潮汐和敌惯用航路，并确认波群会在坐底被动水声阵的有效判明范围内通过。装备平时沉底静默，不主动通信；波群接近时由弹上声学装置判定来向、密集程度和过顶时刻，在最密段垂直穿浪，自下而上展开破片杆幕，直接把一波目标送入同一毁伤区。多枚装备沿航路接力后，敌蜂群在抵达末端前已被连续削减，残余数量和到达时间成为后方火力可以预先处理的对象。敌若继续贴海密集突进，就必须承受逐段折损；若改为爬升，则失去海杂波掩护并暴露给远程火力；若先行反潜清海，则需付出时间、兵力和暴露代价。其失效边界是敌绕开预置海区、声学背景压低判明置信度、航速压缩穿浪时间，或阵位被提前清除。

掠波连扫拦截机面对的是近岸走廊内波前宽、诱饵多、来袭数量可持续增加的饱和攻击。它不建立单机航迹，而由预警系统提供波前位置、宽度、高度带和到达时间，拦截机据此侧向进入截面，以横向展开的破片刃带反复掠穿波前。决定性动作不是命中某一架，而是用一次出动削去一段编队截面，返场再装填或由其他平台接力，持续覆盖敌方航渡时间轴。这样，敌加密波次、混入诱饵不会同步增加我方单趟成本；敌若拉稀或减速，反而延长在走廊中的暴露时间，使其整条输送链难以按时到齐。直接战果表现为波前持续变薄、敌编组节奏被打乱，末端点防御只需处理漏过的零散目标。敌方最有效的反适应不是继续加量，而是拆散方位和时序，改用多路小群或诱饵波前欺骗波级预警；此时本装备的截面优势下降，必须由末端硬杀伤接续。

驻空扫域电磁灭群巡飞弹适合保护前进机场、岛礁节点和舰队核心等高价值目标，尤其针对未完成电磁加固的廉价无人机、诱饵和伴随干扰机。进入条件是能够提前判断主要来袭扇区，并在目标群进入节点近界前让弹体抵达指定高度。装备占位后反复向必经空域施加宽频高功率微波，作用对象是无人机的飞控、电调、数据链和导航接收链路。其关键变化是把清算单位从“每架一枚拦截弹”换成“一个覆盖域在一段驻留时间内持续生效”：蜂群即使疏散、变速或混编，也难以摆脱反复刷新；未加固目标可出现失控、掉线、掉队或坠落，敌协同进袭链随之中断。敌若逐架加固，单机成本、重量和航程受到惩罚；若以反辐射武器或高速自杀机摧毁驻留弹，则需用高价值手段交换一次性防护单元。该装备不能替代对高抗扰目标的硬杀伤，且覆盖域受能源、热管理、波束指向和驻留时间制约；多扇区同时会聚、地形遮蔽和驻留体被先期定位，都会造成防护间隙。

引浪吞波聚爆诱杀弹针对的不是普通蜂群，而是依赖辐射源收敛的反辐射无人机、巡飞弹和自杀机。其使用前提是高价值节点能够保持真源静默，并在旁侧布置具备相近外形和辐射特征的诱爆弹组。进入对抗窗口后，真节点关闭或降低辐射，诱爆弹按预定规律主动发射信号，使敌方弹药无法远距分辨真假，只能向诱源收拢。敌弹群进入预设距离、高度和数量包线后，诱爆弹以温压和破片实施整簇清算。这样，敌“先诱耗、再压制、后送载荷”的攻击次序被倒置：每轮辨真都先损失一批弹药，数量优势转化为目标确认成本。敌若改用光学、预编程或卫星直击，诱爆条件便不再出现；若提前清扫诱饵或识别出信号差异，装备也会退化为普通诱饵，因而真源静默完成率、仿形辐射逼真度和收拢触发可靠性是流程成立的核心。

迎面撒网捕蜂拦截弹用于敌被远程雷达和地形共同压入低空窄走廊、并以密集编队争取末端同时到达的场景。其先决条件是走廊入口和宽度可以预测，且风场允许网幕在目标高度保持有效形态。高空气球或运输机沿入口和中段成串投放网弹，网体依靠迎面气流展开成柔性网幕，直接以缠裹旋翼、气动面和机体的方式使前排整簇失速坠落。该过程不依赖辐射、制导或爆炸，敌干扰、诱饵和隐身无法改变机械接触关系；每次成网都可由沿线观测完成分段清点，漏过数量再交给远程或末端火力。敌爬升会暴露于远程火力，拉散会破坏同时到达条件，加装破网装置则增加单机重量和成本。走廊过宽、风场不利、补网速度低于来袭流量或投放平台失去生存保障时，网幕只能作为局部封段手段。

过境层云爆轰断波弹属于末端窗口遮断装备，只有在敌低空航路收口、过境时间可提前判定、己方车辆能够抵近布设并完成空域清场时才具备使用价值。车载系统在预计过境段铺设可爆气溶胶层，确认云层连续性和浓度达到要求后，待敌波次主体进入覆盖体积，再实施多点同步起爆。其直接作用不是逐架拦截，而是以超压、火球和卷吸在一个时间切片内成批破坏薄壳无人机，使波次失去集中到达的密度。敌若弃窗，必须重新组织航渡并再次暴露；若拉长间隔，则由蜂群变成可被逐批处理的稀疏目标。该装备的主要限制也最明确：海风、湍流、湿度和沉降可能使云层无法保持，判窗误差会导致铺层与目标错位，敌从高空、层下或走廊外绕行则不进入毁伤体积。现有材料未提供海上成层、浓度保持和同步起爆的试验事实，因此其流程仍应视为限定窗口内的概念能力。

对“撞线自付近防弹巢”，现有画像只支持作战意图，尚不足以闭合完整运用流程。其设想是把无辐射的一次性近距弹巢布置在节点外缘、顶面和伪装目标附近，仅当来袭目标形成真正朝节点撞击的末端航段时，最近弹巢才自主起爆，避免被外围巡飞、过航目标和远距诱饵提前消耗。这个思路的直接价值在于把开火条件从“发现目标”收窄为“确认撞线”，使敌必须以接近真实攻击成本的动作才能骗取弹药。但材料没有给出末端航段判定方式、友军误触发边界、弹巢覆盖密度、单巢毁伤范围和连续波次下的剩余量模型，不能据此断言其对饱和攻击的防护寿命或交换比；在这些变量补齐前，只能将其定位为节点末端的待验证自主触发层。

#### 2. 链路闭环分析

上述装备共同解决的是传统“探测—逐架跟踪—单发拦截”链条在蜂群数量、低空遮蔽和反辐射压制下的级联失效，但各自切断的环节不同。随浪伏击反蜂群弹切断敌贴海航渡的隐蔽性，把海杂波遮蔽转化为水下声学暴露；掠波连扫拦截机切断敌波前的完整到达，把单机数量改写为截面损失和航渡时间；驻空扫域电磁灭群巡飞弹切断飞控、通信和协同链，使廉价数量无法稳定形成集群动作；引浪吞波聚爆诱杀弹切断反辐射攻击的辨真环节，让敌确认目标的动作直接产生弹药损失；迎面撒网捕蜂拦截弹则利用低空走廊的几何约束，绕开电磁对抗完成物理清收；过境层云爆轰断波弹承担末端吸收并发峰值的任务，把精确点防御保留下来专门处理破队后的少量残余。

因此，闭环不能用单一装备包打全部威胁。较稳妥的作战链是：外层预警首先判定敌方航路、高度和波次形态；贴海密集目标可由水下伏击和走廊拦网提前削峰，形成集中波前的再由掠波连扫拦截机按截面处理；进入高价值节点附近的未加固蜂群交由驻空电磁清算，反辐射来袭则切换为真假节点诱爆；末端仍保留常规硬杀伤，对高空、加固、绕行和异步小群实施补漏。过境层云爆轰断波弹只有在气象、走廊和时间窗同时满足时插入末端，不能作为普遍替代方案。各装备的验证重点也应随机理变化：水下装备看波次判明与穿浪时序，连扫平台看单位时间截面覆盖，电磁巡飞弹看覆盖域内有效照射占空比，诱爆弹看收拢率和单轮清算比，网弹看段净通过率与补网间隔，云爆断波弹则首先验证成层保持和同步起爆。`撞线自付近防弹巢`因关键变量缺失，暂不能进入同等确定性的作战闭环判断。
