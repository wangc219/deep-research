## 一、需求分析

### （二）国内外现状

#### 1. 国外情况

国外公开材料表明，美军已将无人系统威胁从单一目标拦截问题提升为跨域、规模化和持续演化的作战问题。美国国防部《无人系统反制战略》把小型无人系统对关键设施和兵力集结点的防护列为近期重点，并依托联合反小型无人机办公室、战士高级综合小组和“复制者2”计划推进建设；战略同时强调探测、主动防御与被动防御并用，要求降低无人系统与反制手段之间的成本失衡，加快试验、采购和规模部署。[美国国防部《无人系统反制战略》](https://media.defense.gov/2024/Dec/05/2003599149/-1/-1/0/FACT-SHEET-STRATEGY-FOR-COUNTERING-UNMANNED-SYSTEMS.PDF)

这说明国外的类别事实已覆盖“发现、压制、硬杀伤、被动防护和网络破坏”等方向，但公开材料尚未给出与本项目六类装备一一对应的定型型号、成规模作战案例或可直接移植的性能参数。换言之，国外公开进展更多体现为任务体系和能力组合的建设意图，不能据此推断其已经拥有水下按波伏击、按截面反复清削或按时间窗口体积毁伤等具体装备。

国外另一个具有决策价值的事实是，能力建设并不等于体系已经闭合。美国政府问责局2025年报告指出，美军跨域指挥控制仍缺少能够统一指导投资、衡量进展的综合框架，军种和战区存在相互分散的数据融合项目，互操作、数据共享和经验推广仍是瓶颈。[GAO-25-106454](https://files.gao.gov/reports/GAO-25-106454/index.html)这对本项目有直接启示：反蜂群装备若仍依赖高带宽、实时逐架识别和跨域链路，可能把蜂群数量压力转化为指控时延；因此，随浪伏击反蜂群弹应以本地被动水声判明和弹内闭环为专属优势，掠波连扫拦截机则应把预警要求压缩到波前位置、宽度和时间窗，而不能照搬目标级火控模式。

从公开事实到本项目判断，驻空扫域电磁灭群巡飞弹具备明确的国外技术发展对应关系，即以主动、被动防御和成本失衡为建设方向，但尚无本项目所需的弹载宽频高功率微波作用距离、驻留时长和对不同无人机抗扰水平的公开参数。引浪吞波聚爆诱杀弹也不能简单归入一般电子干扰，其成立依赖反辐射弹药必须向高逼真诱源收拢；国外公开战略只证明反制威胁网络和保护关键节点的任务需求，未证明该诱爆链条已经工程化。迎面撒网捕蜂拦截弹、过境层云爆轰断波弹和撞线自付近防弹巢，在所提供国外材料中均未发现可核验的同类装备案例，属于本项目提出的机理性方案，而非国外现状事实。

#### 2. 国内现状（中国）

本轮输入未提供中国现役或在研反蜂群装备的公开型号、试验报告、部署规模、单次成本、低空杂波探测概率、微波毁伤阈值或特殊战斗部验证数据。因此，不能把装备画像中的概念直接表述为国内已有能力，也不能据“未提供材料”断言中国不存在相关研究。按“空白、关键差距、部分差距、满足、超出”五档衡量，当前证据最多支持对若干方向作“公开证据空白”或“关键差距”判断，尚不能认定任何一项达到“满足”或“超出”。

具体看，随浪伏击反蜂群弹面对的是浅近海走廊内的贴海密集波次，关键差距不在普通水下探测，而在长期坐底值守、低虚警识别过顶声包络、垂直穿浪时延和破片杆幕按波覆盖；现有材料没有这些工况数据。掠波连扫拦截机的差距则表现为国内公开反无人装备通常仍按目标发现、跟踪和逐个拦截描述，尚无证据证明存在以“趟次—截面”结算、依靠可再生横向破片带持续清削波前的成熟装备。

驻空扫域电磁灭群巡飞弹可归入“部分差距”：国内具备电子对抗和无人平台技术基础的可能性不能替代本项目所需的弹载能源、热管理、宽频辐射和覆盖域内统计毁伤数据；若这些数据缺失，不能把“能干扰”推定为“能在驻留时段内清算蜂群”。引浪吞波聚爆诱杀弹属于“关键差距”，其核心是仿形辐射源、真节点静默纪律和收拢起爆判据三者同时成立，普通诱饵或常规硬杀伤不能替代。迎面撒网捕蜂拦截弹的物理原理较直观，但从“部分差距”走向可用装备仍取决于网幕展开概率、风场适应性、段间补投和己方净空管制；过境层云爆轰断波弹则接近“空白”，因为海上开放环境中的成层保持、同步起爆和安全使用约束均缺少公开验证。撞线自付近防弹巢的画像信息更不完整，暂只能列为公开证据空白，不能给出确定的近界距离、触发可靠性或抗诱饵结论。

#### 3. 对比小结

中外公开现状的主要差异，不是国外已经普遍装备本项目所设想的特殊武器，而是国外已形成较明确的反无人系统战略、组织牵引和试验扩展机制；中国侧本轮可核验的装备基线和参数证据不足，导致“现有能力属于哪一档”尚不能完整判定。国外同样存在跨域融合治理滞后，说明本项目不宜把软件平台或指挥体系包装成装备成果。

因此，各装备的立项价值应按自身改变交战关系的方式区分：随浪伏击反蜂群弹改写的是海杂波条件下的探测界面，掠波连扫拦截机改写的是饱和攻击的计价单元，驻空扫域电磁灭群巡飞弹改写的是覆盖域内的持续消耗方式，引浪吞波聚爆诱杀弹改写的是反辐射攻击的辨真成本，迎面撒网捕蜂拦截弹利用的是低空走廊的几何约束，过境层云爆轰断波弹针对的是末端时间窗口，而撞线自付近防弹巢只适合作为真实撞击航段的近界补漏。当前最明确的证据边界是：这些方向可以作为装备机理和验证命题提出，但不能用国外战略表述或国内能力口号替代样机、环境和对抗试验。
