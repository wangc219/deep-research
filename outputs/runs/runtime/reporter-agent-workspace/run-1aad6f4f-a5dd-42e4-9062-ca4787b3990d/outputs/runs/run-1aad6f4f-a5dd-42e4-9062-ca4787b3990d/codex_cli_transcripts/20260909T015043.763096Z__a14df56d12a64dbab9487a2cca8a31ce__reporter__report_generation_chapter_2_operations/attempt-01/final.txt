（二）作战运用模式

1. 作战运用流程

面对第一岛链沿海要地、岛礁和舰队节点遭遇“低成本无人蜂群＋防区外火力”复合饱和突袭，装备运用不能再按逐架发现、逐架授权、逐发拦截组织。敌方真正追求的是以诱饵和干扰扰乱发现分类，以多波次压垮拦截通道，再由后续载荷完成节点瘫痪。因此，各装备应按其改变交战关系的部位分别进入作战流程。

随浪伏击反蜂群弹用于敌蜂群贴海航渡、密集过顶的浅近海走廊。战前依据水深、底质、潮汐和敌惯用航线布设坐底弹体，保持无辐射、无常开链路的低功耗监听。敌机为利用海杂波和视界遮挡而维持掠海密集队形时，其发动机、旋翼和近水面扰动会在水下形成可判别的连续声学事件。弹体只需确认波次来向和过顶时刻，不必建立单机航迹，便在波群最密处垂直穿浪，以破片杆幕覆盖掠海高度层，先行削减整波数量。沿走廊接力布设后，残余波次在末端前被多次折损；敌若爬升规避，即失去海杂波掩护并转入我方远程火力包线；若先行清海，则必须暴露反潜行动并拖慢突袭节奏。

掠波连扫拦截机针对敌以集中波前、多架次同步到达形成饱和峰的情形。预警环节只提供走廊位置、波前宽度和到达时间，不追求单机识别。拦截机前出占位，在敌波前所在高度横向展开可再生破片刃带，连续掠穿同一截面；一次出动的价值由清削的波前长度和趟次决定，而不由截面内真假目标数量决定。敌加密波次或混入诱饵，不能按比例抬高我方单趟成本；若拉稀、减速或拆分波次，则在走廊暴露时间增加，整条输送链按时到齐的概率下降。该机不承担漏网目标的最终点杀，重点是把敌有效到达速率压低到末端火力能够承受的水平。

驻空扫域电磁灭群巡飞弹用于关键节点上空的中段区域防护。接到来袭主轴和时间窗提示后，巡飞弹升至节点与威胁走廊之间的预定高度，按扇区驻留并反复发射宽频高功率微波。进入覆盖域的未充分加固无人机，其飞控、电调、导航接收和通信链路可能同时复位、失控或掉线，清算对象由“单架目标”变为“防护时段内的整个空域”。敌方疏散编组、变速和混入诱饵不能消除覆盖效应；若逐架增加屏蔽和抗扰措施，则重量、成本和航程负担上升，廉价规模优势被反向消耗。驻留弹耗尽或被反辐射手段威胁时，由预备单元轮换，抗扰目标和覆盖外目标移交硬杀伤层。

引浪吞波聚爆诱杀弹服务于敌反辐射无人机、巡飞弹对前沿雷达、通信中继和防空节点的定向压制。诱杀弹组仿形部署在真节点旁，主动模拟其辐射特征，而真节点按计划静默并控制附属设备的电磁泄漏。敌若依赖反辐射引导辨认目标，就必须让一批弹药向诱源收拢；当弹群进入预置距离和方向窗口后，诱杀弹成组起爆，以温压和破片清除收拢弹药。这样，敌“先诱耗、再压制、后投送”的波次顺序被打断，每次辨真都要先付出弹群损失。穿过诱爆区的残余目标再由近程防空处置。其效果不在于替代节点硬防，而在于延长真节点静默存活时间，保住雷达、通信和火力链的重新开机机会。

迎面撒网捕蜂拦截弹适用于敌因规避远程探测而被迫进入的低空狭窄通道。高空气球或运输机在走廊入口和中段预置网弹，来波接近后按风场和密度成串投放，弹体依靠迎面气流展开柔性网幕，直接兜卷密集前排并使其坠落。该动作绕开搜索、识别和单发制导，战果可以按网段和坠落数量逐段核销。电子干扰、诱饵和低可探测外形对机械接触不起作用；敌若爬升，则暴露给远程火力，若拉大间隔，则主动拆掉同时到达的数量峰，若加装破网装置，则单机成本和载荷压力上升。其作战价值是把无形的低空渗透通道改造成可预置、可补投、可清点的实体闸门。

过境层云爆轰断波弹用于末端走廊内能够提前判明低空过境时间窗、且敌机体较轻薄的波次。车载平台在敌群进入前快速铺设一定高度和纵深的可爆气溶胶层，确认云层连续性和过境时刻后实施同步起爆，以超压、火球和卷吸造成层内目标成批失效。其关键动作不是逐机命中，而是把拦截单位改为一个过境时间切片，使高并发蜂群在同一体积内同时失去完整编队。敌若弃用该时间窗，需重新组织航渡；若拉长间隔，则密度下降，后续点防御恢复处理能力。该装备成立高度依赖风场、湿度、云层保持和同步起爆，不能把概念效果直接视为已验证战果。

撞线自付近防弹巢承担最后数十米的节点保命任务。在节点外缘、顶面和伪装阵地周边布设无辐射、无人值守的一次性弹巢，被动感知只对真正指向节点的末端撞击航段触发，最近弹巢提前起爆或直接毁伤来袭机体。巡飞、过航和远距离诱饵不会因进入外围空域而消耗弹巢，敌若要骗取火力，必须把假目标也做成接近真实攻击的末端撞击动作。该装备不依赖外部通信和持续辐射，适合在指挥链受压制时维持节点最后一道防线，但防护寿命仍受弹巢密度和真实末端来袭数量限制。

2. 链路闭环分析

上述装备共同改变的不是某一枚弹药的命中率，而是蜂群“发现—分类—授权—处置—确认—恢复”链条中的不同断点。随浪伏击反蜂群弹首先在电磁探测链之外削峰，迫使敌在贴海密集和爬升暴露之间选择；迎面撒网捕蜂拦截弹把受地形约束的低空走廊转化为实体清点段；掠波连扫拦截机和过境层云爆轰断波弹分别以“波前截面”和“过境时间窗”为结算单位，减少蜂群数量对我方拦截通道和弹药库存的直接压力。二者的成立前提不同，前者要求平台能够重复占位和补充刃带，后者要求气溶胶层在海上环境中保持并与敌过境准确重合，不能混用验证口径。

驻空扫域电磁灭群巡飞弹解决的是中段批量失能问题，其成败取决于覆盖域内实际能注、脉冲刷新率、驻留时间和目标抗扰水平；对全向加固、地形遮蔽或高价值有人平台必须保留硬杀伤接续。引浪吞波聚爆诱杀弹解决的是“敌必须辨真”的瞄准链矛盾，只有当对手依赖辐射收敛、真假源难以区分且真节点能够严格静默时，才会把目标确认动作转化为成批损失。敌改用预编程、光学确认或远距火力先清诱饵后，该链条会明显降效。

撞线自付近防弹巢则负责把未被前层削减的真实攻击限制在节点外缘，避免少量漏网目标直接造成关键功能中断。它不追求控制整个空域，而是以“是否进入真实撞击航段”决定是否消耗，因此与前述按波、按截面、按时段清算的装备形成层次差异。最终制胜链条应表现为：前沿静默伏击和机械封段削减来袭规模，中段区域效应破坏协同和载荷完整性，诱饵聚爆延长关键节点静默生存时间，末端弹巢阻断残余撞击，随后由常规远程和近程火力完成补漏与恢复。

本栏能够确认的是各装备改变交换关系和作战动作的方向，尚不能确认具体成本、覆盖率、再装填节奏、海况适应性、目标抗扰阈值及大规模波次下的连续战果。后续验证应围绕各自失效条件设置压力场景：海杂波与浅海声学背景、波前分散和多方位来袭、强风湿热下的成层可靠性、诱饵逼真度与真节点静默率，以及弹巢在连续真实末端攻击中的剩余防护能力。
