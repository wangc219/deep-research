三、总体方案

（一）总体架构

方案不沿“探测—识别—拦截”重建单链，而是沿敌贴海走廊将装备排成“水下预置—走廊中段—末端收口”三线接力：随浪伏击弹浅近海坐底按波清账，撒网弹与掠波连扫拦截机在走廊截面按段缠收、按趟清削，层云爆轰弹于近岸末端按过境时间片清空；节点侧，电磁巡飞弹、诱爆弹、近防弹巢分别清算敌链的数量、辨真与末端撞击。各线共用同一低带宽批级状态——来向、走廊宽高带与过顶时刻窗，免去单机识别，分类与授权时延由此移出主干；此状态也是公共单点，判明被压制或诱骗时，水下无源与定时成层皆失装订基准而无法独立触发。

三线串联减量而非并行备射：每层只把波次折损至下层可承受密度，残余架数与到达时刻是层间唯一交接量，末端硬杀伤仅补漏不摊峰。任一上游层失效因此不止于局部掉性能，而是整波后移、清账压力逐级放大；多波次连续性的真约束是各层恢复周期须短于敌波次间隔——预置静默类发射即成缺口，刃带与网幕须返场或补投，断点只在波次压力推演中暴露。

开火权限按诱骗门槛与误伤半径分级：近节点层以过顶声包络、末端撞击航段等不可伪造的物理动作自主触发，不耗于圈外诱饵；宽域电磁与爆轰层效应统计性强且覆盖己方净空，只授区域时段照射并保留值班中止，形成越近末端越自主、覆盖越宽越受控的梯度。公共取舍收敛为两道验收门：恢复周期能否压过敌波次间隔，单层失效能否被下游以可承受残余接住。
