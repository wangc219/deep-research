## 二、项目画像

### （一）装备图像概述

| 装备 | 核心技术与形成能力 | 部署或进入方式 | 关键动作、作用对象和直接效果 |
|---|---|---|---|
| 随浪伏击反蜂群弹 | 以坐底潜藏筒体、低功耗被动水声阵和垂直穿浪发射机构为主体，不依赖持续辐射和战时数据链。其关键能力不是识别单机，而是从贴海密集蜂群形成的连续过顶声包络中判明波群来向、密度和时刻，再以竖向破片杆幕覆盖掠海高度层，将拦截结算单位由单架改为波次。 | 按浅近海水深、底质、潮汐和敌惯用航路，在低空航渡走廊内预置多枚弹体，长时间静默值守。各弹独立完成判明和起爆，沿走廊形成接力伏击带；敌若改爬升或先行反潜清海，则分别暴露给远程火力或付出清海时间成本。 | 当敌蜂群贴海密集过顶时，水声阵捕捉其不可取消的近水面扰动，弹体垂直出水，在波群最密处起爆，破片杆幕同时作用于多架低空目标，逐段削减到达末端的数量并提前给出残余波次时刻。其失效边界是海况噪声过强、底质不适配、敌绕开预置走廊或判明至起爆的时间不足。 |
| 掠波连扫拦截机 | 取消单机搜索、识别和末段寻的设备，重点发展横向展开的破片刃带、低空定高、快速再出动和重复掠穿能力。它形成的是“趟次—截面”清削能力：单位出动成本主要由平台能量和刃带消耗决定，不随截面内目标数量及诱饵比例同步增加。 | 由体系预警提供波前到达时间、走廊位置和大致宽度，拦截机前出至预定高度，按航路切入波前平面并反复掉头再扫。多架平台按敌波次节拍接力，覆盖其在走廊内的持续暴露时间，而不是围绕每架目标建立独立航迹。 | 横向刃带掠穿敌波前，作用对象是整段编队截面，真弹和诱饵在几何交会中被同等处理。直接效果是降低蜂群有效到达速率，使敌为保持整链按时到齐而被迫增加冗余；若拉稀或减速，暴露时间反而延长。敌改为多方位异步小群、波级预警遭诱骗或刃带再生跟不上时，能力退化为补充拦截。 |
| 驻空扫域电磁灭群巡飞弹 | 将宽频高功率微波源、定向天线、弹载能源和热管理压缩进可驻空弹体，形成按覆盖域和驻留时段工作的区域电磁清除能力。其效能取决于到达目标的能量是否足以作用于飞控、电调、导航接收和数据链，而非单次脉冲峰值本身。 | 在高价值节点与来袭主轴之间占据预定高度，按威胁扇区反复照射，并通过预备弹轮换维持防护时段连续。任务由区域授权触发，不逐架装订；对己方通信中继、航空器和已加固平台设置禁扫方向与停照条件。 | 覆盖域内未充分加固的无人机、诱饵和伴随干扰机，其飞控复位、电调停转或数据链中断会导致失能、掉队或坠毁。直接效果是把防御消耗从来袭架数改为驻空时段，迫使敌逐架增加屏蔽和抗闩锁措施，承受重量、航程和载荷损失。对高抗扰目标、地形遮蔽航路、反辐射打击和多扇区同时会聚，该装备需由硬杀伤接续。 |
| 引浪吞波聚爆诱杀弹 | 以高逼真仿形辐射源、成组同步控制、收拢状态判定和温压破片聚爆装置形成“主动诱导—聚集清算”能力。核心不是单纯模拟信号，而是让敌导引头在载频、调制、扫描节律和功率变化等方面难以分辨真假，并把敌辨真动作转化为起爆窗口。 | 成组贴设在雷达、通信中继或防空火力节点旁，真节点按预案静默，诱杀弹在攻击窗口主动辐射。敌反辐射无人机、巡飞弹或自杀机向诱源收拢后，在预定距离、高度和数量条件满足时整簇起爆；波次间隙再补充或轮换诱饵组。 | 作用对象是向仿形诱源收拢的敌导引头集群，温压超压破坏电子舱，定向破片毁伤弹体，直接形成“一次起爆、清算一批”。敌“先诱耗、再压制、后送载荷”的攻击顺序因每轮辨真先损失弹药而被打断。若敌采用预编程、卫星或光学直击，或先清扫诱饵、识别出辐射差异，诱爆条件消失，装备只能退化为普通诱饵或近防补充。 |
| 迎面撒网捕蜂拦截弹 | 以可折叠高比强度网材、前缘配重和可靠迎风展开结构为核心，不配置制导、辐射和爆炸部件。它把拦截问题转化为走廊断面上的柔性实体接触，形成不受电子干扰、诱饵和隐身影响的整体缠收能力。 | 依据地形和雷达盲区，把敌低空通道划为若干窄段，由高空气球或运输机在入口及中段成串投放。网弹下降后借来流展开成横张网幕，并按波次密度错时补投；沿线观测点对坠落目标进行分段清点，漏网和爬升目标移交远程火力。 | 低空密集蜂群迎面撞入网幕后，网丝缠入旋翼和气动面，阻力骤增并导致整簇失速坠落。直接效果是把饱和突防拆成若干可核销的清收事件，降低末端同时到达架数。敌若爬升则暴露，拉散则失去饱和密度，逐架加装破网装置则增加成本和载荷负担。走廊过宽、风场不利、波次间隔小于补网周期或敌改走高空时，网幕难以形成有效断面。 |
| 过境层云爆轰断波弹 | 装备本体是车载储喷成云与同步起爆系统，包括燃料储存、雾化铺展、多点起爆和时间窗控制单元。其形成能力不是逐架命中，而是在低空走廊内建立覆盖高度层的可爆气溶胶体积，将拦截结算从架次改为过境时间切片。该构想的主要工程风险在气溶胶保持、浓度均匀性和多点同步起爆。 | 由车载平台前出至末端海上走廊，在外部预警判明敌过境时间窗后快速横向铺层，并在云层完整性达到要求、敌波次主体整体进入后同步触发。弃窗、绕层或拉长分散的残余目标由点防御补漏，下一时间窗再重新成层。 | 体爆轰的超压、火球和卷吸作用于层内薄壳无人机，使多个目标成批解体坠落，破队后的单机难以继续形成饱和。敌只能改期、绕行或拉长航渡，前两者增加暴露和重编代价，后者降低突防密度。若风、雨、湿度和湍流使云层失稳，或判窗误差超过成层保持时间，装备可能只产生局部毁伤，不能外推为任意空域的通用防御手段。 |
| 撞线自付近防弹巢 | 已知构想以节点外缘、顶面和伪装体周边的无辐射一次性弹巢为主体，被动感知只判断目标是否进入真实撞击末段，再由最近弹巢实施近距离迎面起爆或直接毁伤。其可替代的是对圈外诱饵和过航目标逐一识别、逐发拦截的高消耗流程。 | 弹巢分散埋设或贴设在受护节点近界，平时无人值守、保持静默；只有目标航迹持续指向节点并进入末端撞击包线时触发。圈外巡飞、远距侦察和无意干扰不应造成耗弹，从而使诱饵必须付出接近真实攻击的末端代价。 | 作用对象是确实朝节点撞击的自杀机、巡飞弹和末端弹药，直接效果是在数十米级近界提前引爆战斗部或击毁机体，保护核心设施并减少诱饵消耗。现有材料未给出触发判据、近界覆盖率、误触发率、弹巢补充周期和实测成本，因而目前只能确认其“只对真实末端威胁开火”的能力方向，不能据此断言具体防护概率或形成成熟装备结论。 |
