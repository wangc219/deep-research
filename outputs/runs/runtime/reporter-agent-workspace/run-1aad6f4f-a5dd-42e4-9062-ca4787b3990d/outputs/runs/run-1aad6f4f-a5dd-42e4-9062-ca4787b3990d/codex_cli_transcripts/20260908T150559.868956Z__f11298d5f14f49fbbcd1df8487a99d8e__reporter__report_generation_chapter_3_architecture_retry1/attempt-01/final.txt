三、总体方案

（一）总体架构

总体架构不按软硬杀伤类别堆层，而把敌贴海低空密集航渡沿走廊切成水下外沿、中段、末端海面与节点近旁四段接力：随浪伏击反蜂群弹坐底以被动水声判明过顶时刻，出水整波清账；掠波连扫拦截机以固定单价掠穿波前截面，迎面撒网捕蜂拦截弹以无源网幕在入口与中段逐段兜卷；驻空扫域电磁灭群巡飞弹于节点外围按驻留时段体积清算，过境层云爆轰断波弹将整层同步过境作为单一时间切片整体爆轰；引浪吞波聚爆诱杀弹逼反辐射弹群为辨真收拢而整簇被毁，撞线自付近防弹巢只对真末端撞击自触发兜底。任一段缺席，饱和峰即原样前推。

共享状态不是逐机航迹而是波级到达提示：预警按批给出走廊位置、宽度、高度带、到达时刻与真诱构成，扫削、布网、成层与电磁驻空只消费其中少数参数即完成占位、铺层与扫描分配；随浪伏击弹不依赖该提示，在弹内以水声判明自触发，其过顶时刻回传为后段同步基准。每段清账后以残余数量与到达时刻预测误差向下一段移交，末端与稀缺精确火力只补漏不摊峰；处置授权由逐架目标授权改为按防护空域与时段的预定授权加装备物理自触发，单目标授权时延移出公共链路。

共享资源在走廊净空与各段在位率：网幕无源不可辨识、气溶胶层须己方时序避让、水下伏击与诱爆爆区须禁入授权，共用一套净空权限，出错即误伤或错窗；一次性资产补位周期须盖过敌波次间隔。失效因之逐级降效而非一次瘫痪：波级提示被压制，按时段占位布势的一类同步错位空耗，自触发的诱爆与弹巢仍按各自机理兜底；敌拆散集中波前为多方位小群异步渗透，依赖走廊几何的清账层共同退回逐群交换，须由探测与远程火力先把敌逼回可覆盖走廊；敌以连续小波压缩补位间隙，诱爆弹组、网段、气溶胶再铺与电磁弹轮换同步吃紧，唯撞线弹巢消耗只随真实末端撞击增长、与补给链脱钩。架构成立门限是强干扰下波级提示可用率、补位节拍与末端到达时刻误差同时达标。
