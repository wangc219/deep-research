一、需求分析
（一）需求概述
1. 背景分析
外军已进入低成本可消耗无人系统规模化建设与防区外打击并行的公开发展期，其蜂群可借海杂波、视界遮挡与地形走廊贴海低空航渡，规避岛链远程雷达点名，并惯用“诱饵与干扰先导—诱导我方辐射暴露—防区外火力压制探测与能源节点—载荷续进”的波次结构，意图以多波次反复消耗拖垮体系，而非单波击穿。沿海要地、岛礁与机动编队因此被压进同一条发现—分类—授权—处置—确认—恢复任务链，断点恰好落在三处：低空杂波背景下低小慢多目标的首检测与分类可信不足，发现即断；逐架授权时延偏长且软杀伤效果无法物理确认，处置与闭环被拉长；末端按“弹—架”结算的通道面对数百架次级波次先耗尽弹药或被局部击穿，恢复周期无法闭合。敌以数量摊薄通道、以整链按时到齐兑现战果，我方的矛盾焦点由此从单装拦截能力转为链的连续性与单次交换成本。

2. 需求阐述
从Query看，需要的不是增加拦截弹数量，而是三类必须由装备本体承担的命题。其一，把探测目标从稳定跟踪单机降为可靠判明波次进入的方位、规模与时刻，但低空盲区与海杂波中的覆盖连续性、分类置信度须由装备的物理探测本体兑现；公开审计表明跨域集成与治理本身滞后，扩大集成范围可能反增时延，故C2与融合软件不能充当需求出口。其二，把单次拦截成本与单位时间可处理目标数改为与来袭架数解耦，使敌加量、加诱饵都压不动我方单价，同时让非动能手段具备可物理确认的战果闭环，缩短授权与确认时延，解除“贵弹换廉机”的既有锁定。其三，在敌瞄准—导引链段压低我方被瞄准置信度，使要地与编队不必以持续辐射暴露换取自身确认；末端仍须保留只对真实撞击消耗的低值硬杀伤，令诱饵必须先付出接近真弹的末端动作才能骗弹。
证据只够把判断闭合到机理层，缺口须点名：敌蜂群自主性与抗干扰水平未知，直接决定欺骗、压制类命题在何种条件下失效；现役末端通道数、弹药经济性与低空补盲仅有定性公开基线，缺乏支撑立项排序的代价与交换数据；各机理的抗诱饵性、对加固目标的失效门限与多波次恢复节奏，都须以公开单价交换和大规模波次压力推演建立可证伪判据后才能收敛。

3. 项目画像
本项目图像按断链位置与结算单元而非装备类型划定：随浪伏击反蜂群弹把对抗界面推到贴海航渡的水声域，坐底潜伏、被动判明“波次过顶”后垂直穿浪成杆幕，按波清账而不逐架交换，敌绕过它必须爬升现形或先期支付反潜清海代价；掠波连扫拦截机放弃单机识别，以横展破片刃带反复掠穿波前，单趟成本只随出动结算，诱饵与加密波次进不了我方成本函数，敌只能超量投保或拉稀减速、自耗航渡预算；驻空扫域电磁灭群巡飞弹按驻留时段结算宽频高功率微波照射，凡未逐架加固的飞控与数据链进入覆盖域即停摆，疏散变速无效、逐架屏蔽线性抬价，击落驻留体须动用防区外贵弹，反成以贵换廉；引浪吞波聚爆诱杀弹令真节点静默并以仿形诱源主动辐射，迫使敌辨真即令整批弹药向诱源收拢，收拢瞬间温压破片整簇清算，把数量优势逐次折算为目标确认代价。
迎面撒网捕蜂拦截弹把走廊入口切成可按段预置的窄带，以不辐射、不爆炸的柔性网幕迎面缠裹整簇、逐网清点，干扰、诱饵与隐身对力学接触无作用对象；过境层云爆轰断波弹在末端海上走廊现地铺出覆盖整层高度、延绵数公里的可爆气溶胶层，整层同步体爆轰按过境时间切片清账，破队后的单机不再构成饱和；撞线自付近防弹巢密布节点外缘与顶面，以真正朝节点撞击的末端航段为唯一开火条件，数十米内迎面起爆、先敌引炸，弹药只随真实进入次数增长，防御寿命与敌库存和诱饵总量脱钩。
共同制胜增量是把“低成本数量压垮高价通道”改写为敌边际突防成本高于我方边际防护成本，并保证多波次后仍能恢复闭环：从水下航渡、走廊截面到节点近旁，各机理分别以波次、截面趟次、驻留时段、辨真代价、网段、时间切片与真实撞击次数结算同一场饱和交换。每件装备的成立边界由各自物理条件界定——水深与声学本底、走廊几何与风场、目标加固度与自主性、层域保持与撞击判据——敌绕行、越层或升级加固即逐项失效，须以多机理接续而非单装定型判断项目价值，这正是本项研发的确定性来源与主要不确定性所在。
