## 一、需求分析

### （二）国内外现状

#### 1. 国外情况

国外公开事实显示，美国反无人系统建设已从单件装备试制转向“探测、主动防御、被动防御、快速规模化交付”并行推进。美国国防部《[反无人系统战略事实表](https://media.defense.gov/2024/Dec/05/2003599149/-1/-1/0/FACT-SHEET-STRATEGY-FOR-COUNTERING-UNMANNED-SYSTEMS.PDF)》明确把小型无人系统视为能够以低成本改变侦察、干扰和精确打击方式的持续性威胁，并提出由联合反小型无人机办公室、战士高级整合组和“复制者2”计划推动关键设施与兵力集结地域的防护。其公开路线重心是扩大探测跟踪、主动与被动防御、降低反制成本失衡，并针对更多数量和更高自主性的目标开展试验；但该材料没有公开与本项目七类概念装备对应的型号、单次成本、波次实战拦截率或海上低空工况数据。因此，国外可以确认的是建设方向和组织机制，不能据此证明水下伏击、截面扫削、驻空微波或层域毁伤已经形成成熟装备能力。

对“随浪伏击反蜂群弹”，国外公开建设重点仍偏向空中探测和末端防护，尚未见公开资料证明存在以水下被动声学判明贴海蜂群、再按波次垂直毁伤的同类装备。该方案的价值在于把敌方受海杂波约束的低空过顶转化为水声暴露，绕开电磁干扰；成立条件却受海区底质、噪声、敌航速和预置阵位生存性限制。“掠波连扫拦截机”则不同于国外通常按目标或弹药结算的拦截思路，其关键不是提高识别精度，而是以可重复出动的横向破片带处理波前截面；国外公开材料尚无单趟清削率、再生周期和平台损失率证据，不能把其成本优势当作已验证事实。

“驻空扫域电磁灭群巡飞弹”与国外战略所强调的主动、被动防御和成本平衡方向相符，但公开战略只确认高功率电磁反无人系统的任务需求，未给出弹载宽频微波的有效能注、驻留时间、热管理或对复杂加固目标的毁伤概率。其制胜关系是按覆盖域和驻留时间而非按无人机架数结算，失效点则是目标加固、反辐射攻击、地形遮蔽以及对己电磁兼容。“引浪吞波聚爆诱杀弹”依赖反辐射攻击链，作战效果取决于诱源逼真度、真节点静默纪律和敌方是否必须通过辐射收敛辨真；公开资料没有证明该类“诱辐射—聚爆清算”装备已形成可复制案例。

“迎面撒网捕蜂拦截弹”利用的是走廊几何和纯机械接触，不依赖电子压制，若敌为避远程探测而低空密集通过窄带，网幕可将整簇目标变成可清点的段落损失；但其效果受风场、走廊宽度、补网周期和己方净空约束。“过境层云爆轰断波弹”把拦截计价改为过境时间切片，理论上可吸收末端并发峰值，但开放海上气溶胶层的保持、浓度均匀性和同步起爆尚无公开试验支撑。“撞线自付近防弹巢”则以末端撞击航段作为唯一触发条件，专门压制诱饵放空火力，其关键变量是误触发率、近距毁伤包线和对真实末端目标的判定可靠性，现有材料不足以确认同类公开装备水平。

#### 2. 国内现状（中国）

本轮公开底稿未提供中国现役或在研反蜂群装备的可核验型号、海上低空探测数据、单次拦截成本、波次压力试验结果及体系实战案例，因而不能把国内能力直接判定为“满足”或“超出”。能够形成的稳妥判断是：上述七类装备均属于面向特定交战几何重新定义装备本体的方案，不宜用一般反无人机系统的总括能力替代。尤其是水下按波伏击、截面连扫、驻空电磁清域和云爆断波，分别对应声学暴露、时间—截面交换、能量覆盖和开放环境成层四种不同工程基础；若缺少对应工况数据，不能仅凭已有雷达、通信或末端火力基础推断其成熟度。对于诱爆弹、网幕弹和近防弹巢，国内现有弹药、诱饵、近炸引信和无人平台基础可能提供承接方向，但尚缺真假源逼真度、网幕包裹率、末端自主触发误差等直接证据。

#### 3. 对比小结

国外公开优势主要体现为战略牵引、快速试验、规模化采购和跨军种组织，但美国政府问责局《[防务指挥控制报告](https://files.gao.gov/reports/GAO-25-106454/index.html)》同时指出，其跨域数据共享、投资统筹、互操作和经验推广仍存在框架不足，说明“体系整合”不能自动等同于装备链路已经闭合。中国方面，本轮材料缺少可比的公开案例和参数，不能据此宣称存在同等或更高水平，也不能据缺证断言完全空白。就本项目而言，比较重点不应是装备数量，而应看能否把敌我交换单位从“弹对单机”改成“波次、截面、覆盖域、辨真动作或过境时间窗”。其中水下伏击和近防弹巢直接针对电磁压制与诱饵消耗，截面连扫和网幕拦截针对密集航渡，驻空电磁装备针对未加固集群，诱爆弹针对反辐射辨真，云爆断波则针对末端并发峰值。各方案均须以对应工况试验补足公开证据；在此之前，只能作为有明确作战机理和失效边界的装备方向，不能表述为已经形成的现役能力。
