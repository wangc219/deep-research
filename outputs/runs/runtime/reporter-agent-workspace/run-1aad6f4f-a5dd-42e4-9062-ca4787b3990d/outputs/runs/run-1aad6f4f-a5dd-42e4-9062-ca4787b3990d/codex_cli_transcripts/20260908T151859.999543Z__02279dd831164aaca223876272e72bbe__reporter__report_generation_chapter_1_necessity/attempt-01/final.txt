一、需求分析

（三）建设必要性分析

1. 作战使用角度

低成本无人蜂群结合防区外火力，把突防由少数高性能平台变为数百架次贴海波次齐到，我现役“雷达建链—逐架跟踪—拦截弹按架交换”的接敌方式先耗尽火力通道与弹药经济，威胁断点不在单件性能而在交战关系。必要性首先体现为改换使用逻辑：把实时接战每一架，改为在敌必经的航渡、齐到、辨真环节按波、截面、时段与确认动作预置结算，使接敌条件取自敌自身战术必然性，而非我方探测链路是否全程可用。

在走廊航渡段，随浪伏击弹沿敌惯用贴海航路坐底静默，仅以被动水声判明整波过顶的方位与时刻，随即垂直穿浪、自下而上按波起爆；敌借海杂波与视界遮挡实施的“密集过顶”由此成为其无法以电子手段取消的水下暴露，规避只剩爬升现形于远程火力，或每波先为走廊支付暴露自身批次的反潜清海成本。掠波连扫拦截机把前出火力改为按趟作业，以可再生破片刃带反复掠穿波前，敌加密单波、堆叠诱饵都压不动我方单趟成本，拉稀减速只拉长自身走廊暴露；迎面撒网弹改由高空气球或运输机成串投网，无源网幕按段把整簇缠裹坠落，起网即成一笔可点数核销的清点事件，干扰诱饵对纯力学缠裹没有作用对象，逐架破网须自抬单价。

节点与末端的使用改守时段与确认：驻空扫域电磁巡飞弹按防护时段驻留节点上空，对进入走廊的目标维持区域自动照射；过境层云爆轰断波弹判明过境时间窗后现地铺层，整层齐到一次体爆轰，放行或清空改由我方定节奏；引浪吞波聚爆诱杀弹令真节点静默、诱源仿形主动辐射，把敌辨真变成整批弹药向诱源收拢后的聚爆清算；撞线自付近防弹巢只在真实撞线的末段触发，圈外廉价诱饵不诱发消耗。敌每一轮由此在航渡、齐到或辨真中先付一笔不可分摊的代价。

2. 装备能力提升角度

能力提升的实质，是把对抗极限从“我方能同时跟踪拦截多少架”改写为“敌的固定几何暴露能否被预置利用”，且各装备机理互不替代。随浪伏击弹补上雷达被压制、杂波盲区下仍能拦截的断点，整波到达末端的数量与时刻改由我方设伏节奏决定，末端由全波接战降为残余补漏。掠波连扫拦截机把火力通道由“弹—机”点交换升级为“趟—截面”带交换，删除单发制导与末段寻的环节，胜负改由趟次是否跟得上波前节拍决定，敌整链按时齐到的计划前提随之失效。迎面撒网弹形成不依赖传感器与频谱、可逐段补投的持续封段，交换率锚定在可再生网材对敌破网载荷的成本上，并使拦截结果可逐段清点核销。驻空电磁巡飞弹使节点每波次的成本预算由拦截弹基数改为驻空单元与防护时段接力，敌恢复以廉价数量压防须先承受逐架屏蔽加固的增重缩程代价。过境层云爆轰断波弹把最高并发的一段走廊压缩为一次体爆轰事件，稀缺精确弹由摊峰改补漏。引浪吞波诱杀弹把节点存活能力改由敌辨真损耗供给，反辐射饱和下引导、通信节点可静默轮换续存。上述能力共同改写单位交换成本、被瞄准置信度与持续防护时长，但每型只能以自身机理兑现，不能靠增加现役拦截弹基数替代。

3. 领域占位角度

现役“远程预警—区域防空—末端点防”序列中，蜂群突入低空盲区后至进入末端包线之间的时空，以及节点近界的目标确认环节，尚无装备占位。上述装备族以水下伏击、走廊截面清削与无源网段构成外沿清账层，以电磁巡飞弹构成节点前置软杀伤屏，以断波弹承担末端时间窗遮断，以诱杀弹与近防弹巢收口近界确认，体系才具备不以拦截弹数量为结算基础的反蜂群骨架。不建此族，只能退回扩充昂贵弹库与火力通道的路线，恰是敌低成本波次模型设计要压垮的对象。

4. 综合效益

综合效益集中于交换关系与持续作战：防御消耗由随来袭架次线性增长改为按预置布设、防护时段与确认动作结算，弹药寿命与敌波次预算解耦，要地与编队可在持续饱和下保持关键功能存续并隔离后续波次。建设取舍上，一次性水下伏击、气溶胶层与诱爆资产须与远程火力、末端点防构成补漏闭环；应优先以对抗试验闭合决定各机理成立的边界量，即水下被动判明虚警率、微波可送达能注与有效作用距离、开放海域成层保持与公里级同步起爆、网幕展开概率与有效幅宽、诱源辐射逼真度，现有材料均缺实测支撑；近防弹巢仅具概念级材料，触发判据与近距净空工况未闭合，须先补证再定取舍。敌转向全自主、逐架加固或高空样式时多数成立边界收窄，本族定位是改变交换关系的补链建设，而非替代硬杀伤。
