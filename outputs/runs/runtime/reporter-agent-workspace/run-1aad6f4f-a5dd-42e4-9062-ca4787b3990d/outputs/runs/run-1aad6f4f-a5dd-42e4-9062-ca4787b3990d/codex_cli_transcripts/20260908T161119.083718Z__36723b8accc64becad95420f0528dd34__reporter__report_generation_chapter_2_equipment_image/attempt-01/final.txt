## 二、项目画像
### （一）装备图像概述

| 装备名称 | 核心技术 | 部署或进入方式 | 关键动作、作用对象和直接效果 |
|---|---|---|---|
| 随浪伏击反蜂群弹 | 坐底静默待机、被动水声判明、垂直穿浪和定向破片杆幕。 | 沉放在敌惯常贴海航渡走廊的浅近海区，长时不辐射、不联网，只收不发。 | 先用水下声包络判出过顶方位与时刻，再自下而上穿浪起爆，直接把贴海密集过顶的蜂群整波推入近炸半径；敌若要规避，只能爬升现形或先付反潜清海成本。 |
| 掠波连扫拦截机 | 横向展宽破片刃带、趟次再生和重复掠穿。 | 依波级预警前出到走廊侧向预置高度，在敌波前到达时段切入截面。 | 不盯单机，只扫波前截面，一趟掠穿就削去整段编队，诱饵和加密都不改我方单趟成本；敌若减速或拉稀，只会把自己暴露时间拉长。 |
| 驻空扫域电磁灭群巡飞弹 | 宽频高功率微波脉冲、驻空供电和热管理。 | 在受护节点上空驻留轮换，面向来袭必经空域持续扫射。 | 以覆盖域和驻留时段结算，不按来袭架数结算；未加固的无人机、诱饵和干扰机进入域内即会失能、掉队或坠毁，敌靠数量压防的前提被打掉。 |
| 引浪吞波聚爆诱杀弹 | 真伪同形诱源、反辐射收拢判定和温压破片聚爆。 | 贴设在真节点旁，真节点全程静默，诱源按预案主动辐射。 | 诱敌为辨真假向诱源收拢，收拢瞬间整簇起爆，直接清算反辐射弹药群；敌每轮辨真都要先付一批弹药，波次优势被逐步抵扣成确认代价。 |
| 迎面撒网捕蜂拦截弹 | 纯机械柔性网幕、迎风展开和段位补投。 | 由高空气球或运输机在走廊入口和中段成串投放，按段成网。 | 依靠气流把前排蜂群兜卷缠裹坠落，电子干扰和诱饵对网幕无效；原本的低空偷渡通道被改成逐段清点的清收通道。 |
| 过境层云爆轰断波弹 | 车载成云铺层、多点同步起爆和体爆轰。 | 判明低空过境时间窗后，在末端走廊现地铺开可爆气溶胶层。 | 让整层高度在同一时间窗内同步爆轰，把拦截计价从架次改成过境时间切片；层内薄壳蜂群成批解体坠海，敌只能弃窗或拉长分散航渡。 |
| 撞线自付近防弹巢 | 无辐射被动感知、末端撞线触发和近距迎爆。 | 埋设在受护节点外缘、顶面和周边伪装体内，平时完全静默。 | 只在真正朝节点撞击的末端航段开火，最近弹巢迎面起爆，先敌引爆战斗部或直接击毁机体；圈外巡飞、过航和廉价诱饵不触发、不耗弹。 |
