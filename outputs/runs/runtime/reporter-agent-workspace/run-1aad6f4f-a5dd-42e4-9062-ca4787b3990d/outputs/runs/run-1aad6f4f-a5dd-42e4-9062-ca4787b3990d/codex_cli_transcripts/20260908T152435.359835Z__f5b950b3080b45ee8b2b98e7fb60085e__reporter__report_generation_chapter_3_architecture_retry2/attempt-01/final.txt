三、总体方案

（一）总体架构

敌蜂群为借海杂波与低空视界掩护，只能贴海低空、成波成段过境，总体架构的骨架正是这一共享暴露：以“波级事件”取代“单机航迹”作为公共状态，各层只消费走廊位置、过境时间窗与残余数量。随浪伏击弹在水下判明过顶波次并按波清账；掠波连扫机与撒网弹在走廊段按截面、按段削峰；层云断波弹在末端按时间窗整层清账；驻空电磁弹按同一到达时序选扇区占位照射；撞线弹巢只认“真机已做末端撞击”这一判据。后三类接战都不待雷达逐架建链；引浪吞波诱杀层则保护供给上述状态的辐射节点，真源静默、诱源聚爆，属使能环节而非独立杀伤弧段。

公共权限与资源随之改变：开火权按区域、时段、撞击判据预置下沉，水下判明后弹内闭环、驻空自动照射、弹巢自主触发，指挥所只调度波次与跨层移交，敌压制指控或干扰制导取消不了这一拍。衔接沿“削峰—移交—补漏”展开：前段将残余数量与到达时刻预判并同步远程火力与末端层，末端按漏网数反推补网与再铺密度。相互约束集中在同一走廊的时空占用与电磁静默：伏击禁入区、网幕与铺层净空、禁扫方向、真节点静默纪律须统一管制，布设资产被先期清剿即产生级联空档。

失效耦合由共同前提锁定：判窗可用且敌保持走廊几何与波次节奏。敌改爬升、拉散、绕道时，水下、截面、铺层手段逐级降效，威胁向节点收敛，由撞线弹巢与硬杀伤兜底；敌全加固或改用不依赖链路的自主蜂群时，电磁层失效，而机械缠裹、近炸与水下伏击等物理接触手段仍成立。故架构以失效维度互异的异质层冗余取代同型重复拦截，以预警判性决定软硬链切换，不把单件装备机理抽象为公共杀伤层。
