三、总体方案

（一）总体架构

总体架构不把反蜂群能力理解为增加拦截弹数量，而是围绕“发现可信、授权及时、处置可分流、效果可确认、波次可恢复”组织装备关系。沿海要地、岛礁和舰队共用的关键状态只有目标轨迹及分类置信度、交战权限、可用功率与弹药、拦截通道占用情况和处置结果；这些状态必须能在装备之间快速交接，但不能以指挥软件替代装备本体。

低空探测装备承担第一道物理断点：在地海杂波、低空遮蔽和多小目标并行条件下，持续提供目标位置、航迹连续性和可用于授权的分类依据。它的直接作用不是“看得更多”，而是避免漏检、误分把后续硬杀伤引向诱饵或无效目标。其失效将污染全部下游；若只能给出零散告警，软杀伤和拦截装备就无法形成有序分工。

干扰欺骗装备与诱饵装备处理的是敌方瞄准和导引关系。前者以受控电磁作用降低敌蜂群、中继或侦察节点的协同质量，后者以物理假目标分散敌方观测和弹药指向。二者不得共用“软杀伤”这一笼统判断：干扰依赖功率、频段和授权窗口，诱饵依赖布设位置、逼真度和可消耗数量；面对高度自主、无需持续通信的蜂群，干扰效果会明显收窄，诱饵仍可能改变其选择目标，但也会暴露布设规律。

硬杀伤武器和点防御装备只接收经过分类和软处置筛选的高威胁目标，分别承担远近不同的末段清除。前者以较远距离削减进入末端的目标数，点防御则以通道数、反应时间和再装填能力守住关键节点。若软处置不能确认效果，硬杀伤就会被迫逐架补射，重新落入高成本交换；若点防御先耗尽弹药或通道，后续波次将直接击穿要地和舰队功能。

因此，接口设计应优先保证轨迹可信度交接、交战权限转移、弹药与功率状态共享、处置结果回传及波次间恢复，而非扩大集成范围。架构成败以多波次压力下的连续拒止和恢复闭合判定：敌蜂群自主化、抗干扰能力、海杂波工况、波次间隔及我方补给能力仍是必须单独验证的边界。
