二、项目画像

（二）作战运用模式

1. 作战运用流程

本项目的进入条件，不是敌机数量本身，而是敌把蜂群压进第一岛链浅近海走廊、借海杂波和地形遮挡实施低空密集过境的那一刻。对这类威胁，作战运用不是单一“拦截”，而是沿敌航路从外到内分层改写交战几何：先在走廊内把“无痕通过”变成“必经付账”，再把抵近节点的蜂群改成“撞进来就失能”。

在浅近海通道上，随浪伏击反蜂群弹负责最前沿的静默削峰。它提前坐底布设，不辐射、不联网，只靠被动水声判明贴海过顶的方位和时刻，等波群最密处自下而上垂直穿浪，以破片杆幕一次覆盖掠海层。它的决定性动作不是逐架点杀，而是把一整波压进近炸半径，迫使敌要么爬升现形，要么在清海成本里先付一笔代价。只要海区不具备坐底条件，或敌绕开预置走廊，这一层就只能降级为补充手段。

在同一走廊的空中截面上，迎面撒网捕蜂拦截弹和掠波连扫拦截机承担两种不同的面拦截。前者适合入口窄带和低空密集队形，靠无源网幕把整簇前排缠裹坠落，把拦截结果变成可清点事件；后者适合敌波前已经形成、且需要连续多趟压薄的场景，拦截机不追单架，只以横向破片刃带反复掠穿波前截面，把敌的“同刻到达”拆成“逐趟减量”。前者重在封段，后者重在扫削，两者都不靠高价弹药逐架交换，而是把敌的密集优势变成走廊暴露时间的增长。

当敌继续前推到末端时间窗时，过境层云爆轰断波弹负责最后的窗口遮断。它不是按架追杀，而是先判明敌低空过境时窗，再在末端海上走廊现地铺出可爆气溶胶层，待整层同步过境即触发体爆轰，把计价单位从“架次”改成“过境时间切片”。这一动作适合走廊收口、敌波次高度和时序都可预判的场景，一旦敌改道绕行、纵向拉开或判窗失准，效果就从整层清账退回有限拒止。

在节点外沿与上空，驻空扫域电磁灭群巡飞弹承担“空域软杀伤屏”。它驻留在受护节点上方，以宽频高功率微波反复扫域，专门压制未加固的小型无人机、诱饵和伴随干扰机，把敌的低成本数量优势改写为逐架加固、逐架抬价。它适合敌蜂群还在进入走廊、尚未接触末端硬杀伤包线的阶段；若目标已高度加固，或敌改走主波束外的地形遮蔽通道，就必须由后续硬杀伤接手。

围绕高价值辐射节点，引浪吞波聚爆诱杀弹则是专门对付反辐射蜂群的“真假陷阱”。真节点静默，诱源主动辐射，逼敌必须先辨真再收拢；一旦弹药向诱源聚拢，诱爆弹就在收拢瞬间整簇起爆，把“辨真”本身变成一次批量清算。它的前提很清楚，必须是敌依赖辐射收敛，且我方能维持真源静默和诱源逼真；敌若改用预编程、光学直击或先行扫清诱饵阵地，这一手就会明显降效。

在最末端，撞线自付近防弹巢负责补最后一米。它不识别、不辐射，只在确认目标真的朝节点撞来时就近起爆，把诱饵、巡航和干扰型目标挡在外缘之外。它不是替代前几层，而是防止少量漏网目标把前面的削峰成果打穿，尤其适合节点外缘、顶面和局部盲区的最后封口。

2. 链路闭环分析

这套装备群的共同变化，是把反蜂群从“发现后逐架消耗”改成“按走廊、按波次、按时窗结算”。相对于传统做法，最关键的不是拦截手段更强，而是交换关系被改写：有的把目标从单架换成波群，有的把战果从一发换成一段，有的把消耗从来袭架数换成驻留时段，还有的把敌方的识别动作本身变成损失来源。敌越追求数量和同步，我方越容易把其压成固定几何和固定窗口，再用低成本手段完成清账。

各装备之间的闭环也不同。随浪伏击反蜂群弹和迎面撒网捕蜂拦截弹，负责把海上低空走廊拆成可预置、可清点的段；掠波连扫拦截机负责在波前被压薄后继续削减密度；过境层云爆轰断波弹则在末端窗口把残余高密度一次性断开。驻空扫域电磁灭群巡飞弹和引浪吞波聚爆诱杀弹，压的是节点周边的导引链和协调链，防止敌把走廊突防和节点打击连成一体；撞线自付近防弹巢则在最后撞击段兜底，阻止少量漏网目标形成实害。它们合起来，才构成从海面通道到节点外缘的完整闭环。

这条闭环真正的制胜点，是逼敌在三种不利选择里二选一：继续贴海密集过顶，就被水下伏击、网幕、扫削和体积拒止分段消耗；改为拉散、爬升或改道，就把突防密度、隐蔽性和协同一起交出去；先做反潜清海、先清诱饵或先改加固，则把时间和单机成本都推高。直接战果不是“多打掉几架”，而是让敌的波次节奏失去兑现条件，使我方关键节点在持续饱和压力下还能保持可用，后续波次被迫降密、降速、改窗。

边界也必须写清。随浪伏击反蜂群弹依赖水声判明和走廊几何，过宽海域、恶劣海况或绕行会削弱它；迎面撒网捕蜂拦截弹受风场和窄带约束，走廊失形就会掉效率；掠波连扫拦截机和过境层云爆轰断波弹都要求波前和时窗可预判；驻空扫域电磁灭群巡飞弹对加固目标和宽带抗扰目标效能下降；引浪吞波聚爆诱杀弹只对依赖辐射收敛的攻击链成立；撞线自付近防弹巢只处理真正撞线的末端目标。也就是说，这不是一套把所有蜂群都通吃的统一骨架，而是一组按威胁几何分别设局、分别清账、最后互相补漏的作战模式。
