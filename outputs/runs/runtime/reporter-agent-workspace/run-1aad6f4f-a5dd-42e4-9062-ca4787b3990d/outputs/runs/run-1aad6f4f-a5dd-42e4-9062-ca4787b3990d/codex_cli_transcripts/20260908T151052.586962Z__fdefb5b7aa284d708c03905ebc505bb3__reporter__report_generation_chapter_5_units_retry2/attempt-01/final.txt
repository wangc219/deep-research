五、研制基础

（一）参与单位

七型装备均无公开承研单位与分工文件可循，本栏仅按各自不可替代的机理环节给出参与机构类型，并把证据缺口列为归口条件。随浪伏击反蜂群弹的产品责任在被动水声判明与坐底再激活，应由水声探测与水下兵器类机构承担，接口对象是执行走廊布设的渔船、无人潜航器与水下监视网；验收证据须含混响和风浪本底下的判明距离与虚警率，民用航运误伤规避的净空界面尚无归属。掠波连扫拦截机的杀伤载荷按趟成本与截面覆盖率结算，平台与刃带载荷两类机构须先与波级预警方固定预报接口，试验机构标定掠穿包线、刃带寿命与再出动节拍，场级预报精度数据缺失。驻空扫域电磁灭群巡飞弹的研制单位应以弹载宽频高功率源与供电热控为主，先由电磁效应试验机构建立能注—失效概率曲线再集成总体；弹载作用距离与重复频率实测、对己兼容净空均未见公开。引浪吞波聚爆诱杀弹须电子对抗仿形源、温压战斗部与受护真节点装备单位三方协同，真节点辐射特征档案与静默纪律由使用方和装备单位共同交付，敌方分选算法与收拢弹道包线决定配弹量，属当前未知项。迎面撒网捕蜂拦截弹的主体责任在柔性网材与高空气球或运输机投放平台，风场展开试验须交付网目、展开概率与包裹率；网幕无源不可遥测，落网清点取证责任未落实。过境层云爆轰断波弹由燃料空气炸药与车载成层起爆系统机构集成，须在开放海区试验验证浓度维持、同步起爆与气象边界，公里级层域保持目前无公开试验证据。撞线自付近防弹巢依赖低成本被动触发引信与一次性弹体机构，真实末端撞击的触发阈值、安全净空与授权判据须先以靶试闭环，再确定弹巢与受护节点的集成归口。
