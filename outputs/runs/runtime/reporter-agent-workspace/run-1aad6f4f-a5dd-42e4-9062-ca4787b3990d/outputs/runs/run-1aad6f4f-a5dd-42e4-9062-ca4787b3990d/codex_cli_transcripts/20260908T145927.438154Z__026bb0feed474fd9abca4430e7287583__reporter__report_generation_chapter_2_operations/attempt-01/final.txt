二、项目画像

（二）作战运用模式

敌以诱饵与干扰先导耗我火力、再以廉价蜂群多波次低空压顶时，本栏各装备按各自机理在对应航段进入交战，把一次成功的处置接续成可持续的多波次拒止。运用以走廊分段为主线，但进入、退出与恢复节奏随装备机理不同而长短各异，不套统一流程骨架。

1. 作战运用流程

随浪伏击反蜂群弹的运用最依赖预置、单次交战动作最短：战前按敌贴海惯常走廊标定水深与底质逐枚坐底，全程不辐射、不联网，把交战权封在弹内。战斗阶段由被动水声阵以“波”为对象判明过顶来向与时刻，不追求逐架识别；波群最密处垂直穿浪，自下而上起爆出覆盖整个掠海层的破片杆幕，将整波一次清账。走廊内多枚接力，使同一波逐段折损，末端残余数量与到达时刻被预先削减，后段火力得以按预判时刻接续。敌爬升脱离贴海层即现形于远程火力，绕开走廊则该层失去对象而静默待机。

掠波连扫拦截机与迎面撒网捕蜂拦截弹同守走廊约束，循环节拍不同。前者按“到达提示—侧向布带—掠穿—掉头再穿”运转：预警只报波前方位、宽度与到达时间窗，不建单机航迹，值班机以横向破片刃带反复掠穿波前平面，每趟按整段截面结算，真弹诱饵等价，直至波前被削薄到末端可承受密度。后者按“定带—预置—投放—清点”运转：气球或运输机在入口窄带无源待机，成串投下的网弹迎风自展，前排整簇兜卷坠地即成一笔清点事件，与入口计数对账得剔除数；敌派探路机撞网后按段错时补网，把试探本身计入成本。前者受波前几何与趟次再生率限制，后者受网幕在位时长与补网周期限制，共同前提是敌仍把航渡压缩在可预置的窄带内。

近节点两型把开火权让给威胁自身驱动。驻空扫域电磁灭群巡飞弹在告警后飞抵节点上空，按威胁主扇区占位，对必经空域按预设周期反复宽频照射；值班员不逐架报伤，改以域内失能比例调节脉冲刷新与扫描扇区，驻留到限即由预备弹接力，敌若以整体加固机带队则本弹转入硬杀伤链。引浪吞波聚爆诱杀弹按“布—引—聚—爆—补”回应反辐射与按源引导弹药：真节点全程静默，成组诱爆弹仿形主动辐射，敌为辨认真假必须令整批弹向诱源收拢，弹组判明收拢进入包线即整簇温压破片起爆，把“先诱耗、再压制、后送载荷”的次序逐轮折成辨真代价，波次被迫拉长加厚。

末端两型一主动一被动。过境层云爆轰断波弹在判明过境时间窗后，于末端海上走廊现地铺出覆盖整层高度、绵延数公里的可爆气溶胶层，判读层完整后才待敌波主体整层入域同步起爆，按时间切片清账，两次铺层之间是固定的再铺间隙。撞线自付近防弹巢常年密布于受护节点外缘与顶面，被动感知仅在来袭进入“真正朝节点撞击”的末段航迹时于数十米内迎面起爆；圈外巡飞、过航与廉价诱饵不触发不消耗，诱饵要骗弹必须先做出成本接近真弹的撞击动作，弹量只随真实末端进入次数消耗。

2. 链路闭环分析

各装备的闭环载体不同，抗链路压制与战果核实方式随之不同。随浪伏击弹把判明与起爆封在弹内，指挥链被压制也取消不了这一拍，代价是战果无法自报，只能靠走廊后端声学与雷达哨位统计漏网、反推下一轮布设密度，形成“后置核实—下波修正”的闭合。掠扫与网幕都不做逐架确认：前者以扫削时机对波前到达的对齐误差为判据，错位只空耗一趟，靠趟次节拍自校正；后者无源不可遥测，成网与耗尽状态只能经下游光电复核，落网计数滞后会在补网间隙留下试探破口，故沿线对账必须计入闭环。

电磁巡飞弹的闭环在域内失能比例、脉冲刷新率与扫描扇区之间，值班按波次失能率裁决是否追加硬杀伤，对己禁扫与反辐射规避占用的时段须从有效占空中扣除。诱爆弹的闭环由敌收拢动作触发，起爆瞬间即完成清算，不占我方火力决策时延；其开口在收拢判据与静默纪律，真源静默不彻底或引信早炸晚炸都会使清算退化为偶发拦截，须由邻近硬杀伤兜底。弹巢闭环最短：链路受压制不改变触发条件，补充只按真实撞击消耗的巢位计数，防御寿命由此与敌诱饵总量脱钩。

多波次意义上的链路闭合，最终落在各层波间恢复周期对敌波次间隔的比值上：水下伏击带按损耗漏网补设、电磁弹按驻留时段轮换、网幕按段错时补投、云爆层按时间窗再铺、诱爆组按轮清算整补。任一层的恢复周期长于敌可压缩的波间间隔即出现空档，须由相邻层临时接管；压力验证应量化各层的成本交换断点与恢复门限，看敌方以多快的波次节律能把哪一层逼出空档、补位层在该空档内能否压住残余流量，这是本模式区别于单波拦截率的持续作战判据。各层中止以失去作用对象为界：敌弃用贴海走廊、改高分散或改用不依赖辐射引导的预编程与光学直击时，水下伏击、扫削、网段与辨真清算相应转停待机，由中高空与硬杀伤链接管，属运用的正常降级而非体系失效。
