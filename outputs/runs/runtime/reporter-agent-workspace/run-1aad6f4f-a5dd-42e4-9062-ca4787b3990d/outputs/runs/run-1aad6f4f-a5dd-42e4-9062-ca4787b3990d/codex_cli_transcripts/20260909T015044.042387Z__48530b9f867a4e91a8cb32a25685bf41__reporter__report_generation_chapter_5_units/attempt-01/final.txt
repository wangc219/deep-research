## 五、研制基础

### （一）参与单位

本项目不宜按通用“总体单位—分系统单位”套分工，而应按各装备的产品责任和可交付证据配置参与单位。公开材料未披露具体承研归属，以下仅提出必要的机构类型。

随浪伏击反蜂群弹的牵头单位应具备水下弹药总体、坐底结构和自主起爆产品责任，并联合水声探测、海洋环境测量及水下布放回收单位，负责证明复杂海况下的过顶判明、长期值守和穿浪起爆。关键接口是布设海区、民船航迹与后段火力移交；试验单位需交付底质适配、虚警漏判、阵位暴露和误触发证据，现有材料尚不足以确认其海区实测基础。

掠波连扫拦截机应由航空平台和面杀伤战斗部单位共同承担，另需飞行安全、刃带展开与快速再出动保障单位。其核心交付不是单机命中率，而是波前到达提示、平台掠穿包线、截面覆盖率及刃带再生周期的联验证据；目前缺少平台速度、载荷寿命和不同队形下清削率资料，不能据此指定具体航空承研方。

驻空扫域电磁灭群巡飞弹需由巡飞平台、弹载高功率微波源、电源储能和热管理单位联合研制，配套电磁兼容及无人机抗扰效应试验机构。接口集中在驻留时段、照射扇区和对己禁扫区；必须交付有效占空比、覆盖域失能率和轮换连续性数据。公开依据未能证明弹载宽频作用距离与目标阈值，相关单位只能按专业类型确定。

引浪吞波聚爆诱杀弹需要射频仿真、诱饵结构、近炸引信和温压破片战斗部单位协作，真节点所属的雷达、通信设备保障单位负责验证静默纪律与辐射特征隔离。试验责任应覆盖真假源不可辨度、弹群收拢率和诱爆安全距离；敌采用预编程或光学直击时的失效证据尚待补齐。

迎面撒网捕蜂拦截弹的主体应是网材、柔性展开、空投包装和气球或运输机布撒单位，另设低空空域安全与残骸清点试验机构。关键交付为成网完整度、断面覆盖、缠裹率和补网周期，并须证明对己方航空器的隔离能力。现有材料没有投放平台归属及风场试验结果。

过境层云爆轰断波弹需由车载储喷系统、燃料空气爆轰、气象扩散和多点同步起爆单位承担，安全评估机构负责人员、舰船和环境风险边界。其试验必须证明成层保持、同步起爆和走廊判窗可靠性；跨公里级气溶胶层的公开工程证据不足，不宜预设成熟承研单位。

撞线自付近防弹巢应由近炸感知、弹巢结构、末端战斗部和阵地安全单位负责，重点验证只对真实撞击航段触发、对过航诱饵不耗弹及多巢协同安全。现有输入缺少传感器类型、触发距离、布设寿命和实弹试验依据，因此只能确定机构类型，不能确认具体产品责任边界。
