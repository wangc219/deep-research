## 二、项目画像

### （二）作战运用模式

#### 1. 作战运用流程

反蜂群作战的进入条件，不是发现单架无人机后立即逐架拦截，而是确认敌方正在以侦察型、巡飞型和自杀型无人系统组成连续波次，并可能与防区外空面火力在时间上相互配合。沿海要地、岛礁节点和机动舰艇编队应先判断敌方攻击方向、波次关系和可能的瞄准对象，避免因廉价诱饵或先导无人机过早暴露全部防护手段。真正需要保护的是探测、能源、通信、指挥和火力节点的持续工作能力，敌方追求的也不是单波穿透，而是诱导我方高价拦截、迫使关键设备持续辐射，再以后续波次和防区外火力造成体系失能。

首个决定性动作是把低空、海面和岛礁杂波中的小型目标转化为可供交战的可信轨迹。低空探测装备应在敌蜂群尚未进入软硬杀伤范围前持续更新目标位置，重点不是单次报出目标数量，而是区分真实攻击目标、侦察目标、诱饵目标和因地海杂波产生的虚警。对于岛礁和沿岸固定节点，探测装备必须覆盖地形遮蔽、海天线附近和阵地低空盲区；对于舰艇编队，则应适应平台机动、舰体反射和编队自有电磁活动造成的背景变化。只有当首检、分类和轨迹可信度达到交战要求，后续软杀伤或硬杀伤动作才不会建立在错误目标上。现有公开材料能够支持“低成本规模化反无人系统”已成为建设方向，但没有提供本项目装备在海杂波、低空多目标条件下的探测概率、虚警率和更新周期，因此这些变量必须作为进入条件和压力验证的核心边界，不能以一般性“发现即处置”替代。

敌蜂群进入接近段后，软杀伤装备的作用对象不应笼统表述为“无人机本体”，而应针对其瞄准、通信、中继和协同关系实施压制或欺骗。对仍依赖卫星导航、地面控制、编队通信或中继节点的目标，干扰装备应在不暴露固定节点位置的条件下，优先破坏敌方对目标和航路的共同认知，使部分无人机偏航、失去协同、重复搜索或提前耗尽航程。其直接战果不是简单增加击落数量，而是让蜂群从能够集中突入的攻击编组退化为彼此失配的单机或小群，延后其抵达时间，打乱与防区外火力的协同窗口，并把后续硬杀伤从“同时面对整群目标”转化为分散处置。若敌无人机具备较强自主导航和抗干扰能力，软杀伤对飞行控制的影响会下降，此时应把效果判据转向瞄准置信度、编组协同性和攻击时间一致性的下降，而不能宣称其必然使目标坠毁。

诱饵假目标装备解决的是另一种矛盾：敌方侦察链已经锁定我方固定节点或舰艇编队，继续依靠电磁压制可能不足以阻止其自主末制导。此时诱饵应在物理位置、外形特征、电磁辐射和活动规律上制造足以改变敌方选择的替代对象，引导侦察型无人机、巡飞弹或后续火力把注意力转向假目标。对固定要地，诱饵的价值在于把敌方搜索和首轮毁伤从真实能源、通信或火力节点上引开；对舰艇编队，则要利用编队航行和辐射特征变化，使敌方难以确认哪一目标具有最高打击价值。其直接战果是敌弹药被消耗在无效方向，真实节点获得转移、隐蔽或恢复时间。诱饵不能替代硬杀伤，也不能对完全不依赖外部观测、具备自主识别能力的蜂群作出过高承诺；其成立前提是敌方仍需通过传感器特征和目标选择链完成攻击授权。

末端硬杀伤装备只在目标分类可信、软杀伤未能使目标失效且目标已进入可控交战包线时投入。其首要任务不是追求单架命中，而是保护关键通道和高价值节点，优先处置携带毁伤载荷、具备末段突防能力或正在指向能源与指挥设施的目标。点防御装备的制胜机理取决于可同时处理的目标数量、连续射击后的再装填或再供能能力，以及单次处置成本能否承受多波次压力。对固定节点，应保留足够通道覆盖下一波次，避免首轮将弹药全部用于低威胁诱饵；对舰艇编队，应根据航向、目标优先级和舰间防护关系分配射界，防止多个目标同时压入同一薄弱方向。直接战果是蜂群在接近目标前失去有效载荷或被迫偏离攻击航线，关键功能设施和舰艇编队保持作战能力。

一波攻击结束后，作战流程不能以“目标击落”作为闭环。必须确认敌方是否仍有漏过目标、是否存在失联后继续飞行的自主平台、是否有侦察机正在为下一波更新目标信息，并检查我方探测、干扰、诱饵和点防御设备是否仍具备连续工作条件。发现敌方进入下一波准备、我方弹药或能源低于持续防护门限，或者敌方防区外火力已开始压制关键节点时，应缩小暴露范围、调整交战优先级并转入保核心功能的防护状态。退出条件只需以威胁航迹消失、后续波次不再形成和防护链恢复为依据，不能把单次无来袭误判为威胁终止。

#### 2. 链路闭环分析

该作战模式的制胜链条是“连续探测与分类—改变敌方协同或瞄准—低成本消耗与分散—关键目标优先硬杀伤—确认效果并恢复防护”。其中最容易造成级联失效的不是某一种武器射程不足，而是首检漏目标、分类错误、授权迟滞、软杀伤效果无法确认和下一波到来前无法恢复。任何一个环节中断，都会使后续装备被迫在更短时间内面对更多目标，最终重新回到高价弹药逐架交换的被动基线。

低空探测装备改变的是“看不见后只能被动拦截”的交战关系。它的体系贡献只有在复杂背景下仍能提供连续、可复核的轨迹时成立；若只能在开阔空域发现少量目标，或者虚警过高导致交战员不敢授权，其贡献不能外推到蜂群防护。软杀伤装备改变的是敌方协同质量，适合优先处理依赖通信、导航或中继的无人系统，不能把对链路的压制效果等同于对全自主目标的摧毁。诱饵装备改变的是敌方被瞄准置信度，适合保护固定节点和编队中的高价值对象，但其逼真度、布设时机和敌方识别能力决定实际收益。硬杀伤与点防御装备改变的是末端处置效率和剩余防护时间，只有与前段降目标数、降协同性或转移瞄准相配合，才可能突破“弹药数量被波次耗尽”的经济约束。

敌方反适应将直接决定上述链条的失效位置。敌方可采用分散航路、低空贴海飞行、诱饵混编、通信静默、预装航路和自主末制导，降低干扰与欺骗收益；也可先以廉价目标迫使我方暴露探测和火力，再由防区外火力攻击能源、通信或再装填节点。因此验证不能只做单架目标的静态展示，而应设置多波次、混合载荷、杂波背景、链路受压和部分目标失联条件，观察首检分类是否持续、软杀伤是否能被物理或行为结果确认、硬杀伤通道是否在后续波次仍可用，以及防护节点能否在波次间恢复。公开审计材料已指出跨域指挥控制、互操作和数据融合治理存在缺口，这意味着简单扩大系统集成范围可能增加授权时延；本项目的建设判断应优先落到能够缩短交战决策、改善目标可信度并直接产生压制、欺骗或毁伤效果的装备本体，而不能以新增软件平台或泛化的体系联接替代作战能力。
