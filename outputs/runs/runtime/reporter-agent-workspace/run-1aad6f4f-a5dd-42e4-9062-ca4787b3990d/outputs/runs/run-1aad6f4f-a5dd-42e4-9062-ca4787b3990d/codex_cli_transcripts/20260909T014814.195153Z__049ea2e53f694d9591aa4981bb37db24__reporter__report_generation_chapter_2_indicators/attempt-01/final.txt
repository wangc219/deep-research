## 二、项目画像

### （四）主要战技指标

**随浪伏击反蜂群弹。**其战技指标应围绕“水下先判波、穿浪抢窗口、整波削峰”的作战效果设置，而不是沿用单目标命中率。第一，测量贴海蜂群过顶声包络的漏判率、虚警率及方位判定稳定性，直接决定能否在海杂波中可靠触发；第二，考核从声学判明到穿浪、起爆的时间耦合误差，以及破片杆幕对目标高度带的实际覆盖率，判断单枚武器能否把波群送入有效毁伤区；第三，观察多点接力后末端残余数量和到达时刻的预测误差，确认其是否真正为后续火力降低饱和压力；另测阵位长期静默状态下的被发现率和待机可靠性。验证应采用不同底质、海况、噪声背景和波次密度的水池及近海试验，材料尚不足以给出具体阈值。

**掠波连扫拦截机。**该机的效果在于把敌方波前削薄，使“整链按时到齐”失去条件，因此指标应体现“趟次—截面”而非“弹—机”关系。重点测定单趟破片刃带对波前截面的有效覆盖率、截面内目标密度变化对清削率的影响，以及连续掠穿时的再生间隔和单位时间可完成趟次；同时记录波前到达提示与实际掠穿的对齐误差，判断扫削栅栏是否会出现空档。验证应设置密集、拉稀、混入诱饵和多高度波前，比较其对整段通过率的压降；现有材料没有平台速度、刃带寿命和自身损失数据，不宜形成确定交换比。

**驻空扫域电磁灭群巡飞弹。**它要实现的是按驻留时段清除覆盖域内未加固无人机，故首要指标是覆盖域内的失能比例及其与目标抗扰状态、距离和高度的关系，验证电磁作用是否仍具“面清算”性质；其次测量有效照射占空比，扣除热管理、对己电磁兼容和反辐射规避后的实际连续防护时间；再次考核驻留体被发现、受攻击后的覆盖中断时长，以及轮换单元补位成功率。验证应将普通机、诱饵、干扰机和加固机分组，在多扇区会聚条件下记录飞控复位、掉链和坠落结果。材料缺少弹载能量、有效作用距离和重复脉冲数据，指标只能保留为试验变量。

**引浪吞波聚爆诱杀弹。**其直接效果不是单纯毁伤诱饵，而是迫使依赖辐射收敛的敌弹群为辨真付出成批损耗。因此应测诱饵与真节点在导引特征上的不可辨度、真节点静默期间的电磁泄漏率，以及敌弹进入诱爆包线的收拢比例；再以每组诱杀弹对应的敌方损失批量和真节点持续静默时间，判断“确认即付账”是否成立。验证需设置成批反辐射攻击、单发试探、光学确认和预编程直击等对照组，分别观察机制保持和退化情形。当前没有敌方分选算法、诱饵逼真度和起爆判据数据，不应直接承诺批量清算效果。

**迎面撒网捕蜂拦截弹。**该装备改变的是低空走廊的净通过率，指标应锁定网幕成形和物理缠收结果。重点考核单网完整展开概率、有效断面覆盖率、网幕在位时间与目标相对速度的匹配关系，并统计每段投放网数对应的缠坠架次和单位时间净放行架次；补网周期与敌波次间隔的差值，决定走廊是否会出现可利用破口。验证应在不同风向、风速、乱流和目标间距下进行实投，配合光电记录核销缠坠数量；走廊宽度、平台生存性和民用净空条件尚无材料支撑，不能外推到宽正面或高空目标。

**过境层云爆轰断波弹。**其追求的是把末端蜂群从逐架并发改成时间窗口内的整层清账，判别指标首先是成层后的有效体积覆盖率、浓度均匀性和保持时间，决定目标是否真正处于同一杀伤层；其次是多点同步起爆误差与层内薄壳目标的成批失效比例，验证体积作用能否压低残余流量；还需记录判窗误差、铺层完成时间和再铺间隔，判断敌方改期、诱饵试触或分散航渡能否耗空窗口。验证应从缩比风场、湿度和海况试验逐级推进，并设置绕层、高度分离和假波对照。现有材料没有开放环境成层保持和同步起爆实测数据，该装备的指标应先作为工程验证门槛。

**撞线自付近防弹巢。**该装备的判别性不在搜索能力，而在只对真正朝节点末端撞击的目标开火，从而避免被圈外诱饵耗尽。核心应测末端撞击航段的触发判定正确率、近距起爆与目标战斗部先行毁伤的成功比例，以及过航、悬停、旁掠和诱饵目标的非触发率；还要考核阵地布设密度与节点周边覆盖连续性，确认局部弹巢失效时是否留下直达缺口。验证应采用真实末端航迹与非攻击航迹混合试验，分离误触发、漏触发和弹巢提前暴露三类失效。现有资料未提供感知原理、作用距离、弹巢寿命和安全间隔，不能进一步给出点值指标。
