## 三、总体方案

### （一）总体架构

总体架构不把各装备的专属机理硬并为一个公共层，而是围绕“波次是否形成、走廊是否可控、节点是否被稳定瞄准、末端是否被击穿”组织分工。共同接口只保留四类：威胁来向与过境时间窗、可用走廊和禁入空域、交战授权与安全状态、漏网数量及后续补位需求；在通信受压或节点失联时，各装备仍按预置判据降级运行。

外沿水下由随浪伏击反蜂群弹承担静默削峰，利用贴海密集过顶留下的水声暴露，在不辐射条件下判明波次并自下而上整波毁伤；其失效不应拖垮后续层，但会使末端承受更高数量压力。走廊截面由掠波连扫拦截机反复切入，以可再生破片刃带按“趟次—截面”清削，不承担单机识别，依赖波级到达提示和持续出动能力。若敌被迫沿窄带低空密集通过，迎面撒网捕蜂拦截弹在入口或中段形成纯机械网幕，按段缠收并提供可核销的净通过量；风场、走廊宽度或敌高分散将使其迅速降效。

节点前方，驻空扫域电磁灭群巡飞弹以覆盖域和驻留时段压制未加固无人机的飞控、电调及数据链，把廉价蜂群的数量优势转化为加固增重和航程损失；其主攻方向错配、能储耗尽或驻留体被反制时，必须立即移交硬杀伤。对可预测的末端低空时间窗，过境层云爆轰断波弹负责一次性吸收并发峰值，只有在走廊收口、成层可靠、己方航行净空成立时才启用。面对反辐射收敛，引浪吞波聚爆诱杀弹以真假节点混淆迫使敌弹群聚集后整批清算；撞线自付近防弹巢则只对真正指向节点的末端目标自主触发，材料不足以支撑其更高层级的定量承诺，暂作近界补漏。各层失败通过残余数量、到达时刻和节点受威胁状态闭环，避免单一装备失效演变为全线饱和。
