一、需求分析

（二）国内外现状

1. 国外情况

美军公开确立的反无人路线与本项目作战矛盾同源。美国国防部2024年12月发布的《反无人系统战略》情况说明属类别层面的战略事实：其对策方向是规模化、低成本装备对冲低成本蜂群，并以联合反小型无人机办公室和Replicator 2专项推进规模化部署，防护对象明确指向关键设施与部队集结点，与我方要地、岛礁及编队节点的防护场景重合。这表明外军已公开承认高价拦截弹按架交换廉价无人机不可持续，其"以规模对冲规模"的选择印证了本项目对成本矛盾的判断。同期的具体审计案例给出相反方向的证据：GAO关于国防部跨域指挥控制的报告指出，综合框架、互操作与数据融合治理正是滞后环节，扩大集成范围可能反增时延。两则材料叠加可得出一个具体判断：外军规模化反制仍把胜负押在探测—指控—拦截的链路整合上，而其审计公开承认该链路的协同与互操作是薄弱点，恰对应本项目任务断点中的协同链稳定性一项。参数证据层面两源均告缺位：单次拦截成本、通道数与低空多目标探测概率均未披露，"低成本"只是方向表述，不能据以推断其交换比。推断边界须同时注明：公开轨迹中没有把接敌界面移出电磁域、改由水下被动判明或纯机械面完成整批清算的成规模列装报道，此类机理在外军现状中无成熟参照物。

2. 国内现状（中国）

中国侧缺少本次任务可引用的公开事实来源，两侧证据基础天然不对称，只能按类别事实与证据缺口分别说明。类别层面可确认的是：国内反无人机公开产品与试验方向已覆盖低空探测、电磁干扰、网捕与非动能近程拦截，任务对象多为单机与小群，应用场景以要地安防和低空活动管控为主，公开呈现的反制逻辑偏单机、小群处置；针对贴海密集过顶蜂群按波次整批清算的靶场试验、单次拦截成本与数百架级波次压力数据，未见系统披露。工程基础是可支撑判断的：国内无人机与弹载电子产业链规模大、低成本制造能力强，具备规模化生产消耗型反蜂群装备与批量布设的条件，但这属于推断而非引证事实；坐底长时值守、宽频高功率源小型化、大面积柔性网材与气溶胶成层保持等具体环节的成熟度，无公开证据可判定，不推断单位归属与列装状态。

3. 对比小结

两侧的共同确认点是低价蜂群颠覆了逐架拦截的成本模型，差异在于可检验的公开轨迹。美国以战略专项加审计报告留下文本轨迹，既确认低成本规模化方向，又自认跨域协同治理滞后；中国侧公开轨迹集中于民用低空安防与产业能力，蜂群级对抗的定量证据未进入公开域，比较天然不对称。对本项目装备选择的含义有三：其一，水下预置伏击、机械网幕拦收、按截面或时间窗整批清算等机理在外军现状中均无同类成规模参照，须自建验证证据，不能借外军现状背书成熟度；其二，外军审计暴露的协同链缝隙，反向支持不辐射、不依赖链路即可完成交战的装备路线；其三，中美公开材料都不能回答单次成本、探测概率与通道占用等关键参数，现状比较的结论止于方向与断点层面，具体取舍待实测数据闭合后再定。
