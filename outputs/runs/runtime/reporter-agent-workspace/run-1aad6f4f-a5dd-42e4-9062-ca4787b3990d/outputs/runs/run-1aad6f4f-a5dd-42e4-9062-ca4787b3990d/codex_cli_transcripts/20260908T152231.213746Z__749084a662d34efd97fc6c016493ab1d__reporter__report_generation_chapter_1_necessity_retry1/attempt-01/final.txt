一、需求分析

（三）建设必要性分析

1. 作战使用角度

敌以低成本蜂群贴海低空、借杂波与视界遮挡密集成波过顶，以同时到达压穿通道有限的末端火力；沿用“雷达建链—逐架拦截”的用法，防御只能按敌架次线性烧弹，这是作战使用必须改写的根因。随浪伏击反蜂群弹把接敌界面移入水下：坐底弹不辐射、不联网，以被动水声阵判明过顶方位与时刻，垂直穿浪在波群最密处起爆出覆盖整个掠海层的破片杆幕，按波清账、接力逐段折损；干扰、诱饵与隐身都取消不了水下判明，敌爬升即现形于远程火力，清海则先暴露自身批次。掠波连扫拦截机对混入同形诱饵的成波编队不识别、不跟踪单架，只以横向展宽的破片刃带反复掠穿波前、按趟削去整段截面，真弹与诱饵等价处置，加密加码不抬高单趟成本；敌以整链按时到齐为兑现条件，不可预知的截面损失迫其超量投保，拉稀减速又自耗航渡预算。迎面撒网捕蜂拦截弹针对为避远程雷达点名而挤入低空窄带的队形，沿走廊按段投下无源网幕，迎面缠裹整簇前排、逐网清点取证，电子干扰与隐身没有作用对象，爬升、拉散、逐架破网三途分别现形、自破同时到达、自抬单价。三种用法把防御从末端被动接战前移为走廊纵深削峰，分别拆掉敌无痕偷渡、波次饱和与诱饵稀释三根支柱。

2. 装备能力提升角度

能力提升的必要在于把防御容量从火力通道与弹库上解绑，改由装备机理定价。驻空扫域电磁灭群巡飞弹驻留节点上空，按防护时段反复以宽频高功率微波照射必经空域，未逐架屏蔽的飞控、电调与数据链进入覆盖域即失能，消耗按驻留时段与覆盖域结算而非按架数；疏散变速绕不开必经空域，逐架加固线性抬价增重缩程，敌方打悬空弹体须耗昂贵防区外火力。引浪吞波聚爆诱杀弹令真节点全程静默、仿形诱源按档案主动辐射，敌反辐射弹药只能向诱饵收拢辨真，收拢瞬间温压破片整簇起爆、成建制清算，先诱耗—再压制—后送载荷的波次每轮先送掉一批，节点存活不再取决于拦截弹基数。过境层云爆轰断波弹判明时间窗后在末端海上走廊现地铺开绵延数公里的可爆气溶胶层，波次整体入层即同步体爆轰，以超压、火球成批解体层内薄壳机体，把逐架命中概率换成层内体积覆盖，先遣诱饵试触只耗敌自身波次资源。三类能力分别以域结算、真假不可辨、时段清账摆脱弹库约束，是增量拦截弹无法替代的机理跃升。

3. 领域占位角度

领域占位的缺口在现役反无人谱系空白的物理域：水下静默伏击、无源机械封段、临空电磁体积清算与真假诱源聚杀均无同类装备在位。上述项目以水声、力学接触、微波耦合与辐射诱骗补上不可互换的能力格位，构成“增加拦截弹数量”之外的体系占位。

4. 综合效益

综合效益在于把敌数量优势折算为敌自身的波次、时间与单价代价，使我方成本不再随敌供给线性上升。取舍须按失效边界确定：水下伏击受海区条件与长时待机可靠性限制，层云弹的气溶胶保持与同步起爆尚无试验支撑，诱杀弹仅在敌依赖成批反辐射辨真时成立，网幕依赖走廊收口与风场，电磁弹对整体加固目标失效。宜据此确定各自体系层级，先闭合海区水声背景、微波效应阈值、成层试验与网幕展开可靠性等证据缺口，再行立项编成，不以单件替代末端点防御兜底。
