## 二、项目画像

### （一）装备图像概述

| 装备对象 | 核心技术与形成能力 | 部署或进入方式、关键动作 | 作用对象、效应机理与直接效果 |
|---|---|---|---|
| 低空多目标探测装备（任务框架可识别，具体型号与体制未提供） | 装备本体需要在沿海、岛礁和舰艇近海低空环境中，对低小慢目标保持连续物理探测，并在地海杂波、低空遮蔽和多目标同时接近时完成目标分类与轨迹保持。决定性能力不是单纯增加探测距离，而是把“发现一个目标”转化为“持续确认一批目标及其航迹”，使后续软杀伤、硬杀伤获得可用的处置窗口。现有输入没有给出探测概率、虚警率、更新周期、低空盲区高度和可处理目标规模，因而不能确认具体技术路线或成熟度。 | 装备应在蜂群发射后、进入软硬杀伤包线前形成连续覆盖，优先承担首发现、分类和航迹确认动作；其输出只能作为交战授权和处置装备的接口，不能把融合软件或指挥平台本身当作项目能力。沿海固定节点、岛礁阵地和舰艇编队的遮挡条件不同，实际进入方式必须由阵地高度、舰体结构、海况和供电约束决定，当前底稿未提供这些变量。 | 直接作用对象是低成本侦察型、巡飞型和自杀型无人机组成的混合蜂群。其制胜机理是降低首段漏检和误分，使敌方蜂群在接近末段前暴露规模、方向和优先目标，防止敌方以少量诱饵污染处置顺序。直接效果是为分层处置争取时间，并减少因目标轨迹不可信造成的授权迟延；若在公开海杂波、低空和典型蜂群规模下不能给出探测与虚警边界，该装备的项目价值无法成立。 |
| 瞄准链压制与欺骗装备（是否包含独立诱饵装置，输入未明确） | 装备必须依靠自身的发射功率、波形控制、抗压制能力或物理诱饵逼真度，改变敌方从侦察、定位、识别到导引的连续一致性。核心不是泛化的“电子对抗能力”，而是让敌方无法稳定判断真实目标、无法把多架无人机的观测结果汇聚到同一目标上。现有材料未提供敌蜂群使用的通信、导航、协同和自主决策方式，因此不能据此确认压制、欺骗或诱饵三类本体中的优先项。 | 在敌方完成初步定位、但尚未形成稳定瞄准和协同导引时进入作用窗口。固定要地可通过物理假目标改变敌方目标选择，舰艇编队则可能需要伴随机动和电磁辐射控制共同制造观测不一致；具体布设数量、进入距离和持续时间均不能由现有输入补造。关键动作应是使敌方侦察结果无法稳定复核，而不是单纯提高我方信号强度。 | 作用对象是蜂群依赖的侦察定位链、中继通信链和目标分配链，直接效果是把来袭弹药引向假目标、迫使其重复搜索，或使多机协同失去统一目标。其制胜机理是降低敌方被瞄准置信度，从而把蜂群的数量优势转化为无效消耗，减轻末端拦截压力。若敌蜂群能够在完全自主、强抗干扰条件下依靠机载识别独立完成攻击，该装备对核心战果的影响将显著下降，必须以敌方自主程度和抗干扰证据划定适用边界。 |
| 低成本末端硬杀伤与点防御装备（具体武器形式未提供） | 装备本体要解决的是末段“目标数量超过拦截通道、弹药单价高于来袭平台价值”的交换失衡，能力重点包括单位时间可处理目标数、连续射击或发射能力、杀伤可靠性和再装填速度。不能仅以“具备拦截能力”作为立项依据；若仍依赖高价弹药逐架击毁低成本蜂群，就无法改变敌方以规模换消耗的作战逻辑。现有底稿没有提供单次拦截成本、弹药储量、通道数、再装填时间和不同目标类型的杀伤判据，尚不足以确定性能指标。 | 装备在蜂群已经穿过探测和软杀伤环节、进入要地或舰艇末端防护区时承担最后处置动作。固定节点需要关注多方向同时来袭时的通道分配和持续射击，舰艇编队则受弹药携带量、舰体防护和安全射界限制。关键动作不是追求单波全部击落，而是在多波次压力下优先阻断携带毁伤载荷的目标，并保留对后续波次继续作战的能力。 | 作用对象是已经获得较稳定航迹、且无法可靠通过压制或欺骗解除的巡飞弹、自杀式无人机及混合蜂群中的高威胁载荷平台。直接效果是降低进入关键设施和舰艇有效毁伤区的目标数，使防护节点在连续攻击中维持关键功能。其制胜机理取决于单位时间处理量与单位交换成本是否优于敌方；如果弹药耗尽、再装填无法跟上波次间隔，或必须逐架使用昂贵拦截弹，该装备即使单次命中率较高，也不能形成持续拒止。 |
| 诱饵假目标装备（是否作为独立项目，现有画像未给出） | 若单独立项，其核心应是以可布设、可重复消耗的物理目标模拟真实要地、舰艇或关键辐射源，使敌方在目标识别和攻击分配阶段产生可验证的错误选择。决定能力的是外形、热特征、电磁特征、机动或布设状态与真实目标的相似程度，以及在蜂群同时识别、多源观测和重复攻击条件下能否保持逼真；不能用一般“欺骗能力”替代这些装备本体变量。现有输入没有提供假目标类型、逼真度证据和敌方识别传感器信息。 | 其进入方式应位于真实目标周边或敌方可能的攻击航路上，在蜂群建立目标优先级前完成布设并保持必要特征。固定要地与舰艇编队的布设条件不同，前者受阵地空间和供电影响，后者还受航行、海况和暴露风险影响；当前材料不足以判断是否需要伴随部署、一次性消耗或可回收使用。 | 作用对象是依赖目标特征匹配完成攻击分配的侦察和打击型无人机，直接效果是把部分蜂群载荷导向无关目标，延迟真实目标遭受集中攻击的时间。其制胜机理不是摧毁蜂群，而是改变敌方弹药投向，降低真实节点的同时受击密度，为探测恢复和末端防御争取时间。若敌方能够通过多源实时复核、人工授权或高自主度识别排除假目标，该装备的直接战果将收缩，是否值得独立建设必须以公开条件下的识别误导率和敌方反适应结果验证。 |
