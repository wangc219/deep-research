一、需求分析

（三）建设必要性分析

1. 作战使用角度

第一岛链沿海、岛礁和舰队节点面对的不是单一无人机袭扰，而是低成本蜂群与防区外火力叠加形成的多波次饱和突防。敌方借海杂波、低空盲区和电磁压制争取先手，若仍按“发现单机、逐架跟踪、逐发拦截”组织防御，作战节奏将被敌数量和弹药消耗牵引。建设反蜂群专用装备，必要性首先在于把交战对象从单架目标改造成波次、走廊、空域或末端撞击事件。

随浪伏击反蜂群弹针对贴海密集过顶这一不可完全取消的航渡暴露，在敌惯用走廊水下静默预置，以被动水声判明波群过顶时刻，垂直穿浪并在掠海层内形成破片杆幕，按波削减敌机数量。它把易受干扰的空中发现环节前推为水下被动伏击，但只适用于水深、底质和航路适配的浅近海，敌改走高空、分散航线或先期清海时需由其他防线接替。

迎面撒网捕蜂拦截弹利用敌为规避远程雷达而被迫进入的低空窄走廊，由气球或运输机成串投放无源网幕，以迎面相对气流缠住密集前排。其价值不在精确命中，而在把走廊切成可逐段清点的闸门；敌若爬升则暴露于远程火力，若拉散则自行削弱饱和效果。风场、网幕展开可靠性、补网投放节奏和己方航空器净空，是该装备必须验证的成立条件。

过境层云爆轰断波弹面向末端海上咽喉的高并发过境波次，依据时间窗在走廊现地形成覆盖一定高度带的可爆气溶胶层，以一次同步爆轰成批毁伤薄壳无人机，使拦截计价由架次转为时间切片。它可吸收点防御无法承受的瞬时峰值，但成层保持、同步起爆和判窗准确性受风、湿度、湍流及敌方改道影响，不能替代后续点防御。

撞线自付近防弹巢则把最后数十米交战交给节点周边的无辐射自主弹巢，仅在目标真正朝受护节点撞击时触发，过航、巡飞和远距诱饵不消耗弹药。该装备直接保护雷达、通信和火力节点免遭末端漏网目标摧毁，改变“诱饵越多、防御越快耗尽”的关系；其核心风险是末端航迹判定、误触发控制和近距爆炸对己方设施的安全边界。

2. 装备能力提升角度

掠波连扫拦截机解决的是逐架拦截成本随蜂群数量线性上升的问题。它不搜索、不识别单机，而按波前所在高度和空间截面反复掠穿，以可再生破片刃带完成整段清削，使敌加密编队或混入诱饵不再同步抬高我方单次交换成本。其制胜条件是敌仍沿受约束走廊形成可扫波前；若改为多方向、小群、异步渗透，则必须由末端硬杀伤补足。

驻空扫域电磁灭群巡飞弹把非动能对抗由“逐机干扰”改成“按覆盖域和驻留时段清算”。它在节点上空驻留，以宽频高功率微波反复作用于未充分加固无人机的飞控、电调和数据链，使多个波次共同承担同一驻空单元的防护成本。敌若进行逐架屏蔽加固，将面临重量、航程和数量优势下降；但对高抗扰目标、地形遮蔽航线以及能量和热管理不足的工况，必须及时转交硬杀伤。

引浪吞波聚爆诱杀弹专门破坏反辐射蜂群“先辨真、后压制、再送载荷”的攻击顺序。诱弹仿形节点并主动辐射，真节点保持静默，迫使敌弹群向诱源收拢后以温压和破片整簇清算。它使目标确认本身变成敌方损失来源，直接延长关键节点静默存活时间；但对预编程、卫星引导或光学直击目标效果有限，真假辐射逼真度和真节点静默纪律决定其能否成立。

3. 领域占位角度

上述装备共同指向反蜂群领域由“增加拦截弹数量”转向“改变交换单位、缩短决策链并降低末端并发”。水下伏击弹承担贴海航渡段的先期削峰，连扫拦截机承担走廊截面清削，电磁灭群巡飞弹承担节点外层持续封控，聚爆诱杀弹承担辐射节点防护，撒网装备和层云断波弹分别承担低空通道封段与时间窗拒止，近防弹巢负责最终撞击线兜底。各装备没有替代关系，其价值取决于敌方采用的航路、制导方式和蜂群自主化程度。

4. 综合效益

建设必要性最终体现为关键节点和机动编队在多波次攻击下能够持续工作，而不是单次拦截率局部提高。应优先验证水下波次判明、走廊截面清削、驻空电磁有效能注、诱饵逼真度、网幕成形、层云稳定和末端自主触发等决定性变量，并以波次拒止连续性、末端残余数量、恢复周期和成本交换关系检验项目取舍。对缺少实测数据的装备，不宜直接冻结型号和数量；应依据敌方反适应压力，优先建设能够在通信受限、节点受压和弹药不足条件下仍独立完成物理作用的装备本体。
