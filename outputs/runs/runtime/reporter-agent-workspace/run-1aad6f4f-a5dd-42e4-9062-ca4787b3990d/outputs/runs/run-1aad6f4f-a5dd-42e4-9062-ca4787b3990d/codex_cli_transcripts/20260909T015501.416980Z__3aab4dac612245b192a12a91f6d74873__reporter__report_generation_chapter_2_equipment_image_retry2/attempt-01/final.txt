## 二、项目画像

### （一）装备图像概述

| 装备对象 | 核心技术与形成能力 | 部署或进入方式 | 关键动作与直接效果 |
|---|---|---|---|
| 随浪伏击反蜂群弹 | 以坐底潜藏式弹体、低功耗被动水声阵和垂直穿浪战斗部为核心。装备不主动辐射、不依赖持续数据链，把探测对象由单架无人机改为贴海密集波次形成的过顶声学包络；在判明来向和过顶时刻后，使破片杆幕覆盖掠海高度层。它改变了空中逐架拦截的任务链，将交战单位从单机改为整波。 | 按敌惯用贴海航渡走廊，依据水深、底质、潮汐和民用航迹预置多枚坐底弹，形成分段接力的水下清账线。平时静默值守，战时由弹上被动声学判明后自主触发，不把关键动作交给易受压制的岸基链路。 | 蜂群主体贴海密集过顶时，弹体垂直穿浪，在波群最密处起爆，以破片杆幕批量毁伤低空目标，直接削减末端到达数量并提前判明残余波次。敌若爬升便脱离掠海隐蔽而暴露于远程火力；若先反潜清海，则必须为整条走廊投入时间和兵力。海况噪声、声学虚警、时间窗口不足、敌绕开走廊或阵地被清除时，效能明显下降。 |
| 掠波连扫拦截机 | 采用可重复出动的平台和横向展开的定向破片刃带，不配置逐架搜索、识别和末段寻的设备。其制胜机理是把最小打击单元从“单机”改成“波前截面”，用相对掠穿速度、刃带宽度和破片密度完成面状清削，使单次消耗主要随出动趟次发生，而不随截面内真假目标数量线性增加。 | 依据预警系统提供的波前位置、宽度、高度带和到达时间，在低空走廊侧向前出占位。平台完成一次掠穿后退出、再装填或再生刃带，并按敌波次节拍重复进入；多机接力覆盖整段航渡暴露窗。 | 拦截机不追逐单架，而是沿波前法向展开破片刃带并反复掠过，直接削薄整段编队，使敌蜂群难以保持按时齐到。加密波次或混入诱饵不会抬高我方单趟成本；敌若拉稀、减速，则暴露时间和航渡消耗增加。其效果依赖可预占走廊和波级预警，敌改为多方位、异步小群渗透，或平台再出动率、刃带覆盖密度不足时，必须退回逐群或末端点杀伤。 |
| 驻空扫域电磁灭群巡飞弹 | 将宽频高功率微波源、定向天线、弹载供电储能和热管理设备压缩进可驻空巡飞弹。其形成的是按覆盖体积和驻留时段结算的区域软杀伤能力：微波能量经天线、线缆、缝隙和导航接收链路耦合，使未加固无人机的飞控、电调或数据链复位、失控或停摆。 | 在节点与来袭主走廊之间升空驻留，按预警判定的扇区和高度带建立电磁防护域；由预备弹轮换补位，维持多个波次的连续照射。交战控制从逐架授权转为划定空域和时段，并保留对己方通信、航空器和高价值平台的禁扫方向。 | 蜂群进入覆盖域后，装备以周期性宽频脉冲反复扫域，直接造成未加固无人机成批掉队、坠毁或失去协同，降低末端同时到达数量。敌若逐架屏蔽加固，单机重量、成本和航程受到牵制；若以昂贵远程火力摧毁驻空弹，则形成高价值弹药换一次性消耗单元的交换。目标抗扰过高、地形绕行、驻空体被反辐射打掉、能源和热管理压低有效占空比时，只能由硬杀伤接续。 |
| 引浪吞波聚爆诱杀弹 | 由高逼真仿形辐射源、成组贴设弹体和收拢触发的温压破片战斗部构成。真节点保持静默，诱杀弹复现其天线特征、功率起伏和辐射节律，迫使依赖辐射源收敛的反辐射弹药向诱源集中；弹群一旦进入预置包线，即以一次聚爆清算整批导引头，形成“辨真即付损失”的强制交换。 | 成组布置在雷达、通信中继或防空火力节点旁，并同步执行真节点静默、诱源辐射和诱饵轮换。诱饵位置应与真节点保持可控间隔，既使敌难以远距分辨，又避免聚爆超压和破片波及受护设施。 | 敌弹为确认真实辐射源而向诱饵收拢，诱爆弹在收拢瞬间以温压和破片成批摧毁来袭弹药，直接打断“先诱耗、再压制、后送载荷”的波次顺序。敌若少量试探，确认效率降低；若集中投弹，则更易形成聚爆目标。该装备只克制依赖辐射或相关源引导的攻击链，预编程、卫星、光学直击以及先期清扫诱饵阵地等方式会使其效能显著降低；真节点静默不彻底或诱源逼真度不足，也会使敌直接转攻真目标。 |
| 迎面撒网捕蜂拦截弹 | 以密封网弹、配重前缘和高强度可折叠柔性网材为主体，不装主动探测、制导和爆炸战斗部。网弹依靠投放后的迎面气流展开为大面积网幕，利用网丝缠入旋翼、舵面和气动结构造成阻力骤增与失速坠落，把低空密集蜂群由逐架识别改成按走廊段落清收。 | 由高空气球形成长时布撒站，或由运输机在低空走廊入口和中段成串投放。布设前按地形、雷达盲区、风场和敌可能进入方向划分网段，波次间依照落网数量和补网周期错时补投。 | 敌蜂群进入窄带后，网幕迎面兜卷前排目标，直接形成可由光电复核的坠落和清点事件，减少末端同时来袭架次。电子干扰、诱饵和隐身对机械接触不起作用；敌若爬升则暴露于远程火力，拉大间隔则自行拆散饱和峰，加装破网装置则增加单机重量和成本。走廊过宽、风场导致展网失败、波次间隔短于补网周期或己方航空器无法实施净空管制时，网幕会出现破口。 |
| 过境层云爆轰断波弹 | 车载平台集成燃料储喷、气溶胶雾化、层域完整性判读和多点同步起爆装置。其核心不是逐发制导，而是在敌低空过境时间窗内铺设覆盖走廊高度带的可爆气溶胶层，以超压、火球和卷吸对层内薄壳无人机进行体积性毁伤，把拦截计价单位从架次换成过境时间切片。 | 由外部监视链判明敌低空走廊和时间窗后，车组沿末端海上通道快速展开，横向或分段喷布气溶胶并守候其有效存续窗口。成层完成后由多点引信同步触发，残余目标交给点防御；下一时间窗需重新铺层，不能把一次性层域当作连续火力。 | 当蜂群主体进入可爆层的覆盖体积后，多点引信实施同步体爆轰，以超压、火球和卷吸作用批量毁伤层内薄壳无人机，直接打散并发突防，使漏网目标数量降至末端通道可处理范围。敌若弃用该时间窗，需重新组织航渡；若拉长间隔，则失去集中压点。风漂、湍流、湿度和沉降导致云层不完整，判窗误差超过成层守候时间，或敌改道、分高度绕行时，体积杀伤会退化为局部作用。 |
| 撞线自付近防弹巢 | 由埋设式一次性弹巢、无源末端接近感知器和近距先敌起爆战斗部组成。弹巢布置在受护节点外缘、顶面和伪装体周边，不持续辐射、不联网，也不承担远距离识别；只有目标确实转入朝节点撞击的末端航段时，最近弹巢才自主启动，将火力使用条件从“发现并确认每架”改为“确认其撞击方向已不可逆”。 | 在雷达、通信、能源或指挥节点周边按立体威胁方向密集埋设，平时无人值守，依靠本地感知和预置保险逻辑运行。弹巢之间以交叠杀伤区覆盖节点外缘，战后按触发记录和残骸位置补充，不把弹药库存消耗在圈外巡飞、过航或远距诱饵上。 | 来袭无人机进入真实撞击航段后，最近弹巢在数十米距离内迎面起爆，先于机体接触节点引爆其战斗部或直接毁伤机体，直接保护关键设施免遭末端撞击。诱饵若只在外围巡飞不会触发；要骗取弹巢，必须完成接近真实目标相近的末端撞击动作，诱饵消耗难以无代价放大。其边界是近距感知误判、弹巢覆盖间隙、节点周边民用或己方目标净空，以及敌从高空投放、远距爆炸或非撞击方式实施毁伤；公开材料尚不足以给出触发距离、误触发率和单巢覆盖量等确定参数。 |
