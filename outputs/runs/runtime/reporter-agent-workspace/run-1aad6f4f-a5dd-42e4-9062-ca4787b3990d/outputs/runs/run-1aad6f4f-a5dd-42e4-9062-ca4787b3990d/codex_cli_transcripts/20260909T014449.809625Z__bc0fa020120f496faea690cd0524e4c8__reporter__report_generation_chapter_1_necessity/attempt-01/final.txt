## 一、需求分析

### （三）建设必要性分析

#### 1. 作战使用角度

第一岛链沿海、岛礁和舰队节点面对的不是单一无人机来袭，而是低成本蜂群与防区外火力叠加形成的连续饱和突防。敌方通过低空、海杂波、诱饵、反辐射引导和多波次投送，迫使我方以昂贵拦截弹逐架处理，最终在探测、通道和弹药库存任一环节出现断点。因此，建设必要性首先体现为改变交战单位，不能继续把“发现一架、锁定一架、拦截一架”作为唯一作战动作。

随浪伏击反蜂群弹针对的是敌蜂群为隐蔽而必须贴海密集过顶的航渡段。装备坐底静默，以被动水声判明波群方位和过顶时刻，随后垂直穿浪，在波群最密处形成自下而上的破片杆幕，将整波提前削峰。它把末端防御从临机逐架拦截前推为走廊伏击，使敌若继续贴海密集航渡就要逐段承受损失，若爬升则暴露于远程火力，若先行反潜清海又必须付出时间和暴露代价。其价值取决于浅近海底质、水声背景、布设隐蔽性和判明至起爆的时间余量，不能外推为对高空分散目标的通用手段。

掠波连扫拦截机服务于敌仍以集中波前通过近岸走廊的场景。它不追求单机识别，而是以前出平台反复掠穿波前，用横向展开的破片刃带削减整段编队截面。敌增加架数或混入诱饵，不会按比例增加我方单趟负担；敌若拉稀、减速或分散，则延长自身在走廊内的暴露时间，使其按时齐到的作战计划失去可靠性。该装备的作战成败不在单发命中率，而在波级预警、刃带有效覆盖和再出动节拍；当敌改为多方向、小群、异步渗透时，应由末端点防御接管。

驻空扫域电磁灭群巡飞弹改变的是高价值节点上空的防护方式。装备提前占位，在来袭主扇区反复施加宽频高功率微波，使未充分加固的飞控、电调和数据链失能，清算按驻留时段和覆盖空域计算，而不随蜂群架数线性增长。敌方疏散、变速和混编难以绕开覆盖域，逐架加固则会增加重量、成本并压缩航程；但该装备必须接受高抗扰目标、高空绕行、反辐射打击和对己电磁兼容等限制，适合作为前置区域清除层，不替代硬杀伤。

引浪吞波聚爆诱杀弹针对敌反辐射攻击链。它在真节点旁构造仿形辐射源，使真节点保持静默；敌为确认目标而向诱源收拢时，诱杀弹在汇聚区域实施温压与破片清算。装备改变了“真节点开机吸引攻击、再依靠拦截弹硬抗”的使用方式，把敌方辨真动作变成自身弹药损失。它可压缩敌“先诱耗、再压制、后投送”的波次节奏，但对预编程、卫星或光学直击目标作用有限，成立前提是诱源逼真、真源静默和敌弹群确实依赖辐射收敛。

迎面撒网捕蜂拦截弹利用的是低空走廊的几何约束。高空气球或运输机在入口和中段成串投放网弹，网幕迎风展开，以纯机械缠裹处理密集前排，不依赖雷达、数据链或爆炸引信。它使低空走廊由无痕偷渡通道变为可分段清点的物理闸门，敌若爬升便进入远程火力视野，若拉散则自行削弱同时到达的饱和效果。其短板是风场、走廊宽度、补网间隔和己方航空净空，必须与外层火力共同使用。

过境层云爆轰断波弹则试图在末端窗口内以现地成层替代逐架拦截。车载系统根据过境时间窗铺设覆盖低空高度带的可爆气溶胶层，待蜂群主体进入后同步触发，以体积效应破坏薄壳无人机并打散波次。它适合走廊收口、过境时间可判明的场景，能把后续点防御从承受全波改为处置少量残余；但海上风雨、气溶胶保持、同步起爆和再铺间隙均是决定性边界，不能在缺少试验数据时按概念效果直接定型。

撞线自付近防弹巢补足的是节点最后数十米的防护断点。弹巢无辐射、无人值守，只在目标真正朝节点实施末端撞击时自主触发，圈外巡飞和诱饵不消耗弹药，敌若要骗取火力就必须完成接近真实攻击的末端动作。它适合保护雷达、通信和火力节点的顶面及外缘，但材料尚未提供触发可靠性、覆盖密度和误伤控制依据，当前只能作为末端低成本补漏方向。

#### 2. 装备能力提升角度

上述装备的必要性不在于简单增加反无人机型号，而在于分别补上四类不可互相替代的断点：随浪伏击反蜂群弹解决海杂波下的静默预警与波级削峰；掠波连扫拦截机解决集中波前的持续截面消耗；驻空扫域电磁灭群巡飞弹解决未加固蜂群的区域性软杀伤；引浪吞波聚爆诱杀弹解决反辐射辨真链；迎面撒网捕蜂拦截弹解决受地形约束走廊的无源封段；过境层云爆轰断波弹解决末端过境时间片的体积清算；撞线自付近防弹巢则把漏网目标挡在节点毁伤门槛之外。

能力建设应按各自制胜机理设置验证口径，而不能统一采用“探测距离、拦截数量、命中率”评价。前两型重点检验波级判明、截面覆盖、再出动率和末端残余；电磁巡飞弹重点检验有效能注、覆盖连续性、驻留生存和对己兼容；诱杀弹重点检验真假源不可辨度、敌弹群收拢率及真节点静默存活时间；网弹和云爆轰装备重点检验走廊覆盖、成网或成层保持、时间对齐和风场适应；近防弹巢则应验证真实撞击触发与诱饵不误触发的区分能力。当前公开材料没有提供这些装备的实测数据、成本和产能，相关判断应保留为需求方向，不能转写成既成战果。

#### 3. 领域占位角度

建设这些装备可使反蜂群领域从“末端拦截弹数量竞争”转向“改变敌方突防几何、时间和成本结算单位”的装备竞争。其意义不是替代现有雷达、防空和电子战，而是形成水下预置、走廊封段、区域清算、节点诱杀和末端自守等不同作用界面，减少所有威胁同时压向单一拦截通道的风险。外军公开战略已将低成本规模化反无人系统列为关键设施和部队集结点防护方向，但跨域指挥、数据融合和互操作仍存在治理缺口，说明装备本体创新必须与可降级、低依赖的作战使用方式同步推进。

#### 4. 综合效益

综合看，建设重点应优先放在随浪伏击反蜂群弹、掠波连扫拦截机和驻空扫域电磁灭群巡飞弹，先形成对贴海集中波、集中波前和未加固蜂群的分层降耗能力，再以迎面撒网捕蜂拦截弹、引浪吞波聚爆诱杀弹和过境层云爆轰断波弹开展限定场景验证，撞线自付近防弹巢作为节点末端补漏方向。取舍依据不是概念新颖程度，而是能否在真实海况、敌方反适应和通信受限条件下稳定改变直接战果；凡仍依赖昂贵弹药逐架交换、缺少明确降耗环节或无法通过压力试验验证的方案，不宜作为独立建设主线。
