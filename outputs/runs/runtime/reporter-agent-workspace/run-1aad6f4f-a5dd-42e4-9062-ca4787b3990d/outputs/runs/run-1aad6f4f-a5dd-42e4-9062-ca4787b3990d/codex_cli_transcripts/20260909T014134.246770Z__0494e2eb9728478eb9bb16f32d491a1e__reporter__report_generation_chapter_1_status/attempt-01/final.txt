（二）国内外现状

#### 1. 国外情况

美国公开资料显示，国外反无人系统建设已从单一拦截装备转向“探测识别、主动与被动防护、低成本规模化供给”并行推进。美国国防部2024年《反无人系统战略》把小型无人系统的大规模、自主化、联网化和蜂群化列为持续加剧的威胁，并明确要求提高探测能力、发展主动和被动防护、降低反制成本失衡、以更快速度和更大规模提供开放模块化方案；“联合反小型无人机办公室”和“Replicator 2”则是公开可确认的组织与建设抓手。这说明国外公开能力事实已经覆盖类别、任务方向和建设机制，但所给材料没有提供与本项目六类装备一一对应的公开型号、单次成本、覆盖率或波次毁伤参数，不能据此断言其已装备随浪伏击反蜂群弹、掠波连扫拦截机等同类本体。

国外现状的另一特点是，装备效果越来越依赖跨域数据和交战管理。美国政府问责局2025年报告确认，美国国防部正在推进跨域数据共享、目标持续跟踪和联合火力网络，但尚未形成足以统一投资和衡量进度的完整框架，数据分类、接口互操作和各军兵种分散建设仍是实际障碍。对本项目而言，这一事实只支持“波级预警、节点防护和末端补漏需要接口协同”的类别判断，不能把软件融合能力冒充装备本体能力。由此看，随浪伏击反蜂群弹的国外对照重点是低空海杂波下的预置探测与水下伏击，公开证据尚不足以证明已有按波清账装备；掠波连扫拦截机对应的是反饱和和低边际成本方向，但缺少按“趟—截面”结算的公开参数；驻空扫域电磁灭群巡飞弹与引浪吞波聚爆诱杀弹分别对应区域电磁防护、诱饵反制两类方向，公开战略只确认任务需求，不确认其弹载功率、诱饵逼真度或成批毁伤效果。迎面撒网捕蜂拦截弹和过境层云爆轰断波弹则更依赖低空走廊、风场和成层条件，现有国外材料没有提供可直接移植的工程案例。

#### 2. 国内现状（中国）

本次移交材料未提供中国公开装备型号、部队部署、实战案例或可复核试验数据，因此不能把国内现状写成“已有装备成熟”或“完全空白”。能够成立的判断是：围绕第一岛链低空、海空混合蜂群和固定节点防护，现有公开证据尚不足以证明中国已形成与上述六类装备对应的专用能力链，也不足以给出探测概率、单次交换成本、覆盖面积、再装填节奏和抗干扰阈值等参数。

从装备选择角度，六类方向的国内差距并不相同。随浪伏击反蜂群弹首先缺海区水声背景、坐底值守寿命和过顶识别样本；掠波连扫拦截机缺平台重复出动、刃带展宽和单位时间趟次数据；驻空扫域电磁灭群巡飞弹缺弹载能源、有效作用距离和对不同无人机抗扰阈值实测；引浪吞波聚爆诱杀弹缺真假源逼真度、真节点静默纪律和敌弹收拢率证据；迎面撒网捕蜂拦截弹缺风场下成网概率、有效在位时间及走廊净通过率；过境层云爆轰断波弹则缺开放海面气溶胶保持、同步起爆和己方航行安全数据。上述缺口决定这些概念目前应按不同成熟度分别研判，不能用统一“反无人系统”口号替代装备结论。

#### 3. 对比小结

国外公开事实的优势在于已把无人系统威胁、规模化反制、主动与被动防护以及成本失衡纳入正式战略，并暴露出跨域治理和接口协同仍未完全解决；中国侧当前可核实材料不足，无法证明同类装备的公开部署水平。因而本项目的比较结论不是简单判断谁“先进”，而是明确六类装备各自改变交换关系的条件：随浪伏击反蜂群弹依赖贴海密集过顶，掠波连扫拦截机依赖可扫波前，驻空扫域电磁灭群巡飞弹依赖未加固目标，引浪吞波聚爆诱杀弹依赖反辐射收敛，迎面撒网捕蜂拦截弹依赖窄带低空走廊，过境层云爆轰断波弹依赖可判定时间窗和稳定成层。现有公开材料只能支持这些任务机理和验证边界，不能把概念优势直接等同于现役成熟度。
