五、研制基础

（一）参与单位

承研与配套单位的选取应由装备机理而非通用“总体—分系统”目录决定：感知、时机判明与毁伤合并在哪个物理域，承制类型就落在哪个域。公开资料不足以点名具体单位，本目只列机构类型及其应承担的产品、试验与证据责任。

水下域随浪伏击反蜂群弹把接敌界面压到静默水声段，牵头责任在潜藏式水中兵器单位，负浮力坐底筒、长期自持待机、被动声阵唤醒与垂直穿浪属其产品责任；过顶声包络判明须由水声试验机构在浅海混响与风浪本底噪声下交付漏判/虚警率及判明到起爆的时延覆盖率；竖向破片杆幕由含能材料单位承接。现缺海区水声背景与敌典型贴海队形声样本实测，声学辨真门限无法定标。

电磁域两型参与方并不相同：驻空扫域电磁灭群巡飞弹按驻留时段结算，主承制类型是弹载宽频高功率微波源与天线、巡飞平台及发电热控单位，电磁效应试验机构须以器件耦合试验建立失能概率统计，交付弹载条件下有效作用距离与重复频率实测值；引浪吞波聚爆诱杀弹的关键在诱源逼真度与收拢起爆，须由电子对抗辐射源单位按真节点辐射规律成组复现、引信单位判定弹群收拢并组织同步起爆，敌分选算法与收拢弹道包线未知，直接决定两型配弹量与补充节奏。

机械与化学毁伤域三型：掠波连扫拦截机、迎面撒网捕蜂拦截弹由无人机/气球运输机平台单位承担占位、成串投送与刃带再装填，柔性高强材料单位交付可折叠网幕及自展保形；过境层云爆轰断波弹由含能材料、气雾化与多点同步起爆单位负责开阔海面成层。共同试验责任是在靶场按“趟—截面”标定单趟削截率、网幕展开概率与包裹率，在海上验证风漂湿度下的成层保持与起爆时序；单次出动成本、刃带与网材寿命等尚无数据，未取得前不宜指定承制对象。撞线自付近防弹巢画像最薄，仅能确认被动末端触发引信与阵位伪装两类承制类型，其产品与试验责任边界待画像补全。
