## 二、项目画像

### （三）体系贡献率分析

在沿海要地、岛礁阵地和舰队节点面对无人蜂群与防区外火力复合突袭时，体系失效通常不是某一枚拦截弹漏射，而是蜂群先以低小慢、多批次和诱饵目标污染发现与分类，再以数量压缩授权、处置和补充弹药的时间，最后为防区外火力创造稳定瞄准窗口。因此，装备贡献不能按“发现、干扰、拦截”简单相加，而应看其是否切断敌方连续行动，是否使后续波次无法重复利用同一突破口，以及是否把防御交换关系从逐架高价拦截改为敌方持续付出而我方仍能恢复作战。

承担低空首段探测的装备，核心价值不只是扩大搜索距离，而是在地海杂波、岛礁遮蔽和多目标交叠条件下，尽早形成可供处置的可信目标轨迹。它改变的是“敌蜂群先进入末端包线、我方才被动反应”的时间关系，使软杀伤、诱骗和硬杀伤获得连续准备窗口。其直接战果是降低漏过首波侦察型和巡飞型无人机的概率，并把后续攻击从突然袭击转为可分层处理。若探测结果只能给出模糊方位，不能稳定区分真目标、诱饵和杂波，或者更新速度跟不上蜂群分散、合并和变向，贡献会在分类环节迅速衰减；尤其当敌方利用低空掩护和多方向逼近时，单一高点传感器的覆盖缺口仍可能成为整个防护节点的突破口。现有底稿未提供具体探测装备型号、部署位置、典型蜂群规模及公开测试数据，因而不能据此宣称其探测概率或虚警水平已经满足作战要求。

电磁压制装备面对的主要矛盾，是敌蜂群依靠通信、中继、导航或遥控协同维持编队和攻击秩序，而我方若只能在目标进入近程后逐个摧毁，便会被迫承受不利的数量交换。有效的压制应使部分无人机失去协同、偏离航线、延迟攻击或无法把侦察结果稳定传回，从而削弱蜂群整体而非只影响单架飞行器。它的制胜增量在于用持续可调的能量和覆盖，提前消耗敌方协同质量，减少昂贵弹药的使用，并使防区外火力获得的目标信息难以转化为可靠命中。该贡献对敌方自主化程度高度敏感：预设航线、短时断链仍能执行任务或具备抗干扰导航的蜂群，可能只受有限延误；压制还可能暴露固定节点的电磁特征，诱使敌方优先攻击辐射源。因此，必须以不同自主等级、抗干扰方式和波次间隔检验其实际降效，而不能以“能干扰通信”替代作战结果。

诱饵与假目标装备改写的是敌方瞄准置信度。对于舰艇编队和固定要地，若敌方侦察链能够持续确认真实目标，末端防御即使命中率较高，也会被弹药规模拖入不利交换。具备足够物理逼真度、可在合适时间和位置布设的诱饵，能够把敌方观测、识别和导引资源引向无价值目标，迫使其消耗弹药、暴露攻击方向，或延迟对真实节点的打击。与单纯增加拦截通道相比，这类装备直接降低“被准确命中”的概率，保护的是关键功能和恢复时间。其失效边界在于敌方采用多源传感器交叉判别、末端自主识别，或攻击弹药不依赖持续通信；若假目标只改变外观而不能在距离、热特征、电磁特征和机动状态上形成可信差异，反而可能帮助敌方校准识别规则。现有材料没有给出诱饵逼真度、布设数量、持续时间及敌方识别手段，相关贡献只能作为待验证的条件性判断。

硬杀伤装备仍是处理无法被压制或欺骗目标的必要手段，但其体系价值取决于是否承担“不可替代的末端清除”，而不是继续作为所有目标的默认答案。对高速逼近、失控后仍具毁伤能力或具备自主抗干扰能力的无人机，及时击毁可以阻止直接命中；对已经被软杀伤降效、被诱饵分流或威胁等级较低的目标，若仍使用高价弹药逐架处置，则会迅速耗尽通道和库存，给下一波留下空窗。因而其贡献应按目标威胁等级、射击机会和单次交换成本衡量，并与波次持续时间及再装填能力相联系。敌方可通过廉价诱饵、编队分散和多方向同时突进迫使防御系统过度射击；若缺少可持续的低成本处置手段，硬杀伤的局部高成功率仍不能转化为要地在多波次攻击下的存续。

综合看，当前输入能够确认的制胜方向，是让敌方边际突防成本持续上升，同时避免我方在发现、授权和弹药消耗上先行失速：首段探测保证目标不再“突然出现”，软杀伤和诱饵削弱敌方协同与瞄准可信度，硬杀伤只处理必须立即消除的高危目标，点防御则负责填补漏网目标并维持关键通道。任何单件装备若不能说明自身在这条链上的不可替代作用，或者仍依赖昂贵弹药逐架拦截而没有降耗环节，其体系贡献都不足以支撑项目成立。由于尚未提供通过质量门的逐装备能力画像，本栏不能进一步比较具体装备的贡献排序、成熟度和量化贡献率；后续判断至少需要补齐各装备的实际基线、覆盖或处置边界、典型波次工况、敌方自主与抗干扰条件，以及可公开复核的成本交换和恢复周期数据。
