二、项目画像

（三）体系贡献率分析

贴海低空波群的断点先在电磁域：海杂波与视界遮挡使雷达难以在波级尺度连续建链，末端只能按架换弹。随浪伏击反蜂群弹把接敌界面移入只收不发的水声域：坐底静默，以被动声阵判明波群必过顶的方位与时刻，垂直穿浪后在波群最密处起爆，用覆盖整个掠海层的破片杆幕按波清账。相对“持续探测＋按架拦截”的现役基线，其增量是末端到达数量与时刻被预减并判明，外层火力不必等雷达建链；敌规避只剩爬升现形与突袭前清海暴露两路。声学本底与待机可靠性决定触发可信度，走高/中空或绕开走廊即失效。

走廊段失效在“拦截弹—机”逐发交换：成本被波内真假数量线性放大。掠波连扫拦截机把最小打击单元改为“波前截面”，以展宽破片刃带反复掠穿，一趟削去整段编队截面，成本只随自身出动结算，截面内真假与架数不进我方成本函数；敌加密单波压不动单价，而其整链按时到齐计划遭无法分摊的截面损失，只能超量投保，拉稀减速又拉长走廊暴露、累积被扫趟次。敌拆散波前、改多方位小群异步渗透时截面消失，退回逐群交换。

现役处置走廊密集过境靠感知识别加单发弹药，强对抗下链路先断、弹按架耗。迎面撒网捕蜂拦截弹改为按段布幕的机械清道：无源网幕不辐射、不爆炸，干扰、诱饵与隐身没有作用对象，捕获率随敌密度增大而提高，每起一网即成可对账的清点事件，饱和峰在到达末端前被逐段拆散。增量是不受电磁条件制约、可点收核销的闸门层；走廊不收敛为可预置窄带、敌高空过境或补网不及波次间隔时，须由远程火力先把敌逼回可覆盖几何。

末端走廊饱和根因是点防御通道按目标数并行，蜂群并发超通道即漏。过境层云爆轰断波弹不逐发加弹，而在走廊段铺出覆盖整层高度、绵延数公里的可爆气溶胶层，整层同步过境即体爆轰，计价由“架次”改为“过境时间切片”，最高并发被压缩成单个爆轰事件，精确弹只补漏、不摊峰，诱饵试触只耗敌自身波次。风漂、湿度沉降散层、判窗误差或敌越层绕行时，退回低贡献固定栅栏。

节点账本崩坏的根源是单次拦截成本远高于敌单机成本。驻空扫域电磁灭群巡飞弹驻留节点上空，向来袭必经空域反复施加宽频高功率微波，凡未逐架加固的飞控、电调与数据链进入覆盖域即停摆，消耗按驻留时段而非来袭架数结算，单位来袭架边际成本趋零；疏散、变速绕不开体积场，屏蔽加固线性抬价增重缩程，击落高悬弹体反逼敌以昂贵弹药换我一次性消耗品。目标整体屏蔽或高抗扰时须硬杀伤接续，驻留体被清除且无补位时体积结算退化。

反辐射蜂群按先诱耗、再压制、后送载荷打高价值节点，现役真源开机硬防加末端弹量恰在数量饱和处失效。引浪吞波聚爆诱杀弹成组贴设于全程静默的真节点旁并仿形辐射，敌辨真的物理实现只能是整批弹药向诱源收拢，收拢瞬间温压破片整簇起爆，单波有效打击量由敌自愿承担的辨真损耗决定，数量优势逐次抵扣为目标确认代价，节点引导与反击链路得以连续运转。敌改预编程、光学、卫星直击或单机试探时，退化为普通诱饵消耗。

末段断点在识别授权时延与诱饵放空火力。撞线自付近防弹巢无辐射、不识别、无人值守，仅以真正朝节点撞击的末端航段为触发，最近弹巢在数十米内先敌起爆；诱饵须付接近真弹的撞击成本才能骗走一枚，弹药只随真实末端进入次数增长，防御寿命与敌诱饵总量脱钩。触发虚警率与净空判据尚无试验数据，贡献只能定性确认，大装药直撞仍须外层硬杀伤分担。

合观七型：水下预置、走廊截面、机械闸门、末端体爆轰、节点驻空、真假节点与撞线末防，各自改写数量饱和成本方程的一个环节，失效边界相互错开，单层被绕过不使整链崩塌。
