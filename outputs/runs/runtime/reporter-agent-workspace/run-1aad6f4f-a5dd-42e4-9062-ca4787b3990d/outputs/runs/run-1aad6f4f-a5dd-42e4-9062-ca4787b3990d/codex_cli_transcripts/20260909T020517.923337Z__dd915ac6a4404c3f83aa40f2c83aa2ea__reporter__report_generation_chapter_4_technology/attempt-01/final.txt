## 四、关键技术

### （一）关键技术清单与攻关途径

第一岛链沿海要地、岛礁和舰艇编队面对的不是单一无人机目标，而是低成本侦察型、巡飞型和自杀型无人系统与防区外火力叠加形成的多波次饱和突防。其制胜机理在于以低价目标制造高价拦截消耗，并通过持续侦察、通信中继和末端导引把防御节点逐步暴露、压制和击穿。因此，技术攻关不宜按“探测、干扰、拦截、指挥”平均铺开，而应围绕首检测是否可信、敌瞄准链能否被破坏、末端处置能否承受多波次三个决定性断点收敛。

| 装备方向 | 决定成立的技术断点 | 攻关途径与验证判据 |
|---|---|---|
| 沿海低空多目标连续探测装备 | 在地海杂波、低空遮蔽和目标尺寸小、速度低、数量多的条件下，能否保持连续发现、分类和轨迹可信。若首批目标漏检或把诱饵、鸟类、海杂波误判为真实威胁，后续授权、软杀伤和拦截均会失去时间窗口。 | 以典型小型目标、诱饵目标和混合波次构造可重复试验，重点比较不同探测机理在低空盲区、海面反射和目标密集条件下的探测概率、虚警水平、轨迹保持时间和分类可信度。不能只证明“看见过目标”，必须证明探测结果足以支持交战动作；现有材料未提供我方部署高度、覆盖间隙和目标规模等变量，不能预先给出统一点值。 |
| 蜂群瞄准链压制与欺骗装备 | 敌蜂群一旦形成稳定侦察、定位、通信中继和末端导引，单纯增加拦截弹药就会进入不利交换。装备必须通过自身的发射、辐射或假目标布设能力，破坏敌方观测一致性、协同关系或目标指向，使弹药转向无效目标，或使蜂群在进入末端前失去任务质量。 | 重点突破复杂电磁环境下的有效作用距离、方向覆盖、快速换频换波形、抗压制和作用效果确认。试验不能只测“信号压过信号”，应观察敌蜂群队形、航迹、任务分配和导引结果是否发生可重复变化。对具备链路依赖的蜂群，可将通信中继和侦察节点作为优先作用对象；对采用自主导航、视觉识别或惯性飞行的目标，必须单独测定其受影响程度。若无法使全自主目标偏离任务、失去协同或降低命中质量，该装备只能承担局部降效，不能被表述为普遍反蜂群手段。 |
| 低消耗多目标末端处置装备 | 末端防御的核心不是单次命中率，而是在数轮目标连续进入时保持足够通道数、弹药储备和快速再装填能力。仍依赖高成本弹药逐架拦截、且没有低消耗处置环节的方案，在蜂群规模扩大后会先于被保护目标失效。 | 围绕目标分级、近程快速处置、连续射击和再装填展开攻关，比较单次处置成本、单位时间可处理目标数、同时交战数量、误射约束和波次后的恢复时间。验证应采用“诱饵先导、混合目标、间隔不规则、后续波次紧接到达”的压力条件，记录防御是否因弹药耗尽、通道占用或确认滞后出现局部穿透。没有公开的我方弹药库存、再装填时间和敌方波次规模，当前只能把成本交换曲线和持续作战门限列为待测变量，不能以虚构单价证明经济性。 |

对首类装备而言，最难的不是增加单个传感器的最大作用距离，而是在复杂背景中把“目标存在”转化为可供交战的稳定轨迹。低空目标的物理特征、海面反射和阵地周边障碍会共同压缩可用时间；探测设备若只在开阔背景下达到较好效果，进入岛礁背风面、港区建筑和舰艇编队附近就可能失去连续性。攻关应先建立海杂波、低空遮蔽和混合目标的统一试验条件，再筛选能够独立承担首检测和持续跟踪的设备体制。跨源融合、指控软件和链路互操作只能作为接口条件，不能替代探测设备自身的物理覆盖能力。

压制与欺骗装备的技术路线应从“让目标暂时失联”转向“让敌方无法形成可信瞄准”。蜂群可能采用多节点中继、分布式协同和抗干扰通信，单点压制未必能改变整体任务；而固定节点持续辐射又可能暴露我方阵地，为防区外火力提供反向定位依据。因此，设备需要在有效作用、低暴露、快速转移和效果确认之间取得平衡。验证时应把敌方反适应纳入同一场景：改变通信频段、减少链路依赖、切换领机或改用自主航迹后，敌方是否仍能完成侦察、分配和攻击，决定软杀伤命题的有效边界。现有交接材料没有给出敌蜂群自主化程度和抗干扰水平，这两项事实必须在后续试验或情报材料中补齐。

末端处置装备的突破重点是改变成本和时间关系，而不是追求对所有目标采用同一种杀伤方式。侦察机、诱饵机、巡飞弹和携弹无人机对被保护目标的威胁不同，若不区分优先级，就会把有限通道和弹药消耗在低价值目标上。装备应具备适应混合波次的快速选择和连续处置能力，并能在一次攻击后确认目标是否真正失效，避免重复攻击同一目标或把已失效目标继续占用火力通道。只有在压力试验中证明多波次后仍能保留关键功能、完成补给并恢复防护，才具备作为固定要地或舰艇节点末端防御装备建设的依据。

建设顺序上，应优先解决低空首检测和分类可信问题，其次验证瞄准链压制能否产生可确认的直接效果，最后以多波次压力试验检验末端装备的成本交换和恢复能力。美国国防部《反无人系统战略》已把探测、主动与被动防御、降低反制成本失衡和扩大真实试验列为重点，但美国政府问责局《防务指挥与控制》报告同时显示，跨域数据整合、互操作和治理仍存在缺口。由此可见，不能把扩大系统集成范围当作缩短决策时间的充分条件；若集成增加数据转换和授权环节，反而可能延长处置时延。项目验收应最终落到装备本体能否在规定威胁和工况下可靠发现、有效降效、低耗处置并连续恢复，而不是落到平台接入数量或软件功能数量。
