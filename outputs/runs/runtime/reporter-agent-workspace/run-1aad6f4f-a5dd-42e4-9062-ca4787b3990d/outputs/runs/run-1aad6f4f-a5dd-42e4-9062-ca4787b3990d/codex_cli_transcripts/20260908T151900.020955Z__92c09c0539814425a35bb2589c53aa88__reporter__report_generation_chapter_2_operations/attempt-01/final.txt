**（二）作战运用模式**

**1. 作战运用流程**

随浪伏击反蜂群弹的进入条件，是敌为借海杂波与视界遮挡掩护航渡而锁死“贴海、密集、过顶”这一固定几何，且浅近海走廊的水深底质容许坐底；故平时即完成标定布设，战斗阶段不依赖任何常开链路。决定性动作是被动水声阵把探测对象收窄为“波”这一声学事件，判明过顶方位、规模与时刻后垂直穿浪，在波群最密处自下而上起爆，以覆盖整个掠海层的破片杆幕把全波同时送进近炸半径。制胜机理在于毁伤判据由“截获单架”换成“波次必经的空间与时刻”，电子干扰取消不了这一水下接敌界面。直接战果是每波入末段前被削峰，残余数量与到达时刻由我方设伏节奏预先给出并同步远程火力；敌规避只有爬升现形或每波先付反潜清海成本，突袭节奏被清海作业时间窗锁死。弹一次性使用、战中无法补投，流程终止于本波弹药耗尽，折损后的残余移交外层清账。

掠波连扫拦截机进入的条件，是走廊约束使敌形成可占位的集中波前，体系只以波级粒度上报到达方位、时间窗与截面宽度，不建单机航迹。值班机侧向预置后反复掠穿波前平面，横向展宽的破片刃带每趟按整段截面结算，真弹与诱饵等价清削。单趟成本随自身出动固定，敌加密单波、加码总波数、堆叠诱饵都进不了我方成本函数；而敌计划只在整链按时到齐时兑现，面对不可预知又无法分摊的截面损失只能超量投保，拉稀减速又拉长暴露、耗尽航渡预算。直接战果是把到达速率压至预算以下并把波前削薄到末端防御可承受密度；趟次可再生，流程终止条件不是弹尽而是出动节奏跟不上波前节拍。

驻空扫域电磁灭群巡飞弹以预警判性为入口：判定来袭群以未加固消耗品编成为主、主扇区与到达时序可判，才在暴露窗前发射占位。弹驻留节点上空后向来袭必经空域反复发射宽频高功率微波，消耗按驻留时段与覆盖域结算，值班员只判波次是否失能、覆盖是否连续，不逐架报伤。宽频脉冲经前门与后门耦合越过闩锁、烧毁或复位阈值后，飞控、电调与数据链停摆，疏散、变速、混编都不改变单位暴露剂量。直接战果是单次驻留可连续清算多个波次，节点在防护时段保持电子可用；敌恢复以量压防须逐架屏蔽加固，线性抬价增重缩程，或以昂贵防区外火力打高悬弹体，交换率反转。弹到限即离场，预备弹接力维持覆盖。

引浪吞波聚爆诱杀弹的进入条件，是真节点遭反辐射引导蜂群攻击且具备贴设与静默纪律，对抗窗口在分钟级波次间隙。决定性动作是成组诱爆弹仿形真节点的载频、扫描节律与功率起伏并主动辐射，真节点全程静默，迫使敌整批弹药为辨真向诱饵收拢，弹在收拢瞬间以温压破片整簇起爆。机理在于辨真的物理实现必然是向某源收敛弹道，收拢即空间聚集、末段机动受限，恰落入清算包线；敌“先诱耗、再压制、后送载荷”的规划每轮先送掉一批已收拢弹药。直接战果是数量优势逐次抵扣为目标确认代价，真节点不暴露不中弹；诱饵组按在位率于波次间隙轮换补充。

迎面撒网捕蜂拦截弹的进入条件，是敌为避免远程雷达点名而低空密集过境，走廊几何把航线收成可按入口预置的窄带；流程以定带为起点，沿走廊切段预置网弹串。决定性动作是依风场在来波前沿成串投弹，网弹迎风自展为纯机械网幕横张走廊断面，整簇前排被缠裹失速坠落，一网即一笔可点数取证事件。制胜机理是网丝与机体间的力学接触不依赖辐射、制导与引信，干扰、诱饵与隐身没有作用对象；敌爬升即现形、拉散即自拆饱和、逐架加破网装置即抬价挤载荷。直接战果是末端饱和峰被拆成可核销漏流，段通过率与入口计数逐段对账，由漏网数决定下一波补网密度。

过境层云爆轰断波弹要求末端走廊几何收口且探测能提前判明过境时间窗，两者同时成立才组织车载平台前出。决定性动作是铺出覆盖整层高度、横向延绵数公里的可爆气溶胶层并维持浓度边界，判明波次主体整体入层后同步触发体爆轰，把“逐个命中概率”换成“层内体积覆盖率”。薄壳机体在超压、火球与卷吸下成批解体坠海，破队单机不再构成饱和；敌只能弃窗改期或拉长分散航渡，先遣诱饵试触只耗其自身波次。直接战果是以每窗固定布设成本吸收最高并发段，稀缺精确弹只补漏不摊峰；层为单次属性，两次成层之间的再铺间隙是敌以小波试探的窗口。

撞线自付近防弹巢的进入条件，是目标做出真正朝节点撞击的末端航段动作，此前圈外巡飞、过航与干扰诱饵一律不触发。决定性动作是最近弹巢在数十米距离上迎面起爆，先敌引爆战斗部或击毁机体；无辐射、无人值守、不做目标识别。机理是用末端撞击事实替代识别判据，诱饵要骗取一枚必须付出接近真弹的末端动作成本，假目标放空火力的账不再成立。直接战果是防御弹药只随真实突防次数增长，节点外缘形成不受电子压制与指挥链路中断影响的最后一道自主保险。

**2. 链路闭环分析**

各装备的链路闭合位置决定其把断点补在哪一段。随浪伏击弹把“远距发现—逐架跟踪”压缩为水下判明加一次起爆，闭环在弹内完成、不经岸基回传，敌压制指挥所也取消不了这一拍；但整线一次性且战果只能由走廊后端哨位核实，敌绕开预置走廊或先期清海即失位，须远程火力接管。掠波连扫拦截机的闭环依赖波级预警不被诱骗、占位不被驱逐两个外部输入，敌以大诱饵波前诱使空扫耗趟是最现实的反制；波前一旦拆散为多方位小群异步到达，截面判据退化，逐群清剿转交末端硬杀伤。驻空电磁弹的闭合边界在“到达能注—目标抗扰阈值”，整体加固或高抗扰目标须动能接续；强辐射本身即信标，敌借无源测向在停照间隙打击驻留体是此链最需防范的失效通道。诱爆弹的闭环条件最苛刻：真节点静默须管住备份设备与后勤电磁泄漏，敌改预编程、光学慢速确认或先期清扫时收拢条件不出现，机制降为普通诱饵。撒网与云爆都靠走廊几何闭合，前者以入口预测和网幕在位为链节，落网计数滞后会掩护敌在补网间隙试探破口；后者断点在判窗、成层保持与公里级同步起爆，风、雨、海况直接决定层段是否成立，二者均留末端硬杀伤收口。弹巢闭环最局部也最可靠，触发判据即撞击航段本身，位于链路末端，兜住其余各层漏过的真实突防。这些手段能否进入编成，取决于各自未经验证的环节——浅海被动判明虚警率与坐底寿命、刃带展宽与再生周期、弹载宽频微波有效作用距离、诱源辐射一致性、网幕展开概率、开放大气成层保持性、近距引信对真撞击动作的判别——须以对抗性靶试逐项闭合后，再按各自失效边界确定布设密度与层间接续。
