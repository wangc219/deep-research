第三层：能力图像与效能贡献层

⑨ 发展优先级与近期抓手

俄乌战例向装备需求迁移的核心，是反无人作战的交换关系失衡：逐架拦截廉价机，单发成本高于敌单机，打掉一架也拦不住下一架，阵地就在小额渗透与集中波次中持续失血。入选装备都以改写这一交换为方向，改写点分三类：打断再生产的地面根节点、把拦截变成穿越的通行税、把整波一次清零。优先序的判据即在于此——能否打断再生产而不只增加单次成本，能否同时覆盖小额高频与波次饱和两种节奏，敌方反适应代价与工程不确定性如何。据此全序为：循源反辐射巡飞弹（高）、锁律悬雷栅栏反无人机弹（高）、一发抵整波微波拦截弹（中）、蚀翼尘暴反无人机弹（中）、弥空垂帘反无人机弹（中）、染空弥雾电绞拦截弹（低）、断窥高功率微波反察弹（低）。

循源反辐射巡飞弹列第一并作近期先导，理由在打击对象而不在弹体：机组、发射阵地与回收点是敌出动循环中重建最慢的环节，一套地面单元补充以周计，再造一架廉价机不过数日。敌每次出动都要短暂开链，小额渗透由无代价放血变为每次暴露一组地面单元的期望损失；大波次又把众多发射与控制源叠成单一电磁簇，一次寻获即可端掉成批出动能力。近期不应先堆测向精度，而应把现役信号侦察的频率库、网系特征与阵地散布规律接成“截获—分类—测向—抗关机跟踪—放弃复巡”的端到端任务链，以真实辐射源对抗试验标定主源与诱饵判别率和民用电台误伤边界。敌最省钱的反制是压缩开窗、间歇出动、拉开控制与发射距离，却都落在每次出动的尺度上并抬高准备成本，无法一次改型抹平，这是高优先的根本。

锁律悬雷栅栏反无人机弹为第二骨干。它把拦截对象从单机换成敌方惯用走廊：节点零辐射、免逐架判定，小额穿越每次都要付不确定损失，硬闯大波次则多节点同时触发；敌清栅需专用手段，耗时耗弹且追不上补撒，抽调兵力清栅反而把清栅集群送进常规火力覆盖。近期投入集中在无动力节点能否在走廊断面驻留并靠周期补撒维持密度、被动声光唤醒在风雨鸟群下误醒率能否压得住两项，漂移空档与虚警水平决定栅栏从概念到能力的分界，也是敌绕行或清栅后我方仍能按走廊流量重排补撒的前提。

一发抵整波微波拦截弹对应波次饱和这一端：单发在波前空爆，宽谱高功率微波成片烧毁普遍省略屏蔽加固的量产机，拦截成本与波内架数解耦，敌每加一架只放大自身整批损失，逐机屏蔽则抬价压产量，数量换突防的账本被抽空。它不与循源争近期资源，因弹载微波源须从持续供电的平台体制压缩为单次放电的战斗部体制，属原理突破级。当下动作是把“储能—脉冲压缩—宽谱辐射体”单脉冲链做成样机并做电子目标效应试验，把炸点误差、机群散布与覆盖裕度合成爆点决策模型，先证弹径约束下能否批量复现单脉冲源，再谈型号进度。

蚀翼尘暴反无人机弹在中档中回报最特殊：战果不是当场击落，而是延迟故障加返场暴露——带示踪尘的机体返场即交出发射与回收区坐标，正好为循源和反炮兵提供带标记的瞄准提示，把走廊课税接回根节点猎杀。代价是它依赖吸入剂量、风场构型与示踪检出信噪三重耦合，逆风强湍流下滞留与覆盖被压缩，可能退化为瞬时烟障。现阶段动作是先做“吸入—延迟失效概率”与示踪检出试验，以实机穿越标定剂量和失效分布，界定可用气象窗口，再谈布势。

弥空垂帘反无人机弹与锁律同属占域，取舍轴不同：锁律以低成本周期补撒维持长期驻留，弥空以单发在可预测出动窗口内把走廊封成分钟级死段；丝幕低可探测，收割量随编队密度上升，敌散开慢放丢时效，密集突入自投绞杀。当务之急是丝材“细、强、隐”三性和开舱抛撒成网两项验证，用单发封路时长与密度—收割曲线判明窗口化封路是否成立，再与锁律比选。

染空弥雾电绞拦截弹殿后：导电绒雾须把缠绞、桥接短路与静电铺展收进同一批纤维，染空段对友邻电力、低空活动与人员的安全边界最难界定，效果又与锁律、弥空重叠。近期只保留纤维长度分级混配与电荷加载的材料级试验，待占域骨干定型后按缺口决定去留。

断窥高功率微波反察弹排末位不是任务价值低——观侦机群成片中断，敌方纵深火力失去分钟级校射，己方再装填与集结才拿到可计算窗口——而是它需与一发抵整波共用弹载高功率微波源，且敌观侦以接力、间歇覆盖维持看护，单发成片收割的机会窗比整波来袭更难捕捉。近期不单独立项，待该源技术成熟后以换装引信与爆点决策逻辑的方式延伸应用，随源攻关进度递进。

收束两点。其一，俄乌双方月损耗量、再生产速率、电子战致效量与分层反无人战果占比尚无统一口径，本排序只约束投入顺序与近期抓手，不绑定型号级参数承诺，公开证据不足处保留区间与置信度。其二，走廊占域不四案齐建：以锁律为骨干，蚀翼与弥空按试验结果二选一，染空殿后，反察功能并入微波源延伸线；循源若以“削减敌可出动架次与地面单元重建能力”而非“拦截架数”为战果口径通过对抗试验，其定型列装即列为近期最高优先行动，其余装备围绕其接口与频段资源预留。
