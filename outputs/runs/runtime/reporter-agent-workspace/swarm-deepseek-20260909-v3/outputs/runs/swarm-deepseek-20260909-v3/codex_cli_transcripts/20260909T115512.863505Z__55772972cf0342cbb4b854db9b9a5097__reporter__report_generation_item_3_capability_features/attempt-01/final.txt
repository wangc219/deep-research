## 第一层：需求挖掘层——场景·战法/技术·装备能力特征

### ③ 装备能力特征清单

**“循源”反辐射巡飞弹。**俄乌战例中最顽固的循环是：敌方廉价侦察与打击机每次出动都要在分钟级至约半小时的开窗内维持控制与图传链路，而拦截只毁机不毁人，再放一架即续上循环。本弹把任务断点落在“开链即暴露”：静默值守中以宽带接收机无源截获链路帧，连续两个以上突发帧方向一致即判为源，沿测向线逼近并区分主源与诱饵，关机换频后转记忆跟踪，作用对象是操作组、发射阵地与回收点。判别性指标方向是复杂电磁环境下的链路截获率、源与诱饵区分概率、截获至命中耗时对机组转移周期的比速，以及多弹对同一电磁簇的分源处置；在缺少校准数据时，以敌方开窗时长、换频策略与诱饵密度为自变量保留，不生成点值。

**锁律悬雷栅栏反无人机弹。**小额高频渗透的威胁不在单架而在走廊：反复穿越把点防空拖入逐架兑耗，漏一架即免费通行。本弹把防御对象从单机换成走廊本身，炮射或筒射布撒零辐射充气球载微网雷节点并按周期补撒，节点被动声光唤醒、近距释网后破片自毁。其衡量轴应区别于拦截类装备：把“单次拦截概率”换成“单位时间通过折损率”。判别性指标方向是节点漂移包络是否压得住走廊断面、风雨鸟群等环境下的误醒率与近距释网包线、补撒速率对敌方清栅速度的压制关系，以及大波次硬闯时多节点同时触发形成的概率叠加；无动力驻留的随风漂移须由补撒周期兜底，两者关系先以工况变量表达。

**一发抵整波微波拦截弹。**数十至上百架整波冲击下，动能拦截费用随架数线性放大、火力通道被单架占用，是防空失守的直接断点。本弹以高功率微波战斗部在波前或上空空爆，宽谱脉冲整片覆盖低空小机空域，烧毁飞控与动力电子，使单批拦截成本成为不随波内架数变化的固定值。判别性指标方向是起爆点误差与边缘场强裕度的联合边界、单发有效覆盖对编队密度与散布的适用下限、裸机与局部加固机型混入时的拒打门限，以及对我方邻近电磁敏感区的安全边界。敌方以拆散波次和廉价局部加固反制，故装备须内建“密度判定—覆盖计算—拒打决策”闭环；未加固电子失效阈值无公开校准，相关场强一律以区间表述。

**蚀翼尘暴反无人机弹。**廉价穿越机返场可复用、单架损失不传染，是旧交换失效的根因。本弹将打击对象改为走廊内不可预排绕避的尘云：空爆释放磨蚀与示踪双效复合颗粒，随风漂移滞留，单架穿越即累积延迟故障并沾染示踪尘，返场被多光谱识别后反向暴露发射与回收区，火力终点由消耗单机转为压缩敌方可用出动量。判别性指标方向是磨蚀相与示踪相的粒径谱兼容与单位弹重磨蚀剂量、吸入剂量对延迟故障概率的换算关系、返场机体检出信噪比，以及空爆高度对实时风廓线的匹配窗口；粒径与弹重、悬浮寿命相互挤压，须在可吸入、可悬浮、可识别之间标定可行域，剂量数据未公开前只留工况关系。

**弥空垂帘反无人机弹。**敌方以密集编队压缩暴露时间换突防率，点拦截单发只覆盖一条点航路，机群拉开间隔即可摊薄火力。本弹以单发爆散数万根亚毫米级高强飘丝，形成低可探测、驻留数十秒至数分钟的大体积丝幕，把走廊整体占为不可清除的时间死段，收割量随编队密度上升并借失控机互撞放大。判别性指标方向是丝径、强度与可探测性三者的互斥取舍、成幕空洞率与密度均匀性、丝幕驻留时长对敌方出动窗口的覆盖，以及缠停概率随丝密度与穿越路径长度的关系；丝体无金属带来的不可预警性决定敌方只能拉大间隔放慢流速，专项扫丝不经济与滞空时长共同构成“窗口由我方管理”的成立条件，相关拦截体积与单丝成本约束待试验校准。

**染空弥雾电绞拦截弹。**“先探测识别、再逐架点杀”的旧链路在波群数分钟内涌入时反应不及，弹耗随架数累加。本弹不辨单机：空爆释放金属化超细纤维并加载同极电荷，借静电互斥与气流铺展成与低雾背景融合的绒雾，滞空覆盖走廊断面，穿过机群旋翼被缠绞停转、供电与飞控线路被桥接短路。判别性指标方向是电荷质量比与纤维细长形态共同决定的成雾铺展和悬浮窗口对整波穿越时长的覆盖、长卷纤维缠绞与细短纤维导电的分级混配，以及敌方加装滤网、涵道与线路屏蔽后的残余致效——加固代价摊回每架机体，廉价供给前提随之自毁；强风压缩滞空，须以风稳走廊与湿度窗口作为使用工况。

**断窥高功率微波反察弹。**敌方廉价观侦机以冗余机队钉在己方阵地与再装填点上空，逐架点杀一弹换一机，看护不中断，动作全被钉死。本弹抵近编队内侧近炸，以广域电磁脉冲成片烧毁未加固航电，把“一机一弹”改写为“一发毁一群”，直接战果是实时看护成片中断、远程火力失明减速，己方再装填与集结重获以分钟计的可计算窗口。判别性指标方向是编队散布与波束主瓣覆盖的选点解算、弹载储能与微波源在弹径约束下的单次频谱一致性，以及敌方恢复看护所需重新放飞—标定—接链周期对己方窗口启闭的比速；敌方逐架屏蔽加固或退至高空远距，分别以单机成本乘机队规模、校射精度下降偿付，故恢复周期本身应作为该弹效果度量。

共同的证据边界：俄乌公开战例以单机穿越机和中大型侦察打击为主，自主协同蜂群未见确证，以上能力均按“低成本可消耗单机加波次出动”迁移；各指标只到方向级，型号参数与损耗类指标须先校准双方月损耗量、再生产速率、电子战致效占比等口径，再升级为验收判据。
