第三层：能力图像与效能贡献层
⑦ 装备能力图像

俄乌战例的共同失衡是：廉价无人机反复出动，传统反无人火力按架逐发兑换，弹药与火力通道随敌架数线性放大，越拦越亏。下列装备各自以不同作用对象与毁伤机理改写这笔交换，能力图像按装备逐件给出。

“循源”反辐射巡飞弹的图像是猎杀地面根节点而非拦截空中目标：把反辐射寻的从雷达延伸到无人机控制与图传链路，静默值守中截获敌开链辐射、测向逼近并打击操作组、发射阵地与回收点，全程不主动照射。相对逐架拦截，交换由“一发高价弹对一架廉价机”翻转为“一枚值守弹对一组地面单元”：机组减员按周补充、远慢于再造一架机，敌可出动架次随之下降；波次集中时发射与控制源在时空上叠成电磁簇，一次寻获即可成批清除。边界在链路频率库依赖信号侦察积累、抗关机记忆跟踪落点取决于敌转移规律，均无公开定量口径，只能按区间判断。

锁律悬雷栅栏反无人机弹的图像是把走廊变成低空雷场：以炮射或筒射向敌惯用渗透线布撒零辐射气球微网雷节点并周期补撒，敌机贴近才被动唤醒、近距释网毁伤。它不追踪单机，而把单次穿越定价为带随机折损的通行税——小额渗透被逐次抽干，压成大波次硬闯则多节点同发、在可预测窗口内成片拦杀。谱系增量是把区域拒止从地面抬到低空走廊；敌清栅须专用手段且追不上补撒，绕行又拉长航线、落入其他伏击面，节奏主导权转入补撒一侧。节点低渗漏驻留与被动唤醒低虚警是成立边界，补撒速率与敌穿越流量的匹配在公开材料中无定量口径。

一发抵整波微波拦截弹的图像是单发空爆结束一个波次。谱系基线上它把高功率微波从持续供电的地面平台源压缩为弹载单次放电源，作用对象由单机换成前置弹道内的整批机群：弹于波前或上空起爆，宽谱脉冲经孔缝、线缆与天线耦合进未加固飞控与动力电子，整批同刻失控，单批拦截成本成为不随架数放大的固定值。敌为保产量省略屏蔽正是攻击面：逐机加固把单价抬到可与拦截弹相比、整波仍被抹除，数量换突防的账本整体反转；拆波拉距则拖长暴露时间窗。批次稀疏、混入屏蔽改型或有人机、邻近电磁敏感区时应拒打省弹。失效阈值场强与有效覆盖体积缺乏公开参数，保留区间判断。

蚀翼尘暴反无人机弹的判定轴不在当场击落，而在延迟故障与返场暴露：烟幕只能遮蔽、破片只能毁单机，它用空爆尘云对某时段通过走廊的全部航次施加风险剂量，尘云随风漂移、敌无法预排绕避。穿越机旋翼、进气道与光电载荷吸入微磨料后按剂量累积损伤，返场与下次出动之间才显现为概率故障；机体沾染可被多光谱识别的示踪尘，每次返场都交出回收点坐标，单机出击从此累积风险。大编队硬闯时尘浓度叠加，成批功率衰减失明并诱发队形自撞；绕飞则架次与暴露时长双增，小额与波次两种节奏同步劣化。敌方滤尘、包覆或返场清洗都压低出动频次、拉长整备周期，等于放弃数量优势。风场是其主要边界，剂量与故障概率的关系无公开定值。

弥空垂帘反无人机弹的单发价值随编队密度上升：相对网捕的单点小截面与数秒落地，它单发在走廊爆散数万根亚毫米高强丝，数十秒至数分钟内织成雷达与光学难察的滞空丝幕，把威胁空间扩展为立体禁飞域，在敌出动窗口上叠加不可清除的时间死段。单机穿越被随机缠毁只是单次抽税；敌攒成大波次压缩暴露窗口，收割量反而随密度陡增，缠停机与失控机互撞放大波内损失，波次密度由压制手段变成自损放大器。敌只能拉大间隔退回低效小额，丝体无金属、难预警也难清除。与蚀翼尘暴的分界在战果兑现时点：瞬时概率收割对剂量累积。解缠成形与丝材“细、强、隐、缠”互斥构成工程边界，定量拦截概率没有公开证据。

染空弥雾电绞拦截弹与弥空垂帘同属占域族，机理不同：金属化超细纤维以“缠绞加短路”双通道毁伤，诱发电荷使纤维同极互斥、随低空缓风铺展成与雾气背景融合的绒雾，封锁整段走廊断面，开战前无需判明任何目标。穿雾机群旋翼被缠停、裸露供电与飞控线路被桥接短路，成片坠地，单发否定整批，花费不随架数上升。敌方无法点状锁定雾体也无法绕避，恢复优势只能逐机加装涵道滤网与线路屏蔽，单机成本与产量同时恶化，“廉价可弃”前提先被自己放弃。边界在气象与静电：强风压缩滞空、湿度影响铺展，纤维尺度须匹配旋翼间距与线缆裸露状态，量化参数缺乏可核查证据。

断窥高功率微波反察弹清除的不是进袭波次，而是己方阵地与再装填点上空的观侦—校射闭环。敌方廉价多型观侦机高架次冗余盘旋，逐架点杀一发换一架、看护不断；本弹在编队深入、间距收拢的过顶窗口抵近并于编队内侧近炸，广域电磁脉冲成片烧毁未加固航电与数据链端机，把“以冗余摊薄单机损耗”改写为一发毁一群。直接战果不是击落数而是时间：校射成片中断、深打击失明减速，再装填与集结重获分钟级可计算窗口。敌重建看护须重新放飞、标定并接通链路，每轮都再暴露指挥节点；逐架屏蔽则单机成本乘上机队规模。判群选时与编队内炸点决策构成边界，量化口径同样缺乏公开支撑。
