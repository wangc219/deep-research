第二层：技术攻关层——能力实现途径与核心技术

⑤ 核心技术清单与攻关优先级

本栏不按技术门类罗列，只选取决定各弹成败的技术断点，写明其作用环节、物理与工程约束、成熟基础与瓶颈，再按对敌出动成本的破坏强度、反适应代价和工程不确定度排定攻关优先级（P1最高）；公开资料给不出边界值的参数一律保留区间与置信度。

“循源”反辐射巡飞弹决定成败的是两处弹上化。一是短开窗链路的被动截获与测向：敌以中段预编程减少开链、把控制与图传功率压向机侧，辐射暴露仅分钟级，宽带接收与干涉测向虽在地面侦察平台成熟，压进弹体后要在灵敏度、监听功耗与滞空供电之间取舍。二是抗关机记忆跟踪与诱饵、主源判别：敌感知临近即关机换频，弹须按消失前测向线与阵地散布推算攻击落点。两者闭合，敌每开一次链就新增一组地面单元的暴露期望损失，规避只能靠压缩自身效能或增加出动成本，定为P1，使反无人由“毁机”变为“清根”。

“锁律”悬雷栅栏的断点卡在入网与值守。炮射、筒射口径内须同装充气蒙皮、升力气源与唤醒电源，浮球漂移会偏出走廊，蒙皮渗漏又致节点沉降，要靠低渗漏蒙皮与压舱微调限制漂移、以周期补撒兜底；浮空平台、声光探测与网捕均是成熟门类，难在低成本口径内一次装定。值守段零辐射只能被动声光唤醒，风雨鸟群误触发使栅栏自耗，唤醒过迟又留不出释网时间，瓶颈在超低功耗判别、虚警抑制与释网时序，且节点无遥测，存活只能靠穿越事件反推。闭合后每次穿越都付随机折损，敌清栅耗时耗弹追不上补撒，列P2。

“一发抵整波”微波拦截弹的主线是把地面供电、大型器件的高功率微波源收成弹内一次性宽谱战斗部：储能经脉冲压缩单次放电，宽谱须覆盖多机型谐振敏感频段，但辐射效率受弹径压制，窄谱易被改频或简易屏蔽化解，单次源频谱还要能批量复现。爆炸磁通压缩、虚阴极振荡器有原理与试验基础，缺谱宽、峰值功率、弹径兼得的批量窗口。第二断点是炸点裕度：空爆偏差、机群散布与朝向差异压低边缘场强，引信起爆几何须与波束包络、功率裕度联合设计。单发成本与来袭架数解耦，但拆批错峰、廉价局部屏蔽能最快对冲，定P3，须抢在低成本机普遍加固前形成规模。

“蚀翼尘暴”反无人机弹先要把磨蚀与示踪装入同一粒径谱：颗粒越细越易被旋翼、进气道吸入并悬浮，单位弹重携带的磨蚀剂量却越少，须以空爆二次解聚的复合颗粒并靠吸入剂量、检出信噪模型反推装填比；烟幕播撒与多光谱识别成熟，复合颗粒弹种无公开先例。再要解决风场定爆：尘云受重力沉降与风致稀释控制，引信须按实时风廓线定高定时、多发沿走廊连成尘障，短临风场预报与定高不闭环，一次空爆即被吹散。机理使穿越机返场即暴露、自带延迟故障，但窗口依赖气象、战果滞后，列P4，先验证风场与粒径谱。

“弥空垂帘”反无人机弹的两对断点互锁。抛撒成形端：数万根亚毫米丝须按时序解缠、均匀覆盖走廊截面并驻留数十秒以上，成团或现空洞即被按概率穿透，重力沉降与风切变又使细丝聚成条带坠落；预制网弹截面小、落地快，散丝不成幕，须控丝长、卷曲度与解缠时序。丝材端：细到雷达光学难辨、强到缠停旋翼并能绕上桨毂，细强隐缠互相排斥，攻关落在丝体表面构型与缠绕行程；成幕密度阈值、驻留随风速的散布属公开证据不足的变量，须实弹试验给定。波次密度越大单发收割越高、失控机互撞放大波内伤亡，但工程不确定度高，定P5。

“染空弥雾电绞”拦截弹的前提是金属化纤维空爆成雾并滞空至整波穿过。金属纤维密度大，释出后或成团坠落、或漂移露隙，整波钻隙即失效，须在起爆瞬间以同极电荷互斥撑开绒雾、按低空风切变反推定高；金属化干扰丝投放是成熟门类，悬浮、缠绞、短路三效合一则无先例。第二断点是纤维性能互斥：缠绞要长卷抗拉，短路要镀层弯折中导电，滞空要细而轻，只能靠芯丝—镀层界面与长度分级混配平衡。单发染空即否定整段走廊、花费不随架数上升；但成雾可重复性与强风边界最窄，对涵道化、加滤网机型的覆盖率无公开数据，定P6，先做小样成雾与对抗加固试验。

“断窥”高功率微波反察弹与“一发抵整波”共用弹载一次性微波源攻关族，要求更高。源端须把初级储能、脉冲压缩与辐射器件装入战斗部并承受发射过载，爆炸磁通压缩加虚阴极振荡器路线电—微波转换效率低、单次频谱脉宽不稳，攻关目标是让化学能优先转电、转微波；弹道端多出群内选点近炸定向，须在秒级窗口内解算观侦编队散布与弹轴指向、同步天线朝向与源触发，传统定距引信给不了这一决策。它直接中断纵深校射闭环、为再装填与集结开出分钟级窗口，但源小型化、选点决策与单发成本均未闭合，且须以编队深入未散为发射前提，故定P7，作为技术族收敛后的衍生型号推进。

排序共用一条判据：越能直接抬高敌单次出动成本、反制代价越贵的越靠前，工程不确定度只调节同族内的先后。P1、P2以成熟门类集成为主，应先行形成规模；P3、P7共用一次性微波源，先经地面拒止试验标定谱宽、峰值功率与炸点裕度；P4至P6的云雾丝网族先完成风场、粒径谱与成幕试验，再转入型号研制。
