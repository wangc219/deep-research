## 第三层：能力图像与效能贡献层

### ⑧ 效能贡献评估

“循源”反辐射巡飞弹要解决的任务断点，是敌以纵深分散部署的廉价侦察与打击无人机反复出动，单架再放成本低于我方一次拦截，逐架打法只把火力通道耗在低价值目标上。它的效能贡献在于把交换对象从飞行中的单机换成开链作业的地面单元：弹体无源截获敌控制下行与图传上行并测向，沿链路逼近，把操作组、发射阵地与回收点纳入可打击坐标序列。小额渗透由此使每次放机都叠加一组地面单元被清除的期望损失，连续出动变成持续放血；集中波次时众多发射与控制源在时空上聚成单一电磁簇，一次寻获即可端掉成批出动能力，逐架拦截被整波处置取代。敌以压功率、跳频或断链应对，会自降侦察与末端攻击效能；设诱饵源又自添暴露点与成本。我方值守成本不随其架次线性增长，反无人机从应急拦截转为对敌机组与发射节点的按序清除，这是它对任务结果的核心贡献。

锁律悬雷栅栏反无人机弹回答的是走廊问题：地形遮蔽把渗透路径卡在少数低空通道，点拦截只能赌火力赶在一架落一架之前，漏过即免费通行。它把防御对象从单机换成走廊本身，以炮射或筒射向惯用通道布撒并周期补撒零辐射充气球载微网雷节点；节点被动声光唤醒、近距释网并破片自毁，每次穿越都成为带随机折损的通行税。小额高频渗透在一轮轮经过中被逐步抽干，点防空弹药与雷达开机时间不再被低值机兑掉；压成大波次硬闯则多节点集中于可预测时间窗内同时触发、成片拦杀。敌方清栅需要专用扫除手段，耗时耗弹且追不上补撒速率；绕行则航线拉长、暴露上升。走廊节奏的主导权由此落到我方补撒一侧，衡量其贡献的是敌出动率下降与绕行路线暴露，而非击落数字。

一发抵整波微波拦截弹改写的是拦截成本随架数放大的旧规则：廉价小机结成数十上百架波次压来，动能弹逐架拦截时单价与火力通道都随来袭数量加码。它把高功率微波源装入战斗部，单发在波前或上空空爆，以体效应同时覆盖整片编队空域，省略屏蔽加固的量产机飞控与动力电子成片失效，直接战果是单发清零一个波次，拦截花费成为不随架数变化的固定值。防空阵地以同样弹药基数可顶住更多波次，交战决策从逐架排序简化为波次间的火力重置，末端硬杀伤只补漏网。敌保裸机集群则整批折损，逐机加固则单价上升、产量收缩，以数量换制空的经济账反转；拆散编队虽压低单发收益，却拉长突防时间窗，暴露于雷达与逐点截击。此弹贡献能否兑现，取决于预警先行给出方向、密度与起爆时机。

蚀翼尘暴反无人机弹处理的不是某一架穿越机，而是敌方机体便宜、返场可复用、损失不传染的出动循环。弹在必经走廊空爆，形成随风漂移的磨蚀与示踪双效尘云：旋翼、进气道与光电载荷吸入微磨料，延迟故障成为概率事件；机体沾染的示踪尘又使返场机被多光谱识别，起飞与回收点坐标随即交给炮火与巡飞弹溯源打击。效能贡献分两段兑现：任务中失能终止部分渗透，返场暴露端掉出动源头。小额穿插因此每航次累积风险，大编队硬闯则尘浓度叠加、成批失能并诱发队形自撞，绕飞又增加架次与留空暴露。敌最经济的规避是等尘散或改道，但推迟波次丧失突袭窗口，绕行拉长暴露，只能转入更贵更慢的防护通道。它对体系的意义在于把反无人从消耗敌机延伸为压缩其可用出动量并暴露再补给节奏，一发起消耗、识别与引导三重作用。

弥空垂帘反无人机弹的贡献建立在时段预置上。敌方把出动压进少数关键窗口，沿走廊以疏密节奏冲线，逐架识别交战的点防空跟不上节奏伸缩。弹在预判窗口向走廊空域爆散数万根亚毫米高强飘丝，数十秒至数分钟内织成低可探测、窗口内不可清除的立体禁飞域，单发即把一个出动时段变成死段。单机穿越被随机缠毁是一次抽税，失控机在编队内反向撞击扩大伤亡；敌把小额攒成大波次压缩时间窗，反使单发收割量随编队密度陡增。防空由此从力争不漏转为按窗口控制通过率，末端点杀只补漏网，火力通道不再按目标数线性占用。敌拉大间隔、多点绕飞、随机时刻，代价是同时到达的突击密度消失，走廊节奏让渡给我方。其效能判据是窗口内通过率与单波投送量的下降。

染空弥雾电绞拦截弹的独特性在于交战前无需判明任何目标。面对窄走廊内整波涌入的廉价旋翼机，弹在断面空爆，释放的金属化超细纤维借气流与诱发电荷铺展成与低空雾气融为一体的绒雾，滞空覆盖整段走廊。穿雾机体旋翼被缠绞停转，裸露供电与飞控线路被桥接短路，成片坠地，单发染空即否定穿过该段的整批来袭，花费不随架数上升。守方反应链从等目标出现再逐架交战前移为先占空域、等敌来穿，雷达、炮兵与指挥节点不再被波次掏空，任务结果度量从累计击落数变为波次无法穿越。敌方对雾状散布体既不能点状锁定也无法绕避，反制回到成本端：逐机加装滤网与线路屏蔽使单价、重量上升而载重航程收缩，廉价可弃的供给前提先自毁。强风压缩滞空，故需择风稳走廊使用并装定爆高与弥散宽度。

断窥高功率微波反察弹的评估对象不是突防机群，而是为敌远程火力实时指路的廉价观侦机队。多型小型观侦机与侦察巡飞弹在己方再装填点、集结地上空高架次接力，与远程火炮构成分钟级闭合的发现—校射—毁伤链，点杀一架立即补位，坐标照常外送。弹以高功率微波战斗部抵近编队内侧近炸，广域脉冲成片烧毁未加固航电，把一机一弹改写为一发毁一群，实时看护成片中断、深打击失明减速，再装填与集结重获以分钟计的可计算行动窗口。敌恢复看护只有两条路：逐机屏蔽加固，单机成本乘上机队规模自我反噬；退至高空远距，牺牲校射精度、拉长火力闭环。每次重新放飞都再次暴露测控节点供猎杀，评估其效能应看行动窗口的可用概率与持续时间，而非击落数。

这些判断的共同点，是把反无人从与单机逐次交换改为对敌出动循环、走廊通过率或地面节点的体系性征税，但比较轴随机理而异——循源按地面单元暴露计数，微波类按覆盖体积与波次计价，悬雷栅栏、尘暴与垂帘按走廊时段征费，故不存在统一的贡献句。验证边界上，链路截获距离、节点驻留与补撒速率、微波储能密度与起爆裕度、磨料吸入剂量、丝幕驻留时长与绒雾电荷维持等参数在公开战例中均无确定性数据，须保留区间表述。建设取舍宜先以循源闭合侦打末端，走廊占域类按地形与风场条件择区配置，微波类待储能与辐射体小型化突破后再行批产，避免以同一指标列掩盖机理与边界差异。
