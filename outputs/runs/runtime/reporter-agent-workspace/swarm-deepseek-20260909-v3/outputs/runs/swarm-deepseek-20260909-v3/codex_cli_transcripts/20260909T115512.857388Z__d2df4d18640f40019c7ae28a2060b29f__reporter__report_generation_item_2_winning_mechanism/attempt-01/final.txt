## 第一层：需求挖掘层——场景·战法/技术·装备能力特征

### ② 新战法或新概念技术及制胜机理

俄乌对抗把反无人机的矛盾点从“能不能命中”逼到“结算对象选错”：旧范式以空中平台为拦截单位，把侦察—控制—发射—回收的完整出动链简化为对单机的逐架处置，击落一架廉价机既不改变敌在纵深再放一架的循环，也不触碰维持循环的操作组。单次拦截成本数倍于敌单机，弹药库存与火力通道随敌架次线性消耗，最先被拖垮的不是火力密度而是交换比。

本栏装备主体是S6入选的“循源”反辐射巡飞弹。它代表的新战法可概括为链路反查加地面猎杀：弹体以静默值守方式布于敌惯用航路侧方，宽带接收机检出敌控制下行与图传上行辐射，干涉测向结合平台机动把开机源反推为坐标，沿测向线逼近并打击操作组、发射阵地与回收点；弹体全程不主动辐射，任务本质由一次射击变成一段滞空期的占域值守，发射次数与敌架次数量脱钩。被改写的制胜关系，是从“我方高价弹药对敌廉价平台”翻转为“我方一枚值守弹对敌一组地面作战单元”：敌每次出动都必须开链，单机是否便宜不再决定交换结果，决定结果的是暴露一组地面单元后的重建周期——机组减员、发射载具与备弹的补充以周计，远长于重新生产一架机。该弹因此闭合“截获情报到地面节点杀伤”的执行末端，使信号侦察积累的链路频率库与阵地规律第一次能直接兑现为摧毁；指挥上由信号情报先划定猎杀区与优先级，多枚弹沿走廊轮换值守、按序清除，敌每次重放出动都面对已设伏的猎杀圈。

同一机理在俄乌反复出现的两种出动节奏下给出不同兑现：小额高频渗透中，每次开链都是一次地面暴露抽签，连续小额被逐步抽成持续放血；集中大波次则使众多发射与控制源在时空上叠成单一电磁簇，一次成簇寻获即在一个窗口内整波清掉成排出动能力，链路失管后其余无人机被迫返航或失控，对敌出动计划形成连带破坏。相对于旧范式的逐架成功率与单波弹耗基线，新判据换成敌机组存续数与整波被端掉的次数，越出动静默、越集中越危险、越驻留越暴露，消耗节奏的主导权由敌转我。由此形成的被动猎杀圈不靠雷达照射与持续主动干扰换取拦截，己方开机暴露成本下降，敌链路占用越久、越界越深，被定位概率越高。

敌方最现实的反制不在电磁硬对抗而在制度性规避：把操作组、发射点与回收点相互拉开并每次出动后快速转移，压缩单阵地暴露窗口；把出动间歇化、随机化，错开单弹有限滞空时间；中段预编程飞行只在末端确认或投弹瞬间开链，以窄波束定向压低辐射；在远离真阵地区域布设诱饵源消耗弹量。但这些对策都落在“每次出动”尺度上并与自身效能冲突：压功率、跳频或断链飞行自降图像质量与末端协同，间歇化放弃波次集中优势并抬高任务规划与训练成本，诱饵既添购置开支又扩暴露面；弹上记忆跟踪与主源/诱饵判别再收窄“关机脱离”与“假源消耗”两条路径的收益。敌方无论选哪条路径，单架次综合成本都上升，而己方值守成本不随其架次线性增长，消耗方程被单向改写。

成立边界须与机理同写：它以敌每次出动必须开链为物理前提，末端短开链压缩的是暴露时长而非暴露事实，仍是可截获窗口；若敌演进为全程无可截获链路的自主行动形态，寻的目标即消失——该形态目前无确证，只作为滚动跟踪的触发条件而非当前威胁基线。实际效能还依赖战前频率库积累、走廊与阵位规律研判、多辐射源环境下的主源/诱饵分选正确率，以及单弹滞空窗口与补弹节奏的匹配。布势还须在敌惯用航路与阵位纵深取得提前量，若敌周期性更换走廊与开链样式，单次布势价值下降，要靠低成本补撒与机动再部署维持覆盖——属使用边界，不否定机理本身。诱饵配置比例、辐射截获概率与命中概率等参数公开证据不足，本栏只作方向级判断，不承诺点值。
