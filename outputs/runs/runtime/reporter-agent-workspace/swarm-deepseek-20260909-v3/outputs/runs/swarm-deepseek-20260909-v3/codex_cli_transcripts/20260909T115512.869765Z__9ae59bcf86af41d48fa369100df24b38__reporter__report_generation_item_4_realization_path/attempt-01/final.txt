第二层：技术攻关层——能力实现途径与核心技术

④ 能力实现途径

实现途径的分型依据不是单项技术新旧，而是哪一级创新能闭合装备自身的因果链：直接借用现役体制、只改交战对象的走沿用改进，把多个成熟单元重组为新杀伤闭环的走集成创新，机理指标互相排斥、无现役先例可借的才上原理突破。输入未提供各方向的现役装备基线事实，下述分型以机理瓶颈位置为据，成熟度与型号归属留待⑤闭合。

循源反辐射巡飞弹定为集成创新。反辐射寻的、巡飞平台与宽带数字接收分属成熟方向，并无新物理原理；新的是把无人机控制与图传辐射源确立为交战对象，把截获判定、测向逼近、抗关机记忆跟踪与诱饵判别重组为可消耗弹级任务链。工程边界在弹径约束干涉测向基线，压低角精度与可截获距离；低空多径与地物反射污染来波方向，链路特征库须随敌方波形迭代持续更新，敌方断链预编程与定向窄波束进一步压缩开窗，截获率上界由情报更新周期决定。

锁律悬雷栅栏的集成创新成立前须补一段原理级攻关。炮射筒射布撒、充气悬浮、网捕与触发自毁均为可借鉴单元，真正缺成熟件的是零辐射节点在走廊断面内长时间驻留并被动声光判别：低渗漏蒙皮、浮力压舱微调与超低功耗唤醒互相挤占弹内容积。工程边界在于节点随风漂移即成空档、风雨鸟群误醒会自耗栅栏，密度须靠周期性补撒兜底，补撒速率还要压过敌方清栅速度，走廊流量与驻留寿命共同决定“通行税”能否成立。

一发抵整波微波拦截弹需按原理突破组织。地面高功率微波装备依赖持续供电与大型天线阵列，无法移入弹径；弹载单次源须把储能、脉冲压缩、振荡与辐射体装入同一脉冲链并在波前一次性放电，宽谱覆盖、峰值功率与弹径三指标互斥，属体制的尺度性跨越。工程边界为储能密度与放电时间常数决定峰值功率上限，宽谱辐射受弹径限制效率偏低，单次频谱一致性难以批量复现；起爆几何误差与机群散布压低边缘场强，引信、波束包络与功率裕度须联合整定。

蚀翼尘暴弹的瓶颈在药剂本身，属原理突破。现役烟幕只能遮蔽、破片只能毁单机，构不成“吸入—累积磨蚀—延迟故障—返场暴露”链路；磨蚀相与示踪相须在同一粒径谱内兼得硬度、气悬寿命与光谱标记，互斥指标没有现役体系可解，须新开复合颗粒与二次解聚抛撒。工程边界是粒径与弹重对抗：粒径越小越易悬浮吸入，单位弹重可携磨蚀剂量越少，沉降与风稀释又压低尘浓度；空爆点与起爆高度须按实时风廓线装定、多发时序连成尘障，逆风强湍流压缩驻留窗口，成立范围限于气象适配时段。

弥空垂帘弹走集成创新，攻关集中在成形环节。把数万根亚毫米高强丝按时序解缠抛撒，织成覆盖走廊断面、驻留数十秒以上的低可探测丝幕，以一发换一波次的通过概率，难点在抛撒能量、丝长卷曲度与解缠时序的耦合，以及丝材“细到难察、强到缠停”的矛盾。工程边界上，丝一成团或现空洞即被机群按概率穿透，重力沉降与风切变使细丝聚成条带坠落，须以开舱高度、投放诸元与风场解算封闭丝幕构型；驻留时长直接决定单发能封住敌方几个出动窗口。

染空弥雾电绞拦截弹以沿用改进打底、叠加集成创新。旋翼缠绞与线缆桥接短路属经典毁伤机理，可沿现役相关弹药改型；真正新做的是以诱发电荷令金属化纤维同极互斥，借低空缓风铺展成雾并稳定滞空，把点状释放扩展为整段走廊剖面。工程边界是金属纤维密度大、阻力小，空爆后易成团坠落或随风漂移露口，须以电荷质量比与细长形态稳住悬浮窗并按风切变反推定高；缠绞要求长而卷曲抗拉、短路要求镀层弯曲中导电、滞空又要求细而轻，三项互斥决定主攻点落在芯丝镀层界面与长度分级混配。

断窥高功率微波反察弹定为集成创新，其独占性攻关在交战几何而非效应源：须抢在廉价观侦编队深入要地上空、尚未散开时于编队内侧近炸，在秒级窗口内解算编队散布与弹轴指向，使主瓣覆盖最多未加固航电；微波源小型化是共性前提，宜在微波弹预研线上并联收敛。工程边界是主瓣窄且随距离发散，炸点决策须与辐射时序一体化装定；混合机型编队的耦合窗口分散，单发收益须按机型谱加权核算，编队过散时只能弃窗改由点防补漏。
