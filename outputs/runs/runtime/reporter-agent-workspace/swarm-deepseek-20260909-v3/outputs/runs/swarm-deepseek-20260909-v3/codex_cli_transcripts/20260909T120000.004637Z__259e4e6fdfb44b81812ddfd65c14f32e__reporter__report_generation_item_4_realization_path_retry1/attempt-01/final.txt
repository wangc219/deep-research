## 第二层：技术攻关层——能力实现途径与核心技术

### ④ 能力实现途径

“循源”反辐射巡飞弹走集成创新。反辐射寻的能对地面辐射源末端锁定、巡飞弹的平台与批量制造都有可依基础，俄乌战例新增的是目标谱系与开窗规律——无人机每次出动都须短暂开链，操作组与发射点由此成为可打击地面节点——而不是新毁伤原理。改动落在弹体导引链：宽带链路截获、干涉测向、链路特征分类与抗关机记忆跟踪须压缩为弹载一体设备，战斗部与动力沿用巡飞弹构型，把单发成本压到敌方重建一个操作组之下。边界在于它惩罚开机作业：敌方预编程断链飞行时无辐射可寻，诱饵会骗走弹量，特征库不更新则真源与诱饵难分，信号消失后只能按最后测向线记忆跟踪，覆盖不了全程静默的出动样式。

“锁律悬雷栅栏”要把浮空驻留、声光被动唤醒、近距释网与筒炮射布撒合成一种“占域—补撒”闭环的新弹药品类，属集成创新而非沿用改进，因为现役网捕弹只解决单架，拦阻气球又不能按走廊批量布撒。本体变化集中在悬浮网雷节点：零辐射待机、超低功耗唤醒、释网与破片自毁一次装定，节点成本与可靠性须支撑成百颗补撒。选这条路的依据是，走廊渗透下点拦截的发现窗口与单发成本都不成立，只有把作用对象从单机换成走廊本身，才能把每次穿越变成随机折损。工程边界在节点寿命与误警：漂移出走廊即成空档，蒙皮渗漏使浮力衰减，风雨误醒自耗节点；补撒速率压不过敌方清栅速度时，栅栏退化为一次性伏击。

“一发抵整波”微波拦截弹属原理突破。高功率微波对未加固航电的毁伤机理已经明确，卡点是把靠地面连续供电、大型射频器件维持的微波源压缩成弹载“只响一次”的宽谱脉冲战斗部：储能密度、放电时间常数与谱宽一致性互相挤占，覆盖半径能否罩住真实编队散布，还要等“敌方为维持产量普遍省略屏蔽加固”这一前提在实测中兑现。改动集中在弹头，脉冲功率链、宽扇形辐射体与前置爆点引信按同一条链路整定，弹道只修到波前概位。工程边界随之清楚：敌方拆散波次、拉开间距或做廉价局部加固，单发固定成本优势即缩水，故它须与波次判定和开火规则捆绑，不能充当逐架补射的普通弹药。

“蚀翼尘暴”必须从原理突破起步。把“吸入—累积磨蚀—返场示踪”当作武器机理，现役没有对应物：磨蚀相与示踪相须包覆成同一复合颗粒，空爆后二次解聚为可长时悬浮的细粒径谱，吸入剂量与延迟失效概率的关系要靠实测才能反推装填比，烟幕与破片弹都改进不出来。本体新增抛撒药包、复合颗粒与定高引信，平台沿用普通炮弹。其依据是把逐架击落改成按通道计风险，敌方每穿越一次即自带延迟故障与返场暴露。边界由风场主导：尘云须滞留在敌机高度带并随硬闯叠加浓度，逆风强湍流下滞留与覆盖不成立，风向或空爆段选错即整发失效。

“弥空垂帘”属集成创新。丝网缠裹毁伤在反无人机网捕弹上已有基础，真正跨步是把一发从“小截面单网捕获”放大为覆盖走廊截面的立体丝幕，改动集中在抛撒机构与丝束封装：数万根亚毫米丝须按时序解缠、边扩散边搭出连续低密度骨架并驻留数十秒至数分钟，丝材要在细到雷达光学难辨与强到缠住桨毂之间折中。选它而非雷达引导拦截，是因为低慢小目标弱回波使多数窗口来不及锁定，体积概率拦截不依赖逐架航迹。边界在时间窗：丝幕沉降快，只能封住可预测的出动时段，窗口预测失准或风切变使丝体成条带坠落，占域即落空。

“染空弥雾”属沿用改进。金属化纤维缠绞旋翼、桥接裸露线路的体效应，在针对电网与电子设备的纤维武器中已经验证，俄乌战例改变的只是把打击对象换成批量穿越的低成本无人机。本体沿用布撒弹架构，改动集中在释放物与引信：按旋翼间距与裸露线缆尺度选定纤维长度与镀层，并加载同极电荷，靠静电互斥铺展成雾滞空。选它而不选点杀，理由是只判走廊、不辨单机即可交战，反应链最短。边界在纤维三性互斥：可悬浮、可缠绞、可导电难以兼得，金属加重即沉降成团，过细则短路能量不足，强风又压缩滞空，只能选风稳走廊使用。

“断窥”高功率微波反察弹应判集成创新，但增量不在微波源而在秒级交战决策。弹体把微波战斗部送到观侦编队内侧近炸，成片烧毁为校射服务的接收与飞控电子，需要新造的是“判群选时—散布解算—主瓣朝向—近炸起爆”整条决策链，使单发恰好落在敌群深入己方阵地上空、间距收拢到覆盖包线内的窗口。其所以成立，在于廉价冗余机群摊薄单发损耗的算法只有群级清场能打破。边界是时机：敌机四散、退高空远距或目标区邻近己方平台与民区时不能打，该弹只在看护链闭合前的集中过顶段有效。

七件装备的取舍最终汇成一个闸门：凡以占域、整波、概率计价改写交换的实现途径，都须先对真实目标谱系测出覆盖半径与单发代价，再按敌方加固、拆波、清栅等反制后的成本决定批产，机理成立不等于工程成立，验证顺序不能颠倒。
