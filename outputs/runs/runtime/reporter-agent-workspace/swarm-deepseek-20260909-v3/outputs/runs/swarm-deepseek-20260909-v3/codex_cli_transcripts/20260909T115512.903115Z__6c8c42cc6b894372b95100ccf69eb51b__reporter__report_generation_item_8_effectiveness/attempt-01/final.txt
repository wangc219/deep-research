第三层：能力图像与效能贡献层

⑧ 效能贡献评估

“循源”对任务结果的贡献不在提高拦截率，而在把反无人机的交战对象从空中单机换成链端地面单元。逐架拦截毁机不毁人，敌以远低于我方弹价的架次反复补充，越拦越亏；该弹被动截获控制与图传辐射、沿链路测向逼近，打击操作组、发射阵地与回收点，把每次开链出动折算为一组地面单元的暴露与摧毁期望。机组减员的补充以周计、远超再造一架机，可持续架次直接下降；集中波次时发射与控制源叠成单一电磁簇，一次寻获可成批瓦解。敌方压功率、断链飞行、设诱饵源均以自降侦察打击质量或新增暴露点为代价。其效能实质是由“毁机”应急转为“开链即计价”的源头压制，使反无人机进入按序清除机组的持续作战。

锁律悬雷栅栏把拦截对象从单架机换成走廊本身，以一次性发射换取持续占域。敌方沿地形遮蔽卡出的少数通道高频小额渗透，点防逐架拦截追不上节奏，还诱发雷达与火力点开机暴露；该弹在走廊布撒零辐射微网雷节点并周期补撒，节点被动声光唤醒、近距释网并破片自毁，使每次穿越都成为带随机折损的通行税。小额渗透被逐次抽干，既耗不动我方弹药也换不出火力点清单；压成大波次硬闯则多节点同时触发，在可预测时间窗内成片拦杀。对手清栅耗时耗弹且追不上补撒，绕行则拉长航线、增加暴露。其贡献是令“击落数”让位于敌出动率下降与绕行路线暴露，把走廊节奏主导权移交我方补撒侧。

一发抵整波微波弹改写的是防空消耗与来袭架数的线性绑定。廉价机群整波压来时，动能弹一发对一架、火控通道随架数放大，弹库先耗尽；该弹在波前空爆，以宽谱强电磁脉冲覆盖整片编队，烧毁飞控与动力电子，单发清零一波，单批拦截成本成为固定值。为保产量普遍省略屏蔽的低成本机群恰整体暴露于场效应毁伤；逐架加固则单价抬升、产量收缩，整波仍可被单发抹除，数量换突防的账本反转。其贡献是让有限弹药基数覆盖更多波次，并把指挥从逐架排序简化为波次间火力重置，维持长时间拒止；对手拆波、拉距规避，以牺牲突击密度换存活率，调度压力已前移。

蚀翼尘暴针对廉价穿越机返场可复用、损失可摊薄的循环。拦截弹只换单机，干扰可用预编程与断链规避；该弹在走廊低空空爆，形成随风漂移的磨蚀—示踪双效尘云，穿越机吸入微磨料后旋翼、进气道与光电载荷渐进损伤，沾染物可被多光谱识别。单架渗透自带延迟故障与返场暴露，返场即把故障机与出击源坐标交给反炮兵溯源；大编队硬闯则尘浓度叠加，成批功率衰减、失明并诱发队形自撞。敌方加滤尘、包覆、返场清洗等规避恰好压低出动频次、拉长整备周期，把可消耗快件拖回昂贵慢平台。其贡献是把敌损失从“不传染、可摊薄”改为按架次累积的负债，使反无人机由单点拦截转为对出动循环的系统性征税。

弥空垂帘的贡献在时间维：把反无人机由逐目标交战改为按预测窗口预置占域。拦截弹单价高出廉价机数级，点拦截扛不住密集波次；该弹在敌预定出动时段向走廊爆散数万根亚毫米高强飘丝，数十秒至数分钟形成低可探测的滞空丝幕，把穿越走廊改写为禁飞死段。单机穿越被随机缠毁即单次抽税；敌为压缩暴露窗口拉成大波次，反使单发收割量随编队密度陡增，缠停与失控机互撞扩大波内伤亡。丝体无金属、特征极低，难以预警清除，敌只能退回低流量小额渗透，丧失同时到达的突击密度。其贡献是以近似固定弹药支出换得敌方时间窗主动权，末端火力集中补漏，任务结果由“力争不漏”转为“按窗口控制通过率”并维持持续占域。

染空弥雾电绞弹以单发否定整段走廊的整批来袭，且战前无需判明目标。旋翼机群沿遮蔽走廊蜂拥突防时，旧打法须逐架识别、点杀伤，耗弹随架数上升；该弹空爆后借气流与诱发电荷使金属化纤维成绒雾滞空覆盖走廊断面，穿雾机旋翼被缠绞停转、裸露供电与飞控线路被桥接短路，成片坠地，拦截花费不随架数上升。敌方无法对雾状散布体点状锁定或绕避；逐机加装滤网与线路屏蔽又抬高单价与复杂度、压低载重航程与产量，先自毁“廉价可弃”前提。其贡献在于切断弹耗与架数的线性关系，使小防御编组能顶住大规模消耗，并把反无人机从“等目标出现再反应”转为“先占空域、等敌来穿”的分钟级空域否决。

断窥反察弹贡献于切断敌方“发现—校射—毁伤”闭环，而非增加击落数。廉价观侦机群以高架次冗余覆盖炮兵、再装填点与补给线，逐架点杀一弹换一机，漏网即恢复校正，阵地被钉死于敌打击节奏；该弹抵近编队内侧近炸，广域电磁脉冲成片烧毁未加固航电，整群同刻失明，实时看护成片中断，远程火力失校射而减速，己方再装填与集结重获分钟级可计算窗口。敌恢复看护须重新放飞、标定、接通链路，每轮再暴露指挥节点；逐架屏蔽则单机成本乘机队规模反噬，退高空远距又牺牲校射精度。其效能尺度从单发命中率转为己方行动窗口可用概率，并把防御代价转嫁给敌方恢复周期。
