## 二、项目画像

### （一）装备图像概述

| 装备 | 核心技术与形成能力 | 部署或进入方式 | 关键动作、作用对象和直接效果 |
|---|---|---|---|
| 断群近场抑制巡飞弹 | 以巡飞平台、自主潜入控制和近场定向高功率微波载荷为核心，形成“源头断群”能力。它不把来袭无人机逐架作为空中拦截对象，而是瞄准敌方无人机在充电、装配、待发或再次出动节点上的脆弱状态；只要其飞控、电源管理和协同终端仍处于可耦合、可受扰的准备阶段，就可在集群生成前造成关键电子部件失效。该能力的装备价值在于把反制窗口从末端防空前推到敌方组织出动环节，减少后续防区同时面对的有效目标数量。 | 随机动部队或重点防护力量前置投放，依托预先掌握的出动节点、补能点或装配点信息进入目标附近；进入后不依赖持续外部数据链维持作用，可在通信受限、节点受扰条件下按授权规则自主接近、识别作用窗口并实施近场压制。其适用前提是能够获得足够可信的节点位置、进入路径和误伤隔离条件；若只能面对已经离散升空的无人机群，装备效果将从“断群”退化为局部电子杀伤。 | 在敌方无人机尚未形成攻击编组前，巡飞弹靠近其充电架、装配区、起飞位或返场再出动点，释放定向微波脉冲，直接耦合飞控、电源管理、任务终端和协同通信部件，使无人机不能起飞、不能集结或不能再次执行任务。直接战果不是空中逐架击落，而是让敌方一次出动批次在形成前失去组织条件，迫使其转入人工检修、节点转移或分散出动，从而削弱原本依靠低成本连续放飞形成的饱和压力。 |
| 石墨超材料断链弹 | 以石墨基超材料吸收、散射和短时空间介质构建为核心，形成“宽域断链”能力。它针对的是低空集群的控制链路、导航链路和协同链路，而不是单机机体；通过在关键节点外围形成可覆盖多个链路方向的电磁介质，使不同航路、不同频段或不同节点的协同条件同时恶化。相对传统逐架电子压制和硬杀伤，它把作战对象从目标数量转为目标穿越的电磁空间，降低防御资源随目标数量等比例消耗的压力。 | 由地面或车载平台在关键节点外围、集群可能突入航路或编组穿越窗口发射，弹药到达预定空域后形成短时宽域介质层。部署时重点选择集群尚未完成突入、仍需保持控制、导航和协同同步的阶段；若敌方已转为完全独立自主、低密度分散突入，或作用区无法覆盖其协同窗口，则只能造成局部迟滞，不能替代后续拦截。 | 在集群进入防护区前，断链弹使控制、导航和协同信号传播环境同时失稳，作用对象是集群共同依赖的链路体系。直接效果是编组解耦、任务中止、安全返航或被迫分批进入，防御方不再需要为每架无人机持续分配压制波束或拦截弹。敌方若以跳频、分段链路或备用导航应对，也必须增加冗余节点、降低编组密度并拉长突入时间，原有同步饱和优势被削弱。 |
| 黑潮导电丝云拒止弹 | 以导电丝材料可控展开、分层成云和低空短时障碍保持为核心，形成“区域物理拒止”能力。它不依赖夺取链路控制权，也不要求精确识别每架小型无人机，而是通过导电丝云对旋翼、进气口、外露传感部件和局部感知环境施加直接影响，使集群穿越某段低空区域的稳定性和可预测性下降。其能力本质是压缩可用突防通道，而不是保证全部毁伤。 | 由空投或其他投送平台在重点目标外缘、低空必经通道或多方向汇聚区域布设，可多枚在不同高度、相邻区域交错释放，形成短时分层障碍。进入方式要求先确认友方低空飞行器退出、风场和障碍持续时间可控、后续拦截火力能够接管分散目标；若风场使丝云快速断裂，或残留风险无法隔离，装备只能作为临时通道收窄手段使用。 | 导电丝云直接作用于小型无人机的旋翼、进气、外露传感器和避障感知，使其面临缠挂、遮挡、局部导电扰动和编队保持困难。直接效果是集群减速、分散、爬升、绕行或中止原航路，原本可从单一缺口集中突入的目标被迫变成多批次、低同步、长暴露航迹。防御方由此获得重新识别、火力再分配和关键节点连续防护时间，而不是被拖入对每架目标的即时追杀。 |
| “回澜”协议诱导弹 | 以通信载荷、协议身份模拟、状态机诱导和安全处置信号生成能力为核心，形成“共同任务状态折叠”能力。它瞄准敌方集群共享授权、返航、失联处置和任务重组规则，在目标尚未完成出动或重组时，使多个平台把诱导源误判为可执行的状态源。该装备的独特价值在于用任务中止替代逐架毁伤，把交战入口从空中追击前移到授权与安全逻辑环节。 | 前置部署在敌方集群可能出动、重组或进入任务授权更新的窗口附近，以通信载荷进入其可接收范围。使用时必须确认目标确实存在可被外部信号影响的共享授权或安全状态，且友方平台、民用无人设备和无关链路不会被误触发；若敌方已采用强双向认证、独立授权和不接受外部处置信号的自治机制，装备效果将显著下降。 | 诱导弹伪装成集群可识别的授权、返航或失联处置源，使多架无人机同步中止任务、返航、降落或退出重组流程。直接效果不是击落，而是让尚未形成有效攻击航路的集群整体失去节奏，减少同时进入火力通道的目标数量。敌方为规避该装备，必须增加密钥管理、交叉校验和人工复核，随之牺牲快速出动、低延迟协同和低成本重组能力。 |
| 相位诱导编队裂解弹 | 以被动侦测、无线测距特征提取、授时关系识别和短时相干伪参照发射为核心，形成“编队协同裂解”能力。它不把主要作用点放在外部指挥链路上，而是攻击集群成员之间共同依赖的相对位置、时间和避碰判断，使原本用于保持密集突防的协同规则反过来放大内部矛盾。相对宽带压制，它更强调选择集群最敏感的时空参照关系进行短时诱导。 | 作为可消耗电子效应弹前出至低空集群航路侧前方或突防窗口附近，依靠弹上被动侦测判断成员间测距、授时和协同通信是否存在可利用模式；满足窗口后自主释放伪位置和时间参照，不依赖持续外部指挥链。其成立边界是目标确实依赖共享相对参照和队形规则；对完全独立导航、强抗诱导且低密度分散的平台，效果可能退化为局部扰乱。 | 在集群保持密集队形、共享测距和统一授时突入时，裂解弹释放相干伪参照，使不同无人机对间距、避碰、队形保持和任务节奏形成互相冲突的判断。直接效果是编队解散、协同失步、部分平台进入失控或安全模式，剩余目标降速、分散并暴露独立航迹。防御方因此把必须同步应对的整体目标转化为可分段处置的离散目标，减轻后续拦截和近程防护压力。 |
