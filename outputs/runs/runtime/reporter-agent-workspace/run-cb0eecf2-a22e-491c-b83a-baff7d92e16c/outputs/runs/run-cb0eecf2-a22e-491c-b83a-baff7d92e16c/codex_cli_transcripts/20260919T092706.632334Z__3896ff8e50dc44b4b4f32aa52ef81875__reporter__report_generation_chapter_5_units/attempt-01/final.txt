## 五、研制基础

### （一）参与单位

本项目不宜按通用“总体、分系统、试验”平均分工确定参与单位，而应围绕五类装备的产品责任、作用接口和可交付证据配置承研与配套力量。由于现有公开材料未确认具体单位、型号归属和既有样机成熟度，以下仅提出机构类型及其应承担的可核验任务。

“断群近场抑制巡飞弹”应由具备巡飞弹总体设计、近程自主导航和高功率微波效应器研制能力的弹药总体单位牵头，配套微波源、脉冲功率、近场耦合与抗冲击封装等专业单位。其关键接口不是常规远程指挥链，而是前置投放后的自主航迹控制、目标节点识别和效应释放安全逻辑；试验单位需能够提供充电、装配或出动节点模拟环境，并交付飞控、电源管理和协同终端受效后的失效证据。缺少真实负载、作用距离和复杂电磁条件下的试验数据时，不能确认其源头断群效果。

“石墨超材料断链弹”应由弹药总体或电磁效应弹药单位负责，将材料、装药释放、空间作用范围和平台发射安全性统筹起来；石墨基超材料、宽带吸收散射结构及环境适应性可由材料和电磁防护类单位配套。其核心接口是地面或车载发射平台与关键空域的时机、方向和作用区标定，试验单位应同时提供跳频、分段链路、替代导航和多节点编组条件，交付集群级链路失稳、任务中止或返航证据。公开资料不足以证明该材料能够覆盖不同链路形态，需保留验证缺口。

“黑潮导电丝云拒止弹”需要由区域拒止弹药总体单位牵头，配套导电丝材料、抛撒控制、空域安全和小型无人机环境试验单位。其产品责任在于形成分层、交错且可控的低空障碍，而非单架目标毁伤；接口重点是空域管理、抛撒时序和后续拦截通道移交。试验应交付对旋翼、进气和外露传感部件的干扰结果，以及多方向绕行条件下通道压缩效果。现无公开证据支持其持续时间、覆盖规模和环境适应性。

“回澜”协议诱导弹应由通信载荷弹药总体单位与协议安全、嵌入式控制和无人机任务系统测试单位联合承研。其责任对象是授权、返航和失联处置状态机，关键接口是目标协议识别、诱导信号释放和我方后续确认补漏，不应与普通电子压制单位混同。试验单位需在认证更新、独立校验和复杂电磁环境下验证同步中止、返航或降落，并交付误诱导、抗诱导和残余目标处置证据。目标协议未知是当前最大证据缺口。

“相位诱导编队裂解弹”应由自主电子效应弹总体单位牵头，配套无线测距与授时特征分析、被动侦测、相干信号生成和低空动态试验单位。其关键产品责任是识别集群内部相对时空关系，并以短时诱导破坏队形保持，而不是持续压制外部链路；接口包括航路前出、被动工作和裂解后拦截交接。试验需证明编队解散、协同失步及安全模式触发之间的因果关系，并覆盖惯导增强、异构传感器和松散编队等反适应情形。现有公开材料尚不能确认其对不同集群协议的适用范围。
