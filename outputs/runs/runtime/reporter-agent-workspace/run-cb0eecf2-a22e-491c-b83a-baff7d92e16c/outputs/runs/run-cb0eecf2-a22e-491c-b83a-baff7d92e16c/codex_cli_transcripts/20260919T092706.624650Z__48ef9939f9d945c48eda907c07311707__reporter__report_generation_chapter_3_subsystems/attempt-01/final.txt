三、总体方案

（二）子系统方案

本项目的子系统不是对现有探测、压制和拦截设备的简单并列，而是围绕五类入选装备各自切入的任务断点配置。共享关系仅限于目标态势、任务授权、作用空域和效果回报四类信息：前端提供目标位置、航路、密度或协议特征，装备依据自身机理独立完成作用决策，结果再回送处置链，用于确认任务中止、编组裂解、区域通道压缩或源头节点失效。公开材料尚未证明这些新型装备已有装备级性能，因此接口可行性和作用效果均须通过分层试验确认。

| 入选装备 | 产品形态与专属控制 | 必要输入、输出及关键接口 | 工程验证与失效边界 |
|---|---|---|---|
| 断群近场抑制巡飞弹 | 采用可前置投放的自主巡飞弹构型，依靠末段自主识别充电、装配或出动节点，在无需持续外部链路时完成近场定向高功率微波作用；控制重点是潜入、目标确认和作用时机，而非空中追击 | 输入为节点位置、环境约束和自主探测结果；输出为飞控、电源管理或协同终端失效状态，并回传节点是否停止出动。需与任务规划和空域禁入信息接口连接 | 先验证自主抵近、目标判别、近场耦合和多机终端失效之间的因果关系，再验证节点级断群效果。若不能在链路中断、目标伪装或节点迁移条件下保持抵近与作用，应限制其任务边界 |
| 石墨超材料断链弹 | 由地面或车载平台发射，在预定突入窗口释放形成短时宽域电磁介质；控制核心是作用区位置、时机和介质覆盖状态，不以逐架跟踪为前提 | 输入为集群航路、突入方向、目标密度和关键节点外围边界；输出为链路失稳、导航受扰、编组解耦或返航状态。需与火力分配、空域管制和残余目标跟踪接口衔接 | 重点检验材料释放后吸收、散射和空间持续特性是否足以同时影响不同链路形态，并评估己方通信、导航和后续拦截是否受牵连。跳频、分段链路或分批突入可能削弱效果，不能把宽域作用直接等同于全群失效 |
| 黑潮导电丝云拒止弹 | 采用空投或区域投放构型，通过不同高度和相邻区域的多弹布设形成交错导电丝云；控制对象是低空通道和障碍层叠加关系，主要作用于旋翼、进气和外露传感部件 | 输入为突防方向、高度层、速度密度和可用航路；输出为局部飞行不稳、感知受阻、编队松散及可用通道变化。需与空域封控、后续拦截和障碍状态评估接口连接 | 应在不同风场、湿度、机体尺寸和编队密度下验证材料展开、空间保持及对飞行部件的实际干扰。若敌方通过高度调整、分散航路或耐受性改装即可稳定穿越，则其区域拒止价值下降 |
| “回澜”协议诱导弹 | 采用带通信载荷的前置部署弹药，围绕目标集群的授权、返航和失联处置状态实施协议诱导；控制重点是信号身份、时序和覆盖窗口，必须避免把未经确认的目标误纳入安全状态 | 输入为目标协议特征、出动阶段、任务窗口和认证关系；输出为中止、返航、降落或拒绝执行状态，并将未受影响目标交给后续处置链。需与任务授权、识别确认和安全隔离接口连接 | 需在封闭靶场验证协议识别、诱导触发、误导隔离和多机同步效果，并检验敌方双向认证、密钥更新和人工复核下的失效情形。公开证据不足以支持确定性诱导成功率，工程上应保留人工确认和补漏手段 |
| 相位诱导编队裂解弹 | 采用具备自主被动侦测能力的可消耗电子效应弹，前出至航路后提取成员间测距、授时和协同通信特征，选择最敏感的相对参照实施短时相干诱导；其控制闭环在弹上完成，不依赖持续外部指挥 | 输入为被动截获的相对时空特征和集群运动关系；输出为队形保持失败、协同失步、编队解散及部分平台进入安全模式的判定。需与前端空情提示和后端逐目标拦截接口连接 | 验证重点是动态环境下的被动特征提取、伪参照一致性和对避碰、间距保持逻辑的影响，而非单纯验证信号强度。若敌方改用惯导、异构传感器和松散编队后仍能保持协同，则应将装备定位为特定编队条件下的裂解效应器 |

五类子系统的集成边界也不相同：断群近场抑制巡飞弹依赖节点级侦察和自主抵近，石墨超材料断链弹依赖作用区规划与己方电磁兼容，黑潮导电丝云拒止弹依赖低空空间管理和障碍状态评估，“回澜”协议诱导弹依赖协议确认与误导隔离，相位诱导编队裂解弹则依赖被动提取集群内部参照关系。工程验收应分别证明“节点停止出动”“集群链路失稳”“区域通道被压缩”“共同任务状态中止”和“编队协同裂解”五种结果，不能用单一的探测距离、压制时间或拦截数量指标替代。
