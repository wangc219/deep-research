## 五、研制基础

### （一）参与单位

本项目不宜按单一武器承制单位组织。低空多源感知至软硬杀伤闭环杀伤链的主要矛盾，是目标发现、目标确认、授权交战、末端处置和战果回读分属不同装备与权限节点；任何一个节点在强干扰、低空遮蔽、目标密集或通信退化条件下失效，都会把“发现了目标”降级为“不能及时处置”。因此参与单位应按任务链分工确定，而不是按单个平台峰值性能确定。

总体牵头单位应具备低空防空、反无人系统和指挥控制集成经验，负责需求分解、体系接口、交战规则固化、试验评估和安全边界控制。其关键交付不是某一型拦截器，而是把等离子羽流压制无人机、“槲寄生”贴附式低空截杀无人机、折翼泡沫包覆弹、气溶胶结壳拒止火箭弹、地效跃迁守候雷、脉冲弧面近程防空弹、环刃回收式截击无人机接入同一任务链，并在通信受限时仍能按预案降级运行。公开输入未给出国内具体承制单位名称，正文只列单位类型和待明确项，不虚构院所、企业或型号谱系。

感知与识别单位应覆盖低空监视雷达、光电/红外、无线电侦测、声学或被动探测、目标分类算法和传感器标定。其战场价值在于解决小型旋翼机、低速固定翼简易平台、近距侦察投送器在杂波、遮蔽和编队穿插中“看得见但分不清、分得清但来不及交战”的问题。待明确项包括各传感器对低慢小目标的探测边界、虚警率控制方法、跨传感器时间同步方式，以及目标身份置信度如何转化为火控授权条件。

软杀伤与电子对抗单位应承担干扰、诱骗、链路压制、导航扰乱和战果判读接口设计。其作用不是替代硬杀伤，而是在敌方无人机采用分布式航线、抗干扰链路或自主末端飞行时，先压缩其可控飞行窗口，使后续硬杀伤、包覆失能或区域拒止更容易闭合。失败条件应在研制初期写入试验大纲：若软压制不能提供可被火控链读取的失能、偏航、掉高或任务中断证据，就不能作为闭环杀伤的独立战果。

硬杀伤与特种效应载荷单位应分别覆盖近程防空弹、截击无人机、守候雷、包覆弹、拒止火箭弹和等离子羽流类效应载荷。不同单位之间必须共享目标航迹、授权状态、补击时序和毁伤评估格式，否则会出现多个处置节点争抢同一目标、漏网目标无人接管、或过度杀伤造成附带风险的问题。对折翼泡沫包覆弹、气溶胶结壳拒止火箭弹和脉冲弧面近程防空弹，公开输入没有给出可核验点值指标，研制单位只能先以任务级仿真、地面安全试验、靶机试验和体系联试建立区间化指标，不得把假设参数写成定型指标。

通信、任务软件与试验评估单位是本项目能否立项成功的关键支撑。通信单位要解决节点受压后如何保留最低可用链路；任务软件单位要实现目标排序、火力分配、授权记录、补击建议和毁伤回读；试验评估单位要把“发现率、误警率、交战时延、耗弹量、漏防率、再组织时间、通信降级后任务完成度”转化为可复现实验科目。没有这些单位，项目会退化为若干反无人装备的并列采购，无法证明体系补链、强链和替代链的真实贡献。

### （二）技术基础

公开证据显示，反无人系统已从单点采购转向体系化、软件化、规模化和可消耗化建设。美国防部反无人系统战略把无人系统威胁作为跨军种体系问题处理，美方“复制者”相关发布也强调可扩展、自治、可消耗能力进入部署序列；这些公开事实可支撑本项目的研制起点：低空防御不能只追求单发拦截性能，而要同时建设感知补盲、授权闭环、低成本处置和持续波次补充能力。证据边界是，公开材料不能直接证明本项目七类装备的具体架构成熟度、融合门限或交战规则，只能作为需求方向和体系建设逻辑的外部参照。

现有技术基础首先来自多源低空感知。雷达、光电、无线电侦测和被动探测均已有公开工程基础，但单源感知在低空复杂背景下容易出现盲区、虚警和目标身份不稳。本项目的增量不是再增加一个探测器，而是建立“多源发现—置信度融合—授权交战—战果回读”的数据闭环；验证时应故意设置遮蔽、杂波、静默飞行、诱饵目标和通信退化条件，观察系统是否还能把目标分配给合适的软硬杀伤节点。若只能在理想靶场条件下完成闭环，说明技术基础不足以支撑实战立项。

软杀伤技术基础来自电子压制、诱骗、导航干扰和任务软件控制。其对等离子羽流压制无人机的支撑在于把末端压制节点前推到低空威胁接近区，使电子干扰、近防火力和无人机拦截不再分散在不同时间片内。对手可能采用预编程航线、自主视觉导航、抗干扰链路或多机饱和来绕开软压制，因此项目必须保留硬杀伤和区域拒止替代链。验证判据不应只看干扰是否发射，而应看目标是否出现可确认的失控、偏航、掉高、迫降、任务中断或被迫暴露。

硬杀伤技术基础来自近程防空弹、截击无人机、守候弹药和近距反无人弹药。脉冲弧面近程防空弹的研制基础应重点验证单发面域效应能否降低饱和来袭中的火控压力；环刃回收式截击无人机的基础应重点验证可复用、连续处置和回收后的再出动可靠性；“槲寄生”贴附式低空截杀无人机的基础应重点验证末端相对运动控制、贴附确认和安全失效；地效跃迁守候雷的基础应重点验证低空盲区边缘的自主识别、授权安全和友邻目标排除。上述方向均不能用公开缺失参数替代实测，指标应以区间、置信度和判退条件表达。

特种低附带风险处置技术是本项目差异化基础。折翼泡沫包覆弹面向小型旋翼机、低速固定翼简易平台和近距侦察投送器，核心价值是以包覆方式快速打断飞行、观察和操纵功能，并把失能状态转化为火控链可读取的战果信号。气溶胶结壳拒止火箭弹则把“必须精确命中小目标”的难题，转化为对低空通道的短时拒止，使穿越目标承担旋翼效率下降、传感失明、导航漂移和轨迹暴露的代价。二者的共同风险是环境适应性、附带影响、战果确认和重复使用区间不足，必须通过不同风场、湿度、背景目标和友邻活动条件下的试验判定是否可装备化。

任务级仿真、接口联试和演训验证是当前最现实的研制基础。七类装备均需要接入现有指挥信息、情报侦察、保障和训练体系，并在通信受限、数据不完备、局部节点失效时支持降级运行。近期可先建设数字靶场、半实物火控台架、传感器融合试验线和低空目标库，用于比较原方案与新方案在闭环时间、耗弹量、漏防率、补击成功率、持续波次和交换比上的差异；中长期再推进可消耗节点、可复用截击节点和区域拒止节点的动态重构。若压力测试中关键节点受压后无法自动切换替代链，或切换后战果无法回读，本项目应判定为体系集成未达标，而不是简单归因于单件装备性能不足。
