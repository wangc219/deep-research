## 三、总体方案

### （一）总体架构

本项目总体架构不是把若干反无人装备简单并列，而是围绕“低空多源感知至软硬杀伤闭环”建立可降级、可替换、可重构的任务链。基本构成为：低空多源感知层、目标融合与威胁排序层、火控授权与效应选择层、软硬杀伤执行层、毁伤评估与再分配层、保障测试与训练仿真层。其核心矛盾是低空目标小、慢、低、密，且常利用建筑、林缘、地形遮蔽和饱和批量进入，使单部雷达、单型干扰器或单发拦截弹容易在发现、确认、授权、命中和补击任一环节断链。总体方案的价值在于把“发现一个打一发”改为“确认通道、分配效应、持续复核、动态补击”。

感知层采用雷达、光电、被动射频、声振、阵地近感和弹上简化回传的组合。雷达负责给出低空扇区和初始航迹，光电承担类型复核，被动射频用于识别数据链和遥控特征，声振和近感节点补足贴地、转角、林缘等低仰角盲区。各传感器不要求在所有场景都给出完整目标画像，而是向融合层输出统一的“目标类型概率、航迹稳定度、威胁方向、禁射约束、可处置窗口、证据置信度”。这样设计的原因是低空防御中最常见的失败不是某一传感器完全不可用，而是多源信息口径不一致，导致火控等待、重复跟踪或误把诱饵当主目标。

火控与任务软件层采用“效应菜单”而非固定弹种绑定。系统按目标数量、目标速度区间、航迹密度、附带损害约束、电子压制效果和剩余弹药状态，在等离子羽流压制无人机、“槲寄生”贴附式低空截杀无人机、折翼泡沫包覆弹、气溶胶结壳拒止火箭弹、地效跃迁守候雷、脉冲弧面近程防空弹、环刃回收式截击无人机之间选择主效应和备份效应。脉冲弧面近程防空弹用于来袭簇群的短时面域压制，气溶胶结壳拒止火箭弹用于通道封控，折翼泡沫包覆弹和“槲寄生”截杀无人机用于低附带损害近距处置，环刃回收式截击无人机用于漏网目标连续硬杀伤，地效跃迁守候雷用于盲区边缘自主拦阻，等离子羽流压制无人机用于前出压制集群前缘。该分工避免把昂贵弹药消耗在低价值目标上，也避免在密集来袭时让火控链被逐个目标拖垮。

通信与接口层按“全链优先、断链可战”设计。正常情况下，各节点接入指挥信息系统，交换统一目标编号、航迹摘要、效应授权、禁射边界、交战结果和剩余资源；通信受限时，前沿执行节点只保留最小任务包，包括扇区、目标方向、友方禁入区、允许效应类型和中止条件。地效跃迁守候雷、环刃回收式截击无人机和折翼泡沫包覆弹的末端动作不依赖持续宽带回传，毁伤评估可由本地传感、弹上应变、目标减速、姿态失稳和后续传感器复核共同完成。这样能够在对手压制通信、释放诱饵或绕开主雷达覆盖时，维持局部防御链不断裂。

保障与测试层同步纳入总体架构。项目需要建设任务级仿真、半实物接口联试、典型目标库、低空复杂背景靶场和红蓝对抗演训数据闭环。验证不以单个平台峰值作为通过标准，而以体系指标判定：同一扇区多目标拥塞下的目标编号稳定性、效应分配正确率、误伤约束执行情况、补击时序、单节点失效后的任务保持率、通信受限条件下的降级交战成功率。公开资料能够支撑反无人系统向体系化、软件化、规模化和可消耗化发展，但具体融合门限、交战规则和各装备作用距离不能由公开证据直接推出，必须在试验中保留区间和置信度。

### （二）子系统方案

低空多源感知子系统由固定阵地传感器、机动传感器、近场守候传感器和弹上/载荷回传单元组成。输入为雷达航迹、光电视线目标、被动射频特征、声振越线特征、近炸或接触回传；输出为统一目标编号、航迹质量、目标类别、威胁排序和可处置窗口。该子系统重点解决“看见但不能确认、确认但来不及分配、分配后目标又丢失”的断链问题。建设上应优先实现异构数据时间戳统一、目标编号继承和低置信目标标注，避免把未经核验的单源告警直接推入杀伤链。

融合火控与授权子系统是全链核心。其硬件由火控计算单元、任务服务器、边缘计算节点和操作席组成，软件包括目标融合、威胁评估、效应匹配、禁射校验、交战授权、补击管理和战果复核模块。输入为感知子系统目标包、弹药/无人机可用状态、友方空域约束、任务优先级和指挥授权；输出为发射或释放任务、效应参数范围、目标交接包、补击触发条件和中止指令。该子系统不得把“自动化”理解为无条件自主开火，关键是让授权来源、目标证据、效应选择和战果复核可追溯，便于在诱饵、民用低空目标和友方无人平台混杂时控制风险。

软杀伤与复合压制子系统包括等离子羽流压制无人机、脉冲弧面近程防空弹和电子压制接口。等离子羽流压制无人机接收目标群前缘、威胁扇区和禁入边界，在短时交会窗口内对目标通信、导航、姿态稳定和旋翼气动同时施压；脉冲弧面近程防空弹接收目标簇横向展开面和预定效应空域，形成短时电磁扰动区，使多架轻小无人机同时发生链路失锁、飞控异常或任务中断。该子系统的验证重点不是单个目标是否坠毁，而是簇群是否被打散、火控余量是否恢复、漏网目标是否被后续硬杀伤及时接管；当对手增强电磁防护、采用无源航路或拉大队形间隔时，软杀伤效能会下降，必须由气溶胶封控、贴附截杀和可复用截击补链。

低附带损害末端处置子系统由“槲寄生”贴附式低空截杀无人机和折翼泡沫包覆弹构成。“槲寄生”截杀无人机从近距待机点或伴随平台释放，依靠末段相对定位和柔顺接触完成贴附，再通过定向电击、机械夹持或气动扰动使目标受控衰减；折翼泡沫包覆弹由火控装定交会点和近炸窗口，在末段展开稳定面并释放黏附泡沫，遮蔽传感窗口、阻滞旋翼或破坏舵面工作。二者的共同输入是低速小目标的短时稳定航迹和附带损害约束，输出是失能证据、残余威胁判据和是否需要补击。其失效边界主要是目标外形不适合贴附、泡沫未形成有效包覆、目标仍保持稳定航向或环境条件削弱材料作用，此时火控系统必须快速转交环刃截击、近防弹炮或再发射节点。

区域封控与盲区拦阻子系统包括气溶胶结壳拒止火箭弹和地效跃迁守候雷。气溶胶结壳拒止火箭弹接收低空通道、覆盖区和禁射约束，把载荷投送到目标通道前方或侧前方，通过粒子附着在旋翼、传感窗口和机体表面，迫使目标减速、偏航、爬升、坠落或暴露轨迹；地效跃迁守候雷布设在雷达低仰角遮蔽、建筑转角、林缘缺口和通道边界，平时低功耗守候，接到扇区告警或近场越线特征后短距跃迁补位，再以扰流、网状扰动、定向破片或接触处置拦阻目标。该子系统的建设取舍是牺牲部分集中控制精度，换取盲区内的持续存在和低成本拦截；若对手改用高空越障、诱饵触发或绕行未布设通道，则必须通过感知层重新标定热点并调整布设。

可复用硬杀伤子系统以环刃回收式截击无人机为主体。其输入为外层感知确认的漏网目标、局部净空边界和本机剩余能量/结构状态；输出为硬接触处置结果、自检状态、再捕获申请或回收指令。该平台通过侧前方或上方交会，把环形防护刃圈作用于目标旋翼、机翼或外露机臂，不追求摧毁整机，而是打断推进、升力或传动结构，使目标失稳坠落。它的体系价值在于降低末端防御对一次性弹药的依赖，并在软压制、泡沫包覆或气溶胶封控之后清除残余目标。失效条件包括目标速度超出本机可交会范围、碎片环境威胁本机复稳、连续接触后结构状态不足、友方净空不足；火控系统必须把这些状态纳入补击排序，不能默认可无限复用。

保障、训练与评估子系统贯穿全项目。硬件包括通用挂载/发射接口、快速装填与电源保障设备、载荷检测设备、任务记录下载设备、靶标无人机和半实物仿真台；软件包括目标库、红方反制模型、交战复盘、装备健康管理和指标评估工具。输入为演训目标数据、真实交战记录、装备自检、弹药批次和环境条件；输出为融合门限修正、效应选择规则、备弹结构建议、布设优化方案和失效案例库。项目验收应设置单节点失效、通信压制、多目标饱和、诱饵混入、盲区穿越和附带损害约束六类压力场景，只有在这些压力下仍能完成发现、授权、处置、评估和再组织，才说明低空闭环杀伤链真正形成。
