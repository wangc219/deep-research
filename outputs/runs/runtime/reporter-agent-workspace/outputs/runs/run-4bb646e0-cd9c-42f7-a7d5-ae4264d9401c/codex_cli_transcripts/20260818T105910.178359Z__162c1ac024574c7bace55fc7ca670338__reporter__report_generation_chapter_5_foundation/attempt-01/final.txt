## 五、研制基础

### （一）参与单位

本项目公开证据尚不能支撑点名具体国内承制单位或参研院所，参与单位应按能力类型而不是按未核验名称配置。牵头单位需具备弹药总体设计、任务链建模和靶场试验组织能力，负责把“持续监视”和“精确打击”从两个独立环节压缩为可验收的装备闭环；否则项目容易退化为单件弹药研制，无法回答通信受限、节点失效、目标转移后任务链是否仍能续接的问题。

弹药与战斗部单位应分为三类：一类负责空投纤维毯子母弹，重点解决柔性节点散布、落地姿态、误触发抑制和微小效应载荷安全隔离；一类负责砂幕啮合拦截弹，重点解决末段相对运动估计、颗粒云成形、短程伴飞修正和散布风险控制；一类负责“烛龙”盘旋攻顶弹，重点解决长航时低耗弹体、俯视复合传感、盘旋监视到末段攻顶的状态切换和车顶定向毁伤。三类单位可以共享任务软件、仿真环境和接口规范，但战斗部安全边界、目标特征库和末段判据必须分开验收，避免用一种试验结果替代三类完全不同的毁伤机理。

感知、通信和任务软件单位是本项目成败的共同短板来源。目标持续监视要求低功耗、多节点、可降级运行；精确打击授权要求高可信识别和可追溯决策。二者存在天然矛盾：越快闭环，误击和假目标诱骗风险越高；越强调确认，时敏目标越可能脱离杀伤窗口。因此应设置独立的目标识别与火控授权团队，负责目标特征、置信度阈值、人工介入接口、失联降级规则和毁伤评估回传，而不是把授权逻辑封装在单一弹载算法中。

试验验证单位应覆盖任务级仿真、接口联试、半实物仿真、地面安全试验、飞行/投放试验和对抗条件演训。美国国防部公开发布的联合全域指挥控制实施计划强调更快的信息共享和决策闭环，说明国外已经把“传感器到射手”的体系接口作为能力建设对象，而不是只考核单个平台性能。美国政府问责局关于卫星通信韧性的公开报告也提示，多路径和互联架构是防止单一路径中断的关键。这些公开事实可作为本项目设置“链路中断、数据缺失、局部节点失效”压力试验的外部参照，但不能直接证明本项目具体装备已经具备相同成熟度。

保障与训练单位需要从立项初期介入。空投纤维毯子母弹涉及落区环境、地表附着、误触发和回收/清理风险；砂幕啮合拦截弹涉及近距离颗粒散布的友邻空域约束；盘旋攻顶弹涉及空域使用、假目标识别和外部侦察协同。若训练体系只验证理想通信、理想气象和单一目标，将无法暴露对手绕开覆盖区、制造诱饵、压制盘旋空域、利用民用目标混杂等反适应动作。

### （二）技术基础

项目的可启动基础不在于已有某一型装备已经公开定型，而在于三类能力方向均可从现有无人化弹药、末段制导、分布式传感、任务规划和靶场仿真基础上拆分验证。近期建设应优先形成“任务链试验台”：用统一任务软件接入侦察输入、目标状态、通信质量、火力分配、毁伤评估和再攻击决策，先验证链路补接和降级规则，再进入弹体、战斗部和投放平台的工程固化。

空投纤维毯子母弹的技术基础可落在柔性载荷封装、散布建模、低功耗节点和近距识别算法上。它解决的是道路、集结地域或临时补给线中目标短时出现、传统火力难以持续盯防的问题。验证重点不是单个节点峰值性能，而是落区风场、地表材质、节点密度、目标混杂程度变化后，是否仍能提供足够覆盖、识别和触发约束。失效判据应包括节点覆盖明显稀疏、目标转向非覆盖路线、民用车辆与重点装备混杂导致识别规则过严；一旦出现这些情况，该装备只能提供迟滞和心理压制，不能按选择性精确打击能力计算。

砂幕啮合拦截弹的技术基础可依托近程拦截、弹载闭环控制、颗粒材料和终端相对运动估计。它的价值在于以较低成本形成面状毁伤/干扰窗口，对小型来袭目标或脆弱部件目标实施拦截，补上传统点杀伤拦截对末段精度和成本的压力。验证重点应放在释放窗口、颗粒云密度、相对速度、来袭角度、强杂波和诱饵条件；当目标速度过高、机动过大、来袭角度不利，或末段跟踪被杂波和诱饵扰乱时，颗粒云可能错位或密度不足。对重装甲目标、极高速弹体和近距离友邻空域，该方向不宜作为主拦截手段。

“烛龙”盘旋攻顶弹的技术基础可来自巡飞弹、微小型光电/红外复合传感、目标保持跟踪、弹载任务管理和定向战斗部。它主要改变时敏装甲目标、指挥车、火力发射车等“短停即走”目标的交战结果：弹药先在目标可能活动区监视，发现目标后由监视状态切换到攻顶状态，以较薄弱顶部作为毁伤入口。验证重点应覆盖长时间盘旋后的目标再捕获、烟尘/天气遮蔽、假目标相似度、敌方电子压制和盘旋空域压制。若目标长期处于坚固遮蔽下，或俯视传感持续失效，单弹闭环优势会明显下降，必须转入外部侦察引导或其他火力补击。

体系技术基础应围绕“补链、强链、替代链”建设。补链用于侦察节点受损后由弹上感知、临近无人节点或地面传感临时接续；强链用于关键火控、授权和毁伤评估数据的多路径传输；替代链用于主通信、主定位或主指挥节点失效后维持最低可用任务流程。美国“复制者”计划公开强调大量可消耗/自主系统方向，美国海军陆战队远征前进基地作战和部队设计公开材料强调分布式、机动、低特征和较易保障的力量设计，这些可支撑本项目把“数量、分散、可替换、可降级”作为体系韧性设计参照。证据边界是：公开材料只能说明国外能力建设趋势，不能直接推出本项目具体指标。

建设优先序建议采用先软件链路、后弹药分型、再体系演训的路径。第一阶段完成目标状态数据、火控授权、弹药任务指令、毁伤评估回传和失联降级接口；第二阶段分别验证三类弹药的专属末段机理；第三阶段在通信受限、数据不完备、节点损毁和对手诱骗条件下进行压力测试。判定项目具备研制基础的核心标准，不是单发命中演示，而是在关键节点受压后仍能保持监视、授权、打击、评估和再组织的最低闭环能力。
