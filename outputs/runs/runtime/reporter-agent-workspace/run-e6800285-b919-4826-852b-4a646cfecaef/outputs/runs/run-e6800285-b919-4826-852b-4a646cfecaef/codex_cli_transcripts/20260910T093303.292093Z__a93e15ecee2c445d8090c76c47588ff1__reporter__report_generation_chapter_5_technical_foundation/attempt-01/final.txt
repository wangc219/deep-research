# 五、研制基础

## （二）技术基础

本项目可继承的基础主要集中在小型飞行平台、弹载光电与红外感知、被动射频侦测、飞控导航、任务计算、数据链和精确毁伤等通用工程领域。现有公开材料能够证明分布式作战、低成本规模化无人系统和受扰条件下持续行动是明确发展方向，但未提供上述具体装备已经定型、批量生产或完成作战试验的证据。因此，研制重点应放在既有部件的工程集成、失联条件下的自主控制、目标状态判定和安全授权闭环，不能把概念能力直接视为成熟装备基础。

| 装备 | 可继承基础与新增工作 | 可研缺口、试验和供应链条件 |
|---|---|---|
| 百链分散攻击巡飞弹 | 可继承小型巡飞弹的飞控、导航、光电和红外载荷基础；新增被动多源线索融合、弹间局部关联和多方向接敌控制，使部分弹体失效后仍能保持攻击路径。 | 缺少通信受扰、诱饵混杂条件下的目标区分和群体接替证据。需开展单弹抗干扰、弹间协同、批量一致性和末段安全性试验；低成本传感器、导航器件、动力和载荷需具备规模化供应条件。 |
| 低换高耗攻击巡飞弹 | 可继承低成本机体、动力、电源、任务计算机和一次性载荷；新增目标区域分散部署、末端自主选择和批量制造后的飞控校准。 | 缺少在目标信息不完整时区分真实目标、诱饵和非目标的试验依据。应验证低算力识别、失联决策、航迹差异和批量性能离散，供应链重点是标准化接口、低功耗载荷与可替换动力组件。 |
| 时敏断窗打击导弹 | 可继承精确制导、外部目标指示、弹上导航和常规战斗部基础；新增“先局部拒止、后定向毁伤”的双阶段任务管理、状态更新和可中止安全逻辑。 | 缺少不完整确认条件下的授权边界、阶段转换判据及拒止效果可复核证据。试验应覆盖间歇通信、目标换位、载荷转换和附带风险控制；双阶段载荷、引信和控制接口是供应链短板。 |
| 相变门控前置拦截弹 | 可继承高速拦截弹的弹体、制导、飞控和末端毁伤技术；新增受控前置压制、门控状态转换及其与航迹更新的实时耦合。 | 相变结构在高速过载、振动和热环境下的可重复换态能力没有公开证据。需先完成材料与门控机构环境试验，再开展压制—终端毁伤连续闭环验证；关键材料、执行机构和安全控制器需建立稳定来源。 |
| 低耗复用突击无人机 | 可继承可回收无人机平台、模块化挂载、短距通信和任务计算基础；新增分批释放、先期接敌确认、剩余单元再分配及载体撤离控制。 | 缺少释放后载体稳定性、单元互不干扰和目标变化下再次接敌的试验数据。应验证挂载接口、释放时序、局部拦截环境下的控制保持和回收航路；载体结构、释放机构及低成本突击单元需分别组织供应链。 |
| 并行围断攻击巡飞弹 | 可继承巡飞弹导航、末端感知和精确毁伤部件；新增弹间状态判定、条件化补击、相互避碰和目标功能失能识别。 | 缺少“目标暂时停机”与“目标已失能”的可靠区分方法。需进行断续数据链、多方向到达、功能状态识别和终止投入试验；重点保障弹载计算、近距通信和低成本传感器的一致性。 |
| 瞬窗跃层攻击无人艇 | 可继承水下无人航行器、水面无人艇、声学探测和自主导航基础；新增水下接近、水面低特征机动与跃层攻击的一体化控制。 | 跨介质转换中的浮力、推进、姿态和末段识别尚无装备级证据。应开展池试、近岸海况、跃层冲击、声光电异步融合和通信中断试验；可变浮力系统、耐冲击艇体和跨介质推进是专用供应链。 |

总体上，最具近期研制条件的是可沿用现有小型无人平台和弹载感知部件的分散攻击、低换高耗及并行围断类装备；双阶段作用、相变门控和跨介质跃层装备新增技术跨度更大，应先完成材料、结构和环境适应性验证。所有装备均须以通信受扰、信息不完整、诱饵干扰和误识别代价为边界开展试验，公开资料尚不足以支撑确定的性能点值、批产成熟度或既有单位承研结论。
