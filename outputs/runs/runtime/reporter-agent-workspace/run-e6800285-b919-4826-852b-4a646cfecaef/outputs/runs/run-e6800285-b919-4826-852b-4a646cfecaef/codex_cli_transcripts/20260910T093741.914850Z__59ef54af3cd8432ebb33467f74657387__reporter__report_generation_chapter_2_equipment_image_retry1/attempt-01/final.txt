二、项目画像

（一）装备图像概述

| 装备主体 | 核心技术与形成能力 | 部署或进入方式 | 关键动作、作用对象与直接效果 |
|---|---|---|---|
| 百链分散攻击巡飞弹 | 由大量可消耗弹体组成，每枚配置被动光电、红外或射频感知和精确毁伤载荷；依靠弹上局部关联与分散冗余，在通信受扰或部分损失后仍保持有限接敌能力。 | 在高价值时敏目标短暂暴露、即将转移或传统集中链路可能中断时，多枚弹体从不同方向分散进入目标活动区域，减少对单一发射平台、指挥节点和通信频段的依赖。 | 各弹体持续搜索并关联目标，从多方向压缩机动、隐蔽和转移窗口；对确认目标实施直接毁伤，迫使敌方分散防空、电子压制和诱饵资源。其效果取决于失联条件下仍能区分真实目标与诱饵。 |
| 低换高耗攻击巡飞弹 | 以低成本、可批量部署和末端自主选择为核心，通过多方向并发航迹增加敌方探测、识别、分配和拦截负担；重点不是单弹性能，而是以数量换取高价值拦截资源和目标恢复时间。 | 预先将弹体分散配置于目标可能活动区附近，目标刚开机、装填、恢复通信或暴露关键载荷时，各弹体从不同方向进入攻击距离。 | 弹体依据末端获得的电磁、热迹或载荷特征选择真实目标、雷达面、通信天线或发射及补给车辆；即使部分弹体被诱导或拦截，余弹仍可造成直接毁伤或任务中断，迫使敌方提前暴露防护体系。 |
| 时敏断窗打击导弹 | 采用双阶段作用，在目标身份尚未完全稳定但位置、运动和高价值行为达到授权边界时，先实施可复核的局部机动拒止或压制，再依据状态更新完成定向终端毁伤，把确认等待期转化为可利用的作用时间。 | 当目标暴露后即将转移、隐蔽、换乘或切换身份，且多源信息已达到可授权程度时提前介入，不等待完整情报闭合；目标状态变化后由弹上与外部信息共同修正作用阶段。 | 首阶段作用于目标周边道路、掩体入口、护卫或机动通道，限制其撤离和身份切换；状态收敛后转入目标本体或关键功能点毁伤，直接打断指挥、发射、补给或撤收流程。若识别或附带风险不满足边界，应终止作用。 |
| 相变门控前置拦截弹 | 以相变门控结构连接前置压制与终端毁伤，使作用强度和阶段随目标身份、航迹置信度变化而调节；目标变轨、静默或释放诱饵时，拦截链不必完全重置。 | 接入多源航迹和拦截指挥，在目标尚未完全确认但已进入可作用范围时发射；先以受控方式接敌，随目标状态更新逐步收敛至终端处置。 | 初段压制目标机动、制导或通信能力，减少其通过一次变轨争取完整等待窗口的可能；确认边界收紧后触发终端毁伤，直接降低突防和任务完成概率。成立前提是门控结构、飞控和终端作用能够稳定切换。 |
| 低耗复用突击无人机 | 将可回收飞行载体与多枚低成本一次性突击单元分离，形成“先期接敌、状态确认、分批释放、转向撤离”的可调整能力；把载体生存风险与单次攻击消耗分开。 | 载体进入目标附近后不立即释放全部单元，而是在保持接近和撤离余度的情况下，先投入少量单元试探或阻断目标，再根据目标状态和敌方防御反应决定后续动作。 | 先期单元作用于目标机动、护卫或局部关键部位，迫使目标停车、转向、关机或暴露防御火力；确认仍具价值后释放剩余单元集中攻击，目标转移则保留载体并调整方向，直接形成补击或任务中断效果。 |
| 并行围断攻击巡飞弹 | 由多枚可独立部署弹体构成围断单元，具备弹间解耦、局部状态判定和条件化补击能力；首击未完成任务时，余弹不机械重复攻击，而按目标是否仍能机动、发射、通信或作业决定接替。 | 在目标进入短暂暴露或即将恢复关键任务时，从多个方位同时接近并保持持续存在；各弹体保留不同进入方向和补击位置，降低单点拦截或单向诱饵的作用。 | 首枚针对关键设备实施主要毁伤，余弹作用于仍具任务价值的发射、通信、机动或雷达部位；目标失去功能后停止投入，直接把一次命中机会转化为连续失能窗口，避免无效重复消耗。 |
| 瞬窗跃层攻击无人艇 | 具备水下隐蔽接近、水面低特征机动和短时跃层攻击能力，依靠跨介质姿态控制、目标关联和末段导引打破水下、水面与岸基传感器的连续跟踪。 | 面向近岸或海上目标，从水下状态接近目标区域；在目标换位、补给、通信或火力准备造成短时暴露，且敌方尚未完成跨域关联时转入水面并实施跃层突入。 | 先利用水下隐蔽压缩距离，再以低特征水面机动修正攻击角度，跃层作用于近岸指挥、侦察、火力或保障节点，直接造成目标毁伤或行动中断。效果边界在于跨介质转换、复杂海况和末段识别必须保持闭环。 |
