## 三、总体方案

### （一）总体架构

总体架构围绕“目标状态、任务权限、可用资源和交接结果”建立，不把单件装备的感知或毁伤机理上提为公共层。体系共享的最小状态包括目标身份与位置置信度、是否仍具机动、通信、发射或指挥功能、附带风险边界、可用接敌窗口及各装备剩余弹量、能量和通信状态；任务指挥单元据此实施授权、撤销和降级控制，而非要求所有装备持续接受同一中心节点指挥。

侦察与指挥节点确认目标进入时敏窗口后，百链分散攻击巡飞弹承担受扰条件下的分散搜索和多方向持续接敌，低换高耗攻击巡飞弹承担目标区域占位及多航迹消耗防御资源；二者只共享必要的目标约束、禁攻边界和局部状态，避免单点链路中断导致整体停摆。并行围断攻击巡飞弹接收目标功能状态，首击后仅对仍能机动、通信或继续作业的关键设备实施补击；低耗复用突击无人机则以可回收载体保留后续释放权限，根据先期突击引出的真实位置和防御反应决定追加攻击或撤离。

时敏断窗打击导弹与相变门控前置拦截弹共用授权边界和状态更新接口，但作用阶段不同：前者在确认尚未完全闭合时先形成局部拒止，再转入定向毁伤；后者依据身份、航迹置信变化连续调节前置压制与终端拦截。瞬窗跃层攻击无人艇接收海上目标提示和禁入区域信息，在水下接近、水面机动与跃层攻击之间自主切换，并将目标中断、转移或未形成战果的状态交回后续火力。

体系失败具有耦合性：目标状态失真会同时放大误击、错误补击和错误释放风险；授权链中断会使导弹无法转段、巡飞弹无法接替，海上平台也可能错过跃层窗口；局部通信受扰时，百链、低换高耗和并行围断仍须依靠本机状态完成有限任务，低耗复用无人机则保留载体撤离优先权。总体建设应优先保证状态定义、权限边界和交接结果可审计，具体性能参数须在不同目标类型、海空环境和受扰条件下分别验证。
