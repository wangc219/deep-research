一、需求分析

（一）需求概述

1. 背景分析

高价值时敏目标正由固定、持续暴露的目标，转为依托机动平台、短时开机、伪装诱饵、快速转移和电子压制实施间歇性活动的目标。其价值可能集中在指挥、远程火力、雷达、通信、补给或近岸行动节点，暴露时间却短于传统“发现—稳定跟踪—集中授权—火力到达”的处理周期。现有作战链一旦依赖少量传感器、单一指挥节点或单条射手航路，目标改道、静默或切断链路就可能使前序确认失效，造成发现成果无法转化为直接军事效果。

这一矛盾在三类条件下更加突出：正常联网时，多节点串行处理和授权等待侵蚀目标窗口；信息不完整时，确认可信度与快速处置相互牵制，过慢会失去目标，过快又可能误击诱饵；受干扰或节点失效时，集中式闭环容易由局部中断扩展为整体停摆。对手因此可以用一次机动、一次干扰或一次拦截，恢复高价值目标的行动自由。需求的核心不是抽象地追求更快，而是要在目标状态持续变化、交战规则和附带风险受约束的情况下，把有限信息及时转化为可控、可复核的直接效果。

2. 需求阐述

装备需求首先体现为对单点打击链的替代。百链分散攻击巡飞弹需要以大量可消耗单元分担搜索、局部关联和末段毁伤，使通信受扰或部分弹体损失不再等同于任务中止；低换高耗攻击巡飞弹则需要把低成本弹体预置到目标可能活动区域，在目标短暂暴露时从多方向形成压力，弥补少量高价值弹药等待集中确认、容易被逐枚拦截的缺口。二者的需求重点不同：前者解决单点失效和通信依赖，后者解决拦截资源与目标暴露时间之间的不利交换。

时敏断窗打击导弹需要解决“确认尚未完全闭合但目标正在逃逸”的矛盾，使装备能够在授权边界内先形成受控拒止或局部压制，再依据更新状态实施终端毁伤；相变门控前置拦截弹面对的是高速变轨、短时静默和诱饵造成的身份不确定性，需求在于让作用强度随目标置信度变化，避免一次识别变化导致拦截流程重置。低耗复用突击无人机则需要把一次性接敌改成分阶段投入，由可回收载体保留后续选择权，以少量突击单元换取目标状态和防御反应信息，填补目标变化后无法补击、平台与弹药同时损失的空缺。

并行围断攻击巡飞弹的需求不在于简单增加弹量，而在于让多枚弹体依据目标是否仍具机动、发射、通信或作业能力决定接替补击或终止投入，从而把首击未遂转化为连续失能压力。瞬窗跃层攻击无人艇针对近岸和海上目标的单一介质暴露问题，需要在水下隐蔽接近、水面低特征机动与短时跃层攻击之间形成连续能力，避免水面平台过早暴露、水下平台来不及完成确认。上述需求共同指向三个缺口：受扰条件下的局部自主、信息不完整时的可控决策，以及部分失效后仍能保留直接军事效果；具体适用目标、窗口长度、误识别容忍度和交战授权边界仍需由任务场景进一步确定。

3. 项目画像

本项目研发的装备群，作用不是替代全部侦察、指挥和远程火力，而是把目标发现后的短暂优势转化为可兑现的末段行动。百链分散攻击巡飞弹以分散感知和多方向接敌压低单点失败代价；低换高耗攻击巡飞弹以规模化低成本存在迫使对手分散高价值拦截资源。时敏断窗打击导弹把目标等待确认的时间变成受控压制窗口，相变门控前置拦截弹则把航迹不确定性转化为持续分级作用。低耗复用突击无人机依靠载体复用和单元分批消耗延长接敌时间，并行围断攻击巡飞弹通过条件化补击确保关键设备在任务窗口内真正失能，瞬窗跃层攻击无人艇则利用跨介质突入打乱近岸防御的目标关联。

这些装备形成的制胜增量，是使对手不能再依靠一次转移、一次干扰、一次诱饵或一次拦截恢复安全状态。其作战前景体现在：目标必须缩短开机和停留时间，增加护航、诱饵和分层防御力量，或分散任务节点以降低单点损失；但分散和隐蔽又会削弱通信效率、机动协同和任务恢复速度。装备价值成立的边界也很明确：弹上目标判定、受扰降级、作用阶段转换和跨介质控制必须可靠，且快速行动不能突破识别可信度、授权责任和附带风险约束。若这些条件不能闭合，数量优势、前置作用或跨域突入就可能转化为无效消耗和误伤风险。
