## 二、项目画像

### （二）作战运用模式

#### 1. 作战运用流程

高价值时敏目标依托机动、伪装、短时开机、诱饵和电子压制转移时，作战进入条件不是“发现即发射”，而是目标价值、位置变化趋势、授权边界和附带风险已达到可执行范围。不同装备针对的任务断点不同：百链分散攻击巡飞弹用于把短暂发现转化为多方向持续接敌；低换高耗攻击巡飞弹用于在目标可能活动区预先形成低成本压力；时敏断窗打击导弹用于在确认尚未完全闭合时先实施可复核拒止，再完成终端毁伤；相变门控前置拦截弹用于目标航迹和身份持续变化时维持分级拦截作用；低耗复用突击无人机用于分批试探、牵制和集中攻击；并行围断攻击巡飞弹用于首击未能使目标失能时接替补击；瞬窗跃层攻击无人艇则面向近岸和海上目标，通过水下接近、水面机动和跃层突入制造跨介质攻击窗口。

百链分散攻击巡飞弹释放后，各弹体依靠独立的被动光电、红外或射频线索维持局部目标关联，从不同方向压缩机动指挥车、远程火力或通信节点的转移时间。敌方若实施集中干扰、单向诱饵或优先拦截，剩余弹体仍保持有限接敌能力，迫使目标在停留、改道、隐蔽和继续任务之间取舍，直接结果是增加目标暴露和被毁伤机会。低换高耗攻击巡飞弹则强调先占位、后选择：多个低成本弹体进入目标可能活动区，在发现雷达、通信天线、发射车辆或补给节点后独立选择末端对象。敌方必须在真实目标与诱饵、多方向航迹及有限拦截资源之间重新分配力量，因而承担防空弹药消耗、阵地暴露和任务中断代价。

时敏断窗打击导弹的进入条件是目标位置、运动趋势和高价值行为已越过授权边界，即使尚未形成完整确认也不能继续等待。导弹首阶段对目标周边机动通道实施受控拒止或局部压制，使目标减速、改道、停止关键行为或暴露通信；随着状态更新，再转入定向终端毁伤。这样，敌方不能仅靠一次转移或身份切换恢复安全。相变门控前置拦截弹面对的是高速变轨、短时静默和诱饵制造的确认间隙，先以受控前置作用削弱目标机动、制导或通信能力，待身份和航迹置信边界收敛后再转入终端毁伤，直接压缩其突防和规避时间。

低耗复用突击无人机不一次投入全部攻击资源。可回收载体先以少量一次性突击单元接敌，迫使目标停车、转向、关机或暴露护卫火力，再依据目标状态决定集中释放剩余单元，若窗口收窄则保留载体转向或撤离。其直接战果既包括毁伤目标，也包括延长有效接敌时间和迫使敌方持续消耗拦截资源。并行围断攻击巡飞弹由多枚弹体从不同方向保持威胁，首枚实施主要毁伤，其余弹体根据目标是否仍能发射、通信、机动或维持作业决定是否补击；目标失去任务功能后停止投入，避免将剩余弹药机械消耗在无效对象上。

瞬窗跃层攻击无人艇用于近岸港湾、岛礁遮蔽和海上航路中的短时暴露目标。平台先以水下状态隐蔽接近，再以水面低特征机动修正攻击角度，在水面、声学和岸基防御完成连续关联前跃层攻击。敌方若扩大水下巡逻、水面警戒和岸基快速反应力量，就必须在更大空间内维持多域监视；若继续依赖诱饵和短时静默，则可能因介质转换造成跟踪断裂。其直接结果是击毁近岸指挥、侦察或火力节点，或迫使其停止航行、补给和通信活动。

#### 2. 链路闭环分析

上述装备并非以统一流程替代现有侦察、指挥和火力体系，而是分别填补“确认后等待”“单点受扰即中断”“一次接敌即失效”“首击未果即退出”和“单一介质持续暴露”等断点。百链分散攻击巡飞弹以弹体数量和局部自主降低单一节点失败代价；低换高耗攻击巡飞弹以低成本规模换取敌方高价值拦截资源和任务恢复时间；时敏断窗打击导弹把确认等待期变成可控拒止期；相变门控前置拦截弹把状态不确定性转化为分阶段作用；低耗复用突击无人机把载体生存与单元消耗分离；并行围断攻击巡飞弹把一次命中改为按目标功能状态连续补击；瞬窗跃层攻击无人艇则以跨介质突入打乱敌方目标关联。

其共同制胜链条是：在目标仍具有任务价值且窗口即将关闭时进入，以装备自身的感知、控制或作用机理改变敌方状态，使其机动、通信、发射、指挥或防护行为受到限制，再形成直接毁伤、功能性失能或任务中断。对手的反适应也会随装备不同而变化：面对分散弹体，需要增加多方向探测和拦截；面对断窗导弹，需要缩短暴露、增加诱饵并拆分关键行为；面对门控拦截弹，需要减少变轨和通信依赖；面对复用无人机，需要同时追踪载体和突击单元；面对围断攻击，需要持续确认目标功能状态；面对跃层无人艇，则必须建立水下、水面和岸基传感器的快速关联。

退出或中止条件均应服从装备机理：识别置信度不足、附带风险越界、目标失去任务价值或作用链路无法保持时停止投入；但不能把“通信中断”一概等同于任务失败。分散巡飞弹和围断弹应保留局部自主与接替能力，断窗导弹和门控拦截弹应保留可复核、可调整的阶段转换边界，复用无人机应保留载体撤离和再选择窗口，跃层无人艇则应在跨介质转换风险上升时维持隐蔽脱离。最终能否形成稳定战果，取决于各装备自身的目标判定、抗干扰控制、作用转换和安全终止是否闭合；公开材料尚不足以确认具体参数和装备级战果，相关判断应通过不同目标状态、信息完整度和受扰条件下的实装验证加以界定。
