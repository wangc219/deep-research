五、研制基础

（一）参与单位

本项目公开材料未能确认具体承研单位、产品分工和现有试验合同，参与单位宜按装备产品责任、关键接口和证据交付划分为机构类型，不宜直接指定名称。百链分散攻击巡飞弹应由具备低成本弹体总体、被动光电／红外／射频载荷集成和弹间通信研制能力的导弹或无人系统总体单位牵头，配套单位负责端侧目标关联、抗干扰导航、局部协同和批量制造；需由电子对抗试验机构、靶场和鉴定机构共同证明部分弹体失联或受损后仍能保持局部接敌，而非仅提交单弹命中数据。

低换高耗攻击巡飞弹的责任重点是规模化投送、末端自主选择和成本可控，适合由具备巡飞弹批产、弹载任务计算机和低成本飞控能力的总体单位承担，配套批量动力、电源、导航及载荷供应单位；试验单位应重点交付诱饵、干扰、分层拦截条件下的目标选择与剩余弹体效果证据，公开资料尚不足以判断其已有批产线和一致性保障能力。

时敏断窗打击导弹需要导弹总体单位联合制导控制、双阶段战斗部、引信和任务授权接口单位，产品责任不能由单一传感器或指挥系统单位替代。试验应由具备动态目标、局部拒止、状态更新和终端毁伤评估条件的靶场承担，交付“拒止—复核—毁伤”连续证据；目前缺少公开的授权接口、阶段转换判据及安全审查归属。

相变门控前置拦截弹需由高速拦截弹总体单位统筹门控结构、前置压制载荷、末段制导和终端毁伤，材料、热防护和执行机构单位承担关键部件责任。必须配置高速飞行、复杂环境和目标持续变轨条件下的门控切换试验及独立鉴定机构，现有公开依据不能确认相关材料工艺、环境适应性和试验资格。

低耗复用突击无人机应区分可回收载体总体单位与一次性突击单元研制单位，并由飞控、释放机构、短距通信和回收保障单位共同完成接口闭合。试验责任应覆盖分批释放、载体保留、转向撤离和再次出动，需交付载体生存、释放可靠性和任务再组织证据；公开资料未显示具体回收体系及批量保障主体。

并行围断攻击巡飞弹需要巡飞弹总体单位与分布式任务管理、弹间避碰、功能状态识别和战果评估单位协同，试验机构应证明首击未遂时的接替补击、目标失能后的终止投入和通信受限运行。瞬窗跃层攻击无人艇则应由跨介质无人艇总体单位牵头，联合艇体推进、声学感知、低特征水面航行和海上靶场单位，重点交付水下接近、跃层控制、跨域目标关联和末段攻击证据。上述两类装备的具体承研单位、海试条件、鉴定权限及供应链成熟度，当前均缺少公开可核实依据，需在立项阶段补齐。
