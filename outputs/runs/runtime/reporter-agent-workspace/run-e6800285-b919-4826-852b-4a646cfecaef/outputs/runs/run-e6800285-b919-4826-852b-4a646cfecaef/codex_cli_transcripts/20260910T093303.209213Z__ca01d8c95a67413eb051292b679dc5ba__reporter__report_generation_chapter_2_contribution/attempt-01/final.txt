## 二、项目画像

### （三）体系贡献率分析

在目标类别、作战阶段、窗口长度和可接受误识别风险尚未进一步限定的情况下，本栏不将体系贡献率虚构为可加总的百分比，而按各装备相对于现有单一平台、单一航路或单阶段打击基线所填补的任务断点进行比较。七类装备的贡献并非同质叠加：有的解决通信受扰后的链路持续问题，有的改变攻防成本交换，有的把确认等待转化为可利用的作用时间，有的则从水面、水下等不同接敌介质改写防御方的目标关联方式。

**百链分散攻击巡飞弹**主要填补“目标已被发现但集中打击链尚未闭合”的断点。传统少量平台需要依赖连续跟踪、集中授权和稳定通信，敌方通过短停快转、电子压制或摧毁关键节点即可使打击中止。该装备将感知、局部目标关联和精确毁伤分散到大量可消耗弹体，使各单元能够从不同方向保持有限接敌关系；部分弹体被干扰、误导或拦截后，剩余单元仍可能继续压缩目标转移窗口。它直接改变了敌方的防护任务：对手不能只打断一条指挥链，而要同时处理多个来向、多个感知特征和多个末段威胁。其不可替代的增量是降低单点失败对整体任务的影响，直接战果则表现为提高目标在短暂暴露后仍被持续追击和毁伤的可能性。若弹载多模感知不能在诱饵、遮蔽和失联条件下区分真实目标，数量优势将转化为误伤和无效消耗。

**低换高耗攻击巡飞弹**的贡献重点不在局部链路韧性，而在改变拦截资源与攻击弹药之间的价值交换。相对于少量高价值弹药等待完整坐标、集中授权后实施单方向突入，该装备可预先分散进入目标可能活动区域，在目标刚开机、装填、恢复通信或暴露关键载荷时，由多个方向同时逼近并独立选择末端对象。敌方若逐枚拦截，就以昂贵防御资源换取低成本来袭体；若转入电子压制和近程火力，又会暴露防区位置并中断自身任务。由此形成的直接效果不仅是摧毁真实目标或关键载荷，还包括压缩其伪装、转移和任务恢复时间，使敌方难以在拦截后迅速恢复原有秩序。其贡献会在目标区域难以预先判断、弹体无法低成本持续部署或末端自主选择可靠性不足时明显衰减。

**时敏断窗打击导弹**针对的是“目标行为已经显示高价值，但完整确认和授权仍慢于目标转移”的时间断层。传统单阶段终端打击往往把确认等待全部置于毁伤之前，目标可利用这段时间撤收、换乘、隐蔽或切换身份。本装备先在授权边界内实施可复核的局部机动拒止或压制，限制目标继续转移，再依据更新状态完成定向终端毁伤，因此把原本只能等待的确认期转化为受控施压期。它的直接增量是打断指挥转移、发射准备、补给或撤收等行动连续性，为后续火力和侦察留下连续窗口；敌方若规避，必须增加诱饵、护卫和分散中继，牺牲协同效率。该贡献严格依赖授权边界清晰、状态更新不断链以及初段作用可复核，否则“先压制后确认”可能扩大误击和附带风险。

**相变门控前置拦截弹**填补高价值时敏目标在身份、航迹尚未完全收敛时的拦截空档。传统拦截弹通常在确认完成后实施固定阶段、固定效应的终端打击，目标一旦变轨、静默或释放诱饵，拦截链便可能重新计算。该装备把确认程度转化为作用阶段和作用强度的连续调整，先以受控前置效应削弱目标机动、制导或通信能力，待置信边界收紧后再转入终端毁伤。其制胜增量是压缩目标利用不确定性换取的等待时间，使一次规避动作不再自动恢复安全。敌方若增加诱饵和变轨，便要承受更高的协同、通信和护航代价。若门控结构受高速过载、热环境影响而提前释放或无法稳定切换，或前置作用无法与外部航迹更新闭合，该装备将退化为普通拦截弹，甚至提高误击风险。

**低耗复用突击无人机**改变的是一次性接敌的风险分配。现有一次性攻击平台往往必须在目标状态不稳定时押注全量突入，目标移动或诱饵暴露后，载体与载荷一并失去价值。本装备由可回收载体和多枚低成本突击单元构成，先释放少量单元进行短暂接敌、阻断机动或局部毁伤，再依据目标状态和敌方防御反应决定集中释放、延迟攻击或撤离转向。它将“发现即决胜”改成“试探、牵制、确认后再投入”，把载体生存与单次毁伤风险分离。直接战果既可以是目标毁伤，也可以是迫使其停车、关机、改道或暴露护卫火力，从而创造新的补击窗口。敌方必须在拦截廉价单元、追击载体和保护目标之间反复分配资源。若载体无法在受扰条件下维持控制、释放接口和回收航路，该装备的复用优势会退化为一次性突击。

**并行围断攻击巡飞弹**相对于分散攻击的独特贡献，是把首击后的目标功能状态纳入后续火力分配。传统单枚弹体押注一次命中，敌方只需完成一次有效拦截、短时静默或单向诱骗即可恢复行动自由。本装备由多枚弹体从不同方位持续接近，首枚实施主要毁伤，其余单元根据目标是否仍能机动、发射、通信或维持作业决定接替补击；目标失去任务功能后，剩余弹体终止投入。由此直接效果从“可能命中”提升为在窗口内实现关键设备的功能性失能，并避免对已经失效目标重复消耗。敌方必须持续覆盖多个方向并反复确认每个威胁，因而承担更高的探测、拦截和误判成本。若弹体不能在失联和复杂背景下可靠判断目标功能状态，围断就会退化为多枚单次攻击。

**瞬窗跃层攻击无人艇**填补近岸或海上目标在不同介质探测链之间的关联缺口。水面平台持续接近容易被雷达、光电和岸基火控提前标定，纯水下平台则可能难以在短窗口内完成目标确认和攻击姿态调整。本装备先以水下状态隐蔽接近，再转入水面低特征机动，并在目标因换位、补给、通信或火力准备而暴露时完成跃层攻击，使防御方必须重新拼接水下、水面和岸基传感器获得的目标片段。其直接增量是以较小持续暴露换取近岸高价值节点的短促毁伤窗口，并迫使敌方扩大多域巡逻、快速反应和诱饵鉴别范围。该优势在复杂海况、民用航迹密集、跨介质姿态控制不稳或艇端目标关联迟缓时会衰减；若跃层动作暴露过早，平台仍会回到传统水面接敌的劣势。

综合看，百链分散攻击巡飞弹和低换高耗攻击巡飞弹主要提高体系在受扰和高消耗环境下的持续施压能力，但前者侧重局部闭环不断裂，后者侧重以低成本制造防御过载；时敏断窗打击导弹和相变门控前置拦截弹主要压缩确认等待造成的时间损失，但前者以先期拒止争取复核时间，后者以阶段可调作用维持拦截连续性；低耗复用突击无人机通过保留载体增加再选择权，并行围断攻击巡飞弹通过状态触发补击提高功能性失能概率，瞬窗跃层攻击无人艇则从接敌介质变化中取得近岸突入优势。最终贡献率仍须以具体目标类型、窗口长度、授权规则、误识别代价和受扰工况进行实测比较；在这些变量明确前，建设重点应优先放在能够直接减少任务窗口损失且可审计控制风险的装备能力上。
