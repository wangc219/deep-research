五、研制基础

（一）参与单位

本项目参与单位不能按通用“总体、分系统、试验”平均配置，应依据装备的产品责任和直接战果确定。百链分散攻击巡飞弹需由具备巡飞弹总体设计、弹载被动光电/红外/射频感知、抗干扰导航和末段毁伤载荷集成能力的单位承担主体责任；其关键接口是弹上目标关联、失联续链、弹间低带宽协同和引信控制，试验单位应重点提供通信受扰、诱饵混杂、部分弹体损失后的群体接敌证据。公开材料不足以确认具体承研单位、批量一致性水平和实装试验结果。

低换高耗攻击巡飞弹的主体应是能够完成低成本弹体、批量制造、末端自主选靶和模块化载荷接口设计的单位，不能直接沿用高端精确弹药的承研模式。其配套单位须负责低算力识别、失联决策、动力电源管理及批次飞控校准，试验责任应落到多方向同时逼近、部分拦截后剩余弹体继续任务和误识别约束上。现有公开依据未能证明该类装备已有稳定批产或实战化验证。

时敏断窗打击导弹需要承担双阶段任务链的导弹总体单位，并配置目标状态融合、抗间歇通信、局部拒止载荷、阶段转换控制和终端毁伤单位。其关键证据不是单次命中率，而是“拒止—更新—毁伤”能否在授权边界内连续切换；试验应覆盖目标换位、身份不确定、附带风险上升时的中止与脱离。公开资料缺少具体单位归属、双阶段载荷成熟度及授权接口验证。

相变门控前置拦截弹还需引入具备门控材料、受控压制载荷、高速飞行环境适应和弹上实时控制能力的专业单位。材料与战斗部单位对门控换态可靠性负责，导引与飞控单位负责前置作用、航迹更新和终端毁伤的闭环试验；目前没有公开证据证明该结构已形成装备级样机或环境试验数据，不能指定承担机构。

低耗复用突击无人机的核心承研者应同时具备可回收载体、一次性突击单元、分批释放机构和载体再任务控制能力；其供应链需覆盖释放接口、载体稳定控制、短距抗干扰通信及回收保障。试验单位应验证先期接敌后追加释放、目标转移时撤离转向和载体不被单次拦截牵连。公开信息未显示具体单位是否具备完整复用链路。

并行围断攻击巡飞弹需要由分布式弹群总体单位负责弹间状态判定、航迹解耦、接替补击和失能确认，试验机构应提供多方位接敌、首击未遂、短时静默及终止投入的证据。瞬窗跃层攻击无人艇则应由跨介质无人平台单位牵头，联合水下航行、跃层姿态控制、声光电融合和近程毁伤单位，重点验证复杂海况下的潜航—出水—攻击连续性。两类装备均缺少公开的具体承研主体和装备级试验记录，参与单位应在合同中明确产品责任、接口交付物和可审计验证边界。
