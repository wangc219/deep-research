## 二、项目画像

### （四）主要战技指标

群栖自组巡飞精打弹的判别重点，不在单弹航程，而在受GNSS压制、链路间歇时能否维持群内自主分配。应看失链后目标重分配时延、伪目标条件下的一致识别率、末端轮换后仍能完成打击评估的闭环率，这三项分别对应继续接敌、避免误判和保持连续压制。相对依赖外部指令逐目标分派的常规巡飞弹，它的价值是把识别、轮换和毁伤判断前移到弹群内部；若失链后只能各飞各的，这类弹就失去“多弹共识”的压制效果。

蜂簇接力巡猎精打弹不能只看单次命中，而要看前导单元是否真能换来后续单元的穿透窗口。指标应抓释放间隔稳定性、前导单元对敌方搜索与拦截资源的牵制持续时间、后续单元在防空暴露后的命中保持率。它的直接战果是把一次打击拆成连续回合，迫使对手反复换防；若接力节奏失稳，就只剩数量堆叠，难以形成持续消耗。

气膜掠波隐巡击弹的关键，不是跑得多快，而是在超低空贴波时是否还能把自己压在海面背景里。应以贴波高度稳定性、海杂波条件下的目标捕获距离、末端俯冲偏差作为主指标，分别对应隐蔽接敌、可用识别和命中精度。相对一般低空巡飞弹，它的制胜点是缩短敌方雷达可见窗；若高度控制一乱，掠波优势会迅速消失。

形记忆折展巡飞精打弹的判别点，是结构切换是否真能转成战术机动。要看折展展开成功率、巡航到接敌的切换时间、切换后盘旋半径压缩幅度，这三项分别对应远程抵近、临机变向和逼近后的重新选角。它比传统固定翼弹更有机会在接敌末段改写拦截窗口；若展开慢或形变不稳，所谓折展优势就只剩结构概念。

磁流体矢控巡飞精打弹的指标，应围绕“临时改航”是否足够快、足够难预判来设。重点不是一般操稳，而是侧向偏转响应时间、最小可实现转弯半径、连续机动后的航迹重复度；前两项决定能否突然折向岸防雷达和导引站，后一项决定对手能否靠经验预判。它的制胜机理是逼防御提前发射，验证时必须在风扰和电子干扰叠加下做重复轨迹试验。

双体耦合巡飞精打弹最有意义的指标，是前后体协同误差、前段牵制到后段入攻的时间差、两轮拦截拆分成功率。它的作战效果不是多打一个弹头，而是让防御方先应付前体、再面对后体，连续吃两次决策负荷；若两体时序偏差过大，就会从协同突防退化为普通双弹投送。

“玄礁”水下跃升巡飞弹的判别重点在跨介质这一瞬间：水下隐蔽保持时间、出水到末段识别的切换时间、出水后姿态恢复精度。它的价值在于先躲开空中拦截链，再用短窗口完成末段识别和俯冲命中；若上浮暴露过早或出水后姿态不稳，跨介质带来的突然性就不成立。

以上指标都应在GNSS受扰、链路间歇、伪装目标和分层防空条件下验证，不看理想网络环境下的峰值，而看降级条件下还能否保持命中、重构和安全中止。
