## 二、项目画像

### （一）装备图像概述

| 装备对象 | 核心技术与形成能力 | 部署或进入方式 | 关键动作、作用对象和直接效果 |
|---|---|---|---|
| 群栖自组巡飞精打弹 | 以群内协同决策、末端自治识别和失链保持为本体能力，把原本依赖外部指挥链的目标选择、攻击轮换和毁伤评估前移到弹体群内部；其价值不在单弹远射，而在多弹在受扰条件下仍能维持连续判别与接续打击。 | 适合以批量发射、分散布放或多点同时进入的方式投入战场，进入后依靠群内规则自行分工，不把稳定链路当作前提。 | 当岛链防空和反舰火力仍按固定节奏组织搜索、分配和拦截时，这类弹药用多弹接力压缩对手判断时间，优先打雷达、舰艇和发射阵位，使防御方来不及完成重新分配、补位和集中拦截，直接表现为持续毁伤和瘫痪风险上升。 |
| 蜂簇接力巡猎精打弹 | 以单个载体内装并连续释放多个小型攻击单元为核心，前导单元负责探路、消耗拦截和暴露防空反应，后续单元接续补打；它的形成能力是把一次打击拆成多轮压力，而不是把单弹做得更大。 | 由母弹或外部载体送入接敌空域后分段释放，进入阶段天然带有顺序性，前后单元依次接敌，便于在防御方已暴露拦截节奏后再压上主攻单元。 | 其动作重心是“先诱发、再补位”，面对防空火力网、近程反无人机火力和高价值节点时，用连续到达打乱对手恢复周期，降低集中拦截效率，直接把一轮攻击变成多轮消耗，提升关键节点被击穿的概率。 |
| 气膜掠波隐巡击弹 | 依托近海气膜和掠波飞行，把航迹压在海面背景中；真正形成优势的不是速度本身，而是把接敌几何藏进海杂波和低空遮蔽里，使岸基雷达、火控和拦截系统更难稳定跟踪。 | 从近海方向低空进入，沿海面贴波逼近，不依赖长时间暴露在高空航路上，进入方式本身就是隐蔽接敌。 | 它的关键动作是压低可探测性并缩短对手可用反应窗口，主要压向岸基雷达、火控阵地和防空单元；直接效果是让固定探测、跟踪和拦截链条更容易断点，漏防率随之抬升。 |
| 形记忆折展巡飞精打弹 | 以形状记忆折展骨架实现巡航与接敌状态切换，把低阻航程和临机机动合在一个弹体里；其能力重点不在单一飞得远，而在途中保持经济性、末段再迅速改形。 | 平时以收拢形态降低阻力，接敌前折展翼面或改变盘旋半径后进入末段机动，适合对沿岸舰艇、发射车和临机点目标实施临近突击。 | 它通过临机变形打开拦截窗口，使防御方即使大致掌握来袭航路，也难以把火力提前锁死在固定交汇点；直接结果是末段规避空间增大，点状目标更容易被打穿。 |
| 磁流体矢控巡飞精打弹 | 以磁流体在磁场作用下快速重分配为机理，驱动弹体做侧向偏转和小半径折转，把可预测轨迹改成连续可变航迹；它的优势是机动变化快，且不完全依赖传统舵面大幅动作。 | 进入接敌阶段后可按局部磁场调整飞行姿态，适合在岸防雷达、导引站和纵深点状火力前突然变向，形成不规则逼近。 | 关键动作是把航迹改写得难以提前算准，迫使防御方提前发射或过早暴露拦截资源；直接效果是对手拦截时机被挤压，漏防和误判同时上升。 |
| 双体耦合巡飞精打弹 | 以前体引导、后体主攻的双体耦合方式，把一次消耗单元拆成两段决策负荷；前体负责吸引搜索、分配和试探性拦截，后体从偏置航向补入末攻，形成对拦截链的二次冲击。 | 通常先由前段进入吸收防御注意力，再由后段接续穿入，部署逻辑强调前后分工，不是单体一次穿透。 | 它的动作是先消耗对手搜索与分配资源，再利用后段主攻穿入防空节点；直接效果是集中拦截效率下降，关键防空节点更容易被精确毁伤。 |
| “玄礁”水下跃升巡飞弹 | 以跨介质水下潜行和出水后末段识别为核心，先用水下阶段躲开雷达视线和空中拦截链，再在跃升后转入俯冲打击；真正的能力边界在于跨介质接敌而不是单纯水下航行。 | 从水下接近港湾、登陆点或靠岸舰艇，出水即进入末段识别和攻击，不给岸防与防空系统留出完整的同套程序封堵时间。 | 它的关键动作是把接敌路径拆成水下隐蔽段和出水突击段，作用对象集中在港湾、登陆点和靠岸舰艇；直接效果是防御方难以用单一岸防流程提前封堵，拦截链条被错位。 |
