三、总体方案

（一）总体架构

总体架构采用“外部任务支援—弹上自治执行—结果回传评估”的分层方式。外部指挥、侦察和数据链只提供任务区域、目标优先级、禁限射规则及必要更新，不把持续联网、连续目标指示或跨域重规划误作弹药本体能力；弹体必须独立完成抗干扰导航、末端识别、交战决策、飞控和安全中止。各型装备共享的接口应限定为任务装订、状态上报、载荷管理和发射兼容，通信中断时保留预设规则和有限自治，避免单一链路失效导致整批失效。

群栖自组巡飞精打弹把目标选择、攻击轮换和损伤评估下沉到弹群内部，适合压迫依赖固定搜索、分配和拦截节奏的防空体系；其关键衔接是弹间状态共享，失败耦合在于协同规则失配会使多弹同时暴露或重复攻击。蜂簇接力巡猎精打弹则由母体依次释放攻击单元，以前导单元诱发拦截、后续单元补位毁伤，优势是把一次突击转为连续压力，但释放机构、单元识别和时序控制任一失效都会削弱整体效应。

气膜掠波隐巡击弹依靠贴海飞行和海面背景遮蔽压缩探测窗口，专门改变岸基雷达、火控和近程防空的接敌几何；其成立边界是海况、低空控制和末端识别必须同时满足。形记忆折展巡飞精打弹以巡航低阻和接敌变形切换航迹，针对沿岸舰艇、发射车等临机目标，失效点在于折展可靠性与变形后飞控标定。磁流体矢控巡飞精打弹通过快速侧向偏转打破可预判航迹，适合压迫雷达和导引站，但矢控响应、能源供给和末端稳定性存在强耦合。双体耦合巡飞精打弹以前体耗散搜索与分配资源、后体从偏置方向实施主攻，能增加防御决策轮次；若分离、识别或时序不同步，便退化为两枚易被分别处理的弹体。“玄礁”水下跃升巡飞弹以水下潜行避开空中探测，出水后快速识别并攻击港湾、登陆点或靠岸舰艇，成败取决于跨介质转换、出水定位和末段窗口。上述方案均须以受扰、失链和欺骗条件下的可验证直接战果为边界，不能以理想联网示范替代作战成立条件。
