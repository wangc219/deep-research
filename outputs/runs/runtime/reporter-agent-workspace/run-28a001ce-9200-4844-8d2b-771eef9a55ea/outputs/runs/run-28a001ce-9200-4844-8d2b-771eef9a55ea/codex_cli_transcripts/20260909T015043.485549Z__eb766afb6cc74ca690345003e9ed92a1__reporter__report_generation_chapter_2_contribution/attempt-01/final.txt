## 二、项目画像

### （三）体系贡献率分析

群栖自组巡飞精打弹的体系价值，不在于简单增加弹药数量，而在于把原本依赖外部指挥节点完成的目标分配、攻击排序和战果判断部分前移到弹群内部。相对单弹依次突防的基线，多弹可依据局部发现和成员损耗调整攻击方向，使防空体系难以按固定目标清单集中拦截，直接提高对舰艇、雷达和发射阵位形成连续打击的可能性。其贡献成立的前提是弹间协同在链路受压、部分成员失效时仍能降级运行；若必须持续联网，干扰、欺骗或诱饵便可使弹群退化为若干孤立目标。

蜂簇接力巡猎精打弹改变的是一次攻击的时间结构。单一载体携带并依次释放多个攻击单元，前导单元可迫使防御方开机、分配火力或消耗拦截资源，后续单元再利用暴露出的缺口实施补攻。相较一次性齐射，它把防御压力拉成长连续过程，压缩对手重新搜索、换防和补充拦截的间隔，因而更适合打击需要持续保持运行的防空节点。其短板是释放、编组和接力时序必须稳定，若防御方具备快速重组或区域封锁能力，连续回合带来的优势会明显减弱。

气膜掠波隐巡击弹针对的是海上低空接敌中“先被发现、再被稳定跟踪”的关键矛盾。它依靠贴近海面的飞行路径和海面背景遮蔽，压缩岸基雷达的有效发现与跟踪窗口，直接把攻击对象从外围警戒层推进到雷达、火控和近程防空单元。与常规空中接近方式相比，其体系增量体现为改变探测几何，而不是单纯提高速度或载荷。海况、气象、海面杂波处理和超低空飞控失误都可能削弱该优势；对手若采用多点被动探测、低空补盲和近程拦截，漏防率也不会自然上升。

形记忆折展巡飞精打弹的贡献在于把远程巡航与末端机动纳入同一弹体。巡航段保持较低阻力以接近目标，进入搜索或攻击阶段后改变翼面状态和盘旋特性，从而扩大对沿岸舰艇、发射车及临机点目标的搜索和攻击角度。相较固定外形、预设航路的巡飞弹，它增加的是临机改道和目标适配能力，使防御方即便掌握大致来向，也难以覆盖全部末端航迹。其成效受折展机构可靠性、变形时机、气动稳定性和控制能源制约；若变形只能在理想姿态或单一速度区间完成，体系贡献将被维护复杂度抵消。

磁流体矢控巡飞精打弹试图直接削弱防御方对航迹的预测能力。通过改变推进或控制作用的侧向分配，弹体可在接敌过程中持续修正方向，重点威胁岸防雷达、导引站和纵深点状火力。与依靠舵面或固定机动程序的装备相比，其潜在增量是把末段航迹从少数可预判路线扩展为连续变化的接敌路径，迫使防御提前发射或扩大拦截覆盖。但该方向目前更应视为高风险能力储备：控制响应、能量供给、制导闭合和复杂环境下的稳定性，任何一项不足都可能使机动优势不能转化为命中效果。

双体耦合巡飞精打弹以“前体引导、后体主攻”重新分配一次攻击的拦截负荷。前体先诱发搜索和火力分配，后体再从偏置方向进入末攻，使防御方不能用一次决策同时解决发现、跟踪和毁伤问题。相较单体弹药，它的直接体系贡献不是增加单枚威力，而是把一个来袭目标转化为连续两阶段威胁，降低集中拦截效率。该优势依赖两体分离、航向保持和目标信息交接；若前体过早损失、后体无法独立识别，或对手采用区域性火力而非逐目标拦截，其交换比改善会受到限制。

“玄礁”水下跃升巡飞弹的不可替代性来自跨介质接敌。水下航行阶段可避开多数空中搜索和岸基雷达的常规监视链，出水后再转入末端识别和俯冲攻击，因而能够从不同于空中巡飞弹的方向威胁港湾、登陆点和靠岸舰艇。它改写的是防御体系的分工边界，使岸防、水下警戒和近程防空必须同时闭合，而不是只强化空中拦截。其失效风险集中在水下导航、出水姿态、跨介质控制和末端识别；浅水、复杂海况或水下警戒网密集时，隐蔽接敌距离可能显著缩短。

上述贡献不能按装备数量简单相加。真正优先的体系增量，是先证明抗干扰导航、末端识别、失链保持和安全中止能够在非理想条件下稳定闭合；群栖、接力、折展、矢控和跨介质能力则应依据各自的失败模式逐项验证。外部侦察、指挥信息和任务规划可以提供接口支撑，但不能替代弹药本体必须承担的制导、识别、飞控与可控毁伤责任。
