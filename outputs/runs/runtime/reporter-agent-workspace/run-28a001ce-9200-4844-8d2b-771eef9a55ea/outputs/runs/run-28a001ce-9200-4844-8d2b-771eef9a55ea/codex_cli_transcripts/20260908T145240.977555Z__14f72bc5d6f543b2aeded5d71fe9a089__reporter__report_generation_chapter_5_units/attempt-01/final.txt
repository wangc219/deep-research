五、研制基础

（一）参与单位

本项目若要把低成本智能巡飞精打弹药真正做成可交付装备，参与单位不能按通用“总装加配套”空分，而应由产品责任和证据责任反推。核心应是总体集成单位，负责弹体架构、接口定义、任务载荷与发射兼容；其下应有末端识别与降级导航单位，承担抗干扰导航、目标判别、失链保持和安全中止；还应有飞控与能源单位，解决低空长航时、姿态稳定和末段机动的耦合；战斗部、引信和载荷接口单位则对应命中后果与安全边界，决定是精打、压制还是诱饵型载荷可落到同一平台上。对群栖自组和蜂簇接力方向，必须额外配置分布式协同算法与弹间接口单位，但这类能力只能在弹内自治范围内成立，外部侦察和任务规划单位只能提供初始目标、重规划和链路保障，不能替代弹体本身的判别闭环。

按不同机理分解，气膜掠波、形记忆折展、磁流体矢控和双体耦合四条路线，分别对应低空气动设计、可展开结构材料、矢量控制执行器与分体分离机构等专业承研单位；“玄礁”类跨介质方案还需要水下推进、密封发射、出水稳定和末段识别试验单位共同承担。它们的共同任务不是提供概念口号，而是交付能复现实弹飞行、抗扰导航、末端命中和失效中止的试验记录。公开依据目前不足以锁定具体承研方和配套分工，因此只能确认上述机构类型及其必须补齐的接口、环境与验证证据，不能据此倒推出具体单位归属。
