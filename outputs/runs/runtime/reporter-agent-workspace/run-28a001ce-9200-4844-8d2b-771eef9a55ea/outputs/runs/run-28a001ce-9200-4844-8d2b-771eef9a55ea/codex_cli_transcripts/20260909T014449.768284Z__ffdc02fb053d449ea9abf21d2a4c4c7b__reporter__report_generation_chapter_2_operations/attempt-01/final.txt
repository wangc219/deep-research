## 二、项目画像

### （二）作战运用模式

#### 1. 作战运用流程

本项目面对的不是理想网络下的单枚精确打击，而是第一岛链外缘防区外接敌、导航受扰、链路间歇和分层防空共同作用下的连续突防。进入条件应限定为：目标类别和大致地域已由外部侦察或指控系统提供，弹药能够在失去持续联网后保持基本航迹和任务规则，并且敌方防空体系存在可被多方向、多批次或跨介质攻击撕开的处理瓶颈。外部体系负责提供任务边界，装备本体必须承担飞行控制、末端判别、攻击次序或中止判断，不能把关键作战效果建立在持续人工遥控上。

**群栖自组巡飞精打弹**的关键动作是让多枚弹药在接敌后自行分配目标、调整攻击次序，并根据局部探测结果轮换承担搜索、压制和末端打击。其对象不是单一目标，而是敌方舰艇、雷达和发射阵位组成的防空作战链。首批弹体暴露或接近会迫使对手进行搜索、识别和火力分配，后续弹体再依据局部态势补位，使敌方从集中拦截转向多点应对；直接结果是雷达关机、火力转移、发射阵位受损或舰艇失去连续防护。相较单枚巡飞弹各自等待外部指令，该装备的不可替代性在于把目标选择和损毁评估前移到弹群内部。若协同规则只能在稳定通信或完整定位条件下运行，群栖优势即退化为多枚独立弹药，项目成立边界随之失效。

**蜂簇接力巡猎精打弹**适用于敌方防空具备分层拦截、但拦截资源需要按时间窗口恢复和重新分配的场景。单一载体释放多个小型攻击单元，前导单元首先搜索、诱发防空开机或消耗拦截火力，后续单元根据暴露出的防御节点接续进入，并完成对目标的精确毁伤。这里的决定性动作不是扩大一次齐射规模，而是把一次攻击转化为连续回合，使对手无法依靠短时换防、补充弹药或重新组织火控来恢复防护。直接战果更偏向于打开局部通道、压低关键节点的持续防御能力，而非单纯追求首枚命中。其相对普通巡飞弹的变化是把搜索、分发和打击集成到一个载体的释放过程内；若释放机构、单元识别或接力判定可靠性不足，前导单元的消耗就可能只增加成本而不能换取后续突破。

**气膜掠波隐巡击弹**的进入条件是近海航路允许持续贴近海面飞行，且海况、气象和地形能够支持低空遮蔽。它以岸基雷达、火控节点和近岸防空单元为主要对象，决定性动作是维持低空掠波航迹，在探测距离被压缩后迅速完成末端识别和攻击。对手状态将由远距离预警转为短时、低仰角和高杂波条件下的仓促跟踪，直接战果是压缩反应时间、提高漏防概率并破坏岸防节点。相较依赖高空航路或外部引导的弹药，该装备改变的是接敌几何，而不是单纯增加速度。其失效边界也最明确：海况、飞控误差和低空探测能力一旦使贴波飞行无法稳定维持，海面遮蔽就不能转化为可靠突防效果。

**形记忆折展巡飞精打弹**服务于航程与末端机动相互牵制的任务。接敌前采用低阻巡航形态以保持搜索和抵近能力，接敌后通过折展结构改变翼面和盘旋半径，对沿岸舰艇、机动发射车或临机出现的点目标实施重新占位。其决定性动作是把预设航路变成临机机动窗口，使敌方即使掌握大致来向，也难以按固定拦截几何完成提前布置。直接结果是扩大末端可攻击目标范围，并提高对机动目标的跟踪保持能力。与普通固定构型巡飞弹相比，它的优势取决于折展动作是否在受扰、受损和高过载条件下仍可重复；若结构转换时间过长或转换后控制裕度不足，航程收益会被末端失控抵消。

**磁流体矢控巡飞精打弹**针对的是岸防雷达、导引站和纵深点状火力对可预测航迹的依赖。进入末端后，弹体利用磁流体受控重分配形成侧向偏转和小半径折转，使防御方难以按照单一弹道提前计算拦截点。对手将被迫提前发射或扩大拦截区域，继而出现火力浪费、拦截点偏移和局部漏防，直接效果是提高对固定节点的突防机会。该装备相对常规舵面机动弹药的专属性在于连续改变航迹，而不是在少数节点实施一次规避。其成立依赖于矢控响应、能源供给和飞控融合能够同步；若机动只在试验条件下有效，不能将航迹不可预测直接等同于实战突防。

**双体耦合巡飞精打弹**以防空节点和火控链为对象，采用前体引导、后体主攻的接力方式。前体先迫使敌方搜索、识别和分配资源，后体从偏置方向补入末攻，使防御方必须对同一来袭单元连续作出两次决策。直接战果是降低集中拦截效率，并提高对雷达、导引站等关键节点的毁伤概率。它区别于蜂簇弹的地方在于不是依靠多个释放单元形成时间上的连续压力，而是利用双体分工制造方向和决策上的错位。若两体间的时序、距离或信息交接不可控，前体可能只成为无效消耗，后体也会失去偏置突入的意义。

**“玄礁”水下跃升巡飞弹**适用于港湾、登陆点和近岸舰艇受到空中预警与岸防火力严密覆盖的场景。它先以水下航行绕开雷达视线和部分空中拦截链，在接近目标后跃升出水，立即完成末端识别和俯冲攻击。对手必须在水下搜索、海面监视和空中防御之间切换，难以用一套固定程序提前封堵，直接效果是对港口节点、靠岸舰艇或登陆支撑目标形成突然打击。其不可替代性来自跨介质改变威胁方向；但水下航迹、跃升时机和出水后的短时识别若不能稳定衔接，隐蔽性反而会转化为末端态势缺口。

#### 2. 链路闭环分析

上述装备共同形成的制胜链条不是“发现即命中”，而是通过不同方式破坏敌方从发现、识别、分配到拦截的连续性。群栖自组弹改变的是决策位置，把协同和损伤评估下沉到弹群；蜂簇接力弹改变的是时间结构，把一次攻击拆成连续回合；气膜掠波弹改变的是探测几何，压缩岸防预警距离；形记忆折展弹改变的是末端构型，使航路和机动不再固定；磁流体矢控弹改变的是航迹可预测性；双体耦合弹改变的是拦截决策次数；“玄礁”则直接改变来袭介质。因而不能用同一套命中率或突防率概括其贡献，必须分别观察敌方火控是否被迫分散、预警是否被压缩、拦截窗口是否失配以及关键节点是否出现持续失能。

闭环的外部部分仍由侦察、指控、通信和保障体系提供，但这些接口只能下达目标类别、禁限区和任务边界，不能替代装备自身的末端闭环。受干扰时，群栖和双体装备首先检验局部协同是否还能维持；蜂簇装备检验释放与接力是否独立于持续联网；气膜、折展和磁流体装备检验飞控能否在数据不完整时保持安全航迹与末端动作；“玄礁”检验跨介质转换后是否仍有足够识别时间。对手一旦转向多点低功率探测、诱饵目标、分散部署和拦截资源前置，原有优势会分别受到削弱，因此验证应以降级通信、导航受扰、目标欺骗和局部节点失效为边界。公开资料尚不足以支持确定的数量指标，现阶段应优先证明各装备专属动作能否在相应失效条件下仍产生可审计的直接战果。
