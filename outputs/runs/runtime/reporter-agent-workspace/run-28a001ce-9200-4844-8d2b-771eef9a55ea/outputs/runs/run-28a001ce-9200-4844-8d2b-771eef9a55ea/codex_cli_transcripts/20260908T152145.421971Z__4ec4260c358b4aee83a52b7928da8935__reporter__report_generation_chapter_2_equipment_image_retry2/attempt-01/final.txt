## 二、项目画像
### （一）装备图像概述

| 装备对象 | 核心技术与形成能力 | 部署或进入方式 | 关键动作、作用对象和直接效果 |
|---|---|---|---|
| 群栖自组巡飞精打弹 | 以群内自治分配、末端识别和失链保持为本体能力，把目标选择、攻击轮换和毁伤评估前移到弹体群内，核心价值不在单弹极限性能，而在多弹同时改写防空搜索、分配与拦截节奏。 | 依托外部侦察和任务规划进入战区后分散接敌，通信受扰时仍按局部协同规则续飞。 | 对舰艇、雷达和发射阵位实施连续轮换式逼近，迫使防御方在同一轮拦截中反复改判，直接效果是压低防御处理速度，制造持续毁伤或瘫痪。 |
| 蜂簇接力巡猎精打弹 | 依靠单个载体内置并接续释放多个小型攻击单元，把搜索、分发和末段打击串成闭环，形成“前导消耗、后续补位”的接力结构。 | 以一体化载荷装入后前出，接敌前先完成单元分离与任务分工。 | 先用前导单元诱发暴露、消耗拦截，再由后续单元补入命中窗口，作用对象是防空节点与伴随火力，直接效果是把一次攻击拉长为多回合压力，削弱对手集中拦截能力。 |
| 气膜掠波隐巡击弹 | 借近海气膜和掠波效应实施超低空巡猎，本体能力在于贴波飞行、借海面背景隐藏和贴近岸基火控链路。 | 从近海方向进入，沿海面低可探测通道接敌，依赖弹体自身导航和末段判别完成最后逼近。 | 逼近岸基雷达、火控和防空单元，利用几何压低接敌显著缩短对手探测到开火的时间差，直接效果是提高漏防率并优先打断关键节点。 |
| 形记忆折展巡飞精打弹 | 依靠形状记忆折展骨架在巡航与接敌之间快速切换翼面状态，把低阻航程和临机机动合并到同一弹体。 | 平飞阶段保持收拢低阻，接敌阶段快速展开以改变盘旋半径和机动包线。 | 作用于沿岸舰艇、发射车和临机点目标，通过临机变形拉开拦截窗口，直接效果是让防御方即使大致掌握航路，也难以在最后几秒完成有效封堵。 |
| 磁流体矢控巡飞精打弹 | 以磁场驱动磁流体快速重分配，形成侧向偏转和小半径折转能力，使航迹从可预判改写为连续可变。 | 作为末端矢量控制手段嵌入弹体，进入防区后按局部指令频繁修正航向。 | 针对岸防雷达、导引站和纵深点状火力实施突变接敌，迫使防御提前发射并拉高弹药消耗，直接效果是增加漏防、打乱火控跟踪节拍。 |
| 双体耦合巡飞精打弹 | 以前体引导、后体主攻的耦合布局，把一次接敌拆成两轮决策负荷，前段负责牵引和消耗，后段负责末攻。 | 两体协同进入目标区，前体先暴露、后体后置，靠结构分工而非单纯链路依赖完成闭环。 | 先消耗搜索与分配资源，再从偏置航向补入终段打击，作用对象是防空节点，直接效果是压低集中拦截效率并放大一次拦截中的失误代价。 |
| “玄礁”水下跃升巡飞弹 | 跨介质跃升是其关键本体特征，先以水下潜行规避空中探测，再出水转入末段识别和俯冲命中。 | 从水下接敌，适合靠岸海域、港湾外缘或登陆通道附近部署，依靠跨介质机动切换进入末攻。 | 作用于港湾设施、登陆点和靠岸舰艇，利用水下段甩开雷达视线和空中拦截链，直接效果是让岸防与防空难以用同一套程序提前封堵来袭路径。 |
| 群栖自组与蜂簇接力以外的低成本智能巡飞路线 | 公开原料只能支持其作为弹药本体能力集合的判断：抗扰导航、末端识别、局部自治和模块化载荷是必须项，但真实成熟度取决于在干扰、欺骗和链路中断条件下能否保持可验证命中。 | 进入方式更依赖外部ISR/C2提供初始任务，弹体本身承担末段自治；若必须长期联网或高度依赖完好链路，则不构成此类装备的有效形态。 | 直接效果应当落在“提高穿透概率、维持低成本交换比、在受扰条件下保持命中或可控中止”三点上，若只能在理想网络环境展示效果，则对岛链拒止场景的成立边界即被击穿。 |
