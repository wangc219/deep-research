## 二、项目画像

### （四）主要战技指标

主要战技指标不以航程、速度等孤立参数为主，而以装备改变敌我交战关系后的直接效果为判据。由于目标类型、平台生态、成本上限和海况工况尚未给定，以下先确定可判别的指标方向与验证方法，不虚构具体点值。

**群栖自组巡飞精打弹。**其核心效果是把目标选择、攻击轮换和毁伤评估部分前移到弹体群，使敌方防空体系在通信受扰、节点损失后仍持续面对多方向压力。首要指标应是失链或间歇通信条件下的群体任务保持率，重点观察编队能否完成重新分组、目标再分配和安全中止，而不是只看理想联网时的协同展示；其次是群体对单一防御节点形成连续压迫的有效攻击比例。验证应采用通信逐步衰减、局部单元失效和诱导目标混入的对抗试验。若失联后只能各自返航，或目标判别依赖外部持续指挥，该装备的群栖制胜机理不成立。

**蜂簇接力巡猎精打弹。**它依靠“前导单元暴露并消耗防御、后续单元接替完成毁伤”的连续回合机制，直接效果不是单次命中率，而是延长防御方无法恢复和重新分配火力的时间。关键指标应为载体释放后各攻击单元的时序接续成功率，以及前后波次在目标区域形成有效压力的持续性；还要记录前导单元损失后，后续单元能否按预定规则改换目标。验证应将拦截时机、释放间隔和部分单元故障组合测试。若释放机构、单元识别或接替决策任一环节不稳定，连续多回合优势会退化为一次性消耗。

**气膜掠波隐巡击弹。**其作战价值在于利用近海背景和低空接敌几何压缩岸基雷达、火控和近程防空的反应窗口，直接争取关键节点的突防机会。最具判别性的指标不是名义飞行高度，而是不同海况、风场和背景杂波下维持预定贴波航迹的时间比例，以及由航迹偏差引起的末段识别和攻击窗口损失。验证应覆盖平静海面、较强风浪、雷达持续照射和末段通信受限条件。若气膜效应只能在窄小海况范围内保持，或飞控为维持贴波而牺牲末段识别稳定性，其突防收益不能成立。

**形记忆折展巡飞精打弹。**该装备以巡航阶段的低阻滞空换取接敌阶段的临机变形和机动，直接效果是使防御方难以依据早期航路提前确定末段拦截窗口。指标应围绕折展动作本身设置：巡航构型向攻击构型转换的成功率、转换后姿态恢复时间，以及多次折展后航迹控制误差是否仍可接受。验证需在不同速度、载荷状态和温度条件下进行重复循环试验，并把变形失败与目标丢失、误入禁飞区等后果关联评估。若折展只能一次完成，或变形后无法稳定接续制导，其航程与机动兼得的设想将失去基础。

**磁流体矢控巡飞精打弹。**它试图以磁场驱动流体重分配，连续改变侧向运动，使岸防雷达和导引站难以按固定弹道完成提前量计算。核心指标应是矢控响应的可重复性，即相同控制指令下偏转量、响应延迟和小半径折转结果的离散程度；作战效果则以末段仍能保持目标捕获和可控攻击方向来确认。验证必须把温度、磁场强度、电源衰减和高速气动扰动同时纳入，而不能只在实验室静态条件下测偏转。若控制响应随工况剧烈漂移，机动优势可能转化为自身制导不确定性。

**双体耦合巡飞精打弹。**其价值在于以前体牵引防御搜索和分配、后体从偏置方向实施主攻，把防御方的一次拦截任务拆成连续两轮决策。主要指标应是前后体在分离、引导和偏置补入后的时序保持能力，以及前体受损后后体能否继续完成末段攻击；不能以双体同时到达作为唯一判据。验证应设置不同拦截优先级、前体提前损失和后体链路中断情形，观察防御资源是否确实被迫重新分配。若两体必须依赖持续链路或严格同步才能工作，其增加的结构复杂度未必换来有效突防。

**“玄礁”水下跃升巡飞弹。**它通过水下接敌避开空中雷达和部分拦截链，出水后迅速完成识别、转入俯冲攻击，直接争取港湾、登陆点和靠岸舰艇的突然性。首要指标应是跨介质转换后的制导连续性：出水姿态稳定、传感器恢复、目标重捕获和末段攻击能否在同一任务窗口内完成；同时应考察水下航行误差是否把出水点推离有效攻击区域。验证须覆盖不同水深、海况、出水角度及出水后通信受限条件。若水下潜行提高了隐蔽性，却导致出水后无法可靠识别或攻击，跨介质优势不能转化为直接战果。
