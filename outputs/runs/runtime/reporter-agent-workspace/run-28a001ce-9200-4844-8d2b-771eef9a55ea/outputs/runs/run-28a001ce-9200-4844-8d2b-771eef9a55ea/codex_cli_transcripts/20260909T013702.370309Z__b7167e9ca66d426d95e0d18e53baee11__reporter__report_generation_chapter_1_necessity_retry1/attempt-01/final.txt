## 一、需求分析

### （三）建设必要性分析

#### 1. 作战使用角度

岛链拒止环境的直接矛盾，不是单纯缺少打击弹药，而是在全球导航卫星系统受压制、链路间歇、目标伪装和分层防空共同作用下，传统“外部侦察指示、弹药按预定航路突入、末段短时修正”的链条容易在接敌前后断裂。智能巡飞精打弹药的建设必要性，首先体现在把部分判断和处置能力压入弹体本体，使其在失去连续指挥和稳定导航时仍能完成搜索、识别、续航等待、择机攻击或安全中止，避免一次通信失效就转化为打击失效。

群栖自组巡飞精打弹主要针对固定节奏防空链。敌方岸基雷达、舰艇防空和反舰火力通常依靠搜索、分配、拦截、评估、再装填的循环维持防御效率；单枚弹药突防时，防御方可以按目标优先级集中火力。该型装备的作战价值在于多弹进入威胁区后，由弹群内部承担目标接替、攻击排序和毁伤回看，迫使防御系统同时处理多个方向、多个状态和多轮攻击意图。相对依赖外部指控的普通巡飞弹，它把交战关系从“一弹对一目标”改为“弹群持续压迫防御链”，直接战果是压缩对手重新分配火力的时间，并对舰艇、雷达、发射阵位等节点形成连续毁伤压力。其判断边界在于协同规则必须能在通信降级条件下运行，不能把全连接演示误判为实战能力。

蜂簇接力巡猎精打弹解决的是另一类突防矛盾：一次攻击波被防御方拦截后，后续弹药往往需要重新组织航路和目标分配，给对手留下恢复窗口。该型装备以单个载体携带并连续释放多个小型攻击单元，将一次突击拆分成前导诱发、拦截消耗、后续补位和末段精毁多个回合。前导单元的主要作用不是单纯命中，而是逼迫防空系统开机、暴露火控节奏并消耗近程拦截资源；后续单元再利用已经显露的防御缝隙补入攻击。相对一次性齐射，它更适合打港湾、岸防节点和临时展开目标，制胜点是把防御方的“打完一波再恢复”改成“刚处置完前一批又面对下一批”，从而削弱集中拦截和换防能力。

气膜掠波隐巡击弹的必要性来自海空边界探测难题。岛链岸基雷达、防空火控和近程反无人系统对中高空或规则低空目标更容易建立连续航迹；贴近海面飞行时，海杂波、地形遮蔽和低仰角探测限制会缩短发现距离。该型装备依靠弹体本体维持掠波巡猎，把接敌通道压到海面背景之中，使对手雷达发现、稳定跟踪、火控解算和拦截发射的窗口同时变短。它相对普通低空巡飞弹的不可替代性，不在“飞得低”这个口号，而在能否稳定保持超低空航迹并在末段完成目标识别和攻击转换；一旦海况、近岸杂波处理或高度控制不足，其隐蔽接敌优势就会被放大为撞海、失控或提前暴露风险。

形记忆折展巡飞精打弹面向航程和临机机动之间的矛盾。岛链外缘接敌距离长，弹药需要低阻巡航保存能量；但进入岸防火力圈后，又需要缩小盘旋半径、改变末段姿态并对临机点目标保持攻击角度。该型装备通过形状记忆折展结构在巡航和接敌阶段切换气动外形，把“长时间经济飞行”和“末段突然机动”合并在同一弹体内。它适合对沿岸舰艇、机动发射车和短时暴露点目标实施等待后攻击，使防御方即使掌握大致来袭方向，也难以提前覆盖弹体变形后打开的新拦截窗口。其建设价值取决于折展动作的可靠性和变形后的飞控稳定性，不能只以材料概念替代全弹环境验证。

磁流体矢控巡飞精打弹针对的是可预判航迹被防空系统提前解算的问题。传统巡飞弹受舵面、速度和姿态限制，接敌机动往往存在可估计的转弯半径和规避模式；防御方可据此提前发射或设置拦截点。该型装备以磁场调控磁流体分布，形成快速侧向偏转和小半径折转，意在把末段航迹从规则曲线改为连续变化的接敌过程。它对岸防雷达、导引站和纵深点状火力的意义，是迫使防御方在目标状态不稳定时提前用弹，增加虚耗和漏防。该方向的风险也更集中：若矢量控制只能在有限包线内稳定工作，或响应速度不足以改变火控解算结果，其作战收益会明显低于结构复杂度带来的成本和可靠性代价。

双体耦合巡飞精打弹的必要性在于以单个消耗单元制造两轮防御决策。前体负责引导、诱发开机或吸引拦截，后体保持主攻能力并从偏置航向补入末段攻击。与蜂簇接力巡猎精打弹的多单元连续压力不同，双体耦合更强调“一次来袭目标内部的真假、前后、诱攻关系”，使防御方难以判断应把拦截资源投向前段还是保留给后段。它直接改变集中拦截效率，对防空节点、火控站等高价值目标更有意义；失效边界则在前后体分离、识别、协同和末段切换是否足够可靠，否则前体消耗资源之后，后体未能接续攻击，反而会暴露攻击意图。

“玄礁”水下跃升巡飞弹面向岸防和防空程序相互割裂的薄弱点。其跨介质接敌先以水下潜行避开雷达视线和空中拦截链，接近港湾、登陆点或靠岸舰艇后再出水转入末段识别与俯冲攻击。相对全程空中突防弹药，它把防御方的预警起点后移，使岸防反潜、近岸警戒和防空火控难以用同一套程序连续封堵来袭路径。该型装备最适合打固定或半固定近岸目标，制胜机理是通过介质转换打断对手从发现到拦截的连续性；若水下导航、出水姿态转换和末段识别不能闭合，则跨介质优势无法转化为命中效果。

#### 2. 装备能力提升角度

上述装备共同指向的能力提升，不是简单增加弹药品种，而是把抗扰导航、末端识别、失链保持、任务中止和低成本消耗约束纳入弹药本体。群栖自组巡飞精打弹优先提升降级协同和弹群内任务分配能力，决定其能否在外部指挥受压制后继续形成突防压力；蜂簇接力巡猎精打弹优先提升载体内多单元释放、接力搜索和补位攻击能力，决定其能否把一次投送转化为多轮战果；气膜掠波隐巡击弹优先提升贴海稳定飞控和末段目标确认能力，决定其低可探测接敌是否可控；形记忆折展巡飞精打弹优先提升变形结构与飞控耦合能力，决定其能否兼顾航程和临机机动；磁流体矢控巡飞精打弹优先提升快速矢量控制与末段稳定能力，决定其能否真正破坏防御解算；双体耦合巡飞精打弹优先提升前后体协同和诱攻识别能力，决定其能否把拦截资源消耗转化为后段命中；“玄礁”水下跃升巡飞弹优先提升跨介质转换和出水后自主攻击能力，决定其能否把隐蔽接近转化为有效毁伤。

能力建设的取舍应按作战失效原因排序。第一优先级应放在抗扰自治、失链降级和末端判别，因为这些能力直接决定弹药在岛链拒止环境中是否还能完成可验证打击；第二优先级放在协同、接力、双体和跨介质等改变交战关系的形态创新；第三优先级才是更激进的特殊机动或材料路线。公开证据不足的航程、命中率、成本和成熟度不能写成确定指标，应转化为后续试验需要验证的边界条件。

#### 3. 领域占位角度

建设智能巡飞精打弹药，可在低成本精确火力、受限通信自治、反防空消耗和岛链近岸节点打击之间形成装备占位。其意义不在替代有人平台、远程导弹或外部侦察体系，而是在高价值平台不宜前出、昂贵弹药不宜大量消耗、通信链路不宜长期依赖的场景中，提供一种可批量投送、可降级执行、可用战损换取防御资源消耗的中间层火力。该领域若长期缺位，作战使用将继续依赖少量高价值弹药穿透完整防空链，成本交换和持续压制能力均受限制。

#### 4. 综合效益

项目综合效益体现为三类直接变化：一是把防御方的拦截问题从处理少量确定航迹，改为处理多点、多轮、低空、变轨和跨介质目标；二是把我方打击链从持续依赖外部指挥，改为弹药在受扰条件下保留最低限度自主处置；三是把库存使用从单一精打消耗，扩展为诱发、压制、毁伤、补位和评估一体化组合。建设边界也必须明确：凡是需要战区级情报融合、持续目标指示和跨域重规划的能力，只能作为体系接口提出，不能冒充弹药本体能力；凡是不能在导航受扰、链路间歇、目标欺骗和局部节点失效条件下证明有效的能力，均不应作为本项目成立的核心依据。
