# 一、需求分析

## （一）需求概述

### 1. 背景分析

第一岛链拒止环境下，防御体系通常依靠远程预警、分层防空、反导和近程反无人系统构成连续拦截链，并通过卫星导航压制、通信干扰和诱骗目标削弱来袭弹药的发现、识别与末端决策能力。进攻方的主要矛盾已不只是“能否抵达目标”，而是弹药在失去持续联网和稳定导航后，能否继续完成目标判别、航迹保持、攻击选择和必要的安全中止。若低成本巡飞弹药仍依赖理想链路、固定航路或单一末制导方式，其数量优势容易被防御方的集中分配和分批拦截抵消。

因此，本项目需求应围绕任务链断点收敛：弹药本体必须承担抗干扰导航、末端识别、飞行控制、载荷释放或毁伤，并在失链、数据不完备和局部节点失效时维持有限自治；外部侦察、指挥信息系统和战区级重规划只能作为接口保障，不能被误写成弹药自身能力。不同装备的价值，则取决于它改写的是防御方的搜索节奏、拦截几何、决策负荷，还是来袭方向和介质边界。

### 2. 需求阐述

对群栖自组巡飞精打弹，需求重点是让多弹在通信受压时仍能完成有限的目标分工、攻击轮换和损毁判断。现有单弹或强中心控制方式难以持续压迫分层防空，缺口在于局部协同规则和失链后的任务接续，而不是简单增加弹药数量。对蜂簇接力巡猎精打弹，需求是把一次载荷投送转化为连续的搜索、诱导和精确攻击压力，解决单次突防后防御体系仍可恢复、换防和集中拦截的问题；其缺口在于载体内多单元释放、任务接替与末端识别之间的可靠衔接。

气膜掠波隐巡击弹针对海面背景下岸基雷达、火控和近程防空的低空探测压力，所需能力是稳定维持贴海飞行并在海况、气象和导航受扰时保持可控航迹。其需求不能简化为“飞得更低”，关键缺口是低空飞行安全性、末端识别和海面杂波条件下的有效交战边界。形记忆折展巡飞精打弹则面向航程与临机机动难以兼顾的矛盾，需要在巡航阶段保持低阻，在接敌阶段改变翼面和盘旋特性，以应对沿岸舰艇、发射车等位置不稳定目标；但其需求成立的前提是折展动作不显著损害飞控可靠性和有效载荷。

磁流体矢控巡飞精打弹所需的不是一般意义上的机动增强，而是使防御方难以依据稳定航迹完成提前量计算和拦截分配。当前缺口在于这种矢量控制能否在实际飞行约束、能量限制和末制导要求下形成可重复的航迹变化。双体耦合巡飞精打弹针对单个来袭目标只触发一次搜索和拦截决策的结构性弱点，需求是由前体消耗探测与分配资源、后体从偏置方向完成末攻；其关键缺口是双体释放、时序控制和末端目标确认不能因结构复杂化而失效。“玄礁”水下跃升巡飞弹承担的是跨介质突防需求，要求水下潜行与出水后空中攻击之间保持连续控制，并在港湾、登陆点和靠岸舰艇场景中完成快速识别；目前应明确其通信、导航、出水姿态和海况适应边界，不能预设其已有实战成熟度。

### 3. 项目画像

本项目不是单一型号替代，而是面向岛链拒止条件的低成本智能巡飞精打弹药方向。其中，群栖自组巡飞精打弹的不可替代增量在于把部分目标分配和损毁评估前移到弹群内部，直接增加防御体系的处理负荷；其效果在通信完全中断、目标信息严重缺失时会明显下降。蜂簇接力巡猎精打弹通过载体内连续释放形成多回合压力，适合压缩防御恢复窗口，但若释放机构、单元识别或成本失控，规模优势将被抵消。

气膜掠波隐巡击弹改变的是接敌高度和探测几何，前景取决于复杂海况下的稳定性，而非概念上的低可探测表象。形记忆折展巡飞精打弹以形态切换换取航程与临机机动的兼容，适合打击航路掌握不等于末端可预测的目标，但其制胜增量受材料寿命、展开可靠性和飞控耦合限制。磁流体矢控巡飞精打弹直接挑战拦截方的航迹预测，具有较强前瞻性，但现有输入不足以证明其工程成熟度，应定位为高风险探索方向。双体耦合巡飞精打弹用一次消耗单元制造两轮防御决策压力，适合攻击关键防空节点，前提是双体动作在受扰条件下仍能保持目标一致性。“玄礁”水下跃升巡飞弹则从水下介质切入，打破岸防与空防按单一来袭路径组织拦截的假设，作战前景具有差异化价值，但其成立范围高度依赖海况、出水控制和末端识别证据。总体上，抗扰自治、失链保持和可验证的末端交战能力应优先于复杂构型扩展；凡只能在持续联网、理想目标信息或未公开参数下成立的效果，均不能直接转化为确定性装备结论。
