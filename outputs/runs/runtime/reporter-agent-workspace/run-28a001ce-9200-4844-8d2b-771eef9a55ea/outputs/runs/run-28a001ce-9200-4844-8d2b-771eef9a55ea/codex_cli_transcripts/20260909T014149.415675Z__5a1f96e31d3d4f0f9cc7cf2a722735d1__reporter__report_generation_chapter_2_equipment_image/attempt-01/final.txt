## 二、项目画像

### （一）装备图像概述

| 装备及核心技术 | 形成能力与部署或进入方式 | 关键动作与作用对象 | 直接效果及成立边界 |
|---|---|---|---|
| **群栖自组巡飞精打弹**：以弹体内置的目标判别、群间协同和失链后局部重规划为核心，使多枚弹药能够在外部指挥信息不连续时保持有限协同。 | 适合由多平台分散发射，以批量进入防空搜索区；外部体系只需提供初始任务、目标类别和必要更新，目标选择、攻击轮换及损毁评估由弹群在局部完成，避免把持续联网当作成立前提。 | 先由部分弹体侦察、诱发或牵制，再由其他弹体依据共享结果调整航向和攻击顺序，作用对象为舰艇、岸基雷达和发射阵位等相互关联节点。 | 将防御方原本按固定节奏进行的搜索、分配和拦截，转化为多方向、不同时间到达的连续压力，争取形成节点压制或瘫痪。制胜关键是失链状态下仍能保持队形和任务分工；若通信中断即逐枚失去目标判别能力，则不具备该项目价值。 |
| **蜂簇接力巡猎精打弹**：采用一个载体携带并依次释放多个小型攻击单元，重点解决一次投放后难以持续施压的问题。 | 由单一母体接近目标区后分批释放单元，既可降低前段暴露，也可按防御反应决定后续单元的释放次序；载体负责搜索和分发，小型单元承担末端跟踪与打击。 | 前导单元先迫使防空开机、消耗拦截弹或暴露火控位置，后续单元改变方向和时间间隔补入，主要作用于防空节点、舰艇和重要固定目标。 | 把一次齐射改造成连续多回合交战，压缩对手换防、补弹和重新分配火力的时间，直接提高后续单元抵达目标区的机会。其边界在于分发机构、单元间识别和释放后的自主控制必须可靠；若母体过早被击毁或单元无法区分真假目标，接力优势会消失。 |
| **气膜掠波隐巡击弹**：拟利用贴近海面飞行、海面杂波遮蔽和低空航迹控制，形成区别于常规中高空巡飞弹的接敌几何。 | 从海上方向低空进入，在通信受限时依靠本体飞控、地形与海况约束维持航迹；外部侦察主要负责给出目标区域，不承担末端持续操纵。 | 沿海面背景逼近岸基雷达、火控设备和近岸防空单元，在末段依据自身传感器完成目标确认和攻击。 | 通过缩短防御方的有效发现和跟踪时间，打乱固定探测、分配与拦截节奏，直接争取关键节点受损。该路线高度受海况、风浪、传感器杂波处理和飞控误差制约，不能把“低空隐蔽”直接等同于稳定突防，必须以不同海况下的可控飞行和末端识别结果验证。 |
| **形记忆折展巡飞精打弹**：以形状记忆材料或折展结构改变翼面状态，在巡航段和接敌段之间切换升阻特性与转弯能力。 | 适合由空中或地面平台发射，先以较低阻力状态完成较远距离接近，再在目标区展开或改变翼面，形成更大的盘旋和转向能力；任务规划只给出目标区域，临机机动由弹体自主完成。 | 接敌前保持航程和隐蔽性，发现沿岸舰艇、机动发射车或临时点目标后改变翼面和盘旋半径，从非固定方向实施末段攻击。 | 使防御方即使掌握大致航路，也难以覆盖弹体临机变形后产生的全部拦截窗口，提升对移动和临时目标的追击价值。成立条件是折展动作的时机、锁定可靠性和结构耐久性；若变形增加重量、振动或故障率，航程与命中收益可能被抵消。 |
| **磁流体矢控巡飞精打弹**：设想利用磁场驱动导电流体重新分配，产生侧向控制力，补充或替代部分传统舵面操纵。 | 主要面向需要临近目标区快速改向的弹药形态，可由常规平台发射后按预设航线接近，再以弹体内部控制装置实施小半径偏转；其进入方式不依赖外部持续遥控。 | 在岸防雷达、导引站和纵深点状火力附近连续改变航向，使防御系统难以依据早期航迹稳定预测末段位置。 | 直接效果是迫使防御提前发射或扩大搜索范围，从而增加漏防机会。该装备目前更适合作为高风险技术方向审慎论证，关键边界包括磁流体响应速度、能耗、控制力大小、散热和复杂环境可靠性；若只能产生有限修正量，不能支撑“小半径折转”的作战判断。 |
| **双体耦合巡飞精打弹**：采用前体引导、后体主攻的分体结构，使一次投放形成具有时间和方向差的两段威胁。 | 可由同一发射单元整体进入目标区，前体承担先期探测、诱导或火控暴露，后体保留主战斗部和末段制导；分离动作应由弹体按距离、目标状态或防御反应触发。 | 前体先进入防御视野，消耗搜索和分配资源，后体随后从偏置航向补入，对雷达、导引站或防空节点实施精确攻击。 | 把防御方的一次拦截决策拆成前后两轮，使集中火力难以同时覆盖两个方向和两个时机。其价值取决于分离后的独立飞控、目标交接和后体抗干扰能力；若前体暴露后不能有效牵制，或后体仍沿同一路径进入，双体结构只会增加重量和故障点。 |
| **“玄礁”水下跃升巡飞弹**：采用水下潜行与出水飞行相结合的跨介质结构，将接敌阶段从雷达可见空域转移到水下环境。 | 可由水下平台、近岸隐蔽载体或其他适配发射装置释放，先在水下完成接近，再按任务条件跃升并切换为空中飞控；出水后的目标识别和末端制导必须由弹体独立完成。 | 水下阶段避开空中搜索与部分拦截链，出水后快速识别港湾、登陆点或靠岸舰艇并实施俯冲攻击，重点作用于岸防薄弱区和近岸高价值目标。 | 通过跨越水下与空中两种防御边界，使对手难以用单一岸防或防空程序提前封堵来袭路径。成立边界集中在水下航行稳定性、出水姿态控制、跨介质传感器切换和末段剩余能量；若出水点易被预判或跃升后无法及时完成识别，隐蔽接近优势不能转化为直接战果。 |
