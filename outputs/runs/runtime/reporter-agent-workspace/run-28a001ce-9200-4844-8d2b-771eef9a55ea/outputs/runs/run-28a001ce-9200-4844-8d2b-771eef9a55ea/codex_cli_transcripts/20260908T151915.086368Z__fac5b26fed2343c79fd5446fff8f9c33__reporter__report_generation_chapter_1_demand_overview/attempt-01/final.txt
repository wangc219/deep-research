一、需求分析

（一）需求概述

1. 背景分析
第一岛链拒止环境的核心压力，不是单次打击强度，而是敌方把防空、反导、反无人机和岸基火力编成连续任务链后，能够在探测、分配、拦截、补损之间快速闭合。对低成本巡飞精打弹药而言，真正的战场门槛不在“能不能飞”，而在GNSS受扰、链路间歇、目标伪装和局部失联条件下，能否继续完成发现、识别、接敌和末端命中，并让打击成本仍低于防御方的拦截成本。由此，需求不再是泛化的远程无人打击，而是把弹药本体必须承担的自治导航、末端判别、机动规避、载荷适配和安全中止能力，和只能由外部体系提供的任务规划、情报融合、战区指控严格切开。

在这一压力结构下，群栖自组巡飞精打弹的价值，不在单弹命中率本身，而在多弹把目标选择、攻击轮换和毁伤评估前移到弹体群内，迫使对手的搜索与拦截节奏被拆散；蜂簇接力巡猎精打弹则面对的是对方靠固定周期恢复防空火力的习惯，它用连续回合压力把防御方拖入补位不及的状态；气膜掠波隐巡击弹直接利用海面背景压缩接敌几何，打的是岸基雷达、火控和防空阵位的早期发现窗口；形记忆折展巡飞精打弹与磁流体矢控巡飞精打弹分别把航程与末段机动、可预判航迹与临机折转重新耦合，解决的是“看得见航路却拦不住临机动作”的矛盾；双体耦合巡飞精打弹通过前后体分工把一次拦截拆成两轮决策负荷；“玄礁”水下跃升巡飞弹则把空中拦截链前置失效，专门打港湾、登陆点和靠岸舰艇这类高价值节点。它们面对的是同一威胁环境，但各自改写的交战关系不同，不能用同一句能力口号概括。

2. 需求阐述
本题真正需要的是一组可独立论证的装备需求，而不是一个笼统的“智能巡飞弹药”概念。低成本巡飞精打弹药首先需要弹体本体在干扰环境下保持最低限度的任务闭环，这意味着末端识别、降级导航、失链保持和可控中止必须内生化；若这些能力仍依赖持续联网或稳定外部引导，弹药就只能在理想条件下成立。其次，协同突防并非天然属于弹药本体，只有当多弹可在通信受限时仍维持局部协同、局部重规划和目标分配，群栖自组和蜂簇接力才构成真实需求，否则它们只是外部C2能力的延伸。再次，面对岛链岸防，气膜掠波、折展变形、矢控折转、双体耦合这些路线各自对应不同的缺口：有的缺隐蔽接敌，有的缺临机机动，有的缺拦截分层下的决策扰动，有的缺跨介质突防。需求判断必须回答“缺什么”，而不是先预设型号；如果某条路线不能在受扰条件下给出可审计的直接军事效果，就不能进入需求主干。

3. 项目画像
从项目画像看，这类研究的作用不是替代既有远程火力，而是把低成本规模化打击转化为对敌防空体系的持续消耗能力。群栖自组巡飞精打弹更像是把一轮打击变成群内接力，直接抬高防御方的处理负荷；蜂簇接力巡猎精打弹把一次出动拆成多次命中机会，适合压制和补毁高价值点状目标；气膜掠波隐巡击弹对岸基节点的意义在于缩短发现后反应时间，使对手来不及把拦截资源摆到最优位置；形记忆折展与磁流体矢控两类装备，则是在航程和机动之间寻找新的战术平衡，提升近岸复杂海况下的接敌不可预测性；双体耦合装备强调的是用结构分工制造拦截负担，而“玄礁”水下跃升则把突防维度从海面以下打开。它们共同构成的制胜增量，是让敌方即便维持分层防空，也无法把每次来袭都稳定转换成低成本拦截。其失效边界同样清楚：一旦外部侦察、数据链和任务重规划无法提供最低限度的接口，这些装备的优势会明显收缩，因而本栏更应强调弹药本体的自治下限、抗扰边界和可证伪效果，而不是把系统协同当作默认成立的前提。
