## 一、需求分析
### （二）国内外现状
#### 1. 国外情况
公开资料显示，国外对这类装备的主攻点不是“单机飞得更远”，而是把它放进受限环境下的分布式作战链条里处理。美军公开文件把第一岛链、韧性指挥控制、无人系统和精确火力并列考虑，反无人系统战略则明确把探测、跟踪、识别与主动/被动防护连成一条成本交换链，这意味着防御方已经在按“发现得更早、识别得更快、拦截得更便宜”来压缩巡飞弹药的效能窗口。

更有代表性的公开进展在自治维持上。DARPA CODE展示的重点不是平台外形，而是在通信离线、GPS不可用条件下仍能继续协同执行任务，这说明国外已经把“失链不断、受扰可飞”视为弹药体系的关键门槛。其公开边界也很清楚：现有证据更多证明的是受限通信下的协同自治框架，而不是在复杂海空背景、伪装目标和强欺骗条件下，末端识别与安全中止都能由弹体本体稳定完成。

#### 2. 国内现状（中国）
国内公开论述对巡飞弹药的推进，更多集中在两条线：一是蜂群、自主协同、分布式打击等作战观念，二是与现有发射平台的兼容改造。公开报道中的“飞龙-60A”表明，巡飞弹药正在向火箭炮平台兼容、折叠翼收纳、存储运输发射一体化推进；这类路线的直接价值，是让既有火力平台在不大改硬件的前提下补上察打一体能力，降低列装门槛和补充速度。

但从公开证据看，国内更强的是平台接入和体系想象，弱项仍是弹药本体在高压电磁环境下的独立判别能力。公开材料对蜂群、自组网和“侦控打评保”一体化讲得很充分，也说明国内已把群体协同和低成本规模化看得很重；可一旦场景收束到岛链拒止、GNSS受扰、链路间歇、诱饵目标和分层防空并存，公开可核验的内容就主要停留在概念演示和平台适配层面，缺少足以支撑决策的末端识别、失链保持、降级导航和可审计中止验证。

#### 3. 对比小结
国外公开基线更强调在受限环境里让无人系统继续作战，重点落在自治、韧性C2和反制成本管理；国内公开基线更强调把巡飞弹药嵌入现有火力平台和群体协同框架，重点落在模块兼容、批量应用和体系接入。两者都承认低成本无人系统会重塑防御方节奏，但国外已经把“在干扰和失联下维持有效行动”当作硬门槛，国内公开资料则更多证明“能接入、能组织、能批量用”，还没有同等充分地公开证明“在强干扰与欺骗条件下仍能稳定命中”。

因此，本项目真正的现状判断不是再泛化讨论“智能巡飞”概念，而是要把能力收敛到弹药本体必须独立承担的部分：末端识别、抗干扰导航、失链保持、控制中止和低成本交换比。凡是仍依赖外部ISR、链路持续在线或理想目标环境才能成立的能力，都不能视为装备本体已成熟的直接战果。
