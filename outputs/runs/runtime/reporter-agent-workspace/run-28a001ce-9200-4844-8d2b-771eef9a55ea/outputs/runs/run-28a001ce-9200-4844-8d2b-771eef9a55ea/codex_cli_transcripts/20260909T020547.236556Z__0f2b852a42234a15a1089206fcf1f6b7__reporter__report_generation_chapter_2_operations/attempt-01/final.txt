（二）作战运用模式

#### 1. 作战运用流程

第一岛链拒止环境下，智能巡飞精打弹药的进入条件不是持续联网，而是外部侦察和指挥体系能够提供目标区域、威胁分布及禁打边界，弹药本体在卫星导航受扰、链路间歇和目标伪装条件下仍能完成末端导航、目标判别、攻击决策和必要中止。外部体系负责粗分任务和选择发射窗口，不能替代最后一段交战判断。

群栖自组巡飞精打弹适合目标分散、防御节点较多且需要连续压迫的场景。多枚弹体进入目标区后，在局部规则下完成搜索分工、目标接替和攻击排序，个别弹体被拦截或失链时，剩余弹体仍能重排任务。其决定性动作是把目标选择和毁伤评估从后方链路前移到弹群内部，使敌方雷达、火控、发射阵位和舰艇必须反复搜索、分配和转火。直接战果不是单弹命中率的简单提高，而是迫使防御体系进入持续补位、频繁换向和拦截资源被切碎的状态。若群内协同必须依赖稳定通信，或局部识别无法在受扰条件下成立，其“自组”优势将退化为普通数量投放。

蜂簇接力巡猎精打弹适用于近程拦截密集、但防御纵深有限的节点。载体接近后分批释放攻击单元，前导单元先诱发雷达开机、火控分配和拦截消耗，后续单元再利用已暴露的火力点或目标转移痕迹实施补位攻击。它改写的是防御时间节奏：敌方不能在完成首轮拦截后立即恢复隐蔽、换防和集中射击。直接效果是延长防空系统的持续占用时间，并增加对雷达、火控设备和临时暴露目标的连续打击机会。若释放时序、目标分发或单元接续依赖理想链路，前导消耗便不能转化为后续毁伤。

气膜掠波隐巡击弹面向近岸、港湾外缘和岛礁周边的低空防御薄弱区。弹体利用贴海飞行和海面背景压缩敌方从发现到稳定跟踪的时间，先逼近岸基雷达、火控节点和近岸防空阵位，再在末段完成识别和攻击。其关键动作不是增加攻击数量，而是改变来袭目标与探测背景的几何关系，使对手由主动组织拦截转为仓促反应。直接战果优先表现为低空预警迟滞、观察和火控节点短时失能，继而削弱后续拦截。海况、气象、近海障碍、低空补探测和末段抗干扰识别一旦不利，掠波优势就不能稳定转化为命中效果。

形记忆折展巡飞精打弹解决的是远距离巡航与末段机动难以兼顾的矛盾。巡航阶段保持有利于航程的外形，接敌后通过折展结构改变翼面和盘旋半径，对沿岸舰艇、机动发射车及临机点目标实施再搜索和快速转向。它打破了防御方依据早期航迹预设拦截点的做法，使对手即使掌握大致来向，也难以在末段建立稳定提前量。直接战果是增加临机目标再捕获和末段修正机会。其成立依赖折展机构、结构承载和飞控补偿同步工作；若变形造成姿态扰动或能量损失，航程与机动兼得的效果便会被可靠性问题抵消。

磁流体矢控巡飞精打弹主要用于压迫岸防雷达、导引站和纵深点状火力。弹体在末段通过磁场驱动流体重新分配，形成连续侧向偏转和小半径折转，使敌方难以沿单一弹道完成提前拦截解算。决定性动作发生在敌方已经建立跟踪、但尚未完成稳定火控的阶段；弹体连续改变航迹，迫使防御方提前发射、重复修正或放弃较优拦截窗口。直接效果是增加拦截失配和弹药消耗，为后续精确毁伤创造机会。若磁控响应慢于敌方火控闭环，或者能源和导航稳定性不足，轨迹变化就可能变成不可控偏差，而不是有效的不可预测性。

双体耦合巡飞精打弹适合防空节点位置较明确、但集中拦截能力较强的场景。前体承担引导、诱发搜索和吸引火力的任务，后体从偏置方向切入末攻，将一次来袭拆成两个相位不同的防御事件。前体造成的雷达开机、火控暴露和资源偏移，为后体攻击防空节点创造窗口。其直接战果是把同一消耗单元转化为“诱发暴露加末段毁伤”，压低敌方对主攻体的集中拦截效率。该路线区别于蜂簇接力的核心在于前后体时序和方向耦合；若分离、目标继承或偏置航向失配，双体设计反而会增加故障点。

“玄礁”水下跃升巡飞弹用于港湾、登陆点、靠岸舰艇及近岸设施。它先在水下接近，绕开以雷达和空中拦截为主的常规发现链，接近目标后跃升出水，立即完成姿态转换、末段识别和俯冲攻击。它改变的是防御介质和处置程序，使敌方难以用同一套岸防流程同时覆盖水下接近、出水暴露和空中末攻。直接战果是压缩港湾和登陆支撑点的反应时间，打乱靠岸舰艇或近岸设施的机动、卸载和组织节奏。水下航行、跃升瞬态、出水后快速识别和海况适应任一环节失稳，跨介质突防效果都会迅速下降。

#### 2. 链路闭环分析

本项目的制胜链条应是“外部提供边界，弹体完成判断，局部形成闭环，结果再回传”。任务规划、外部侦察和指挥链可以提供目标区域、威胁等级、禁打规则和初始航路，但末端制导、抗干扰导航、目标识别、飞控、载荷使用和安全中止必须由弹药本体承担。否则一旦通信受压制或目标实施欺骗，所谓智能化能力就会退化为依赖理想网络的遥控攻击。

不同装备的闭环断点并不相同。群栖自组弹要证明局部节点损失后仍能完成目标分配和攻击接替；蜂簇接力弹要证明释放后的单元能够独立搜索、补位并在错误目标或威胁消失时受控中止；掠波弹要证明贴海控制确实压缩了敌方火控窗口；折展弹要证明构型变化带来的机动收益超过机构复杂性；磁流体矢控弹要证明快速偏转仍能收敛到目标；双体耦合弹要证明前体诱发能够真实转化为后体命中机会；“玄礁”则要证明水下接近和跨介质转换不会吞噬出水后的识别时间。

对手可能通过增加低空和海面探测、缩短雷达开机时间、使用诱饵目标、分散防空节点和提高近程拦截密度进行反适应。因此，各装备的直接效果不能用同一套突防或命中指标替代。只有在降级通信、导航受扰、目标欺骗和局部单元损失条件下，仍能完成各自的关键动作并形成可审计战果，相关作战模式才具备稳定成立的基础。
