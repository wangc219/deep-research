## 二、项目画像

### （四）主要战技指标

群栖自组巡飞精打弹的判别重点，不在单弹航程，而在群内自治能否在GNSS受扰、链路间歇和伪装目标并存时继续完成目标重分配与攻击轮换。首要指标应看“失链后重分派完成率”和“真假目标混编下的末段误击抑制”，因为它们直接决定群体能否把防御方拖入持续应对，而不是一次性对冲。验证时必须在通信降级和目标遮蔽条件下检验，不能只看联网状态下的集群演示。

蜂簇接力巡猎精打弹的核心不是一次命中，而是前导单元先逼出拦截与暴露、后续单元再接续补位。指标应抓“分发后连续打击保持率”和“前后波次在拦截压力下的接战间隔压缩”，前者决定攻击链是否断裂，后者决定防御是否来得及换防和集中拦截。若多单元释放后只能各自飞行、不能形成接力压力，这类方案就失去其制胜意义。

双体耦合巡飞精打弹不看单体弹道多漂亮，而看前体引导开机后能否把防御第一次拦截变成两轮决策。指标应抓“前体诱导后后体接管的航向偏置保持率”和“二段补入时的末攻时间误差”，因为它们决定前段是否真能消耗搜索与分配资源、后段是否还能从偏置航向完成命中。验证要在分层防空与近程拦截并存条件下进行；若耦合段一旦失配就只剩单次消耗，这种设计就失去拆分拦截窗口的意义。

气膜掠波隐巡击弹最关键的是把接敌几何压进海杂波和雷达地平线以下，因此指标应是“贴波高度保持稳定性”和“末段识别在海杂波背景中的有效判别率”。这两项直接对应其压缩探测、跟踪和拦截窗口的能力。验证应放在不同海况、不同岸基雷达俯仰角和强杂波背景下；若一遇海况上升就丢失高度或误识别，掠波隐巡的战术价值会明显下降。

形记忆折展巡飞精打弹的判别点在于巡航低阻与接敌机动能否通过同一弹体顺畅切换。应看“折展动作重复可靠性”和“展开后的转弯半径压缩幅度”，因为这两项决定它能否在接敌末段把大致航路转成临机攻击窗口。验证必须覆盖反复折展、热-振-载耦合和接敌瞬间姿态切换；若折展后控制裕度不足，低阻航程换来的机动优势就会被结构失稳抵消。

磁流体矢控巡飞精打弹的价值在于用快速侧向偏转打乱防御提前量，所以指标应聚焦“指令到侧向力建立的响应时延”和“小半径折转下的轨迹可变范围”。前者决定对手是否来得及提前发射，后者决定它能否持续改写可预判航迹而不只是一次性偏移。验证要在风场扰动和能量受限条件下做闭环试验；若磁流体驱动响应慢于火控修正节奏，便难以形成实际漏防。

“玄礁”水下跃升巡飞弹的关键不在水下航行本身，而在跨介质出水后能否迅速完成识别并转入末攻。指标宜看“出水后目标接管时间”和“跨介质后命中链连续性”，因为它们直接决定能否把岸防与防空的两套程序撕开。验证必须同时覆盖近岸浪涌、出水姿态偏差和水面到空中识别切换；若出水后目标接管迟滞，水下潜伏带来的隐蔽收益就会在末段丢失。
