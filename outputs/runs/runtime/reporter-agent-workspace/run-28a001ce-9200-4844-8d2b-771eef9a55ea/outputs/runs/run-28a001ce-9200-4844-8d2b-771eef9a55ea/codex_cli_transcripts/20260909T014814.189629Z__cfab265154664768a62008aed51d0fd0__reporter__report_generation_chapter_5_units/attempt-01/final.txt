## 五、研制基础

### （一）参与单位

本项目参与单位不宜按“总体、分系统、试验”套用通用分工，而应按弹药本体在拒止环境中必须独立承担的责任反推。总体责任单位应具备智能巡飞弹药产品定义、弹体安全性、任务闭环和成本约束的统筹能力，能够把末端识别、抗干扰导航、飞控控制、战斗部适配、发射兼容和证据交付纳入同一产品基线；外部侦察、任务规划和指挥控制单位只能作为接口保障单位，不能替代弹药本体完成受扰条件下的末段判断。

群栖自组巡飞精打弹的承研核心，应是具备无人集群任务控制、弹载自治决策和多弹协同安全约束能力的总体单位，配套方重点承担低成本弹体、分布式通信、边缘识别、毁伤评估和批量生产一致性。其试验责任不能停留在多弹联网演示，必须由试验鉴定单位组织链路间歇、导航受扰、部分节点失效条件下的目标分配、攻击轮换和损毁评估验证；公开依据不足之处在于尚缺可审计的降级协同成功率、误识别处置和成本消耗边界。

蜂簇接力巡猎精打弹的主责单位应同时掌握母弹释放机构、小型攻击单元、序列化搜索打击逻辑和弹内任务分发。关键配套单位包括微小型动力与供电、折叠或收纳结构、单元间短距通信、末段识别和小型战斗部单位。它的试验重点不是单个子弹命中，而是前导单元诱发暴露、消耗拦截后，后续单元能否补位形成连续毁伤；目前缺少公开释放可靠性、单元失效后的任务重排和多回合压力对防御恢复周期影响的证据。

气膜掠波隐巡击弹应由低空飞行器总体与海面复杂环境控制能力较强的单位牵头，配套涉及近海贴波飞控、海杂波背景下目标识别、抗盐雾材料、低空测控和岸海靶场保障。其关键接口在于任务规划只给出威胁区和目标区，贴波保持、末段规避和命中判别必须由弹上系统完成。试验单位需交付不同海况、风场和电磁压制下的飞行稳定、探测暴露和末攻可靠性证据；公开材料不足以确认气膜或掠波机理在可消耗弹药上的工程余度。

形记忆折展巡飞精打弹的参与单位应突出智能材料结构、折展机构、气动外形和飞控重构的耦合能力。其制胜点来自巡航低阻与接敌机动的状态切换，因此承研方必须证明变形过程不会破坏导航、识别和战斗部安全；配套单位应覆盖形状记忆材料、轻量化承力结构、作动控制和疲劳试验。公开缺口主要是折展寿命、温度敏感性、变形后气动稳定和批产成本。

磁流体矢控巡飞精打弹更适合由新概念控制执行机构与弹药总体联合承担预研责任，不能直接并入成熟巡飞弹生产线。相关配套应包括磁场控制、电源管理、流体密封、热管理和高速姿态测量单位。它面对的是防御方按可预测航迹提前拦截的矛盾，试验鉴定必须证明侧向偏转响应、能耗、密封可靠性和末段识别之间不存在互相挤占；当前公开依据不足以支撑工程成熟度判断，只能列为高风险探索方向。

双体耦合巡飞精打弹的主责单位应具备分离体气动、前后体任务接续、诱导暴露和主攻命中闭环能力。关键配套集中在可靠分离、前体传感诱导、后体制导接管、偏置航向控制和安全保险。试验责任应覆盖前体被拦截、失联或误诱导后，后体是否仍能完成目标确认与末攻；缺少公开证据时，不得把“两轮拦截负荷”直接等同于有效毁伤。

“玄礁”水下跃升巡飞弹涉及跨介质发射和末段空中打击，应由水下航行器、弹药总体、出水姿态控制和末段识别单位共同承担，但需要明确单一产品责任边界。配套单位包括水密壳体、出水转换动力、惯性导航、近岸目标识别、港湾靶场和水下试验保障。其证据交付重点是潜行隐蔽、出水稳定、空中识别和俯冲命中的连续链条；公开依据不足以确认水下段、出水段和空中段在低成本约束下能同时成立。
