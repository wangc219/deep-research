三、总体方案

（一）总体架构

总体架构按七类装备改变交战关系的方式分层配置，而不抽象为同一种“智能巡飞弹平台”。群栖自组巡飞精打弹把目标选择、攻击排序和损毁评估部分下沉至弹群，用多方向接敌打乱防空系统的搜索、分配和拦截节奏；蜂簇接力巡猎精打弹依靠单一载体的释放时序，将前导单元的诱发暴露、资源消耗与后续单元的补攻衔接起来，把一次拦截转化为连续处置压力。气膜掠波隐巡击弹以贴海低空和海面背景遮蔽缩短稳定跟踪时间，主要压迫岸基雷达、火控和近程防空节点；形记忆折展巡飞精打弹则在巡航低阻与末段变形机动之间切换，扩大对沿岸舰艇、机动发射车等临机目标的航路调整空间。磁流体矢控巡飞精打弹通过快速侧向偏转和小半径折转破坏拦截航迹外推，双体耦合巡飞精打弹以前体诱发开机、后体偏置补攻增加防御方的连续判别负荷；“玄礁”水下跃升巡飞弹利用水下接近、出水重建和俯冲攻击改变来袭介质，压缩港湾、登陆点及靠岸舰艇的预警纵深。

多型装备真正共享的应是任务装订、目标合法性约束、发射兼容、状态报告、失链处置权限和安全中止接口，而不是飞行、变形或跨介质机理。外部情报侦察与指挥控制体系提供任务区域、禁攻边界、目标优先级及必要的重规划信息；弹药本体必须保持导航、飞控、末端识别以及命中或中止判别。若把持续目标指示、全程联网协同或战区融合态势当成本体能力，受干扰条件下的直接战果将被高估。

衔接上，群栖自组弹适合制造入口压力，蜂簇接力弹负责延长同一方向的攻击回合，掠波弹与水下跃升弹从不同介质压缩防御反应时间，折展弹、磁流体矢控弹和双体耦合弹承担特定末段机动或分段突防。失败耦合集中于共同目标数据、导航基准和授权规则：目标装订错误可能使多型弹药同时攻击伪装目标；导航欺骗会同时削弱编组协同、变形机动和出水末攻；通信受压时若自治权限不清，则可能出现等待、重复攻击或误入禁区。因此建设顺序应先确保抗扰自治、失链保持和可控中止，再扩展复杂协同与跨介质能力；缺少公开试验支撑的性能只能作为待测变量。
