三、总体方案

（一）总体架构

总体架构采用“外部任务筹划、弹药自主执行、结果回传评估”的分层方式。指挥信息、情报侦察系统只提供目标类别、威胁区域、禁入边界和任务优先级，不把持续联网作为成立前提；弹药本体承担飞控、末端识别、导航降级、攻击或中止决策。各型装备共用发射兼容、任务装订、状态报告和安全授权接口，但不共用专属飞行机理。共同失效点是目标数据过时、授权链中断或保障接口不统一；因此必须允许断链后按最近一次有效任务状态继续或受控退出。

群栖自组巡飞精打弹由弹群内部完成目标分配、攻击轮换和损毁评估，外部只设定打击边界与优先序。其不可替代作用是把单弹突防转为持续压力；通信受压时应由局部节点维持编组，若身份确认或共享态势失效，群体可能退化为无序单弹，连续毁伤效果随之消失。

蜂簇接力巡猎精打弹的核心不在多弹联网，而在单一载体对攻击单元的释放时序和任务分发。前导单元负责暴露或消耗拦截资源，后续单元接替精打；若释放机构、单元识别或时序控制失败，整枚载体的多回合优势将坍缩为一次性攻击。

气膜掠波隐巡击弹依靠本体贴海飞行和海面背景遮蔽逼近岸基雷达、火控与防空节点，外部体系只需提供海区限制和目标线索。其效果受海况、气象、海面杂波和高度控制精度共同约束，不能用群体协同能力替代。

形记忆折展巡飞精打弹以巡航阶段低阻和接敌阶段变形机动换取航迹不确定性，重点攻击沿岸舰艇、发射车等临机目标；其架构应单独保证折展机构的重复可靠性和变形后的飞控重构，机构卡滞会同时损失航程与末段机动。

磁流体矢控巡飞精打弹通过磁场驱动侧向偏转和小半径折转，改写防御方对航迹的预测，适合压迫雷达、导引站等点状节点。该能力依赖快速状态感知、磁流体响应和能量管理，不能把普通航迹规划接口视为等效替代；控制响应不足时，突防收益将转为能耗和失速风险。

双体耦合巡飞精打弹由前体引导开机、后体偏置补入末攻，把一次拦截拆成连续决策负荷。总体架构必须管理双体间的时间、位置和目标状态交接；任一环节延迟都会使后体重新暴露在已建立的拦截链中。 “玄礁”水下跃升巡飞弹则以水下潜行避开雷达视线，出水后迅速完成识别和俯冲攻击，关键接口是跨介质状态切换与末端授权。其失效主要来自出水位置误差、姿态重建和水面环境变化，不能按空中巡飞弹的导航边界验收。
