## 三、总体方案

### （二）子系统方案

本项目不采用单一巡飞弹体加统一控制软件的方案，而按不同装备改变交战关系的方式分别配置飞行、任务控制、末端效应和外部接口。各装备的共同边界是：任务规划、外部侦察和指挥链提供初始条件，但弹药本体必须在链路间歇、导航受扰或局部节点失效时完成最低限度的安全飞行、目标判别和任务收束；具体性能不得由概念推演直接转化为确定指标。

| 装备 | 产品形态与控制机理 | 必要输入、输出及关键接口 | 工程验证与成立边界 |
|---|---|---|---|
| 群栖自组巡飞精打弹 | 由多个具备独立飞控、末端识别和任务执行能力的弹体组成，核心不是持续集中遥控，而是由弹体之间分担目标选择、攻击排序和损毁评估。控制规则应支持通信稀疏、节点退出后的局部重规划，使群体仍能保持攻击方向和任务优先级。 | 输入包括初始任务意图、有限目标线索、个体位置状态和邻近弹体健康状态；输出为目标分配、攻击角色、撤止或补位状态。接口重点是低带宽任务指令、时间基准和状态回报，不把持续联网作为成立前提。 | 先验证通信中断、导航受扰和个别成员失效条件下的任务连续性，再验证多目标分配与损毁评估是否会出现重复攻击或集体失控。其优势仅在协同规则确能降低防御方分配效率时成立；若必须依赖全连接链路，则不能证明相对单弹基线的价值。 |
| 蜂簇接力巡猎精打弹 | 采用一个母体携带多个小型攻击单元的构型，母体负责接敌、搜索和释放管理，攻击单元按时序接替完成末段任务。控制重点是释放间隔、前后单元角色转换和目标信息交接，以连续压力代替一次性齐射。 | 需要母体航迹、释放状态、前导单元探测结果和后续单元可用状态；输出包括释放次序、目标分发和末段攻击授权。关键接口是安全分离、单元唤醒、信息交接及故障隔离，不能把任何一个小单元的失效等同于整弹任务失败。 | 验证应覆盖携带状态下的飞行稳定、连续释放可靠性、前导单元失效后的重排以及防御暴露后能否完成后续补位。若释放机构、重量或可靠性使母体无法保持基本航程和控制余度，连续多回合压力就不成立。 |
| 气膜掠波隐巡击弹 | 以贴近海面飞行和海面背景遮蔽为主要生存手段，飞控不是简单保持固定高度，而是根据海况、姿态和探测结果在安全飞行与隐蔽接敌之间切换。末端系统需在接近岸基雷达、火控和防空单元时完成目标确认。 | 输入包括海面相对高度、速度姿态、海况变化和目标线索；输出为掠海航迹、避障动作和末端攻击状态。接口集中在发射初始航向、外部目标指示与末端识别之间，外部链路中断后仍须维持自主航迹。 | 工程验证要把海况扰动、传感器受水汽和浪面反射影响、低空突变机动放在同一试验链中，观察飞控是否出现高度丢失和误识别。其成立依赖海面遮蔽确实压缩对手探测和反应时间；面对高位探测或连续低空覆盖时，效果边界必须单独测定。 |
| 形记忆折展巡飞精打弹 | 采用可折展翼面或骨架，在巡航阶段保持较低阻力，在接敌阶段改变翼面和盘旋特性，以获得临机转向和短时盘旋能力。控制系统必须把结构变形状态纳入飞控，而不能先变形、后由普通飞控被动修正。 | 输入包括任务阶段、剩余能量、目标几何关系和结构温度或变形状态；输出为翼面构型、航迹模式和末端接敌姿态。关键接口是热控、电源、结构锁止和变形反馈，任何一个状态未确认都应触发限幅或中止。 | 重点验证多次折展后的结构一致性、变形过程中的姿态扰动、低能量状态下的可控性以及临机目标条件下的模式切换。若变形带来的机动收益不足以抵偿重量、热管理和故障率增加，则应退回固定翼或简化折展路线。 |
| 磁流体矢控巡飞精打弹 | 将磁流体受磁场驱动产生的侧向作用用于快速修正航向，产品形态更接近高功率矢量控制弹体，而非传统舵面放大。其关键是把电磁驱动、飞控预测和末端制导合成一个闭环，形成连续变化而非单次突变的接敌轨迹。 | 输入包括当前速度姿态、期望转向量、剩余能源和威胁方向；输出为侧向控制量、航迹修正和末端攻击姿态。接口必须处理电源、散热、磁场驱动与制导计算的优先级，避免大幅机动耗尽末段效应所需能量。 | 应验证控制响应延迟、能源消耗、重复修正能力及高动态状态下的导航稳定性，并与常规气动控制在相同干扰条件下比较。若矢控只能在理想能源和温度条件下工作，或无法形成可重复的姿态收益，则不能据此宣称提高突防效果。 |
| 双体耦合巡飞精打弹 | 由前体引导单元和后体主攻单元组成，前体先承担探测、诱导或消耗防御资源，后体依据偏置航向完成主攻。两部分不是简单串联，而是通过接敌时序和相对位置把一次拦截转化为连续决策负荷。 | 输入包括前体发现信息、前后体相对状态、后体攻击窗口和目标更新；输出为前体任务终止、后体接替和末段攻击授权。接口重点是分离安全、相对导航、目标信息交接和后体独立接管，前体失效时不得造成后体无条件失控。 | 验证应覆盖前体先行、偏置补入、通信受限和前体被拦截等情形，确认后体能否保持独立攻击链。若两体分离误差、时序误差或信息交接误差扩大到无法稳定接替，其对集中拦截的分解作用即失去依据。 |
| “玄礁”水下跃升巡飞弹 | 采用水下潜行、跨介质跃升和空中末段打击的复合构型。水下阶段重点是隐蔽接近和航迹保持，出水后立即切换为空中飞控与末端识别，不能用一套控制律覆盖两个介质环境。 | 输入包括水下航行状态、跃升窗口、海面目标线索和出水后的识别信息；输出为跃升时机、空中接敌航迹和末端命中或中止状态。关键接口是水下导航、跨介质姿态转换、密封与动力切换，以及出水后传感器快速恢复。 | 首先验证水下航行与出水转换的重复性，再验证不同海况、目标机动和识别数据不完整时的末端收束。该方案不能默认水下潜行必然突破防区；其价值取决于转换过程不暴露、出水后仍保有足够识别与控制余度。
