二、项目画像

（一）装备图像概述

| 装备 | 核心技术与形成能力 | 部署或进入方式、作用对象 | 关键动作、作用对象和直接效果 |
|---|---|---|---|
| 群栖自组巡飞精打弹 | 将目标选择、攻击排序和毁伤复判的一部分下沉到弹体群，通过局部协同、分布式识别和失链降级规则，使弹群在导航受扰、链路间歇时仍能维持有限的任务连续性。相对单枚巡飞弹，其不可替代性在于个体受损后可由其他弹体接替，而不是单弹性能简单提高。其成立前提是弹体具备独立末端识别、航迹保持和安全中止能力；公开材料尚不足以证明其在完全失联和强欺骗条件下仍能稳定完成群体协同。 | 采用多枚分散进入方式，面向第一岛链防空与反舰体系中的舰艇、岸基雷达、导引站和发射阵位。外部侦察、初始目标指示和任务规划只能作为接口保障，不能替代弹体本身的末端判别。 | 弹群在接敌中根据目标状态和成员损耗调整先后次序、攻击方向与补打关系，先压迫传感器和火力节点，再利用防御链条出现的间隙实施连续攻击，直接造成雷达失能、发射阵位受压或局部防区瘫痪。对手若采取区域封锁、持续干扰和快速目标关联，其优势将转化为对失链规则、导航降级和单弹自治可靠性的更高要求。 |
| 蜂簇接力巡猎精打弹 | 由一个载体携带并按时序释放多个小型攻击单元，使搜索、诱导暴露、任务分发和末段攻击形成连续链条。与一次性齐射不同，它把一次投放机会转化为多轮交战压力：前导单元迫使防空系统开机、跟踪或消耗拦截资源，后续单元再利用暴露窗口完成重点毁伤。载体释放可靠性、单元间识别、重量分配和载荷剩余空间是关键边界。 | 由兼容平台在防区外缘或接敌阶段投放，随后分批释放攻击单元，主要作用于防空搜索雷达、火控节点、近程拦截单元及其支援阵位。具体投放平台、单元数量和航程档位尚未给定，不能据此推定实际规模或部署方式。 | 前导单元从多个方向制造低成本威胁，诱发雷达暴露、火力分配和拦截发射；后续单元趁对手换防、再装填或重新分配之际补入关键方向，直接压缩防御体系的恢复时间和连续拦截窗口。其效果是增加持续突防压力而非保证每个单元命中；若对手采用分散部署、被动探测和拦截储备管理，接力优势会明显减弱。 |
| 气膜掠波隐巡击弹 | 依靠近海气膜减阻、掠波飞行和自主高度保持，使弹体长期贴近海面背景飞行，将接敌几何压低到岸基雷达较难稳定发现和连续跟踪的高度层。相较普通巡飞弹短时降低高度的做法，其核心变化是持续维持低空背景遮蔽，而非依赖末段突降。海况、风浪、导航误差和末端识别精度决定其可用程度。 | 从海上方向沿近海低空进入岸防体系，主要针对岸基雷达、火控站、近程防空阵位和沿岸传感器节点。贴波控制必须由弹体自身完成，不能假设持续外部引导或稳定通信。 | 在被稳定跟踪前保持贴海航迹，接近目标后切换末端识别和攻击航迹，使防御方的发现距离、跟踪持续时间和拦截准备时间同时缩短，直接提高关键节点漏防和迟滞处置的可能性。海况恶化、多点低空补盲雷达投入或弹体无法维持安全高度时，海面背景带来的隐蔽优势将迅速消失。 |
| 形记忆折展巡飞精打弹 | 使用形状记忆折展骨架，在巡航阶段保持较低阻力，在接敌阶段改变翼面、升阻特性和盘旋半径，使远距离接近与末段临机机动由同一弹体承担。相对固定翼巡飞弹，它可在不更换投放平台的情况下调整最后一段接敌走廊，但折展机构重复可靠性、展开后的气动稳定性和结构重量代价仍缺少公开定量依据。 | 需要由能够容纳折叠构型的外部平台投放，具体发射平台和进入高度尚未确定。其适用对象包括沿岸舰艇、机动发射车和临时暴露点目标，尤其适合目标位置变化或预设航路容易被防御方掌握的场景。 | 先以折叠低阻构型完成接近，再在目标区展开翼面、改变盘旋半径或转入新的攻击方向，使防御方难以仅依据前段航路封闭末段拦截扇区，直接提高对机动目标和临时目标的到达机会。若展开延迟、机构卡滞或目标区空间不足，航程与末段机动兼得的制胜机理将不能成立。 |
| 磁流体矢控巡飞精打弹 | 通过磁场驱动磁流体重新分配，产生侧向偏转和小半径转向，试图减少传统舵面和固定推力布局对航迹的限制。其与常规气动控制的根本差异，是能够连续改变末段接敌方向，而非依靠少数预设机动动作。目前响应速度、能量消耗、结构密封和高动态控制效果均缺少公开试验证据，属于高风险技术路线，不能直接等同于成熟突防能力。 | 进入岸防纵深后，面向雷达、导引站和点状火力节点实施非固定方向接敌。其外部进入方式仍可能采用常规巡航，但末段航迹整形须由弹体矢控系统完成；若能量供应或控制回路不稳定，外部链路无法弥补本体缺陷。 | 在末段连续改变航迹，使防御方难以按单一弹道提前配置拦截点，可能迫使其提前发射或扩大火力覆盖，直接增加拦截资源消耗和漏防概率。若矢控响应不足、能量中断或目标识别更新滞后，复杂机动会放大导航误差，导致失靶、误攻或提前中止。 |
| 双体耦合巡飞精打弹 | 以前体承担引导、诱导或暴露防御反应，后体保留主攻任务，通过时序差、偏置航向和双体任务分工，把一个消耗单元转化为两轮防御决策压力。相对单体弹，它改变的不是单纯射程或载荷，而是拦截节奏；前后体释放、间隔控制、目标归属和末段协同必须稳定，否则将退化为两个缺乏配合的独立目标。 | 以双体组合状态进入防区，接敌后前体先行、后体从偏置方向补入，主要作用于防空雷达、导引站和前沿火力节点。初始任务与必要更新可由外部系统提供，但双体间的基本时序和动作应能在通信受限时保持。 | 前体先诱发搜索、跟踪和火力分配，迫使防御方暴露拦截意图；后体随后改变进入方向完成主攻，使一次拦截决策被拆成连续两次判断，直接降低防御方集中拦截效率并增加关键节点被命中的机会。若对手具备统一火控、快速目标关联和多源航迹融合能力，双体造成的额外判断负荷可能被压缩。 |
| “玄礁”水下跃升巡飞弹 | 以跨介质航行连接水下隐蔽接敌和空中末段精打：水下阶段规避岸基雷达和部分空中拦截链，接近目标后跃升出水，再依靠末端识别转入俯冲攻击。其不可替代性在于改变来袭目标的介质和暴露时机，而非单纯增加空中航程。跨介质结构可靠性、出水姿态控制、近岸水文适应和出水后的短时制导是主要失效点。 | 从水下方向接近港湾、登陆点或靠岸舰艇，在目标附近跃升进入空中末段。该路线不能被扩展解释为具备长期水下巡航或任意海域部署能力；具体发射方式、潜行时间、适用水深和末段识别条件尚未给定。 | 先以水下航迹绕开常规岸防搜索，再在目标附近突然出水、完成识别并俯冲攻击，使防御方难以按单一空中航路提前配置雷达和拦截火力，直接增加港湾、近岸舰艇和登陆点的防护盲区。若水下航行受海况限制、出水位置易被预测，或出水后留给识别和制导的时间不足，跨介质进入优势将难以转化为稳定战果。 |
