## 五、研制基础
### （一）参与单位

从公开材料看，这类岛链拒止环境智能巡飞精打弹药并不对应单一成熟型号，更像由若干能力方向拼接出的装备族，因此参与单位应按“谁承担本体、谁负责接口、谁负责试验、谁交付证据”来倒推，而不是沿用通用承研分工表。就本体责任看，弹体总体、飞控制导、末制导识别和抗扰导航应由具备小型精确制导弹药或无人机弹药研制能力的总体单位牵头；其直接证据应包括失链保持、末端判别、降级中止和贴海/低空控制的可审计试验记录。就接口责任看，任务规划、协同突防、边缘重规划和数据链适配更可能由信息化作战系统、嵌入式算法或任务载荷单位承担，但公开依据不足，不能据此反推具体院所或公司名称。

分机责任上，群栖自组、蜂簇接力和双体耦合类构型的关键，不在概念口号，而在弹上协同逻辑、分离机构、时序控制和末段再分配是否能在通信受限条件下闭环；因此应由负责弹上软件、嵌入式控制和发射兼容的单位承担核心接口。形记忆折展、磁流体矢控和气膜掠波方向，则更依赖材料、结构、机动控制与海空环境耦合试验单位，公开材料若未披露风洞、海试、弹道或跨介质试验链，便只能确认存在此类技术依赖，不能确认具体承研主体。“玄礁”这类跨介质跃升构型还要求水下段、出水段和空中末段分别有人负责工况验证，试验责任通常应分置于水动力、飞行试验和末制导鉴定单位之间，但现有公开证据不足以锁定单位名称。整体看，本栏能确认的是参与单位类型和能力边界，不能确认具体归属；缺失的正是可公开核验的型号归口、试验分工和证据交付链。
