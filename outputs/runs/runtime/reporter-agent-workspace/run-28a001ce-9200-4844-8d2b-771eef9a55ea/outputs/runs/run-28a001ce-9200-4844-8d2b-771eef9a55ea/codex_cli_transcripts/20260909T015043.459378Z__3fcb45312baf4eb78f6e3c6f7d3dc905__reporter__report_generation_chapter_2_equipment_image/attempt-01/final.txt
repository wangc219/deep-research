## 二、项目画像

### （一）装备图像概述

| 装备对象 | 核心技术与形成能力 | 部署或进入方式、作用对象 | 关键动作与直接效果 |
|---|---|---|---|
| 群栖自组巡飞精打弹 | 以多枚弹体间的局部协同、目标分配和损毁评估替代对单一外部链路的完全依赖，使弹群在通信不连续、定位受扰时仍能维持有限编组和任务接续。其不可替代之处不在于单枚弹的巡飞，而在于把搜索、选择、攻击轮换和战果判断分散到弹群内部；若协同规则只能在持续联网条件下成立，则不能形成预期能力。 | 由空中或远程发射平台批量释放，主要进入岛链外缘至岸防纵深的接敌空域，作用对象包括舰艇、岸基雷达和反舰导弹发射阵位。外部侦察和指挥系统可提供初始区域、威胁等级或禁攻约束，但不应被假定持续承担末端目标选择。 | 弹群先分散接近并建立局部态势，再按威胁变化调整侦察、诱导和攻击次序；部分弹体被拦截或失联后，剩余弹体仍能重新分配目标并完成末端突击。直接结果是把防御方固定的发现、分配、拦截节奏变成多点同时处置压力，增加关键节点漏防和连续失能的可能。 |
| 蜂簇接力巡猎精打弹 | 将多个小型攻击单元装入同一载体，由母体完成运输、释放和初始任务管理，再由单元分别搜索、识别和攻击。该路线以“载体一次进入、弹药多轮作用”提高单次出动的目标覆盖和库存使用效率；其边界在于释放机构、单元间隔离、末端识别和总体可靠性必须同时满足要求，任何一项失控都会抵消数量优势。 | 适合从防区外平台或远程发射装置进入防空覆盖区，作用对象可按先暴露防空、后打击雷达、火控和舰艇的顺序安排。外部系统负责任务区域和优先级设定，载体与子单元则承担接敌后的分发和局部决策。 | 前导单元先进入高威胁方向，迫使防御方开机、分配拦截资源或暴露火控位置；后续单元根据前一轮结果改变方向和目标，补入末段完成毁伤。直接效果不是单次突击强度增加，而是延长防御方的连续应对时间，压缩其换防、补弹和重新组织拦截的间隔。 |
| 气膜掠波隐巡击弹 | 依靠贴近海面的低空飞行控制、海面背景利用和末端自主识别，把弹体航迹压入岸基雷达较难稳定分离的背景区。核心能力是稳定维持低空接敌并在海况、风场和通信受限条件下完成姿态与航向控制，而非简单追求低飞高度；若只能在平静海况或完整外部引导下飞行，其隐蔽接敌价值会明显下降。 | 从海上或空中平台进入近岸海域，沿海面方向逼近岸基搜索雷达、火控雷达和近程防空单元，也可针对靠岸舰艇。外部侦察可提供岸线和目标区域，但贴波航行、末端修正和攻击时机须由弹体自身保持。 | 弹体利用海面遮蔽缩短有效预警距离，在接近目标后快速完成识别、转向和俯冲或侧向攻击，减少防御系统从发现到稳定跟踪再到拦截的可用时间。直接效果是提高关键节点遭到突然打击的概率；其成立取决于海况适应性、低空导航误差和末端识别抗欺骗能力。 |
| 形记忆折展巡飞精打弹 | 采用可折展翼面或形状记忆结构，在巡航段保持较低阻力，在接敌段改变展弦比、转弯性能或盘旋范围，使航程与临机机动不再由同一气动状态决定。制胜机理是临近目标时改变可预测航迹，而不是单纯延长滞空时间；折展响应迟滞、反复动作可靠性和结构强度是主要失效边界。 | 可由常规发射筒、机载挂架或其他兼容平台投放，进入沿岸舰艇、机动发射车及临时部署点周边空域。任务初段按预设航路巡航，临近目标或发现威胁后由弹体根据识别结果切换飞行构型。 | 巡航阶段采用低阻构型保持接敌距离，进入末段后展开或收拢翼面，改变盘旋半径和进攻方向，再对舰艇、发射车或临机点目标实施精确攻击。直接效果是使防御方即使掌握大致来袭方向，也难以提前覆盖变形后的末端拦截窗口；若变形动作不能在规定时间内完成，则航程和机动两项优势不能同时兑现。 |
| 磁流体矢控巡飞精打弹 | 以磁场驱动导电流体重新分布，产生侧向控制力或姿态修正，减少对传统舵面和大幅转弯空间的依赖。该技术试图在末段提供连续、小半径和快速变化的航向控制，使弹体能够对雷达、导引站等点状目标实施非固定方向接敌；其关键未知包括控制力规模、能量消耗、响应时间和高温高速环境下的稳定性。 | 适合从防区外进入岸防体系，在末段面向岸防雷达、导引站和纵深火力节点实施机动突防。外部系统可提供目标区域和初始航路，但连续偏转必须由弹体的磁流体执行机构、导航和飞控闭合完成。 | 接近防区后根据目标位置和拦截威胁连续修正航向，主动避开可预测航迹，迫使防御方提前判断并扩大火力覆盖范围。直接效果是增加拦截解算难度和漏防机会，并为点状高价值节点创造偏置方向的攻击路径；在控制力不足或能量储备不足时，弹体仍会退化为普通航迹，不能把理论机动优势计入战果。 |
| 双体耦合巡飞精打弹 | 由前体和后体构成不同分工的攻击单元，前体负责先行探测、诱导或消耗防御资源，后体保留主攻载荷并从偏置方向完成末端突击。其独特价值是把一个来袭目标拆成先后相接的两次防御判断，改变传统单枚弹被发现后集中拦截的关系；两体分离时序、相互识别和后体独立导航决定该优势能否实现。 | 可由同一发射平台整体进入，再在接敌阶段分离或错位推进，主要针对岸防雷达、火控节点和其他需要持续搜索与分配资源的防空设施。外部指挥系统负责设定目标优先级，前后体的分工和末段切换应由弹体内部保持。 | 前体先制造接敌压力并诱使防御开机或分配拦截，后体随后改变进入方向，绕过已暴露的重点火力完成主攻。直接结果是增加防御方连续决策和拦截资源消耗，降低其对单一航迹集中处置的效率；若前体与后体必须依赖持续通信才能分离和攻击，则双体设计只增加复杂度，不能形成稳定的突防收益。 |
| “玄礁”水下跃升巡飞弹 | 采用水下潜行、跨介质跃升和出水后自主识别相结合的弹体形态，把水下航段作为规避岸基雷达和空中拦截的接近手段，再在末段转入空中飞行和精确攻击。其不可替代变化是让防御方不能只用岸防雷达和防空程序覆盖全部来袭过程；水下航行稳定性、出水姿态、介质转换和末端识别仍是决定成败的关键变量。 | 可从海上平台或水下载体释放，沿近岸水域接近港湾、登陆地域和靠岸舰艇，在合适位置跃升进入末段空中航路。外部侦察只能提供海域、岸线和目标先验信息，水下航迹保持、跃升时机和出水后的目标判别需由弹体完成。 | 弹体先在水下绕开雷达视线和部分空中拦截链，接近目标后跃升并立即切换到末段识别、俯冲或定向攻击。直接效果是把防御预警和拦截窗口压缩到出水后的短时阶段，对港湾设施、登陆点和靠岸舰艇形成突袭压力；若水下航行、跨介质转换或出水后识别任一环节不稳定，前段隐蔽性就无法转化为有效命中。 |
