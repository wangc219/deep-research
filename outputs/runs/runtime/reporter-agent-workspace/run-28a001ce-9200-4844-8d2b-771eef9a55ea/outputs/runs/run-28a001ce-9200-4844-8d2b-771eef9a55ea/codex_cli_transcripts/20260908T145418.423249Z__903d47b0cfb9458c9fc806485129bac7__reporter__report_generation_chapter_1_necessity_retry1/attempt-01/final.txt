## 一、需求分析

### （三）建设必要性分析

#### 1. 作战使用角度
第一岛链拒止环境的核心矛盾，不是火力有没有，而是低成本弹药能否在GNSS受扰、链路间歇和强防空覆盖下持续进入末端。群栖自组巡飞精打弹把目标选择、攻击轮换和毁伤评估前移到弹体群内，适合对舰艇、雷达和发射阵位实施连续压制；蜂簇接力巡猎精打弹则把一次打击拆成多轮接力，先逼防御暴露，再由后续单元补位毁伤，专门消耗对手的拦截节奏；气膜掠波隐巡击弹利用贴波接敌压缩探测与反应窗口，更适合打岸基雷达、火控和防空节点；“玄礁”水下跃升巡飞弹通过水下潜行后出水突防，改变来袭方向，补足海空拦截链对跨介质目标的空白。它们分别对应群体压制、连续消耗、贴海渗透和跨介质突防，才能把对手拖入既要分散火力、又来不及重组防线的交战状态。

#### 2. 装备能力提升角度
这类装备的必要性，首先体现在本体能力必须前移，而不能寄托于外部体系。双体耦合巡飞精打弹用前体引导、后体主攻，把一次拦截拆成两轮决策负荷，直接压低集中拦截效率；形记忆折展巡飞精打弹把低阻航程与临机机动合并，适合沿岸机动目标和临机点目标；磁流体矢控巡飞精打弹则把可预判航迹改写为连续变化的接敌流形，迫使防御提前发射。三者共同说明，建设重点不是口号化“智能化”，而是弹体自身的降级导航、末端识别、姿态控制、失链保持和安全中止能力。若这些能力不在弹药本体内闭合，所谓协同、突防和精打就会在受压环境下退化为对外部指控与链路稳定性的依赖。

#### 3. 领域占位角度
若不及早形成这类低成本、可降级、可验证的智能巡飞精打弹药能力，岛链拒止场景中的近程压制、海上通道封控和岸基节点瘫痪能力，就会被更高成本平台和更长闭环的武器形态占位。该领域的先发价值，不在单一型号，而在把侦察、欺骗、压制和精打压缩进同一消耗链，用可批量列装的弹药持续制造防御方的成本失衡。这个位置一旦被对手体系化补上，再追赶就只能在更高拦截密度和更高作战成本下争取同类效果。

#### 4. 综合效益
综合看，这类项目能同时提升穿透概率、交换比和库存利用率，但前提是把能力边界限定在公开可验证的降级场景，不能把理想网络条件下的协同示范误判为实战效果。对本体依赖过强外部C2、模块化导致重量和成本失控、失链后无法自保的路线，不宜作为主建方向。建设必要性因此不只在“能打”，更在于形成一条在受扰、受压、受骗条件下仍可验证有效的弹药路径。
