## 五、研制基础
### （一）参与单位

公开材料不足以锁定具体承研方，只能按产品责任、关键接口、试验责任和证据交付反推参与单位类型。对这类岛链拒止条件下的智能巡飞精打弹药，真正需要的是“总装集成单位 + 末端智能/导航分系统单位 + 试验验证单位 + 战术接口单位”的组合，而不是泛化的通用分工。

| 方向 | 可能参与单位类型 | 公开证据缺口 |
|---|---|---|
| 群栖自组巡飞精打弹 | 弹体总成与飞控单位、群协同通信与抗干扰接口单位、任务自治算法单位、弹群仿真与对抗试验单位 | 缺少失链降级、群内目标接替、命中判别和损失容忍度的可审计试验记录 |
| 蜂簇接力巡猎精打弹 | 载体弹舱/分离机构单位、小型攻击单元单位、接续释放控制单位、分段毁伤评估单位 | 缺少多次释放可靠性、互扰边界、前导消耗与后续补位的公开验证 |
| 气膜掠波隐巡击弹 | 低空气动与耐海况结构单位、海面背景识别与末端导航单位、近海靶场试验单位 | 缺少海况窗口、贴波稳定性、海杂波条件下识别精度的公开数据 |
| 形记忆折展巡飞精打弹 | 形状记忆结构件单位、折展机构与锁定装置单位、低阻巡航控制单位、展折寿命试验单位 | 缺少重复展开精度、锁定一致性和折展后气动偏差的证据 |
| 磁流体矢控巡飞精打弹 | 矢控执行机构单位、电磁兼容单位、热管理与功耗控制单位、机动响应试验单位 | 缺少响应时间、能耗、磁场耦合稳定性和受扰条件下的验证 |
| 双体耦合巡飞精打弹 | 前后体耦合结构单位、分离/接力控制单位、末段协同算法单位、双体对抗仿真单位 | 缺少失联接力、误分离、两轮决策负荷是否真正成立的公开证据 |
| “玄礁”水下跃升巡飞弹 | 水下航行体单位、出水机构单位、跨介质姿态恢复单位、海试与出水可靠性试验单位 | 缺少水下隐蔽航行、出水后稳定识别、盐雾与冲击环境下的验证材料 |

从责任链看，最关键的不是“谁参加过”，而是哪些单位必须对失链、抗扰、跨介质转换和末端识别负责。凡公开证据没有覆盖到试验场景、判据和接口边界的，只能停留在机构类型判断，不能上升为确定承研分工。
