## 一、需求分析

### （一）需求概述

#### 1. 背景分析
岛链拒止条件下，来袭弹药面对的不是单一防空点，而是由GNSS压制、链路干扰、分层防空、近程反无人机和反导火力共同组成的连续任务链。防御方的关键优势不在单次拦截，而在于稳定搜索、持续识别、快速分配和层层接续拦截，一旦我方弹药仍依赖外部联网、固定航路和一次性末制导，就会在接敌前、末端突防和损伤确认三个节点同时暴露。由此形成的核心矛盾，不是“有没有巡飞弹”，而是低成本巡飞精打弹药能否在受扰、受骗、失链条件下，把识别、导航、协同和中止控制压缩到弹体本体内，继续产生可验证的直接命中效果，并迫使对手付出远高于弹药单价的防御代价。

#### 2. 需求阐述
围绕这一Query，需求必须严格落在“需要什么、为何需要、缺什么”上。首先，需要末端自治识别与降级导航能力，因为岛链防空环境的主要失效点不是飞不出去，而是进不了最后一段就失去目标判别；如果弹体不能在GNSS受扰和伪装目标背景下独立完成末制导，所谓智能化只剩外部体系的转述。其次，需要在链路间歇下维持任务连续性的失链保持与安全中止机制，因为巡飞弹药面对的不是全程稳定指控，而是高概率断联和局部欺骗，不能把持续目标指示误当成本体能力。再次，需要模块载荷和通用接口边界清晰，因为同一平台要在侦察、压制、诱饵和精打之间切换，靠的不是统一口号，而是载荷、任务和发射兼容性的可重构；若模块化抬高重量、成本或故障率，这条需求就不成立。最后，需要边缘协同规则来支撑分布式突防，但必须承认协同只能增强，不可替代弹体自身的末段命中和降级运行。

#### 3. 项目画像
从项目画像看，这类装备的作用不是简单增加一个“会飞的弹头”，而是把第一岛链外缘的打击链条改写成可在受扰条件下自行闭环的低成本精打单元。群栖自组巡飞精打弹的价值，在于把目标选择、攻击轮换和损毁评估前移到弹体群内，使防御方难以按固定节奏恢复阵位；其制胜增量是把“拦截一个弹”变成“应对一组不断重排的攻击节点”。蜂簇接力巡猎精打弹则更适合对高密度防御体系实施多回合压力，前导单元消耗防空窗口，后续单元补位完成毁伤，改变的不是单枚命中率，而是敌方恢复和换防的时间结构。气膜掠波隐巡击弹、形记忆折展巡飞精打弹和磁流体矢控巡飞精打弹分别对应超低空贴波接敌、航程与机动兼顾以及可变航迹突防三类需求，分别压缩岸基雷达探测窗口、扩大临机变形带来的拦截失配、迫使对手提前发射并消耗火力资源。双体耦合巡飞精打弹和“玄礁”水下跃升巡飞弹则把突防路径从空中常规窗口中抽离出来，前者通过前后体分工拆解防御方决策，后者通过跨介质潜行绕开空中预警链。它们的共同前景，不在于堆砌概念，而在于在公开可审计的受扰场景中证明：低成本弹体本体能够在有限外部支持下保持命中、可控中止和持续压制，从而形成对第一岛链防御体系的稳定交换比优势。
