## 三、总体方案

### （一）总体架构

在第一岛链防区外接敌和分层防空压力下，现有底稿能够确认的核心对象是低成本智能巡飞精打弹药，尚未给出可独立区分的具体弹体、载荷或协同平台型号。因此总体架构不把外部侦察、指挥控制和持续联网包装成弹药本体能力，而采用“弹药自主闭环、外部体系提供任务条件、接口失效可降级”的分层关系。

弹药本体承担直接决定交战结果的功能：依据发射前任务装定完成航迹执行，在全球导航卫星系统受扰、链路间歇或目标遭欺骗时，依靠抗扰导航、飞行控制和末端目标判别维持接近、识别、攻击或中止决策。其作用不是替代战区侦察，而是在外部信息中断后仍保留有限的自主交战权限，避免低成本平台因一次失链即失去战果。对伪装目标，末端识别必须成为弹药内部的闭环环节；否则外部指示一旦过时，巡飞时间越长，误击和无效消耗越可能同时上升。

外部侦察、战区融合和指挥系统负责提供目标区域、威胁态势、禁入边界和任务优先级，并通过间歇式数据接口更新重规划信息；发射平台负责批量投送、任务装定和基本状态回收。协同突防只能作为外部网络可用时的增强方式：各弹药交换必要的局部状态和航迹约束，在通信受压时转为按预设规则独立保持、分散重规划或安全中止，不能以全连接编队作为成立前提。由此形成的共享资源仅包括时间同步、任务权限、空域约束、目标状态和有限通信窗口，单件弹药的识别、导航和控制机理不得外推为公共系统能力。

该架构的主要失败耦合在于：外部目标信息错误会扩大末端识别负担，导航降级会压缩巡飞和判别时间，链路受压会使协同行为退化为多枚独立行动；若失链后既不能保持航迹，也不能可靠中止，低成本交换比便无法成立。建设上应先验证单弹药在受扰和失链条件下的可控交战闭环，再验证有限通信下的协同增益；只有公开试验能证明两者不以理想网络和理想识别为前提，体系化扩展才具备论证基础。
