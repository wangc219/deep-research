三、总体方案

（一）总体架构
本栏把智能巡飞精打弹药的共性收敛在三类必须共享、且会改变任务结果的要素上：一是任务授权、发射约束和安全中止规则，二是受扰时仍可维持的失链保持、降级导航和局部态势交换，三是与外部侦察、指控和装载平台对接的通用接口。除此之外，末端识别、机动控制、载荷承载和突防机理必须留在弹体本体内，不能被抽象成统一软件层，否则一旦链路间歇或导航受压，整个任务会从“可控打击”退化成“依赖理想网络的演示”。

各型装备的分工应围绕它们改写交战关系的方式展开。群栖自组型靠弹体群内协同接替目标选择、攻击轮换和损毁评估，重点不是单弹性能，而是在压制环境下维持群内接续；蜂簇接力型靠前后波次的释放顺序和接口配合，把一次拦截拆成多轮消耗，任何释放失序都会把穿透压力降回单弹水平；气膜掠波型的关键是贴海稳定飞行和海面背景下的末端识别，若低空保持不住，再强的识别也进不了有效接敌；形记忆折展、磁流体矢控和双体耦合分别通过翼面重构、侧向矢量重分配和前后体分工压缩拦截窗口，但这些机理互不通用，不能并入同一套机动模块；“玄礁”则把水下隐蔽和出水末攻拆成两段状态转换，最脆弱的是出水瞬间的识别切换和时序控制。

因此，总体架构的核心不是堆功能，而是先固化发射兼容、失链保持、降级导航和安全中止，再在明确接口上叠加群协同、模块载荷和跨介质接敌能力。只有在GNSS受扰、链路受压和欺骗目标并存时仍能证明这些分层不相互拖累，架构才算成立。
