二、项目画像

（一）装备图像概述

| 装备对象 | 本体机理与形成能力 | 进入战场与关键动作 | 作用对象、直接战果与失效边界 |
|---|---|---|---|
| 群栖自组巡飞精打弹 | 把目标选择、攻击轮换和损毁评估前移到弹体群内，靠局部自治而不是单弹独判来维持任务连续性；核心价值不在单枚命中，而在多弹协同下持续改写对抗节奏。 | 在受扰空域成群进入后，依靠弹间共享的局部感知与简化协同规则完成临机分配，链路间歇时仍能接续任务，不把外部指控当成本体前提。 | 主要压向舰艇、雷达和发射阵位这类固定节奏依赖强的节点，直接效果是让对手的搜索、分配、拦截链条连续失速，并形成可见毁伤或瘫痪；若必须依赖持续联网和高质量外部修正，其优势就会明显回落。 |
| 蜂簇接力巡猎精打弹 | 以单个载体接续释放多个小型攻击单元，先由前导单元诱发拦截和暴露，再由后续单元补位完成精确毁伤；相较单弹一次性突防，它把一次打击拆成多回合消耗。 | 通过内置分发序列进入末段接敌，前段先占用对方搜索和发射资源，后段从已经被扰乱的防空节奏中补入主攻。 | 面向分层防空和反无人机火力覆盖区，直接战果不是单点爆破，而是拖慢防御恢复、换防和集中拦截的周期，使雷达、火控和防空节点在连续压力下失去窗口；若模块拆分导致重量、可靠性或成本失控，这条路线就失去成立基础。 |
| 气膜掠波隐巡击弹 | 依托近海气膜和掠波效应维持超低空贴波飞行，把接敌几何压入海面背景，靠海杂波和视线遮蔽缩短发现到拦截的时间。 | 沿海面低空逼近岸基目标，关键动作是始终把弹体压在海平面附近，在最后阶段才暴露并转入识别。 | 直接指向岸基雷达、火控和防空单元，效果是压缩对方的探测、跟踪和射击窗口，抬高漏防率；它对海况、贴波控制和末段识别稳定性更敏感，一旦飞行高度和海面背景控制不住，隐蔽优势会快速衰减。 |
| 形记忆折展巡飞精打弹 | 借形状记忆折展骨架在巡航与接敌之间切换翼面和盘旋半径，把低阻航程和末端机动合成同一弹体能力；折展不是装饰，而是让航程和突防方式同步变化。 | 前段以收拢状态降低阻力、延长航程，接敌后快速展开并缩小转弯半径，用临机变形打开拦截空隙。 | 适合打沿岸舰艇、发射车和临机点目标，直接效果是让防御方即使掌握大致航路，也很难提前把火力覆盖到变形瞬间；如果折展机构带来的重量、可靠性或维护代价过高，这种机理就会被反向抵消。 |
| 磁流体矢控巡飞精打弹 | 依靠磁流体在磁场作用下的快速重分配，驱动侧向偏转和小半径折转，把原本可预测的航迹改写成连续变化的接敌流形。 | 在逼近阶段不断做细小航向修正，不追求大幅度机动，而是让对方的跟踪和提前量计算持续失配。 | 主要压向岸防雷达、导引站和纵深点状火力，直接效果是迫使防御提前发射、增加误判和漏防；其短板在于控制响应、热管理和场强维持，一旦偏转能力不足，机动优势就只剩概念层面。 |
| 双体耦合巡飞精打弹 | 以前体引导开机、后体主攻的耦合方式，把一次来袭拆成两轮决策负荷：前段先耗搜索与分配资源，后段再从偏置航向补入末攻。 | 进入末段时，前体先暴露并牵引防御反应，后体从不同角度接力跟进，不给对方一轮集中拦截完成闭环的机会。 | 作用对象是防空节点及其火控链，直接战果是压低集中拦截效率并提高终端命中概率；它高度依赖前后体耦合时序和分离稳定性，接口一旦失配，整套节奏就会塌掉。 |
| “玄礁”水下跃升巡飞弹 | 先以水下潜行甩开雷达视线和空中拦截链，再在出水后立即转入末段识别并俯冲命中，把跨介质隐蔽和空中精打串成一体。 | 关键动作是潜航接近、出水跃升、末段识别和俯冲攻击的连续切换，防御方很难用同一套岸防与防空程序提前封堵。 | 适合港湾、登陆点和靠岸舰艇等近岸目标，直接战果是把来袭路径从常规空情预警体系中剥离出来；若跨介质转换暴露过大或末段识别不稳定，其生存与命中价值都会明显下降。 |
