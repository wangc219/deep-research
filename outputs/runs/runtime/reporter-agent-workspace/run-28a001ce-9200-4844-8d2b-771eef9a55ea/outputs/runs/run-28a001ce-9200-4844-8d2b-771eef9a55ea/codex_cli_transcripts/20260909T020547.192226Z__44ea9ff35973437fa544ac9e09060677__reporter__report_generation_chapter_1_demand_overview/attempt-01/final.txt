一、需求分析

（一）需求概述

1. 背景分析

第一岛链拒止环境下，防御方可能以全球卫星导航压制、通信干扰、欺骗目标、分层防空反导和近程反无人系统构成连续拦截链。低成本巡飞精打弹药如果仍依赖持续联网、稳定卫星导航和外部实时指挥，其成本优势会在接敌后迅速转化为高消耗率：平台能够抵近，却不能确认目标；能够收到任务，却不能在链路中断后保持有效航行；能够形成数量压力，却可能被逐枚诱骗或拦截。真正的任务链压力不在于是否具备远程飞行，而在于受扰条件下能否把“发现、判别、接战”闭合为可核验的直接军事效果。

公开资料显示，美国防高级研究计划局的“受限环境协同作战”项目已将通信离线、全球定位不可用条件下的协同自治作为研究方向，但美国政府问责局对联合全域指挥控制的评估也表明，多域资产连接、数据融合和投资框架仍未完全成熟。因此，协同突防可以作为外部体系提供的增益，不能直接假定为弹药本体的固有能力。该装备必须首先解决单弹在导航受扰、目标受骗和链路间歇时不立即失效的问题，再讨论批量协同带来的防御压迫效果。

2. 需求阐述

相关装备首先需要具备不依赖持续卫星导航和连续遥控的有限自治能力，使弹药在接敌前后能够保持可控航迹，并在外部信息暂时中断时继续执行已授权任务或安全退出。之所以需要这一能力，是因为防御方只要压制导航或切断链路，就能把低成本弹药从打击工具变成失控飞行体；现有通用巡飞平台若缺少降级航行和失链处置，无法支撑拒止环境下的直接战果。需求缺口不是单纯增加航程，而是让弹药在信息不完整时仍能作出边界清晰的继续、转向、待机或中止判断。

其次，需要把目标识别和末端交战判别部分前移到弹药本体，使其能够区分真实目标、伪装目标和诱导目标，避免把外部持续目标指示当作成立前提。外部侦察和战区融合可以提供初始目标线索，但不能替代末端确认；否则敌方通过假目标、目标转移或信息污染即可改变弹药的最终攻击对象。这里需要补足的是受干扰、低能见度和目标特征不完整条件下的稳健判别，而不是预设其拥有无限制的自主搜索和跨域决策权。

再次，需要形成可更换的任务载荷和通用接口，使同一弹体能够在侦察、压制、诱饵和精确毁伤之间调整用途，以缓解单一弹种库存利用率低、批量部署成本高的问题。但模块化不能以可靠性、重量和制造成本失控为代价；若更换载荷导致飞控、识别或发射兼容性明显下降，则其所谓通用性不能转化为有效战力。协同突防能力则应被视为有限增益：在通信受压时，弹药至少要能依据局部信息保持自身任务，不应把全连接编队作为需求成立条件。

3. 项目画像

本项目应定位为面向第一岛链防区外接敌和末端突防的低成本智能巡飞精打弹药，核心作用不是替代外部侦察、指挥和战区重规划，而是在这些体系能力不连续时保住弹药本体的直接作战价值。它通过抗扰降级导航维持接战方向，通过末端自主判别减少欺骗目标造成的无效攻击，通过失链保持和可控中止降低失控与误伤风险，再以可重构载荷扩大单一库存对不同任务的适配范围。

相较依赖持续网络的通用无人平台，该装备的制胜增量在于把关键交战闭环压缩到弹药自身，使防御方即使成功压制部分导航和通信，也不能立即消除全部突防压力。批量使用时，有限的局部协同还可迫使防御方同时处理真假目标、不同任务载荷和不完全一致的接近方向，从而压缩其反应和拦截窗口；但这一效果会在识别误差累积、协同链路完全失效、载荷模块导致成本上升或防御方形成稳定反制规则时减弱。项目成立的边界因此是：抗扰自治和失链保持必须先形成可独立核验的装备价值，协同突防、跨域分发和持续目标指示只能作为外部体系接口，不能替代弹药本体的制胜能力。
