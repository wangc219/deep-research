## 一、需求分析

### （一）需求概述

#### 1. 背景分析
第一岛链拒止环境下，低成本巡飞精打弹药面对的不是单点火力，而是由GNSS压制、链路干扰、伪装欺骗、分层防空和近程反无人机共同构成的连续任务链。对手的优势不在一次拦截，而在搜索、分配、跟踪、再拦截和补防之间的节奏稳定，一旦弹体仍依赖外部联网、固定航路和持续指令，就会在接敌前、末端判别和损毁确认三个环节同时失速。这里的根本压力，不是“能不能飞”，而是“在受扰、失链、受骗条件下，弹体本体还能不能独立形成可验证的直接战果”。

#### 2. 需求阐述
围绕这一Query，需求必须收敛到“需要什么、为何需要、缺什么”。首先，需要末端自治判别、抗干扰导航和失链保持，因为岛链外缘最常见的失效点并非平台出动，而是最后几公里失去目标识别与航向控制；如果这部分能力仍要外部体系兜底，装备本体就没有独立作战价值。其次，需要明确安全中止机制，因为在链路间歇和目标欺骗并存的条件下，弹药不能把持续目标指示误当成本体能力。再次，需要模块载荷和通用接口边界清楚，才能让同一平台在侦察、压制、诱饵和精打之间切换，但前提是可靠性、重量和成本交换比不能被模块化反向拖垮。最后，需要边缘协同规则支撑分布式突防，但协同只能增强，不能替代弹体自身的末端命中与降级运行。

#### 3. 项目画像
从项目画像看，这类装备研发的作用，是把第一岛链外缘的打击链条改写为可在受扰条件下自行闭环的低成本精打单元。群栖自组巡飞精打弹的价值，在于把目标选择、攻击轮换和损毁评估前移到弹体群内，直接把对手拖入“跟不上、拦不住、补不回”的压制局面。蜂簇接力巡猎精打弹则把一次攻击拆成连续多回合压力，前导单元先消耗防空窗口，后续单元再补位完成毁伤，改变的是防御方恢复和换防的时间结构。气膜掠波隐巡击弹依靠贴波接敌压缩探测距离和反应窗口，专打岸基雷达、火控和防空节点；形记忆折展巡飞精打弹通过巡航与接敌间的构型切换，把航程与临机机动合并起来；磁流体矢控巡飞精打弹则用连续可变航迹迫使对手提前发射、增加误判。双体耦合巡飞精打弹通过前后体分工拆解一次拦截的决策负荷，“玄礁”水下跃升巡飞弹则把接敌路径从空中常规预警链外侧绕入，先隐蔽接近，再在末段转入俯冲命中。它们的制胜增量，不是堆高单项性能，而是在群体协同、路径隐蔽、波次压迫和跨介质突防上，分别重写敌我交战关系；其成立边界也清楚，凡是只能依赖理想联网、固定目标或单一演示环境的方案，都不足以构成本栏要论证的装备需求。
