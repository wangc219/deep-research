## 二、项目画像

### （一）装备图像概述

| 装备对象 | 核心技术形成的独有能力 | 部署或进入方式与关键动作 | 作用对象、直接效果及成立边界 |
|---|---|---|---|
| 群栖自组巡飞精打弹 | 将目标分配、攻击排序和毁伤判断部分下沉到弹体群，由单弹按局部观测结果保持任务连续性；即使通信间歇，仍可依据预设规则进行分散、接替和末端选择，形成多方向、非同步的压迫式打击，而不是把所有弹药绑定在单一外部控制节点上。 | 获得初始目标区和禁限约束后，多枚弹药分散进入防区外缘，在接敌过程中共享有限状态信息；先由部分弹药搜索或吸引火力，其他弹药保持隐蔽接近，再根据目标暴露、友邻损毁和拦截态势调整攻击顺序，无法确认目标时转入待机、绕飞或安全中止。 | 主要作用于岛链舰艇、岸基雷达和防空发射阵位，直接效果是让防御方难以按固定节奏完成搜索、分配和集中拦截，并对关键节点形成连续毁伤或功能压制。其不可替代性在于“群内接替”而非单纯增加数量；若协同完全依赖持续联网，或失链后不能保持目标约束和安全中止，该能力即退化为普通分散攻击，须以断链、导航受扰和局部节点失效试验加以证伪。 |
| 蜂簇接力巡猎精打弹 | 以一个载体携带并依次释放多个小型攻击单元，使搜索、诱导、消耗拦截和精确毁伤在同一弹药中连续展开。它的价值不是扩大单次装药，而是把一次突防转化为多个时序相连的交战回合，利用先后单元之间的任务接替维持攻击压力。 | 载体接近目标区后按威胁方向和目标优先级释放单元；前导单元承担搜索、诱发雷达开机或吸收近程拦截，后续单元根据已暴露的防区缺口改变进入方向和攻击对象，优先打击已被识别且仍具作战价值的节点。 | 适合压迫分层防空、反无人机火力和点状警戒阵地，直接效果是延长防御系统的连续应对时间，增加其换防、补射和集中拦截之间的衔接失误，并提高后续攻击单元抵达目标的机会。成立边界在于载体释放可靠性、单元间隔控制和末端识别必须同时成立；若前导单元只造成消耗而不能带来有效暴露，或释放后各单元无法独立完成攻击，则“接力”不会转化为实际毁伤优势。 |
| 气膜掠波隐巡击弹 | 以贴近海面的稳定飞行、海面背景遮蔽和低空自主控制共同压缩防御探测距离，把弹药的隐蔽性建立在接敌几何和飞行高度上，而非仅依靠外部干扰。核心能力是长期保持低空航迹，并在海况变化、导航受扰和目标机动时完成姿态修正与末端识别。 | 从海上或沿岸方向进入近海空域，沿海面低空巡飞并利用雷达视线受限区域接近目标；在确认岸基雷达、火控节点或防空单元后缩短暴露时间，转入末段攻击，避免在目标区长时间盘旋导致自身被重新捕获。 | 直接针对岸基雷达、火控站和近岸防空单元，效果是压缩对手发现、跟踪、交战的时间窗口，增加漏防和迟滞，并为后续精确打击创造缺口。该装备不能脱离海况、风浪、海面杂波和低空导航误差单独评价；若只能在平静海面或预先掌握航路条件下保持飞行，其相对常规低空巡飞弹的优势不足，验证应覆盖不同海况、传感器失配和末端目标伪装。 |
| 形记忆折展巡飞精打弹 | 采用可折展承力与翼面结构，在巡航阶段保持较低阻力和较长滞空能力，接敌时改变翼展、转弯特性或盘旋半径，使同一弹体在远程进入与临机机动之间切换。其本体差异是用结构形态变化扩展飞行包线，而不是单靠发动机增推。 | 发射和远程巡航时保持收拢或低阻构型，进入目标区后依据目标运动、地形遮蔽和防御火力方向展开翼面或调整构型，再以较小转弯半径改变接敌方向；对临机出现的舰艇、发射车或点状目标，可在末段重新规划攻击航迹。 | 主要作用于沿岸舰艇、机动发射车和临机暴露的点目标，直接效果是使防御方即使掌握大致来向，也难以准确预测最终攻击窗口，从而提高目标区的规避和拦截负担。建设取舍集中在折展机构的可靠性、结构强度、展开时机和重量代价；若构型切换造成航迹扰动、维护复杂或末段控制收益低于可靠性损失，则不应以概念上的机动性替代实测效果。 |
| 磁流体矢控巡飞精打弹 | 利用磁场驱动导电流体重新分布，产生侧向控制力，使弹体在不完全依赖传统舵面的大幅动作下实现快速偏转和连续变向。它所改变的是末段航迹的可预测性，可在目标区临机修正攻击方向，减少防御方依据单一弹道提前布置拦截的机会。 | 以常规航迹进入目标区后，在接近岸防雷达、导引站或纵深火力节点时启用矢量控制，根据传感器更新结果实施短促侧偏、折转和航向修正；关键动作应受剩余能量、目标识别可信度和安全边界约束，避免为追求机动而失去命中条件。 | 直接作用于岸防雷达、导引站和纵深点状火力，预期效果是迫使防御方提前发射或扩大拦截覆盖范围，增加其火力分配错误和漏防概率。该方案的成立取决于磁流体响应速度、供能负担、环境适应性与末端制导耦合；在公开证据不足时只能把机动收益作为待测变量，不能据此给出确定的突防比例或命中指标。 |
| 双体耦合巡飞精打弹 | 由前体和后体构成分工明确的耦合弹药：前体负责引导、暴露或扰乱搜索分配，后体保留主要毁伤能力并承担最终攻击。相较于单枚弹药，它把防御方对一次来袭目标的判断拆成连续的两次决策，使拦截资源必须在“先打谁、是否继续跟踪、如何重新分配”之间反复切换。 | 进入防区后以前体先行开机或制造可观测目标，诱导防御雷达和火控系统提前处理；后体保持偏置航向或短时隐蔽，在前体吸收拦截、暴露防区缺口后补入末段，从另一方向完成对防空节点的精确攻击。 | 主要针对防空雷达、火控节点和拦截单元，直接效果是降低防御方集中火力一次性解决来袭目标的效率，并增加后体穿透和命中的可能。其短板是耦合释放、前后体时序、相互识别和距离保持均会引入新的故障点；若前体过早损毁不能产生有效诱导，或后体无法在偏置航向上重新捕获目标，双体结构反而会降低单位成本效益。 |
| “玄礁”水下跃升巡飞弹 | 将水下潜行、跨介质跃升和空中末段识别组合在同一弹药本体内，使其避开主要依赖雷达和空中拦截的常规接敌路径。制胜机理不是单纯提高飞行速度，而是改变来袭目标所处介质，让岸防体系难以用同一套探测、跟踪和拦截程序贯穿全程。 | 从近岸水下方向潜行接近，在水下阶段保持低可探测和有限自主航行；到达预定出水区后跃升转入空中，迅速完成目标确认、航向修正和俯冲攻击，优先利用短暂暴露窗口打击港湾设施、登陆点或靠岸舰艇。 | 直接作用于港湾、登陆地域和近岸舰艇，效果是把防御方的预警与拦截链条分割在水下和空中两个阶段，降低其提前封堵航路的能力。成立边界包括水下导航、出水姿态、跨介质结构密封和跃升后末端识别；任何一环不能稳定衔接，都会使其从“改变接敌介质”的装备退化为难以控制的单次突入弹药。 |
