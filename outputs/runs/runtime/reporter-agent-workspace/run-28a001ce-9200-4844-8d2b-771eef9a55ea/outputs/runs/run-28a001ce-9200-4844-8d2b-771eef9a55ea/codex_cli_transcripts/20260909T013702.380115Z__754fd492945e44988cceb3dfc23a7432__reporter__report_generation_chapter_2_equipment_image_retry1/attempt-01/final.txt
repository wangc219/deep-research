二、项目画像

（一）装备图像概述

| 装备 | 核心技术与形成能力 | 部署或进入方式、作用对象 | 关键动作与直接效果 |
|---|---|---|---|
| 群栖自组巡飞精打弹 | 以弹体间的局部协同、分布式目标判别和失链降级规则，把原本依赖外部指挥链完成的目标选择、攻击排序和毁伤评估部分前移到弹群内部。相较单枚巡飞弹，它的不可替代性不在于单弹更强，而在于一枚受扰或被拦截后，其余弹体仍可重新分配任务；但公开材料不足以证明其在完全失联、强欺骗条件下仍能稳定完成协同。 | 以多枚弹体分散进入第一岛链防空与反舰火力覆盖区，主要作用于舰艇、岸基雷达和发射阵位。外部侦察、任务规划和初始目标指示仍属于接口保障，弹体本身必须承担末端识别、有限航迹保持和安全中止。 | 弹群在接敌过程中自主调整先后次序和攻击方向，使防御方难以按固定节奏完成搜索、分配和拦截；先造成传感器或火力节点的连续失效，再扩大后续弹体的突防机会，直接形成压制或瘫痪效果。对手若改用区域封锁和持续干扰，其优势将转化为对协同规则、导航降级和单弹自主能力的更高要求。 |
| 蜂簇接力巡猎精打弹 | 由一个载体携带并按时序释放多个小型攻击单元，弹体同时承担搜索、分发和末段攻击闭环。其相对单次齐射的变化，是把一次突防改造成连续多轮交战：前导单元用于迫使防空系统暴露和消耗拦截资源，后续单元再利用暴露窗口实施精打。载体释放可靠性、单元间识别和载荷重量约束是成立边界。 | 由单一兼容平台投放至目标区域，再在防区外缘或接敌阶段释放攻击单元，重点作用于防空搜索、火控和近程拦截节点。具体投放平台、单元数量和航程档位尚未给定，不能据此推定实际部署规模。 | 先以低成本单元制造多方向、多时段威胁，诱发雷达开机、火力分配或拦截发射，再由后续单元补入关键方向，压缩防御方换防和再装填时间。直接效果是提高连续突防压力，而不是保证每个单元均命中；若对手采用分散部署、被动探测和拦截储备管理，接力优势可能明显下降。 |
| 气膜掠波隐巡击弹 | 依靠近海超低空贴波飞行、海面背景遮蔽和自主高度保持，降低岸基雷达对来袭目标的稳定发现和连续跟踪机会。它与普通低空巡飞弹的差异在于把接敌几何长期压在海面背景附近，而非仅在末段短时降低高度；海况、风浪、导航误差和末段识别能力决定其是否可用。 | 从海上方向进入岸防体系低空盲区，主要攻击岸基雷达、火控单元和近岸防空阵位。其有效性依赖弹体本体完成贴波控制，不能把持续外部引导或理想通信当作必备条件。 | 在被稳定跟踪前保持贴海航迹，接近目标后切换末端识别和攻击航迹，利用探测链不连续造成的反应迟滞直接毁伤关键节点。它改变的是防御方的发现距离和拦截窗口；若海况恶化、雷达采用多点低空补盲或弹体无法维持安全高度，隐蔽优势会快速失效。 |
| 形记忆折展巡飞精打弹 | 采用形状记忆折展骨架，在巡航阶段保持较低阻力，在接敌阶段展开或改变翼面和盘旋半径，使远距离滞空与临机机动由同一弹体承担。相对固定翼巡飞弹，它可能扩大临机航迹变化空间；但折展机构的重复可靠性、展开后气动稳定和重量代价尚无公开定量依据。 | 需由能够兼容其折叠状态的外部平台投放，具体发射平台和进入高度未给定。适合面向沿岸舰艇、机动发射车及临时暴露点目标，在目标位置不确定或航路可能被预判时发挥作用。 | 先以低阻构型完成接近或巡航，再在目标区根据威胁方向改变翼面和盘旋范围，从已知航路转入临机攻击，迫使防御方扩大搜索和拦截覆盖范围。直接效果是提高对机动或临时目标的到达机会；若折展转换延迟、机构卡滞或目标区空间受限，航程与机动的兼得就不能成立。 |
| 磁流体矢控巡飞精打弹 | 以磁场驱动磁流体重新分配，产生侧向偏转和小半径转向，目标是减少传统舵面和固定推力布局对航迹的约束。其潜在差异是能够连续改变接敌方向，而非依靠少数预设机动动作；但响应速度、能量消耗、结构密封和高动态控制效果均缺少公开试验证据，现阶段只能作为高风险技术路线。 | 进入岸防纵深后，针对雷达、导引站和点状火力节点实施非固定方向接敌。由于其作用机理仍处于概念验证边界，不能把磁流体控制直接等同于已经具备的末段突防能力。 | 通过连续改变航迹使防御方难以按单一弹道提前配置拦截点，并可能迫使其提前发射或扩大火力覆盖，直接结果是增加漏防概率和拦截资源消耗。若矢控响应不足、能量供应中断或目标识别不能及时更新，复杂机动反而会扩大导航误差，导致失靶或提前中止。 |
| 双体耦合巡飞精打弹 | 由前体承担引导、诱导或暴露防御反应，后体保持主攻任务，通过双体间的时序和偏置航向把一个消耗单元转化为两轮交战压力。相较单体弹，它增加了防御方的识别和火力分配负担；但前后体释放、间隔控制和末段目标归属必须稳定，否则会退化为两个难以协同的独立目标。 | 以同一发射单元进入防区，在接敌后由前体先行、后体从偏置方向补入，主要作用于防空雷达、导引站及其周边火力节点。外部链路只提供初始任务和必要更新，双体之间的基本动作应能在通信受限时保持。 | 前体先消耗搜索和分配资源，诱使防御方暴露拦截意图，后体随后改变方向完成主攻，使一次拦截决策被拆成连续两次判断。直接效果是降低防御方集中拦截效率并提高关键节点被命中的机会；若对手采用统一火控和快速目标关联，双体带来的额外负荷可能被压缩。 |
| “玄礁”水下跃升巡飞弹 | 以跨介质航行把水下隐蔽接敌与空中末段精打连接起来，弹体在水下阶段避开岸基雷达和部分空中拦截链，出水后再依靠末端识别转入俯冲攻击。其不可替代性是改变来袭目标的介质和暴露时机；出水控制、跨介质结构可靠性、近岸水文条件和出水后的短时制导是主要失效点。 | 从水下方向接近港湾、登陆点或靠岸舰艇，在目标附近跃升并进入空中末段。该路线不应被扩展解释为具备长期水下巡航或任意海域部署能力，具体发射方式、潜行时间和适用水深尚未给定。 | 先利用水下航迹绕开常规岸防搜索，再在接近目标时突然出水、完成目标识别并俯冲命中，迫使防御方不能只按空中航路提前布置。直接效果是增加港湾和近岸目标的防护盲区；若水下接敌受海况限制、出水位置可预测或末段识别时间不足，其跨介质优势将难以转化为稳定战果。
