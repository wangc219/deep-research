**三、总体方案**

**（一）总体架构**

本项目的架构不是把所有巡飞精打弹药并成一套通用弹体，而是把真正共享的任务状态、授权边界、资源与接口前置到体系层，把末端识别、降级导航、飞控和中止逻辑压在弹体本体内。外部体系只保留任务包下发、目标指示、链路校正、发射约束和战损回传等接口，弹体在链路间歇、GNSS受扰和目标欺骗条件下仍能独立完成接敌、判别和终端致效；一旦外部侦察不稳，体系只能退回到更保守的预装航路与局部重规划，不能把协同、持续指示当成弹体固有能力。

装备分工按作战矛盾而不是按统一平台展开。群栖自组巡飞精打弹依赖弹体群内的目标分配、攻击轮换和损毁评估，价值在于把防御方固定节奏的搜索与拦截链条拆散；蜂簇接力巡猎精打弹靠一次载荷分发出多轮压力，前导单元消耗拦截窗口，后续单元补位完成精确毁伤；气膜掠波隐巡击弹与“玄礁”水下跃升巡飞弹分别把接敌几何压到海面背景和水下通道里，改变对手探测域；形记忆折展、磁流体矢控与双体耦合则把航程、变形和末段机动做成专属本体机理，专打沿岸点目标和防空节点。

因此，体系内真正共享的是任务接口、导航约束、通信降级规则、载荷管理和安全中止机制；真正分化的是接敌域、机动域和毁伤域。其失败耦合也由此清晰：链路被压制时，群栖与双体型仍可依赖局部自治维持最低作战效果，但蜂簇型会失去连续回合压力，气膜掠波与水下跃升型则对地形/海况和出水时机更敏感，形变与矢控型一旦结构动作失灵，原本用于压缩拦截窗口的优势会直接消失。
