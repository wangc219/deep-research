## 一、需求分析

### （三）建设必要性分析

#### 1. 作战使用角度

在第一岛链拒止环境中，敌方依托分层防空、反舰火力、近程反无人系统和电磁压制，试图通过固定的发现、分配、拦截节奏削弱低成本弹药的突防效果。建设智能巡飞精打弹药，关键不在于简单增加飞行平台数量，而在于把末端识别、受扰导航、攻击选择和失链处置落实到弹药本体，减少对持续联网和单一指挥节点的依赖。

**群栖自组巡飞精打弹**适合用于压迫舰艇、岸防雷达和发射阵位等需要持续搜索和轮换防护的目标。外部侦察和指挥系统负责提供初始任务区域，弹群进入目标区后依据局部信息完成目标选择、攻击轮换和毁伤复核，使防御方难以用一次集中拦截消除全部威胁。其直接战果是把单次突防转化为连续压制，迫使敌方在火力分配、目标排序和节点修复之间反复决策；但若协同完全依赖稳定数据链，通信受压制后仍可能退化为分散失效，因此必须以失链保持和局部重规划作为成立边界。

**蜂簇接力巡猎精打弹**改变的是弹药释放方式。单一载体接敌后，先释放前导单元侦察、诱导或消耗拦截资源，再由后续单元接替搜索和末段攻击，可将一次攻击拆分为有时间间隔的多轮压力。其制胜作用不是单纯扩大数量，而是打破防御方“处置一波后恢复”的时间假设，使其刚完成前批目标处理便再次面对新的攻击单元，从而削弱集中拦截、换防和补充射击能力。该装备的价值取决于释放控制、单元识别和后续补位是否可靠；若载体释放后无法维持目标分发闭环，连续压力就会退化为无序消耗。

**气膜掠波隐巡击弹**针对的是海岸雷达、火控节点和近海防空单元的探测几何。弹体以贴近海面的飞行方式利用海面背景和地平线遮蔽逼近目标，再在末段完成识别和攻击，可压缩敌方发现、跟踪到射击的反应时间。相较常规高空或较规则航迹弹药，它通过改变接敌高度和背景关系提高漏防可能，适合攻击沿岸关键节点；但海况、气象、海面杂波和低空飞控稳定性会直接影响效果，不能把理想海况下的隐蔽性外推为普遍结论。

**形记忆折展巡飞精打弹**面向航程与末端机动难以兼顾的矛盾。巡航阶段保持较低阻力和较高滞空效率，接敌时通过折展结构改变翼面状态、盘旋半径或机动方式，能够对沿岸舰艇、机动发射车和临机点目标实施方向不固定的末段攻击。它使敌方即便掌握大致航路，也难以预设最终拦截窗口。其失效风险集中在结构动作可靠性、展开后气动一致性和重复控制精度，必须通过不同速度、海况和姿态下的动作验证确认其军事价值。

**磁流体矢控巡飞精打弹**以连续改变飞行侧向状态为主要突防手段，适合攻击岸防雷达、导引站和纵深点状火力。磁流体受控重分配后形成侧向偏转和小半径折转，可降低航迹可预测性，迫使防御系统提前判断并增加拦截资源消耗。它直接改写的是敌方火力解算和拦截提前量，而非单纯提高速度；如果矢量控制响应不足、能量代价过高或末段制导无法跟随机动，机动优势就可能转化为命中率下降。

**双体耦合巡飞精打弹**通过前体引导与后体主攻的分工，把一次来袭过程拆成先导暴露、偏置补入和末段毁伤三个相互衔接的动作。前体吸引搜索与分配资源，后体从不同方向完成主攻，可对防空节点形成两轮决策压力，降低敌方集中拦截的效率。其核心不是简单增加弹体数量，而是利用时序和航向差制造防御错配；若双体分离、通信或后体自主接续不稳定，前后协同关系即难成立。

**“玄礁”水下跃升巡飞弹**则从介质转换上改变接敌关系。弹体先在水下接近港湾、登陆点或靠岸舰艇，避开主要雷达视线和部分空中拦截链，出水后迅速完成末段识别并俯冲攻击。它为岸防体系引入水下来袭方向，迫使防御方同时维护水下警戒、出水点监视和空中末防，适合打击靠岸目标及港口节点。其边界在于水下航行、出水控制和出水后识别必须连续可靠，且目标区域的水深、海况和水下障碍条件尚未给定，相关适用范围不能预先扩大。

#### 2. 装备能力提升角度

相对依赖外部持续指引的传统巡飞弹药，本项目首先应提升弹药在全球卫星导航受扰、链路间歇和目标伪装条件下的独立完成能力。弹体应承担抗干扰导航、末端目标判别、飞行控制、攻击或安全中止；外部情报侦察、指挥控制和战区融合则主要提供任务区域、目标优先级及必要更新。能力评价应围绕受扰条件下的有效命中、可控中止、误击抑制和损毁确认展开，不能用全连接网络中的演示结果替代降级场景验证。

不同装备的提升方向不能混同：群栖自组弹强调局部协同和损毁评估，蜂簇接力弹强调释放时序与后续补位，气膜掠波弹强调贴海飞控和末段探测，形记忆折展弹强调结构变形后的航迹控制，磁流体矢控弹强调快速侧向控制与能量管理，双体耦合弹强调分离后任务接续，“玄礁”弹强调跨介质转换和出水识别。上述能力均应以公开可审计试验或仿真闭环验证；目前缺少具体航程档位、成本上限、目标类型、通信条件和平台生态，不能据此生成确定性战技点值。

#### 3. 领域占位角度

该项目可在低成本远程精确火力、拒止环境无人作战和反分层防空交叉领域形成装备方向。其占位意义在于将弹药本体智能化与低成本规模化结合，形成可分散部署、可按任务重构、可在局部失联条件下继续行动的精打弹药族，而不是把外部指控能力包装成弹药能力。优先顺序应保持抗扰自治和失链保持在前，协同、跨介质和新型矢控结构依据工程验证结果分阶段推进。

#### 4. 综合效益

建设必要性最终体现在三个方面：一是以较低单件消耗换取对敌方雷达、火控和拦截资源的持续占用，改善拒止环境下的交换关系；二是通过多种接敌几何和攻击时序，迫使防御方增加探测方向、决策轮次和拦截库存；三是以通用发射兼容和模块化载荷提高库存利用率，但模块增加不得牺牲可靠性、成本和重量约束。若验证结果表明能力只在理想通信、理想海况或无欺骗目标条件下成立，则应缩小建设范围，而不应将概念性优势直接转化为作战结论。
