# 三、总体方案

## （二）子系统方案

子系统设计不采用统一弹体加统一智能模块的做法，而是按各装备改变交战关系的方式确定承担边界。外部体系主要提供任务授权、初始目标线索、发射平台适配和战果回传；弹药本体必须独立完成与其制胜机理直接相关的飞行控制、末端判别和失效处置。通信中断、导航受扰或目标信息不完整时，装备应能转入预设的降级状态，并对无法确认的目标执行等待、转向或中止，避免把理想网络条件误当作装备能力。

| 装备 | 产品形态与控制机理 | 必要输入输出及关键接口 | 工程验证重点 |
|---|---|---|---|
| 群栖自组巡飞精打弹 | 由多个可独立飞行、可局部协同的巡飞弹组成，重点不是保持完整编队，而是让剩余弹体能够依据局部态势重新分配搜索、压制和攻击任务。控制核心应包括成员状态广播、目标竞争消解、攻击轮换和损毁评估；单弹失联后，其任务由邻近成员接替。 | 输入为有限目标区域、威胁类别和编组约束，输出为局部任务状态、目标确认结果和攻击或中止指令。接口需允许外部指挥系统只下达任务边界，不依赖持续遥控；弹间通信应支持低带宽、间歇连接和节点退出。 | 在导航受扰、通信间歇和部分成员被拦截的条件下，验证任务是否仍能收敛，重点观察目标误判、重复攻击、成员争抢和剩余弹体失去任务的问题。若必须持续联网才能完成分工，群栖方案的核心价值不成立。 |
| 蜂簇接力巡猎精打弹 | 采用一个母体载运多个小型攻击单元的构型，母体负责接敌、释放时机和初始区域管理，释放单元分别完成搜索、诱导防御反应或末段打击。控制逻辑是按防御反应动态安排先后顺序，而不是一次性同时放飞。 | 输入为目标区域、释放条件和载荷组合，输出为各攻击单元的分配状态、目标线索和末段结果。关键接口集中在母体与子单元之间，必须解决释放后时序同步、身份确认、故障隔离和载荷状态回传。 | 重点验证母体受损、部分单元未释放、释放间隔偏差以及目标信息变化时的接力连续性；同时核查载运机构、能源和通信设备增加后，低成本与高消耗之间是否仍有合理交换关系。 |
| 气膜掠波隐巡击弹 | 采用适于近海超低空贴波飞行的弹体，飞控以海面高度保持、姿态稳定和障碍规避为中心，末端再根据目标特征完成航向修正。其产品重点是持续维持低空接敌几何，而非依赖外部平台实时引导。 | 输入包括初始航路、海况边界和目标类别；输出为飞行状态、导航可信度和目标判别结果。接口应连接海况与地形数据、末端探测器及发射平台装定设备，导航系统需支持卫星信号受扰时的组合定位。 | 验证重点是不同海况、能见度、海面杂波和导航欺骗条件下的高度保持、目标区进入和末端识别。若贴波飞行窗口只在平静海面成立，或末端识别无法区分海面背景与目标，则应限制其任务范围。 |
| 形记忆折展巡飞精打弹 | 采用可折展翼面或控制面，巡航阶段保持低阻和便于储运，接敌阶段改变展开状态、升阻特性和盘旋半径。控制系统必须把结构变形状态纳入飞行控制，而不能将折展机构视为单纯展开附件。 | 输入为航路、变形时机和目标区域，输出为结构状态、气动状态和末端攻击状态。关键接口包括折展机构位置反馈、锁定确认、飞控计算机和战斗部安全控制。 | 需在温度、振动、冲击和多次启停后验证展开一致性、锁定可靠性及变形后的控制裕度；还要比较变形带来的机动收益是否足以抵消重量、故障点和维护成本。 |
| 磁流体矢控巡飞精打弹 | 以磁流体受控偏转形成侧向控制力，适用于需要快速改变航迹、压缩防御预判时间的末段。产品形态应优先保证供能、热管理和磁场控制单元的可靠集成，飞控则采用受约束的偏转指令，防止连续修正造成失稳。 | 输入为目标方向、当前姿态和矢控系统状态，输出为侧向控制量、航迹变化和系统健康状态。接口需连接电源管理、磁场驱动、姿态测量和末端导引系统；外部系统只提供目标区域和交战边界。 | 重点验证矢控响应与弹体姿态变化的一致性、能源消耗、热负荷和故障后的传统控制接管能力。公开材料不足以支撑确定性机动指标，工程验收应先确认可重复的偏转效果和失效可控性。 |
| “玄礁”水下跃升巡飞弹 | 采用水下潜行、近目标跃升、空中末段攻击的跨介质构型。水下阶段以航向保持和深度控制为主，跃升转换阶段完成介质切换、姿态重构和传感器启用，出水后立即进入短时自主识别和攻击或中止判断。 | 输入为水下航路、跃升区域和目标类别，输出为潜行状态、跃升状态、空中识别结果及任务终止状态。接口重点是水下导航、跃升机构、空中飞控和末端探测器之间的状态交接，不能依赖出水后重新建立完整外部链路。 | 应分阶段验证水下航迹保持、出水姿态稳定、传感器切换和末端识别的连续性，并检查海况、入水冲击和水下通信缺失对任务闭环的影响。若跨介质转换导致识别窗口过短或姿态误差不可控，应缩小其适用目标和环境边界。
