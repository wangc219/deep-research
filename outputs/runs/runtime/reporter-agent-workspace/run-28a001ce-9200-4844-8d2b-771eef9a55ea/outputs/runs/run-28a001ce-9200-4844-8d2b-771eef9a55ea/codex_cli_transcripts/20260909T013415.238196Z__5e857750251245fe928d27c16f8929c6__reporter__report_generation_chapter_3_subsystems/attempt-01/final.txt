## 三、总体方案

### （二）子系统方案

**群栖自组巡飞精打弹。** 产品形态应是具备独立飞控、末端识别和局部任务处理能力的低成本弹体群，而不是依赖持续联网的无人机编队。单弹输入包括初始任务区、目标类别约束、时间窗口和自身导航信息；群内交换仅承担邻近态势、位置状态、目标置信度和攻击进度，外部指挥系统负责下达任务边界及必要的目标更新。控制机理以分布式任务分配、攻击轮换和损伤复核为核心，失链后仍能按预设规则保持、重分配或中止。输出应包括目标选择、航路调整、攻击顺序和结果回报。接口重点是任务装订、低带宽通信、导航替代和安全解算。工程验证必须在通信间歇、卫星导航受扰、单弹失效和目标诱骗条件下检验群体是否仍能完成有限任务；若必须依靠全连接链路才能保持编队和攻击秩序，该形态不成立。

**蜂簇接力巡猎精打弹。** 其核心不是多弹临时组网，而是一个母体携带并按时序释放多个小型攻击单元，因此产品重点应放在母体的搜索、释放管理、任务分发和单元状态监视。母体接收目标区域和威胁约束，先行单元负责暴露防御反应、消耗拦截资源或形成目标确认，后续单元依据结果接替攻击。关键接口包括母体与攻击单元之间的机械释放、电源、时序同步和任务装订接口，外部链路只提供有限更新。控制系统必须处理提前释放、单元漏发、局部失联和目标转移。验证不能只测试单元命中率，还要检验连续释放是否真正延长防御方决策负荷，并测定母体故障、释放顺序紊乱时的可控中止边界。

**气膜掠波隐巡击弹。** 该装备需要专门的超低空飞行平台、海面高度感知、姿态稳定和末端识别组件，不能由普通巡飞弹简单降低航高替代。输入主要是海况估计、航路约束、目标区域和实时高度状态；飞控依据海面起伏、风浪和速度变化连续修正航迹，末端传感器在接近目标后完成识别和攻击。外部接口应限于发射装定、导航校正和目标指示，贴海飞行安全不能依赖持续遥控。工程验证应分层开展：先验证气膜或掠波效应能否在代表性海况下稳定改善低空接近，再验证雷达高度计失真、海面杂波、喷水和导航受扰时的保持能力。其成立边界取决于海况适应范围和末端识别可靠性，而非概念上的低可探测描述。

**形记忆折展巡飞精打弹。** 产品形态应围绕可重复折展的承力翼面、位置感知和故障锁定机构展开。巡航阶段采用低阻构型保持航程，接敌或盘旋阶段依据目标方向和防御空隙展开或改变翼面，以获得临机机动。输入包括航路、目标方位、速度状态和机构健康状态；输出是翼面构型、盘旋半径和末端攻击姿态。关键接口在于折展机构与飞控、供能、热管理和弹体承力结构的耦合。验证重点是多次折展一致性、展开不同步、局部卡滞和高速气动载荷下的姿态恢复。若机构增重、耗能或故障率抵消了航程与机动收益，应转为有限次数的单次变形方案，而不能继续追求复杂变形。

**磁流体矢控巡飞精打弹。** 该方向应先按原理验证项目配置磁流体驱动和侧向控制模块，再决定是否进入完整弹体。其理论产品形态包括密封流体单元、磁场驱动组件、状态测量和常规飞控冗余通道。输入为姿态、速度、航向误差和末端目标线，输出为侧向修正力或折转指令。接口集中在供电、散热、磁场控制和飞控指令分配，不能假定磁流体控制能够独立承担全部机动。工程验证顺序应从流体稳定性、响应时间和可重复侧向力测试开始，继而进入风洞和缩比飞行试验，并与常规舵面控制比较。若能量需求、响应迟滞或流体状态变化无法控制，其直接军事效果只能停留在技术储备层。

**双体耦合巡飞精打弹。** 装备由前体引导单元和后体主攻单元构成，关键不是简单增加弹体数量，而是让前后两个部分在接敌时形成不同方向、不同时间的防御压力。前体输入目标区域和威胁状态，承担先行探测、诱导暴露或消耗拦截；后体依据预设时序和自身末端传感器从偏置方向完成主攻。必须明确机械连接、分离触发、短程状态交换和分离后的独立飞控边界。验证重点是高速分离、姿态扰动、前体失效、后体提前暴露及通信中断条件下的安全航迹和攻击闭环。若后体不能在缺少前体持续引导时完成末端识别，该装备只能作为双段攻击弹，而不具备所设想的耦合优势。

**“玄礁”水下跃升巡飞弹。** 该装备必须采用跨介质构型，将水下潜行、跃升转换、空中飞控和末端识别作为连续而非并列子系统。水下段输入航路、深度、海流和目标大致区域，依靠自主导航接近预定跃升点；转换段完成姿态、密封和动力状态切换；出水后由空中飞控接管，并在末段完成目标确认和俯冲攻击。接口重点是发射平台、潜航导航、跃升触发、跨介质供能以及空中导引头的快速接管。工程验证应优先检验水下航行误差、跃升姿态散布、结构密封、海况影响和出水后传感器恢复时间。其直接效果只有在水下隐蔽收益足以弥补跨介质转换风险时成立，不能把水下接近自动等同于成功突防。

总体建设上，优先形成抗扰导航、末端识别、失链保持和安全中止等共性底座，但各装备仍按自身作用链配置专用验证：群栖弹看降级协同，蜂簇弹看释放接力，掠波弹看海况适应，折展弹看机构可靠性，磁流体弹看原理可行性，双体弹看分离耦合，水下跃升弹看跨介质转换。公开证据不足的航程、成本、命中率和拦截收益不得直接写成确定指标，须以工况化试验结果逐步收敛。
