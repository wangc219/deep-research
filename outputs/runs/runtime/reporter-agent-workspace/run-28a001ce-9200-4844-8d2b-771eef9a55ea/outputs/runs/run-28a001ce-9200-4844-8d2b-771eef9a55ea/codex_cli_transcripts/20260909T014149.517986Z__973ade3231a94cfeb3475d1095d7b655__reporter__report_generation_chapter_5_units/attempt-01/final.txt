五、研制基础

（一）参与单位

公开材料尚不足以确认具体承研单位、型号归属和既有研制基础，因此本项目宜按产品责任、接口责任、试验责任和证据交付责任配置单位类型，不宜直接指定机构名称。总体牵头单位应具备弹药总体设计、任务载荷集成、发射兼容和安全性统筹能力，并对末端识别、导航降级、飞控、战斗部及全弹成本承担最终产品责任。

群栖自组巡飞精打弹的核心不在外部指挥平台，而在弹体群能够在通信间歇、定位受扰时完成编组保持、目标分配、攻击轮换和损毁判别。因此，需要由智能弹药总体单位牵头，配置自主控制、协同决策和抗干扰导航方向的专业单位；指挥信息和外部侦察单位只承担接口适配、任务注入与数据交接验证。试验单位应交付失链、错失目标和局部节点失效条件下的全过程日志，现有公开资料尚不能证明相关单位具备此类证据能力。

蜂簇接力巡猎精打弹的责任重点转为载体内部的释放机构、多个攻击单元之间的时序控制和末段接替。除弹体总体单位外，还需有小型攻击单元、引信或安全解除机构、载荷分发及结构强度专业单位共同承担产品责任；试验单位必须验证连续释放、单元失效后的任务重排和剩余单元安全性。公开依据不足以判断国内是否已有完整的载体—子单元联合试验链。

气膜掠波隐巡击弹需要海上低空飞行控制、海面杂波条件下的探测识别和抗盐雾环境保障，参与单位应包括低空飞行器总体、海洋环境试验、导引头与目标识别专业单位。其关键证据不是一般飞行成功，而是不同海况、能见度和海面背景下仍能保持安全高度并完成目标确认；目前缺少可核验的海试条件、探测数据和末端命中记录。

形记忆折展巡飞精打弹应由飞行器结构与智能材料单位联合承担，重点解决折展机构在发射冲击、长时间巡航和临机变形后的锁定可靠性。试验责任需覆盖重复折展寿命、展开不同步、姿态恢复及与既有发射装置的兼容性，公开资料尚不足以支持具体单位归属或工程成熟度判断。

磁流体矢控巡飞精打弹涉及电磁驱动、快速偏转、能源供给和热管理的深度耦合，宜由电磁流体控制、弹载电源和弹体总体单位组成专门联合体。其证据交付必须证明偏转响应、供能连续性和电磁兼容不会破坏制导识别；目前公开信息缺少可审计的实物试验、功率需求和环境适应数据，不能据此指定承研机构。

双体耦合巡飞精打弹需要总体单位、分离控制和双弹协同制导单位共同负责，试验重点是前体与后体分离后的航迹安全、目标交接和偏置航向末攻。若只有单体飞行或静态分离演示，不能证明其能够形成两轮防御压力，现有公开依据也不足以确认具备完整验证条件的单位。

“玄礁”水下跃升巡飞弹则必须引入水下航行器、跨介质转换、出水后飞控和末端识别等专业单位。总体责任应覆盖水下潜行、跃升转换、姿态稳定和靠岸目标确认的连续闭环；试验单位需提供水下航迹、出水姿态、通信恢复和末段识别的对应记录。由于缺少公开型号、试验场景和性能证据，具体承研或配套单位只能待立项论证后确定。
