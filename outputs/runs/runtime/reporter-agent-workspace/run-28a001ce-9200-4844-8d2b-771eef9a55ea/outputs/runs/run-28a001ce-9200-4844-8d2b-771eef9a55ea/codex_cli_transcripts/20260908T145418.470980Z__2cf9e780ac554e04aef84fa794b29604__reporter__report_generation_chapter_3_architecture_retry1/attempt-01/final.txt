## 三、总体方案
### （一）总体架构

本栏总体架构不把所有巡飞弹药抽象成同一套公共机理，而是按岛链拒止下“谁来保留任务决定权、谁来承担末端闭环、谁来消耗防空资源”来分层。外部体系只保留任务规划、目标更新、发射编组和战损回传接口；弹体本体必须承担抗扰导航、末端识别、飞控和安全中止，失链后仍能维持可验证的命中或终止。群栖自组型负责把目标选择、攻击轮换和损毁评估前移到弹体群内，改变的是分配权和决策节奏，不是单弹末制导机理；蜂簇接力型负责把一次接敌拆成多回合压力，关键在载荷分发与拦截消耗接口；双体耦合型则用前体引导、后体主攻把一次拦截拉成两轮负荷。三者共享的资源只有有限链路、统一任务包和损毁回传，不共享各自的成败机理。

其余型号按接敌几何分工：气膜掠波型依靠超低空贴波进入岸基雷达死角，改变的是探测窗口而非航迹随机性；形记忆折展型把航程与末段机动合并，改变的是转入攻击时的盘旋半径和可覆盖角域；磁流体矢控型用连续侧向偏转打乱防御预判，改变的是末段机动频谱；“玄礁”水下跃升型则先脱离空中防区，再在出水后完成识别和俯冲，改变的是防御体系的拦截链起点。它们只在统一指控接口、海空环境基准和目标库更新上耦合，任何一环失效都会把优势压回到单机自治水平，链路可靠性、目标判别置信度和跨介质转换稳定性因此成为本总体架构的共同失效边界。
