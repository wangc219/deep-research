二、项目画像

（四）主要战技指标

群栖自组巡飞精打弹的判别重点，不是单弹航程，而是通信受压和成员损失后仍能否维持群体任务闭环。指标应围绕“局部信息条件下的目标分配、攻击轮换和损伤评估连续性”设置，直接对应压缩防御方反应时间、维持多方向穿透压力的作战效果；同时考察部分成员失效后剩余弹体能否自主改派目标、调整队形并完成可控退出。验证应采用通信间歇、定位受扰、成员逐步损失和诱骗目标并存的实弹或半实物试验，不能用全连接网络演示替代。若一旦失去外部指挥就无法重新分工，或群体判断因少量错误目标而整体转向，则其制胜机理不成立。

蜂簇接力巡猎精打弹的核心指标是载体释放、前导单元耗散防御资源与后续单元接替攻击之间的时序闭合程度。它要形成的效果，是把一次突防转化为连续多回合压力，使防御方难以在拦截、换防和火力恢复之间获得完整间隔；因此应重点验证小型攻击单元的释放成功率、接力状态传递完整性以及前导单元失效后的后续补位能力。试验需引入近程拦截、诱骗和部分释放失败条件，检查剩余单元能否按目标优先级继续完成末段打击。若释放机构、单元间隔或载体受损会同步破坏全部后续攻击，该装备只能增加载荷数量，不能真正改变防御节奏。

气膜掠波隐巡击弹的关键不在概念上的“低空隐蔽”，而在不同海况下保持贴近海面飞行、导航稳定和末端识别的联合能力。其作战效果是利用海面遮蔽缩短岸基雷达和火控系统的有效反应窗口，优先打击雷达、导引站等关键节点。主要指标应包括海况变化时的飞行高度保持、波面扰动下的航迹恢复能力，以及进入末段后从海面背景中分离真实目标的判别可靠性。验证应覆盖风浪、盐雾、海杂波和导航受扰环境，并以防御系统实际探测链的发现距离和持续跟踪能力作为外部判据。若平静海面有效、复杂海况即失去控高或识别能力，则其隐蔽优势不能外推到岛链作战。

形记忆折展巡飞精打弹应以“巡航效率与末段机动能否在同一弹体内切换”为主要判断。它所追求的直接效果，是先以较低阻力接敌，再通过翼面和盘旋形态改变临机攻击方向，使防御方难以仅凭预设航路布置拦截。指标应突出折展动作的重复一致性、变形后气动状态恢复时间和末段机动期间的制导连续性，而不是单纯比较展开尺寸。验证需进行多次冷热循环、振动冲击和飞行状态转换试验，并检查变形误差是否扩大末端命中偏差。若结构变形受温度、冲击或疲劳影响明显，导致展开后控制面不同步，则其临机机动反而会成为最先失效的环节。

磁流体矢控巡飞精打弹的判别指标应直接服务于“改变可预判航迹”这一效果，重点考察侧向偏转和小半径折转能否快速、重复地发生，并且不以过高能量消耗换取短时机动。验证项目应包括磁流体响应的可控性、连续偏转后的姿态恢复和高低温条件下的输出稳定性；作战试验则应观察防御方根据既有航迹预测进行拦截时，是否因临机偏转而出现拦截窗口错失。当前缺少公开的实用化参数和工程试验事实，不能预设具体偏转角、响应时间或射程增益。若磁场驱动不足、热管理负担过重，或动作重复性无法满足制导要求，该路线不应按“高机动”计入指标。

双体耦合巡飞精打弹的核心是把一个消耗单元转化为前后两次不同方向的防御决策。其指标应围绕前体引导或诱导、后体偏置补入之间的相对位置保持和任务交接成功率设置，直接验证能否分散搜索、分配和末段拦截资源。试验要加入前体提前损失、链路短时中断和目标机动，检查后体是否仍能依据自身传感器完成末攻，而不是等待外部重新指令。若前体被拦截即使后体失去定位，或者双体间距与入射方向难以稳定复现，所谓“两轮负荷”就只是结构叠加，不能形成可靠的突防增益。

“玄礁”水下跃升巡飞弹最重要的是跨介质转换后的连续作战能力。它依靠水下接近避开岸基雷达和空中拦截，再在出水后迅速完成姿态建立、目标重捕获和俯冲攻击，因此应把水下航迹保持、出水成功率与出水后自主识别的衔接作为主要指标。验证须覆盖不同海况、水深和出水姿态，并检查出水窗口受扰时能否中止、改向或转入备用目标。若水下潜行有效但出水后传感器无法快速适应海空背景，或跨介质转换导致姿态和导航丢失，其隐蔽接敌不能转化为直接战果。

上述指标均应采用工况化判据，不把公开资料中缺少的航程、成本、命中率和成熟度擅自写成确定点值。最终是否成立，取决于各装备能否在受干扰、受拦截、受欺骗和局部失效条件下证明自身的独特作战动作，而非仅在理想网络或单一环境中展示功能。
