## 二、项目画像

### （二）作战运用模式

#### 1. 作战运用流程

岛链拒止环境下，本项目的作战运用不应从“巡飞弹药数量足够即可饱和突防”起步，而应从敌方已经具备全球导航卫星系统压制、链路干扰、分层防空、近程反无人机火力和伪装欺骗能力这一态势起步。低成本智能巡飞精打弹药进入战场的基本条件，是外部侦察和指挥体系能够给出初始目标区域、禁击边界和任务优先级，但不能假定飞行全程都有稳定数据链、连续目标指示或统一空情分发。弹药本体必须在接敌前就装订降级导航、失链处置、目标再确认和安全中止规则，否则一旦进入拒止区，外部体系只能提供有限修正，不能替代弹药完成末端识别和交战判断。

第一类作战动作是“失链不断打”的抗扰自治精打。其作用对象不是敌纵深全域目标，而是已由外部体系筛选过、位置误差可被弹药末段搜索覆盖的高价值或时间敏感目标。发射后，弹药依靠惯性、地形或景象等组合导航保持航迹，在通信间歇时按预置航路接敌；进入末段后，边缘识别模块对目标外形、热特征、运动状态和背景关系进行再确认，并把“命中”“复核”“放弃”作为本体动作而不是等待上级二次授权。该模式改写的交战关系在于，敌方通过压制导航和切断链路只能降低弹药搜索效率，却不能直接把弹药变成失控飞行器；我方制胜链条由“外部发现、任务装订、抗扰接敌、末端自治识别、战斗部毁伤、结果回传或事后判读”构成，直接战果是受扰条件下仍能保持有限但可验证的命中能力，并把误击和无效消耗控制在任务规则内。相对依赖卫星导航和连续链路的普通低成本无人弹药，该方向的不可替代变化是把最后数分钟的判别权和中止权下沉到弹体本身。其失效边界也很清楚：若目标伪装使本体识别置信度无法区分真伪，或初始目标区域误差超出弹药可搜索范围，就不能用“自治”掩盖情报不足。

第二类作战动作是“多载荷同体切换”的任务重构。它面对的矛盾不是单次命中，而是库存、平台和战场任务之间的不匹配：同一岛链方向可能同时需要侦察补盲、火力诱骗、通信压制、伴随评估和精确毁伤，若每项任务都绑定专用弹体，前沿分布式力量的携行、补给和维护压力会迅速吞噬低成本优势。模块化巡飞精打弹药的进入条件，是载荷接口、供电、重心、软件权限和发射适配边界已经固化，任务前可在不同载荷之间快速组合，但不把模块化扩大为无限改装。其决定性动作是按战场断点选择载荷：敌防空火力未暴露时，先使用侦察或诱饵载荷迫使雷达、光电和近防火力开机；目标窗口出现后，换用战斗部载荷完成点毁伤；需要压缩敌反应时间时，则以干扰或假目标载荷扰乱其探测识别链。该模式的直接战果不是单枚弹药威力增大，而是同一库存能在不同任务段转化为不同压力，使敌方难以用一种拦截规则同时应对侦察、诱骗和毁伤。相对单一弹体基线，它提高的是前沿部队的任务弹性和库存利用率。其成立边界在工程上很硬：若模块更换导致可靠性下降、重量失控、成本接近专用弹药，或不同载荷需要完全不同训练和保障流程，则模块化会削弱而不是增强作战持续性。

第三类作战动作是“弱通信协同突防”。它进入战场的前提不是全连接集群，而是少量弹药之间能够在通信受限时执行本地规则：谁先探测、谁继续压迫、谁转入诱骗、谁保留打击窗口。敌方防御体系通常希望把低成本巡飞弹药切成孤立目标，按探测、跟踪、识别、拦截的顺序逐个处理；弱通信协同的关键动作，是用分批进入、方向错开、任务角色转换和局部重规划，让防御方在有限时间内面对多个真假不一、速度和高度不完全一致的威胁。这里的制胜机理不是把每枚弹药都变成复杂无人机，而是让防御方的传感器、火控通道和拦截弹药同时承压，使其提前开机、过早射击或把高价值拦截资源消耗在低价值目标上。直接战果表现为压缩敌方反应窗口、扩大其处理负荷，并为后续精打弹药制造更短、更混乱的末端通道。该方向相对单枚突防的变化，是把成本交换从“弹药对拦截器”扩展为“弹药群对探测识别火控链”。但公开证据边界必须被保留：协同突防若依赖稳定广域指挥控制、连续数据融合和全程联网，在拒止环境中就不能作为本体确定能力，只能作为外部体系成熟后的增益能力。

#### 2. 链路闭环分析

本项目链路闭环的核心不是追求每个环节都在线，而是在关键断点上明确哪些动作由体系完成、哪些必须由弹药自担。发现和初始分配主要依赖外部侦察、指挥控制和任务规划；弹药本体承接的是进入拒止区后的航迹保持、目标复核、末端攻击和安全退出。这样划分后，链路闭环从传统的“持续发现、持续指挥、持续修正、末端打击”，转为“外部给出可打击问题，弹药在受扰区内完成可验证处置”。如果外部体系只能提供模糊区域而不能给出目标类别、禁击规则和任务优先级，弹药本体不应被要求弥补战略侦察缺口；如果本体不能在失链和导航受扰时保持可控动作，外部体系再强也难以保证末端军事效果。

抗扰自治精打方向的闭环重点在“末端证据能否支撑交战”。敌方反适应会集中在导航欺骗、假目标布设、热源诱骗和电磁静默上，试图让弹药把错误目标当成真目标，或因无法确认而放弃攻击。对应的我方闭环不能只考核飞到目标区，而要考核受扰接敌、目标复核、命中判定和中止动作是否一致。直接战果成立的判据，是弹药在通信间歇、导航退化和目标伪装同时存在时，仍能把攻击集中到授权目标类别，并在识别失败时可控放弃。该方向的建设取舍应优先给导航降级、边缘识别和飞控安全留出成本与算力，而不是把成本消耗在依赖外部实时控制的复杂协同功能上。

模块载荷方向的闭环重点在“同一弹体是否真的缩短任务转换”。敌方反适应会通过目标分散、短时暴露和假火力点迫使我方频繁切换侦察、诱骗、压制和毁伤任务。若模块化只能在后方长周期改装，或不同模块之间需要重新认证发射平台、重新训练操作者，它就不能改善前沿作战节奏。有效闭环应表现为任务规划能够根据敌防御状态选择载荷，前沿单元能够按既定接口完成配置，弹药发射后载荷效应能够被外部体系或伴随平台识别，并反向支撑下一批弹药的释放顺序。直接战果是用更少种类的库存覆盖更多任务断点，而不是宣称一枚弹药包办所有任务。

弱通信协同方向的闭环重点在“通信降级后队形是否仍产生压力”。敌方最可能采取的反适应，是压制弹间链路、诱导单元分散、优先击落中继节点，并利用近程反无人机系统把低速目标逐个清除。因此，协同闭环必须以局部规则为底线：单元失联后仍按角色继续执行，局部探测结果只能在近距离、短窗口内触发有限重规划，不能依赖远方指挥节点实时重排全群任务。该方向的直接战果只有在降级通信条件下仍能增加防御方识别和拦截负荷时才成立；若释放时序、目标分发或单元接续依赖理想链路，前导消耗便不能转化为后续毁伤，协同突防也就退化为分散发射。

因此，本栏对应的作战运用模式应把三类能力区分使用：抗扰自治精打负责保证受扰末端仍有可验证毁伤，模块载荷负责提高前沿库存和任务重构效率，弱通信协同负责增加敌防御体系处理压力。三者可以在同一作战周期内衔接，但不能互相替代；自治识别不足时，协同不会自动带来命中；模块接口失控时，低成本优势会被保障复杂度抵消；外部指挥控制框架未成熟时，群体协同只能按降级规则使用。退出或中止条件宜保持简明：目标类别无法确认、禁击边界被触发、导航误差超过安全包线、载荷状态异常或协同链路退化到无法保证后续动作时，应放弃攻击、转入预设处置或等待下一批次任务重构。
