## 二、项目画像

### （三）体系贡献率分析

在第一岛链拒止环境下，现有低成本巡飞弹药的直接效果通常受制于外部侦察、持续通信和单弹决策：目标变化、链路受扰或防御方完成重新分配后，弹药容易从“可搜索、可命中”退化为“只能飞抵”。因此，各装备的体系贡献不能按航程、速度或载荷简单相加，而应看其是否把关键决策和突防动作前移到弹体本身，并由此改变防御方的搜索、分配、拦截和恢复节奏。

**群栖自组巡飞精打弹**的增量在于把单弹执行的任务改造成弹群内部的动态分工。相对依赖外部指挥链逐枚指定目标的基线，该装备可由多枚弹体在局部信息不完整时完成目标选择、攻击轮换和毁伤评估，使敌方不能只拦截一枚或等待上级重新分配。其直接战果不是单枚弹的命中率孤立提高，而是对舰艇、雷达和发射阵位形成连续压力，迫使防御体系在目标真假、优先级和拦截时序之间反复切换，放大漏防和补防迟滞。其贡献成立的前提是群内规则在通信间歇、定位受扰和个别弹体损毁后仍能稳定运行；若识别错误无法被群体纠正，或协同必须依赖全连接网络，则其相对单弹的交换优势会明显衰减。对手还可通过诱饵、静默和分散部署降低群体判断的有效目标密度。

**蜂簇接力巡猎精打弹**改变的是一次齐射的时间结构。单一载体内置并依次释放多个攻击单元后，前导单元可以迫使防御方开机、分配火力或消耗拦截资源，后续单元再利用暴露出的空隙完成搜索和末段打击。它相对于同时抵达的常规巡飞弹药，增加了连续多回合的决策负荷，直接压缩防御方换防、补弹和重新建立火控解算的时间，适合攻击防空节点或需要反复确认的临机目标。其弱点也集中在载体释放机构、单元间时序和末段识别闭环：只要释放失败、前导单元未能诱发有效反应，或防御方转用区域火力和延迟射击，接力关系就可能退化为多个低效小目标，且载体为保持重量和可靠性可能牺牲单元性能。

**气膜掠波隐巡击弹**主要贡献于接敌几何，而非群体数量。弹体以近海超低空贴波方式逼近岸基雷达、火控和防空单元，可利用海面背景压缩有效探测和跟踪距离，使防御方更晚获得稳定航迹。相对常规空中巡飞弹药，它有机会把防御反应从完整跟踪拦截降为临近区域的仓促处置，直接提高关键节点被漏防或来不及转移的概率。该优势高度依赖海况、气象、海面杂波、飞控精度和末段传感器工作窗口；在复杂海况、近岸多层传感器或低空反无人机火力覆盖下，遮蔽效果并不等于不可探测。对手还可通过低空补盲、被动探测和近岸分层火力抵消其接近收益，因此不能把贴波飞行直接换算为确定命中结果。

**形记忆折展巡飞精打弹**试图解决航程与末端机动相互牵制的矛盾。巡航阶段保持较小阻力和较高续航，接敌后再改变翼面形态或盘旋半径，可使弹体由预定航线转入临机搜索和攻击，适用于沿岸舰艇、发射车及短时出现的点目标。它相对固定构型弹药的体系价值，是扩大防御方依据航路设置拦截区时的误差，使“发现大致来向”不再等同于“能够覆盖末端窗口”。但折展动作必须在高速、振动和有限能量条件下可靠完成，反复变形还可能增加结构故障、控制滞后和红外特征；若变形只改变航迹而不能同步提升识别与命中控制，直接战果有限。对手可通过扩大末端警戒区、机动目标和多方向火力降低其临机机动收益。

**磁流体矢控巡飞精打弹**的设想是以磁场驱动流体受力，实现快速侧向偏转和小半径转向，从而削弱传统舵面、喷口或外露执行机构对航迹的约束。若该机理能够在弹体尺度上提供足够控制力，它将把可预测的接敌航迹变成持续变化的路径，针对岸防雷达、导引站和纵深点状火力迫使防御方提前发射并承担更高解算误差。与前述装备相比，它的贡献更偏向末端机动控制，而不是隐蔽接近或攻击编组。现有输入没有给出公开可审计的推力、响应时间、供电、热管理和环境适应数据，因此这只能作为待验证的潜在增量；一旦控制力不足、能耗过高或磁流体状态不稳定，其体系贡献会低于成熟舵面方案。防御方则可采用多传感器持续跟踪和近程高密度火力压缩其可机动空间。

**双体耦合巡飞精打弹**通过前体引导、后体主攻，把一个消耗单元拆成前后相继的两次防御决策。前体先吸引搜索与分配资源，后体从偏置航向进入末攻，相比单体弹药更可能造成拦截对象判断、火力分配和末段补射之间的错位。其直接效果是降低防御方集中拦截同一航迹的效率，并提高防空节点遭受精确毁伤的机会。该方案的贡献依赖双体分离、相对航迹保持和后体自主接续；若前体与后体过早暴露、间隔无法控制，或者防御方具备稳定的多目标火控，双体结构反而会增加体积、成本和可识别特征。它与蜂簇接力的区别在于前者依靠双体偏置制造一次攻击内的决策错位，后者依靠多个单元形成持续多轮压力，不能将两者的战果直接合并计算。

**“玄礁”水下跃升巡飞弹**改变的是来袭介质和防御责任边界。弹体先在水下接近，再跃升转入空中末段识别和俯冲攻击，可将雷达、岸防和空中拦截分属不同环节，迫使防御方不能用一套预设空中航迹覆盖全程。相对纯空中巡飞弹药，它对港湾、登陆点和靠岸舰艇提供了更隐蔽的接敌方向，直接价值在于提高关键时刻的突袭性和节点瘫痪可能。但水下航行、出水姿态、跨介质转换、出水后短时识别和通信恢复构成连续失效链；海况、障碍物、近岸水下警戒和出水区火力均可能抵消其优势。当前证据未给出这些环节的可审计成熟度，因而其贡献应按“跨介质突防潜力”计入，而不能视为已被证明的命中增益。

综合比较，群栖自组弹优先改写目标分配和毁伤评估，蜂簇接力弹优先改写防御时间节奏，气膜掠波弹优先压缩探测几何，折展弹优先扩大末端航迹选择，磁流体矢控弹瞄准机动控制方式，双体耦合弹制造两轮决策负荷，“玄礁”则从水下接敌方向重构防御链。它们的贡献具有替代关系而非简单叠加：在受扰条件下，任何依赖持续联网、稳定识别或未经验证的新机理都可能成为单点失效。建设上应先验证能在降级通信和不完备数据下维持直接战果的本体能力，再评估复杂结构和跨介质方案能否以可接受成本换取真实的拦截窗口压缩。
