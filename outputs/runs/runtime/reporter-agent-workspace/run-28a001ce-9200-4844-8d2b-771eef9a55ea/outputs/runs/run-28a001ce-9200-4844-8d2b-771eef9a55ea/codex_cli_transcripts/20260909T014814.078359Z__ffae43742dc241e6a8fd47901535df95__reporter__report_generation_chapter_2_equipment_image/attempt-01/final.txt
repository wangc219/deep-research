## 二、项目画像

### （一）装备图像概述

| 装备对象 | 核心技术与形成能力 | 部署或进入方式 | 关键动作、作用对象与直接效果 |
|---|---|---|---|
| 群栖自组巡飞精打弹 | 将目标选择、攻击轮换和毁伤评估部分前移至弹体群，通过弹间局部协同、分布式任务分配和失联后自主重规划，使多个低成本弹药不再依赖单一指挥节点维持完整编组。相对单弹独立突防，它改变的是防御方按固定节奏搜索、分配和拦截的处理方式；其不可替代性在于单枚受损后仍可由其他弹体接替任务。 | 可由同一批次或多方向分散进入威胁区，外部系统主要提供初始任务和目标范围，弹群在接敌后自行调整攻击次序。研究上不应假定持续联网，必须把通信间歇、数据不完备和局部节点失效作为基本工况。 | 弹群先分散压迫敌方搜索与火力分配，再依据局部发现结果轮换攻击舰艇、雷达和发射阵位，并对已受击目标进行复核或放弃。直接效果是延长防御方连续处置时间，形成多点、连续的毁伤压力；若协同规则只能在全连接网络中工作，或消耗率抵消低成本优势，该能力即失去成立基础。 |
| 蜂簇接力巡猎精打弹 | 单一载体内置并依次释放多个小型攻击单元，弹体本身承担释放、搜索分发和末段打击衔接。前导单元可迫使防空系统开机、暴露位置或消耗拦截资源，后续单元据此改变进入方向和攻击顺序，形成连续回合而非一次性齐射。其核心价值不是简单增加数量，而是把一次拦截任务转化为持续的时间压力。 | 适合由一个较大载体接敌后分批展开，减少大量小弹在远距离航段的管理负担；进入末段后由已释放单元完成局部搜索和接力攻击。尚缺少公开证据证明其在复杂海况、释放故障和单元识别失误下仍能保持可靠闭环，载体与小单元的接口可靠性是建设边界。 | 前导单元首先吸引拦截、探测防御反应，后续单元从暴露较少或防守薄弱方向补入，连续作用于雷达、火控节点或舰艇关键部位。直接效果是压缩防御方恢复、换防和集中拦截的时间窗口；若释放次序固定、单元容易被同时识别，敌方即可重新建立拦截节奏。 |
| 气膜掠波隐巡击弹 | 依靠贴近海面的低空飞行、海面背景遮蔽和自主末段控制，降低岸基雷达对来袭弹药的稳定发现和持续跟踪能力。与普通巡飞弹依靠较高空域搜索不同，该装备把主要生存性放在接敌几何和海面杂波利用上，再由末端识别完成攻击。 | 主要从近海方向低空进入，外部侦察只需提供大致目标区，弹体在接近岸线后完成搜索和攻击决策。其部署价值受海况、风场、飞控精度、雷达布置和目标高度影响，当前输入没有给出足以证明气膜效应稳定增益的试验数据，不能直接转化为确定的隐身或漏防指标。 | 弹体沿海面背景逼近岸基雷达、火控和近程防空单元，在对手跟踪链尚未稳定建立前完成末段攻击。直接效果是提高关键节点被突然命中的可能性，并迫使防御方扩大低空警戒和拦截覆盖；当海况恶化、航迹高度波动或敌方采用多传感器协同探测时，其掠波遮蔽优势可能明显下降。 |
| 形记忆折展巡飞精打弹 | 以可折展翼面或骨架在巡航、盘旋和末段机动之间切换，使弹体兼顾远距离低阻飞行与接敌阶段的转向、盘旋和临机攻击。相对固定外形弹药，其差异在于通过形态变化扩大可用航迹，而不是单纯依靠发动机或外部指挥提高机动性。 | 发射和远程巡航阶段保持收拢或低阻状态，进入目标区后再展开并根据目标位置改变盘旋半径。该形态适合打击沿岸舰艇、机动发射车和临机出现的点目标，但折展机构的抗冲击、重复动作可靠性、展开后控制稳定性和重量代价尚无公开定量依据，应先验证动作成功率与失效后的可控性。 | 接敌前利用低阻航迹保持滞空或接近，发现目标后改变翼面和盘旋状态，从既定航路转入临机末攻，使防御方难以仅按原航路布置拦截。直接效果是增加对机动目标和临时暴露目标的攻击机会；若变形时间过长、展开动作暴露明显，或折展后无法保持稳定控制，航程优势将不能转化为命中优势。 |
| 磁流体矢控巡飞精打弹 | 通过磁场调节内部磁流体分布，产生侧向控制力或辅助转向，目标是减少传统舵面转向半径和固定航迹可预测性。其形成的不是一般意义上的高速突防，而是让末段航迹持续变化，增加防御方预测交点和提前发射的困难。 | 可按预设航路进入目标区，在末段由弹体自主控制完成连续偏转，重点面向岸防雷达、导引站和纵深点状火力。该路线仍缺少磁流体响应速度、能耗、环境适应性以及控制力与弹体姿态耦合的公开验证，不能把理论可偏转直接等同于可用战术机动。 | 接敌时主动改变侧向运动和折转方向，避开防御方根据早期航迹建立的拦截解算，优先攻击探测、导引和火力分配节点。直接效果是迫使防御方更早开火、扩大拦截弹消耗，并提高局部漏防概率；若控制响应不足以抵消气动扰动，或偏转造成速度和航程过快损失，反而会降低末段突防能力。 |
| 双体耦合巡飞精打弹 | 采用前体引导、后体主攻的双体耦合结构，把一次来袭拆为两个具有时间和方向差异的处置对象。前体负责提前暴露、牵制搜索和分配资源，后体则利用偏置航向完成主攻击；其不可替代变化是增加防御方的决策轮次，而非简单提高单枚弹的毁伤量。 | 可由同一发射单元成对进入，在接敌前后保持耦合或按任务阶段分离。外部系统需提供初始目标和航路，但前体、后体的职责切换应由弹体内部规则完成，以避免链路中断导致任务失配。耦合结构增加了分离控制、相对定位、动力匹配和误差传递风险，必须证明前体受损后后体仍能安全完成攻击。 | 前体先进入防区并诱发搜索、跟踪和拦截资源调动，后体随后从不同方向或不同时间窗口补入，对防空节点实施主攻。直接效果是把防御方的一次集中拦截拆成连续两轮负荷，降低其集中处置效率；若两体间隔、航向和特征过于固定，敌方可将其作为同一批目标统一处理，双体优势随之消失。 |
| “玄礁”水下跃升巡飞弹 | 以水下潜行与空中巡飞相结合的跨介质形态，避开传统空中来袭目标在远距离上形成的雷达暴露，再在接近目标后跃升、识别并转入俯冲攻击。其核心变化是使防御方不能用同一套空中预警、岸防和近程防空程序覆盖完整来袭路径。 | 适合从近岸或港湾外缘水下进入，在预定海域跃升后完成短时空中巡猎和末段打击。装备本体必须承担水下导航、出水姿态控制、跨介质转换和跃升后的目标识别；目前缺少水下航行工况、出水成功率、海况限制及跨介质转换误差的公开证据，不能预设其适用所有近海环境。 | 水下阶段绕开雷达视线和部分空中拦截链，出水后立即锁定港湾、登陆点或靠岸舰艇并俯冲命中。直接效果是缩短目标从发现到受击的反应时间，打破岸防体系按固定方向预警和拦截的节奏；若水下航迹易被声学或水面监视发现，或出水后识别时间不足，该装备的跨介质优势将难以转化为稳定战果。 |
