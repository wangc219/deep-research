## 五、研制基础

### （一）参与单位

公开资料不足以确认具体承研单位、型号归属和既有分工，故本项目宜按产品责任和证据交付组织机构类型。总体牵头单位应承担弹体方案、任务闭环、发射兼容、成本约束和系统级交付责任，不能仅由承担外部指挥或情报融合的单位替代。对于群栖自组巡飞精打弹，需配置具备多弹协同、自主任务分配、失链保持和损毁评估能力的弹药总体与飞控单位；蜂簇接力巡猎精打弹则应由总体单位统筹载体释放机构、前后单元接续和分批攻击时序，重点提交连续拦截压力而非单枚命中证明。

气膜掠波隐巡击弹需要气动布局、近海环境适应、超低空飞控和末端制导单位共同承担责任，试验单位必须能提供海况、风场、海面杂波条件下的贴波稳定和探测规避证据。形记忆折展巡飞精打弹的核心责任落在折展结构、形状记忆材料、重复展开可靠性及巡航到接敌状态切换，相关材料与结构机构应证明变形不会破坏控制、载荷和发射安全。

磁流体矢控巡飞精打弹应由电磁执行机构、磁流体回路、能源管理和高动态飞控单位联合研制；其关键交付不是概念演示，而是侧向偏转、连续折转与末端识别在同一弹体上的闭环数据。双体耦合巡飞精打弹需要双体连接释放、前后体时序控制、偏置航向协同和末攻制导单位承担接口责任，须验证前体失效或链路中断时后体是否能安全降级，不能沿用普通协同弹的证明口径。

“玄礁”水下跃升巡飞弹还需水下航行、耐压密封、出水转换、空中飞控和跨介质末制导单位协同，试验责任应覆盖水下潜行、出水姿态稳定及出水后快速识别的连续过程。另需设置独立的综合试验与鉴定单位，负责抗干扰导航、间歇通信、伪装目标、分层拦截和局部节点失效条件下的可审计证据。现有公开信息缺少具体单位名单、资质边界、接口标准、试验场景和原始记录，后续只能据此核实承研归属与交付能力。
