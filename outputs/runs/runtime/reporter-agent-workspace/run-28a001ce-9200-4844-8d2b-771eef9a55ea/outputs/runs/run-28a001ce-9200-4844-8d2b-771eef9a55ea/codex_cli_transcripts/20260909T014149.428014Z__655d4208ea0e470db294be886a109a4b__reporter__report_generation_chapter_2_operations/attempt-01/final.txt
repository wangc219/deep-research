## 二、项目画像

### （二）作战运用模式

#### 1. 作战运用流程

本项目面向第一岛链外缘至近岸方向的拒止环境，进入条件不是持续联网和完整目标指示，而是已有侦察或任务规划能够提供大致目标区、威胁区和禁入边界，弹药在接敌后仍须依靠本体完成航迹保持、末端判别和交战决策。敌方主要依托分层防空、反舰火力、近程反无人系统以及全球卫星导航压制和通信干扰，力图在发现、分配、拦截三个环节恢复稳定节奏。因此，装备运用的核心不是简单增加飞行数量，而是让弹体在失链、定位受扰和目标伪装条件下继续制造有效决策压力，并把直接战果落实到雷达、火控、发射阵位、舰艇和港湾节点等具体对象。

**群栖自组巡飞精打弹**适用于敌方防空节点分散、火力配置存在空隙但能够依靠网络快速调度的场景。进入威胁区后，多枚弹体不把全部判断交给外部指挥链，而是在局部信息范围内完成编组保持、目标优先级调整、攻击轮换和损伤判断。其决定性动作是将部分弹体用于持续侦察、牵制或诱发敌方雷达工作状态，其他弹体根据暴露情况改变接敌顺序和攻击对象。这样形成的直接结果，不是单枚弹药对单个目标的孤立命中，而是使敌方防空体系同时面对目标真假判断、火力分配和拦截次序冲突，迫使其提前开机、分散火力或放弃部分目标。相对单批次、固定航线的巡飞弹药，该装备的不可替代变化在于把编组层面的自适应前移到弹体群内。敌方可通过关闭辐射源、扩大近程拦截密度和制造诱饵目标反适应；若弹体无法在通信间歇时保持编组规则，或无法区分真实目标与诱饵，群体数量将转化为相互干扰，必须中止攻击或回到预设安全区。

**蜂簇接力巡猎精打弹**解决的是单次突防被敌方按固定窗口集中拦截的问题。其运用前提是目标区具有持续搜索价值，且载体能够在接敌前释放多个攻击单元。首批单元不必立即追求最终毁伤，可先迫使防空系统暴露探测和射击状态，消耗拦截资源；后续单元依据前导单元回传或预设规则，选择新的进入方向和攻击对象，完成对雷达、火控或关键设施的补打。对手状态由“集中拦截一次来袭”转变为“连续处理多轮来袭”，其恢复、换防和重新装填节奏被压缩，直接战果表现为关键节点被反复压制，或防御方为保留核心火力而降低局部拦截强度。它不同于群栖自组弹的多弹自主分工，优势在于同一载体内部的释放时序和接力关系，能够在外部链路不稳定时保持攻击波次。敌方可通过提前设置拦截区、优先打击母载体、加强末端近防来削弱接力效果；一旦释放机构、单元间识别或末段目标判别不可靠，连续攻击就会退化为无序消耗。

**气膜掠波隐巡击弹**主要用于近海低空接敌，针对岸基雷达、火控站和防空单元依赖较稳定探测几何的弱点。进入条件是海况、风场和沿岸地形允许弹体维持贴近海面的飞行状态，并且任务规划能够避开无法承受的障碍和水面风险。其关键动作不是改变攻击波次，而是在接敌过程中持续保持低空掠行，以海面背景和地球曲率压缩敌方有效探测距离，直至末段才完成目标确认和攻击。对手即使掌握大致来袭方向，也可能因发现时间缩短而无法完成稳定跟踪、火力分配和拦截窗口准备，直接战果首先体现为岸防传感器和火控节点失效，继而削弱后续防空火力的组织能力。相对常规中高空巡飞弹药，该路线以接敌几何而非群体数量形成突防价值。敌方可部署低空补盲传感器、海面巡逻力量和近程拦截火力；海况突变、浪高超出控制能力或末段识别窗口不足时，应停止追击，避免把低空优势变成失控风险。

**形记忆折展巡飞精打弹**适合目标位置存在变化、航路需要兼顾远距离巡航和临机机动的任务。弹体在巡航阶段保持较低阻力构型，以较小能量成本接近目标区；进入末段后，通过折展翼面或改变盘旋形态扩大侧向机动和搜索覆盖，使沿岸舰艇、机动发射车及临时部署点目标难以依据既有航迹预置拦截。其直接效果是把“可预测航路”转化为“临机选择窗口”，提高对移动或短时暴露目标的交战机会。防御方即使提前掌握大致方向，也需在更短时间内重新判断目标位置和拦截点。该装备的成败集中取决于折展动作的可靠性、变形后的飞控稳定性和末端识别是否能够同步工作；若变形后航迹误差扩大，或者机动消耗的能量超过预留，远距离优势将无法转化为命中。

**磁流体矢控巡飞精打弹**面向具有较强航迹预测和点状拦截能力的岸防体系。其决定性动作是利用磁场改变导电流体分布，形成快速侧向偏转和小半径折转，使弹体在接敌阶段不再受单一舵面和固定机动模式限制。它优先打击岸防雷达、导引站和纵深点状火力，通过连续改变来袭方向迫使防御方提前发射或重复修正拦截方案，直接增加漏防和错配概率。相较折展翼弹依赖构型变化，该装备以矢量控制连续改写航迹，理论上更适合穿越多层点状火力，但磁流体响应速度、能源供给、热管理和控制稳定性均是关键未知。敌方若采用多角度传感器融合和近程区域覆盖，可降低单纯机动带来的收益；在矢控响应不能稳定复现前，不宜把其机动潜力直接换算为确定性突防指标。

**双体耦合巡飞精打弹**针对防空系统能够快速锁定单一飞行体、但在前后分离目标间需要重复分配资源的矛盾。前体承担引导、暴露或吸引火力，后体保持偏置航向，在敌方搜索和拦截资源被牵制后再进入末段攻击。其直接作用是把一次拦截决策拆为两个连续阶段，使防御方不能只按一个目标的航迹和速度完成火力闭环。该装备的专属价值在于前后体之间的时间差和空间偏置，而不是简单增加弹体数量。敌方可优先攻击前体、扩大交战区或使用多目标同时拦截，迫使后体提前暴露；若双体分离后无法维持相对关系，后体将失去由前体创造的突防条件。必要时应放弃后续末攻，保留对失控单元的安全处置。

“玄礁”水下跃升巡飞弹改变的是来袭介质。它先在水下接近港湾、登陆点或靠岸舰艇，避开主要空中雷达和部分岸防火力，再在接近目标后跃升出水，迅速完成末端识别和俯冲攻击。敌方原本可以依据空中航迹提前组织防空，此时必须同时处理水下搜索、出水位置判断和空中末段拦截，防御链被迫跨介质重组。直接战果重点是港湾入口、靠岸舰艇和登陆支援节点受到突袭，而非远距离持续巡飞。其不可替代性来自水下潜行与空中末攻的转换，但水下导航、出水姿态、通信断续和海况适应性决定其是否能在目标附近完成闭环；若无法确认出水区安全或末段目标特征不足，应中止跃升攻击。

#### 2. 链路闭环分析

本项目的制胜链条应由“外部提供任务边界、弹体完成局部闭环、战果信息回流修正后续行动”构成。外部情报侦察和指挥信息系统可以提供目标区、威胁区、时间约束和禁攻边界，但不应被默认成持续目标指示来源。弹药本体必须承担抗干扰导航、失链保持、末端识别、飞控和载荷作用；群体重规划、跨域目标分发和战区级战果确认仍依赖外部体系。由此，装备比较的关键不在名义上的智能程度，而在通信受压后仍能保留多少可验证的直接效果。

群栖自组弹的闭环重点是成员状态共享和局部任务重分配，验证应观察通信间歇、成员失效和诱饵存在时是否仍能完成有效分工；蜂簇接力弹则应验证释放时序、前后波次间隔与拦截资源消耗之间的关系，不能用普通群体协同结果替代。气膜掠波弹的闭环核心是导航、飞控和末端识别的连续耦合，海况变化下的贴波保持比理想条件下的飞行展示更能决定项目成立与否。形记忆折展弹须把变形可靠性和末段命中判别绑定验证，磁流体矢控弹则要先证明矢量偏转可以重复控制，再讨论对拦截窗口的压缩效果。双体耦合弹应验证分离后相对航迹是否能稳定制造两轮防御负荷；“玄礁”弹则必须同时验证水下导航、出水转换和出水后快速识别，任何单环节失效都会使跨介质优势消失。

因此，第一优先级是抗扰自治、失链保持和安全中止，第二优先级是与现有发射平台及指挥信息系统的标准接口，随后才是群体协同、波次接力、构型变形、矢量机动或跨介质转换等增强能力。公开资料已显示，受限通信条件下的协同自治具有研究基础，但尚不足以证明上述具体弹药形态能够稳定形成战果；项目验收应以降级场景下的发现、识别、交战和可控损失为判据，缺少公开试验支撑的参数只能作为待测变量，不能直接写成确定性作战结论。
