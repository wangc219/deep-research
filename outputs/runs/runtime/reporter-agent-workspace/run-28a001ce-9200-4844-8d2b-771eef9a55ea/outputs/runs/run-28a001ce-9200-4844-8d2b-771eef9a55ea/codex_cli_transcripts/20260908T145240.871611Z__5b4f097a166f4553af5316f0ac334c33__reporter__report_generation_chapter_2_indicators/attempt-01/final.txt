二、项目画像

（四）主要战技指标

群栖自组巡飞精打弹的核心不是单弹命中，而是在GNSS受扰、链路间歇和假目标并存时仍能把群内目标选择、攻击轮换和毁伤评估接续起来，因此最能判别其价值的指标应是“失链后自治重分配时间”和“末端有效命中保持率”。前者决定弹群能否在外部指控中断后继续压迫防空链，后者决定它面对诱饵、遮蔽和局部损失时是否还能形成连续毁伤。验证上应看降级通信条件下的实弹或高保真靶场表现，而不是理想联网下的编队演示。

蜂簇接力巡猎精打弹依靠前导单元先消耗拦截资源、后续单元补位完成精确毁伤，其关键指标不该泛写成“群体协同”，而应抓“接力轮次保持率”和“前导消耗后续补位成功率”。前者反映多回合压力能否按预定节奏落到对手防空窗口，后者反映前段诱发暴露后，后段主攻能否接上并打穿残余防御。若接续间隔失控、分发偏差增大或后续单元在干扰中失去识别，整型装备就退化为一次性撒布载荷。

气膜掠波隐巡击弹的制胜点在于把接敌几何压进海面背景里，因此最有区分度的指标是“超低空贴波高度稳定误差”和“末段首探距离压缩率”。前者对应能否长期压住雷达视线，后者对应能否把敌方从发现到可拦截的反应窗压短到不足以完成稳定射击。验证必须在不同海况、风场和岸基雷达背景下进行；若只能在平静海面和固定航路下成立，这型装备的隐蔽优势就不稳。

形记忆折展巡飞精打弹把远程巡航和临机机动绑在同一弹体上，真正决定交换比的不是“能折展”，而是“翼面切换响应时间”和“折展后机动半径压缩率”。前者决定它能否在接敌瞬间快速改写航迹，后者决定它能否把防御方已经预判的拦截窗口重新拉开。若折展机构增加阻力、迟滞过大或反复切换后稳定性下降，这种装备就会在最后几十秒失去价值。

磁流体矢控巡飞精打弹的意义在于用连续可变的侧向偏转打乱对手火控解算，所以应盯住“矢控响应滞后”和“高机动航迹保持命中率”。前者体现磁场驱动和流体重分配是否足够快，后者体现它在小半径折转、连续变向时能否仍把载荷送到正确象限。若能耗过高、控制力不足或磁流体状态受温度和振动影响明显，这型弹药就难以在实战中保持可重复的机动优势。

双体耦合巡飞精打弹的专长是把一次拦截拆成两轮决策负荷，因此更该看“前后体耦合时差稳定度”和“双体偏置入攻命中率”。前者决定诱偏与主攻是否真正构成两次负荷，后者决定敌方完成第一次反应后，第二体能否从偏置航向补入末攻。若分离误差大、姿态同步差或前体消耗效果不稳定，它就会从压低拦截效率变成普通双弹串联。

“玄礁”水下跃升巡飞弹的价值在于跨介质突防，最关键的指标不是航程，而是“水下潜行到出水转换时间”和“出水后末段识别命中率”。前者决定它能否在暴露前完成路径切换，后者决定它出水后是否还能快速识别港湾、登陆点或靠岸舰艇并完成俯冲打击。若出水特征过大、转换过慢或末段识别依赖单一视景，这型装备就会被岸防与防空联手提前封堵。
