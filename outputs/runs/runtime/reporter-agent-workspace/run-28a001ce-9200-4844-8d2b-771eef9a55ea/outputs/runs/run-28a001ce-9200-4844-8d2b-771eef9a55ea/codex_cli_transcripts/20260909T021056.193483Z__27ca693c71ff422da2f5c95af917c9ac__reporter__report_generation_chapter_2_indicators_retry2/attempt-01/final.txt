二、项目画像

（四）主要战技指标

主要战技指标不宜按“航程、速度、精度、载荷”作通用堆列，而应从岛链拒止环境下最容易断裂的交战链条反推。对低成本智能巡飞精打弹药而言，第一项判别指标是“受扰末端命中保持能力”：其作战效果不是单纯提高命中精度，而是在卫星导航受压制、链路间歇、目标伪装并存时，仍能完成末端搜索、识别、攻击或中止决策。该指标应重点考核弹药本体在失去连续外部指示后的降级导航、末端目标再确认和攻击窗口保持能力；若只能在连续联网、目标无遮挡、导航信号正常条件下命中，则不能说明其适合拒止环境。验证上应设置导航受扰、链路中断、相似诱饵共存的组合场景，观察其能否维持可审计的命中、偏离或中止结果。

第二项指标是“失链后任务闭合能力”。它对应的作战效果是把弹药从远程遥控消耗品转为具备有限自治的交战节点，避免在防区外接敌和末端突防阶段因链路压制而成批失效。其重点不是让单弹具备完整战场理解，而是要求其在预设任务边界内保留航路修正、目标区搜索、合法目标确认和安全处置规则。直接战果是压缩防御方通过通信压制中断攻击的窗口，使对手必须同时投入探测、拦截、欺骗和近程防护资源。验证应以通信离线比例、失链持续时间和任务边界外中止率为核心变量，不能用全程在线演示替代。

第三项指标是“低成本交换下的可消耗突防能力”。在分层防空和反无人机火力覆盖下，巡飞精打弹药的价值不在单枚平台性能压倒防御体系，而在以可承受成本迫使防御方消耗更昂贵的拦截、传感和指挥资源。因此，指标应关注单位任务效果所需弹药数量、诱饵与实弹混合后的防御处理负荷、被拦截后的残余打击概率，以及批量发射条件下的任务成功分布。若成本降低以牺牲制导、识别和可靠性为代价，导致多数弹药在接敌前即失控或误击，则成本优势不能转化为军事效果。

第四项指标是“欺骗目标环境下的识别与拒止误击能力”。岛链拒止环境中的目标不会以清晰、静止、无遮蔽状态出现，防御方也会通过伪装、假目标和电磁欺骗削弱低成本弹药的末端判别。该指标对应的作战效果是把火力从“到达目标区”推进到“击中有价值目标”，并把误击、空耗和被诱导偏航控制在可接受范围内。验证应使用相似外形诱饵、热源干扰、遮蔽目标和非目标车辆混杂场景，重点考察弹药是否能在置信度不足时转入盘旋、重搜或中止，而不是强行攻击。

第五项指标是“模块载荷更换后的任务可靠性”。其作战效果是让同一弹体在侦察、诱骗、压制和精打之间形成库存复用，而不是为每种任务重新建设一条弹药链。该指标的关键不在接口概念本身，而在换装后重心、供电、散热、数据接口、发射兼容和飞控参数是否仍保持稳定。若模块化造成重量超限、可靠性下降或单枚成本明显抬升，则会削弱低成本批量使用的根本优势。验证应以不同载荷构型下的发射成功率、飞行稳定性、末端识别可用性和维护换装时间为判据。

第六项指标是“降级协同下的局部重规划能力”。协同突防不能假定稳定网络已经存在，公开信息也显示多域指挥控制框架仍需继续完善，因此该指标只能限定为弹药本体或小规模弹群在弱通信条件下的局部协同。其作战效果是当部分弹药被拦截、链路受压或目标状态变化时，剩余弹药仍能调整搜索扇区、攻击顺序或诱骗分工，维持对防御体系的连续压力。验证应在低带宽、间歇通信和节点损失条件下进行；若协同行为依赖全连接、实时人工重规划或外部体系持续目标指示，则不能计入弹药本体战技指标。
