## 二、项目画像

### （一）装备图像概述

| 装备 | 核心技术与形成能力 | 部署或进入方式、作用对象 | 关键动作与直接效果 |
|---|---|---|---|
| 群栖自组巡飞精打弹 | 以弹体间局部通信、分布式目标判别和失链重分配规则，把目标接替、攻击排序和损毁判断的一部分留在弹群内部。其相对单枚巡飞弹的变化，不是单弹性能叠加，而是部分弹体被干扰或拦截后，剩余弹体仍能维持有限任务闭环。外部侦察、初始目标区和任务优先级只能作为输入，末端识别、航迹保持和安全中止必须由弹体承担。 | 以多枚弹体从防区外缘分散进入，面向舰艇、岸基雷达和发射阵位。适用于敌方依靠固定搜索、分配和拦截节奏组织防御的场景；若对手采用持续区域干扰、诱饵和多点火力封锁，弹群协同收益将受制于单弹导航、识别一致性和局部通信保持能力。 | 接敌后按目标可信度、剩余能量和局部威胁调整先后次序，使防御方难以按原有节拍逐枚处置；部分弹体牵制或攻击传感器、火力节点，其余弹体再转向舰艇或发射阵位，直接形成连续压制机会。若协同必须依赖中心节点或全程联网，则其低成本规模优势不能成立。 |
| 蜂簇接力巡猎精打弹 | 由一个载体携带多个小型攻击单元，并在弹体内部完成释放管理、目标分派和末段攻击衔接。它把一次齐射改造成有先后的多轮交战：前导单元承担诱发搜索、消耗拦截和暴露防御反应，后续单元利用新形成的缺口实施精打。成立条件集中在载体释放可靠性、单元间最低限度状态共享以及载荷和重量约束。 | 由兼容平台将载体送至目标区或防区外缘，再按威胁方向和时序释放攻击单元，主要作用于防空搜索设备、火控节点和近程拦截阵位。具体投放平台、单元数量和航程档位尚未给定，不能据此推定实际部署规模或交换比。 | 先以低成本单元制造多方向、分时段威胁，迫使雷达开机、火力分配或拦截发射，再由后续单元补入关键方向，压缩防御方换防和再装填时间。直接效果是延长并加密防御压力，而非保证每个单元均命中；若对手采取被动探测、分散部署和拦截储备管理，接力收益会下降。 |
| 气膜掠波隐巡击弹 | 依靠近海超低空贴波飞行、海面背景遮蔽和自主高度保持，长期把弹体压在岸基雷达较难稳定跟踪的探测几何内。相较普通巡飞弹末段短时降高，它改变的是整个接敌段的暴露方式。其能力核心不是“低空”标签，而是海况适应、姿态稳定、导航降级和末端识别共同维持安全贴波航迹。 | 从海上方向进入岸防体系低空区域，主要攻击岸基雷达、火控单元和近岸防空阵位。弹体需要自主完成贴波控制，外部链路只提供航路约束、目标区和必要授权；海况、风浪、海面杂波以及目标区低空补盲能力是关键边界。 | 在被稳定发现前保持贴海航迹，接近目标后切换末端识别和攻击姿态，利用发现链不连续造成的反应迟滞，直接争取对雷达或火控节点的毁伤窗口。若风浪导致高度控制失稳，或对手采用多点低空探测、红外补盲和近程拦截，其隐蔽收益将迅速转化为安全风险。 |
| 形记忆折展巡飞精打弹 | 采用形状记忆折展结构，使同一弹体在投放和巡航阶段保持紧凑、低阻构型，在目标区再改变翼面或有效展弦比，从而兼顾较长接近过程与临机转向。相对固定翼巡飞弹，它试图扩大目标区内的航迹变化空间，但折展机构寿命、展开后气动稳定、飞控重构和结构增重尚无公开定量依据。 | 由能够容纳折叠状态并完成释放的外部平台投放，具体平台和进入高度未明确。可面向沿岸舰艇、机动发射车及临时暴露目标，尤其适合目标位置不确定、原有航路容易被预判的区域，但不应据此推定其已具备任意平台兼容能力。 | 先以低阻构型完成远距离接近，再根据威胁方向改变翼面和盘旋范围，由既定航路转入临机攻击，迫使防御方扩大搜索和拦截扇面。直接效果是提高对机动或短时暴露目标的到达机会；若展开延迟、机构卡滞或目标区空间不足，航程与机动的兼得就会失效。 |
| 磁流体矢控巡飞精打弹 | 设想利用磁场驱动磁流体重新分配，产生侧向偏转和小半径转向，减少传统舵面和固定推力布局对航迹的约束。其潜在差异是连续改变接敌方向，而非依靠少数预设机动动作；但响应速度、供能代价、密封可靠性和高动态控制效果缺少公开试验证据，现阶段只能视为高风险探索路线。 | 计划从防区外缘进入岸防纵深，面向雷达、导引站和点状火力节点实施非固定方向接敌。该装备不能把概念上的磁流体控制直接等同于成熟突防能力，必须由弹体本身完成姿态控制、导航修正和末端识别，外部链路不能替代其快速闭环。 | 通过连续侧向偏转改变原可预测航迹，迫使防御方提前发射或扩大拦截覆盖，可能增加漏防和拦截资源消耗。若矢控响应不足、能量中断或识别更新跟不上机动变化，复杂转向反而会放大导航误差，导致失靶、误攻或提前中止；其直接效果须以公开可审计试验验证。 |
| 双体耦合巡飞精打弹 | 由前体承担引导、诱导或暴露防御反应，后体保留主攻任务，通过时序、间隔和偏置航向把一个发射单元转化为两轮交战压力。相较单体弹，它改变的是防御方目标关联和火力分配负担，而非单纯增加弹量。前后体释放状态、目标归属和通信受压条件下的基本动作必须保持一致。 | 以同一发射单元进入防区，接敌后前体先行，后体从偏置方向补入，主要作用于防空雷达、导引站及其邻近火力节点。外部体系只提供初始目标和攻击边界，双体之间的释放、跟随和末段权限应能在链路间歇条件下完成。 | 前体先牵引搜索和拦截资源，诱使防御方暴露处置意图，后体随后改变方向完成主攻，使一次拦截被拆成连续两次判断，直接降低集中拦截效率并提高关键节点受击机会。若对手具备快速目标关联和统一火控，或前后体交接失稳，双体结构带来的额外负荷可能被压缩。 |
| “玄礁”水下跃升巡飞弹 | 以跨介质航行把水下隐蔽接敌与空中末段精打连接起来，水下阶段规避岸基雷达和部分空中拦截链，接近目标后再转换为短时空中飞行和俯冲攻击。其不可替代性在于改变来袭介质和暴露时机，而不是简单延长巡飞时间；跨介质结构、出水姿态、近岸水文适应和出水后的快速识别是主要失效点。 | 从水下方向接近港湾、登陆点或靠岸舰艇，在目标附近跃升并进入空中末段。发射方式、潜行时间、适用水深和海况范围尚未给定，不能延伸为长期水下巡航或任意海域部署能力；出水后仍须由弹体完成导航收敛、敌我判别和攻击授权检查。 | 先利用水下航迹避开常规岸防搜索，再突然出水、完成目标识别并转入俯冲，迫使防御方不能只按空中航路提前布置。直接效果是增加港湾和近岸目标的防护盲区；若出水位置可预测、水下航行受海况限制，或末段识别时间不足，跨介质优势将难以转化为稳定战果。 |
