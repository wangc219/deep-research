三、总体方案

（二）子系统方案

本项目不采用一套通用弹体架构覆盖全部方向，而是按各装备改变交战关系的方式分别配置本体功能。共同边界是：外部侦察、战区指挥和任务规划负责提供初始任务及必要更新，弹药本体必须独立完成飞行安全、末端交战和失链处置；凡依赖持续联网才能成立的协同或识别效果，均不作为本体确定能力。

| 装备方向 | 产品形态与核心作用 | 控制闭环及必要输入输出 | 关键接口与工程验证 |
|---|---|---|---|
| 群栖自组巡飞精打弹 | 多枚低成本巡飞弹组成具备成员自治能力的弹群，面向舰艇、雷达和发射阵位实施连续搜索、分工和攻击 | 输入为初始任务区、目标类别和成员状态；弹群依据邻近通信和本地感知完成目标分配、攻击轮换及损毁判断，输出为成员航迹、交战状态和中止结果 | 接口重点是低带宽成员通信、发射平台任务装订和外部目标更新；须在通信间歇、导航受扰和部分成员失效时验证编组是否仍能完成可控攻击，不能以全连接演示替代降级试验 |
| 蜂簇接力巡猎精打弹 | 单一母弹体内置并分时释放多个小型攻击单元，适合对防空节点实施连续多回合施压 | 母体完成航路保持和释放管理，前导单元承担暴露、牵制或初始攻击，后续单元依据剩余目标和防御反应接续补位，输出为单元释放状态、目标分配和末段命中或中止信息 | 关键接口是母体与子单元之间的释放、识别和状态回传接口；验证应覆盖释放间隔误差、单元损失、目标变化及母体受损后的安全处置，重点确认模块数量增加没有使可靠性和成本失控 |
| 气膜掠波隐巡击弹 | 采用适应近海低空环境的贴海飞行弹体，直接逼近岸基雷达、火控和近程防空单元 | 飞控以海面高度、姿态和速度感知为主要输入，持续修正贴波航迹；末端由目标特征和航迹条件共同触发攻击或中止，输出为飞行状态、目标判别和战斗部动作 | 必须连接海面环境感知、末制导和战斗部安全控制；验证重点不是抽象隐身指标，而是不同海况、风浪和目标背景下的稳定飞行、探测窗口压缩及末端判别，相关机理目前缺少公开可审计数据，结论应保留为待测方向 |
| 形记忆折展巡飞精打弹 | 以可折展翼面或承力骨架在巡航与接敌阶段切换构型，兼顾远距离低阻飞行和临机小半径机动，攻击沿岸舰艇、发射车及点目标 | 航程阶段保持低阻构型，接敌阶段依据目标方位、威胁方向和剩余能量改变翼面或盘旋形态；输入为姿态、速度、目标位置和结构状态，输出为构型指令、机动轨迹与攻击状态 | 接口集中在折展机构、飞控计算机和末端导引之间；工程验证应先证明反复折展后的结构可靠性、气动模型一致性和故障锁定能力，再评价其是否确实改变拦截窗口，不能把概念机动直接等同于突防效果 |
| 磁流体矢控巡飞精打弹 | 以磁场驱动流体介质产生侧向控制力，面向岸防雷达、导引站和纵深点状火力，形成难以提前预测的末段航迹 | 导引系统根据目标方位和威胁方向计算侧向偏转，磁场控制单元调整流体分布，飞控再对姿态和能量进行闭环修正；输出为偏转状态、航迹变化和末端攻击指令 | 关键接口是磁场执行机构、流体状态监测、能源系统和飞控之间的实时耦合；验证必须证明控制力响应、重复性、能源消耗和高动态飞行下的稳定性，并在无可靠公开数据前，不把小半径折转或漏防效果写成确定指标 |
| “玄礁”水下跃升巡飞弹 | 采用水下潜行、出水转空和末段俯冲的一体化跨介质构型，针对港湾、登陆点及靠岸舰艇 | 水下段以航向、深度和姿态保持为主，出水前后完成介质转换、姿态重建和末端识别；必要输入包括发射位置、目标区域和环境状态，输出为跨介质状态、目标判别及攻击或中止指令 | 接口重点是水下导航、出水转换机构、空中飞控和末制导的时序衔接；验证应分阶段检查水下航迹保持、出水成功率、转换后传感器恢复和末段识别，不能仅凭单次出水试验推定完整作战闭环成立 |

上述方案中，群栖自组巡飞精打弹的制胜点是把目标分配和损毁评估下沉到弹群，蜂簇接力弹则把一次攻击转化为连续释放和接续攻击，二者不能互换。气膜掠波弹依靠接敌高度和海面背景改变探测几何，折展弹依靠构型切换扩大航迹选择，磁流体弹依靠执行机构直接改变末段控制规律，“玄礁”弹则通过跨介质转换避开单一防御程序。工程建设应优先锁定抗扰导航、失链保持和末端安全中止，再分别验证协同、释放、贴波、折展、矢控及跨介质转换；若某方向只能在持续通信、理想海况或完整目标指示条件下获得效果，应将其定位为外部体系增强能力，而不认定为弹药本体能力。
