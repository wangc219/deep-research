一、需求分析

（一）需求概述

1. 背景分析  
第一岛链拒止环境下，低成本巡飞精打弹药面对的不是单点防护，而是GNSS压制、链路干扰、伪装诱饵、分层防空和近程反无人机交织形成的任务链压力。敌方一旦把搜索、分配、拦截和补防做成稳定节奏，通用巡飞弹就会在接敌前后同时失去导航、识别和末制导窗口，表现为命中不稳、撤收不及、交换比迅速恶化。公开基线已经把分布式作战、韧性C2和无人系统绑定到受限环境火力运用，这说明项目需求不再是“能飞能打”，而是在受扰、失链和欺骗并存时仍能保持可验证的直接军事效果。

2. 需求阐述  
从Query看，真正缺口集中在弹药本体而非外部体系。它需要末端自治判别、抗干扰导航、边缘目标识别、失链保持、可控中止，以及面向低成本规模化的发射兼容和载荷约束；外部ISR、任务规划和指控只能提供进入战区的起点，不能替代末段交战闭环。换言之，需求不是把协同突防当作前提，而是要证明单枚或群体在通信间歇、数据不完备和目标欺骗条件下仍能独立完成发现、识别、接敌与终止判断。若一项能力只能在理想联网条件下成立，它就不构成这里的有效需求。

3. 项目画像  
本项目的价值，不在于把单一平台做得更复杂，而在于把低成本弹药分化成能分别承担群内分工、连续压制、隐蔽接敌、轨迹突变和跨介质逼近的装备族。群栖自组方向重在让多弹在弹内完成目标选择、攻击轮换和损毁评估，蜂簇接力方向重在用连续回合压力拆解对手恢复周期，气膜掠波方向重在压缩岸基雷达和防空单元的发现时间窗，形记忆折展、磁流体矢控和双体耦合方向则分别服务于航程机动一体化、轨迹不可预判和拦截负荷分拆。“玄礁”水下跃升则提供跨介质逼近的另一条路径。它们共同指向的制胜增量，是把对手的拦截组织从稳定节拍拖入高负荷、低确认、难补防的状态；一旦失去受扰条件下的本体自治和安全中止，这一增量就不成立。
