## 二、项目画像

### （二）作战运用模式

#### 1. 作战运用流程

在岛链拒止环境中，本项目进入作战运用的前提不是取得持续联网优势，而是在敌方具备卫星导航压制、链路干扰、分层防空、近程反无人机火力和目标伪装能力时，仍能把打击判断的一部分压入弹药本体。其共同任务矛盾是：外部侦察和指控可提供初始目标区、威胁区和禁打边界，但末端目标确认、航迹修正、攻击时序和中止控制不能完全依赖后方链路。进入条件应限定为已掌握目标活动区域或关键节点分布、允许低成本弹药承受一定消耗、且交战收益高于暴露平台风险；若目标信息仅停留在宽泛海域或岸区、敌我识别边界不清，巡飞精打弹药不应转入自主攻击。

群栖自组巡飞精打弹主要用于打破敌防空反舰体系的固定工作节奏。其进入条件是敌方雷达、舰艇、防空阵位和发射单元需要按“发现、分配、拦截、再装填或转移”的周期运行，而我方需要用多枚低成本弹体制造持续压力。作战动作不是单枚弹药寻找一次命中机会，而是由弹群在目标区附近保持分散搜索，发现高价值节点后在弹群内部完成目标接替、攻击排序和毁伤确认。当前导弹体被拦截或丢失链路时，后续弹体继续接管目标窗口，使敌方无法通过拦下一两枚弹药恢复防御节奏。直接战果是压低对手连续拦截效率，对舰艇、岸基雷达、发射阵位形成反复打击或迫使其关机、转移和中断射击准备。相对单发巡飞弹，其制胜点在于把“命中一个目标”的问题改写为“让防御系统连续处理超出节奏的目标流”；但若弹群自治规则在通信受限下不能稳定去重、分配目标和识别毁伤，该模式会退化为无序消耗。

蜂簇接力巡猎精打弹适合攻击防御纵深较浅、但近程拦截密集的岸岛节点。它以一个母载体接近目标区，随后接续释放多个小型攻击单元，由弹体内部完成搜索、分发和末段打击。前导单元承担诱发开机、暴露火控、消耗近程拦截弹药的任务；后续单元利用已暴露的火力点、雷达波束变化或目标转移痕迹实施补位攻击。它改变交战关系的关键，不是单个小单元杀伤力更强，而是把一次来袭拆成多轮连续压力，使防御方难以在一个拦截周期后重新隐蔽、换防或集中火力。直接战果是对防空节点、雷达辅助设施、火控设备和临时暴露目标形成连续命中机会。该装备不宜用于目标稀疏且远距离大范围搜索的任务，因为小型攻击单元的续航、传感和战斗部余量受母体释放逻辑约束。

气膜掠波隐巡击弹的作战入口是近海岸线、港湾外缘和岛礁周边存在雷达低空盲区或海杂波背景时。它通过弹体本体维持贴近海面的掠波飞行，把来袭方向压入海面背景，缩短敌方从发现到稳定跟踪再到拦截的时间。其决定性动作是沿海面低高度逼近岸基雷达、火控单元和防空发射阵位，在末段再完成目标识别与俯冲攻击。对手状态变化表现为早期预警窗口被压缩，防空系统必须在目标航迹不稳定、海面回波复杂、拦截时间不足的条件下作出反应。直接战果是提高关键节点漏防概率，并在首轮压制中削弱敌方低空探测和火控能力。该模式的失效边界集中在海况、近海障碍、低空传感稳定性和末段抗干扰识别，不能把贴波接敌简单等同于隐身突防。

形记忆折展巡飞精打弹面对的主要矛盾是远距离巡航要求低阻稳定，临近目标后又需要小半径盘旋、急转搜索和快速再瞄准。它依靠形状记忆折展骨架在不同飞行阶段切换翼面状态，巡航段保持较高效率，接敌段扩大机动空间并改变盘旋半径。其适用对象是沿岸舰艇、机动发射车和临机出现的点目标，尤其适合目标会短暂停留、转移窗口窄、外部链路可能中断的环境。对手即使掌握大致来袭航路，也难以用固定拦截扇面覆盖弹体变形后形成的新攻击角。直接战果是增加对临机目标的再捕获和末段修正机会，把原本依赖外部实时引导的打击，部分转化为弹体自身气动构型与末端控制的组合优势。若折展机构可靠性、控制稳定性或低空机动识别不足，则其航程和机动兼得的假设不成立。

磁流体矢控巡飞精打弹用于攻击岸防雷达、导引站和纵深点状火力时，核心是让敌方难以用既有弹道预测模型提前布设拦截。它通过磁场作用下的磁流体快速重分配，形成侧向偏转和小半径折转能力，使接敌航迹持续变化。决定性动作发生在敌方已经建立跟踪但尚未完成稳定火控解算的阶段，弹体通过连续偏转迫使防御方提前发射、重复修正或放弃最佳拦截窗口。直接战果是增加漏防概率，并使高价值防空节点为保护自身消耗更多拦截资源。与折展弹相比，它不是通过翼面变形扩大搜索和盘旋，而是通过矢量控制打乱拦截计算；其成立边界取决于磁流体控制响应、能源代价和高动态条件下的制导闭合能力。

双体耦合巡飞精打弹适合在敌方集中拦截效率较高、但目标节点位置相对明确时使用。它以前体引导开机、吸引搜索和分配资源，后体从偏置航向进入末攻，把防御方对一个来袭目标的处置拆成两次判断。前体不只是诱饵，还承担逼迫雷达开机、暴露火控逻辑和扰乱拦截分配的作用；后体利用前体制造的注意力偏移和拦截空当，对防空节点实施精确打击。直接战果是降低敌方集中火力对单一来袭方向的效率，使同一发射消耗产生“诱发暴露加末段毁伤”的复合效果。该模式的风险在于前后体分离时序、目标继承和偏置航向控制必须可靠，否则会从双轮压迫退化为简单分体消耗。

“玄礁”水下跃升巡飞弹进入作战的前提是目标位于港湾、登陆点、靠岸舰艇或近岸设施，且空中来袭路径容易被岸防和防空体系提前封堵。它先以水下潜行规避雷达视线和空中拦截链，接近目标区后跃出水面，立即转入末段识别、姿态转换和俯冲攻击。对手状态变化是防御体系难以用同一套岸防流程同时覆盖水下接近、出水瞬间识别和空中末攻，预警与拦截程序被迫跨域切换。直接战果是对靠岸舰艇、港湾关键设施和登陆支撑点形成突然打击，压缩其机动或卸载窗口。其失效边界不是传统巡飞弹的航迹问题，而是跨介质转换可靠性、出水后快速识别和海况适应能力。

#### 2. 链路闭环分析

本项目的制胜链条应按“外部给边界、弹体做判断、局部成闭环、结果可回传”组织。外部体系只负责提供目标区、禁打规则、初始威胁态势和发射窗口，不能被设定为持续控制每一枚弹药。弹药本体必须完成受扰导航下的航迹维持、目标再识别、攻击排序、末段控制和必要中止；否则一旦卫星导航受压制、通信间歇或目标伪装出现，所谓智能巡飞精打就会变成依赖理想网络的普通遥控弹药。

不同装备的闭环重点不同。群栖自组巡飞精打弹的闭环在弹群内部，关键判据是局部节点失效后能否继续完成目标分配和毁伤确认；蜂簇接力巡猎精打弹的闭环在母体释放节奏与子单元补位攻击之间，关键判据是前导消耗是否能转化为后续命中机会；气膜掠波隐巡击弹的闭环在贴波飞行、海面背景识别和末段俯冲之间，关键判据是低空突防是否真正压缩了敌方火控窗口；形记忆折展巡飞精打弹的闭环在构型切换、临机搜索和末段再瞄准之间，关键判据是变形带来的机动收益是否超过机构复杂性；磁流体矢控巡飞精打弹的闭环在高动态偏转和制导解算之间，关键判据是航迹不可预测性是否仍能保持命中稳定；双体耦合巡飞精打弹的闭环在前体诱发和后体主攻之间，关键判据是两体分工是否真实造成拦截资源错配；“玄礁”水下跃升巡飞弹的闭环在水下接近、跨介质转换和出水末攻之间，关键判据是突然性是否能抵消转换过程带来的风险。

对手的反适应主要包括扩大低空和海面探测覆盖、提高反无人机火力密度、使用假目标和诱骗信号、缩短雷达开机时间、分散防空节点并引入自动化拦截分配。针对这些变化，本项目不能把单一突防手段视为长期优势，而应按任务分层组合使用：群栖和蜂簇负责制造持续处理负荷，掠波和水下跃升负责改变来袭方向与发现时机，折展和磁流体矢控负责末段机动与临机目标捕获，双体耦合负责诱发暴露并打击防空节点。若公开证据不能证明降级通信、受扰导航和伪装目标条件下的闭环效果，则相关能力只能作为待验证方向，不能转化为确定作战收益。
