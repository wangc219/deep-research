## 一、需求分析

### （三）建设必要性分析

#### 1. 作战使用角度

第一岛链拒止环境下，防御方依托分层防空、反舰火力和反无人系统，形成搜索、识别、分配、拦截相互衔接的防御链条。单枚巡飞弹药一旦遭遇导航受扰、通信中断或目标伪装，容易在末端失去稳定航行和可靠判别能力。因此，建设群栖自组巡飞精打弹，重点不在简单增加弹体数量，而在于把部分目标选择、攻击轮换和毁伤判断前移到弹体群内，使其在外部指示不连续时仍能利用局部信息调整攻击对象和次序，对舰艇、雷达和发射阵位保持连续压力。其直接效果是打乱防御方按固定节奏搜索和集中拦截的方式；若协同必须依赖持续联网，则只能按普通多弹攻击评价，不能认定为自治群栖能力。

蜂簇接力巡猎精打弹解决的不是多枚弹药同时抵达，而是一次攻击如何持续制造威胁。单个载体连续释放多个攻击单元，前导单元可承担搜索、诱导或消耗拦截资源，后续单元再根据暴露出的防御缺口补入末端打击，将一次突防转化为连续回合。即使首轮拦截有效，也未必能阻断后续单元对关键节点的补攻，从而压缩防御方换防、补充和重新分配火力的时间。该方案必须以释放顺序、单元接替和末段识别在链路受损时仍能维持基本闭环为前提，否则复杂结构会增加故障点和保障负担。

气膜掠波隐巡击弹针对海面方向低空接敌的探测和拦截盲区。弹体通过贴近海面飞行，利用海面背景压缩雷达发现、稳定跟踪到武器拦截之间的时间，使岸基雷达、火控和近程防空单元难以按常规高度层组织防御。它相对于一般低空巡飞弹的独特价值，在于依靠接敌几何而非单纯数量制造漏防机会，直接服务于岸防节点和海上通道突防。但海况、风浪、盐雾、导航误差以及末段抬升动作都会改变实际效果，理想海面条件下形成的隐蔽性不能直接外推到复杂近岸环境。

形记忆折展巡飞精打弹面对的是航程、搜索时间与临机机动难以兼顾的矛盾。巡航阶段保持有利气动外形以降低阻力、延长滞空和搜索时间，接敌或发现临机目标后再改变翼面和盘旋特性，使沿岸舰艇、机动发射车及临时部署目标不再只面对一条固定航路。它改变了防御方依据预设航迹布置拦截窗口的方式，适合攻击位置变化快、情报时效短的目标。其作战收益取决于折展机构可靠性、动作时机和变形后的飞控稳定性；这些条件不能满足时，结构复杂度会抵消低成本弹药的优势。

磁流体矢控巡飞精打弹所改变的是末段航迹的可预测性。若磁场驱动流体重分配能够提供快速侧向偏转和小半径折转，弹体便可在接敌过程中持续修正来向，重点攻击岸防雷达、导引站和纵深点状火力，迫使防御方提前开火并承担更高的拦截不确定性。其制胜机理是缩短防御方对末段落点的有效预判时间，而不是替代目标识别或外部侦察。由于现有输入缺少公开试验参数，建设判断只能围绕偏转响应、能量代价、控制稳定性和命中保持能力展开，不能预先承诺突破传统飞控性能。

双体耦合巡飞精打弹以同一消耗单元形成两次威胁为主要特征。前体先承担引导、暴露或干扰任务，后体从偏置方向进入主攻段，迫使防御方重新完成目标确认、火力分配和拦截决策。相较单体弹药，它增加的是防御决策轮次和方向负荷，因而更适合用于防空节点突防，而非泛化为所有目标的通用方案。前后体分离、状态交接或偏置航向控制任一环节失效，都可能使两轮压力退化为两枚能够分别处理的目标。

“玄礁”水下跃升巡飞弹面向空中来袭路径容易被岸防体系提前覆盖的问题。弹体先以水下航迹接近目标，再跨介质跃升进入末段识别和俯冲攻击，可将水下隐蔽接近与空中突防结合起来，针对港湾、登陆点和靠岸舰艇制造不同于空中巡飞弹的来向。其直接战果取决于出水位置、跃升后剩余反应时间和末段识别可靠性。若水下航行、跨介质转换或出水后制导不能稳定衔接，就难以形成对传统岸防程序的真正穿透，因此更适合作为特殊方向验证，不宜在缺少跨介质试验数据时承担近期规模化任务。

#### 2. 装备能力提升角度

上述装备不能用统一的航程、速度或载荷指标概括。群栖自组巡飞精打弹应优先验证失链保持、局部重规划和目标判别边界；蜂簇接力巡猎精打弹应重点考核连续释放、单元接替和整体可靠性；气膜掠波隐巡击弹则须围绕贴波飞控、海况适应和末段抬升建立试验条件。三者分别对应自治决策、任务重构和接敌几何三种能力缺口。

形记忆折展巡飞精打弹的核心不是材料名称，而是折展动作能否实质改善航程、搜索半径和末端机动；磁流体矢控巡飞精打弹必须证明偏转响应足以改变拦截窗口，且不会因能量消耗削弱命中能力。双体耦合弹应把结构分离、状态交接和双方向末攻作为独立考核对象；“玄礁”则需建立水下航行、出水转换和末端识别连续可追踪的验证链。外部情报侦察、指挥控制和战区重规划只能提供任务输入，不能替代弹体本身的导航、飞控、识别、战斗部承载和安全中止能力。

#### 3. 领域占位角度

项目的领域价值在于推动低成本巡飞弹药从依赖联网使用的无人平台，转向能够在受扰条件下维持有限作战闭环的战斗装备，并形成群体协同、连续接力、海面贴波、变形机动、矢量突防、双体分工和跨介质接敌等差异化方向。建设顺序应先保障抗扰自治和失链保持，再依据试验结果选择群栖、蜂簇等能够较快形成效能的路线；磁流体矢控和水下跃升等不确定方向，则应以关键机理验证为先，避免把概念潜力直接转化为列装承诺。

#### 4. 综合效益

建设必要性最终体现为：在不假定持续联网、理想识别和稳定外部指示的条件下，提升弹药从防区外接敌到末端突防的有效交战概率，保持受扰时的可控中止能力，并通过不同接敌路径、攻击节奏和目标分工提高低成本交换效率。对防御方而言，群栖协同增加了目标选择和攻击轮换压力，蜂簇接力延长了连续拦截周期，贴波、变形、矢控、双体及跨介质方案则分别改变探测几何、航迹预测、决策轮次和防御方向。综合取舍上，应以公开试验或可审计数据验证降级运行、直接命中、释放衔接和失效模式；凡效果只能在理想通信、海况、目标暴露或完整链路条件下成立的，不作为确定性建设依据。
