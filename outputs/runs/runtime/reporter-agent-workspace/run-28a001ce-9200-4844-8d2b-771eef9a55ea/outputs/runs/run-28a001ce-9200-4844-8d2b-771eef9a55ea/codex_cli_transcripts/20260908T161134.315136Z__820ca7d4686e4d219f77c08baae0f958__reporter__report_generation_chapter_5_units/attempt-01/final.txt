## 五、研制基础
### （一）参与单位

公开材料不足以锁定具体承研方时，这一栏只能按产品责任、关键接口、试验责任和证据交付反推参与单位类型，而不能把通用“总装加配套”直接当结论。对本项目而言，基础单元应当不是单一总装厂，而是围绕弹体总成、末端识别与降级导航、飞控与能源、战斗部与引信、环境试验与对抗验证分成若干责任主体；其中，外部侦察、任务规划和链路保障只能提供输入，不能替代弹体本体完成末端判别、失链保持和安全中止。

| 方向 | 应承担的参与单位类型 | 公开证据缺口 |
|---|---|---|
| 群栖自组巡飞精打弹 | 弹体总成单位、群内协同与抗干扰接口单位、自治判别算法单位、弹群对抗试验单位 | 缺少失链后接替目标、群内轮换和损毁评估的可审计试验 |
| 蜂簇接力巡猎精打弹 | 载体弹舱与分离机构单位、小型攻击单元单位、接续释放控制单位、分段毁伤评估单位 | 缺少多次释放可靠性、前导消耗与后续补位的公开验证 |
| 气膜掠波隐巡击弹 | 低空气动与耐海况结构单位、海面背景识别与末端导航单位、近海靶场试验单位 | 缺少海况窗口、贴波稳定性和海杂波识别精度数据 |
| 形记忆折展巡飞精打弹 | 形状记忆结构件单位、折展锁定机构单位、低阻巡航控制单位、折展寿命试验单位 | 缺少重复展开精度、锁定一致性和折展后气动偏差证据 |
| 磁流体矢控巡飞精打弹 | 矢控执行机构单位、电磁兼容单位、热管理与功耗控制单位、机动响应试验单位 | 缺少响应时间、能耗、磁场耦合稳定性和受扰条件验证 |
| 双体耦合巡飞精打弹 | 前后体耦合结构单位、分离与接力控制单位、末段协同算法单位、双体对抗仿真单位 | 缺少失联接力、误分离和两轮决策负荷成立性的证据 |
| “玄礁”水下跃升巡飞弹 | 水下航行体单位、出水机构单位、跨介质姿态恢复单位、海试验证单位 | 缺少水下隐蔽航行、出水后稳定识别与盐雾冲击验证材料 |

按责任链看，真正关键的不是“谁参加过”，而是哪一类单位必须对抗干扰、跨介质转换、末端识别和失效中止负责。凡公开证据没有覆盖试验场景、判据和接口边界的，只能停留在机构类型判断，不能倒推出具体单位归属。
