## 二、项目画像

### （二）作战运用模式

#### 1. 作战运用流程

岛链拒止环境下，智能巡飞精打弹药的进入条件不是单纯“发现目标后发射”，而是敌方已形成全球卫星导航压制、链路干扰、分层防空和近程反无人机火力叠加，我方常规精确弹药在末段容易丢失定位、被迫依赖外部指示或被防御方按固定节奏拦截。此时弹药必须把一部分发现、识别、航迹保持和中止判断前移到本体内，外部体系只提供任务意图、目标区大致约束和必要更新，不能假定全程稳定联网。作战运用的核心不是追求单发弹药性能最大化，而是在受扰、受骗、受拦截的窗口内，把敌方“探测、分类、分配火力、拦截、恢复”的链条打乱，使低成本弹药仍能形成可验证的直接军事效果。

群栖自组巡飞精打弹适合进入敌方岸基雷达、舰艇编队、火力阵位相互支援但反应周期相对固定的态势。其决定性动作是多弹在目标区内自主保持任务关系：部分弹药维持搜索和确认，部分弹药转入压制或攻击，已失效、失链或命中后的空位由邻近弹药接替。它改变交战关系的关键在于，防御方不再面对一批按预定航路依次来袭的目标，而是面对会在局部范围内重新分配目标、轮换攻击顺序并根据毁伤迹象调整后续指向的弹体群。直接战果是防空节点、舰艇传感器或发射阵位在短时间内承受连续压力，防御方即使拦截部分来袭弹，也难以立即恢复原有搜索和火力分配节奏。该模式相对普通巡飞弹的不可替代性在于“群内接替”，但成立边界也很清楚：若局部协同规则在强干扰下退化为各弹独立乱飞，或损毁评估只能依赖后方链路回传，其制胜效果就会大幅下降。

蜂簇接力巡猎精打弹面向的是防御方拦截资源充足、但对一次来袭通常按单轮处置流程运行的场景。它的进入条件是目标区存在防空火力、诱饵识别和短时恢复能力，单枚弹药突入容易被集中拦截。其决定性动作不是横向铺开，而是由一个载体接续释放多个小型攻击单元，让前导单元先搜索、诱发防空开机或消耗近程拦截，后续单元再依据暴露出的火力点、目标状态或防御空隙补位攻击。对手状态变化表现为防御方必须把一次拦截决策拆成多次判断：前导单元是否为主攻、后续单元从何处补入、哪些火力还要保留。直接战果是把本来可集中处置的一次攻击拉长为连续多回合压力，压缩其换防、装填、重新搜索和目标确认时间。该装备优于普通子母式投放的地方在于小型单元承担巡猎和末段判断，而不是被动散布；但若各单元之间无法形成最低限度的目标分发，蜂簇压力会退化为数量消耗，成本交换优势随之失效。

气膜掠波隐巡击弹适合用于近海、岸岛交错、海面杂波可遮蔽低空目标的接敌环境，主要矛盾是常规空中航迹过早进入岸基雷达和火控系统稳定跟踪区。其决定性动作是弹体依靠贴近海面的稳定飞行能力，把接敌几何压低到海面背景中，在末段前尽量减少被连续跟踪的时间。对手状态变化不是简单“看不见”，而是探测到目标的时间变晚、航迹质量变差、拦截窗口被压缩，防空系统难以从早期预警平稳过渡到稳定照射和射击解算。直接战果指向岸基雷达、火控单元和低空防空节点的突然性毁伤，尤其适合打开后续火力进入窗口。它相对群栖自组弹的差异在于，制胜点来自接敌几何和海面遮蔽，而不是多弹决策；若海况、近岸障碍、目标区高度差或低空探测补盲能力使贴波航迹无法保持隐蔽，其运用价值会明显下降。

形记忆折展巡飞精打弹的进入条件是目标机动性较强、目标区信息不完整，且弹药既需要较低阻力完成较长时间巡飞，又要在接敌阶段突然改变盘旋半径、速度包线或末段进入角。其决定性动作是通过折展构型在巡航和攻击之间切换，使弹体在前段保持适合航程与滞空的形态，进入末段后改变机动特性以压缩对手预测空间。对手即使掌握大致来袭方向，也难以用固定火力扇面覆盖弹体临机变形后的拦截窗口。直接战果是对沿岸舰艇、发射车和临机点目标形成更灵活的末段进入方式，弥补普通固定翼巡飞弹在航程与急转机动之间的取舍。该模式的成立重点不在“变形”概念本身，而在变形后的可控飞行和识别稳定性；若构型切换导致姿态扰动、载荷视场丢失或命中判别不稳，作战收益会被可靠性风险抵消。

磁流体矢控巡飞精打弹适合进入防御方已能根据常规弹药航迹提前建立拦截解算的态势，作用对象偏向岸防雷达、导引站和纵深点状火力。其决定性动作是利用磁流体重分配带来的快速偏转能力，在末段制造连续变化的接敌轨迹，使拦截系统难以把早期航迹外推为稳定命中点。对手状态变化表现为提前发射概率上升、火控修正次数增加、近程拦截弹药消耗加快，同时对真正末攻方向的判断更迟。直接战果是提高点状节点的漏防率，并迫使防御体系以更高代价维持同等防护。它不同于气膜掠波弹的低可探测接敌，也不同于折展弹的构型切换，而是用末段矢量控制扰动防御解算；若磁流体控制无法在弹体尺度、能耗和热管理约束下稳定工作，或机动超出自身识别与引信窗口，其制胜机理不成立。

双体耦合巡飞精打弹用于对付拦截流程高度程序化、但对真假主攻和来袭方向切换敏感的防空节点。其决定性动作是以前体诱导、引导或吸引防御开机，后体保持主攻能力并从偏置方向补入末攻，把一个消耗单元内部分成两轮交战事件。对手状态变化是搜索资源和火力分配先被前体牵引，随后又必须对后体重新识别、重建航迹和再分配拦截火力。直接战果是降低集中拦截效率，并使防空节点在暴露、误配或火力空档中遭受精确毁伤。它相对蜂簇接力弹的差异在于，不依靠多个小型单元连续释放，而是在同一弹体组合内制造前后两段压力；若前后体分离后的信息关系、时序关系或末段识别关系不能闭合，双体设计会退化为复杂而昂贵的诱饵组合。

“玄礁”水下跃升巡飞弹适合岸岛港湾、登陆点、靠岸舰艇等空中防御严密但水下接近路径相对难以被同一套防空程序覆盖的场景。其决定性动作是先以水下潜行绕开雷达视线和常规空中拦截链，接近目标区后跃升出水，随即转入短时空中末段识别和俯冲攻击。对手状态变化是岸防和防空系统无法从远距空情预警开始连续跟踪，必须在出水后的短窗口内完成发现、分类、火力指派和拦截。直接战果是对港湾设施、登陆点集结目标或靠岸舰艇形成突发打击，迫使防御方同时加强水下警戒和近岸低空拦截。该装备的不可替代性来自跨介质路径切换，而不是单纯低空突防；若水下导航误差、出水姿态转换或末段目标识别不能满足闭环要求，其作战模式会在出水瞬间暴露并失去突然性。

#### 2. 链路闭环分析

本项目的制胜链条应按“外部体系给定任务边界、弹体自主保持进入条件、末端本体完成判别与打击、有限回传支撑后续决策”理解。外部侦察和指控可以提供目标区、禁打边界、优先级和时敏更新，但在全球卫星导航受扰、链路间歇和欺骗目标并存时，不能把持续目标指示当作弹药本体必然可用条件。真正决定直接战果的是弹体在失链后能否维持可解释的航迹、在目标候选混杂时能否完成最低可信识别、在命中条件不足时能否中止或转入备用规则。退出或中止条件只需围绕目标可信度不足、误击风险不可控、协同关系崩解和安全边界被突破设置，不应把撤收流程写成主要能力。

不同装备的闭环侧重点不同。群栖自组巡飞精打弹的闭环重心在群内任务接替，验证时应关注通信降级后目标分配是否仍能避免重复攻击和空档；蜂簇接力巡猎精打弹的闭环重心在载体释放、前导诱发、后续补位之间的时序，若前导单元不能产生可利用的防御暴露，后续攻击就缺少依据；气膜掠波隐巡击弹的闭环重心在贴波航迹、海面遮蔽和末段捕获之间的连续性，任何一环被近岸补盲雷达稳定捕获都会削弱突防收益；形记忆折展巡飞精打弹的闭环重心在构型切换后的飞控稳定、传感器视场和末段判别一致性；磁流体矢控巡飞精打弹的闭环重心在机动扰动与目标锁定之间的平衡，不能让规避动作破坏命中条件；双体耦合巡飞精打弹的闭环重心在前后体分工和时序欺骗，前体消耗防御资源必须服务于后体主攻；“玄礁”水下跃升巡飞弹的闭环重心在水下接近、出水转换和短窗口识别，跨介质转换失败会直接切断制胜链条。

因此，作战运用上应把抗扰自治和失链保持置于首要位置，把协同突防视为有条件增益而非天然能力。对手的反适应方向主要包括增强低空和近岸补盲探测、用电子压制破坏群内协同、以诱饵目标污染末端识别、把近程拦截火力下沉到关键节点周边，以及通过多源传感器缩短重新捕获时间。项目判断只有在降级通信、导航受扰、目标伪装和局部节点失效条件下仍能证明直接毁伤、可控中止或成本交换优势时才成立；公开证据不足的航程、命中率、协同规模和突防概率不能写成确定指标，只能作为后续试验要验证的变量。
