## 一、需求分析
### （二）国内外现状
#### 1. 国外情况
国外公开基线已经把第一岛链式受限环境当成分布式作战问题来处理。美国海军陆战队 Force Design 公开把第一岛链、韧性指挥控制、无人系统和精确火力放在同一套语义里，说明其关心的不只是“有无弹药”，而是弹药在电磁受扰、分布式部署和快速换防条件下能否继续形成可验证打击。DARPA 的 CODE 计划进一步把协同自治推进到通信离线、全球定位不可用的场景，核心价值不在联网炫技，而在失链后仍能维持搜索、分工、接敌和任务完成。与此同时，美军反无人系统策略强调探测、跟踪、识别以及主动和被动防护的组合，并把成本失衡管理列为关键问题，说明低成本巡飞精打弹药的竞争焦点已从“是否能飞”转向“能否在防御方先发现、先拦截、先干扰之前完成末端决策并保留交换比”。国防部体系建设报告又指出，联合全域指挥控制仍缺少足够完整的投资和进展框架，这意味着外军公开能力虽更重体系联接，但真正可落地的仍是分层自治、降级运行和末端独立判别，而不是单纯依赖持续数据链。

#### 2. 国内现状（中国）
中国公开材料呈现的不是单一成熟型号，而是一组围绕岛链拒止环境分化出来的机理路线。群栖自组和蜂簇接力更强调把目标选择、攻击轮换和损毁评估前移到弹体群内，用数量与协同压缩防御方的分配窗口；气膜掠波、形记忆折展和磁流体矢控则分别从超低空贴波、巡航接敌构型切换和航迹不可预判三个方向，去改写雷达发现、跟踪和拦截节奏；双体耦合试图把一次拦截拆成前后两轮决策负荷；“玄礁”水下跃升则把接敌起点移到水下，先绕开空中拦截链，再在末段转入俯冲命中。它们的共同点，是都把作战收益压在弹药本体的末端识别、降级导航、局部自治和接敌几何改写上，而不是把关键效果完全寄托给外部指挥链。差别也很清楚：公开证据更强的是机理分化和局部验证，较弱的是在伪装目标、链路间歇、频谱压制和低成本约束下，是否还能把“发现-识别-命中-可中止”连成完整闭环。换言之，国内路线已经把问题拆开，但是否能在同一弹体内同时守住可靠性、成本和抗扰性，仍是决定能否从概念收敛为装备本体的关键变量。

#### 3. 对比小结
对比看，国外更突出体系化运用、失链自治和反制环境下的可验证运行，国内更突出构型创新、路径分化和围绕接敌几何的多机理探索。两者真正重合的部分，是都不再接受“持续联网才有效”的旧前提；两者真正拉开差距的部分，是国外公开材料更早把降级运行、成本交换和联合框架放进验证语境，国内公开材料则更丰富地提出了群体协同、贴波突防、跨介质和变形机动等弹体级解法。对本项目而言，这说明低成本智能巡飞精打弹药的关键不是再堆一种概念，而是要明确哪些能力必须由弹药本体承担，哪些只能由外部侦察、指控和规划提供。
