二、项目画像

（四）主要战技指标

主要战技指标不宜先列统一的航程、速度和命中精度，而应从每型弹药真正改变交战关系的动作倒推。岛链拒止环境下，防御方会同时使用卫星导航压制、链路干扰、分层拦截、近程反无人机火力和伪装目标；因此指标必须证明弹药在外部体系不完整时仍能产生直接战果，并能说明在何种反适应下失效。

群栖自组巡飞精打弹的核心指标应落在“群内接替”而非单弹性能上。它面对的是防空与反舰火力按固定周期完成搜索、目标分配和拦截的体系，制胜动作是多弹在局部通信受损、部分弹体损失后仍能自行改派目标、轮换攻击顺序并接续毁伤判别。判别性指标包括受扰条件下的群内任务重分配成功性、被拦截后剩余弹药对舰艇、雷达或发射阵位的续攻保持性、对假目标和已毁伤目标的再分配抑制能力。验证不应只看全连接编队演示，应设置通信间歇、卫星导航不可用、目标诱饵混入和弹体随机损耗；若群体一旦失去中心链路就退化为互不协调的单弹齐射，其体系压制价值即不成立。

蜂簇接力巡猎精打弹的指标应围绕“同一载体内连续释放小型攻击单元”建立。它不是依靠大规模外部蜂群同时压上，而是把一次来袭拆成前导搜索诱发、后续补位打击和末段确认的多回合压力，迫使防御方提前暴露火控节奏。关键指标应包括载体释放后的攻击单元间隔可控性、前导单元诱发拦截或暴露防空节点后的后续接续锁定能力、载体内部搜索分发闭环在失链状态下的任务保持能力。验证应采用分批释放、前导单元被击落和防空阵位短时转移的场景；若后续单元只能按预置坐标机械冲击，不能利用前导造成的暴露窗口，蜂簇设计就只是弹药数量堆叠。

气膜掠波隐巡击弹的指标应证明它确能把接敌几何压入海面背景。其作战对象是岸基雷达、火控单元和近岸防空节点，关键动作是贴近海面稳定巡猎并在末端保持识别、拉起或俯冲控制。判别性指标包括复杂海况下的贴海飞行保持性、海杂波背景中的目标跟踪连续性、末段从低空隐蔽接敌转入精确毁伤的控制稳定性。验证应覆盖浪高变化、海面反射干扰、岸线杂波和近程拦截火力；若一遇海况变化就必须抬高航迹，其压缩探测距离和拦截窗口的机理会被削弱。

形记忆折展巡飞精打弹的指标要围绕“航程形态”和“接敌形态”的可靠切换。它的直接价值在于巡航阶段保持低阻飞行，接近沿岸舰艇、发射车或临机点目标后通过翼面折展改变盘旋半径和机动窗口，使防御方难以按已知航路提前布防。关键指标包括折展机构在多次热循环和载荷扰动下的动作可靠性、形态切换后的飞控收敛能力、临机目标出现时的盘旋保持与再攻击窗口。验证应把温度变化、结构疲劳、目标短时暴露和末段机动同时纳入；若折展只能在理想环境下完成，或切换后需要长时间重新稳定，该型弹药无法兑现“巡航省能、末段灵活”的取舍优势。

磁流体矢控巡飞精打弹的指标应集中在侧向偏转的响应质量。它面对的是可预测航迹容易被岸防雷达、导引站和纵深点状火力提前解算的问题，制胜动作是通过磁场控制流体分布形成连续变轨，使拦截方被迫提前发射并增加漏防。判别性指标包括连续变轨时的姿态稳定性、矢控响应与制导修正的同步性、长时间机动后的能耗和热管理可承受性。验证应使用拦截预测模型、连续规避航段和末段精确锁定串联测试；若偏转响应滞后于火控解算，或机动后无法回到有效攻击姿态，变轨能力会反而消耗命中条件。

双体耦合巡飞精打弹的指标应验证前体和后体能否真正制造两轮决策负荷。它的作战动作是前体先开机、诱导搜索分配和消耗拦截资源，后体从偏置航向补入主攻，对防空节点形成精确毁伤。关键指标包括前后体分离后的姿态扰动可控性、前体诱发对手火控响应的可观测性、后体利用偏置航向重新捕获目标的成功性。验证应设置防御方识别诱饵、前体提前损失和目标短时机动条件；若防御系统能快速区分前体与主攻体，或后体受分离误差影响丢失末段锁定，该型弹药就不能有效压低集中拦截效率。

“玄礁”水下跃升巡飞弹的指标必须落在跨介质转换，而不是普通巡飞末制导。它先以水下潜行避开雷达视线和空中拦截链，出水后立即完成姿态建立、目标识别和末段俯冲，主要作用于港湾、登陆点或靠岸舰艇。判别性指标包括水下航行到跃升出水的定位误差控制、出水瞬间动力和飞控接续可靠性、海水冲击后传感器快速恢复识别的能力。验证应覆盖近岸浅水、浪涌、盐雾、电磁压制和靠岸目标遮挡；若出水后需要外部持续指示才能找到目标，或跨介质转换造成过大位置漂移，它绕开岸防与防空程序的独特价值就会失效。
