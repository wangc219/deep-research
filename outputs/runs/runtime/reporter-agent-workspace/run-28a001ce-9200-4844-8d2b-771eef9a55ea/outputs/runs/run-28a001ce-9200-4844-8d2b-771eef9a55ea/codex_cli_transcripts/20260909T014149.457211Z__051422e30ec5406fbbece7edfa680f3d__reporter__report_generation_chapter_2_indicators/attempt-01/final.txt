## 二、项目画像

### （四）主要战技指标

**群栖自组巡飞精打弹。** 首要指标不是编队规模，而是通信间歇、导航受扰和局部节点损失后，弹群仍能完成目标重分配、攻击轮换和损伤结果回传的任务连续性；它直接决定能否把防御方的固定搜索—分配—拦截节奏拖入失配。其次考察弹群由局部观测形成目标优先级的稳定性，避免多弹重复攻击同一目标或因误判转攻非目标。验证应采用失链、卫星导航不可用、部分成员被剔除和目标伪装同时存在的闭环试验；若必须依靠持续外部指挥或完整通信网络才能维持协同，则该指标不成立。

**蜂簇接力巡猎精打弹。** 判别重点是载体释放攻击单元后，前导单元被拦截、诱导或失效时，后续单元能否按既定次序补位并保持末端攻击闭环，作战效果是把一次突防转化为连续多轮压力，压缩防御系统恢复和重新分配时间。应同时考察释放间隔的一致性、剩余单元的任务接管率以及载体受损后可用单元比例，因为其中任何一项失控都会使“接力”退化为一次性齐射。验证需在模拟拦截和通信受限条件下进行多轮释放试验；若前导单元未暴露或未被消耗时系统才表现良好，不能证明其具有实际的持续压迫能力。

**气膜掠波隐巡击弹。** 核心指标应是复杂海况下贴近海面的稳定飞行能力及其对末端探测窗口的压缩效果，直接关系到能否绕开岸基雷达、火控和近程防空的常规发现节奏。不能只测理想平静海面上的飞行高度，还要关注浪高变化、海面反射和姿态扰动造成的突然抬升、失控或提前暴露。验证应把海况变化、雷达探测和末端识别放在同一试验链中，比较其从进入威胁区到可被稳定跟踪的时间窗口；若贴波效果仅在单一海况或无真实海杂波条件下出现，则只能视为局部气动能力，不能据此判定突防效果。

**形记忆折展巡飞精打弹。** 该装备的判别指标是巡航构型向接敌构型切换的可靠性、切换后姿态恢复时间以及剩余机动能量。其作战价值在于用低阻巡航换取滞空和航程，再以临机展开改变盘旋半径和接敌方向，使防御方难以依据预设航路布置拦截。验证要覆盖重复折展、温度变化、振动冲击和切换后末端机动，而不能只验证一次结构动作；若构型变化造成控制迟滞、航迹偏差或末端能量不足，反而会扩大可预测窗口，不能以“能够展开”作为合格判据。

**磁流体矢控巡飞精打弹。** 应优先考察磁流体驱动下的侧向控制响应、连续转向保持能力及能量消耗对末端航程的影响，作战效果是让来袭航迹不再局限于少数可预判通道，迫使防御提前分配拦截资源。验证需要建立磁场控制、流体状态、飞行姿态和热管理之间的闭环模型，并以硬件在环试验检验控制指令能否转化为稳定偏转；现有输入没有给出公开的样机参数、响应时间或实飞证据，因此不能把“轨迹不可预测”直接写成确定能力。若快速变向依赖过高功耗或只能在短时实验中实现，该路线应判为概念性指标。

**双体耦合巡飞精打弹。** 关键指标是前后体分离后的引导连续性、偏置航向形成的有效时间差，以及防御系统能否把两体正确识别为同一攻击单元。其直接作用不是简单增加弹体数量，而是把一次拦截决策拆成前段搜索分配和后段末攻两个时序问题，降低集中拦截效率。验证应在分离误差、链路短时中断和防御方多目标跟踪条件下，检查后体能否从预定偏置方向完成独立末攻；若分离后两体被迅速合并识别，或前体失效即导致后体失去目标，则双体结构不会产生预期的决策负荷。

**“玄礁”水下跃升巡飞弹。** 最具判别性的指标是水下航行至出水、跨介质转换和末端再识别三个环节的连续成功率，直接决定其能否避开空中雷达视线后，在港湾、登陆点或靠岸舰艇附近重新建立有效攻击。尤其要测出水姿态散布、出水后传感器恢复时间和末段识别距离，不能只证明弹体能够完成一次上浮。验证应结合水下航行、海面状态、出水扰动和末端目标识别开展连续试验；若跨介质转换后需外部持续指示才能锁定目标，或出水位置偏差导致无法进入预定末攻区，则其水下隐蔽优势不能转化为可验证战果。
