# 不完备与不确定战场信息条件下精确打击研究：市场需求挖掘报告

## 一、需求挖掘层

### ① 典型作战场景

**场景A：强对抗纵深机动目标打击。**  
目标短时暴露、频繁机动、伪装诱饵混杂，己方只能获得碎片化、多源异步情报。需求核心不是单个平台“看得远、打得远”，而是把天基、高空、空中、地面和电磁侦察数据快速融合成可置信目标轨迹。美国陆军TITAN即被公开描述为利用天基、高空、空中和地面传感器，支持远程精确火力与多源目标提名。[U.S. Army](https://www.army.mil/article/284276/enabling_fires_modernization_how_peo_iews_supports_the_fires_community)

**场景B：GPS受扰、通信受限环境下的精确打击。**  
电子战导致GNSS、数据链、传感器链路间歇失效，精确打击由“弹药精度问题”升级为“全链路定位、授时、通信、验证问题”。公开材料指出，PNT是远程精确火力的基础，并强调GPS降级/拒止环境下的Assured PNT能力。[U.S. Army](https://www.army.mil/article/284276/enabling_fires_modernization_how_peo_iews_supports_the_fires_community)

**场景C：跨域协同的时间敏感目标处置。**  
目标可能由空中平台发现，但最佳效应手段来自海上、陆基或非动能系统。JADC2公开定位即是连接跨域传感器、指挥节点和打击手段，使“任意传感器到合适射手”成为体系能力。[U.S. Department of Defense](https://www.defense.gov/News/News-Stories/article/article/2427998/joint-all-domain-command-control-framework-belongs-to-warfighters/)

**场景D：低成本无人系统与诱饵饱和下的精确识别。**  
乌克兰战场公开经验显示，低成本无人系统被用于侦察、打击、欺骗和饱和，迫使防空和目标识别体系重视规模、成本控制与多系统集成，而非依赖少数高端系统。[NATO Lessons Learned Portal / Ifri](https://nllp.jallc.nato.int/iks/sharing%20public/20260201_u_article_ifri%20ukraine%20battlefield%20lessons.pdf)

### ② 牵引需求的新战法/新概念技术及制胜机理

**从杀伤链转向杀伤网。**  
不确定条件下，线性“发现-定位-打击-评估”链条容易被单点干扰打断。杀伤网强调多传感器、多节点、多效应器冗余连接，允许数据绕行、任务重构和射手重选。SDA公开提出通过Custody、Transport、Tracking、Navigation、Battle Management等层实现目标持续跟踪、低时延传输和杀伤网闭合。[SDA Custody](https://www.sda.mil/custody/)

**从“精确坐标打击”转向“概率目标状态打击”。**  
目标位置不再被视为确定坐标，而是带置信度的时空轨迹、身份概率、活动模式和误伤风险。制胜机理是把不确定性显式量化，在目标确认、效应选择、时机选择、毁伤评估中持续更新。

**从人工串联系统转向AI辅助融合与决策。**  
GAO指出，美军CJADC2目标是从人工在不同系统间搬运数据的“swivel chair”模式转向集成数据模式，但仍面临框架、数据共享、分类限制和互操作挑战。[GAO](https://files.gao.gov/reports/GAO-25-106454/index.html) RAND也指出，AI可在复杂系统协调、方案评估、决策支持和更快决策方面改变未来作战。[RAND](https://www.rand.org/content/dam/rand/pubs/research_reports/RRA4300/RRA4316-1/RAND_RRA4316-1.pdf)

**从单一高端平台转向可消耗、分布式、弹性体系。**  
面对诱饵、电子战和饱和攻击，体系需依靠多层低成本传感、边缘计算、抗毁通信和多效应器组合来维持可用性。

### ③ 装备能力特征清单

| 能力域 | 定性特征 | 定量指标方向 |
|---|---|---|
| 多源感知与目标保持 | 天基/高空/无人/地面/电磁多源互补，支持断续观测下目标保持 | 目标更新率、重捕获时间、持续跟踪概率、虚警率/漏警率 |
| 不确定性建模 | 输出目标身份、位置、轨迹、意图和误伤风险置信度 | 置信区间收敛速度、轨迹预测误差、置信度校准误差 |
| 数据融合与边缘处理 | 近源处理、跨域融合、自动目标提名 | 数据处理时延、融合吞吐量、跨源关联准确率 |
| 抗干扰通信与数据织网 | 多链路、自组网、断连续传、低可探测通信 | 端到端时延、链路可用率、抗压吞吐、断链恢复时间 |
| Assured PNT | GPS降级/拒止下保持定位、授时、同步 | 定位误差、授时误差、PNT可用率、降级模式切换时间 |
| 人机协同决策 | AI给出候选目标、效应组合和风险提示，人类保留授权与规则约束 | 决策周期缩短率、建议采纳率、人工复核负担、误报处置时间 |
| 效应器适配 | 支持动能/非动能、远程/近程、有人/无人平台协同 | 射手匹配时间、任务重规划时间、效应-目标匹配成功率 |
| 战损评估闭环 | 自动汇聚打击后传感数据，更新目标状态 | BDA完成时间、毁伤置信度、二次打击需求识别准确率 |
| AI可信与可验证 | 可测试、可解释、可审计、可控降级 | 测试覆盖场景数、模型漂移告警时间、审计可追溯率 |

## 二、技术攻关层

### ④ 能力实现途径判断

| 能力特征 | 实现途径判断 |
|---|---|
| 多源感知与目标保持 | 集成创新为主：传感器多已存在，难点在跨域接入、时空配准和目标保持 |
| 不确定性建模 | 原理突破+工程化并重：需把概率推理、因果判断、可信AI嵌入指挥流程 |
| 数据融合与边缘处理 | 集成创新：云边端协同、MLOps、数据标准是关键 |
| 抗干扰通信与数据织网 | 沿用改进+集成创新：多链路、卫星网、战术网、低轨中继组合 |
| Assured PNT | 沿用改进+局部突破：惯导、视觉/地形匹配、机会信号、低轨PNT增强 |
| 人机协同决策 | 原理突破倾向明显：难在信任校准、责任边界、规则约束和异常解释 |
| 效应器适配 | 集成创新：核心在开放架构、任务分配算法、火力/空域/电磁协同 |
| 战损评估闭环 | 集成创新：重点是快速回传、变化检测、多源证据融合 |
| AI可信与可验证 | 原理突破+制度工程：DoD AI测试指南强调形式化方法、可测试需求、人机系统集成、信任校准和涌现行为测试。[OUSD R&E](https://www.cto.mil/wp-content/uploads/2025/02/TE_of_AIES_Guidebook_Final_26Feb25.pdf) |

### ⑤ 核心技术清单

1. **多模态目标关联技术**：SAR/EO/IR/RF/通信情报/开源地理数据的时空配准、跨传感器身份关联、诱饵识别。  
2. **断续观测目标保持技术**：遮蔽、静默、伪装、机动条件下的轨迹预测与重捕获。  
3. **不确定性量化技术**：目标身份概率、轨迹置信区间、传感器可信度评分、误伤风险估计。  
4. **边缘AI与在轨/近源处理技术**：低时延目标检测、数据压缩、事件触发传输、模型轻量化。SDA公开提到在轨融合、低时延处理和目标假设在卫星节点间分发。[SDA Custody](https://www.sda.mil/custody/)  
5. **开放式数据与任务接口**：统一目标对象模型、火力请求接口、权限标记、跨军兵种数据治理。  
6. **抗毁通信织网技术**：多路径路由、链路自愈、断连缓存、优先级队列、低轨卫星中继。SDA说明低轨传输层可通过网状网络重路由数据。[SDA NDSA](https://www.sda.mil/the-national-defense-space-architecture-ndsa-an-explainer/)  
7. **Assured PNT融合技术**：惯导、星基增强、视觉/地形、射频机会信号、时间同步冗余。  
8. **人机协同目标审核技术**：候选目标解释、证据链展示、规则约束、人工授权流转。DoD Responsible AI文件强调AI需以合法、伦理、负责、可问责方式设计、测试、采购、部署和使用。[DoD RAI](https://www.ai.mil/Portals/137/Documents/Resources%20Page/DoD%20Responsible%20AI%20Strategy%20and%20Implementation%20Pathway.pdf)  
9. **效应器智能匹配技术**：根据目标时效、可用射手、通信状态、风险约束、成本交换比进行任务推荐。  
10. **快速BDA与再规划技术**：变化检测、毁伤概率评估、二次目标提名、效应闭环学习。  

### ⑥ 技术耦合关系与短板风险

**最大卡点：数据互操作与可信数据治理。**  
如果多源数据不能按统一对象模型、权限规则和时空基准流动，AI、火力匹配、BDA都会退化为人工拼接。GAO已明确指出CJADC2缺少全面框架、经验共享不足、数据分类限制等问题会拖慢进展。[GAO](https://files.gao.gov/reports/GAO-25-106454/index.html)

**第二卡点：目标置信度与误差传播。**  
上游传感器误差若未被量化，下游决策系统会把“看似精确的错误坐标”当作高可信目标，造成误击、空耗或错失窗口。

**第三卡点：抗干扰PNT与通信。**  
PNT和链路一旦失效，远程精确火力的定位、授时、同步、任务更新和BDA均受影响。陆军公开材料把PNT称为支撑远程精确火力每一阶段的基础能力。[U.S. Army](https://www.army.mil/article/284276/enabling_fires_modernization_how_peo_iews_supports_the_fires_community)

**第四卡点：AI测试与战场泛化。**  
训练数据不足、场景偏差、对抗欺骗和模型漂移会导致系统在真实环境中失效。AI系统测试需覆盖人机集成、信任校准、涌现行为和作战概念耦合。[OUSD R&E](https://www.cto.mil/wp-content/uploads/2025/02/TE_of_AIES_Guidebook_Final_26Feb25.pdf)

## 三、能力图像与效能贡献层

### ⑦ 装备能力图像

建议将目标装备定义为：**不确定信息条件下精确打击支撑系统**，不是单一导弹、无人机或雷达，而是“感知-融合-决策-效应-评估”一体化装备族。

**能力域构成：**

```text
多源感知层
  天基/高空/无人/地面/电磁/网络化观测
        ↓
目标认知层
  关联、识别、轨迹预测、不确定性量化
        ↓
任务决策层
  人机协同、规则约束、效应器匹配、风险评估
        ↓
弹性连接层
  抗干扰通信、低轨中继、开放接口、Assured PNT
        ↓
效应闭环层
  动能/非动能协同、BDA、再规划
```

**指标画像：**

| 指标族 | 目标方向 |
|---|---|
| 时间 | OODA/杀伤链周期由“小时级/十分钟级”压缩至“分钟级/近实时方向” |
| 质量 | 目标身份、位置、轨迹、误伤风险均带置信度输出 |
| 弹性 | 单一传感器、链路或PNT源失效后保持降级可用 |
| 规模 | 可同时处理大量候选目标、诱饵和无人系统事件 |
| 成本 | 以低成本传感节点、软件定义能力和开放架构降低扩展成本 |
| 可信 | AI建议可解释、可审计、可回放，人类授权边界清晰 |

**谱系位置：**  
位于传统C4ISR、火力指挥控制、远程精确火力、无人系统集群、低轨通信/感知星座之间的交叉地带。它不是替代现有火力平台，而是把现有侦察、指挥、PNT、通信和效应器从“烟囱式能力”升级为“可组合杀伤网能力”。美国陆军Fires 2028概念明确提出，未来火力需要在多域、复杂电磁环境中获取目标，并利用有机与非有机传感器提供可用于打击的数据。[U.S. Army Fires 2028](https://api.army.mil/e2/c/downloads/2021/10/06/869ca62b/afc-concept-for-fires-2028-oct21.pdf)

### ⑧ 效能贡献评估

**对杀伤链的贡献方式：**

| 环节 | 贡献 |
|---|---|
| Find/Detect | 多源传感覆盖提升，降低单点盲区 |
| Fix/Track | 断续观测下保持目标轨迹，减少目标丢失 |
| Target | 输出置信度、风险和效应建议，降低人工筛选负担 |
| Engage | 自动匹配可用效应器，缩短射手选择与任务分配时间 |
| Assess | 快速BDA和目标状态更新，支持再打击或任务终止 |

**可量化评估方向：**

1. 目标发现至任务建议的平均时间缩短率。  
2. 目标轨迹保持概率与重捕获时间。  
3. 多源关联准确率、虚警率、漏警率。  
4. GPS/通信受扰条件下任务完成率。  
5. 单位目标处置成本与效应器利用效率。  
6. BDA完成时间与二次打击减少率。  
7. 人工分析负荷下降比例。  
8. 误击风险告警准确率和规则约束触发率。  

### ⑨ 发展优先级与近期抓手

**优先级一：数据底座与目标对象模型。**  
近期最应启动的是跨传感器、跨军兵种的目标对象模型、置信度标签、时空基准和权限标记。没有这个底座，AI和火力协同只能局部演示。

**优先级二：不确定性目标融合与AI辅助审核。**  
建设“候选目标-证据链-置信度-风险”一体化工作台，让系统明确告诉指挥员：看到了什么、为何判断、缺什么证据、风险在哪里。

**优先级三：Assured PNT与抗毁通信最小可用网。**  
以GPS降级、链路间歇、带宽受限为默认条件设计系统，而不是作为异常情况补丁。

**优先级四：边缘处理与低时延BDA。**  
把目标检测、变化检测、压缩传输和BDA前移到传感器侧、无人平台侧或卫星侧，减少回传压力。

**近期演示验证项目构想：**

**项目1：不确定目标杀伤网数字靶场。**  
构建含诱饵、遮蔽、通信中断、GPS降级、目标机动的仿真环境，验证多源融合、置信度输出、任务推荐和BDA闭环。重点指标：目标保持概率、任务建议时延、误报漏报、人工负荷。

**项目2：多源传感到火力C2接口样机。**  
选择现有无人机、地面雷达、电子侦察、商业遥感样例数据，形成统一目标对象模型，向火力指挥系统输出候选目标和证据链。重点验证互操作与数据治理。

**项目3：GPS拒止条件下精确任务链路演示。**  
不涉及实弹打击，验证多源PNT、时间同步、断连续传、任务重规划和BDA回传。重点指标：定位/授时降级幅度、链路恢复时间、任务连续性。

**项目4：人机协同目标审核与AI测试框架。**  
围绕AI建议可解释、人工授权、异常回放、模型漂移和对抗样本测试建立评估规范，避免系统只在演示环境有效。

**结论：**  
该领域的核心市场需求不是“更远射程”本身，而是在信息不完备、目标不确定、链路受扰、诱饵饱和的环境中，仍能形成可信目标、快速决策、弹性连接和闭环评估。近期突破口应优先放在数据互操作、不确定性融合、Assured PNT、抗毁通信和AI可信测试，随后再扩展到更复杂的跨域效应器协同。
