**概念界定**

“间歇通信条件下精打武器任务保持与任务续接”，本质是把精确打击武器从“发射后依赖连续链路/一次性预案”升级为“带任务状态、授权边界、异步通信、协同自治和可验证安全约束的任务节点”。它不要求全程在线，而是在链路可用时接收更新、交换状态；链路中断时保持任务意图、保存状态、按预设规则降级执行；链路恢复后可续接任务、重构协同关系、同步新目标优先级或撤销/终止指令。

公开资料显示，这一需求由三类事实共同牵引：一是未来作战将长期处于退化、受争夺的电磁环境，JADC2明确要求在跨域、跨层级条件下“sense, make sense, act”并依赖安全韧性基础设施和AI/自动化能力；二是DoD C3现代化强调小型分布式单元在D-DIL环境下独立行动、再聚合，并需要多频谱网状连接把传感器与射手连接起来；三是乌克兰战场已证明GPS、SATCOM、C2链路和精确弹药会被电子战持续压制，HIMARS、Excalibur、GLSDB、JDAM等公开报道均出现精度退化问题。参见[JADC2 Strategy](https://media.defense.gov/2022/Mar/17/2002958406/-1/-1/1/SUMMARY-OF-THE-JOINT-ALL-DOMAIN-COMMAND-AND-CONTROL-STRATEGY.pdf)、[DoD C3 Modernization Strategy](https://dodcio.defense.gov/Portals/0/Documents/DOD-C3-Strategy.pdf)、[CSIS关于空间与电子战的评估](https://www.csis.org/analysis/chapter-8-extending-battlespace-space)。

**第一层：需求挖掘层**

① 典型作战场景

场景一：远海/岛链高对抗环境中的移动目标打击。  
远程平台在防区外投放网络化精确弹药或巡飞平台，目标可能移动，外部ISR、卫星链路、战术数据链受干扰，只能出现短时通信窗口。任务保持能力使武器在失联时继续导航、搜索、等待或转入备用任务；任务续接能力使其在短暂连通时接收目标优先级、禁打区、终止命令、协同分工等更新。该场景的核心矛盾是“目标动态性”和“通信非连续性”同时存在，传统一次性发射诸元难以覆盖全程不确定性。

场景二：陆上纵深精确火力支援中的D-DIL链路。  
前沿传感器、无人平台、火力单元和指挥节点分散部署，地形遮蔽、电子压制、网络拥塞导致数据链间歇可用。DoD C3战略提出，小型分布式单元需在D-DIL环境中独立行动并能再聚合；这直接对应武器端需要“可断点续传、可状态恢复、可任务再绑定”的能力，否则杀伤链会停在“发现/跟踪”之后，无法稳定转化为打击效果。

场景三：压制/穿透高密度防空与电子战覆盖区。  
精打武器进入高威胁区后，外部通信、GNSS和中继链路都可能被压制。此时连续遥控不可假设成立，武器必须具备多源PNT、自治任务管理、协同去冲突和严格授权边界。DARPA CODE曾公开展示无人系统在通信离线、GPS不可用条件下仍完成任务目标，并强调多机在退化条件下协同适应；这说明“任务保持/续接”已经从通信技术问题扩展为自治、测试、保障和指挥授权问题。来源：[DARPA CODE演示](https://www.darpa.mil/news/2019/code-success)。

② 新战法/新概念技术及制胜机理

一是“分布式杀伤链/马赛克战”。RAND对Mosaic Warfare的研究指出，分布式体系的优势在于韧性、适应性和没有单点失效，但代价是控制难度、通信需求和重复投入增加。对精打武器而言，任务保持与续接就是把弹药从单个末端执行器变成分布式杀伤链中的可组合节点，降低任一链路中断对整个任务的摧毁性影响。来源：[RAND Distributed Kill Chains](https://www.rand.org/pubs/research_reports/RRA573-1.html)。

二是“网络化、协同、自主武器”。AFRL Golden Horde公开资料显示，该项目聚焦Networked, Collaborative and Autonomous武器，演示了多枚小直径炸弹建立通信、接收飞行中目标更新、与JADC2连接并实施协同行为；其资料同时强调半自主边界，即仅攻击任务规划中由人类预先选择的目标或目标组，并受预设交战规则约束。来源：[AFRL Golden Horde飞行演示](https://www.afrl.af.mil/News/Article-Display/Article/2634538/afrl-successfully-completes-golden-horde-collaborative-small-diameter-bomb-flig/)、[Golden Horde Colosseum资料](https://afresearchlab.com/wp-content/uploads/2020/02/AFRL_Golden-Horde_FS_0922.pdf)。

三是“延迟/中断容忍网络”。NASA对DTN的说明表明，DTN通过存储-转发克服链路中断和延迟，节点可在通信中断时保存数据，待下一节点可用时再传输；IETF RFC 4838也强调DTN适用于长期延迟、断续端到端连接和异步消息通信。对应到精打武器，技术机理不是追求始终在线，而是把任务包、状态包、授权包、更新包设计成可独立处理的异步单元。来源：[NASA DTN](https://www.nasa.gov/communicating-with-missions/delay-disruption-tolerant-networking/)、[IETF RFC 4838](https://datatracker.ietf.org/doc/html/rfc4838)。

|---|---|---|

| 协同自治 | 多武器共享状态、分配任务、去冲突、重规划 | 协同节点规模、单点失效后的任务完成率、协同一致性收敛时间 |

| 人控授权边界 | 失联自治不越权，恢复通信后可审计 | 预授权目标集约束合规率、终止/禁止指令生效率、任务日志完整性 |

**第二层：技术攻关层**

④ 能力实现途径判断

| 能力特征 | 实现途径判断 | 理由 |
|---|---|---|
| 任务状态保持 | 集成创新 | 需把任务管理、飞控/GNC、通信、安全日志和授权规则整合到武器级实时架构 |
| 间歇通信适配 | 沿用改进+集成创新 | DTN、异步消息、存储转发已有基础，但需适配武器端低时延、高动态、强安全约束 |
| 任务续接 | 集成创新 | 难点是断链前后任务版本、授权边界、目标状态和协同关系的一致性 |
| 协同自治 | 集成创新，局部原理突破 | Golden Horde/CODE已有公开验证，但大规模、高对抗、可证明可靠仍未成熟 |
| 抗退化PNT | 沿用改进+原理突破 | DARPA PRIGM已推动GPS拒止下弹药惯导；长航时低漂移、小型化仍是瓶颈 |
| 目标/环境感知 | 集成创新 | 传感器、ATR、数据融合成熟度不一，关键在抗欺骗和规则约束 |
| 安全与可信 | 集成创新 | AFRL Weapon Cyber已明确关注弹药体系的网络、GNC、传感器、自治安全 |
| 人控授权边界 | 沿用改进+集成创新 | 任务规划、ROE和审计机制可沿用，但需嵌入自治决策闭环 |

⑤ 核心技术清单

1. 武器端任务状态机：任务阶段、授权范围、目标优先级、等待/返航/终止/自毁等安全状态的形式化建模。  
2. 断点续接协议：任务包版本管理、状态摘要、冲突解决、幂等更新、撤销指令优先级。  
3. 低带宽异步通信：DTN式存储转发、机会路由、优先级队列、压缩状态上报。  
4. 可信任务包：端到端认证、完整性校验、时间有效性、抗重放、密钥生命周期管理。  
5. 协同任务分配：多弹药目标分配、时序协同、去冲突、冗余覆盖与失效重分配。  
6. 退化PNT融合：高可靠惯导、视觉/地形/星光/磁/信号机会源融合、抗欺骗一致性检测。  
7. 末端感知与确认：多模传感、目标特征匹配、置信度门限、禁打区/非授权目标排除。  
8. 可验证自治：规则约束、运行时监控、形式化验证、仿真覆盖、失效安全策略。DARPA Assured Autonomy强调学习型网络物理系统需要运行时持续保障安全与功能正确性，适合作为该方向的技术参照。来源：[DARPA Assured Autonomy](https://www.darpa.mil/research/programs/assured-autonomy)。  
9. 武器网络安全：弹载实时系统、传感器、GNC、武器间网络的零信任与抗篡改。AFRL相关公开需求已将“嵌入式实时、武器间通信、传感器/导引/控制、可信自治”列为研究重点。来源：[Doolittle Institute/AFRL Weapon Cyber](https://doolittleinstitute.org/research-area-19-cyber-resiliency-security-research-for-precision-guided-munitions/)。  
10. LVC/HIL验证环境：软件在环、硬件在环、替身平台、电子战/断链/欺骗注入、任务续接评估。

⑥ 技术耦合关系与短板风险

最核心耦合链条是“任务状态机-通信续接-安全授权-自治决策”。如果任务状态机不可形式化，通信恢复后就无法判断哪个任务版本有效；如果认证与授权薄弱，敌方欺骗或重放更新可能比断链本身更危险；如果自治策略不可验证，失联期间的任务保持会变成不可控行为。

关键短板排序如下：

| 卡点 | 拖垮方式 |
|---|---|
| 可信任务包与授权边界 | 一旦无法保证指令真实、完整、未过期，任务续接能力不能进入实装 |
| 退化PNT | GNSS拒止下误差快速累积，会使任务保持只剩“保持飞行”，无法保持精确效果 |
| 续接一致性 | 多节点收到不同版本更新，会导致重复攻击、漏打、目标冲突或协同失效 |
| 可验证自治 | 无法证明失联行为受控，会限制试验、采办和作战授权 |
| 低带宽状态压缩 | 如果每次续接都需要大量数据，短通信窗口无法支撑动态任务更新 |
| LVC/HIL试验体系 | 没有可重复注入断链、欺骗、误码和协同失效的环境，指标无法闭环 |

**第三层：能力图像与效能贡献层**

⑦ 能力图像

谱系位置：该装备能力位于传统精确制导弹药、巡飞弹、协同无人平台和JADC2杀伤网之间。它不是单纯“更准的弹”，也不是完全自主武器，而是“受控半自主、可联网、可断链保持、可恢复续接”的精确打击节点。

能力域构成可概括为“五层一边界”：

| 层级 | 能力画像 |
|---|---|
| 任务层 | 可保存任务意图、优先级、约束、禁止条件和终止条件 |
| 网络层 | 可在短时链路中接收/发送高价值摘要，而非依赖连续遥控 |
| 协同层 | 可与同类武器、无人平台或中继节点共享有限状态并重分配任务 |
| 导航层 | 可在GNSS退化时维持可接受导航精度和时间同步 |
| 感知层 | 可对目标、环境、禁打约束进行有限自治判断 |
| 授权边界 | 人类预授权目标集、ROE、审计日志和失效安全策略贯穿全流程 |

指标画像建议采用“任务成功率-续接成功率-授权合规率-抗退化能力”四类主指标，而不是只看命中精度。原因是间歇通信问题首先摧毁的是杀伤链连续性，其次才表现为末端精度下降。

⑧ 效能贡献评估

对杀伤链的贡献方式：

1. 对“发现-定位-跟踪”：武器可接收短时目标更新，并在失联时保持对目标状态的预测或等待条件，降低目标信息过期造成的任务失败。  
2. 对“决策-授权”：预置授权边界和可审计规则，使失联期间仍能在限定任务空间内行动，同时保留恢复通信后的人工干预入口。  
3. 对“交战-毁伤”：协同武器可分配目标、错开时序、避免过度集中，提高对移动、分散或受保护目标的打击稳定性。  
4. 对“评估-再攻击”：任务日志、状态摘要和残余武器重分配能力，可把战果评估与后续任务续接连接起来。  
5. 对体系韧性：从“链式、单路径杀伤链”转为“网状、多路径杀伤网”，单一通信节点或单次链路失败不再直接导致任务失败。

可量化方向：

| 效能项 | 度量方向 |
|---|---|
| 杀伤链闭合概率 | 断链/强干扰条件下从发现到交战的闭合率 |
| 时间敏感目标响应 | 目标更新到武器任务生效的时间 |
| 任务保持收益 | 同等干扰条件下任务完成率相对传统弹药提升 |
| 协同收益 | 多武器任务分配后的目标覆盖率、重复打击率下降 |
| 抗PNT退化收益 | GNSS不可用条件下CEP增长受控程度 |
| 人控安全 | 预授权范围外行为发生率、终止指令接收后生效率 |
| 网络效率 | 单次通信窗口可完成的任务更新数量和状态同步成功率 |

⑨ 发展优先级与近期抓手

优先级建议：

1. 第一优先级：可信任务包、授权边界、断点续接协议。  
这是准入能力，没有它就无法把“失联自治”转化为可采购、可试验、可授权的装备能力。

2. 第二优先级：退化PNT与任务状态保持。  
CSIS对乌克兰经验的总结显示，GPS/SATCOM干扰已直接影响精确弹药和无人系统效能；DARPA PRIGM也说明弹药级GPS拒止PNT是独立攻关方向。来源：[DARPA PRIGM](https://www.darpa.mil/research/programs/precise-robust-inertial-guidance-for-munitions)。

3. 第三优先级：低带宽协同自治。  
Golden Horde证明网络化协同弹药具有可行性，但从演示到实装的关键在于规模化、鲁棒性、跨平台接口和可验证测试。

4. 第四优先级：LVC/HIL试验体系。  
该方向不是辅助项，而是装备成熟的前置条件。AFRL Golden Horde后续Colosseum强调数字工程、硬件在环和替身UAV测试，说明低成本、高频次验证是推动网络化协同武器成熟的现实抓手。

近期可启动的演示验证项目构想：

项目一：间歇通信任务续接原型验证。  
目标是在仿真和半实物环境中验证“任务包下发-链路中断-状态保持-链路恢复-任务更新生效-审计回放”闭环。重点指标包括最小通信窗口、续接成功率、版本冲突处理正确率和未授权更新拒绝率。

项目二：GNSS拒止下任务保持验证。  
构建GNSS可用、退化、欺骗、拒止多种工况，测试惯导与多源辅助导航在任务保持阶段的误差增长、任务状态稳定性和恢复通信后的重定位能力。

项目三：小规模协同弹药数字靶场。  
以3-6个替身飞行平台或仿真节点构建协同任务，验证目标优先级更新、节点失效、链路间歇、任务重分配和时序协同，不进入实弹设计，先把体系接口、任务逻辑和安全边界跑通。

项目四：武器任务安全红队测试。  
围绕任务包篡改、重放、过期指令、虚假状态、链路恢复欺骗和节点冒充进行安全评估，形成“任务续接安全基线”。该项目应与飞控/GNC、传感器和通信团队共同设计，因为安全机制的时延和资源开销会直接影响实时任务性能。

总体判断：该需求不是单一弹药升级，而是精确打击体系从“高质量平台+连续链路”向“分布式节点+异步续接+受控自治”的演进。近期最有价值的市场切入点不是直接追求大规模自主协同，而是先形成可验证、可审计、可跨平台复用的任务保持与续接中间件，并通过LVC/HIL和替身平台快速积累可信证据。
