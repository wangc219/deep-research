**间歇暴露目标搜索与精确打击研究报告**

**概念界定**  
“间歇暴露目标”指平时隐蔽、机动、伪装或受遮蔽，仅在发射、转移、补给、通信、雷达开机、越障、出入口通行等短窗口暴露的高价值或高威胁目标。公开美军条令将 time-sensitive target 定义为需要立即响应的高价值、短暂机会目标或可能威胁己方的目标，这与本概念高度重合；其作战难点在于目标暴露时间短于传统“发现-定位-跟踪-决策-打击-评估”流程的闭合周期。[AFDP 3-60 Targeting](https://www.doctrine.af.mil/Portals/61/documents/AFDP_3-60/3-60-AFDP-TARGETING.pdf)

## 第一层：需求挖掘层

### ① 典型作战场景

**场景A：机动火力/反炮兵场景**  
自行火炮、火箭炮、迫击炮等火力单元发射后快速转移，暴露窗口来自弹道反推、雷达/红外/声学特征、发射阵地烟焰与交通痕迹。Q-53反炮兵雷达的公开测试材料显示，其任务就是探测、分类、跟踪来袭弹药并定位威胁火力源，以支撑及时反制；但测试中误报、齐射识别、网络生存性也暴露为关键风险。[DOT&E Q-53](https://www.dote.osd.mil/Portals/97/pub/reports/FY2014/army/2014q-53counterfire_target_acquisition_radar.pdf?ver=2019-08-22-110521-813)

**场景B：纵深机动高价值目标场景**  
包括机动指挥节点、机动防空系统、战术导弹发射车、电子战节点、补给车队等。其共同特征是“可被发现但难以持续掌握”，需要从宽域感知转入连续目标监管，再转入快速效应分配。Air & Space Forces Magazine对杀伤链压缩的讨论指出，敌方会主动缩短自身暴露时间，因此必须压缩F2T2EA各阶段及阶段之间的延迟。[Compressing the Kill Chain](https://www.airandspaceforces.com/article/0303killchain/)

**场景C：濒海/岛礁分布式拒止场景**  
目标分散于复杂海岸、岛礁、港口、道路网和民用背景中，可能短时开机、短时机动、短时发射。需求重点不是单个传感器“看得远”，而是多域传感器、低空无人平台、空间/空中广域监视、地面侦察和火力节点的快速组合。

**场景D：城市与遮蔽地形近战场景**  
建筑、林地、地下出入口和短街区机动造成“看见即丢失”。DARPA OFFSET公开材料把城市环境中的高楼、狭窄空间、受限视距和通信约束列为无人集群应用背景，目标是用大量协同无人系统增强侦察、通信和态势感知。[DARPA OFFSET](https://www.darpa.mil/research/programs/offensive-swarm-enabled-tactics)

### ② 牵引需求的新战法/技术与制胜机理

**由平台链转为杀伤网。**  
RAND对“Mosaic warfare/分布式杀伤链”的研究指出，多域作战强调跨军种、跨域、跨功能把传感器和射手快速组合成非线性杀伤网。[RAND Distributed Kill Chains](https://www.rand.org/content/dam/rand/pubs/research_reports/RRA500/RRA573-1/RAND_RRA573-1.pdf) 对间歇暴露目标而言，关键不是预先指定某一平台打某一目标，而是在目标暴露瞬间把“最合适的传感器、处理节点、授权节点、效应器”动态拼接起来。

**由周期性侦察转为持续目标监管。**  
俄乌战场公开研究显示，密集无人机轨道、FPV和巡飞弹既可主动搜寻目标，也能确认敌方位置，形成近线战场透明化，并在一定纵深内维持较低延迟侦察。[RUSI Ukraine Tactical Developments](https://static.rusi.org/tactical-developments-third-year-russo-ukrainian-war-february-2205.pdf) 这说明市场需求正从“发现一次”转向“发现后不断保持目标可信度”。

**由人工串行处理转为AI辅助机器到机器流转。**  
DoD的JADC2战略摘要强调“sense, make sense, act”，利用数据、自动化、AI和安全韧性基础设施提升决策速度。[JADC2 Strategy Summary](https://media.defense.gov/2022/Mar/17/2002958406/-1/-1/1/SUMMARY-OF-THE-JOINT-ALL-DOMAIN-COMMAND-AND-CONTROL-STRATEGY.pdf) Project Convergence公开资料也强调用AI、JADC2和战术云把传感器到射手流程从传统延迟压缩到分钟级。[Project Convergence](https://www.lineofdeparture.army.mil/Journals/Field-Artillery/Field-Artillery-Archive/Field-Artillery-2025-E-Edition/Project-Convergence/)

**由纯打击弹药转为“侦打一体/可等待”效应器。**  
巡飞弹市场页面显示，该类系统可在区域上空搜索、跟踪目标，并在授权后打击；2025-2030年全球市场预计从53.6亿美元增至132.6亿美元，增长动因包括AI目标识别、自主跟踪、抗干扰导航、模块化载荷和指挥系统集成。[MarketsandMarkets](https://www.marketsandmarkets.com/ResearchInsight/loitering-munitions-market-size.asp) 其制胜机理是把“等待目标暴露”的时间从指挥链转移到前沿空中平台上。

| 侦打一体效应 | 巡飞、无人平台、远程火力等组合 | 响应时间、待机时间、任务成功率、单位目标成本 |

## 第二层：技术攻关层

### ④ 能力实现途径判断

| 能力特征 | 实现途径判断 |
|---|---|
| 宽域发现 | 集成创新：整合空间、空中、地面、无人平台和开源地理信息 |
| 微弱暴露捕获 | 集成创新为主，部分原理突破：低信噪比检测、异常行为识别、复杂杂波抑制 |
| 连续监管 | 原理突破+工程集成：多目标多传感器跟踪、身份保持、遮蔽后重识别 |
| AI识别 | 沿用改进+集成创新：成熟视觉模型需适配小样本、遮蔽、伪装、跨谱段 |
| 动态任务分配 | 原理突破：从静态指派转向实时杀伤网编排 |
| 通信与数据链 | 集成创新：多链路融合、边缘缓存、断续连接下的任务协同 |
| 精确定位 | 集成创新：SAR/GMTI、EO/IR、电子支援、地理配准、时空同步融合 |
| 侦打一体效应 | 沿用改进+集成创新：巡飞弹、无人机、远程火力和授权流程一体化 |
| 体系韧性 | 集成创新：分布式架构、零信任、抗毁网络、低成本冗余 |
| 评估闭环 | 沿用改进：图像变化检测、战果评估模型、任务再规划 |

### ⑤ 核心技术清单

1. **多源宽域感知**：SAR/GMTI、EO/IR、低空无人机、地面侦察、电子支援、声/光/热异常检测的融合使用。E-8C JSTARS公开资料显示，其雷达和计算系统可收集地面部队信息并近实时转发，覆盖大面积战场，说明宽域GMTI/C2ISR长期是该问题的核心能力基础。[USAF E-8C Fact Sheet](https://www.af.mil/About-Us/Fact-Sheets/Display/Article/104507/e-8c-joint-stars/)

2. **短窗口目标检测**：低信噪比目标检测、背景杂波建模、发射/机动事件检测、变化检测、轨迹突变检测。

3. **跨传感器目标监管**：多目标关联、轨迹拼接、短时丢失补偿、重识别、目标身份置信度传播。

4. **高置信定位与时间同步**：传感器精确标定、统一时空基准、误差传播建模、坐标质量分级。

5. **边缘AI与人机协同确认**：在无人机、车载节点、前沿网关上进行初筛、压缩和优先级排序，保留人工授权与规则约束。

6. **动态杀伤网编排**：根据目标时效、武器可用性、附带风险、通信状态、交战规则和成本自动推荐效应组合。

7. **抗干扰通信与降级运行**：多链路自适应、带宽受限数据产品、断点续传、任务级缓存、低概率截获/探测通信。

8. **侦打一体平台**：巡飞弹、察打一体无人机、可消耗传感器、远程精确火力的协同。公开陆军特种作战期刊指出，巡飞弹填补小分队“有机ISR+精确打击”缺口，同时受成本、航程、载荷、电子战和训练限制约束。[SWCS Loitering Munitions](https://www.swcs.mil/Special-Warfare-Journal/Article/4338971/loitering-munitions-in-modern-combat-addressing-tactical-gaps-at-the-small-unit/)

9. **自动战果评估**：打击前后变化检测、目标消失/失能判断、二次搜索任务生成。

10. **网络安全与可信AI**：数据投毒检测、模型漂移监测、虚假目标识别、审计链、授权留痕。

### ⑥ 耦合关系与短板风险

**最大卡点：目标监管与置信度管理。**  
间歇暴露目标不是“看见就结束”，而是要在遮蔽、伪装、机动、断链、虚假目标背景下保持目标身份连续性。若目标监管失败，后续定位、任务分配和效应评估都会建立在错误对象上。

**第二卡点：低时延数据链与数据标准。**  
JADC2强调以自动化、AI和安全网络支撑快速感知、理解和行动；若数据链不通、格式不通、授权链过慢，传感器能力会被浪费。[DoD JADC2 Release](https://www.defense.gov/News/Releases/Release/article/2970094/dod-announces-release-of-jadc2-implementation-plan/)

**第三卡点：虚警控制。**  
Q-53测试中虚假目标率显著影响作战有效性，说明“发现很多”不等于“可用目标多”。虚警会占用火力、压垮指挥节点并增加误判风险。

**第四卡点：电子战与网络生存性。**  
巡飞弹和小型无人系统依赖导航、链路和感知；公开资料普遍将电子战、劫持、低空防御和训练成本列为限制因素。若抗干扰不足，侦察和打击两端都会退化。

**第五卡点：授权与人机协同。**  
AI可压缩处理时间，但不能替代合法、可靠的交战授权。系统必须提供置信度、证据链和风险提示，否则“快”会带来误伤和升级风险。

## 第三层：能力图像与效能贡献层

### ⑦ 装备能力图像

可将该装备理解为“分布式间歇目标搜索-监管-精确效应系统”，不是单一导弹或单一无人机。

```
天基/空基宽域传感器
        |
低空无人机/地面侦察/电子支援
        |
边缘AI初筛 + 多源融合定位
        |
目标监管与置信度引擎
        |
动态任务分配 / 人机授权
        |
巡飞弹、无人平台、远程火力、电子压制
        |
战果评估与再搜索
```

**谱系位置：**

| 现有能力谱系 | 典型特征 | 本概念位置 |
|---|---|---|
| 传统侦察平台 | 重发现、轻闭环 | 扩展为发现-监管-评估闭环 |
| 反炮兵雷达 | 对发射事件响应快 | 扩展到多类间歇暴露目标 |
| 察打一体无人机 | 平台内闭环强 | 扩展为跨平台杀伤网 |
| 远程精确火力 | 打击能力强、目标依赖外部提供 | 强化动态目标输入和时效性 |
| 巡飞弹 | 可等待、可确认、可打击 | 成为前沿侦打一体节点 |
| JADC2/战术云 | 数据和C2骨架 | 成为跨域编排底座 |

**指标画像建议：**

| 指标类别 | 近期目标方向 | 中远期目标方向 |
|---|---|---|
| 发现时效 | 分钟级发现与告警 | 秒级事件触发与自动分发 |
| 监管能力 | 短时遮蔽后重捕 | 跨域连续身份保持 |
| 定位质量 | 满足指挥决策和火力准备 | 动态目标高置信坐标质量管理 |
| 决策周期 | 人机协同压缩到分钟级 | 多方案自动推荐，人工快速授权 |
| 体系韧性 | 单节点失效可替代 | 多节点损失下能力优雅降级 |
| 成本结构 | 高低搭配 | 大量可消耗节点支撑持续覆盖 |

### ⑧ 效能贡献评估

**对杀伤链的贡献：**

1. **Find/Detect：** 从单点侦察变成多源持续搜索，提高短窗口暴露捕获概率。  
2. **Fix/Track：** 通过多源融合和轨迹监管，减少“发现后丢失”。  
3. **Target：** 通过置信度、坐标质量和风险分级，缩短人工判断时间。  
4. **Engage：** 通过动态效应分配，把远程火力、巡飞弹、无人平台和非动能效应纳入同一选择空间。  
5. **Assess：** 用打击后变化检测和再搜索，提高闭环速度，避免重复消耗。

**可量化方向：**

| 效能指标 | 衡量方式 |
|---|---|
| 杀伤链闭合时间 | 从首次可靠发现到完成效应评估的时间 |
| 目标逃逸率 | 暴露后未能保持监管或未能形成有效处置的比例 |
| 单目标处置成本 | 传感器、通信、弹药、平台损耗和人员投入综合成本 |
| 火力利用效率 | 有效处置次数/火力任务次数 |
| 虚警负担 | 每单位时间需人工复核的无效目标数 |
| 体系韧性 | 通信受扰、节点损失、GNSS受限条件下的能力保持率 |
| 附带风险控制 | 目标置信度、环境识别和授权流程的合规通过率 |

### ⑨ 发展优先级与近期抓手

**优先级1：目标监管与置信度引擎。**  
近期应优先做跨传感器目标身份保持、遮蔽后重捕、坐标质量分级和证据链展示。该模块是全系统的“可信目标账本”，也是避免误击和浪费火力的核心。

**优先级2：多源低时延数据底座。**  
先解决数据格式、时间同步、边缘计算、任务消息和降级通信问题。没有可靠数据底座，AI识别和火力分配都只能局部有效。

**优先级3：低成本前沿侦察/巡飞节点。**  
市场和战场经验均显示巡飞弹、低空无人机和可消耗传感器正在成为需求增长点，但要同时解决成本、训练、抗干扰和人机授权。

**优先级4：电子战环境下的验证。**  
所有演示验证必须纳入通信受限、导航受扰、虚假目标、诱饵、遮蔽和节点损失条件，否则指标会偏乐观。

**近期演示验证项目构想：**

1. **“短窗口目标监管”演示**  
目标：在模拟复杂地形中，对短时出现、快速消失、再次出现的机动目标完成多源发现、轨迹接续、身份置信度更新和告警。  
考核：重捕时间、身份连续性、虚警率、人工复核负担。

2. **“传感器到效应器分钟级闭环”演示**  
目标：连接无人机、地面传感器、指挥节点和模拟效应器，验证从发现到授权建议、再到战果评估的闭环流程。  
考核：端到端时延、数据丢包下任务完成率、授权界面可解释性。

3. **“电子战降级运行”演示**  
目标：在链路受扰、GNSS受限和部分节点失效条件下，验证边缘AI、缓存、异步同步和备用链路。  
考核：能力保持率、恢复时间、误报变化、目标监管中断次数。

4. **“巡飞/侦察一体协同”演示**  
目标：验证前沿可等待平台与后方宽域传感器之间的目标交接、复核、跟踪和模拟效应分配。  
考核：搜索覆盖、目标确认时间、单目标处置成本、任务取消/返航或再分配比例。

**结论**  
间歇暴露目标搜索与精确打击的真实需求，不是单纯采购更远射程弹药，而是建设“持续感知、可信监管、快速编排、授权打击、闭环评估”的体系能力。近期最值得投入的是目标监管、低时延数据底座、低成本前沿无人节点和电子战条件下的体系验证；谁先把“短窗口目标”转化为“可持续、可确认、可分配的目标对象”，谁就能显著压缩杀伤链并提升精确效能。
